19B.1 ทุนขั้นต่ำของเกม — Edge เป็น % ผ่าน แต่เป็น $ ไม่พอจ่าย Fee

ch19 คิด edge เป็น bps เทียบ friction เป็น bps — ผ่านทั้งคู่ แต่บัญชีเล็กเจอ "พื้นค่าธรรมเนียมแบบ absolute" ที่ไม่ scale ลง: futures คิด fee ต่อสัญญา (CME GC ~$2.5-5/side/contract รวม ~$10-20 ต่อ round-turn 2 ขา) MT5 ECN คิด $3-7/lot บาง exchange มี minimum fee ต่อ order

Minimum Viable Capital
ทุนขั้นต่ำ ≈ (fixed_fee_ต่อรอบ × safety_3) / (expected_edge_ต่อรอบ เป็นเศษส่วนของ notional)
ตัวอย่างหลัก: Edge ที่ "ผ่าน" แต่ $ ไม่พอ
Edge = 10bps บน position $1,000 = $1 ต่อรอบ Bybit taker 0.055% × 4 legs = $2.20 Net = $1 − $2.20 = −$1.20 ทุกรอบที่ "ชนะ" → edge 10bps "ผ่าน" เกณฑ์ % แต่ $ ไม่พอจ่าย fee ขั้นต่ำเลย
วิธีใช้

ก่อนเปิดบัญชีในตลาดไหน ให้เช็คว่า "ทุนของคุณถึงไหม" — ตารางจริง: Bybit taker 5.5bps×4 ขา, CME GC spread 1 lot, MT5 $/lot คำนวณทุนขั้นต่ำจากสูตรด้านบนก่อนเสมอ ตลาดที่ทุนยังไม่ถึงให้ข้ามไปก่อน ไม่ใช่ฝืนเทรดที่ size เล็กกว่าที่คณิตศาสตร์อนุญาต

19B.2 ต้นทุนคงที่รายเดือน — Hurdle Rate ที่บัญชีเล็กข้ามไม่ผ่าน

ระบบตามเล่มนี้ต้องมี: VPS ใกล้ venue 1-2 ตัว ($10-40/เดือน/ตัว), real-time market data (~$3-15/exchange/เดือนผ่านโบรกเกอร์), historical data สำหรับ walk-forward, charting/monitoring — รวม $50-150/เดือน = $600-1,800/ปี เป็น cost ที่จ่ายทุกเดือนไม่ว่าจะมี trade หรือไม่

ตลาด Full-Carry ที่ "ไม่มี Order" เจ็บซ้ำสอง

ตลาดที่ระบบบอกว่า "ไม่มี order" (ซึ่งถูกแล้ว ตาม ch17 §17.8) จึงเจ็บซ้ำสอง: จ่าย overhead เต็มแต่รอบเทรดเป็นศูนย์ บนทุน $5,000 overhead $1,200/ปี = ต้องทำ 24%/ปี แค่เพื่อเท่าทุน ก่อนคิด edge ใดๆ เลย

Break-even overhead: ทุน $5,000 + overhead $100/เดือน → hurdle = 24%/ปี ทุน $50,000 + overhead $100/เดือน → hurdle = 2.4%/ปี # เกมเดียวกัน คนละความเป็นไปได้ — ทุนที่ต่างกัน 10 เท่า ทำให้ hurdle ต่างกัน 10 เท่า
เพิ่มบรรทัดที่ 6 ใน Edge Waterfall ของ ch19

annualized_fixed_cost / capital แล้วให้สูตร break-even: ทุนขั้นต่ำที่ overhead เหลือ <2% ต่อปี เทคนิคลด: เริ่มจาก venue ที่ data ฟรี (Bybit/Lighter WebSocket ฟรี) เลื่อน CME ไปจนพอร์ตถึงขั้น รวม infra หลายกลยุทธ์บน VPS เดียว

19B.3 Annualize ก่อนตกหลุมรัก — เทียบกับ Benchmark เสมอ

Edge ต่อรอบดูสวย (เช่น 40bps) แต่ตัวหารคือเวลา: τ½ 5 วัน + รอ setup → 15-25 รอบ/ปี/คู่ → 6-10%/ปี บนทุนที่ล็อกเต็ม (สองขา+buffer ตาม ch17 §17.13) — ขณะที่ benchmark ที่ passive กว่ามากมีอยู่จริง: cash-and-carry รับ funding เฉลี่ย 8-15%/ปี หรือ T-bill 4-5%

กลยุทธ์ที่ "กำไร" อาจยังแพ้ทางเลือกที่ง่ายกว่า — และมองไม่เห็นเพราะไม่เคยเทียบ

ทุนที่จมใน trade ที่ยืด 3×τ½ (ดู time-stop ใน ch19 §19.11) คือทุนที่เปิดโอกาสใหม่ไม่ได้ ทั้งที่ z ตัวใหม่สวยกว่ากำลังวิ่งผ่านหน้า

Annualized Return on Locked Capital
annualized_ROC = edge_net × (365/avg_holding_days × utilization) / capital_locked
edge = 40bps × 18 รอบ/ปี = 7.2% บน notional หาร capital lock 2.5 เท่า (สองขา+buffer) = 2.9% จริง # เทียบ T-bill ~4-5%/ปี → 2.9% < T-bill!
กติกา

ทุกกลยุทธ์ต้องมีบรรทัด annualized ROC แล้วเทียบ 3 benchmark เสมอ: funding carry, T-bill, ไม่ทำอะไรเลย — ถ้าไม่ชนะ carry แบบ passive อย่างน้อย 1.5 เท่า ไม่คุ้มความซับซ้อน+tail risk ที่แบกเพิ่ม (สอดคล้องกับ Situation Card ทุกกลยุทธ์ในเล่มนี้ที่ควรมีช่อง "ความถี่×edge ต่อปี")

19B.4 ภาษีของนักสเปรดไทย

spread trade ที่กำไรสุทธิ +$200 มักประกอบจากขา A +$1,000 / ขา B −$800 — ปัญหาคือกฎภาษีมองที่ "รายธุรกรรม/รายประเภทสินทรัพย์" ไม่ได้มองที่ ε

กำไรขา A โดนเก็บเต็ม ขาดทุนขา B หักไม่ได้ → เทรดที่ชนะกลายเป็นขาดทุนหลังภาษี
  • ไทย: กำไร crypto เป็นเงินได้พึงประเมิน แต่การหักกลบขาดทุนทำได้เฉพาะธุรกรรมบน exchange ที่ได้รับอนุญาตจาก ก.ล.ต. ไทย — Bybit/Lighter ไม่ใช่ → ปีที่ gross win 500k / gross loss 450k อาจโดนประเมินบนฝั่งกำไรโดยหักฝั่งขาดทุนไม่ได้
  • เงินได้จากต่างประเทศ: (CME ผ่านโบรกนอก, MT5 offshore) ตามแนวปฏิบัติที่บังคับใช้ นำเข้าเมื่อไรเสียภาษีเมื่อนั้น ไม่ว่าจะเกิดปีไหน — การถอนกำไรกลับมาใช้จึงมี tax event ติดมาด้วย
  • ข้ามประเภทสินทรัพย์: (กำไร futures / ขาดทุน CFD) ยิ่งไม่มีช่องให้ net
ปีที่ net +50k แต่ gross win 500k: ถ้าหักกลบไม่ได้และโดน marginal rate 20% → ภาษี 100k = ขาดทุนจริง −50k ทั้งที่เทรด "กำไร"
ป้องกัน/ตรวจจับ
  1. ก่อนเลือก venue ถามว่า "ขาดทุนขานี้ หักกลบกับกำไรขาไหนได้บ้างตามกฎหมายไทย" — ตารางสถานะ: exchange ไทยที่ได้ใบอนุญาต (net ได้) vs offshore (เสี่ยง gross) vs futures ต่างประเทศ (เงินได้ต่างประเทศ)
  2. กันเงิน 15-35% ของ gross winning leg ไว้เป็น tax reserve — ไม่ใช่ % ของ net
  3. จังหวะ remit เงินกลับไทยคือ decision variable — วางแผนก่อน ไม่ใช่โอนตามอารมณ์
  4. เก็บ statement ทุก venue รายเดือน — ภาระพิสูจน์อยู่ฝั่งเรา

⚠️ กฎภาษีเปลี่ยนได้ตลอดเวลาและซับซ้อนตามสถานการณ์แต่ละคน — เนื้อหานี้เพื่อความเข้าใจเบื้องต้นเท่านั้น ปรึกษาผู้เชี่ยวชาญด้านภาษีก่อนตัดสินใจจริงเสมอ

🎯 สถานการณ์ที่ได้ใช้ (Situation Card) — เศรษฐศาสตร์ของบัญชีเล็ก
  • Trigger: ก่อนเปิดบัญชีหรือขยายไปตลาดใหม่ทุกครั้ง — ไม่ใช่แค่ตอนหาสัญญาณเทรด
  • เช็คก่อนเทรด: ทุนขั้นต่ำผ่านไหม (§19B.1), overhead รายเดือนกิน edge เกิน 2%/ปีไหม (§19B.2), annualized ROC ชนะ benchmark passive อย่างน้อย 1.5 เท่าไหม (§19B.3)
  • เช็คภาษี: ก่อนเทรดข้าม venue/jurisdiction ต้องรู้ว่าหักกลบกำไร-ขาดทุนได้ไหม (§19B.4) — อย่ารอจนถึงปีถัดไป
  • สัญญาณ setup พัง: ทุนไม่โต แต่ overhead คงที่หรือเพิ่มขึ้น (data fee ขึ้นราคา, VPS แพงขึ้น) → hurdle rate สูงขึ้นเรื่อยๆ จนกลยุทธ์ที่เคยคุ้มไม่คุ้มอีกต่อไป
โจทย์ 19B.1 — ทุนขั้นต่ำและ Overhead

กลยุทธ์หนึ่ง: edge เฉลี่ย 15bps/รอบ, 20 รอบ/ปี, fee ขั้นต่ำ $2/รอบ, overhead $80/เดือน

(ก) ทุนขั้นต่ำที่ position size ต้องมีเพื่อให้ fee ไม่กิน edge หมด (ให้ fee ≤ 30% ของ edge ต่อรอบ)
(ข) ทุนขั้นต่ำที่ overhead เหลือ <2%/ปี

ดูคำตอบ

(ก) edge ต่อรอบ = 15bps × position → ต้องการ 0.30 × (15bps × position) ≥ $2
position ≥ $2 / (0.30 × 0.0015) = ≈$4,444

(ข) overhead ปี = $80×12 = $960 → ต้องการ $960/capital < 0.02 → capital > $960/0.02 = $48,000

สรุป: (ข) เป็น binding constraint — ต้องมีทุนอย่างน้อย ~$48,000 ถึงจะทำให้ overhead ไม่ใช่ปัญหาหลัก แม้ (ก) จะผ่านที่ทุนแค่ ~$4,444 ก็ตาม

โจทย์ 19B.2 — Annualize แล้วเทียบ Benchmark

กลยุทธ์ A: edge 30bps/รอบ, 12 รอบ/ปี, capital lock 3× (cross-venue margin)

ถาม: Annualized ROC บน capital ที่จมจริงคือเท่าไร และชนะ T-bill (4.5%/ปี) ไหม

ดูคำตอบ

Edge บน notional = 30bps × 12 = 360bps = 3.6%/ปี
ROC จริง = 3.6% / 3 = 1.2%/ปี

1.2% < 4.5% (T-bill) → กลยุทธ์นี้แพ้การถือ T-bill เฉยๆ แม้จะมี "edge" ทางสถิติที่แท้จริงก็ตาม — ไม่คุ้มความซับซ้อนและความเสี่ยงที่แบกเพิ่ม ควรหาคู่ที่ capital lock ต่ำกว่า หรือ edge ต่อรอบสูงกว่านี้มาก

✓ สรุปบทนี้ — 4 อย่างที่ต้องจำ
  1. เช็คทุนขั้นต่ำก่อนเข้าตลาดไหนเสมอ — edge เป็น % ผ่านไม่ได้แปลว่า $ พอจ่าย fee ขั้นต่ำ
  2. Overhead รายเดือนคือ hurdle rate จริง — ทุนเล็กเจอ hurdle สูงกว่าทุนใหญ่มากในเกมเดียวกัน
  3. Annualize แล้วเทียบ benchmark เสมอ — "กำไร" ที่แพ้ T-bill ไม่คุ้มความซับซ้อนที่แบกเพิ่ม
  4. วางแผนภาษีล่วงหน้า — โดยเฉพาะข้าม venue/jurisdiction ที่หักกลบกำไร-ขาดทุนไม่ได้
