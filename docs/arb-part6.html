บทที่ 22: Merger Arbitrage (Risk Arb)

22.1 Cash Deal

Company A ซื้อ Company B ที่ ฿50/หุ้น (cash deal)
B ตอนนี้ซื้อขาย ฿47.50
Spread = 50 - 47.50 = ฿2.50 (5% ของราคาดีล ฿50)
ถ้า deal close ใน 3 เดือน → Annualized = 5% × 4 = 20% ต่อปี

📖 อ่านสูตรว่า: "สเปรด เท่ากับ 50 ลบ 47.50 เท่ากับ 2.50 บาท" แล้ว "ต่อปี เท่ากับ 5% คูณ 4" · โครงที่ต้องเห็น: ส่วนต่างเป็นบาท → หารด้วยราคาจึงเป็น % ต่อรอบ → คูณจำนวนรอบต่อปีจึงเป็น % ต่อปี สามขั้น สามหน่วย · กับดักการอ่าน: 2.50/47.50 = 5.26% (ฐานคือเงินที่ลงจริง) ส่วน 2.50/50 = 5% (ฐานคือราคาดีล) กล่องใช้ตัวหลัง ต้องตกลงให้ชัดว่าฐานคืออะไร · "× 4" คือ annualize แบบไม่ทบต้น และสมมติว่าดีลปิดครบ 3 เดือนพอดี — ปิดช้าอีกเดือน ตัวเลขต่อปีตกเป็น 15% ทันที (5% × 12/4)

Risk: Deal Break

ถ้า deal ไม่สำเร็จ → B อาจตกกลับไป ฿35 → เสีย ฿12.50 (25%!)
Risk/Reward = เสีย ฿12.50 เพื่อได้ ฿2.50 → ต้องมั่นใจ >83.3% ว่า deal จะสำเร็จ (P > 12.50/15 = 83.3%)

22.2 Stock Deal

A ซื้อ B ด้วยหุ้น A ในอัตรา 0.8 หุ้น A ต่อ 1 หุ้น B
→ Long B + Short 0.8×A = locked spread (ถ้า deal close)
กำไร = B - 0.8×A - transaction costs

📖 อ่านสูตรว่า: "กำไร เท่ากับ บี ลบ ศูนย์จุดแปดคูณเอ ลบ ต้นทุน" · โครงที่ต้องเห็น: โครงเดียวกับ spread ของ pairs (B − βA) แต่คราวนี้ β = 0.8 เป็นอัตราแลกที่ประกาศในดีล รู้แน่ ไม่ต้องประมาณจาก regression — นี่คือเหตุที่ spread นี้ล็อกได้ถ้าดีลปิด · กับดักการอ่าน: "0.8 หุ้น A ต่อ 1 หุ้น B" อ่านว่า short A 0.8 หุ้นต่อทุก 1 หุ้น B ที่ถือ ไม่ใช่ short 80% ของเงินที่ลงใน B

บทที่ 23: Special Situations

23.1 Spin-Off Arbitrage

Parent แยก SpinCo ออก → นักลงทุนขาย SpinCo เพราะไม่ต้องการ (forced selling) → SpinCo ถูกเกินไป

23.2 Index Rebalancing

หุ้นเข้า SET50 → index funds ต้องซื้อ → demand spike → ราคาขึ้นชั่วคราว
หุ้นออก SET50 → index funds ต้องขาย → supply spike → ราคาลงชั่วคราว
→ ซื้อก่อนวัน rebalance → ขายหลัง index funds ซื้อเสร็จ

23.3 Stub Trading

Parent ถือ SpinCo 80% + Other Business
Other Value = Parent Market Cap - 0.8 × SpinCo Market Cap
ถ้า Other Value ≤ 0 → ตลาดให้ราคา Other = ศูนย์หรือติดลบ! → ซื้อ Parent Short SpinCo

📖 อ่านสูตรว่า: โครงเดียวกับ 22.2: "มูลค่าธุรกิจอื่น เท่ากับ มูลค่าตลาดของแม่ ลบ ศูนย์จุดแปดคูณมูลค่าตลาดของลูก" — 0.8 คือสัดส่วนที่แม่ถือ (รู้แน่) และ "ซื้อแม่ short ลูก 0.8 เท่า" คือพอร์ตที่แปลงสมการนี้เป็นไม้จริง · กับดักการอ่าน: ทั้งสองข้างต้องเป็น market cap (บาท) ไม่ใช่ราคาต่อหุ้น เพราะจำนวนหุ้นของแม่กับลูกไม่เท่ากัน

กรณีศึกษา: Yahoo / Alibaba (2015)

Yahoo ถือ Alibaba 15% → มูลค่า Alibaba stake > Yahoo market cap → Yahoo's core business ถูก value ติดลบ!
Stub trade: Long Yahoo + Short Alibaba → กำไรเมื่อ market "ตื่น" ขึ้น (ใช้เวลา 2 ปี)

จาก Special Situations ที่เป็น "เหตุการณ์ระดับบริษัท" (M&A, Spin-Off, Index Rebalancing) ตอนนี้เราจะขยายไปสู่ เหตุการณ์ที่เกิดซ้ำๆ เช่น ประกาศผลประกอบการ การประชุม Fed — และใช้ Options เป็นเครื่องมือ:

บทที่ 24: Event-Driven with Options

24.1 Earnings Arbitrage: IV vs Realized Move

ก่อนประกาศผล: IV spike สูง (ตลาดกลัว)
Historical average earnings move = ~1.6% (≈ 25% annualized vol)
ถ้า IV = 45% → overpriced 20 vol points
→ Sell straddle/strangle → เก็บ premium ส่วนเกิน [Lv.4 Heuristic]

📖 อ่านสูตรว่า: "move เฉลี่ย 1.6% ประมาณเท่ากับ vol 25% ต่อปี" · กับดักการอ่าน: ≈ ตรงนี้ซ่อนสมมติฐานสองข้อ — (1) ถือว่า move วันประกาศเป็น σ รายวัน แล้วคูณ √252: 1.6% × 15.87 ≈ 25.4% (2) ถือว่า move กระจายแบบ normal ซึ่งวันประกาศมักไม่ใช่ (หางอ้วน) · "20 vol points" = 45 − 25 อยู่ในหน่วย % ต่อปีของ σ ไม่ใช่กำไร 20% · ต้องแปลงทั้งสองข้างเป็นหน่วยเดียวกันก่อนพูดว่า "แพงเกิน" — เทียบ 1.6% กับ 45% ตรงๆ ไม่มีความหมาย

ระวัง: Tail Risk!

ส่วนใหญ่ move < IV → seller wins → แต่ 1 ครั้งใน 10 move >> IV → เสียหนัก
ต้อง size เล็ก + ทำเป็น portfolio ของหลายๆ earnings → Law of Large Numbers

24.2 Binary Events: FDA, Election

เหตุการณ์ที่ผลออก 2 ทาง → ราคากระโดด → ใช้ PM probability cross-check กับ IV

PM + Options Edge

PM "FDA approve" = 65% แต่ Options implied prob = 50% → inconsistency 15%
ถ้าเชื่อ PM มากกว่า → ซื้อ Call (ราคายัง price 50%) → edge 15%
[Heuristic — ต้องประเมินว่าใครถูกกว่า]

เรื่องจริง: Porsche-VW Squeeze (2008)

Porsche ค่อยๆ สะสมหุ้น VW + options จนถือ 74% โดยไม่มีใครรู้ → ประกาศ → short sellers ต้องซื้อคืน (short squeeze) → VW กลายเป็นบริษัทที่ market cap สูงสุดในโลกชั่วคราว (€1,000/หุ้น จาก €200!)
บทเรียน: Merger/Event arb มี hidden risks ที่ model ไม่จับ — ใครจะคิดว่า VW จะเป็นหุ้นแพงสุดในโลก?
