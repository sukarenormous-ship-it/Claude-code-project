🧭 เส้นทางอ่าน

🟢 มือใหม่: ทำ Visual Drill 1 (นับจุดหักศอก) ให้แม่นก่อน เพราะเป็นทักษะอะตอมที่ drill อื่นต่อยอด · 🔵 มีพื้นบ้างแล้ว: ลอง Drill 5 (ฝาแฝด) เพื่อทดสอบว่าตาคุณแยก "รูปทรง" ออกจาก "วิธีสร้าง" ได้จริงไหม

บทนี้เป็นคู่แฝดภาพของ Workshop ในบท VI (drill ที่เป็นตัวหนังสือ) — ทำหลังจากผ่าน Drill Level 1-2 ของบทนั้นแล้วจะได้ผลที่สุด

ในบท VI เราฝึกอ่าน payoff จาก ตัวหนังสือ ("แบน(−5) → +1 ที่ 90 → −1 ที่ 110"). แต่หน้างานจริง คุณเจอ ภาพ ก่อนเสมอ — บนจอเทรด ในรีเสิร์ช ในสไลด์ที่โบรกเกอร์ยื่นให้ ทักษะที่ต่างออกไปคือ "เห็นเส้น แล้วถอดกลับเป็น legs ได้ทันที" นี่คือสนามฝึกของทักษะนั้น

❓ ทำไมกราฟในบทนี้ถึงเป็นเส้นสีเดียว ไม่มีเขียว/แดง

ทั้งเล่มเราระบายเขียว=กำไร แดง=ขาดทุน เพื่อช่วยให้อ่านง่าย — แต่ในสนามฝึกนี้เราจงใจตัดสีออก เหลือเส้นน้ำเงินเส้นเดียว เพราะถ้ามีสีช่วย ตาจะแอบใช้สีเดา แทนที่จะอ่าน "รูปทรง" จริง ๆ พอฝึกอ่านรูปเปล่าได้แล้ว เวลากลับไปเจอกราฟมีสี คุณจะอ่านเร็วขึ้นอีก

Visual Drill 1: นับจุดหักศอก

🚶 อ่านเป็นภาษาคนก่อน: "จุดหักศอก" (kink) คือจุดที่เส้นเปลี่ยนความชัน แต่ละจุดหักศอกเกิดที่ strike หนึ่งค่า ดังนั้นนับจุดหักศอกได้เท่าไร ก็รู้ทันทีว่ากราฟนี้เกี่ยวกับ strike กี่ค่า — และรู้ว่าอย่างน้อยต้องใช้ option กี่ขาถึงจะสร้างมันได้

บทเรียนหลัก: "จำนวนจุดหักศอก = จำนวน strike ที่ไม่ซ้ำ" — แต่ ขนาดของการกระโดดที่แต่ละจุด บอกว่ามี option กี่ขากระทำตรงนั้น (กระโดด 2 หน่วย = 2 ขาซ้อนที่ strike เดียว เหมือน Straddle/ขากลางของ Butterfly)

🧠 มุมที่มองต่าง

มือใหม่เห็น Straddle (ข้อ 3) กับ Long Call (ข้อ 1) ว่า "ก็มีจุดหักศอกเท่ากัน (1 จุด) น่าจะซับซ้อนพอกัน" — แต่คนที่อ่านเป็นจะดูความชันสองข้างของจุดหักศอก ก่อน: ข้อ 1 กระโดดจาก 0→+1 (1 ขา) ส่วนข้อ 3 กระโดดจาก −1→+1 (2 ขา) จุดหักศอกเดียวกันแต่ "น้ำหนัก" ต่างกัน

Visual Drill 5: ฝาแฝดที่ไม่เหมือน

🚶 อ่านเป็นภาษาคนก่อน: กราฟสองอันที่ รูปทรงเหมือนกันเป๊ะ อาจถูกสร้างจาก option คนละชุด — และถ้า payoff เท่ากัน มันก็คือของสิ่งเดียวกันในเชิงความเสี่ยง ต่างแค่ "ป้ายชื่อ" กับกระแสเงินตอนเปิด position เท่านั้น drill นี้ฝึกตาให้เชื่อ "รูปทรง" มากกว่า "ชื่อ"

คู่ A — เหมือนกันเป๊ะ: ทั้งสองคือ Bull Call Spread (จาก Call) กับ Bull Put Spread (จาก Put) — payoff รูปทรงเดียวกัน (แบน → ขึ้น → แบน) ต่างกันแค่กระแสเงินตอนเปิด: BCS จ่าย premium ก่อน (debit) ส่วน BPS รับ premium ก่อน (credit) จะเลือกอันไหนขึ้นกับว่าฝั่งไหนราคาดีกว่า (skew)

คู่ B — เหมือนกันเป๊ะ: คือเอกลักษณ์ Covered Call = Short Put จากบทที่ 7 — ชันขึ้นทางซ้าย แล้วแบน (cap) ทางขวาเหมือนกัน ทั้งคู่คือ "เก็บ premium แลกกับ upside ที่ถูกจำกัด และแบก downside เต็ม ๆ" คนละชื่อ แต่ความเสี่ยงตัวเดียวกัน

บทเรียนหลัก: ถ้ารูปทรงเท่ากัน = payoff เท่ากัน = ความเสี่ยงเท่ากัน อย่าให้ "ชื่อ" หลอกตา ให้ตัดสินที่รูปทรงและต้นทุนจริงเสมอ

🎯 3 อย่างที่ต้องจำจากสนามฝึกนี้
  • นับจุดหักศอก = นับ strike — ทักษะอะตอมที่ทำก่อนอย่างอื่นเสมอ
  • ขนาดการกระโดดที่จุดหักศอก = จำนวนขา ที่กระทำตรงนั้น (กระโดด 2 = 2 ขาซ้อน)
  • รูปทรงเท่ากัน = ของสิ่งเดียวกัน — ชื่อกับกระแสเงินต่างได้ แต่ความเสี่ยงเท่ากัน
📋 บทเต็มจะเพิ่มอะไรอีก (ถ้าเดินต่อ)

Pilot นี้โชว์ 2 ใน 8 drill สายตา — บทเต็มจะเติมอีก 6 แบบ แต่ละแบบฝึกทักษะคนละตัว:

  • เดาความชันด้วยตา — แยก slope 0 / +1 / +2 ให้ออกเมื่อมอง (+2 กับ +1 หลอกตาได้)
  • เช็คหาง 2 ข้าง — มองซ้ายสุด-ขวาสุด รู้ทันทีว่า risk จำกัดหรือไม่
  • 3 วินาที: เห็นแล้วบอกชื่อ — flashcard ภาพ → ชื่อ strategy
  • จับผิดกราฟ — กราฟที่วาด slope ผิด 1 จุด หาให้เจอ
  • ตัวไหนแปลก — 4 กราฟ อันไหนไม่เข้าพวก
  • มองทะลุ = แยกชั้น — ลากเส้นรวมกลับเป็นแต่ละขา
อ่านกราฟเหมือนอ่านตัวอักษร — ตอนเริ่มคุณสะกดทีละจุดหักศอก พอฝึกพอ คุณจะอ่านทั้งรูปในแวบเดียว โดยไม่รู้ตัวว่าเคยต้องสะกด
📖 ศัพท์ใหม่ในตอนนี้

จุดหักศอก (kink) = จุดที่เส้น payoff เปลี่ยนความชัน เกิดที่ strike แต่ละค่า · ขนาดการกระโดด (slope jump) = ความชันเปลี่ยนไปกี่หน่วยที่จุดหักศอก บอกจำนวนขาที่กระทำตรงนั้น · ฝาแฝด payoff = สอง strategy ที่รูปทรง payoff เหมือนกันเป๊ะ แต่สร้างจาก option คนละชุด
