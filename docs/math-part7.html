บทที่ 15: ทุกอย่างรวมกัน — "อ่าน Black-Scholes ออก"

ถึงเวลาพิสูจน์ว่าคุณเข้าใจจริง — ไล่สูตร BS ทีละตัวแล้วชี้ว่าแต่ละส่วนมาจากบทไหน

15.1 สูตร Black-Scholes ฉบับเต็ม

C = S₀ × N(d₁) - K × e-rT × N(d₂)

P = K × e-rT × N(-d₂) - S₀ × N(-d₁)
d₁ = [ln(S₀/K) + (r + σ²/2)T] / (σ√T)
d₂ = d₁ - σ√T

15.2 ไล่ทีละตัว — มาจากบทไหน?

ส่วนประกอบความหมายเรียนในบทที่
S₀ราคาหุ้นปัจจุบันบท 1: ตัวแปรในฟังก์ชัน
KStrike Priceบท 1: max(0, S-K)
e-rTDiscount factor (PV)บท 3: Continuous compounding
K × e-rTPV(K) ใน Put-Call Parityบท 3: Present Value
N(d)CDF ของ Normal Distributionบท 6: Normal, Z-score, CDF
N(d₁)≈ P(expire ITM) ปรับด้วย deltaบท 6: CDF + บท 7: Delta
N(d₂)≈ P(exercise) ใน risk-neutral worldบท 14: Risk-Neutral Pricing
ln(S₀/K)Log moneynessบท 3: ln, log return
σVolatility (Std Dev ของ log returns)บท 4: σ + บท 6: Lognormal
σ√TVolatility scaled ด้วยเวลาบท 14: Brownian Motion (variance ∝ T)
r + σ²/2Drift ใน risk-neutral worldบท 14: GBM + Ito's correction
σ²/2Ito's correction termบท 14: Ito's Lemma

15.3 พิสูจน์ Put-Call Parity จาก BS

C - P = S₀·N(d₁) - K·e-rT·N(d₂) - [K·e-rT·N(-d₂) - S₀·N(-d₁)]
= S₀·[N(d₁) + N(-d₁)] - K·e-rT·[N(d₂) + N(-d₂)]
= S₀·(1) - K·e-rT·(1)    ← เพราะ N(x) + N(-x) = 1
= S₀ - K·e-rT

→ C + K·e-rT = P + S₀    ✓ Put-Call Parity!
ทุกอย่างเชื่อมกัน!

Put-Call Parity (บท 2) ← มาจาก BS formula ← มาจาก Ito's Lemma (บท 14) ← มาจาก Chain Rule (บท 7) + Brownian Motion (บท 14) ← มาจาก Normal Distribution (บท 6) ← มาจาก e, ln (บท 3)

บทที่ 16: Monte Carlo Simulation — "จำลองอนาคต 10,000 ครั้ง"

เมื่อไม่มีสูตร closed-form (exotic options, complex strategies) → จำลองราคาหุ้นหลายๆ ครั้ง แล้วเฉลี่ย

16.1 แนวคิด Monte Carlo

สุ่มหลายๆ ครั้ง แล้วเฉลี่ย = คำตอบ — Law of Large Numbers รับรองว่า converge

1. สุ่ม Z ~ N(0,1) จำนวน N ครั้ง (เช่น N = 100,000)
2. คำนวณ S(T) = S₀ × exp((r - σ²/2)T + σ√T × Z)
3. คำนวณ Payoff แต่ละ path: max(0, S(T) - K)
4. ราคา Call = e-rT × mean(Payoffs)

16.2 เปรียบเทียบ MC กับ BS

พารามิเตอร์ค่า
S₀ = 100, K = 100, r = 5%, σ = 25%, T = 1 ปี
BS Formula (exact)C = 12.336
MC 1,000 pathsC ≈ 12.5 ± 0.8
MC 10,000 pathsC ≈ 12.38 ± 0.25
MC 100,000 pathsC ≈ 12.34 ± 0.08
MC 1,000,000 pathsC ≈ 12.336 ± 0.025
สังเกต: ยิ่ง paths มาก ยิ่งแม่น (error ∝ 1/√N)

100,000 paths → error ≈ 0.08 — ดีพอสำหรับการเทรดจริง
ข้อดีของ MC: ใช้ได้กับทุก option ไม่ว่าจะซับซ้อนแค่ไหน

16.3 Exotic Options — ที่ BS แก้ไม่ได้

Exotic OptionPayoffทำไมต้อง MC?
Asian Optionmax(0, avg(S) - K)Payoff ขึ้นกับราคาเฉลี่ยตลอดทาง
Barrier Optionหมดค่าถ้าราคาแตะ barrierขึ้นกับเส้นทางทั้งหมด
Lookback Optionmax(0, max(S) - K)Payoff ขึ้นกับราคาสูงสุดตลอดทาง
Basket Optionmax(0, avg(S₁,S₂,...) - K)ขึ้นกับหลายสินทรัพย์พร้อมกัน
ทุก option price ได้ด้วย MC เพียงแค่:

1. จำลอง price paths (อาจต้องหลายสินทรัพย์, หลายช่วงเวลา)
2. คำนวณ payoff ตาม definition ของ exotic option นั้นๆ
3. เฉลี่ย แล้ว discount กลับ
ไม่ต้องมีสูตร closed-form — นี่คือพลังของ Monte Carlo!

16.4 Variance Reduction

ทำให้ MC แม่นขึ้นโดยไม่ต้องเพิ่ม paths:

เทคนิควิธีการผลลัพธ์
Antithetic Variatesถ้าสุ่ม Z → ใช้ -Z ด้วย (คู่สมมาตร)ลด variance ~50%
Control Variatesใช้ option ที่มี closed-form เป็น "ตัวควบคุม"ลด variance มาก

ภาคผนวก: แผนที่ความรู้ทั้งหมด
