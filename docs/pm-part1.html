บทที่ 2: Put-Call Parity — "สมการที่ทรงพลังที่สุด"

C + K·e⁻ʳᵀ = P + S

📖 อ่านสูตรว่า: "ซี บวก เค คูณ อี ยกกำลัง ลบ อาร์ที เท่ากับ พี บวก เอส" · โครงที่ต้องเห็น: สมการสองฝั่งที่ต่างเป็น "ผลรวมของขา" — ฝั่งซ้าย Call + เงินสด ฝั่งขวา Put + หุ้น · ถ้า r = 0 หรือ T = 0 ตัวคูณกลายเป็น e⁰ = 1 → สูตรย่อเหลือ C + K = P + S · กับดักการอ่าน: e⁻ʳᵀ คือ ตัวลดค่า (น้อยกว่า 1 เสมอเมื่อ r, T > 0) ไม่ใช่ตัวแปรใหม่ — มันคูณอยู่กับ K เท่านั้น ไม่ได้คูณทั้งฝั่ง · เลขยกกำลังติดลบอ่านว่า "หนึ่งหารด้วย eʳᵀ" · C, P, S คือราคา วันนี้ ส่วน K คือตัวเลขในสัญญาที่จ่ายกัน วันหมดอายุ — e⁻ʳᵀ คือสิ่งที่ดึง K มาอยู่วันเดียวกับตัวอื่น

e⁻ʳᵀ คืออะไร? (สำหรับผู้อ่านใหม่)

e⁻ʳᵀ = "ตัวคูณลดค่า" — แปลงเงินอนาคตเป็นมูลค่าวันนี้
K=100, r=5%, T=0.5 ปี → Ke⁻ʳᵀ = 100 × e⁻⁰·⁰²⁵ = ฿97.53
= "ฝาก ฿97.53 วันนี้ ดอกเบี้ย 5% → 6 เดือนหลังได้ ฿100 พอดี" = PV(K)

พิสูจน์ PCP ด้วย Payoff Chart

ฝั่งซ้าย: Long Call + Bond (เงินสด K ณ expiry)

ถ้า S > K: ใช้สิทธิ Call ซื้อหุ้นที่ K, จ่าย K จาก Bond → ได้หุ้นมูลค่า S → รวมได้ S
ถ้า S ≤ K: Call หมดค่า + มีเงินสด K → ได้ K
→ ฝั่งซ้ายได้ = max(S, K)

📖 อ่านสูตรว่า: max(S, K) อ่านว่า "ค่าที่มากกว่าระหว่าง S กับ K" — คนละตัวกับ max(S − K, 0) ของบท 1: ตัวนี้เลือก ราคา ตัวนั้นเลือก ส่วนต่าง · ลองแทน S = 120, K = 100 → 120 · S = 80 → 100 · โครงที่ต้องเห็น: กล่องนี้คือการแยกกรณี (S > K / S ≤ K) แล้วสรุปเป็นฟังก์ชันเดียว — กล่องถัดไปทำแบบเดียวกันกับฝั่งขวาและได้คำตอบเดียวกัน นั่นคือตัวพิสูจน์

ฝั่งขวา: Long Put + Stock

ถ้า S > K: Put หมดค่า + มีหุ้นมูลค่า S → ได้ S
ถ้า S ≤ K: ใช้สิทธิ Put ขายที่ K + หุ้น → ได้ K
→ ฝั่งขวาได้ = max(S, K)
ทั้งสองฝั่ง = max(S, K) เสมอ!

ไม่ว่าราคาจะจบที่ไหน → ทั้งสองฝั่งให้ผลเท่ากัน → ราคาวันนี้ต้องเท่ากัน
นี่คือ Put-Call Parity: C + PV(K) = P + S [Exact Identity — จริงเสมอสำหรับ European Options]

ตัวอย่างตัวเลข

S=100, K=100, r=5%, T=0.5, C=8.50, P=5.80

ฝั่งซ้าย: C + PV(K) = 8.50 + 97.53 = 106.03
ฝั่งขวา: P + S = 5.80 + 100 = 105.80
ต่าง = 0.23 → Violation! แต่หลังหัก costs อาจไม่เหลือ (ดูบท 4)
Phantom Arb — ระวัง!

ถ้าลืมใส่ e⁻ʳᵀ แล้วคำนวณ C + K (แทนที่จะเป็น C + Ke⁻ʳᵀ):
C + K = 8.50 + 100 = 108.50 vs P + S = 105.80 → ต่าง ฿2.70!
แต่ ฿2.47 ของส่วนต่างนี้คือ phantom arb จากการลืม discount!
Arb จริงมีแค่ ฿0.23 (ถ้ามี) — นี่คือ mistake ที่พบบ่อยที่สุดของ PCP

PCP ใช้ได้เมื่อไร?

✅ European Options (ใช้สิทธิได้แค่วันหมดอายุ)
⚠️ American Options → เป็น inequality ไม่ใช่ equality (เพราะ early exercise)
⚠️ มี Dividend → ต้องปรับ: C + PV(K) = P + S − PV(Dividends)

ลองคิดดู (บท 2)

C=12, P=7, S=100, K=100, r=2%, T=1 → PV(K) = 100×e⁻⁰·⁰² = 98.02
ฝั่งซ้าย = ? ฝั่งขวา = ? มี violation ไหม? ถ้ามีทำอะไร?
เฉลย: ซ้าย=12+98.02=110.02, ขวา=7+100=107.00 → violation ฿3.02 → ซ้าย>ขวา → Conversion (ซื้อขวา ขายซ้าย)

3 สิ่งที่ต้องจำ

1. C + PV(K) = P + S — จริงเสมอสำหรับ European Options
2. อย่าลืม PV(K)! ใช้ Ke⁻ʳᵀ ไม่ใช่ K → ลืม = เห็น phantom arb ฿2.47
3. ทั้งสองฝั่ง = max(S,K) ที่ expiry → payoff เท่ากัน → ราคาต้องเท่ากัน

บทที่ 3: Synthetic Positions — "จัดรูป PCP = สร้างทุกอย่าง"

จากสมการเดียว C + B = P + S (B = PV(K)) → จัดรูปใหม่ได้ 6 Synthetics (3 คู่ Long/Short):

คู่ที่ 1: Synthetic Stock

Synthetic Long Stock = Long Call + Short Put + Bond
S = C − P + B

Synthetic Short Stock = Short Call + Long Put − Bond
−S = −C + P − B

📖 อ่านสูตรว่า: "เอส เท่ากับ ซี ลบ พี บวก บี" — จัดรูปจาก C + B = P + S โดยย้าย P ข้ามเครื่องหมายเท่ากับ · โครงที่ต้องเห็น: payoff = ผลรวมของขา: เครื่องหมาย + หน้าตัวไหน = Long ตัวนั้น เครื่องหมาย − = Short · บรรทัด −S = −C + P − B คือสมการเดิมคูณ −1 ทั้งสองฝั่ง จึงพลิกทุกขาพร้อมกัน · กับดักการอ่าน: B = PV(K) คือเงินสดที่ลดค่าแล้ว (K·e⁻ʳᵀ จากบท 2) ไม่ใช่ราคาพันธบัตรตัวใหม่ · สองกล่องถัดไป (Synthetic Call, Synthetic Put) อ่านด้วยกฎเดียวกัน — ย้ายตัวที่อยากได้ไปฝั่งซ้าย แล้วดูเครื่องหมายที่เหลือ

ใช้เมื่อไร?

ยืมหุ้นไม่ได้ (short sell ban) → สร้าง Synthetic Short Stock แทน
ต้องการ stock exposure แต่ไม่อยากซื้อหุ้นจริง (leverage) → ใช้ Synthetic Long Stock

คู่ที่ 2: Synthetic Call

Synthetic Long Call = Long Stock + Long Put − Bond
C = S + P − B

Synthetic Short Call = Short Stock + Short Put + Bond
−C = −S − P + B

คู่ที่ 3: Synthetic Put

Synthetic Long Put = Long Call + Short Stock + Bond
P = C − S + B

Synthetic Short Put = Short Call + Long Stock − Bond
−P = −C + S − B
กฎทอง: "ถ้าไม่มี X → สร้างจาก Y + Z"

ไม่ต้องจำ 6 สูตร — แค่จัดรูป C + B = P + S แล้วแยกตัวที่ต้องการไปอยู่ฝั่งซ้าย
ทุก Synthetic payoff "same shape" กับของจริง (ต่างกันแค่ค่าคงที่จาก financing)

ลองคิดดู (บท 3)

1. ต้องการ Short Put แต่ broker ไม่อนุญาต → สร้าง Synthetic ยังไง?
2. Synthetic Long Stock ราคา ฿98 แต่หุ้นจริงราคา ฿100 → ทำอะไรได้?
เฉลย: 1. −P = −C + S − B → Short Call + Long Stock − Bond 2. ซื้อ Synthetic ฿98 ขาย Stock จริง ฿100 = กำไร ฿2 (ถ้าหลังหัก costs ยังเหลือ)

บทที่ 4: Conversion, Reversal, Box Spread

4.1 Conversion = "ล็อคกำไรจาก PCP Violation"

Conversion = Long Stock + Long Put + Short Call
= S + P − C = PV(K) = Bond
→ Payoff = คงที่ทุกสถานการณ์ = risk-free profit (ถ้ามี violation)

📖 อ่านสูตรว่า: "เอส บวก พี ลบ ซี เท่ากับ พีวีของเค" · โครงที่ต้องเห็น: ผลรวมสามขาที่ตัวแปรสุ่ม S หายไปจากฝั่งขวา — เหลือแต่ค่าคงที่ PV(K) นี่คือความหมายของ "risk-free": payoff ไม่ขึ้นกับ S แล้ว · ลองเช็ค payoff วันหมดอายุที่ K = 100: S = 120 → หุ้น 120 + Put 0 − Call 20 = 100 · S = 80 → หุ้น 80 + Put 20 − Call 0 = 100 — ได้ K ทุกกรณี มูลค่าวันนี้จึงเท่ากับ PV(K) · Reversal ในกล่องถัดไปคือสมการเดิมคูณ −1

4.2 Reversal = "กลับด้าน Conversion"

Reversal = Short Stock + Short Put + Long Call
= −S − P + C = −PV(K)
→ ใช้เมื่อ PCP violation ไปทางตรงข้าม

4.3 Box Spread = "สร้าง Bond จาก Options"

Box Spread = Bull Call Spread(K₁,K₂) + Bear Put Spread(K₁,K₂)
= PV(K₂ − K₁) [Exact Identity]

ตัวอย่าง: K₁=90, K₂=110, r=5%, T=0.25
Fair Box = (110-90) × e⁻⁰·⁰¹²⁵ = 20 × 0.9876 = ฿19.75
ถ้า Box ซื้อได้ ฿18.50 → กำไร ฿1.25 risk-free!

📖 อ่านสูตรว่า: "บ็อกซ์ เท่ากับ พีวีของ เคสอง ลบ เคหนึ่ง" — มูลค่าปัจจุบันของความกว้างระหว่างสองสไตรก์ · โครงที่ต้องเห็น: สองสเปรดที่รวมกันแล้ว payoff = K₂ − K₁ ทุกกรณี (bull call ให้ส่วนบน bear put ให้ส่วนล่าง) → มูลค่าวันนี้ต้องเท่ากับเงินสดจำนวนนั้นที่ลดค่าแล้ว · กับดักการอ่าน: ตัวห้อย 1, 2 ใน K₁, K₂ คือ หมายเลขสไตรก์ (ต่ำ/สูง) ไม่ใช่เวลา · e⁻⁰·⁰¹²⁵ มาจาก r × T = 0.05 × 0.25 = 0.0125 — ทั้งก้อนอยู่บนเลขยกกำลัง ไม่ใช่ "e ลบ 0.0125"

⚠️ Box ≠ Bond ถ้า American Options!

Box Spread = PV(width) เฉพาะ European Options เท่านั้น
ถ้าใช้ American → Short legs อาจถูก exercise ก่อนหมดอายุ → "Bond" แตก!
กรณี Reddit 2019: User ทำ Box บน Robinhood (American Options) → เสีย $58,000
เพราะ Box "แตก" จาก early exercise → ตรวจ exercise style ก่อนเสมอ!

4.4 Dividend Arbitrage

ก่อน ex-div: American Call อาจคุ้มที่จะ exercise ก่อนเพื่อรับ dividend
ถ้า Options ไม่ price early exercise premium → ซื้อ Call ถูก → exercise → ได้ dividend

ลองคิดดู (บท 4)

Box Spread: K₁=95, K₂=105, r=3%, T=0.5 → Fair = ? ถ้าซื้อได้ ฿9.50 → กำไรเท่าไร?
เฉลย: Fair = 10 × e⁻⁰·⁰¹⁵ = 10 × 0.9851 = ฿9.85 → ซื้อ ฿9.50 → PV profit ฿0.35 วันนี้ (nominal profit ที่ expiry = 10 - 9.50 = ฿0.50) [Lv.1 ถ้า European]

3 สิ่งที่ต้องจำ

1. Conversion = S + P − C = Bond → ล็อคกำไร PCP violation
2. Box Spread = PV(K₂−K₁) → สร้าง "พันธบัตร" จาก Options [European เท่านั้น!]
3. ตรวจ exercise style ก่อนเสมอ — American Box ≠ Bond (Reddit $58K lesson)
