ในบท VI เราฝึกอ่าน payoff จาก ตัวหนังสือ ("แบน(−5) → +1 ที่ 90 → −1 ที่ 110"). แต่หน้างานจริง คุณเจอ ภาพ ก่อนเสมอ — บนจอเทรด ในรีเสิร์ช ในสไลด์ที่โบรกเกอร์ยื่นให้ ทักษะที่ต่างออกไปคือ "เห็นเส้น แล้วถอดกลับเป็น legs ได้ทันที" นี่คือสนามฝึกของทักษะนั้น

❓ กติกา 2 ข้อของสนามฝึกนี้

1. งานคือ "มองรูป" ไม่ใช่ "จำชื่อ": ทุกโจทย์ตอบได้ด้วยการนับ/เทียบ/มองรูปทรงล้วน ๆ ไม่ต้องรู้จักชื่อกลยุทธ์มาก่อน เฉลยเท่านั้นที่จะเปิดชื่อให้ — เพื่อให้คุณเรียนชื่อจากรูป ไม่ใช่ท่องชื่อแล้วมาเดารูป

2. ตัดสีออกโดยตั้งใจ: ทั้งเล่มระบายเขียว=กำไร แดง=ขาดทุน แต่ในสนามนี้เหลือเส้นน้ำเงินเส้นเดียว เพราะถ้ามีสีช่วย ตาจะแอบใช้สีเดาแทนอ่านรูปทรงจริง พอฝึกอ่านรูปเปล่าได้ เวลากลับไปเจอกราฟมีสีจะเร็วขึ้นอีก

Drill 1: นับจุดหักศอก

🚶 อ่านเป็นภาษาคนก่อน: "จุดหักศอก" (kink) คือจุดที่เส้นเปลี่ยนความชัน แต่ละจุดหักศอกเกิดที่ strike หนึ่งค่า ดังนั้นนับจุดหักศอกได้เท่าไร ก็รู้ทันทีว่ากราฟนี้เกี่ยวกับ strike กี่ค่า — และรู้ว่าอย่างน้อยต้องใช้ option กี่ขาถึงจะสร้างมันได้

บทเรียนหลัก: "จำนวนจุดหักศอก = จำนวน strike ที่ไม่ซ้ำ" — แต่ ขนาดของการกระโดดที่แต่ละจุด บอกว่ามี option กี่ขากระทำตรงนั้น (กระโดด 2 หน่วย = 2 ขาซ้อน) และ จุดหักศอกคือ "การเปลี่ยนความชัน" ไม่ใช่ "การเปลี่ยนทิศ" — เส้นที่ขึ้นชันกว่าเดิมก็หักศอกแล้ว (ข้อ 7) ส่วนเส้นตรงสนิท = 0 จุด = ไม่มี option (ข้อ 8)

🧠 มุมที่มองต่าง

มือใหม่เห็น Straddle (ข้อ 3) กับ Long Call (ข้อ 1) ว่า "ก็มีจุดหักศอกเท่ากัน (1 จุด) น่าจะพอกัน" — แต่คนที่อ่านเป็นจะดูความชันสองข้างของจุดหักศอกก่อน: ข้อ 1 กระโดด 0→+1 (1 ขา) ข้อ 3 กระโดด −1→+1 (2 ขา) จุดหักศอกเดียวกันแต่ "น้ำหนัก" ต่างกัน

Drill 2: เช็คหาง — อันไหนอันตราย?

🚶 อ่านเป็นภาษาคนก่อน: ก่อนสนใจตรงกลางกราฟ ให้มอง ปลายซ้ายสุดกับปลายขวาสุดก่อน — ถ้าปลายไหน "แบน" แปลว่าฝั่งนั้นความเสี่ยงจำกัด แต่ถ้าปลายไหน "ชันลง" ไม่หยุด แปลว่าฝั่งนั้นขาดทุนได้ไม่จำกัด นี่คือการเช็คความปลอดภัยใน 1 วินาที ก่อนดูอย่างอื่น

กับดักที่ต้องระวัง: ข้อ 3 (Butterfly) หน้าตา "แหลม ๆ" ดูน่ากลัว แต่ปลายทั้งสองแบน = ปลอดภัยสุด · ส่วนข้อ 4 (Ratio) ตรงกลางหน้าตาเหมือน Butterfly เป๊ะ แต่ปลายขวาดิ่งไม่หยุด = ขาดทุนไม่จำกัด — ตาที่ฝึกมาจะมองหางก่อนมองตรงกลางเสมอ

🧠 มุมที่มองต่าง

"หน้าตากราฟน่ากลัว" ≠ "อันตราย" — Butterfly (ข้อ 3) ดูแหลมหวาดเสียวแต่ปลอดภัยที่สุดในหน้านี้ ส่วน Short Put (ข้อ 6) ดูเรียบ ๆ เหมือนบันไดขั้นเดียว แต่ซ่อนหางซ้ายที่ขาดทุนได้ไม่จำกัด ความเสี่ยงจริงอยู่ที่หาง ไม่ใช่ที่ความ "หวือหวา" ของรูป

Drill 3: จับคู่ภาพกับความเชื่อ

Drill 4: ฝาแฝดที่ไม่เหมือน

🚶 อ่านเป็นภาษาคนก่อน: กราฟสองอันที่ รูปทรงเหมือนกันเป๊ะ อาจถูกสร้างจาก option คนละชุด — และถ้า payoff เท่ากัน มันก็คือของสิ่งเดียวกันในเชิงความเสี่ยง ต่างแค่ "ป้ายชื่อ" กับกระแสเงินตอนเปิด drill นี้ฝึกตาให้เชื่อ "รูปทรง" มากกว่า "ชื่อ"

🎯 3 อย่างที่ต้องจำจากสนามฝึก I
  • นับจุดหักศอก = นับ strike · ขนาดการกระโดด = จำนวนขา · เส้นตรง = 0 ขา (แค่หุ้น)
  • มองหางก่อนมองกลาง — ปลายที่ชันลงไม่หยุด = ขาดทุนไม่จำกัด "หน้าตาน่ากลัว ≠ อันตราย"
  • รูปทรงเท่ากัน = ของสิ่งเดียวกัน — ชื่อกับต้นทุนต่างได้ แต่ความเสี่ยงเท่ากัน
อ่านกราฟเหมือนอ่านตัวอักษร — ตอนเริ่มคุณสะกดทีละจุดหักศอก พอฝึกพอ คุณจะอ่านทั้งรูปในแวบเดียว โดยไม่รู้ตัวว่าเคยต้องสะกด
📖 ศัพท์ใหม่ในตอนนี้

จุดหักศอก (kink) = จุดที่เส้น payoff เปลี่ยนความชัน เกิดที่ strike แต่ละค่า · ขนาดการกระโดด (slope jump) = ความชันเปลี่ยนกี่หน่วยที่จุดหักศอก บอกจำนวนขาที่กระทำตรงนั้น · หาง (tail) = ปลายซ้าย/ขวาสุดของกราฟ ใช้เช็ค bounded/unbounded · ฝาแฝด payoff = สอง strategy ที่รูปทรงเหมือนกันเป๊ะ แต่สร้างจาก option คนละชุด
