แก่นของ Part นี้ — อ่านก่อน
Calculated Risk ไม่ใช่การหลีกเลี่ยงความเสี่ยง — มันคือ การคำนวณก่อนว่า Worst Case คือเท่าไหร่ แล้วตัดสินใจว่ารับได้ไหม ถ้ารับได้ เล่นได้ทุกอย่าง
WCL = sup_{s ∈ S_adverse} L(s) → Gate A + Gate B → PROCEED

A — นิยามและ Notation

ก่อนเริ่ม ต้องกำหนด Universe ของระบบให้ชัดเจน:

C₀ = ทุนเริ่มต้นทั้งหมด (Total Capital) Z = Zone allocation = สัดส่วนทุนที่จัดสรรให้ game นี้, Z ∈ (0,1] โดย Σ Zᵢ ≤ 1 (ทุก game รวมกันไม่เกิน 100%) F = Floor = ระดับทุนต่ำสุดที่ยอมรับได้ (absolute) = C₀ × (1 − MaxDD_macro) MaxDD_macro = DD limit ระดับ system (เช่น 20% ของ C₀) MaxDD_micro = DD limit ของแต่ละ game (เช่น 25-30% ของ Zone) H_dd = DD Halt threshold (หยุดทุก game เมื่อ portfolio DD ถึง %นี้)

B — 3 คำถาม Calculated Risk

กฎเหล็ก: ต้องตอบได้ทั้ง 3 คำถามก่อน deploy ทุก technique

ขาดคำถามใดคำถามหนึ่ง = ไม่ใช่ Calculated Risk = เสี่ยงโดยไม่รู้ตัว

Q1 — Identify: Worst Case คืออะไร?

ต้องระบุ scenario ที่สร้างผลขาดทุนมากที่สุด ไม่ใช่แค่ "ขาดทุน" แต่ต้องชี้ให้ได้ว่า:

W(θ, S) = worst-case loss scenario = f(strategy θ, state space S) "ถ้า BTC ทำ X ในเวลา T โดยมีเงื่อนไข Y — portfolio จะเกิดอะไร?" S_adverse = {scenarios ที่ price/vol/correlation เคลื่อนที่ไม่เป็นคุณ}

Q2 — Quantify: ตัวเลขคือเท่าไหร่?

WCL(θ) = sup_{s ∈ S_adverse} |Loss(θ, s)| WCL$ = Worst-Case Loss ในหน่วย USDT (absolute) WCL% = WCL / (C₀ × Z) ← % ของ zone allocation ที่จัดสรร สำคัญ: ต้องคำนวณเป็นตัวเลข USDT จริงๆ ไม่ใช่แค่ % ที่ฟังดูเล็กน้อย

Q3 — Accept: รับได้ไหม?

Gate condition — ต้องผ่านทั้งสองข้อ: Gate A: WCL$ ≤ C₀ × Z × MaxDD_micro (Micro DD limit) Gate B: WCL$ ≤ C₀ × MaxDD_macro (System Floor) Hard Gate = min(Gate A, Gate B) ถ้า WCL$ ≤ Hard Gate → DEPLOY ได้ ถ้า WCL$ > Hard Gate → RESIZE / HEDGE / REJECT ก่อน

C — Worst-Case Formula ตาม Game Category

Category A: Sizing Games (Soft Martingale, Bell Curve, Pyramid)

Soft Martingale — N levels, multiplier m, base size q₀:

Position size ที่ level k: qₖ = q₀ × mᵏ Total exposure ถ้าเข้าทุก level: Q_total = q₀ × (mᴺ − 1)/(m − 1) WCL_martingale = Q_total × |P_entry_avg − P_stop| โดย: P_entry_avg = Σ(qₖ × Pₖ) / Q_total P_stop = ราคา hard stop ของ level สุดท้าย ตัวอย่าง BTC (C₀ = $100k, m = 1.5, N = 3): q: 0.02, 0.03, 0.045 BTC → Q_total = 0.095 BTC Entry: $100k, $97k, $94k → P_avg ≈ $96,211 Hard stop: $90,000 WCL = 0.095 × ($96,211 − $90,000) = 0.095 × $6,211 ≈ $590

Bell Curve Sizing (Kelly-variant):

f* = (p × b − q) / b ← Kelly fraction p = P(win), b = win/loss ratio, q = 1 − p WCL_kelly = C₀ × Z × f* × |max adverse move| Conservative (Half-Kelly): f_safe = f*/2 WCL_halfkelly = C₀ × Z × (f*/2) × |max adverse move|

Category B: Options Games (CSP, Iron Condor, Butterfly)

Cash-Secured Put (CSP):

WCL_CSP_practical = (K_s − P_floor) × Lot − Prem_received K_s = strike ที่ short P_floor = ราคาที่จะ close/defend (ไม่ยอมให้ต่ำกว่า) Lot = จำนวน BTC Prem = premium received ตัวอย่าง BTC: K_s = $90,000, Lot = 1 BTC, Prem = $800, P_floor = $75,000 WCL_CSP = ($90,000 − $75,000) × 1 − $800 = $14,200

Iron Condor (Put spread + Call spread):

WCL_IC = max(W_put, W_call) × Lot − Total_Prem W_put = K_short_put − K_long_put W_call = K_long_call − K_short_call Note: IC ขาดทุนได้เพียง 1 side (ไม่ใช่ทั้งคู่พร้อมกัน ยกเว้น gap/flash crash ที่ผ่าน body ทั้งหมด) ตัวอย่าง BTC (Grid Zone $90k–$110k): Short $88k put / Long $82k put → W_put = $6,000 Short $113k call / Long $120k call → W_call = $7,000 Prem received = $1,050, Lot = 1 BTC WCL_IC = max($6,000, $7,000) × 1 − $1,050 = $5,950

Butterfly:

Long Butterfly (ซื้อ 2 wing, ขาย body): WCL_longfly = Net_Debit_Paid ← จำกัด, รู้ตั้งแต่เปิด Short Butterfly (ขาย body, ซื้อ wing): WCL_shortfly = W × Lot − Prem_received W = ระยะห่างระหว่าง wing กับ body

Category C: Spread Games (Pair Grid, Basis Trade, Stat Arb)

Spread = Sₐ − β × S_b β = hedge ratio (จาก regression หรือ cointegration) σ_sp = volatility ของ spread WCL_spread = |Spread_entry − Spread_worst| × Lot ΔSpread_max (scenario-based): Conservative: μ ± k × σ_sp, k = 3~5 Stress test: historical max dislocation (FTX collapse, COVID) ตัวอย่าง BTC Basis Trade: Long BTC spot @ $100k, Short BTC Perp @ $100.3k (basis = $300) Worst case: basis blow-out (short squeeze) → ΔBasis_max = $2,000 WCL_basis = $2,000 × 1 BTC = $2,000 (+ funding cost แยก)

Category D: Decay Games (Calendar, Vol Carry, Theta)

Calendar Spread (Long far / Short near): WCL_calendar = Loss_vega + Loss_gamma − Theta_collected 1. Vol Inversion Risk (สำคัญมาก!): ปกติ: IV_near < IV_far (term structure normal) Crisis: IV_near > IV_far → calendar กลับเป็นลบ WCL_volinv = (IV_near_spike − IV_far) × Vega_near × Lot 2. Spot jump ผ่าน short strike: Loss_gamma = Gamma_near × (ΔS)² / 2 Vol Carry (Short near-term vol): WCL_volcarry = (RV_max_historical − IV_sold) × Vega × Lot RV_max ของ BTC ≈ 200%+ annualized (March 2020, FTX)

D — กฎ Micro ≤ Macro: 3 ตัวอย่างจริง

ภาพรวมระบบ (C₀ = $100,000)

Macro Floor: F = $100,000 × (1 − 0.20) = $80,000
ห้ามขาดทุนเกิน $20,000 ในทุกกรณี (Gate B = $20,000)

ตัวอย่างที่ 1: Soft Martingale — PASS

Setup: C₀ = $100,000 · Zone = 30% = $30,000 MaxDD_micro = 30% → Gate A = $9,000 MaxDD_macro = 20% → Gate B = $20,000 Hard Gate = min($9,000, $20,000) = $9,000 WCL ที่คำนวณได้ = $590 Gate A: $590 ≤ $9,000 ✓ Gate B: $590 ≤ $20,000 ✓ → DEPLOY ได้ → Worst case: เสีย $590 = 0.59% ของทุนรวม

ตัวอย่างที่ 2: Iron Condor — PASS (barely)

Setup: Zone = 25% = $25,000 MaxDD_micro = 25% → Gate A = $6,250 MaxDD_macro = 20% → Gate B = $20,000 WCL_IC = max($5,000, $5,000) × 1 − $1,500 = $3,500 Gate A: $3,500 ≤ $6,250 ✓ Gate B: $3,500 ≤ $20,000 ✓ → DEPLOY ได้ แต่ถ้าเพิ่ม Lot เป็น 2 BTC: WCL = $7,000 → Gate A FAIL ($7,000 > $6,250) → ต้อง resize หรือเพิ่ม Zone ก่อน

ตัวอย่างที่ 3: Pair Grid — REJECT → Resize

Setup: Zone = 25% = $25,000 MaxDD_micro = 30% → Gate A = $7,500 Initial: Long 1.0 BTC / Short 15 ETH (β = 15) Correlation break scenario (ρ drops 0.85 → 0.3): BTC drops 20%: Loss_BTC = $20,000 ETH drops 5%: Gain_ETH = 15 × $500 = $7,500 Net WCL = $20,000 − $7,500 = $12,500 Gate A: $12,500 ≤ $7,500 ✗ FAIL! → REJECT — ต้อง resize Resize: ลด position เหลือ 0.6 BTC / 9 ETH WCL_resized = $12,500 × 0.6 = $7,500 Gate A: $7,500 ≤ $7,500 ✓ (ผ่านพอดี — monitor อย่างใกล้ชิด) Gate B: $7,500 ≤ $20,000 ✓ → DEPLOY ได้หลัง resize

WCL vs Gate A: ตัวอย่างที่ 1 (Martingale) และ 2 (Iron Condor) ผ่าน Gate · ตัวอย่างที่ 3 (Pair Grid เต็ม) ไม่ผ่าน — ต้อง Resize

E — 5 Warning Cases: False Security

คิดว่า Calculated แล้ว แต่จริงๆ ยังไม่ได้ Calculate

⚠ Warning 1: Scenario ไม่ครอบ Tail Events

กับดัก: "ฉัน stress test ด้วย BTC ลง 20% แล้ว WCL ผ่าน Gate" ปัญหา: Historical tail ของ BTC: - March 2020: ลง 50% ใน 2 วัน - FTX collapse: ลง 30% + liquidity หาย + basis blow-out - Leverage unwind: ลง 20% ใน 4 ชั่วโมง Fix: WCL_true = max(WCL_σ, WCL_historical_max, WCL_scenario_stress) ใช้ค่ามากสุดเสมอ — ไม่ใช่ค่าเฉลี่ย

⚠ Warning 2: ลืม Correlation Breakdown

กับดัก: "BTC/ETH Pair Grid ปลอดภัย เพราะ correlation 0.85" ปัญหา: ρ(BTC,ETH) ในสภาวะปกติ ≠ ρ(BTC,ETH) ในวิกฤต Crisis correlation ที่พบจริง: BTC ETH BTC 1 0.3 ← ไม่ใช่ 0.85 อีกต่อไป ETH 0.3 1 Fix: คำนวณ β_stress แยก สำหรับ crisis period ใช้ WCL_worst = WCL(β_stress) ไม่ใช่ WCL(β_normal)

⚠ Warning 3: Liquidity Risk ไม่ถูก Quantify

กับดัก: "Iron Condor WCL = $2,800 ตาม formula ฉันจะ close ถ้า BTC วิ่งออก range" ปัญหา: Slippage + Bid-ask spread ใน crisis ≠ normal BTC options ปกติ: bid-ask spread = $50–100 BTC options crisis: spread = $500–2,000+ หรือไม่มี liquidity เลย Fix: WCL_adjusted = WCL_formula × Liquidity_multiplier Liquidity_multiplier สำหรับ BTC options = 1.3–2.0x ใน stress

⚠ Warning 4: Aggregation Risk (Portfolio Level)

กับดัก: "ทุก technique ผ่าน Gate ทีละตัว ดังนั้นรวมก็ปลอดภัย" ปัญหา: ใน BTC crisis ทุก game ขาดทุนพร้อมกัน: - Soft Martingale: BTC ร่วง → ขาดทุน - Iron Condor: short put ITM → ขาดทุน - Pair Grid: correlation break → hedge ล้มเหลว - Calendar: vol spike → calendar inversion WCL_correlated ≈ Σ WCL_i × ρ_stress_factor (≈ 1.0 ในวิกฤต!) Fix: Macro Gate ต้องรองรับ "all techniques lose simultaneously" Sum of all WCL_i ≤ MaxDD_macro × C₀

⚠ Warning 5: Path Dependency

กับดัก: "Soft Martingale WCL = $590 ถ้าราคาไปถึง stop" ปัญหา: path อาจทำให้ Q_total ใหญ่กว่าที่ estimate: Path A: $100k → $90k (ตรง) → WCL = $590 Path B: $100k → $97k (เข้า L2) → $100k (ดูเหมือน OK) → $94k (เข้า L3) → $90k → Q_total ณ จุดนั้นใหญ่กว่า Path A → WCL จริง > $590 Fix: Monte Carlo simulation ของ path WCL_path = E[max loss | path through all levels]
