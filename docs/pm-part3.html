บทที่ 10: Butterfly — "เต็นท์แหลม"

Long Call Butterfly: +1 Call K₁, -2 Call K₂, +1 Call K₃

Slope analysis (K₁=90, K₂=100, K₃=110):
ก่อน K₁: slope = 0 (แบน)
ที่ K₁: +1 → slope = +1 (ชันขึ้น)
ที่ K₂: -2 → slope = +1-2 = -1 (ชันลง)
ที่ K₃: +1 → slope = -1+1 = 0 (แบน)

Net slope ปลายขวา = 0 → bounded! ปลอดภัย
รูปร่าง: แบน → ขึ้น → ลง → แบน = "เต็นท์" peak ที่ K₂

📖 อ่านสูตรว่า: "+1 Call K₁, −2 Call K₂, +1 Call K₃" อ่านว่า "ซื้อหนึ่งสัญญาที่สไตรก์หนึ่ง ขายสองสัญญาที่สไตรก์สอง ซื้อหนึ่งสัญญาที่สไตรก์สาม" — เลขหน้าคือจำนวน × ทิศ (+ ซื้อ − ขาย) · โครงที่ต้องเห็น: slope ในแต่ละช่วงคือ ผลรวมสะสม ของการเปลี่ยนความชันที่ผ่านมา: 0 → +1 → −1 → 0 · เช็คเร็ว: บวกเลขหน้าทุกขา +1 − 2 + 1 = 0 → ปลายขวาแบน = bounded · กับดักการอ่าน: ตัวห้อย 1, 2, 3 คือหมายเลขสไตรก์เรียงจากต่ำไปสูง ไม่ใช่เวลา

Net profit (หลังหัก premium)

Butterfly Convexity Condition

C(K₁) - 2C(K₂) + C(K₃) ≥ 0 (สำหรับ equally-spaced strikes)
ถ้า < 0 → Arbitrage! ซื้อ butterfly ได้ "ฟรี" → เป็นไปไม่ได้ในตลาดปกติ

3 สิ่งที่ต้องจำ

1. Butterfly slope: +1, -2, +1 → net = 0 → bounded ทั้งสองด้าน
2. กำไรสูงสุดที่ K₂ พอดี → ต้องแม่นยำมาก
3. Butterfly ≥ 0 = convexity condition → ถ้าผิด = arb

บทที่ 11: Iron Condor — "ที่ราบสูงตรงกลาง"

Iron Condor = Bull Put Spread(K₁,K₂) + Bear Call Spread(K₃,K₄)
= +Put K₁, -Put K₂, -Call K₃, +Call K₄

Slope analysis (K₁ < K₂ ≤ K₃ < K₄):
+1 at K₁ → -1 at K₂ → (slope=0 ช่วงกลาง) → -1 at K₃ → +1 at K₄
Net slope = 0 → bounded ✓
รูปร่าง: แบน(ขาดทุน) → ขึ้น → แบน(กำไร) → ลง → แบน(ขาดทุน) = "ที่ราบสูงตรงกลาง"

Max profit = net premium received
Max loss = (K₂-K₁) - net premium (= width of one spread - premium)

📖 อ่านสูตรว่า: Bull Put Spread(K₁,K₂) อ่านว่า "สเปรดที่ใช้สไตรก์ K₁ กับ K₂" — ตัวในวงเล็บคือพารามิเตอร์ ไม่ใช่ตัวคูณ · โครงที่ต้องเห็น: payoff = ผลรวมของสองสเปรด และ Max loss = (K₂ − K₁) − net premium คือ "ความกว้างของสเปรดข้างหนึ่ง ลบสิ่งที่รับมาแล้ว" · ลอง K₁ = 90, K₂ = 95, premium 2 → 5 − 2 = 3 · กับดักการอ่าน: สูตร max loss นี้ถือว่าสองสเปรดกว้างเท่ากัน — ถ้าไม่เท่า ต้องใช้ความกว้างของข้างที่กว้างกว่า

Net profit (หลังหัก premium)

⚠️ "Short Strangle ที่มีปีก" — ยังอันตราย!

Iron Condor = Short Strangle + Long Wings (protection)
Max loss จำกัด (= width - premium) แต่ เสียเต็ม max loss ทันทีเมื่อราคา gap ผ่าน wings
Payoff chart ดูสวย → แต่จำไว้ (Ch8): payoff ≠ prediction!
"Iron Condor กำไร 80% ของเวลา" = 20% ที่เหลือเสียหนักพอจะล้างกำไรทั้งหมด

3 สิ่งที่ต้องจำ

1. Iron Condor = "เดิมพันว่าราคาจะนิ่ง" → กำไรจำกัด ขาดทุนจำกัด
2. ทุก strategy ที่ "กำไรบ่อย" = เสียหนักเมื่อเสีย → check Expected Value!
3. ดู payoff chart อย่างเดียวไม่พอ → ต้องรู้ probability distribution ด้วย

บทที่ 12: Calendar + Diagonal — "มิติของเวลา"

ทุกอย่างที่ผ่านมา = same expiry → บทนี้เพิ่มมิติ "เวลา"

Calendar Spread = Short near-term + Long far-term (same strike)
→ กำไรจาก time decay ที่ near-term หมดค่าเร็วกว่า far-term

Diagonal Spread = Calendar + ต่าง strike
→ ผสมมิติเวลา + ทิศทาง

Net profit (หลังหัก premium)

สำคัญ: ใช้ BS theoretical price ไม่ใช่ at-expiry payoff

Calendar Spread payoff ณ near-term expiry ไม่ใช่เส้นตรงหักศอก → เป็นเส้นโค้ง
เพราะ far-term leg ยังมี time value อยู่ → ต้องใช้ Black-Scholes price
(ถ้ายังไม่รู้จัก BS → ดูเล่มคณิตศาสตร์ บทที่ 7 + 15)

บทที่ 13: Ratio Spreads — "ปืนที่บรรจุกระสุน"

1×2 Ratio Call Spread = Long 1 Call K₁ + Short 2 Call K₂
Slope: +1 at K₁, -2 at K₂ → net slope = +1-2 = -1 ≠ 0
→ UNBOUNDED loss ด้านขวา!

📖 อ่านสูตรว่า: "1×2" อ่านว่า "หนึ่งต่อสอง" — สัดส่วนจำนวนสัญญา ไม่ใช่ 1 คูณ 2 · โครงที่ต้องเห็น: เช็คเดียวกับ Butterfly ในบท 10: บวกเลขหน้าทุกขา +1 − 2 = −1 ≠ 0 → ปลายขวาชันลงไม่หยุด = ขาดทุนไม่จำกัด · Back Ratio ในกล่องถัดไปคือเครื่องหมายกลับกัน: −1 + 2 = +1

Net profit (หลังหัก premium)

⚠️ Net slope ≠ 0 = Unlimited Risk!

Ratio Spread ดูเหมือน "ได้ premium ฟรี" เพราะ Short 2 ชดเชย Long 1
แต่ ถ้าราคาพุ่งขึ้นมาก → Short 2 ขาดทุนเร็วกว่า Long 1 ได้กำไร
→ ขาดทุนไม่จำกัด!
กฎ: เช็ค net slope ที่ปลายขวาเสมอ → ถ้า ≠ 0 → unlimited risk!

Back Ratio = Short 1 Call K₁ + Long 2 Call K₂ → net slope = +1 → unlimited profit!

บทที่ 14: วิธีต่อเลโก้ขั้นสูง — Payoff Algebra

3 ขั้นตอน: Belief → Piecewise → Instruments

Step 1: เขียน "สิ่งที่อยากได้" เป็น piecewise function
Step 2: จับคู่กับ building blocks ที่รู้จัก (slope analysis ย้อนกลับ)
Step 3: เลือก instruments ที่ถูกที่สุด

ตัวอย่าง: "กำไรถ้าราคาอยู่ระหว่าง 90-110 ไม่เสียเกิน ฿3"

Piecewise:
  S < 90: payoff = -3 (flat)
  90 ≤ S ≤ 100: payoff = -3 + (S-90) → ที่ S=90: -3, ที่ S=100: +7 (peak!)
  100 < S ≤ 110: payoff = +7 - (S-100) → ที่ S=110: -3
  S > 110: payoff = -3 (flat)

Slope changes: +1 at 90, -2 at 100, +1 at 110 → = Butterfly!
Net premium = ฿3, Max profit = width - net = 10 - 3 = ฿7

📖 อ่านสูตรว่า: อ่านทีละบรรทัดว่า "ถ้า S น้อยกว่า 90 payoff เท่ากับ −3 · ถ้า S อยู่ระหว่าง 90 ถึง 100 payoff เท่ากับ −3 บวก (S ลบ 90)" — ฟังก์ชันที่เขียนเป็นช่วง (piecewise) ต้องอ่านเงื่อนไขก่อน แล้วค่อยอ่านสูตรของช่วงนั้น · โครงที่ต้องเห็น: แต่ละช่วงเป็นเส้นตรง และค่าตรงจุดหักต้องต่อกันพอดี: ช่วงสองที่ S = 100 ให้ −3 + 10 = +7 ช่วงสามเริ่มที่ +7 เท่ากัน · กับดักการอ่าน: ≤ กับ < ที่ขอบช่วงบอกว่าจุดขอบเป็นของช่วงไหน — payoff ต่อเนื่อง ค่าเท่ากันทั้งสองข้าง จึงไม่กระทบตัวเลข

กฎ: รูปเดียว สูตรเดียว

Payoff ที่มี n จุดหักศอก + net slope ปลาย = 0 → ต้องใช้ พอดี n option legs (minimal representation)
ถ้า net slope ≠ 0 → ต้องเพิ่ม stock หรือ bond อีก 1 ตัว
ไม่ต้องกลัวว่า "พลาดคำตอบที่ดีกว่า" — คำตอบมีเดียว!

Transaction Costs — Reality Check

ยิ่งหลายขา ยิ่งแพง

ทุก leg = commission + bid-ask spread + slippage
4-leg Iron Condor: ~4 × (commission + half-spread) = อาจกิน 30-50% ของ max profit
กฎ: คำนวณ costs ก่อนเสมอ → ถ้า costs > 30% ของ max profit → อาจไม่คุ้ม

ลองคิดดู (บท 14)

"อยากได้กำไร ฿500 ถ้า S > 2500, ไม่อยากเสียเกิน ฿200" → สร้าง payoff?
เฉลย: Piecewise = {-200 ถ้า S≤2500, +500 ถ้า S>2500} → jump +700 at 2500 → = Digital Call × 700 หรือ tight Call Spread(2500, 2500+ε) × 700/ε
