7.1 อนุพันธ์ = ความชัน (กลับมาเจอเพื่อนเก่าจาก Part I)

🚶 อ่านเป็นภาษาคนก่อน: อนุพันธ์ f'(x) ตอบคำถามเดียว: "ณ จุดนี้ ถ้าขยับ x ไปนิดเดียว f ขยับเท่าไร" มันคือ ความชันของเส้นสัมผัส ณ จุดนั้น — ซึ่งเราเจอแล้วใน Part I (slope) แค่ตอนนี้ใช้กับเส้นโค้งได้

f'(x) = lim(h→0) [ f(x+h) − f(x) ] / h ← "ขยับนิดเดียว แล้วดูอัตราส่วน"

📖 อ่านสูตรว่า: "เอฟไพรม์ของเอ็กซ์ เท่ากับ ลิมิต เมื่อ เอช เข้าใกล้ศูนย์ ของ เอฟของเอ็กซ์บวกเอช ลบ เอฟของเอ็กซ์ หารด้วย เอช" · ′ (prime) หลังชื่อฟังก์ชันอ่านว่า "อนุพันธ์ของ" ไม่ใช่ตัวคูณ · โครงที่ต้องเห็น: นี่คือ Δy/Δx จาก Part I 1.3 เป๊ะ (ขึ้นเท่าไร ต่อ ขวาเท่าไร) แล้วบีบก้าว h ให้เล็กจนเหลือความชัน ณ จุดเดียว · ลอง f(x) = 3x: [3(x+h) − 3x]/h = 3 ทุก h → f′ = 3 คือความชันของเส้นตรงเดิม · กับดักการอ่าน: lim(h→0) อ่านว่า "ปล่อย h เล็กลงไม่จำกัด" — ห้ามแทน h = 0 ตรง ๆ จะได้ 0/0 · f(x+h) คือ "เอา x+h เข้าเครื่อง f" ไม่ใช่ f คูณ (x+h)

7.2 อนุพันธ์ของ eˣ และ Chain Rule

🚶 อ่านเป็นภาษาคนก่อน: eˣ พิเศษตรงที่ "ความชันของมัน = ตัวมันเอง" (ยิ่งสูงยิ่งชันเร็ว = การเติบโตแบบทบต้น) · Chain Rule คือกฎ "ลอกเปลือกทีละชั้น" เมื่อฟังก์ชันซ้อนกัน

d/dx(eˣ) = eˣ ← อนุพันธ์ของตัวเอง Chain Rule: y = f(g(x)) → dy/dx = f'(g(x)) · g'(x) ตัวอย่าง: d/dT(e^(−rT)) = e^(−rT) · (−r) = −r·e^(−rT)

📖 อ่านสูตรว่า: "ดีบายดีเอ็กซ์ ของ อี ยกกำลังเอ็กซ์ เท่ากับ อี ยกกำลังเอ็กซ์ · ดีวาย บาย ดีเอ็กซ์ เท่ากับ เอฟไพรม์ของ จีของเอ็กซ์ คูณ จีไพรม์ของเอ็กซ์" · d/dx(…) คือคำสั่ง "หาอนุพันธ์เทียบ x ของ…" ไม่ใช่เศษส่วนที่ตัด d ทิ้งได้ · โครงที่ต้องเห็น: Chain Rule = "อนุพันธ์ชั้นนอก (แทนชั้นในเข้าไปทั้งก้อน) คูณ อนุพันธ์ชั้นใน" — นับชั้นวงเล็บ = นับตัวคูณ · บรรทัดสาม: ชั้นนอก eu ให้ eu ชั้นใน u = −rT ให้ −r จึงได้ −r·e−rT ติดลบ แปลว่ายิ่ง T ยาว PV ยิ่งลด · กับดักการอ่าน: d/dT บอกว่าตัวแปรที่ขยับคือ T ส่วน r ถูกตรึงเป็นค่าคงที่ · f′(g(x)) คือ "หาอนุพันธ์ของ f ก่อน แล้วจึงแทน g(x)" ไม่ใช่อนุพันธ์ของ f(g(x)) ทั้งก้อน

เชื่อมกับ Options

Chain Rule คือพื้นฐานของ Ito's Lemma — "Chain Rule ของโลกสุ่ม" ที่ใช้ derive สูตร Black-Scholes (เจอกันใน Part IV)

7.3 อนุพันธ์ย่อย = Greeks ทุกตัว

Greeks = อนุพันธ์ย่อยของราคา Option Black-Scholes greeks ★★★ ต้องรู้จัก

🎯 Thesis

"ราคา Option ขึ้นกับหลายตัวแปร V(S, t, σ, r) · Greek แต่ละตัวคือ 'อนุพันธ์ย่อย' = ผลของตัวแปรเดียว โดยตรึงตัวอื่นไว้ — มันคือ 'หน้าปัดวัด' ที่บอกว่าพอร์ตคุณไวต่ออะไรบ้าง"

🚶 อ่านเป็นภาษาคนก่อน: ∂V/∂S อ่านว่า "เปลี่ยน S ค้าง t, σ, r ไว้" เหมือนหมุนปุ่มทีละปุ่มดูว่าเสียงเปลี่ยนยังไง โดยไม่แตะปุ่มอื่น

💡 เรื่องหน่วยของ Vega ที่พลาดกันบ่อย

∂V/∂σ ตามนิยามคือ "ราคาเปลี่ยนต่อ σ ที่ขยับ 1 หน่วยเต็ม (= 100 จุด vol เช่นจาก 20% เป็น 120%)" · แต่เทรดเดอร์ quote Vega เป็น "ต่อ 1 จุด vol (1%)" ซึ่ง = ∂V/∂σ × 0.01 · อย่าสับสนสองหน่วยนี้ เวลาอ่านตัวเลข Vega ให้เช็คก่อนว่าเป็น "ต่อ 1 หน่วย" หรือ "ต่อ 1%"

🎬 ฉากหน้าจอ — เฉลย hook หน้าแรก

Call ที่เทรดเดอร์ถือมี Δ=+0.5, Θ=−0.08/วัน, ν=+0.12 (ตัวเลขกลม ๆ เพื่อสาธิต — ค่าจริงจาก BS ของ Call ATM ตัวนี้คือ Δ≈0.627, Γ≈0.015 ดูที่ §7.6) · วันนั้น: หุ้น +฿1 → ได้จาก Delta ≈ +0.5 · แต่เวลาผ่าน 1 วัน → Theta ≈ −0.08 · และ σ ตก 4 จุด → Vega ≈ 0.12×(−4) = −0.48 · สุทธิ ≈ 0.5 − 0.08 − 0.48 = −0.06 (ขาดทุน) ทั้งที่เดาทิศถูก — เพราะ Vega กับ Theta รวมกันชนะ Delta

7.4 อนุพันธ์อันดับ 2 = Gamma (ความโค้ง)

Gamma — ความโค้งของ payoff อนุพันธ์อันดับ 2 ★★★ ต้องรู้จัก

🚶 อ่านเป็นภาษาคนก่อน: ถ้า Delta คือ "ความชัน" แล้ว Gamma คือ "ความชันของความชัน" = ความโค้ง · มันบอกว่า Delta เปลี่ยนเร็วแค่ไหนเมื่อหุ้นขยับ · Gamma สูง = Delta วิ่งไว = ต้องปรับ hedge บ่อย

Gamma (Γ) = ∂²V/∂S² = ∂(Delta)/∂S

📖 อ่านสูตรว่า: "แกมมา เท่ากับ อนุพันธ์ย่อยอันดับสองของวีเทียบเอส เท่ากับ อนุพันธ์ย่อยของเดลตาเทียบเอส" · โครงที่ต้องเห็น: อนุพันธ์ = ความชัน อนุพันธ์อันดับสอง = ความโค้ง — หาความชันสองรอบ: รอบแรกได้ Delta รอบสองได้ Gamma · ลอง payoff เส้นตรง (ถือหุ้นเปล่า V = S): Delta = 1 คงที่ → Gamma = 0 ไม่มีความโค้ง · กับดักการอ่าน: ∂² บนและ ∂S² ล่างเป็นสัญลักษณ์เดียวอ่านว่า "อันดับสอง" ไม่ใช่ยกกำลังสองแล้วหาร · ∂ (ย่อย) แปลว่าขยับ S อย่างเดียว ตรึง t, σ, r ตามตาราง 7.3 · Γ ใหญ่คือ Greek ตัวนี้ ส่วน γ เล็กในบทอื่นของคลังคือ risk-aversion (ระดับความกลัวความเสี่ยง) — คนละตัว

🧠 มุมที่มองต่าง — "ได้ Gamma จ่าย Theta"

มือใหม่เห็น: Gamma เป็นแค่สัญลักษณ์กรีกอีกตัว
คนเทรดเห็น: Gamma กับ Theta คือ "ดีลแลกเปลี่ยน" ที่ตลาดบังคับ — ถ้าคุณ Long Gamma (ได้กำไรเวลาหุ้นเหวี่ยงแรง) คุณต้องจ่าย Theta (ค่าเวลาที่ไหลออกทุกวัน) · ไม่มีใครได้ทั้งความโค้งฟรี ๆ นี่คือ "ไม่มีของฟรี" ที่จับต้องได้จริงบนโต๊ะ

🎯 3 อย่างที่ต้องจำเรื่อง Gamma
  • Gamma = ความโค้ง = Delta เปลี่ยนเร็วแค่ไหน
  • Gamma สูงสุดที่ ATM (โค้งมากสุด) → ต้อง rehedge บ่อยสุดตรงนั้น
  • Long Gamma มาคู่กับ Short Theta เสมอ — ได้ความโค้ง แลกกับค่าเวลา
✍️ ลองทำเอง (ก่อนไปต่อ)

Option มี Δ=0.5, Γ=0.05 · ถ้าหุ้นพุ่ง +฿6 ราคา option เปลี่ยนประมาณเท่าไร (ใช้ Delta+Gamma) และถ้าใช้ Delta อย่างเดียวจะได้เท่าไร?

ดูเฉลย

Delta+Gamma: 0.5×6 + ½×0.05×6² = 3.0 + 0.9 = +3.9 · Delta อย่างเดียว: 0.5×6 = +3.0 · Gamma เพิ่มให้อีก 0.9 (เพราะโตตาม ΔS² = 36) — ยิ่งหุ้นวิ่งแรง Gamma ยิ่งสำคัญ · สูตรเต็มและ Python เทียบราคาจริงอยู่ที่ §7.6

7.5 อินทิกรัล — "พื้นที่ใต้กราฟ" กลับมาเป็น N(d)

🚶 อ่านเป็นภาษาคนก่อน: อินทิกรัล ∫ คือกระบวนการย้อนกลับของอนุพันธ์ และตีความได้เป็น "พื้นที่ใต้กราฟ" · จำ N(d) จาก Part II ได้ไหม? มันคือพื้นที่ใต้ระฆัง = อินทิกรัลของ bell curve นั่นเอง

∫ xⁿ dx = xⁿ⁺¹/(n+1) + C ∫ eˣ dx = eˣ + C ∫ (1/x) dx = ln|x| + C

📖 อ่านสูตรว่า: "อินทิกรัลของ เอ็กซ์ยกกำลังเอ็น ดีเอ็กซ์ เท่ากับ เอ็กซ์ยกกำลังเอ็นบวกหนึ่ง หารด้วย เอ็นบวกหนึ่ง บวก ซี" · ∫ … dx อ่านว่า "รวมพื้นที่ใต้ … ไปตามแกน x" — dx ท้ายสุดบอกตัวแปรที่รวม ไม่ใช่ตัวคูณ · โครงที่ต้องเห็น: ปุ่ม undo ของอนุพันธ์: ตรวจได้โดยหาอนุพันธ์ของคำตอบ — d/dx[xⁿ⁺¹/(n+1)] = (n+1)xⁿ/(n+1) = xⁿ ✓ และ ex กลับมาเป็นตัวเอง (7.2) · กับดักการอ่าน: + C คือค่าคงที่ที่ไม่รู้ (ค่าคงที่หายตอนหาอนุพันธ์ จึงกลับมาเป็นอะไรก็ได้) ไม่ใช่ราคา Call · ln|x| มี |·| เพราะ ln รับเฉพาะค่าบวก · สูตรแรกใช้ไม่ได้เมื่อ n = −1 (หารด้วยศูนย์) — กรณีนั้นคือสูตรที่สาม

  • ราคา Option = ∫ payoff × ความหนาแน่นความน่าจะเป็น = Expected Payoff คิดลด

7.6 Taylor Series → Delta-Gamma Approximation

Delta-Gamma Approximation Taylor 2 เทอม ★★★ ต้องรู้จัก

🚶 อ่านเป็นภาษาคนก่อน: Taylor Series คือการประมาณ "ถ้าขยับไปนิดหนึ่ง ค่าใหม่ ≈ ค่าเดิม + ความชัน×ระยะ + ครึ่งหนึ่งของความโค้ง×ระยะ² " · เอามาใช้กับ option ตรง ๆ จะได้สูตรที่ risk desk ใช้ทุกวัน

f(x+h) ≈ f(x) + f'(x)·h + ½·f''(x)·h² ΔV ≈ Delta·ΔS + ½·Gamma·(ΔS)² └ เชิงเส้น ┘ └ แก้ความโค้ง ┘

📖 อ่านสูตรว่า: "เอฟของเอ็กซ์บวกเอช ประมาณ เอฟของเอ็กซ์ บวก เอฟไพรม์ของเอ็กซ์ คูณ เอช บวก ครึ่งของเอฟดับเบิลไพรม์ของเอ็กซ์ คูณ เอชกำลังสอง · เดลตาวี ประมาณ เดลตา คูณ เดลตาเอส บวก ครึ่งแกมมา คูณ เดลตาเอสกำลังสอง" · โครงที่ต้องเห็น: ค่าเดิม + ความชัน×ระยะ + ½×ความโค้ง×ระยะ² — พจน์แรกคือเส้นตรง พจน์สองคือ "ค่าแก้" ที่โผล่เพราะเส้นโค้ง · ลอง ΔS = 0: ΔV = 0 ราคาไม่ขยับก็ไม่มีอะไรเปลี่ยน (สูตรนี้ยังไม่มีพจน์เวลา) · กับดักการอ่าน: ≈ มีสมมติฐานว่า h หรือ ΔS เล็ก — ยิ่งขยับไกล พจน์อันดับสูงที่ตัดทิ้งยิ่งใหญ่ · บรรทัดสองมี Δ สองความหมาย: ΔV, ΔS (มีตัวแปรตาม) = "การเปลี่ยนแปลง" ส่วน Delta, Gamma ที่เขียนเป็นคำ = Greeks · (ΔS)² ยกกำลังทั้งก้อน ไม่ใช่ Δ(S²)

🧮 ตัวอย่าง — ทำไม Delta อย่างเดียวไม่พอ

Option มี Δ=0.5, Γ=0.04 · หุ้นพุ่ง ΔS = +฿10

  • ถ้าใช้ Delta อย่างเดียว: ΔV ≈ 0.5×10 = +5.0
  • รวม Gamma: ΔV ≈ 0.5×10 + ½×0.04×10² = 5.0 + 2.0 = +7.0

Gamma เพิ่มอีก +2.0 — ยิ่งหุ้นขยับแรง (ΔS ใหญ่) เทอม Gamma ยิ่งสำคัญ เพราะมันโตตาม (ΔS)² · นี่คือเหตุผลที่ Long Gamma กำไรเมื่อตลาดเหวี่ยงแรง

🐍 พิสูจน์ด้วย Python ว่า Taylor แม่นแค่ไหน — เทียบ 3 อย่าง: (1) Delta อย่างเดียว (2) Delta+Gamma (3) ราคาจริงจาก BS reprice (บทที่ 11) · ใช้ Call ATM จริง (V=12.336, Δ=0.627, Γ=0.0151):

🐍 Python — Delta-Gamma approx เทียบราคาจริง
from math import log, sqrt, exp, erf
def N(x): return 0.5*(1 + erf(x/sqrt(2)))
def bs(S, K, r, s, T):
    d1 = (log(S/K)+(r+s*s/2)*T)/(s*sqrt(T)); d2 = d1 - s*sqrt(T)
    return S*N(d1) - K*exp(-r*T)*N(d2)

K, r, sig, T = 100, 0.05, 0.25, 1
S0 = 100
V, Delta, Gamma = 12.336, 0.6274, 0.0151     # Greeks ที่จุดเริ่ม (บท 11)

print(" dS | จริง(reprice) | Delta อย่างเดียว | Delta+Gamma")
for dS in [1, 5, 10, 20, -10, -20]:
    true   = bs(S0+dS, K, r, sig, T) - V     # ราคาจริงเปลี่ยนไปเท่าไร
    d_only = Delta*dS                        # ประมาณเชิงเส้น
    d_gam  = Delta*dS + 0.5*Gamma*dS**2      # + เทอมความโค้ง
    print(f"{dS:+4d} | {true:+8.3f}     | {d_only:+8.3f}       | {d_gam:+8.3f}")
#  dS | จริง(reprice) | Delta อย่างเดียว | Delta+Gamma
#   +1 |   +0.635     |   +0.627       |   +0.635   ← ขยับนิด: เท่ากันหมด
#   +5 |   +3.319     |   +3.137       |   +3.326
#  +10 |   +6.969     |   +6.274       |   +7.029   ← Delta เดี่ยวเริ่มพลาด
#  +20 |  +15.070     |  +12.548       |  +15.568   ← Delta พลาด 2.5! Gamma กู้กลับมาเกือบตรง
#  -10 |   -5.466     |   -6.274       |   -5.519   ← Delta คิดว่าขาดทุน 6.27
#  -20 |   -9.194     |  -12.548       |   -9.528   ← จริง ๆ ขาดแค่ 9.2 (Gamma พยุง)
✅ อ่านผลลัพธ์ — 3 บทเรียนจากตาราง
  • ขยับนิดเดียว Delta ก็พอ — ที่ ΔS=+1 ทั้ง 3 ค่าเท่ากันหมด (ความโค้งยังไม่ทันสำคัญ)
  • ขยับแรง ต้องมี Gamma — ที่ ΔS=+20 Delta เดี่ยวพลาดถึง 2.5 บาท แต่ Delta+Gamma เกือบตรง · เทอม Gamma โตตาม (ΔS)² จึงเด่นขึ้นเมื่อขยับใหญ่
  • Gamma พยุงขาลง (convexity) — ตอนหุ้นตก −20 Delta คิดว่าขาดทุน 12.5 แต่จริง ๆ ขาดแค่ 9.2 · การถือ Long Gamma ทำให้ "ขึ้นได้มากกว่า ลงเจ็บน้อยกว่า" ที่ Delta ทำนาย — นี่คือมูลค่าของ convexity ที่จ่ายผ่าน Theta

🎓 รวมร่าง: อ่าน Greeks ของไม้จริง 1 ไม้

เอา Greeks ทั้งชุดมาใช้กับไม้เดียว · คุณถือ Long Call ATM (Δ=+0.50, Γ=+0.05, Θ=−0.10/วัน, ν=+0.15) มาไล่ทีละสถานการณ์:

🧭 นิสัยคิด — เจอเหตุการณ์ ให้ถามว่า "Greek ตัวไหนทำงาน"
  1. หุ้นพุ่ง +฿4 ทันที: ΔV ≈ Δ·ΔS + ½Γ·ΔS² = 0.50×4 + ½×0.05×16 = 2.0 + 0.4 = +2.4 (Gamma ช่วยเพิ่ม 0.4)
  2. ผ่านไป 1 วัน หุ้นนิ่ง: ΔV ≈ Θ = −0.10 (ค่าเวลาไหลออก — คุณ "จ่ายค่าเช่า")
  3. ตลาดตกใจ σ พุ่ง +3 จุด: ΔV ≈ ν×3 = 0.15×3 = +0.45 (Long Call ได้ประโยชน์จาก σ ที่สูงขึ้น)

อ่าน Greeks เป็น = คุณรู้ล่วงหน้าว่าไม้นี้ "ชอบ" อะไร (หุ้นวิ่ง, σ ขึ้น) และ "กลัว" อะไร (เวลาผ่าน) — นั่นคือ "เอาไปคิดต่อได้" จริง ๆ

✍️ ลองทำเอง

ไม้เดียวกัน (Δ=0.50, Γ=0.05, Θ=−0.10, ν=0.15) · วันหนึ่งเกิดพร้อมกัน: หุ้น −฿2, เวลาผ่าน 1 วัน, σ ตก 2 จุด · ประเมินว่ากำไรหรือขาดทุนรวมประมาณเท่าไร?

ดูเฉลย

หุ้น: 0.50×(−2) + ½×0.05×(−2)² = −1.0 + 0.1 = −0.9 · เวลา: −0.10 · σ: 0.15×(−2) = −0.30 · รวม ≈ −1.30 (ขาดทุน) — ทั้งสามแรงกดลงพร้อมกัน วันแย่ของ Long Call
