บทที่ 4: สถิติพื้นฐาน — "อ่านข้อมูลให้ออก"

Options เป็นเครื่องมือที่ซื้อขาย "ความไม่แน่นอน" — ถ้าไม่เข้าใจสถิติ ก็ไม่เข้าใจ Options บทนี้สอนตั้งแต่พื้นฐานสุด

4.1 ข้อมูลและการนำเสนอ

ก่อนจะวิเคราะห์ได้ ต้อง "เห็น" ข้อมูลก่อน เครื่องมือหลัก:

Histogram (ฮิสโตแกรม): แบ่งข้อมูลเป็นช่วงๆ นับจำนวนในแต่ละช่วง

เชื่อมกับ Options

Histogram ของ daily returns มักมีรูปร่างคล้าย "ระฆัง" (Bell Curve) — นี่คือ Normal Distribution ที่ Black-Scholes ใช้เป็นสมมติฐานหลัก จะเรียนละเอียดในบท 6

4.2 ค่ากลาง (Measures of Central Tendency)

เมื่อมีข้อมูลชุดหนึ่ง "ค่ากลาง" บอกว่า "ตรงกลาง" อยู่ที่ไหน

ตัวอย่าง: Daily returns ของหุ้น 6 วัน: -5%, +2%, +8%, -1%, +3%, +50%

ค่ากลางวิธีคำนวณผลลัพธ์จุดเด่น
Mean (ค่าเฉลี่ย)(-5+2+8-1+3+50)/6+9.5%ใช้ทุกค่า แต่ไวต่อ outlier (+50%!)
Median (มัธยฐาน)เรียง: -5,-1,2,3,8,50 → กลาง = (2+3)/2+2.5%ไม่ไวต่อ outlier — ภาพจริงมากกว่า
Mode (ฐานนิยม)ค่าที่ซ้ำบ่อยสุดไม่มี (ไม่ซ้ำ)ใช้กับ discrete data
ระวัง: Mean ถูก Outlier บิดเบือน!

ค่า +50% ทำให้ Mean = 9.5% ซึ่งสูงเกินจริงมาก — วัน "ปกติ" ได้แค่ -5% ถึง +8%
Median = 2.5% สะท้อนความเป็นจริงมากกว่า นี่คือเหตุผลที่ในการเงินมักดู Median ด้วย

Weighted Average (ค่าเฉลี่ยถ่วงน้ำหนัก):

Weighted Mean = Σ(wᵢ × xᵢ) / Σ(wᵢ)
เชื่อมกับ Options

Portfolio Return = Σ wᵢ × rᵢ (ผลตอบแทนพอร์ต = weighted average ของ return แต่ละหุ้น)
เช่น: หุ้น A (40% ของพอร์ต, return +5%) + หุ้น B (60%, return -2%)
Portfolio Return = 0.4×5% + 0.6×(-2%) = 2% - 1.2% = +0.8%

4.3 ค่าการกระจาย — Variance และ Standard Deviation

Variance (ความแปรปรวน) วัดว่าข้อมูลกระจายออกจาก Mean มากแค่ไหน

Variance (σ²) = Σ(xᵢ - μ)² / n
= "ค่าเฉลี่ยของระยะห่างจาก mean ยกกำลัง 2"

Standard Deviation (ส่วนเบี่ยงเบนมาตรฐาน) = √Variance → กลับมาหน่วยเดิม

σ = √(Σ(xᵢ - μ)² / n)

ตัวอย่าง: หุ้น A (returns: +1%, -1%, +2%, -2%) vs หุ้น B (returns: +10%, -8%, +12%, -14%)

หุ้น Aหุ้น B
Mean0%0%
σ (Std Dev)1.58%11.2%
ความหมายนิ่ง สงบผันผวนมาก!
เชื่อมกับ Options — σ = Volatility!

Standard Deviation ของ returns = Volatility (ความผันผวน)
นี่คือค่าที่กำหนดราคา Options โดยตรง!
หุ้น B (σ=11.2%) จะมี Options แพงกว่าหุ้น A (σ=1.58%) มาก
เพราะ "ความไม่แน่นอนสูง" = "โอกาสที่ option จะมีค่า" สูง

4.4 Percentile และ Quartile

Percentile = "ค่าที่มีข้อมูล X% อยู่ข้างล่าง"

Percentileชื่อความหมาย
P25 (Q1)Quartile ที่ 125% ของข้อมูลอยู่ต่ำกว่านี้
P50 (Q2)Median50% อยู่ต่ำกว่า = กลางพอดี
P75 (Q3)Quartile ที่ 375% อยู่ต่ำกว่านี้
P55th Percentileมีแค่ 5% ที่แย่กว่านี้
เชื่อมกับ Options — VaR (Value at Risk)

VaR ที่ 95% = P5 ของ returns = "ในวันที่แย่ที่สุด 5% ขาดทุนอย่างน้อยเท่าไหร่"
เช่น: ถ้า VaR (95%, 1-day) = -3.2% บนพอร์ต ฿1 ล้าน → มีโอกาส 5% ที่จะเสีย ≥ ฿32,000 ในวันเดียว

4.5 Covariance และ Correlation

Covariance วัดว่าตัวแปร 2 ตัว "เคลื่อนไหวไปด้วยกัน" หรือไม่:

Cov(X,Y) = Σ(xᵢ - μₓ)(yᵢ - μᵧ) / n

Correlation (ρ) = Covariance ที่ปรับสเกลแล้ว อยู่ระหว่าง -1 ถึง +1:

ρ = Cov(X,Y) / (σₓ × σᵧ)
ρความหมายตัวอย่าง
+1ขึ้น/ลงพร้อมกันเป๊ะหุ้น CPALL กับ ดัชนี SET50
0ไม่สัมพันธ์กันหุ้นไทย กับ ราคาข้าวสาลี
-1สวนทางกันเป๊ะหุ้น กับ ราคาทองคำ (บางช่วง)
เชื่อมกับ Options

ถ้าหุ้น 2 ตัวมี ρ สูง → diversification ไม่ช่วยลด risk มาก
Portfolio Variance = Σᵢ Σⱼ wᵢwⱼσᵢσⱼρᵢⱼ — สูตรนี้จะใช้ในบท 8 (Linear Algebra)

สรุปบทที่ 4

✓ อ่าน Histogram ออก (เห็นรูประฆัง = Normal Distribution)
✓ เข้าใจ Mean, Median, Mode และข้อจำกัดของแต่ละตัว
✓ คำนวณ Weighted Average ได้ (Portfolio Return)
✓ σ (Standard Deviation) = Volatility — ค่าที่กำหนดราคา Options
✓ เข้าใจ Percentile → VaR
✓ เข้าใจ Correlation → Portfolio Risk

บทที่ 5: ความน่าจะเป็น — "วัดความไม่แน่นอน"

Options คือการ "ซื้อขายความน่าจะเป็น" — ถ้าไม่เข้าใจ probability ก็ไม่เข้าใจราคา Options

5.1 ความน่าจะเป็นพื้นฐาน

P(A) = ความน่าจะเป็นที่เหตุการณ์ A จะเกิด อยู่ระหว่าง 0 (ไม่มีทางเกิด) ถึง 1 (เกิดแน่นอน)

P(not A) = 1 - P(A)
P(A or B) = P(A) + P(B) - P(A and B)
P(A and B) = P(A) × P(B)    ← ถ้า A, B เป็นอิสระต่อกัน
ตัวอย่าง

ทอยลูกเต๋า: P(ได้ 6) = 1/6 ≈ 16.7%
P(ไม่ได้ 6) = 1 - 1/6 = 5/6 ≈ 83.3%
ทอย 2 ลูก P(ได้ 6 ทั้งคู่) = 1/6 × 1/6 = 1/36 ≈ 2.8%

5.2 Combinations (การจัดหมู่)

C(n, k) = n! / (k! × (n-k)!) = จำนวนวิธีเลือก k ชิ้นจาก n ชิ้น (ไม่สนลำดับ)

nkC(n,k)ตัวอย่าง
5210เลือกหุ้น 2 ตัวจาก 5 ตัว
103120เลือก option 3 ตัวจาก 10 strike
426เลือกขาขึ้น 2 วันจาก 4 วัน
เชื่อมกับ Options

C(n,k) จะใช้ใน Binomial Distribution (บทถัดไป) ซึ่งเป็นพื้นฐานของ Binomial Tree — วิธี pricing Options แบบ discrete ที่ง่ายที่สุด

5.3 Conditional Probability และ Bayes' Theorem

P(A|B) = ความน่าจะเป็นที่ A เกิด เมื่อรู้แล้วว่า B เกิด

P(A|B) = P(A and B) / P(B)

Bayes' Theorem:
P(A|B) = P(B|A) × P(A) / P(B)
ตัวอย่าง: อัพเดทมุมมอง

ก่อนประกาศผล: P(หุ้นขึ้น) = 60%
รู้ว่ากำไรดีกว่าคาด (B): P(กำไรดี | หุ้นขึ้น) = 80%, P(กำไรดี | หุ้นไม่ขึ้น) = 30%
P(กำไรดี) = 0.8×0.6 + 0.3×0.4 = 0.60
P(หุ้นขึ้น | กำไรดี) = 0.80×0.60 / 0.60 = 80% ← อัพจาก 60% เป็น 80%!

5.4 Expected Value (ค่าคาดหวัง)

E[X] = "ค่าเฉลี่ยระยะยาว" ถ้าทำซ้ำหลายๆ ครั้ง

E[X] = Σ xᵢ × P(xᵢ)    (สำหรับ discrete)

สมบัติสำคัญ:
E[aX + b] = a × E[X] + b
E[X + Y] = E[X] + E[Y]    ← ใช้ได้เสมอ!
เชื่อมกับ Options — Expected Payoff

ราคา Option ≈ PV ของ Expected Payoff ภายใต้ risk-neutral probability:
C = e-rT × E*[max(0, S-K)]
E* = expected value ใน "โลก risk-neutral" (จะเรียนในบท 14)

5.5 Variance — Properties

Var(X) = E[(X - μ)²] = E[X²] - (E[X])²

สมบัติสำคัญ:
Var(aX + b) = a² × Var(X)    ← บวกค่าคงที่ไม่เปลี่ยน Var!
Var(X + Y) = Var(X) + Var(Y) + 2×Cov(X,Y)
เชื่อมกับ Options — Portfolio Variance

จาก Var(X+Y) ขยายเป็นหลายตัวแปร:
Portfolio Variance = Σᵢ Σⱼ wᵢ wⱼ σᵢ σⱼ ρᵢⱼ
เขียนเป็น matrix form: σ²_p = wT Σ w (จะเรียนในบท 8)

สรุปบทที่ 5

✓ คำนวณความน่าจะเป็นพื้นฐานได้
✓ ใช้ Combinations → Binomial coefficient
✓ อัพเดทความเชื่อด้วย Bayes
✓ คำนวณ Expected Value → Expected Payoff
✓ เข้าใจ Variance properties → Portfolio Variance

บทที่ 6: Distributions — "รูปทรงของความไม่แน่นอน"

ทุก Distribution คือ "รูปทรง" ที่บอกว่าค่าแต่ละค่ามีโอกาสเกิดขึ้นมากน้อยแค่ไหน บทนี้สอน Distributions ที่สำคัญที่สุดสำหรับ Options

6.1 Binomial Distribution

ถ้าทำการทดลองที่ "สำเร็จ" ด้วยความน่าจะเป็น p จำนวน n ครั้ง โอกาสสำเร็จ k ครั้ง:

P(X = k) = C(n,k) × pk × (1-p)n-k

ตัวอย่าง: โยนเหรียญ 4 ครั้ง (p=0.5) โอกาสได้หัว k ครั้ง:

k (หัว)C(4,k)P(X=k)เปอร์เซ็นต์
010.06256.25%
140.250025.0%
260.375037.5%
340.250025.0%
410.06256.25%
เชื่อมกับ Options — Binomial Tree

ใน Binomial Option Pricing Model ราคาหุ้นขึ้น (probability p) หรือลง (probability 1-p) ในแต่ละ step — เป็น Binomial Distribution พอดี!
เมื่อ n → ∞ (จำนวน steps → มาก) Binomial → Normal (Central Limit Theorem)

6.2 Normal Distribution — หัวใจของ Black-Scholes

Normal Distribution (การแจกแจงปกติ) มีรูปร่าง "ระฆัง" สมมาตร กำหนดโดย 2 ค่า:

  • μ (mean) = จุดศูนย์กลาง (ยอดระฆัง)
  • σ (standard deviation) = ความกว้างของระฆัง
PDF: f(x) = (1 / σ√(2π)) × e-(x-μ)²/(2σ²)
(ไม่ต้องจำสูตร แค่เข้าใจรูปร่าง)

กฎ 68-95-99.7:

ช่วงครอบคลุมตัวอย่าง: หุ้น μ=0%, σ=20%/ปี
μ ± 1σ68.3%68% ของปี return อยู่ใน -20% ถึง +20%
μ ± 2σ95.4%95% อยู่ใน -40% ถึง +40%
μ ± 3σ99.7%99.7% อยู่ใน -60% ถึง +60%

6.3 Z-Score และ Standard Normal N(0,1)

Z-score = "ห่างจาก mean กี่ standard deviations"

Z = (x - μ) / σ

N(d) = CDF ของ Standard Normal = ความน่าจะเป็นที่ค่าจะ ≤ d

dN(d)ความหมาย
-2.00.0228มีแค่ 2.3% อยู่ต่ำกว่า -2σ
-1.00.158715.9% อยู่ต่ำกว่า -1σ
0.00.500050% พอดี (= median)
+1.00.841384.1% อยู่ต่ำกว่า +1σ
+2.00.977297.7% อยู่ต่ำกว่า +2σ
เชื่อมกับ Options — N(d₁) และ N(d₂) ใน Black-Scholes!

ในสูตร BS: C = S₀×N(d₁) - K×e-rT×N(d₂)
• N(d₁) ≈ ความน่าจะเป็นที่ option จะ expire ITM (ปรับแล้ว)
• N(d₂) ≈ ความน่าจะเป็นที่จะถูก exercise
d₁ และ d₂ คือ Z-scores! ที่รวม ln(S/K), r, σ, T เข้าด้วยกัน

6.4 Lognormal Distribution — ทำไมราคาหุ้นไม่เป็น Normal

ปัญหา: ถ้าราคาหุ้นเป็น Normal Distribution → ราคาอาจติดลบได้! (เช่น -฿50) ← ไม่สมจริง

ทางออก: ถ้า ln(ราคา) เป็น Normal → ราคาเป็น Lognormal → ราคา > 0 เสมอ!

ถ้า ln(S) ~ Normal(μ, σ²) แล้ว S ~ Lognormal
→ S = eln(S) > 0 เสมอ (เพราะ e ยกกำลังอะไรก็เป็นบวก)
เชื่อมกับ Log Return (จากบทที่ 3)

จำได้ไหม? log return r = ln(S₁/S₀) = ln(S₁) - ln(S₀)
ถ้า r ~ Normal → S₁ = S₀ × er ~ Lognormal
นี่คือ chain: Log return เป็น Normal → ราคาเป็น Lognormal
Black-Scholes สมมติว่า log returns เป็น Normal Distribution

6.5 Central Limit Theorem (CLT)

CLT = ทฤษฎีบทที่สำคัญที่สุดในสถิติ:

Central Limit Theorem

"ค่าเฉลี่ยของตัวอย่างจำนวนมาก → Normal Distribution เสมอ ไม่ว่า distribution เดิมจะเป็นอะไร"

นี่คือเหตุผลที่ Normal Distribution ปรากฏทุกที่ใน finance!

เชื่อมกับ Options

• Binomial Tree (n steps) → เมื่อ n → ∞ → Black-Scholes (CLT!)
• Return รายวันอาจไม่เป็น Normal แต่ return รายเดือน/ปี ≈ Normal (CLT!)
• Monte Carlo ใช้ CLT: เฉลี่ย payoff จากหลายๆ simulation → ค่า converge

6.6 Skewness และ Kurtosis

ตลาดจริงไม่ใช่ Normal พอดี — มีการเบ้และหางหนา:

สมบัติNormalตลาดจริงผลกระทบ
Skewness (เบ้)0 (สมมาตร)เบ้ซ้าย (negative)ตกหนักกว่าขึ้น
Kurtosis (หาง)3 (mesokurtic)>3 (fat tails)เหตุการณ์สุดขั้วเกิดบ่อยกว่า
เชื่อมกับ Options — Volatility Smile/Skew

เพราะตลาดจริงมี fat tails → ตลาด "รู้" ว่า Normal ไม่พอ → OTM Puts แพงกว่าที่ BS ทำนาย
ผลลัพธ์: กราฟ Implied Volatility vs Strike เป็นรูป "ยิ้ม" (Smile) หรือ "เอียง" (Skew)
นี่คือข้อจำกัดหลักของ Black-Scholes ที่ quant ทุกคนต้องรู้

สรุปบทที่ 6

✓ Binomial Distribution → สะพานสู่ Binomial Tree pricing
✓ Normal Distribution: Bell curve, กฎ 68-95-99.7, Z-score
✓ N(d) = CDF → อ่าน N(d₁), N(d₂) ใน BS ออกแล้ว!
✓ Lognormal: ราคาหุ้นเป็น Lognormal เพราะ log return เป็น Normal
✓ CLT: ทำไม Normal ปรากฏทุกที่
✓ Skewness/Kurtosis: ทำไม Volatility Smile เกิดขึ้น
