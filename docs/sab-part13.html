3 คำที่ต้องจำก่อน

  • แรงดึงกลับ (mean reversion) = แรงดึง X เข้าหาค่ากลาง ห่างมากดึงมาก
  • φ (ฟาย) = ทุกช่วงระยะห่างจากค่ากลางเหลือกี่ส่วน
  • ครึ่งชีวิต (half-life) = ช่วงที่เส้นค่าเฉลี่ยใช้ลดระยะห่างลงครึ่ง

ที่เหลือ

  • เดินสุ่ม (random walk) = การเปลี่ยนเฉลี่ยศูนย์แต่ไม่มีแรงดึงกลับ
  • แรงสะบัด (noise) = การขยับสุ่มของ X แต่ละช่วง
  • เวลาแตะเป้า (first passage) = ช่วงจนเส้นทางหนึ่งแตะเป้าครั้งแรก
  • ใบหลักฐาน 6 แถว = สถานะหลักฐานแรงดึงกลับ ผ่าน / ยังไม่ชัด / ไม่ผ่าน
