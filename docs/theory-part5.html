เปิดเรื่อง: กับดักที่ฆ่า quant มือใหม่มากที่สุด

ปี 1974 Granger & Newbold ตีพิมพ์ผลที่น่าตกใจ: เอา random walk สองเส้นที่ไม่เกี่ยวอะไรกันเลย มา regress กัน — แล้วได้ R² สูง, t-stat สวยงาม, ดู "มีความสัมพันธ์" อย่างมีนัยสำคัญ ทั้งที่มันสุ่มล้วน เรียกว่า spurious regression ที่ร้ายคือ ยิ่งใส่ข้อมูลมากขึ้น ภาพลวงยิ่งชัดขึ้น (t-stat ลู่ออกแทนที่จะลู่เข้า — Phillips 1986) นี่คือกับดักที่ฆ่า quant มือใหม่มากที่สุด: เห็นรูปแบบที่ไม่มีอยู่จริง

Part V คือชุดเครื่องมือ 2 ฝั่ง: ฝั่งหนึ่งคือวิธีหาโครงสร้างจริงในเวลา (GARCH, cointegration, regime) อีกฝั่งคือวิธีพิสูจน์ว่าโครงสร้างนั้นจริง ไม่ใช่บังเอิญ (deflated Sharpe) — Engle กับ Granger ได้โนเบลปี 2003 จากการสร้างเครื่องมือเหล่านี้

ในการเทรด ศัตรูที่อันตรายที่สุดไม่ใช่ตลาด — มันคือตัวคุณเองที่อยากเชื่อว่า backtest สวย ๆ เป็นเรื่องจริง

รากฐาน: Stationarity และตระกูล ARIMA

Stationarity & ARIMA 1970 · Box-Jenkins ★★ ควรรู้ · concept-card

🎯 Thesis

"จะวิเคราะห์อนุกรมเวลาได้ มันต้อง stationary ก่อน (ค่าเฉลี่ย/ความแปรปรวนไม่เปลี่ยนตามเวลา) — ราคาหุ้นไม่ stationary (เดินสุ่ม) แต่ ผลตอบแทน ใกล้เคียงกว่า; ARIMA จับ pattern เชิงเส้น (autocorrelation) ที่เหลือ"

❓ ทำไมต้องรู้จัก

เพราะ การวิเคราะห์อนุกรม non-stationary = spurious regression ถ้าไม่เข้าใจ stationarity คุณจะ regress ราคา 2 ตัวแล้วคิดว่าเจอ edge ทั้งที่มันสุ่ม — เป็นบทเรียนแรกก่อนแตะ time series ใด ๆ และเป็นฐานของ GARCH/cointegration ที่ตามมา

AR(1): X_t = φ·X_{t-1} + ε_t (|φ|<1 → stationary; φ=1 → random walk = unit root)
ARIMA(p,d,q): AR(p) + ผลต่าง d ครั้ง (ทำให้ stationary) + MA(q)
เลือก p,q ด้วย ACF/PACF · เช็ค unit root ด้วย ADF

⚠️ ADF: H₀ = "มี unit root" → reject แล้วถึงสรุปว่า stationary; "reject ไม่ได้" ≠ พิสูจน์ว่า stationary
🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: เอาราคามา fit โมเดลทำนายราคาตรง ๆ
quant เห็น: งานครึ่งหนึ่งคือ แปลงข้อมูลให้ stationary ก่อน (diff, log, แปลงเป็น spread) เพราะ pattern จริงซ่อนหลังการแปลง และ non-stationarity คือเหตุที่ correlation ดิบ ๆ โกหก · เครื่องมือเสริม: Hurst exponent บอกว่าอนุกรม mean-revert/trend/สุ่ม

📚 อ้างอิง

Box & Jenkins (1970) Time Series Analysis · Dickey-Fuller (1979) unit root · Phillips (1986) spurious regression theory · (คณิตที่ math-part6)

GARCH — ความผันผวนที่พยากรณ์ได้

ARCH / GARCH 1982 / 1986 · Engle / Bollerslev ★★★ ต้องรู้จัก

🎯 Thesis

"ทิศของผลตอบแทนเดาไม่ได้ แต่ขนาดของมัน (volatility) เดาได้ — เพราะ vol เกาะกลุ่ม (vol clustering): วันผันผวนตามด้วยวันผันผวน วันสงบตามด้วยวันสงบ GARCH โมเดล vol วันนี้จาก vol + shock เมื่อวาน"

❓ ทำไมต้องรู้จัก

มันคือ จุดที่ random walk พังแล้วเราหากินได้ (โยง Part I): returns เป็น martingale difference แต่ vol มี structure → ใช้พยากรณ์ความเสี่ยง, ตั้ง position size, ตั้งราคา option (vol forecast) Engle ได้ โนเบล 2003 จากอันนี้

🚶 อ่านเป็นภาษาคนก่อน: ลองนึกถึงสภาพอากาศ — พายุไม่ได้มาสุ่มกระจาย มันมาเป็น "ฤดู": วันพายุมักตามด้วยวันพายุ วันสงบตามด้วยวันสงบ · ความผันผวนของตลาดก็เหมือนกัน (vol clustering) · GARCH แค่เขียนเป็นสมการว่า "vol พรุ่งนี้ = ส่วนหนึ่งของ vol เมื่อวาน + ส่วนหนึ่งของ shock ที่เพิ่งเกิด" — คุณเดาทิศพรุ่งนี้ไม่ได้ แต่เดาขนาดการแกว่งได้ดีทีเดียว

GARCH(1,1): σ²_t = ω + α·ε²_{t-1} + β·σ²_{t-1}
  α = น้ำหนัก shock เมื่อวาน · β = น้ำหนัก vol เมื่อวาน (β สูง = vol "จำ" นาน)
  persistence = α+β (ใกล้ 1 = clustering แรง; =1 คือ IGARCH) · long-run variance = ω/(1−α−β)

รุ่นต่อยอด: EGARCH (Nelson 1991), GJR (Glosten-Jagannathan-Runkle 1993) จับ "leverage effect" (ตลาดลง→vol พุ่งกว่าตลาดขึ้น); innovations แบบ Student-t/GED จับ fat tails (Bollerslev 1987)
🧮 ตัวอย่างการใช้งาน — long-run vol + persistence

สมมติ fit ได้ ω = 0.000002, α = 0.08, β = 0.90
→ persistence = α+β = 0.98 (ใกล้ 1 มาก = vol "จำ" นาน, shock จางช้า)
→ long-run variance = ω/(1−α−β) = 0.000002/0.02 = 0.0001 → σ = √0.0001 = 1%/วัน ≈ 1%×√252 ≈ 15.9%/ปี
👉 แปลว่า: เวลา vol พุ่งสูงตอนวิกฤต GARCH จะทำนายว่ามันค่อย ๆลู่กลับหา 1%/วัน (ยิ่ง persistence ใกล้ 1 ยิ่งลู่กลับช้า) — นี่คือ mean-reversion ของ vol ที่ใช้ตั้ง position size
✍️ ลองทำเอง: ถ้า α=0.05, β=0.94 persistence เท่าไร และลู่กลับเร็วหรือช้ากว่าตัวอย่างนี้?

✅ ใช้ได้เมื่อไร
  • พยากรณ์ vol ระยะสั้น-กลาง, position sizing, vol forecast สำหรับ option
  • เป็น benchmark/บรรพบุรุษทางความคิดของ risk model — แต่ของจริงบนโต๊ะมักเป็น EWMA/realized vol (ดูด้านล่าง)
❌ พังเมื่อไร
  • ระยะสั้นดี แต่ระยะยาวลู่กลับ long-run mean (ทำนาย "พรุ่งนี้" เก่งกว่า "ปีหน้า")
  • จับ jump ไม่ได้ (vol พุ่งแบบกระโดดจากข่าว) ปรับตัวช้าหลังเหตุ
  • estimation ไม่เสถียร: MLE บน sample สั้น/สงบ มัก pin α+β ใกล้ 1 หรือไม่ converge → พารามิเตอร์ drift
  • GARCH ดิบแทบไม่ใช่ production: เดสก์ใช้ EWMA หรือ realized/HAR vol ที่ง่ายกว่าและมักสูสี/ชนะ
  • พยากรณ์ realized vol แต่ไม่บอกว่า option แพง/ถูก — การเทรดจริงอยู่ที่ implied-vs-realized (vol risk premium)
⚖️ ข้อดี
  • จับ vol clustering ซึ่งเป็นข้อเท็จจริงที่ทนทานสุดในตลาด
  • โครงสร้างตีความได้ (persistence, leverage effect)
  • benchmark/รากความคิดของ risk model
⚠️ ข้อเสีย
  • ระยะยาว/ตอน jump อ่อน; estimation ไม่เสถียร
  • EWMA/realized vol มักชนะด้วยความง่าย → GARCH ดิบไม่ใช่ production
  • บอก realized ไม่บอก implied (ของที่เทรดจริง)
🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: ตลาดเดาไม่ได้ทั้งหมด
quant เห็น: first moment (ทิศ) เดาไม่ได้ แต่ second moment (vol) เดาได้ — ส่วนที่พยากรณ์ได้ของตลาดคือ "ความเสี่ยง" ไม่ใช่ "ทิศทาง" แต่ระวัง: การพยากรณ์ vol ก็เป็นการพยากรณ์ที่ crowded ที่สุด (ทุกคนทำเหมือนกัน) edge จริงจึงอยู่ที่ execution/regime-timing และ implied-vs-realized ไม่ใช่ตัว forecast เอง

🎯 3 อย่างที่ต้องจำ
  • ทิศ (first moment) เดาไม่ได้ แต่ vol (second moment) เดาได้ เพราะ vol clustering
  • persistence = α+β (ใกล้ 1 = shock จำนาน); long-run variance = ω/(1−α−β)
  • GARCH ดิบไม่ใช่ production (เดสก์ใช้ EWMA/realized); ของที่เทรดจริงคือ implied-vs-realized
📍 ปัจจุบัน + 📚 Papers

production จริงคือ EWMA/realized-HAR (intraday) + implied vol; GARCH ใช้เชิงวิชาการ/structured/long-horizon scenario · Engle (1982) · Bollerslev (1986/1987) · Nelson (1991) · Glosten-Jagannathan-Runkle (1993) · โนเบล 2003

Cointegration & Ornstein-Uhlenbeck — รากของ Pairs Trading

Cointegration & OU Process 1987 · Engle-Granger; OU 1930 ★★★ ต้องรู้จัก

🎯 Thesis

"สองอนุกรมที่ต่างก็เดินสุ่ม (non-stationary) อาจ เดินไปด้วยกัน จน 'ส่วนต่าง (spread)' ของมัน stationary — เรียกว่า cointegrated สเปรดนั้นจะ ดึงกลับหาค่าเฉลี่ย (mean-revert) เหมือนสปริง = รากคณิตของ pairs trading"

❓ ทำไมต้องรู้จัก

มันคือทางออกจากกับดัก spurious regression และฐานคณิตของ stat-arb ทั้งหมด — cointegration คือสิ่งที่บอกว่าคู่ไหนเทรดได้จริง (correlation บอกไม่ได้) OU บอกว่าควรเข้า/ออกตรงไหน (z-score) และถือนานแค่ไหน (half-life)

🚶 อ่านเป็นภาษาคนก่อน: ลองนึกถึงคนจูงหมาเดินเล่น — ทั้งคนและหมาเดินไปเรื่อย ๆ เดาตำแหน่งไม่ได้ (ต่างก็ random walk) แต่สายจูงทำให้ระยะห่างระหว่างสองตัวไม่มีวันไกลเกินไป มันดึงกลับเสมอ · "สายจูง" นั้นคือ cointegration และ "ระยะห่าง" คือ spread ที่ mean-revert · pairs trading = เดิมพันว่าสายจูงยังอยู่: เข้าเมื่อระยะห่างมากผิดปกติ ออกเมื่อมันดึงกลับ

Cointegration: X_t, Y_t ต่าง non-stationary แต่ (Y_t − β·X_t) = spread stationary
ทดสอบ: Engle-Granger (สมการเดียว, เลือกตัวตาม, ทดสอบได้ "อย่างมาก 1 ความสัมพันธ์") · Johansen (VAR, หา จำนวน (rank) ความสัมพันธ์ในหลายตัวพร้อมกัน, สมมาตร) · เมื่อเจอ cointegration → เขียนเป็น VECM

Ornstein-Uhlenbeck (โมเดลสเปรด): dX = θ(μ − X)·dt + σ·dW
  θ = แรงดึงกลับ · half-life = ln2/θ (จากข้อมูล: fit AR(1) ของสเปรด φ=e^{−θΔt} → half-life = −ln2/ln φ)
  สัญญาณ: z-score = (spread − μ)/σ → เข้าเมื่อ |z| สูง ออกเมื่อกลับ 0
🧮 ตัวอย่างการใช้งาน — half-life ของสเปรด

fit AR(1) กับสเปรดรายวัน ได้ φ = 0.95
→ half-life = −ln2 / ln(φ) = −0.693 / ln(0.95) = 0.693 / 0.0513 ≈ 13.5 วัน
👉 แปลว่าถ้าสเปรดเบี่ยงไป มันใช้เวลา ~13.5 วันกลับครึ่งทางสู่ค่าเฉลี่ย — ต้องถือไหวอย่างน้อยหลาย half-life ก่อนกำไรจะมา · ถ้า half-life = 100 วัน คู่นั้นอาจ "cointegrate ในกระดาษ" แต่ช้าเกินจะเทรดคุ้ม
เข้าเมื่อ |z-score| ≥ 2 (สเปรดห่าง 2σ) ออกเมื่อ z กลับ ~0
✍️ ลองทำเอง: ถ้า φ = 0.90 half-life สั้นลงหรือยาวขึ้น? (คำใบ้: φ ต่ำ = ดึงกลับแรง = half-life สั้น)

⚠️ correlation ≠ cointegration (จุดที่คนพลาดบ่อยสุด)

correlation = "ขยับพร้อมกันวันต่อวัน" (เรื่องผลตอบแทน) · cointegration = "ลอยไปด้วยกันระยะยาว สเปรดกลับเข้าหากัน" (เรื่องระดับราคา) สองตัวอาจ correlate สูงแต่ลอยห่างเรื่อย ๆ (ไม่ cointegrate → เจ๊ง) หรือ correlate ต่ำแต่ cointegrate (เทรดได้)

✅ ใช้ได้เมื่อไร
  • คู่/ตะกร้าที่มีเหตุผลเชิงเศรษฐกิจให้ผูกกัน (หุ้นกลุ่มเดียวกัน, ETF vs ตะกร้า, on/off-the-run bond) ไม่ใช่แค่สถิติบังเอิญ
  • half-life สั้นพอเทียบทุน/horizon (ถือไหวก่อนความสัมพันธ์พัง)
  • residual ของ factor model (Avellaneda-Lee) เป็น OU → stat-arb สเกลใหญ่
❌ พังเมื่อไร (วิธีที่ pairs book ระเบิดจริง)
  • break เงียบและไม่สมมาตร: คุณรู้ว่าความสัมพันธ์พังก็ต่อเมื่อสเปรดถ่างไป 4–5σ แล้วไปต่อ — แย่สุดคือ z-score scaling สั่งให้เติมไม้ตอนมันถ่างออก (averaging into two diverging assets) = สูตรเจ๊ง
  • half-life เอนเอียง: θ ที่ประมาณจากอดีตเร็วเกินจริงอย่างเป็นระบบ (estimation bias บนอนุกรม persistent) → live half-life ยาวกว่า backtest เสมอ
  • pair-mining: รัน Engle-Granger/Johansen ข้ามพันคู่ → เจอ "cointegrated" ปลอมแน่นอน; p-value ของ test ไม่ validใต้การค้นหา (ต้องแก้ multiple-testing บน test เอง ไม่ใช่แค่ Sharpe)
  • crowding: ทุกคนรัน Johansen บน universe เดียวกัน → deleverage พร้อมกัน (Quant Quake 2007)
⚖️ ข้อดี
  • ฐานคณิตที่ถูกต้องของ mean-reversion (ไม่ใช่ correlation)
  • ให้สัญญาณเข้า/ออก (z-score) และ horizon (half-life) ชัด
  • market-neutral โดยโครงสร้าง
⚠️ ข้อเสีย
  • คือการ "ขาย insurance" (short gamma): กำไรเล็กบ่อย ขาดทุนใหญ่นาน — Sharpe สวยเพราะหางซ้ายยังไม่มา
  • break เงียบ + half-life bias + crowded
🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: "หาหุ้นที่ correlate กันสูง ๆ แล้วเทรดส่วนต่าง"
quant เห็น: correlation เป็นกับดัก — ที่เทรดได้คือ cointegration และที่ลึกกว่า: pairs trading คือการขายประกัน mean-reversion — คุณถูกจ่าย premium เล็ก ๆ เพื่อแบกความเสี่ยงว่าความสัมพันธ์จะ "พังถาวร" คำถามจริงไม่ใช่ "คู่นี้ cointegrate ไหม" แต่คือ "half-life สั้นพอจะถือไหวก่อนมันพังไหม"

💎 ความงาม

ความงามของ cointegration อยู่ที่ Granger Representation Theorem: ถ้าสองอนุกรม cointegrate มันต้องมี "เทอมดึงกลับ" (error-correction) ซ่อนอยู่เสมอ — คณิตศาสตร์รับประกันว่าสายจูงมีจริง ไม่ใช่แค่ภาพลวงตา · จากความสุ่มสองก้อนที่เดาอะไรไม่ได้เลย โผล่ออกมาเป็นสปริงที่คำนวณแรงดึง (θ) และเวลาได้ (half-life) · Granger ได้โนเบลปี 2003 ส่วนหนึ่งเพราะเปลี่ยน "spurious regression ที่ฆ่าคน" ให้กลายเป็น "เครื่องมือหาความสัมพันธ์จริง" — กับดักและทางออกมาจากคนคนเดียวกัน

🎯 3 อย่างที่ต้องจำ
  • correlation (ขยับพร้อมกัน) ≠ cointegration (ลอยไปด้วยกัน สเปรดกลับหากัน) — ที่เทรดได้คืออย่างหลัง
  • OU ให้สัญญาณครบ: z-score (เข้า/ออก) + half-life = ln2/θ (ถือนานแค่ไหน)
  • pairs = ขายประกัน mean-reversion (short gamma): กำไรเล็กบ่อย เจ๊งใหญ่ตอนสายจูงขาดถาวร

ฐานของ pairs/stat-arb, basket/index arb, basis trade; Avellaneda-Lee (2010) residual OU · Engle & Granger (1987) · Johansen (1988) · Uhlenbeck-Ornstein (1930)

Markov Regime-Switching 1989 · Hamilton ★★ ควรรู้ · concept-card

🎯 Thesis

"ตลาดไม่ได้มีพฤติกรรมเดียว — มันสลับ 'โหมด' (regime) เช่น สงบ/วิกฤต, bull/bear โดยแต่ละโหมดมี mean/vol ต่างกัน และการสลับเป็นแบบ Markov (โอกาสสลับขึ้นกับโหมดปัจจุบัน)"

❓ ทำไมต้องรู้จัก

เพราะโมเดลที่ดีในโหมดหนึ่งพังในอีกโหมด — correlation, vol, แม้แต่ทิศของ edge เปลี่ยนตาม regime เข้าใจแล้วจะไม่เอา parameter จากตลาด bull ไปใช้ตอน bear

❌ กับดักสำคัญ: filtered ≠ smoothed

regime ที่เห็นชัดในกราฟย้อนหลังคือ smoothed (ใช้ข้อมูลอนาคต — look-ahead!) แต่ที่เทรดได้จริงคือ filtered (ใช้ข้อมูลถึงวันนี้) ซึ่งช้า — คุณจะรู้ว่า regime สลับก็ต่อเมื่อมันผ่านไปครึ่งทางแล้ว backtest ที่ condition บน regime มักแอบใช้ตัว smoothed = หลอกตัวเอง

🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: หา parameter ชุดเดียวที่ "ถูกที่สุด"
quant เห็น: ไม่มี parameter ชุดเดียว — ความเสี่ยงจริงคือ การสลับโหมด ที่มาเร็วและทำให้ทุกอย่างที่ fit มา invalid พร้อมกัน และคุณรู้ว่าโหมดสลับก็ต่อเมื่อมันทำเงินคุณหายไปแล้ว

Deflated Sharpe & Backtest Overfitting 2014–18 · Bailey-López de Prado; Harvey-Liu-Zhu ★★★ ต้องรู้จัก

🎯 Thesis

"ถ้าลองกลยุทธ์ 1,000 แบบ ย่อมมีบางแบบที่ Sharpe สวยโดยบังเอิญล้วน — Sharpe ที่ไม่บอกว่า 'ลองมากี่ครั้ง' คือตัวเลขไร้ความหมาย Deflated Sharpe หักลบจำนวนครั้งที่ลอง เพื่อบอกว่ามัน 'จริง' หรือแค่โชค"

❓ ทำไมต้องรู้จัก

การ์ดที่สำคัญที่สุดในเล่มสำหรับคนจะลงเงินจริง — เพราะ การหลอกตัวเองด้วย backtest ปลอมคือสาเหตุอันดับหนึ่งที่ quant มือใหม่เจ๊ง มันเปลี่ยนคุณจาก "คนหา pattern" เป็น "นักวิทยาศาสตร์ที่ระแวงตัวเอง"

สัญชาตญาณ: ลอง N กลยุทธ์บน noise ล้วน → Sharpe สูงสุดที่คาดได้โตตาม ~√(2·ln N)
  → ยิ่งลองเยอะ "เกณฑ์ผ่าน" ยิ่งต้องสูงขึ้น (เหมือนยิงปืนรัวแล้ววาดเป้ารอบรูที่โดน)
Deflated Sharpe = เทียบ Sharpe ที่ได้ กับ Sharpe สูงสุดที่คาดจาก noise (ปรับ N + skew/kurtosis)
🧮 ตัวอย่างการใช้งาน — √(2·ln N)

ลองกลยุทธ์ N = 1,000 แบบบน noise ล้วน (ไม่มี edge จริงเลยสักตัว)
→ "best" Sharpe ที่คาดจากโชคล้วน ≈ √(2·ln 1000) = √(2×6.91) = √13.8 ≈ 3.7 (หน่วย standard error)
👉 แปลว่า ถ้าลอง 1,000 แบบ แล้วได้ตัวที่ "ดีสุด" Sharpe ดู 3.7σ เหนือศูนย์ — นั่นคือสิ่งที่ noise ให้ฟรี ๆ ไม่ใช่ edge! คุณต้องได้เกิน 3.7 มากถึงจะเริ่มน่าเชื่อ
เทียบ: ลองแค่ N=10 → √(2·ln10) ≈ 2.1 · นี่คือเหตุผลที่ "ลองน้อยครั้ง" มีค่า — เกณฑ์ผ่านต่ำลง
✍️ ลองทำเอง: ถ้าลอง N=100 เกณฑ์ noise ประมาณเท่าไร? (คำใบ้: √(2·ln100), ln100≈4.6)

🛡️ เครื่องมือกัน self-deception (López de Prado)

💸 จากสัญญาณสถิติ → edge ที่เทรดได้จริง (ช่องว่างที่ฆ่าคนมากสุด)

ผ่าน deflated Sharpe = แค่ "ไม่ใช่ของปลอมเชิงสถิติ" ยังไม่ใช่กำไร — สัญญาณ Sharpe 1.5 gross กลายเป็น ติดลบสุทธิได้ง่าย ๆ หลังหัก spread/impact/borrow/fee:

  • Turnover = ตัวเลขสำคัญอันดับ 2 รองจาก Sharpe: net Sharpe ≈ gross − (turnover × ต้นทุนต่อรอบ) → สัญญาณ turnover สูง (เช่น momentum รายวัน) ต้อง gross มหาศาลถึงรอด
  • Capacity: backtest รันที่ size = 0; กลยุทธ์ที่สวยที่ $1M อาจแบนที่ $100M
  • Live decay: live Sharpe มักเหลือราวครึ่งของ backtest — การทดสอบที่เชื่อถือได้สุดคือ paper/small-live tracking ไม่ใช่สถิติ in-sample ใด ๆ
🗄️ ความจริงที่ลึกกว่า overfitting: "งานส่วนใหญ่คือ data"

ข้อผิดที่พบบ่อยและร้ายกว่าการ overfit เชิงสถิติ คือข้อผิดเชิงข้อมูล:

  • Survivorship bias — บริษัทที่เจ๊ง/delist หายจาก universe → ผลดูดีเกินจริง
  • Look-ahead / point-in-time — ใช้งบที่ restate ภายหลัง, index membership, earnings ที่รู้ทีหลัง; การ normalize/winsorize ด้วยสถิติทั้ง sample; เลือก β cointegration จากทั้ง sample → ทั้งหมดคือ look-ahead ที่ซ่อนอยู่

👉 มือใหม่คิดว่างานคือโมเดล — จริง ๆ งานคือ ข้อมูล point-in-time ที่สะอาดและการนับ trial อย่างซื่อสัตย์

⚖️ ข้อดี
  • กันการหลอกตัวเอง #1 ที่ฆ่า quant
  • ให้กรอบเชิงปริมาณกับ "ลองกี่ครั้ง"
  • บังคับวินัยแบบวิทยาศาสตร์
⚠️ ข้อเสีย
  • ต้องรู้ "จำนวน trial จริง" ซึ่งมักประเมินต่ำกว่าจริง
  • กันของปลอม แต่ไม่ได้สร้างของจริง (ยังต้องผ่าน cost/capacity)
  • toolkit (purged CV ฯลฯ) influential แต่ contested — หลายเดสก์ยังเชื่อ walk-forward เคร่ง ๆ มากกว่า
🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: "backtest Sharpe 3 = เทพ รีบใช้!" และรัน backtest ให้เยอะที่สุดเพื่อหาตัวที่ดีสุด
quant เห็น: Sharpe ที่ไม่มี "ลองกี่ครั้ง" = ไร้ความหมาย และวินัยที่แท้จริงคือ การไม่มอง — ล็อก holdout ไว้แตะครั้งเดียวตอนจบ, ตั้งสมมติฐานก่อนดูข้อมูล (ไม่ใช่ขุดก่อนแล้วค่อยตั้ง), และยอมรับว่า ทุกการลองเพิ่มหนึ่งครั้ง ทำให้ทุกผลที่เก็บไว้น่าเชื่อถือน้อยลง — เก่งคือประหยัดจำนวนครั้งที่มอง ไม่ใช่ลองให้มากสุด

🧭 นิสัยคิด (heuristic ระดับโต๊ะ)

ก่อนเชื่อ backtest ใด ๆ ให้ตอบ 3 ข้อ: (1) ลองมากี่ครั้งจริง ๆ (นับทุก config/param ที่เคยเห็นผล ไม่ใช่แค่ตัวสุดท้าย)? (2) net Sharpe หลังหัก turnover×cost + capacity เหลือเท่าไร? (3) live/paper Sharpe เทียบ backtest เป็นยังไง (คาดว่าเหลือ ~ครึ่ง)? — ถ้าตอบไม่ครบ อย่าเพิ่งลงเงิน · กฎเหล็ก: ล็อก holdout ไว้แตะครั้งเดียวตอนจบ

🎯 3 อย่างที่ต้องจำ
  • Sharpe ที่ไม่บอก "ลองกี่ครั้ง" = ไร้ความหมาย (noise ให้ best ~√(2·ln N) ฟรี ๆ)
  • งานส่วนใหญ่คือ data สะอาด (point-in-time, กัน survivorship/look-ahead) + turnover/cost ไม่ใช่โมเดล
  • วินัยที่แท้จริงคือ "การไม่มอง" — ประหยัดจำนวน trial, ล็อก holdout, ตั้งสมมติฐานก่อนดูข้อมูล

mindset (multiple-testing, OOS holdout, trial logging, point-in-time DB, paper-vs-live) เป็นมาตรฐานที่จริงจัง — ส่วน toolkit เฉพาะ (purged CV, meta-labeling) ยัง contested · Bailey & López de Prado (2014) DSR · Bailey-Borwein-López de Prado-Zhu (2014) PBO / Pseudo-mathematics and Financial Charlatanism · López de Prado (2018) AFML · Harvey-Liu-Zhu (2016) · Harvey (2017) · ("factor zoo" ที่จริงบัญญัติโดย Cochrane 2011)
