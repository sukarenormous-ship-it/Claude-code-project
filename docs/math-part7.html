บทที่ 15: ทุกอย่างรวมกัน — "อ่าน Black-Scholes ออก"

อุปมา: อ่านแผนที่สมบัติที่แต่ละสัญลักษณ์มีความหมาย

ครั้งแรกที่เห็น BS formula มันดูเหมือนรหัสลับ — N(d₁), σ√T, e⁻ʳᵀ ...

แต่ตอนนี้ ทุกตัวอักษรมีบทที่มาจาก ที่คุณเรียนมาแล้ว:

e⁻ʳᵀ = บท 3 | N(d) = บท 6 | σ = บท 4 | √T = บท 14 | σ²/2 = Ito บท 14

บทนี้คือ "อ่านแผนที่" — ไล่ทีละตัวแล้วชี้ว่ามาจากไหน และ หมายความว่าอะไรในเชิงเศรษฐกิจ

ถึงเวลาพิสูจน์ว่าคุณเข้าใจจริง — ไล่สูตร BS ทีละตัวแล้วชี้ว่าแต่ละส่วนมาจากบทไหน

15.1 สูตร Black-Scholes ฉบับเต็ม

$$ C = S_0\,N(d_1) - K\,e^{-rT}\,N(d_2) $$
$$ P = K\,e^{-rT}\,N(-d_2) - S_0\,N(-d_1) $$
$$ d_1 = \frac{\ln(S_0/K) + (r + \sigma^2/2)T}{\sigma\sqrt{T}} \qquad d_2 = d_1 - \sigma\sqrt{T} $$
อ่านสูตร C = SN(d₁) − Ke⁻ʳᵀN(d₂) ใหม่ให้ออก

SN(d₁) = "มูลค่าที่คาดว่าจะได้รับจากหุ้น" — ถ้า option ถูก exercise, ได้หุ้นมูลค่า S แต่มีโอกาส N(d₁) ที่จะ exercise (ปรับ delta)

Ke⁻ʳᵀN(d₂) = "PV ของต้นทุนที่คาดว่าจะจ่าย" — ต้องจ่าย K เมื่อ exercise, discount กลับ (e⁻ʳᵀ), คูณด้วยโอกาส exercise N(d₂)

C = "สิ่งที่ได้" − "สิ่งที่จ่าย" = มูลค่าสุทธิของสิทธิ์นี้

Trader's View: ตลาด Quote ด้วย Implied Vol — ไม่ใช่ราคา

ในตลาด options จริง ผู้ค้ามักไม่ quote "ราคา ฿12.29" — แต่ quote "IV = 25%":
• เหตุผล: IV เปรียบเทียบได้ข้าม strike และ maturity ทันที — ฿12.29 สำหรับ Call เดือนหน้ากับ ฿12.29 Call 3 เดือนบอกอะไรไม่ได้
• BS เป็น translation layer: Vol → Price (สำหรับ quote) และ Price → Vol (สำหรับ mark-to-market)
• IV = 25% แปลว่า "ตลาดคาด annualized 1σ move = 25%" — ใช้เปรียบเทียบกับ realized vol เพื่อหา edge

15.2b N(d₁) vs N(d₂) — ต่างกันอย่างไร?

ทำไมต้องมีทั้ง d₁ และ d₂?

N(d₂) = ความน่าจะเป็นที่ S(T) > K ในโลก risk-neutral = "โอกาสที่จะ exercise"

N(d₁) = N(d₂) ที่ปรับด้วย "ขนาดที่ได้รับ" → Delta = N(d₁) (ถ้า S สูงขึ้น option ได้เท่าไหร่)

ความต่าง: d₁ = d₂ + σ√T → σ√T คือ Ito correction! (จากบท 14: d(lnS) = (μ−σ²/2)dt + σdW)

เหมือนถามว่า "จะ exercise ไหม?" (N(d₂)) vs "ถ้า exercise แล้วได้เท่าไหร่?" (N(d₁) × S)

1คำนวณ d₁, d₂: S=100, K=100, r=5%, σ=25%, T=1ปี

2ln(S/K) = ln(100/100) = ln(1) = 0 (ATM!)

3d₁ = [0 + (0.05 + 0.03125)×1] / (0.25×1) = 0.08125/0.25 = 0.325

4d₂ = 0.325 − 0.25 = 0.075

5N(d₁) = N(0.325) ≈ 0.627, N(d₂) = N(0.075) ≈ 0.530

6Ke⁻ʳᵀ = 100×e⁻⁰·⁰⁵ = 100×0.9512 = ฿95.12

7C = 100×0.627 − 95.12×0.530 = 62.70 − 50.41 = ฿12.29

15.3 พิสูจน์ Put-Call Parity จาก BS

ทำไมต้องพิสูจน์ PCP จาก BS?

เราเรียน PCP ในบท 2 จาก "เหตุผลทางการเงิน" (no-arbitrage)

ถ้า BS ถูกต้อง → ต้องสอดคล้องกับ PCP โดยอัตโนมัติ

การพิสูจน์นี้แสดงว่า BS มีความสอดคล้องภายในเอง — ไม่ใช่สูตรที่ "สุ่มมา"

$$ C - P = S_0[N(d_1)+N(-d_1)] - Ke^{-rT}[N(d_2)+N(-d_2)] = S_0 - Ke^{-rT} $$
$$ \Longrightarrow\quad C + Ke^{-rT} = P + S_0 \quad\text{✓ Put-Call Parity} $$
Normal CDF → N(x)+N(-x)=1 → C−P = S−Ke⁻ʳᵀ → PCP พิสูจน์แล้ว!
ทุกอย่างเชื่อมกัน!

Put-Call Parity (บท 2) ← มาจาก BS formula ← มาจาก Ito's Lemma (บท 14) ← มาจาก Chain Rule (บท 7) + Brownian Motion (บท 14) ← มาจาก Normal Distribution (บท 6) ← มาจาก e, ln (บท 3)

15.3b กรีกทั้งห้าในรูป Closed-Form (ตารางกรีกครบชุด)

อุปมา: มาตรวัดบนแผงหน้าปัดรถ 🔍

เรารู้ราคา option (C) แล้ว — แต่ราคานั้น ขยับ เมื่อปัจจัยรอบตัวขยับ: หุ้นขึ้น/ลง, เวลาเดิน, σ เปลี่ยน, r เปลี่ยน

กรีกแต่ละตัว = อนุพันธ์ของราคา option เทียบกับปัจจัยหนึ่ง — วัดว่าราคาขยับแค่ไหนเมื่อปัจจัยนั้นขยับทีละหน่วย

เหมือนมาตรวัดบนรถ: มาตรวัดความเร็ว (Δ), มาตรวัดความเร่ง (Γ), เกจน้ำมันที่ลดลงตามเวลา (Θ) — แต่ละอันบอก "ราคาตอบสนองอย่างไร" ต่อปัจจัยคนละตัว

ข่าวดี: ทุกตัวมี สูตรปิด (closed-form) — แค่หาอนุพันธ์ของ C = SN(d₁) − Ke⁻ʳᵀN(d₂) เทียบกับแต่ละปัจจัย

ตารางต่อไปนี้คือกรีกของ Call (φ = PDF ของ standard normal, N = CDF):

Greekนิยามสูตร (Call)ความหมาย
Delta (Δ)∂C/∂SN(d₁)ราคาขยับต่อ ฿1 ของหุ้น
Gamma (Γ)∂²C/∂S²φ(d₁) / (S·σ·√T)Delta ขยับเร็วแค่ไหน
Vega (ν)∂C/∂σS·φ(d₁)·√Tราคาขยับต่อ 1% ของ σ
Theta (Θ)∂C/∂t−S·φ(d₁)·σ/(2√T) − rK·e−rT·N(d₂)time decay ต่อวัน
Rho (ρ)∂C/∂rK·T·e−rT·N(d₂)ราคาขยับต่อ 1% ของ r
d₁, φ มาจากไหน?

φ(x) = (1/√(2π))·e−x²/2 คือ ความหนาแน่น (density) ที่จุด x — ไม่ใช่ความน่าจะเป็นสะสม N(x) (บท 6)

ทุกสูตรกรีกมีแต่ N(d) และ φ(d) เท่านั้น — ไม่ต้องมีสูตรลึกลับเพิ่ม เพราะมันคืออนุพันธ์ของ N(d₁), N(d₂) ที่เรามีอยู่แล้ว

ตัวอย่างคำนวณ: กรีกของ Call ที่ ATM

ใช้ตัวเลขชุดเดิม: S=100, K=100, r=5%, σ=25%, T=1ปี → d₁=0.325, d₂=0.075

ค่าที่ต้องใช้: φ(0.325) ≈ 0.378, N(0.325) ≈ 0.627, N(0.075) ≈ 0.530

1Delta = N(d₁) = N(0.325) = 0.627 → หุ้นขึ้น ฿1 ราคา option ขึ้นประมาณ ฿0.63

2Gamma = φ(d₁)/(S·σ·√T) = 0.378/(100×0.25×1) = 0.378/25 = 0.0151

3Vega = S·φ(d₁)·√T = 100×0.378×1 = 37.8 (per 1.00 vol) → ÷100 = 0.378 ต่อ 1% vol

4Theta = −S·φ(d₁)·σ/(2√T) − rK·e⁻ʳᵀ·N(d₂) = −(100×0.378×0.25/2) − (0.05×100×0.9512×0.530) ≈ −4.725 − 2.521 = −7.25 ต่อปี (÷365 ≈ −฿0.020 ต่อวัน)

5Rho = K·T·e⁻ʳᵀ·N(d₂) = 100×1×0.9512×0.530 ≈ 50.4 (per 1.00) → ÷100 = 0.504 ต่อ 1% ของ r

ข้อตกลงเรื่องหน่วย (conventions) — ระวังให้ดี!

Vega: สูตรให้ค่าต่อ vol = 1.00 (คือ 100%) — เทรดเดอร์มัก quote ต่อ 1% vol → หารด้วย 100 (37.8 → 0.378)
Theta: สูตรให้ค่าต่อปี — มัก quote เป็น time decay ต่อวันปฏิทิน → หารด้วย 365
Rho: เช่นเดียวกับ Vega มัก quote ต่อ 1% ของ r → หารด้วย 100

กรีกของ Put — ได้ฟรีจาก Put-Call Parity

เพราะ P = C − S + Ke⁻ʳᵀ (PCP, บท 2) อนุพันธ์ของ Put ต่างจาก Call แค่พจน์ที่ไม่ใช่ฟังก์ชันของ N(d):

Delta_put = N(d₁) − 1 (เป็นลบเสมอ — Put ได้กำไรเมื่อหุ้นลง)
Gamma_put = Gamma_call (เท่ากันทุกประการ)
Vega_put = Vega_call (เท่ากัน — vol สูงดีต่อทั้งสองฝั่ง)
Theta_put = Theta_call + rK·e⁻ʳᵀ (พจน์ discount กลับเครื่องหมาย)
Rho_put = −K·T·e⁻ʳᵀ·N(−d₂) (เป็นลบ — Put เสียมูลค่าเมื่อ r ขึ้น)

โจทย์: Gamma และ Vega ของ Call

ใช้ S=100, K=100, r=5%, σ=25%, T=1, φ(d₁)=φ(0.325)≈0.378
(ก) คำนวณ Gamma (ข) คำนวณ Vega ต่อ 1% vol (ค) ถ้า σ เพิ่มจาก 25% → 26% ราคา option ขึ้นประมาณเท่าไหร่?

ดูเฉลย

(ก) Gamma = φ(d₁)/(S·σ·√T) = 0.378/(100×0.25×1) = 0.0151

(ข) Vega (per 1.00) = S·φ(d₁)·√T = 100×0.378×1 = 37.8 → ต่อ 1% vol = 37.8/100 = 0.378

(ค) σ เพิ่ม 1% (จาก 25% → 26%) → ราคาขึ้นประมาณ Vega ต่อ 1% × 1 = ≈ ฿0.378

(เป็นค่าประมาณเชิงเส้น — Vega เองก็เปลี่ยนเมื่อ σ ขยับมาก จึงแม่นเฉพาะการขยับเล็กๆ)

15.4 ข้อจำกัดของ BS — สิ่งที่ต้องรู้

ทำไม BS ยังใช้กันอยู่ทั้งๆ ที่ผิด?

BS ใช้สมมติฐานที่ผิดจากความเป็นจริงหลายข้อ แต่ยังเป็น "ภาษากลาง" ของตลาด

Traders quote ด้วย Implied Volatility (IV) แทนราคา — ซึ่งใช้ BS เป็น translation layer

"All models are wrong, but some are useful" — ต้องรู้ว่า BS ผิดตรงไหน เพื่อจะได้ hedge ความผิดพลาดนั้น

สมมติฐาน BSความเป็นจริงผลกระทบ
σ คงที่σ เปลี่ยนตลอด (บท 12 GARCH)Volatility Smile/Skew — IV ต่างกันตาม K
Log returns เป็น NormalFat tails (บท 6.6)Underestimate tail risk — OTM options ถูกเกินไปใน BS
ไม่มี jumpsราคากระโดดได้ (gap opening)Deep OTM options มีราคาต่ำเกินไป
Trading ต่อเนื่องตลาดปิด/เปิดOvernight risk ไม่ถูก model
ไม่มี transaction costsมี commissions, bid-ask spreadHedging ไม่ perfect ในทางปฏิบัติ
Volatility Smile — หลักฐานว่า BS ไม่สมบูรณ์

ถ้า BS ถูกต้อง → IV ควรเท่ากันทุก Strike (σ คงที่)
แต่ในตลาดจริง: IV ของ OTM Put > ATM > OTM Call → เป็น "รอยยิ้ม" (Smile)
หรือ IV(OTM Put) >> IV(ATM) แบบเฉียง → เป็น "Skew"
Skew แสดงว่าตลาดกลัว downside มากกว่าที่ BS คาด (fat left tail)

15.5 ข้อสมมติที่ต้องจำให้ขึ้นใจ — European-only + ไม่มีปันผล

สี่ข้อสมมติที่ทำให้ BS ใช้ "ตรง ๆ" ไม่ได้เสมอไป

(1) European exercise เท่านั้น — สูตร BS ใช้กับ American option ตรง ๆ ไม่ได้ เพราะ American exercise เมื่อไหร่ก็ได้ก่อนหมดอายุ โดยเฉพาะ American put อาจ คุ้มที่จะ exercise ก่อนกำหนด (เอาเงิน K มาลงทุนต่อได้ดอกเบี้ย) → ต้องใช้ binomial tree หรือ MC แทน

(2) ไม่มี dividend — สูตรเดิมสมมติหุ้นไม่จ่ายปันผล ถ้าหุ้นจ่ายปันผลแบบ yield q ต้องใช้สูตรปรับ: แทน S ด้วย S·e−qT (ราคาหุ้นถูกหักด้วย PV ของปันผลที่จะจ่าย)

(3) r และ σ คงที่ — ในความเป็นจริง σ เปลี่ยนตลอด (เห็นได้จาก volatility smile/skew ข้างบน) และ r ก็ขยับตามตลาดพันธบัตร

(4) ซื้อขายต่อเนื่อง ไม่มี transaction cost — การ hedge แบบ delta จริงต้องปรับพอร์ตเป็นช่วง ๆ และมี commission + bid-ask spread → hedge ไม่ perfect

$$ C = S\,e^{-qT}\,N(d_1) - K\,e^{-rT}\,N(d_2) \qquad d_1 = \frac{\ln(S/K)+(r-q+\sigma^2/2)T}{\sigma\sqrt{T}} $$
Model Risk: "All Models Are Wrong" — รู้ว่า BS ผิดตรงไหน แล้วหาประโยชน์จากจุดนั้น

BS ยังเป็น benchmark ของตลาด แต่ต้องใช้พร้อมกับความเข้าใจข้อจำกัด:
• Vol Smile/Skew = หลักฐานชัดเจนที่สุดว่า lognormal ไม่พอ — OTM Put แพงกว่า BS predict
• Vanna/Volga: second-order vol Greeks ที่ BS ไม่ model — market makers hedge ด้วย Stochastic Vol
• ใช้ BS ถูกวิธี: quote ใน IV, hedge delta + gamma daily, เข้าใจ smile เพื่อ carry/spread trade
"เก่งกว่าคนอื่น ไม่ใช่ใช้ model ที่ถูกกว่า — แต่รู้ว่า model ผิดตรงไหน แล้วหาประโยชน์จากจุดนั้น"

บทที่ 16: Monte Carlo Simulation — "จำลองอนาคต 10,000 ครั้ง"

อุปมา: บริษัทประกันชีวิตกับนักสถิติ

บริษัทประกันไม่รู้ว่าคุณจะตายปีไหน แต่รู้ว่า "ถ้ามีลูกค้า 100,000 คน คนอายุ 40 ปีเฉลี่ยจะตายเมื่ออายุ 75"

Monte Carlo คิดแบบเดียวกัน: ไม่รู้ว่าหุ้นจะขึ้นหรือลง แต่รู้ว่า "ถ้าจำลอง 100,000 paths ตาม GBM จะได้ payoff เฉลี่ยเท่าไหร่"

Law of Large Numbers รับรอง: ยิ่งจำลองมาก ค่าเฉลี่ยยิ่งใกล้ค่าจริง

เมื่อไม่มีสูตร closed-form (exotic options, complex strategies) → จำลองราคาหุ้นหลายๆ ครั้ง แล้วเฉลี่ย

16.1 แนวคิดและสูตร Monte Carlo

1. สุ่ม \(Z \sim \mathcal{N}(0,1)\) จำนวน \(N\) ครั้ง

2. \(S_T = S_0\exp\!\left[(r-\tfrac{\sigma^2}{2})T + \sigma\sqrt{T}\,Z\right]\)

3. \(\text{Payoff}_i = \max(0,\,S_T^{(i)}-K)\)

4. \(C = e^{-rT}\,\overline{\text{Payoff}}\)

ทำไมสูตร S(T) ถึงเขียนแบบนี้?

จากบท 14: d(lnS) = (μ−σ²/2)dt + σdW (Ito's result)

Integrate ตั้งแต่ 0 ถึง T: ln(S(T)/S₀) = (μ−σ²/2)T + σ√T × Z

Exponentiate: S(T) = S₀ × exp((μ−σ²/2)T + σ√T × Z)

ในโลก risk-neutral: μ = r → ใช้ r แทน μ ใน simulation!

1MC ตัวอย่าง: S=100, K=100, r=5%, σ=25%, T=1ปี

2สุ่ม Z₁=1.2, Z₂=-0.5, Z₃=0.8 (3 paths ตัวอย่าง)

3(r−σ²/2)T = (0.05−0.03125)×1 = 0.01875,   σ√T = 0.25

4Path 1: S(1) = 100×exp(0.01875 + 0.25×1.2) = 100×exp(0.3188) = 100×1.375 = ฿137.5

5Path 2: S(1) = 100×exp(0.01875 + 0.25×(−0.5)) = 100×exp(−0.1063) = 100×0.899 = ฿89.9

6Path 3: S(1) = 100×exp(0.01875 + 0.25×0.8) = 100×exp(0.2188) = 100×1.245 = ฿124.5

7Payoffs: max(37.5,0)=37.5, max(-10.1,0)=0, max(24.5,0)=24.5

8Average = (37.5+0+24.5)/3 = 20.67, discount: 20.67×e⁻⁰·⁰⁵ = ฿19.65 (แค่ 3 paths — ต้องการมากกว่านี้!)

9ทำซ้ำ 100,000 paths → average → BS price ≈ ฿12.34

⚠️ ทำไม 3-path ตัวอย่างให้ ฿19.65 สูงกว่าค่าจริง ฿12.34?

Z ที่สุ่มมา (1.2, −0.5, 0.8) มีค่าเฉลี่ย = +0.5 ซึ่ง เอนขึ้น — ตามทฤษฎี Z ควรมีค่าเฉลี่ย ≈ 0 เมื่อ sample เยอะพอ ด้วย path น้อย ค่าเฉลี่ย sample เพี้ยนจาก 0 ได้มาก ทำให้ราคาประเมินเพี้ยน นี่คือเหตุผลที่ต้องใช้ paths เยอะ (standard error ลดลงตาม 1/√N)

Monte Carlo GBM paths — each run gives different S(T); average = option price

16.3 Exotic Options — ที่ BS แก้ไม่ได้

อุปมา: ประกันที่จ่ายตามค่าเฉลี่ยความเสียหาย ไม่ใช่ความเสียหายสุดท้าย

Vanilla Call: Payoff = max(0, S(T)−K) → ขึ้นกับแค่ราคาวันสุดท้าย

Asian Option: Payoff = max(0, avg(S)−K) → ขึ้นกับราคา เฉลี่ยตลอดทาง

Barrier Option: หมดค่าถ้าราคาแตะ "รั้ว" → ขึ้นกับ เส้นทางทั้งหมด

BS ไม่รู้เรื่อง "เส้นทาง" — แค่รู้จุดเริ่มและจุดจบ → ต้องใช้ MC ที่ simulate ทุก step

Exotic OptionPayoffทำไมต้อง MC?
Asian Optionmax(0, avg(S) - K)Payoff ขึ้นกับราคาเฉลี่ยตลอดทาง
Barrier Optionหมดค่าถ้าราคาแตะ barrierขึ้นกับเส้นทางทั้งหมด

1Asian Call MC: S=100, K=100, σ=25%, r=5%, T=1ปี, 12 monthly steps

2สุ่ม Z ทั้งหมด 12 ค่า ต่อ 1 path: Z = [-0.3, 0.5, 1.1, -0.8, 0.2, ...]

3คำนวณ S(t) ทุกเดือน: S(1)=100×exp(...), S(2)=S(1)×exp(...), ...

4avg(S) = (S(1)+S(2)+...+S(12))/12 = สมมติ ฿108.5

5Payoff = max(108.5−100, 0) = ฿8.5

6ทำซ้ำ 100,000 paths → เฉลี่ย payoff → discount → Asian price

7Asian price < Vanilla price เพราะ avg(S) ผันผวนน้อยกว่า S(T) เดี่ยวๆ

ทุก option price ได้ด้วย MC เพียงแค่:

1. จำลอง price paths (อาจต้องหลายสินทรัพย์, หลายช่วงเวลา)
2. คำนวณ payoff ตาม definition ของ exotic option นั้นๆ
3. เฉลี่ย แล้ว discount กลับ
ไม่ต้องมีสูตร closed-form — นี่คือพลังของ Monte Carlo!

16.4 Variance Reduction

อุปมา: แบ่งการสำรวจ ไม่ใช่แค่สุ่มทั้งหมด

ถ้าต้องสำรวจความคิดเห็น 100 คน จาก 4 กลุ่ม — สุ่มสัมภาษณ์ 100 คน อาจได้กลุ่มหนึ่งมากเกินไป

Stratified sampling: สำรวจ 25 คน จากแต่ละกลุ่ม → แม่นกว่า ใช้คนเท่ากัน

Antithetic Variates เป็นแนวคิดเดียวกัน: สุ่ม Z แล้วใช้ -Z ด้วย → ครอบทั้ง "ขาขึ้น" และ "ขาลง" ในคู่เดียว

ทำให้ MC แม่นขึ้นโดยไม่ต้องเพิ่ม paths:

เทคนิควิธีการผลลัพธ์
Antithetic Variatesถ้าสุ่ม Z → ใช้ -Z ด้วย (คู่สมมาตร)ลด variance ~50% ฟรี!
Control Variatesใช้ option ที่มี closed-form เป็น "ตัวควบคุม"ลด error มาก

16.4b Standard Error — วัดความแม่นของ MC

อุปมา: โพลสำรวจที่มี "ค่าความคลาดเคลื่อน ±3%"

MC ให้ราคาประมาณ — แต่ ประมาณแค่ไหน? เหมือนโพลที่บอก "45% ± 3%" เราต้องรู้ความคลาดเคลื่อนถึงจะใช้ตัวเลขได้

Standard Error (SE) คือ "ค่า ± " ของ MC: มันบอกว่าค่าเฉลี่ยที่ได้น่าจะห่างจากค่าจริงเท่าไหร่

สูตร SE และตัวอย่างคำนวณ
$$ SE = \frac{\sigma_\text{payoff}}{\sqrt{N}} $$

σpayoff = ส่วนเบี่ยงเบนมาตรฐานของ payoff ข้าม paths, N = จำนวน paths

1สมมติ std ของ payoff = ฿15, N = 10,000

2SE = 15 / √10,000 = 15 / 100 = ฿0.15

395% CI = estimate ± 1.96 × SE = estimate ± 1.96×0.15 = ± ฿0.29

4อยากให้ SE ลดครึ่ง (฿0.15 → ฿0.075)? ต้องใช้ paths เพิ่ม 4× (40,000) — เพราะ SE ∝ 1/√N

16.4c Antithetic Variates — สุ่ม Z แล้วใช้ −Z

วิธีการและตัวอย่าง

สำหรับทุก Z ที่สุ่มมา ให้ใช้ −Z สร้างอีก path หนึ่งด้วย → สองเส้นทางนี้ สหสัมพันธ์เป็นลบ (ตัวหนึ่งขึ้น อีกตัวลง) ค่าเฉลี่ยของคู่จึงผันผวนน้อยลง

1สุ่ม Z = +1.2 → S₊ = 100×exp(0.01875 + 0.25×1.2) = ฿137.5 → payoff = ฿37.5

2ใช้คู่ −Z = −1.2 → S₋ = 100×exp(0.01875 + 0.25×(−1.2)) = 100×exp(−0.281) = ฿75.5 → payoff = ฿0

3ค่าเฉลี่ยของคู่ = (37.5 + 0)/2 = ฿18.75 — เมื่อ path หนึ่งสุดโต่งขึ้น อีก path ดึงกลับลง → ค่าเฉลี่ยเสถียรกว่าการสุ่มอิสระสองครั้ง

4ผลทั่วไป: ลด variance ได้ราว ~50% ฟรี โดยไม่ต้องเพิ่มจำนวนการสุ่ม Z

16.4d Control Variates — ยืมราคาที่รู้แน่ มาแก้ค่าที่ไม่รู้

ใช้ option ที่รู้ราคาแน่ ๆ มาแก้ MC ของ option ที่ยาก

สมมติเราอยาก price Asian option (ไม่มี closed-form) แต่ vanilla option เรารู้ราคาจริงจาก BS แน่นอน → เอามาช่วยแก้ค่า:

$$ Y^* = Y_\text{Asian,MC} - \beta\,(Y_\text{Vanilla,MC} - Y_\text{Vanilla,BS}) $$

พจน์ในวงเล็บ (Yvanilla,MC − Yvanilla,BS exact) คือ ความผิดพลาดของ MC บน vanilla — และเรารู้มันเป๊ะ เพราะรู้ราคา BS จริง

ถ้า MC รอบนี้ประเมิน vanilla สูงไป → มันก็มักประเมิน Asian สูงไปด้วย (สหสัมพันธ์กัน) → เราจึง ลบ error นั้นทิ้ง ออกจากค่า Asian

β คือสัมประสิทธิ์ที่ปรับให้เหมาะ (มักได้จาก regression ของ Y_asian กับ Y_vanilla) → ลด variance ได้ถึง 80–90% เมื่อสองตัวสหสัมพันธ์สูง

ระวัง: variance reduction หด "ค่าคงที่" ไม่ใช่ "อัตรา"

การ converge ของ MC ยังคงเป็น 1/√N เสมอ — เทคนิคพวกนี้ทำให้ค่าคงที่ข้างหน้า (σpayoff) เล็กลง ไม่ได้เปลี่ยนเลขชี้กำลัง

ดังนั้นถ้าอยากแม่นขึ้น 10× คุณยังต้องใช้ paths เพิ่ม 100× อยู่ดี — เว้นแต่จะลด variance ลงด้วยเทคนิคข้างต้น (ซึ่งแค่ขยับเส้นกราฟลง ไม่ได้ทำให้มันชันขึ้น)

โจทย์: Standard Error และ Confidence Interval

MC ประเมินราคา Call ได้ ฿12.34 จาก N = 40,000 paths โดยมี std ของ payoff = ฿18
(ก) คำนวณ SE (ข) หา 95% CI (ค) ถ้าอยากให้ SE = ฿0.045 ต้องใช้กี่ paths?

ดูเฉลย

(ก) SE = σpayoff/√N = 18/√40,000 = 18/200 = ฿0.09

(ข) 95% CI = 12.34 ± 1.96×0.09 = 12.34 ± 0.176 → [฿12.16, ฿12.52]

(ค) ต้องการ SE ลดครึ่ง (0.09 → 0.045) → ลด SE ลง 2× ต้องเพิ่ม paths 2² = 4× → N = 40,000×4 = 160,000 paths

(ตรวจ: 18/√160,000 = 18/400 = 0.045 ✓)

โจทย์ 1: คำนวณ BS Call ด้วยมือ

กำหนด S=100, K=105, r=4%, σ=20%, T=0.5ปี
d₁ = [ln(100/105) + (0.04+0.02)×0.5] / (0.2×√0.5) = ?
คำนวณ d₁, d₂, แล้วหา C โดยใช้ N(-0.13)≈0.448, N(-0.28)≈0.390

ดูเฉลย

ln(100/105) = ln(0.952) ≈ -0.049

σ√T = 0.2×√0.5 = 0.2×0.707 = 0.1414

numerator = -0.049 + (0.04+0.02)×0.5 = -0.049 + 0.03 = -0.019

d₁ = -0.019 / 0.1414 = -0.134 ≈ -0.13

d₂ = -0.134 − 0.1414 = -0.275 ≈ -0.28

N(d₁) = N(-0.13) ≈ 0.448, N(d₂) = N(-0.28) ≈ 0.390

Ke⁻ʳᵀ = 105×e⁻⁰·⁰²= 105×0.980 = 102.9

C = 100×0.448 − 102.9×0.390 = 44.8 − 40.1 = ฿4.7

โจทย์ 3: Volatility Smile — BS ตีความอะไร?

สังเกตว่า IV ของ Options บน SET50 เป็นดังนี้:

Strike (K)9095100105110
IV (%)35%30%25%28%32%

ถ้า BS ถูกต้อง IV ควรเป็นเท่าไหร่? Pattern นี้บอกว่าตลาดกลัวอะไร?

ดูเฉลย

ถ้า BS ถูกต้อง: IV ควรเท่ากันทุก Strike = 25% (flat)

Pattern จริง: IV สูงขึ้นทั้งสองฝั่งจาก ATM (K=100) — เป็น "รูปยิ้ม" (Smile)

IV(K=90) สูงกว่า IV(K=110): ตลาดกลัว downside มากกว่า upside → Skew

ความหมาย: ตลาดเชื่อว่า fat left tail มีมากกว่าที่ Normal distribution คาด (crash risk)

สำหรับ Trader: OTM Put แพงกว่า BS เสมอ → ขาย OTM Put ด้วย BS price มักได้กำไรจาก "Skew premium"
