บทที่ 7: แคลคูลัส — "ภาษาของ Greeks"

Greeks ทุกตัวคือ อนุพันธ์ (derivatives) ของราคา Option — ถ้าไม่รู้จักแคลคูลัส ก็ไม่เข้าใจว่า Delta, Gamma, Theta, Vega มาจากไหน บทนี้อธิบาย intuition ก่อนสูตร

7.1 Limit — แนวคิด "เข้าใกล้"

🔍 อุปมา: วิ่งเข้าหากำแพงครึ่งนึงทุกครั้ง

สมมติวิ่งเข้าหากำแพงที่ระยะ 1 เมตร
ก้าวแรก: วิ่ง 0.5 เมตร → เหลือ 0.5 เมตร
ก้าวที่ 2: วิ่งอีก 0.25 เมตร → เหลือ 0.25 เมตร
ก้าวที่ 3: วิ่งอีก 0.125 เมตร → เหลือ 0.125 เมตร...

วิ่งไปกี่ก้าวก็ไม่ถึงกำแพง แต่ เข้าใกล้ 1 เมตรมากขึ้นเรื่อยๆ — นี่คือ Limit!
lim = "ค่าที่เข้าใกล้ แต่ไม่จำเป็นต้องถึง"

$$ \lim_{x \to a} f(x) = L $$
ตัวอย่าง: lim(h→0) [f(x+h) − f(x)] / h

นี่คือ "อัตราการเปลี่ยนแปลง ถ้า h เล็กมากๆ" → นิยามของ Derivative!
เมื่อ h เข้าใกล้ 0 (แต่ไม่ถึง 0) → ค่า limit คืออัตราการเปลี่ยนแปลง ณ จุดนั้น

เชื่อมกับ Options — Delta ใช้แนวคิด Limit

Delta = "ถ้าราคาหุ้นเปลี่ยน ΔS นิดเดียว ราคา Option เปลี่ยน ΔV เท่าไหร่"
Delta = lim(ΔS→0) ΔV/ΔS = อัตราการเปลี่ยนแปลงทันที ไม่ใช่ค่าเฉลี่ย

7.2 Derivative — อัตราการเปลี่ยนแปลงทันที

🔍 อุปมา: มาตรวัดความเร็วรถ

คุณขับรถจาก กทม. → เชียงใหม่ 700 กม. ใน 7 ชั่วโมง
ความเร็วเฉลี่ย = 700/7 = 100 กม./ชม. (คล้าย slope ของเส้นตรง)
มาตรวัดความเร็ว บอกความเร็ว "ตอนนี้" = 120 กม./ชม. (= Derivative ณ จุดนั้น)

Derivative = "ความเร็วทันที" ไม่ใช่ความเร็วเฉลี่ย
Delta = "อัตราการเปลี่ยน Option ตอนนี้" ณ ราคาหุ้นปัจจุบัน

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

(slope ของเส้นสัมผัส)

🔍 ทำไม Power Rule: d/dx(xⁿ) = nxⁿ⁻¹?

ลองแทน f(x) = x²:
f'(x) = lim(h→0) [(x+h)² − x²] / h
= lim(h→0) [x² + 2xh + h² − x²] / h
= lim(h→0) [2xh + h²] / h
= lim(h→0) [2x + h] = 2x ✓ (= nxⁿ⁻¹ เมื่อ n=2)

f(x)f'(x)ทำไม?
xⁿnxⁿ⁻¹Power Rule (พิสูจน์ข้างต้น)
c (ค่าคงที่)0ไม่เปลี่ยนแปลง → slope = 0
c × f(x)c × f'(x)scale ทั้งกราฟ → slope ×c ด้วย
f(x) + g(x)f'(x) + g'(x)slope รวม = slope แต่ละส่วนรวมกัน
eˣeˣ← อนุพันธ์ของตัวเอง! (special property)
ln(x)1/xย้อนกลับจาก d/dx(eˣ)=eˣ
f'(x) = instantaneous slope of tangent line at x
เชื่อมกับ Options — Delta!

Delta (Δ) = ∂V/∂S = derivative ของราคา Option เทียบกับราคาหุ้น
= slope ของ payoff curve ณ จุดนั้น
ATM Call: Delta ≈ 0.5 → ราคาหุ้นขึ้น ฿1 → Option ราคาขึ้น ≈ ฿0.50

7.3 อนุพันธ์ของ eˣ — ทำไม e สำคัญที่สุด

🔍 อุปมา: แบคทีเรียที่โตตามขนาดตัวเอง

แบคทีเรีย 1,000 ตัว แบ่งตัวในอัตรา 10%/ชม. ต่อ "ตัวเอง"
ถ้ามี 1,000 ตัว → โตชั่วโมงนี้: 100 ตัว
ถ้ามี 5,000 ตัว → โตชั่วโมงนี้: 500 ตัว

"อัตราการเปลี่ยนแปลง = สัดส่วนของจำนวนปัจจุบัน"
นี่คือสมบัติ unique ของ eˣ: f'(x) = f(x) → derivative = ตัวเอง!

$$ \frac{d}{dx}(e^x) = e^x \qquad \frac{d}{dx}(e^{ax}) = a\,e^{ax} \qquad \frac{d}{dx}(e^{-rT}) = -r\,e^{-rT} $$
🔍 ทำไม d/dx(eˣ) = eˣ?

ใช้นิยาม limit:
d/dx(eˣ) = lim(h→0) [eˣ⁺ʰ − eˣ] / h
= lim(h→0) eˣ × [eʰ − 1] / h
= eˣ × lim(h→0) [(eʰ − 1) / h]
พิสูจน์ได้ว่า lim(h→0) (eʰ − 1)/h = 1 → d/dx(eˣ) = eˣ × 1 = eˣ ✓

7.4 Chain Rule — กฎลูกโซ่

🔍 อุปมา: แปลงสกุลเงินหลายขั้น

ถ้าอัตราแลกเปลี่ยน: 1 ดอลลาร์ = 36 บาท (rate = 36 บาท/ดอลลาร์)
และ: 1 บาท = 4 เยน (rate = 4 เยน/บาท)
แล้ว: 1 ดอลลาร์ = 36 × 4 = 144 เยน (rate = 144 เยน/ดอลลาร์)

Chain Rule คูณ "อัตรา" (rate) ของแต่ละขั้น ไม่ใช่คูณเปอร์เซ็นต์ — ถ้าดอลลาร์แข็งขึ้น dollar 1 หน่วย ทำให้บาทขยับ 36 หน่วย และบาท 1 หน่วยทำให้เยนขยับ 4 หน่วย → ดอลลาร์ขยับ 1 หน่วยทำให้เยนขยับ 36×4 หน่วย
Chain Rule: "อัตราการเปลี่ยนแปลงสุดท้าย = ผลคูณของอัตรา (slope) แต่ละขั้น"

$$y = f(g(x)) \quad\Longrightarrow\quad \frac{dy}{dx} = f'(g(x)) \cdot g'(x)$$
ตัวอย่าง: หา dy/dT ของ y = e⁻ʳᵀ (Discount Factor)
1กำหนด u = −rT → y = eᵘ
2dy/du = eᵘ (derivative ของ eᵘ)
3du/dT = −r (derivative ของ −rT เทียบ T)
4Chain Rule: dy/dT = eᵘ × (−r) = −r × e⁻ʳᵀ

แปลว่า: discount factor ลดลงเร็วแค่ไหน? → −r × (ค่า discount ปัจจุบัน)

เปลี่ยน T → เปลี่ยน u=−rT → เปลี่ยน u → เปลี่ยน eᵘ → รวม: dy/dT = −r·e⁻ʳᵀ
เชื่อมกับ Options — Theta!

Theta = −∂C/∂T = "Option ราคาลดลงเท่าไหร่ต่อวัน" (time decay) โดย T = เวลาที่เหลือก่อน expire
ใน BS: Theta ใช้ Chain Rule ผ่าน d₁, d₂ ที่เป็น function ของ t
Chain Rule ยังเป็นพื้นฐานของ Ito's Lemma ที่ใช้ derive Black-Scholes

7.5 Product Rule & Quotient Rule — กฎผลคูณ-ผลหาร

🔍 อุปมา: พื้นที่สี่เหลี่ยมที่ทั้งกว้างและยาวเปลี่ยนพร้อมกัน

สี่เหลี่ยมผืนผ้ามีด้านกว้าง u และด้านยาว v → พื้นที่ = u·v
ถ้าทั้งสองด้าน "ขยาย" พร้อมกันนิดเดียว พื้นที่เพิ่มจาก 2 ส่วน:
• ด้านกว้างขยาย (u') × ความยาวเดิม (v) → แถบเพิ่มด้านบน = u'·v
• ด้านยาวขยาย (v') × ความกว้างเดิม (u) → แถบเพิ่มด้านข้าง = u·v'

(มุมเล็กๆ ที่ขยายทั้ง 2 ด้าน u'·v' เล็กจนทิ้งได้เมื่อ Δ→0)
(uv)' = u'v + uv' — "เปลี่ยนตัวแรกค้างตัวหลัง บวก เปลี่ยนตัวหลังค้างตัวแรก"

$$(u \cdot v)' = u'v + uv' \qquad \left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}$$
ตัวอย่าง: หา d/dS ของ S·N(d₁) (พจน์แรกของสูตร Black-Scholes Call)

เทอม S·N(d₁) เป็น "ผลคูณ" ของ u = S และ v = N(d₁) — ต้องใช้ Product Rule!

1u = S → u' = du/dS = 1
2v = N(d₁) → v' = dv/dS = N'(d₁)·(∂d₁/∂S) (Chain Rule! เพราะ d₁ เป็น function ของ S)
3Product Rule: d/dS[S·N(d₁)] = u'v + uv' = N(d₁) + S·N'(d₁)·(∂d₁/∂S)

นี่คือเหตุผลที่การ differentiate สูตร Black-Scholes ต้องใช้ Product Rule — ราคา Call มีเทอม S·N(d₁) ที่ทั้ง S และ N(d₁) เปลี่ยนตาม S พร้อมกัน

เชื่อมกับ Options — พจน์ S·N'(d₁) ที่ "หายไป" อย่างมหัศจรรย์

เมื่อ differentiate สูตร Call ครบทุกเทอม จะได้เทอม S·N'(d₁)·(∂d₁/∂S) โผล่มา
แต่เทอมนี้ หักล้าง (cancel) กับเทอมที่มาจาก K·e⁻ʳᵀ·N(d₂) พอดี
ทำให้ผลลัพธ์เหลือเพียง Delta = N(d₁) เกลี้ยงสวยงาม (ดูรายละเอียดใน §7.7)

7.6 Partial Derivatives — Greeks ทุกตัว

🔍 อุปมา: ความสุขขึ้นกับหลายปัจจัย

สมมติความสุข H = f(ห้องอุณหภูมิ T, เพลง V, แสง L)
"ถ้าอยากรู้ว่าอุณหภูมิมีผลแค่ไหน" → เปิดแอร์ แต่ค้างเพลงและแสงไว้ → วัด ∂H/∂T

Partial Derivative = "เปลี่ยนตัวแปรเดียว ค้างตัวอื่น" = Greeks ทุกตัว!

$$ \frac{\partial f}{\partial x} : \text{ ถือ } y \text{ คงที่ แล้ว differentiate เทียบ } x $$
ตัวอย่าง: f(x, y) = x²y + 3xy
∂/∂xtreat y เป็นคงที่: ∂f/∂x = 2xy + 3y
∂/∂ytreat x เป็นคงที่: ∂f/∂y = x² + 3x

ราคา Option V ขึ้นกับหลายตัวแปร: V(S, t, σ, r)

Greekสูตรความหมายเปลี่ยนอะไร ค้างอะไร
Δ Delta∂V/∂SOption เปลี่ยนเท่าไหร่ต่อหุ้นขยับ ฿1เปลี่ยน S, ค้าง t,σ,r
Θ Theta−∂C/∂TOption เปลี่ยนเท่าไหร่ต่อวัน (T = time to expiry)เปลี่ยน T, ค้าง S,σ,r
ν Vega∂V/∂σOption เปลี่ยนเท่าไหร่ต่อ σ เพิ่ม 1%เปลี่ยน σ, ค้าง S,t,r
ρ Rho∂V/∂rOption เปลี่ยนเท่าไหร่ต่อดอกเบี้ยเพิ่ม 1%เปลี่ยน r, ค้าง S,t,σ
เชื่อมกับ Options — เข้าใจ Greeks ทุกตัวแล้ว!

Greeks ทุกตัวคือ "อัตราการเปลี่ยนแปลงของราคา Option เมื่อปรับตัวแปรทีละตัว"
ไม่ใช่ตัวเลขลอยๆ — แต่ล้วนมาจาก partial derivative ของสูตร Black-Scholes

7.7 Partial Derivative บนสูตร Black-Scholes จริง — The Real Greeks

🔍 อุปมา: เปิดฝากล่อง Black-Scholes ดูว่า Delta มาจากไหนจริงๆ

หนังสือส่วนใหญ่บอกแค่ "Delta = N(d₁)" แล้วจบ — แต่ไม่บอกว่า ทำไม
สูตร Call มีตั้ง 2 เทอม (S·N(d₁) และ K·e⁻ʳᵀ·N(d₂)) ทั้งคู่ขึ้นกับ S
ตอน differentiate ควรได้เทอมยุ่งๆ เต็มไปหมด — แต่กลับเหลือแค่ N(d₁) เกลี้ยง
ความ "มหัศจรรย์" นี้คือการหักล้างของพจน์ ที่เราจะเปิดให้ดูในหัวข้อนี้

$$C = S\,N(d_1) - K e^{-rT} N(d_2)$$
$$\Delta = \frac{\partial C}{\partial S} = N(d_1)$$

← เหลือเท่านี้เท่านั้น!

เหตุ → ผล: ทำไม ∂C/∂S = N(d₁) เกลี้ยงๆ

differentiate ทั้ง 2 เทอมเทียบ S (ใช้ Product Rule + Chain Rule จาก §7.5):

1เทอม 1: ∂/∂S[S·N(d₁)] = N(d₁) + S·N'(d₁)·(∂d₁/∂S)
2เทอม 2: ∂/∂S[−K·e⁻ʳᵀ·N(d₂)] = −K·e⁻ʳᵀ·N'(d₂)·(∂d₂/∂S)
3เพราะ d₂ = d₁ − σ√T → ∂d₂/∂S = ∂d₁/∂S (ต่างกันแค่ค่าคงที่)
4พิสูจน์ได้ว่า S·N'(d₁) = K·e⁻ʳᵀ·N'(d₂) พอดี (เอกลักษณ์ของ lognormal)
5ดังนั้น 2 พจน์ที่มี N' เท่ากันและตรงข้าม → หักล้างกันหมด!

เหลือเพียง ∂C/∂S = N(d₁) — นี่คือ "ความมหัศจรรย์" ที่หนังสือส่วนใหญ่ข้ามไป

ตัวอย่างตัวเลขจริง: คำนวณ Delta ของ Call ATM

กำหนด S=100, K=100, r=5%, σ=25%, T=1 ปี

1d₁ = [ln(S/K) + (r + σ²/2)·T] / (σ√T) = [ln(1) + (0.05 + 0.03125)·1] / (0.25·1) = 0.08125 / 0.25 = 0.325
2Delta = N(d₁) = N(0.325) ≈ 0.627
3ตีความ: หุ้นขยับขึ้น ฿1 (จาก ฿100 → ฿101) → ราคา Option ขยับขึ้น ≈ ฿0.627

Delta = 0.627 > 0.5 เพราะ drift (r + σ²/2) ดันให้ Call ATM เอนไปทาง ITM เล็กน้อย

Greeks ตัวอื่น = partial derivative ตัวอื่นของสูตรเดียวกัน

เมื่อเข้าใจว่า Delta = ∂C/∂S แล้ว Greeks ที่เหลือก็คือ partial derivative คนละตัว:
• Gamma = ∂²C/∂S² = ∂(Delta)/∂S = N'(d₁)/(S·σ√T) — ความโค้ง (ดู §7.8)
• Vega = ∂C/∂σ = S·N'(d₁)·√T — ไวต่อความผันผวน
• Theta = −∂C/∂T (เครื่องหมายลบ เพราะเวลาเหลือน้อยลง) — time decay
• Rho = ∂C/∂r = K·T·e⁻ʳᵀ·N(d₂) — ไวต่อดอกเบี้ย

โจทย์ฝึก §7.7

Call: S=50, K=50, r=4%, σ=20%, T=1 ปี

(ก) คำนวณ d₁   (ข) หา Delta = N(d₁) เมื่อกำหนด N(0.3)≈0.618   (ค) ถ้าหุ้นขยับ +฿1 ราคา Option ขยับประมาณเท่าไหร่?

ดูเฉลย
(ก) d₁ = [ln(50/50) + (0.04 + 0.02)·1] / (0.20·1) = (0 + 0.06)/0.20 = 0.30
(ข) Delta = N(0.30) ≈ 0.618
(ค) หุ้น +฿1 → Option ≈ +฿0.618 (≈ Delta × ΔS)
Quant Desk: Delta Hedging — ปรับพอร์ต ทุก ΔS ที่มีนัยสำคัญ

Market maker ที่ขาย options มักทำ delta-neutral hedging ทุกวัน:
• Short 1 Call (Delta = −0.6) → ซื้อหุ้น 0.6 หุ้น → net delta = 0
• เมื่อหุ้นขยับ delta เปลี่ยน → ต้อง rebalance → Gamma ≠ 0 ทำให้ต้อง rebalance บ่อย
• ผู้ขาย option เป็น short gamma, long theta: เก็บ Theta ทุกวัน (รายได้) แต่เสียเงินจากการ rebalance ทุกครั้งที่ตลาดขยับแรง (ซื้อแพง-ขายถูกเสมอเมื่อ short gamma)
กำไรของ market maker ≈ Theta ที่เก็บได้ − Gamma losses → ทำงานได้เมื่อ realized vol < IV ที่ขายไว้ (ฝั่งตรงข้าม: ผู้ซื้อ option ที่เป็น long gamma จะกำไรเมื่อ realized vol > IV)

7.8 อนุพันธ์อันดับสอง — Gamma

🔍 อุปมา: ความโค้งของถนน

ขับรถบนถนนตรง: Slope = ทิศทาง, Gamma = ความโค้ง
ถนนตรง: slope คงที่, Gamma = 0 (ไม่โค้ง)
ถนนเลี้ยว: slope เปลี่ยนตลอด, Gamma > 0 (โค้ง)

Gamma ของ Option = ความโค้งของ payoff curve
Gamma สูง = เส้น payoff โค้งมาก = Delta เปลี่ยนเร็ว = ต้อง rehedge บ่อย

$$\Gamma = \frac{\partial^2 V}{\partial S^2} = \frac{\partial(\Delta)}{\partial S}$$

"Delta เปลี่ยนเท่าไหร่ เมื่อราคาหุ้นเปลี่ยน ฿1"

🔍 ทำไมต้อง differentiate 2 ครั้ง?

Delta = f'(S) = slope ณ จุดนั้น
Gamma = f''(S) = slope ของ slope = "Delta เปลี่ยนเร็วแค่ไหน"

ตัวอย่าง: f(x) = x³
f'(x) = 3x² (slope)
f''(x) = 6x (slope เปลี่ยนเร็วแค่ไหน ณ x นั้น)

Gamma = curvature of option value curve; always positive (convex)
ทำไม Gamma สำคัญสำหรับ Trader?

• Long Gamma (ซื้อ options): ได้ประโยชน์เมื่อตลาดเคลื่อนไหวมาก — "กำไรจาก vol"
• Short Gamma (ขาย options): เสียเมื่อตลาดเคลื่อนไหวมาก — ต้อง rehedge ตลอด
• Gamma สูงสุดที่ ATM: Options ATM โค้งมากที่สุด = ไวต่อการเคลื่อนไหวของราคา

7.9 Integration — พื้นที่ใต้กราฟ

🔍 อุปมา: คิดระยะทางจากความเร็ว

ขับรถที่ 100 กม./ชม. เป็นเวลา 2 ชั่วโมง → ระยะทาง = 100 × 2 = 200 กม.
"ระยะทาง = พื้นที่ใต้กราฟ velocity vs time"

Integration คือการ "ย้อนกลับ" ของ derivative:
ถ้า derivative วัด "เปลี่ยนเร็วแค่ไหน" → integral สะสม "เปลี่ยนไปเท่าไหร่รวม"

$$ \int x^n\,dx = \frac{x^{n+1}}{n+1} + C \qquad \int e^x\,dx = e^x + C \qquad \int \frac{1}{x}\,dx = \ln|x| + C $$
🔍 ทำไม ∫xⁿ dx = xⁿ⁺¹/(n+1)?

เพราะเราต้องการ F(x) ที่ F'(x) = xⁿ
ลองดู: d/dx[xⁿ⁺¹/(n+1)] = (n+1)xⁿ/(n+1) = xⁿ ✓
→ Antiderivative ของ xⁿ คือ xⁿ⁺¹/(n+1) นั่นเอง

เชื่อมกับ Options

• N(d) = CDF ของ Normal = ∫ bell curve → พื้นที่ใต้กราฟทางซ้ายของ d
• E[X] = ∫ x × f(x) dx (expected value ของ continuous distribution)
• ราคา Option = ∫ payoff × probability density = E*[payoff] ที่ discount แล้ว

7.10 Integration หา Expected Payoff — ราคา Option = ∫ payoff × density

🔍 อุปมา: รวมพื้นที่ใต้กราฟ payoff×ความน่าจะเป็น = ราคายุติธรรม

ถ้าจะตั้งราคา "ลอตเตอรี่" ที่ยุติธรรม → คิดทุกผลลัพธ์ที่เป็นไปได้:
(เงินที่ได้ในผลลัพธ์นั้น) × (ความน่าจะเป็นของผลลัพธ์นั้น) แล้วรวมกันทุกผล

Option ก็เหมือนกัน: ราคายุติธรรม = รวม (payoff ของแต่ละราคาหุ้น) × (ความน่าจะเป็นที่หุ้นจบที่ราคานั้น)
"รวมทุกผลลัพธ์ต่อเนื่อง" = Integration → แล้ว discount กลับมาเป็นมูลค่าวันนี้

$$ C = e^{-rT} \int_0^\infty \max(0,\, S-K)\cdot f(S)\,dS $$

\(f(S)\) = risk-neutral lognormal density; \(\max(0,S-K)\) = payoff

7.11 Taylor Series — ประมาณค่าจาก Derivative

🔍 อุปมา: ประมาณค่าจากข้อมูลใกล้เคียง

คุณรู้ว่า ณ วันนี้ หุ้น ฿100, Delta=0.5, Gamma=0.03
ถ้าหุ้นขึ้นเป็น ฿102 (+฿2) → Option ราคาเปลี่ยนเท่าไหร่?

ประมาณ: ΔV ≈ 0.5 × 2 + ½ × 0.03 × 2² = 1.0 + 0.06 = +฿1.06
(ดีกว่าแค่ Delta × ΔS = +฿1.00 เพราะ Gamma ช่วย correct ความโค้ง)

$$ f(x+h) \approx f(x) + f'(x)\,h + \tfrac{1}{2}f''(x)\,h^2 $$
$$ \Delta V \approx \Delta \cdot \Delta S + \tfrac{1}{2}\,\Gamma\,(\Delta S)^2 $$
🔍 ทำไมสูตรถึงมีรูปแบบนี้?

term แรก f(x+h) ≈ f(x): ถ้า h = 0 → ไม่เปลี่ยน
+ f'(x)·h: การประมาณเชิงเส้น (slope × ระยะทาง)
+ ½f''(x)·h²: correction สำหรับความโค้ง (Gamma × ½ × ΔS²)

ยิ่งเพิ่ม term มาก ยิ่งแม่นขึ้น — แต่ 2 terms มักพอสำหรับ options risk

เชื่อมกับ Options — Delta-Gamma Approximation ใช้ทุกวัน!

ΔV ≈ Delta × ΔS + ½ × Gamma × (ΔS)²
ใช้ใน P&L estimation, risk limit checking, scenario analysis
ถ้า ΔS ใหญ่ (crash) → Gamma term สำคัญมาก! Short Gamma trader ระวัง

7.12 Multivariate Taylor & The Full Options P&L — สมการกำไร-ขาดทุนที่เทรดเดอร์ใช้จริง

🔍 อุปมา: ประมาณการเปลี่ยนแปลงราคา Option จากหลายปัจจัยพร้อมกัน

ใน §7.11 เราประมาณ ΔV จากการขยับของหุ้น (S) อย่างเดียว — แต่ในชีวิตจริง
ภายในวันเดียวกัน มีหลายอย่างเปลี่ยนพร้อมกัน: หุ้นขยับ, เวลาเดินไป 1 วัน, ความผันผวนเปลี่ยน

Multivariate Taylor คือการ "บวกผลจากทุกปัจจัยเข้าด้วยกัน" — แต่ละ Greek คือ slope ของแต่ละแกน
รวมทุก slope × ระยะที่ขยับ = ประมาณการเปลี่ยนแปลงราคา Option รวม

$$ \Delta V \approx \underbrace{\Delta \cdot \Delta S}_{\text{directional}} + \underbrace{\tfrac{1}{2}\Gamma(\Delta S)^2}_{\text{convexity}} + \underbrace{\Theta \cdot \Delta t}_{\text{time decay}} + \underbrace{\nu \cdot \Delta\sigma}_{\text{vol P\&L}} $$
แต่ละเทอมหมายถึงอะไร

• Delta·ΔS — กำไร/ขาดทุนจากทิศทาง (หุ้นขึ้น/ลง) = directional P&L
• ½·Gamma·(ΔS)² — กำไรจากความโค้ง = convexity / gamma P&L (เป็นบวกเสมอถ้า long gamma ไม่ว่าหุ้นขึ้นหรือลง)
• Theta·Δt — time decay = มูลค่าที่ลดตามเวลา (มักเป็นลบสำหรับคนถือ option)
• Vega·Δσ — กำไร/ขาดทุนเมื่อความผันผวน (vol) เปลี่ยน = vol P&L

ตัวอย่างตัวเลขจริง: แตก P&L 1 วันของ position

Position: Delta=0.5, Gamma=0.03, Theta=−0.05/วัน, Vega=0.12 (ต่อ 1 vol point = 1%)
เหตุการณ์ในวันนั้น: หุ้นขยับ ΔS=+฿2, เวลาเดิน Δt=1 วัน, vol เพิ่ม Δσ=+1 vol point

1Delta·ΔS = 0.5 × 2 = +฿1.00 (directional)
2½·Gamma·(ΔS)² = 0.5 × 0.03 × 2² = 0.5 × 0.03 × 4 = +฿0.06 (convexity/gamma)
3Theta·Δt = −0.05 × 1 = −฿0.05 (time decay)
4Vega·Δσ = 0.12 × 1 = +฿0.12 (Vega ใช้ convention "ต่อ 1 vol point" → vol +1% → คูณ 1)
5รวม: ΔV ≈ 1.00 + 0.06 − 0.05 + 0.12 = +฿1.13
Delta +฿1.00 + Gamma +฿0.06 + Theta −฿0.05 + Vega +฿0.12 = ΔV +฿1.13
เชื่อมกับ Options — นี่คือวิธี attribute P&L รายวันของเทรดเดอร์จริง

คำถาม "ทำไมวันนี้กำไร/ขาดทุน?" ตอบได้ด้วยการแยกเป็นรายปัจจัย:
• กำไรเพราะเดาทิศถูก (delta) หรือเพราะตลาดเหวี่ยงแรง (gamma)?
• ขาดทุนเพราะเวลาผ่านไป (theta) หรือเพราะ vol ตก (vega)?
การแตก P&L แบบนี้เรียกว่า P&L attribution / Greeks explain — ใช้ทุกวันบนโต๊ะเทรด

Model Risk: Taylor P&L ดีแค่ Small Move — ระวัง Gap/Jump

สมการ ΔV ≈ Δ·ΔS + ½Γ(ΔS)² + Θ·Δt + ν·Δσ ใช้ได้ดีเมื่อ ΔS เล็ก แต่:
• Gap opening: หุ้นเปิดตลาดต่าง −10% (หลังข่าวใหญ่กลางคืน) → Γ term underestimate P&L มาก
• Vol jump: Δσ +10 vol points ใน 1 วัน (ช่วง Lehman / COVID) → ν·Δσ อาจไม่เพียงพอ
• Cross-gamma (∂²V/∂S∂σ) ถูก neglect — เมื่อหุ้นตก vol มักพุ่งขึ้นพร้อมกัน ปฏิสัมพันธ์นี้ไม่อยู่ในสมการ
ใช้ full repricing (Monte Carlo หรือ binomial tree) เมื่อ ΔS > 2–3%

โจทย์ฝึก §7.12

Position: Delta=−0.4, Gamma=0.02, Theta=−0.03/วัน, Vega=0.10 (ต่อ 1 vol point)
ในวันนั้น: หุ้นขยับ ΔS=−฿3, Δt=1 วัน, vol ลด Δσ=−2 vol points
แตก ΔV เป็น 4 เทอม แล้วรวม

ดูเฉลย
Delta·ΔS = −0.4 × (−3) = +฿1.20
½·Gamma·(ΔS)² = 0.5 × 0.02 × (−3)² = 0.5 × 0.02 × 9 = +฿0.09
Theta·Δt = −0.03 × 1 = −฿0.03
Vega·Δσ = 0.10 × (−2) = −฿0.20
รวม: ΔV ≈ 1.20 + 0.09 − 0.03 − 0.20 = +฿1.06

✓ d/dx(eˣ) = eˣ ← อนุพันธ์ตัวเอง = ทำไม eˣ ปรากฏทุกที่ใน finance

✓ Partial Derivatives = Greeks ทุกตัว: Δ Θ ν ρ

✓ อนุพันธ์อันดับ 2 = Gamma = ความโค้ง → Long/Short Gamma

ข้อ 3. สูตร Black-Scholes Call: C = S·N(d₁) − K·e⁻ʳᵀ·N(d₂)
(ก) ∂C/∂S คืออะไร? (= Greek ตัวไหน)
(ข) ∂C/∂r มีค่าบวกหรือลบ? (= Greek ตัวไหน)
(ค) ∂C/∂T มีค่าบวกหรือลบ? (T = time to expiry — Greek ตัวไหน และทำไม?)

ดูเฉลย
(ก) ∂C/∂S = N(d₁) = Delta (≈ 0–1 สำหรับ Call)
(ข) ∂C/∂r > 0 → Rho บวก (ดอกเบี้ยสูง → K·e⁻ʳᵀ เล็กลง → Call แพงขึ้น)
(ค) ∂C/∂T > 0 (เวลาเหลือมาก → option มีค่ามาก) → Theta = −∂C/∂T < 0 → Theta ลบ (เมื่อเวลาผ่านไป T ลดลง → มูลค่าลด = time decay)
