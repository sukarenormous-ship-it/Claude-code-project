"เครื่องมือคัดคู่เป็นของฟรีที่ทุกคนมี — ความต่างอยู่ที่บ่อที่คุณสแกน และวินัยที่คุณคัดออก"

2.1 The Screening Funnel — ค่า cut-off ที่ใช้กันจริง

คู่ที่ "ควรเทรด" ต้องรอดผ่านหลายด่าน — นี่คือค่าที่พบบ่อยในงานวิจัยและงานจริง (ใช้เป็นจุดตั้งต้น ไม่ใช่กฎศักดิ์สิทธิ์)

ด่านค่าที่ใช้กันจริงทำไม / กับดัก
1. Correlation prescreenρ(log-returns) > 0.8ตัวกรองหยาบ ลดจำนวนคู่ · ใน S&P500 มีเพียง ~872 คู่ที่ > 0.8 · ไม่ใช่ข้อพิสูจน์ tradability
2. Engle-Granger ADFp < 0.05 (เข้ม: < 0.01)ทดสอบว่า residual (spread) stationary · แต่ single test บนหลายร้อยคู่ = false positive เพียบ (§2.3)
3. Hurst exponentH < 0.5 (ยิ่งต่ำยิ่ง revert)ยืนยันซ้ำว่า mean-revert จริง ไม่ใช่ ADF ผ่านโดยบังเอิญ
4. Half-life (OU)ใช้ได้ราว ~1–30 วันสั้นไป = churn ค่าคอมฯ · ยาวไป = ทุนถูกล็อก + คู่มีเวลาพัง (empirical เห็นตั้งแต่ <1 ถึง ~70 วัน)
5. Johansen (≥2 ขา)trace / max-eigen > criticalสำหรับ basket >2 ตัว (เล่ม 1 ไม่มี) · จัดการหลาย cointegrating vector พร้อมกัน
Half-life: spread เป็น OU → dX = θ(μ−X)dt + σdW
Half-life = ln(2) / θ ← "นานแค่ไหนกว่า spread กลับครึ่งทาง"

ประมาณ θ จาก: ΔX_t = a + b·X_{t−1} + e → θ ≈ −b → HL = ln(2)/(−b)
อ่านเป็น decision funnel ไม่ใช่ท่องค่า

ทุกคู่ต้องผ่าน หลายด่านพร้อมกัน — ADF ผ่าน และ Hurst < 0.5 และ half-life สมเหตุผล · ผ่านด่านเดียวไม่พอ เพราะแต่ละ test มีจุดบอดคนละแบบ การให้ยืนยันกันเองคือวิธีกัน false positive ที่ถูกที่สุด

2.2 "ทุกคนใช้เหมือนกัน แล้วต่างตรงไหน" — 5 จุด

funnel ข้างบนเป็นของสาธารณะ AI เขียนให้ได้ใน 5 นาที · ความต่างไม่ได้อยู่ที่ funnel — อยู่ที่ 5 อย่างนี้

จุดต่างทำอะไร
1. Universeสแกนบ่อที่คนอื่นไม่สแกน (small-cap · ไทย/SEA · crypto) — funnel เดิม แต่บ่อใหม่ ← จุดแข็งรายย่อย (ชั้น D)
2. Validation เข้มกว่าre-test cointegration แบบ out-of-sample (ไม่ fit ครั้งเดียวจบ) + รวมหลาย test กัน false positive
3. Parameter regimeจูน half-life band / cut-off ให้เข้ากับ cost ของตัวเอง ไม่ลอกค่าจาก paper (คนต้นทุนสูงต้อง half-life สั้นกว่า)
4. When-NOT-to-tradecoint p-value ลอย / half-life พุ่ง = ถอย (โยง Part VII kill-switch) ← ชั้น C
5. Dependence ต่างจากฝูงใช้ copula จับความสัมพันธ์/จังหวะที่ linear-cointegration ของฝูงพลาด (§2.4)

2.3 กับดักตัวจริง — ที่ทำให้ backtest สวยแต่ live พัง

📉 กับดัก 1 — In-sample cointegrate → out-of-sample พัง (อันดับ 1)

คู่ที่ cointegrate สวยในอดีตไม่การันตีว่าจะ cointegrate ต่อ — ความสัมพันธ์เสื่อมได้ (บริษัทเปลี่ยนธุรกิจ · ควบรวม · วิกฤตเฉพาะตัว) · ต้อง validate บนช่วงที่โมเดลไม่เคยเห็นเสมอ

📉 กับดัก 2 — Multiple testing (ร้ายกาจที่สุดตอนสแกนเยอะ)

สแกน 500 คู่ที่ระดับนัยสำคัญ α = 0.05 → คาดว่าจะเจอ "คู่ที่ผ่าน" ~25 คู่จากความบังเอิญล้วน ๆ ทั้งที่ไม่มีความสัมพันธ์จริง · ยิ่งสแกนเยอะ ยิ่งเจอผีเยอะ

คาดหวังจำนวน false positive ≈ (จำนวนคู่ที่ทดสอบ) × α
500 คู่ × 0.05 = 25 คู่ "ผ่าน" แบบมั่ว ๆ

ทางแก้: ปรับ threshold ด้วย Bonferroni / FDR หรือใช้ deflated Sharpe ที่หักจำนวนการทดสอบ (López de Prado) — โยง Part IX

📉 กับดัก 3 & 4 — Look-ahead + Regime dependence
  • Look-ahead ใน selection: เลือกคู่จากทั้ง sample แล้ว backtest บน sample เดิม = โกงตัวเอง (รู้อนาคตตอนเลือก)
  • Regime dependence: คู่ที่ coint ในตลาดขาขึ้น อาจพังในวิกฤต — cointegration ไม่ใช่คุณสมบัติถาวร
🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: "เจอคู่ที่ ADF p = 0.001 = เจอขุมทอง"
quant เห็น: ถ้าสแกนมาพันคู่ p = 0.001 อาจเป็นแค่ผีตัวหนึ่งใน 1000 — คำถามไม่ใช่ "p ต่ำแค่ไหน" แต่คือ "ฉันทดสอบมากี่ครั้งกว่าจะเจอมัน"

2.4 Copula สำหรับรายย่อย — จับสิ่งที่เส้นตรงมองไม่เห็น

correlation/cointegration เป็นเครื่องมือ เชิงเส้น — จับได้แค่ความสัมพันธ์แบบเฉลี่ย ๆ · copula แยก marginal (พฤติกรรมแต่ละตัว) ออกจาก dependence (โครงสร้างการเชื่อมโยง) → จับ non-linear + tail dependence ที่เส้นตรงพลาด และใช้ได้แม้ hedge ratio เชิงเส้นจะพัง

🚶 อ่านเป็นภาษาคนก่อน

ลองนึกว่า "หุ้น 2 ตัวนี้เชื่อมกันตอนไหน" — บางคู่เกาะกันแน่นเฉพาะตอนตลาดตก (แห่ขายพร้อมกัน) แต่ตอนปกติต่างคนต่างไป · correlation ตัวเดียวจับความต่างนี้ไม่ได้ แต่ copula จับได้ผ่าน "tail dependence"

CopulaTail dependenceใช้เมื่อ
Gaussian / Frankไม่มีเชื่อมกันปกติ ไม่มีหางพิเศษ
Student-t2 หาง สมมาตรเชื่อมแรงทั้งตอนขึ้น/ลง (คู่ในเซกเตอร์เดียว)
Claytonหางล่างเชื่อมแรงตอน ตลาดตก (crash together)
Gumbel / Joeหางบนเชื่อมแรงตอน ตลาดขึ้น
Signal: Mispricing Index (MI)

แทนที่จะใช้ z-score ของ spread → copula ให้ conditional probability: "ถ้า B อยู่ตรงนี้ ปกติ A ควรอยู่ตรงไหน"

MI = P(U ≤ u | V = v) − 0.5

MI > 0 → A แพงกว่าที่ควร (เทียบ B) → short A / long B
MI < 0 → A ถูกกว่าที่ควร → long A / short B
สะสม MI ข้าม threshold → เข้า/ออก

❌ Copula พังเมื่อไร (ต้องเตือน)
  • ต้อง fit marginal ให้ดีก่อน (ใช้ empirical CDF/ECDF) — marginal ผิด copula ผิดตาม
  • เลือก family มั่ว = overfit — อย่าลองทุก family แล้วเลือกอันที่ backtest สวยสุด
  • tail-dependence estimate ไม่นิ่งบนข้อมูลน้อย (หางมีจุดน้อยโดยธรรมชาติ)
  • ต้อง out-of-sample เสมอ

2.5 ขีดจำกัดของโลกทีละคู่ → สะพานสู่ Part III

สังเกตว่าทั้ง correlation · cointegration · copula — ทุกอย่างมอง ทีละคู่ · แต่ทำไมหุ้น 2 ตัวถึงเดินด้วยกันตั้งแต่แรก? ไม่ใช่เพราะมี "ความสัมพันธ์วิเศษ" เฉพาะคู่ — แต่เพราะมัน แชร์ common factor เดียวกัน (market · sector · style)

และนั่นเปิดคำถามที่พลิกทั้งเกม:

"ถ้า co-movement มาจาก factor ร่วม — ทำไมต้องนั่งเลือกคู่ทีละคู่? ทำไมไม่หัก factor ทิ้ง แล้วเทรดสิ่งที่เหลือทั้งกระดาน?"

นั่นคือ Part III — ที่ pairwise กลายเป็นแค่กรณีพิเศษ และ edge (กับความเสี่ยงที่ซ่อนอยู่) เปลี่ยนหน้าตาไปเลย

📖 ศัพท์ใหม่ในตอนนี้
  • Screening funnel — ลำดับด่านคัดคู่ (correlation → ADF → Hurst → half-life → Johansen)
  • Half-life — เวลาที่ spread กลับครึ่งทางสู่ค่าเฉลี่ย = ln(2)/θ
  • Hurst exponent — วัดว่าอนุกรม mean-revert (H<0.5) / random (0.5) / trending (>0.5)
  • Multiple testing — ยิ่งทดสอบเยอะ ยิ่งเจอ false positive จากความบังเอิญ
  • Copula — แยก marginal ออกจาก dependence; จับ tail dependence
  • Mispricing Index (MI) — สัญญาณจาก conditional probability ของ copula (= P − 0.5)
