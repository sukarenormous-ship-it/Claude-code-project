บท 17 — สิ่งที่อยู่ถัดไป: ความสัมพันธ์ไม่เป็นเส้นตรง และ options
Correlation ของ BTC กับ ETH คือ 0.82 แต่ในวันที่แย่ที่สุด 10% ทั้งสองเหรียญไปด้วยกัน 71% ขณะที่วันที่ดีที่สุดไปด้วยกันเพียง 53% บทนี้สอน copula ด้วยตารางอันดับ 5 × 5 ที่คิดด้วยมือ แล้วสอน options เป็นเพดานขาดทุนของขาในคู่ ด้วยต้นไม้สองทาง ทั้งสองเรื่องจบที่สิ่งที่เครื่องมือบอกไม่ได้

ภาค 5 · บท 17 จาก 18 · บทนี้มีสี่ตอน อ่านทีละตอนได้ (ตอน ก copula ด้วยมือสิบวัน · ตอน ข หางของเหรียญจริงเทียบโลกที่รู้คำตอบ · ตอน ค options ด้วยต้นไม้สองทาง · ตอน ง ประกันสองขาของคู่จริงในช่วงตรวจ) · ต้องรู้จากบทก่อน: (1) Rank Correlation คือ Correlation ที่คิดจากอันดับแทนค่าจริง ห้าคู่ตัวอย่างได้ 0.4 (บท 8) · (2) Log Return คือผลตอบแทนแบบ log รายวัน ซึ่งบวกกันข้ามวันได้ (บท 2) · (3) เครื่อง backtest ของบท 13 ถือ short X ของ BTC–ETH ไม้ละไม่เกิน 30 วันเกือบทั้งช่วงตรวจ จบ −55.53 และ Equity เคยลงถึง 608.92

  2. ถืออะไรจริง — สองขาที่ควรหักล้างกัน ถ้าวันพังไม่พังพร้อมกัน ขาหนึ่งจะลากทั้งชุด

Correlation ตัวเดียวบอกได้แค่ว่าสองเหรียญไปด้วยกันโดยเฉลี่ย แล้วจะวัดอย่างไรว่าในวันที่แย่ที่สุดมันไปด้วยกันแค่ไหน และถ้าหางของคู่หนากว่าที่คิด จะซื้อเพดานขาดทุนได้ไหม ด้วยราคาเท่าไร

ตอน ก copula ด้วยมือ · 1 — สิบวันของ A กับ B: ในวันที่ A แย่สุดสองวัน B แย่สุดด้วยทั้ง 2 วัน

คำถามของพี่ฝนฟังง่าย แต่ตอบด้วยเครื่องมือที่มินมีอยู่ไม่ได้ Correlation ของบท 1 คิดจากทุกวันรวมกัน วันธรรมดาหลายร้อยวันมีน้ำหนักในตัวเลขนั้นมากกว่าวันพังไม่กี่วัน แต่สำหรับคนที่ถือคู่ วันพังไม่กี่วันนั้นคือวันที่บัญชีเจ็บจริง มินจึงต้องการวิธีที่ดูเฉพาะวันสุดขอบ โดยไม่ให้วันธรรมดามากลบ

ระดับ = อันดับ ÷ (จำนวนวัน + 1)

อ่านสมการ: วันที่ 2 A ได้อันดับ 1 จากสิบวัน ระดับคือ 1 ÷ 11 ราว 0.09 ส่วนวันที่ 10 ได้อันดับ 10 ระดับคือ 10 ÷ 11 ราว 0.91 copula เต็มรูปคือภาพของจุด (ระดับ A, ระดับ B) ทุกวัน ส่วนตาราง 5 × 5 คือภาพเดียวกันแบบหยาบ

ตัวเลขที่ตอบพี่ฝน คือ "B อยู่กลุ่มแย่สุดกี่ส่วน เมื่อรู้แล้วว่า A อยู่กลุ่มแย่สุด" มีชื่อว่า Conditional Probability (ความน่าจะเป็นแบบมีเงื่อนไข) คือความน่าจะเป็นที่คิดเฉพาะในวันที่เงื่อนไขหนึ่งเป็นจริงแล้ว ตัวหารจึงไม่ใช่วันทั้งหมด แต่เป็นเฉพาะวันที่เข้าเงื่อนไข

🚶 อ่านเป็นภาษาคนก่อน: ตัดวันที่ไม่เข้าเงื่อนไขทิ้งให้หมดก่อน เหลือแต่วันที่ A แย่สุด แล้วนับว่าในวันที่เหลือนั้น B แย่สุดด้วยกี่วัน

ความน่าจะเป็นที่ B แย่สุด เมื่อ A แย่สุด = จำนวนวันที่ทั้งคู่อยู่กลุ่มแย่สุด ÷ จำนวนวันที่ A อยู่กลุ่มแย่สุด

อ่านสมการ: โลกตกพร้อมกัน 2 ÷ 2 ได้ 100% โลกหางแยก 0 ÷ 2 ได้ 0% สองโลกมี Rank Correlation 0.9 เท่ากัน แต่ตัวเลขนี้ต่างกันสุดขั้ว

💻 ทำด้วย Python 
A = [1.2, -4.0, 0.5, -0.8, 3.1, -2.5, 0.1, 2.0, -1.5, 4.4]
B_together = [0.9, -5.0, -0.6, 0.3, 2.4, -3.2, -1.0, 1.6, -0.2, 3.0]
B_apart = [0.9, -1.0, 0.3, -3.2, 2.4, -0.6, -0.2, 1.6, -5.0, 3.0]

def ranks(v):                                   # อันดับ 1 = วันที่แย่ที่สุด
    order = sorted(range(len(v)), key=lambda i: v[i])
    r = [0] * len(v)
    for k, i in enumerate(order):
        r[i] = k + 1
    return r

def summary(a, b, groups=5):
    n, ra, rb = len(a), ranks(a), ranks(b)
    ga = [(r - 1) * groups // n + 1 for r in ra]   # อันดับ → กลุ่ม 1..5
    gb = [(r - 1) * groups // n + 1 for r in rb]
    worst = [i for i in range(n) if ga[i] == 1]
    p = 100 * sum(1 for i in worst if gb[i] == 1) / len(worst)
    d2 = sum((x - y) ** 2 for x, y in zip(ra, rb))
    return round(p), round(1 - 6 * d2 / (n * (n * n - 1)), 2)

print(*summary(A, B_together), *summary(A, B_apart))
# ผลที่ต้องได้: 100 · 0.9 · 0 · 0.9

ฟังก์ชัน ranks คือขั้นเรียงอันดับ บรรทัด ga และ gb คือขั้นแบ่งกลุ่ม ส่วน worst คือการตัดวันที่ไม่เข้าเงื่อนไขทิ้ง ถ้าใช้ pandas ให้ใช้ s.rank() แทน ranks และ pd.qcut(s.rank(), 5, labels=False) แทนการแบ่งกลุ่ม แล้ว pd.crosstab สองคอลัมน์กลุ่มจะได้ตาราง 5 × 5 ทันที

⚠️ พังเมื่อไร / บอกอะไรไม่ได้ — ตารางอันดับ (copula)
  • บอกไม่ได้ว่า ขาดทุนเท่าไร copula ตัดขนาดทิ้ง ถ้าวันที่ 2 B ลง 15% แทน 5% อันดับของ B ก็ยังเป็น 1 ตาราง 5 × 5 ไม่เปลี่ยนแม้แต่ช่องเดียว และความน่าจะเป็นแบบมีเงื่อนไขยังเป็น 100% แต่เงินที่ชุด long A short B ได้ในวันนั้นจะเปลี่ยนจาก 1 เป็น 11 เงินต้องคิดจากขนาด ซึ่งต้องดูแยกต่างหาก
  • พังเมื่อ ข้อมูลน้อย สิบวันแบ่งห้ากลุ่มเหลือกลุ่มละ 2 วัน ความน่าจะเป็นที่ได้จึงมีแค่ 0%, 50% หรือ 100% วันเดียวที่ย้ายช่องเปลี่ยนคำตอบไป 50 จุด ตอน ข จะเห็นว่าแม้มีหางยาว 36 วัน โลกที่รู้คำตอบเดียวกันยังให้ผลกระจายกว้างถึง 28 จุดเปอร์เซ็นต์
  • บอกไม่ได้ว่า วันพรุ่งนี้จะไปด้วยกันไหม ตารางนับเฉพาะการขยับในวันเดียวกัน ไม่ได้บอกว่าระยะห่างของคู่จะกลับหรือไม่ ซึ่งเป็นคำถามของ ADF และ Half-life ในภาค 1

import math
from sab2_realdata import load_closes
import sab2_stats as S

def ranks(v):
    order = sorted(range(len(v)), key=lambda i: v[i])
    r = [0] * len(v)
    for k, i in enumerate(order):
        r[i] = k + 1
    return r

_, p = load_closes("formation", coins=["BTC", "ETH"])
a = [math.log(y / x) for x, y in zip(p["BTC"], p["BTC"][1:])]     # Log Return รายวัน
b = [math.log(y / x) for x, y in zip(p["ETH"], p["ETH"][1:])]
n, ra, rb = len(a), ranks(a), ranks(b)
k = round(0.1 * n)                                                  # หาง 10% = 73 วัน
low = sum(1 for i in range(n) if ra[i] <= k and rb[i] <= k)
high = sum(1 for i in range(n) if ra[i] > n - k and rb[i] > n - k)
print(low, high, round(S.corr(a, b), 2), round(S.corr(ra, rb), 2))

ตรวจอีกทาง ขาดทุนสูงสุดคิดได้โดยไม่ต้องทำตาราง ขา short เสียได้ไม่เกินระยะจากราคาเข้าถึงราคาใช้สิทธิ์ คือ 110 − 100 หรือ 10 บวกค่าพรีเมียมที่จ่ายไปแล้ว 5 ได้ 15 ตรงกับสี่แถวล่างของตาราง

ขาอีกข้างของคู่คือ long B ขานี้เสียเมื่อ B ลง สิทธิ์ที่คุ้มครองขานี้คือสิทธิ์ที่จะ ขาย ในราคาที่ตกลงไว้ เรียกว่า Put (สิทธิ์ขาย) Payoff ของ Put คือราคาใช้สิทธิ์ลบราคา ณ วันหมดอายุ ถ้าติดลบให้เป็นศูนย์ ในต้นไม้เดิม Put ของ A ที่ราคาใช้สิทธิ์ 110 ให้ 0 เมื่อ A ขึ้นไป 120 และให้ 110 − 80 หรือ 30 เมื่อ A ลงไป 80 ค่าเฉลี่ยคือ (0 + 30) ÷ 2 จึงได้ค่าพรีเมียม 15

เฉลย 🛑 ก่อน ในต้นไม้ที่แกว่ง ±30 Call ราคาใช้สิทธิ์ 110 ให้ 130 − 110 หรือ 20 เมื่อขึ้น และให้ 0 เมื่อลง ค่าเฉลี่ยคือ 10 เพิ่มเป็นสองเท่าทั้งที่ราคาเฉลี่ยของ A ไม่ได้ขยับเลย ราคาของสิทธิ์ขึ้นกับว่าราคาจะแกว่งไกลแค่ไหน เพราะฝั่งที่สิทธิ์ได้เงินโตขึ้น ส่วนฝั่งที่เสียยังติดอยู่ที่ศูนย์

ต่อไปดูสิ่งที่เกิดเมื่อถือ Call กับ Put ที่ราคาใช้สิทธิ์เดียวกันพร้อมกัน โดยซื้อ Call หนึ่งตัวและขาย Put หนึ่งตัว กลับไปที่ต้นไม้ ±20 กับราคาใช้สิทธิ์ 110 ถ้า A ขึ้นไป 120 Call ให้ 10 ส่วน Put ที่ขายไว้ไม่มีใครใช้สิทธิ์ รวมได้ 10 ถ้า A ลงไป 80 Call ให้ 0 แต่คนที่ซื้อ Put จากมินจะใช้สิทธิ์ขาย A ให้มินที่ 110 ทั้งที่ตลาดขาย 80 มินจึงเสีย 30 รวมได้ −30

ผลรวมเท่ากับ A − 110 ทุกทาง ซึ่งก็คือผลของการตกลงซื้อ A ที่ 110 ในอีก 30 วันแบบผูกมัด แบบเดียวกับ Futures (สัญญาซื้อขายล่วงหน้า) ของเล่ม 1 เมื่อสองชุดให้เงินเท่ากันทุกทาง ราคาวันนี้ก็ต้องเท่ากัน ราคาวันนี้ของ Call ลบ Put คือ 5 − 15 หรือ −10 ส่วนราคาวันนี้ของการตกลงซื้อที่ 110 เมื่อของมีค่า 100 คือ 100 − 110 หรือ −10 ตรงกัน

ตรวจอีกทาง ด้วยราคาใช้สิทธิ์ 100 ในต้นไม้เดียวกัน Call ให้ 20 หรือ 0 จึงมีค่า 10 Put ให้ 0 หรือ 20 จึงมีค่า 10 Call ลบ Put ได้ 0 เท่ากับ 100 − 100 พอดี ความสัมพันธ์นี้มีชื่อว่า Put-Call Parity (ความเท่าเทียมระหว่างพุตและคอล) คือราคา Call ลบราคา Put ที่ราคาใช้สิทธิ์และวันหมดอายุเดียวกัน ต้องเท่ากับราคาสินทรัพย์ลบราคาใช้สิทธิ์ เมื่อดอกเบี้ยเป็นศูนย์

🚶 อ่านเป็นภาษาคนก่อน: ซื้อสิทธิ์ซื้อคู่กับขายสิทธิ์ขาย ก็คือการตกลงซื้อแบบผูกมัดนั่นเอง ราคาของสองอย่างนี้จึงต้องเท่ากัน ถ้าไม่เท่า จะมีคนซื้อฝั่งที่ถูกขายฝั่งที่แพงจนราคาเข้าที่

ราคา Call − ราคา Put = ราคาสินทรัพย์วันนี้ − ราคาใช้สิทธิ์

อ่านสมการ: ราคาใช้สิทธิ์ 110 ได้ 5 − 15 เท่ากับ 100 − 110 คือ −10 ทั้งสองข้าง ของจริงที่ดอกเบี้ยไม่เป็นศูนย์ ราคาใช้สิทธิ์ต้องคูณ Discount Factor (ตัวคิดลด) ก่อน แต่โครงยังเป็นแบบนี้

ถ้าตลาดตั้งราคาผิด เช่น Call 8 กับ Put 15 ซึ่งต่างกัน −7 แทนที่จะเป็น −10 คนที่ขาย Call ที่ 8 ซื้อ Put ที่ 15 และซื้อ A ที่ 100 จะได้ชุดที่ปิดได้ที่ 110 ทุกทาง เงินที่ใช้คือ 100 + 15 − 8 หรือ 107 จึงล็อกได้ 3 ก่อนต้นทุน นี่คือ Arbitrage (การเก็งกำไรส่วนต่างราคา · อาร์บิทราจ) ของเล่ม 1 บท 0 ซึ่งในตลาดจริงจะเหลือหลังค่าธรรมเนียม Bid-Ask Spread (ส่วนต่างราคาเสนอซื้อ-เสนอขาย) และหลักประกันน้อยมาก

กลับมาที่สิ่งที่ 🛑 ชี้ไว้ ราคาของ Call ขึ้นจาก 5 เป็น 10 เมื่อการแกว่งเพิ่มจาก ±20 เป็น ±30 ส่วน Put ราคาใช้สิทธิ์ 110 ขึ้นจาก 15 เป็น 20 และ Call ลบ Put ยังเป็น −10 เท่าเดิม Put-Call Parity ไม่สนว่าแกว่งแรงแค่ไหน แต่ราคาของสิทธิ์แต่ละตัวสนมาก

เมื่อเห็นราคาของสิทธิ์ในตลาด ก็ย้อนกลับได้ว่าตลาดคาดว่าราคาจะแกว่งแรงแค่ไหน ถ้า Call ราคาใช้สิทธิ์ 110 ขายที่ 10 ในต้นไม้นี้ แปลว่าตลาดตั้งราคาราวกับว่า A จะแกว่ง ±30 ความแกว่งที่อ่านย้อนจากราคาสิทธิ์แบบนี้เรียกว่า Implied Volatility (ความผันผวนแฝง)

ส่วนความแกว่งที่เกิดขึ้นจริงหลังจากนั้นคือ Realized Volatility (ความผันผวนที่เกิดขึ้นจริง) คนที่ซื้อสิทธิ์ได้เปรียบเมื่อราคาแกว่งจริงแรงกว่าที่จ่ายไว้ และเสียเปรียบเมื่อแกว่งน้อยกว่า

def tree(price, move, strike):
    """ต้นไม้สองทาง: ขึ้นหรือลง move โอกาสเท่ากัน ราคาเฉลี่ยไม่เปลี่ยน ดอกเบี้ยศูนย์"""
    up, down = price + move, price - move
    call = (max(up - strike, 0) + max(down - strike, 0)) / 2
    put = (max(strike - up, 0) + max(strike - down, 0)) / 2
    return call, put

c20, p20 = tree(100, 20, 110)
c30, p30 = tree(100, 30, 110)
cap = (110 - 100) + c20                         # เพดานขาดทุนของ short A ที่ 100
print(c20, p20, c20 - p20, c30, p30, cap)
# ผลที่ต้องได้: 5 · 15 · −10 · 10 · 20 · 15

ทั้งต้นไม้อยู่ในสามบรรทัดของ tree ค่าพรีเมียมคือค่าเฉลี่ยของ Payoff สองทาง ลองเปลี่ยน strike เป็น 100 จะได้ Call ลบ Put เป็นศูนย์ ถ้าใช้ไลบรารี options ทั่วไป ฟังก์ชันตั้งราคาจะรับความผันผวนต่อปีและวันหมดอายุเป็นปี ซึ่งตอน ง ใช้แบบเดียวกัน

📖 ศัพท์ใหม่ในตอนนี้
  • Copula (โคพูลา) = ตารางหรือภาพที่บอกว่าอันดับของสองสินทรัพย์ผูกกันอย่างไร โดยตัดขนาดของการขยับทิ้ง · สองโลกสิบวัน Rank Correlation 0.9 เท่ากัน แต่ตารางต่างกันที่มุมแย่สุด
  • Conditional Probability (ความน่าจะเป็นแบบมีเงื่อนไข) = ความน่าจะเป็นที่คิดเฉพาะในวันที่เงื่อนไขเป็นจริงแล้ว ตัวหารคือวันที่เข้าเงื่อนไข · 2 ÷ 2 ได้ 100% กับ 0 ÷ 2 ได้ 0%
  • Tail Dependence (การพึ่งพากันที่หาง) = โอกาสที่สินทรัพย์หนึ่งอยู่ในหาง เมื่ออีกตัวอยู่ในหางเดียวกัน แยกหางล่างกับหางบน · BTC–ETH ช่วงเลือก 71% กับ 53% ที่หาง 10%
  • Call / Put (สิทธิ์ซื้อ / สิทธิ์ขาย) = สิทธิ์ ไม่ใช่หน้าที่ ที่จะซื้อหรือขายสินทรัพย์ที่ Strike Price (ราคาใช้สิทธิ์) ภายใน Expiration (วันหมดอายุ) · Payoff (ผลตอบแทน ณ วันหมดอายุ) ของ Call 110 เมื่อ A อยู่ 130 คือ 20
  • Premium (ค่าพรีเมียม (ราคาออปชัน)) = ราคาที่ผู้ซื้อจ่ายเพื่อได้สิทธิ์ · ในต้นไม้สองทางคือค่าเฉลี่ยของ Payoff เมื่อราคาเฉลี่ยไม่เปลี่ยน · Call 110 ในต้นไม้ ±20 คือ 5
  • Put-Call Parity (ความเท่าเทียมระหว่างพุตและคอล) = ราคา Call − ราคา Put = ราคาสินทรัพย์ − ราคาใช้สิทธิ์ (ดอกเบี้ยศูนย์) · 5 − 15 เท่ากับ 100 − 110
  • Implied Volatility (ความผันผวนแฝง) = ความแกว่งที่อ่านย้อนจากราคาสิทธิ์ เทียบกับ Realized Volatility (ความผันผวนที่เกิดขึ้นจริง) · Put ของ ETH ตั้งราคาที่ 55% แต่แกว่งจริง 75.6% จึงได้คืน 1.69 เท่า

ทฤษฎีบทของ Sklar: ถ้า FA และ FB คือการแจกแจงสะสมของแต่ละตัว การแจกแจงร่วมเขียนได้เป็น H(a, b) = C(FA(a), FB(b)) โดย C คือ copula ซึ่งเป็นการแจกแจงร่วมของระดับ (u, v) บนสี่เหลี่ยม [0, 1]² · ระดับ = อันดับ ÷ (n + 1) คือการประมาณ F จากข้อมูล (pseudo-observations)

สัมประสิทธิ์หางล่าง λL = ลิมิตของ P(V ≤ q | U ≤ q) เมื่อ q → 0 · copula แบบปกติ (Gaussian) ที่ correlation น้อยกว่า 1 มี λL = λU = 0 แม้ที่หาง 10% จะยังได้ราว 59% ที่ correlation 0.82 (ค่าที่หาง 10% ลดลงเรื่อย ๆ เมื่อหางแคบลง) · copula แบบ Student-t มีหางสองข้างเท่ากันและมากกว่าศูนย์ · Clayton มีแต่หางล่าง · Gumbel มีแต่หางบน · ค่าที่ q คงที่ (10%) ในหน้านี้จึงไม่ใช่ λ แต่เป็นตัวชี้วัดที่คิดด้วยมือได้และเทียบกับโลกที่รู้คำตอบได้ตรง

Correlation ธรรมดาของสองโลกมือในตอน ก ต่างกัน (โลกตกพร้อมกัน 0.93 · โลกหางแยก 0.72) เพราะในโลกหางแยก วันที่ B ลงแรงที่สุดไปตกในวันที่ A ขยับน้อย Correlation ธรรมดาสนขนาด จึงแยกสองโลกนี้ได้โดยบังเอิญ แต่บนข้อมูลจริงของตอน ข Correlation ธรรมดากับ Rank Correlation เท่ากันที่ 0.82 ทั้งที่หางไม่สมมาตร ตัวเลขตัวเดียวทั้งสองแบบจึงไม่ใช่เครื่องมือวัดหาง

โลกตกพร้อมกัน: การขยับ log ของสองเหรียญเป็นปกติร่วมที่ correlation 0.7 (SD แรงร่วม 3% ต่อวัน) บวก −12% พร้อมกันในวันที่ตัวสุ่มอิสระอีกตัวต่ำกว่าเส้น 7% ล่าง · ค่าจริงของทั้งสองโลกหาจากโลกยาว 200,000 วันหนึ่งโลก
