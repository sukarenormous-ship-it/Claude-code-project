Black-Scholes — "สูตรที่บอกว่าเส้นโค้งอยู่ตรงไหน"

แนวคิด: ทำไมต้องรู้?

Payoff chart ณ expiry = เส้นหักศอก (ตรงไปตรงมา)
แต่ก่อน expiry = เส้นโค้ง → Black-Scholes บอกว่าเส้นโค้งนั้นอยู่ตรงไหน

Black-Scholes Call Price

C = S·N(d₁) - K·e⁻ʳᵀ·N(d₂)

d₁ = [ln(S/K) + (r + σ²/2)·T] / (σ·√T)
d₂ = d₁ - σ·√T

📖 อ่านสูตรว่า: "ซี เท่ากับ เอส คูณ เอ็นของดีหนึ่ง ลบ เค คูณ อียกกำลังลบอาร์ที คูณ เอ็นของดีสอง" · d₁ อ่านว่า "ล็อกธรรมชาติของ S หาร K บวก (r บวก ครึ่งของซิกมากำลังสอง) คูณ T ทั้งหมดหารด้วย ซิกมา คูณ รูท T" · โครงที่ต้องเห็น: โครงเดียวกับ payoff S − K แต่แต่ละก้อนถ่วงด้วยความน่าจะเป็น: หุ้น × โอกาสได้หุ้น ลบ สไตรก์ที่ลดค่าแล้ว × โอกาสต้องจ่าย · ลอง σ → 0 และ S > K·e⁻ʳᵀ: d₁, d₂ → ∞ ทำให้ N(·) → 1 → C → S − K·e⁻ʳᵀ · กับดักการอ่าน: N(d₁) คือฟังก์ชัน CDF ของ normal มาตรฐาน (ค่า 0–1) ไม่ใช่ "N คูณ d₁" · e⁻ʳᵀ คือตัวลดค่าที่คูณ K เท่านั้น · ln(S/K) = 0 พอดีเมื่อ S = K · σ·√T คือ SD ตลอดอายุ — เวลาเข้ามาแบบรูท ไม่ใช่เส้นตรง

ความหมายแต่ละส่วน

S·N(d₁) = "ส่วนที่ได้จากหุ้น" → Delta × ราคาหุ้น → มูลค่าหุ้นที่ option "ครอบครอง"
K·e⁻ʳᵀ·N(d₂) = "ส่วนที่ต้องจ่าย" → PV ของ strike × probability ที่จะต้องจ่าย
N(d₂) = probability ที่ option จบ ITM (risk-neutral) → "โอกาสที่จะได้ใช้สิทธิ"
N(d₁) = Delta = hedge ratio → "ต้องถือหุ้นกี่หุ้นเพื่อ hedge option 1 สัญญา"

Black-Scholes Put Price

P = K·e⁻ʳᵀ·N(-d₂) - S·N(-d₁)

หรือจาก PCP: P = C - S + K·e⁻ʳᵀ (ง่ายกว่าคำนวณเอง)

📖 อ่านสูตรว่า: "พี เท่ากับ เค คูณ อียกกำลังลบอาร์ที คูณ เอ็นของ ลบดีสอง ลบ เอส คูณ เอ็นของ ลบดีหนึ่ง" — โครงเดียวกับ Call แต่กลับลำดับสองก้อนและใส่ลบหน้า d · กับดักการอ่าน: N(−d) ไม่ใช่ "ลบ N(d)" — ด้วยความสมมาตรของ normal N(−d) = 1 − N(d): N(−d₂) คือโอกาส (ใต้ Q) ที่จบต่ำกว่า K ส่วน N(−d₁) = 1 − Delta ของ Call ไม่ใช่ความน่าจะเป็นตัวเดียวกัน · บรรทัดสองคือ PCP ย้ายข้าง (Part I บท 2) — ให้คำตอบเดียวกันเป๊ะ จึงใช้ตรวจเลขได้

ตัวอย่างคำนวณ

ข้อมูล: S=100, K=100, r=5%, σ=20%, T=0.5 (6 เดือน)

Step 1: คำนวณ d₁
d₁ = [ln(100/100) + (0.05 + 0.04/2)×0.5] / (0.20×√0.5)
   = [0 + (0.05 + 0.02)×0.5] / (0.20×0.7071)
   = [0.035] / [0.1414]
   = 0.2475

Step 2: คำนวณ d₂
d₂ = 0.2475 - 0.1414 = 0.1061

Step 3: หา N(d₁) และ N(d₂) จากตาราง Normal Distribution
N(0.2475) ≈ 0.5977 (Delta)
N(0.1061) ≈ 0.5422 (P(ITM))

Step 4: คำนวณ Call Price
C = 100×0.5977 - 100×e⁻⁰·⁰²⁵×0.5422
  = 59.77 - 97.53×0.5422
  = 59.77 - 52.88
  = ฿6.89

Step 5: คำนวณ Put Price (ผ่าน PCP)
P = 6.89 - 100 + 97.53 = ฿4.42

ตรวจสอบ PCP: C + PV(K) = 6.89 + 97.53 = 104.42 | P + S = 4.42 + 100 = 104.42 ✓
3 สิ่งที่ต้องจำ (BS)

1. N(d₂) = probability ITM → "โอกาสที่ option จะมีค่าเมื่อหมดอายุ"
2. N(d₁) = Delta → "ต้องถือหุ้นกี่หุ้นเพื่อ hedge"
3. BS ใช้ได้แค่ European + สมมติ vol คงที่ (จริงๆ มี smile/skew)

Digital Option Pricing — "PM ควรราคาเท่าไร?"

Digital Call = e⁻ʳᵀ × N(d₂)

ตัวอย่าง (ข้อมูลเดิม): e⁻⁰·⁰²⁵ × 0.5422 = 0.9753 × 0.5422 = $0.529

ความหมาย: PM Above Yes ที่ K=100 ควรมีราคา ≈ 53¢ (ถ้า price ด้วย BS)
ถ้า PM ขาย 62¢ → PM แพงกว่า Options implied 9¢ → อาจมี edge (หรือ PM มีข้อมูลมากกว่า)

📖 อ่านสูตรว่า: "ราคาดิจิทัลคอล เท่ากับ ตัวลดค่า คูณ เอ็นของดีสอง" · โครงที่ต้องเห็น: ราคา = PV ของ (จ่าย $1 × โอกาสจ่าย) — ก้อนที่สองของสูตร BS Call เมื่อตัด K ออก เพราะดิจิทัลจ่ายเงินคงที่ไม่ใช่ K · ถ้า r = 0 ราคาคือ N(d₂) ตรง ๆ = ความน่าจะเป็น risk-neutral ที่จบ ITM · กับดักการอ่าน: ≈ 53¢ มีสมมติฐาน: ความน่าจะเป็นแบบ risk-neutral ภายใต้ σ คงที่ ไม่ใช่โอกาสจริงที่ตลาด PM พยายามทาย — ส่วนต่าง 9¢ จึงไม่ใช่ edge อัตโนมัติ

Greeks Formulas — "ตัวเลข exact"

จาก Part V เรียนว่า "Delta = slope, Gamma = curvature" แต่ไม่มีสูตร — ตอนนี้เพิ่มสูตร exact

Normal PDF: N'(x)

N'(x) = (1/√(2π)) × e⁻ˣ²/² ≈ 0.3989 × e⁻ˣ²/²
(ใช้ในสูตร Gamma, Theta, Vega)

📖 อ่านสูตรว่า: "เอ็น-ไพรม์ของเอ็กซ์ เท่ากับ หนึ่งหารด้วยรูทของสองไพ คูณ อี ยกกำลัง ลบ เอ็กซ์กำลังสอง ส่วน สอง" — เครื่องหมาย ′ (prime) คืออนุพันธ์: N′ คือความชันของ N หรือ "ความหนาแน่น" ของ normal (รูประฆัง) ส่วน N คือพื้นที่สะสม · โครงที่ต้องเห็น: ค่าคงที่ × e ยกกำลังลบ — สูงสุดที่ x = 0 (e⁰ = 1 → 0.3989) แล้วลดลงสมมาตรสองข้าง · กับดักการอ่าน: ทั้ง −x²/2 อยู่บนเลขยกกำลัง ไม่ใช่ "e ลบ x² หาร 2" · √(2π) มี π (ค่าคงที่วงกลม) ไม่ใช่ตัวแปร · 0.3989 = 1/√(2π) ≈ 1/2.5066

Delta — "Option เปลี่ยนเท่าไรเมื่อหุ้นขยับ ฿1"

Delta_Call = N(d₁) → ค่าอยู่ระหว่าง 0 ถึง +1
Delta_Put = N(d₁) - 1 → ค่าอยู่ระหว่าง -1 ถึง 0

ตัวอย่าง: Delta_Call = N(0.2475) = 0.5977
→ หุ้นขึ้น ฿1 → Call ขึ้น ≈ ฿0.60
Delta_Put = 0.5977 - 1 = -0.4023
→ หุ้นขึ้น ฿1 → Put ลง ≈ ฿0.40

📖 อ่านสูตรว่า: "เดลตาของคอล เท่ากับ เอ็นของดีหนึ่ง" · "เดลตาของพุต เท่ากับ เอ็นของดีหนึ่ง ลบ หนึ่ง" · โครงที่ต้องเห็น: Delta คือความชันของราคา option ต่อราคาหุ้น (บท 20) — N(d₁) เป็น CDF จึงอยู่ใน 0–1 อัตโนมัติ Put เลื่อนลงมาอยู่ใน −1 ถึง 0 · Delta_Call − Delta_Put = 1 เสมอ — ตามมาจาก PCP (C − P = S − PV(K)) เมื่อ S ขยับ 1 ฝั่งขวาขยับ 1 · กับดักการอ่าน: Δ ตรงนี้คือ Greek (ยืนคนเดียว) — ไม่ใช่ Δslope ของ Part III-A บท 15 ที่แปลว่า "การเปลี่ยนแปลง" · ตัวห้อย Call/Put คือชื่อกำกับ ไม่ใช่ตัวแปร

Gamma — "Delta เปลี่ยนเร็วแค่ไหน"

Gamma = N'(d₁) / (S × σ × √T) (เท่ากันสำหรับ Call และ Put)

ตัวอย่าง: N'(0.2475) = 0.3989 × e⁻⁰·⁰³⁰⁶ = 0.3989 × 0.9698 = 0.3869
Gamma = 0.3869 / (100 × 0.20 × 0.7071) = 0.3869 / 14.14 = 0.0274
→ หุ้นขึ้น ฿1 → Delta เปลี่ยนประมาณ 0.027

📖 อ่านสูตรว่า: "แกมมา เท่ากับ เอ็น-ไพรม์ของดีหนึ่ง หารด้วย เอส คูณ ซิกมา คูณ รูท T" · โครงที่ต้องเห็น: อัตราส่วน — ตัวเศษคือความหนาแน่น (สูงสุดเมื่อ d₁ ≈ 0 คือ ATM) ตัวส่วนคือ "ราคา × SD ตลอดอายุ" · ตัวส่วนโตเมื่อ T หรือ σ โต → Gamma เล็ก · T เล็กมาก → ตัวส่วนวิ่งเข้าศูนย์ → Gamma พุ่ง = gamma cliff ของบท 21 · กับดักการอ่าน: N′ (มี prime) ไม่ใช่ N — ใช้ CDF แทน PDF จะได้เลขผิดโดยไม่มี error · หน่วยคือ "Delta ต่อ ฿1" จึงเป็นเลขเล็กอย่าง 0.027

Theta — "Option เสียค่าเท่าไรต่อวัน"

Theta_Call = -S×N'(d₁)×σ/(2√T) - r×K×e⁻ʳᵀ×N(d₂)

ส่วนแรก = time decay ของ optionality (ติดลบเสมอ)
ส่วนสอง = ดอกเบี้ยบน exercise price

ตัวอย่าง (ต่อปี):
= -(100×0.3869×0.20)/(2×0.7071) - (0.05×100×0.9753×0.5422)
= -(7.738)/(1.4142) - (2.644)
= -5.473 - 2.644 = -8.12 ต่อปี
= -8.12/365 = -฿0.022 ต่อวัน
→ ทุกวันที่ถือ Call เสียค่าประมาณ ฿0.02

📖 อ่านสูตรว่า: "ทีตาของคอล เท่ากับ ลบ เอส คูณ เอ็น-ไพรม์ของดีหนึ่ง คูณ ซิกมา หารด้วย สองรูท T ลบ อาร์ คูณ เค คูณ ตัวลดค่า คูณ เอ็นของดีสอง" · โครงที่ต้องเห็น: ผลรวมสองก้อนที่ติดลบทั้งคู่: ก้อนแรกคือ S × ความหนาแน่น × σ / (2√T) (ค่าเวลาที่ละลาย — ยิ่ง T เล็กยิ่งเร็ว) ก้อนสองคือดอกเบี้ย r บน PV(K) × โอกาสต้องจ่าย · กับดักการอ่าน: หน่วยคือต่อปี เพราะ T เป็นปี — ต้องหาร 365 เองจึงได้ต่อวัน ตามที่ตัวอย่างทำ · ก้อนแรกใช้ N′ ก้อนสองใช้ N — คนละฟังก์ชัน · 2√T คือ 2 คูณ รูท T ไม่ใช่รูทของ 2T

Vega — "Option เปลี่ยนเท่าไรเมื่อ vol เปลี่ยน 1%"

Vega = S × N'(d₁) × √T (เท่ากันสำหรับ Call และ Put)

ตัวอย่าง: 100 × 0.3869 × 0.7071 = 27.36 (ต่อ 100% vol)
→ ต่อ 1% vol: 27.36/100 = ฿0.274
→ ถ้า IV เพิ่มจาก 20% เป็น 21% → option ขึ้น ≈ ฿0.27

📖 อ่านสูตรว่า: "เวก้า เท่ากับ เอส คูณ เอ็น-ไพรม์ของดีหนึ่ง คูณ รูท T" · โครงที่ต้องเห็น: ตัวเศษเดียวกับ Gamma (N′(d₁)) จึงสูงสุดที่ ATM เหมือนกัน แต่ √T อยู่ตัวเศษแทนตัวส่วน — option ยาวไวต่อ vol มากกว่า ตรงข้ามกับ Gamma · กับดักการอ่าน: สูตรให้ค่าต่อ σ เปลี่ยน 1.00 (คือ 100 จุดเปอร์เซ็นต์) — ต้องหาร 100 เองจึงได้ "ต่อ 1%" ตามที่ตัวอย่างทำ · Vega ไม่ใช่อักษรกรีกจริง แต่เรียกเป็น Greek ตามธรรมเนียม

Breeden-Litzenberger — "Butterfly = ตัวดูด Probability"

f(K) = eʳᵀ × d²C/dK²

ความหมาย: ถ้าเราหาอนุพันธ์อันดับสองของราคา Call เทียบกับ Strike
→ ได้ risk-neutral probability density ที่ strike นั้น

ในทางปฏิบัติ: ราคา Butterfly ที่ width → 0
= ตลาดบอกว่า "probability ที่ราคาจะจบตรง K นี้ = เท่าไร"

📖 อ่านสูตรว่า: "เอฟของเค เท่ากับ อียกกำลังอาร์ที คูณ อนุพันธ์อันดับสองของ C เทียบกับ K" · โครงที่ต้องเห็น: อนุพันธ์อันดับสองคือ "ความโค้ง" และในตลาดจริงคือ Butterfly แคบ ๆ: [C(K−h) − 2C(K) + C(K+h)] / h² — ราคาเต็นท์หารด้วยความกว้างกำลังสอง · ผลลัพธ์คือความหนาแน่น f(K): ยิ่งสูง ตลาดยิ่งให้น้ำหนักว่าราคาจะจบแถว K · กับดักการอ่าน: d²C/dK² ไม่ใช่ "d กำลังสอง คูณ C" — เป็นสัญลักษณ์เดียวอ่านว่า "อนุพันธ์อันดับสอง" · eʳᵀ เลขยกกำลังบวก คือตัวถอดการลดค่า (กลับด้านของ e⁻ʳᵀ) เพราะราคา Call ถูกลดค่ามาแล้ว · f(K) เป็นความหนาแน่นแบบ risk-neutral (ต้องคูณความกว้างช่วงจึงเป็นความน่าจะเป็น) ไม่ใช่โอกาสจริง

เชื่อมโยงกลับ: Butterfly Convexity (บท 10)

C(K₁) - 2C(K₂) + C(K₃) ≥ 0 (convexity condition)
Breeden-Litzenberger อธิบายว่า ทำไม: เพราะค่านี้ = probability density × width
Probability ≥ 0 เสมอ → Butterfly price ≥ 0 เสมอ → ถ้า < 0 = arbitrage!

Expected Payoff — "ปิดลูป Payoff ≠ Prediction"

บท 8 สอนว่า "Payoff ≠ Prediction — payoff chart ไม่มี probability"
ตอนนี้เรา ปิดลูป: ถ้ามี probability density → คำนวณ Expected Value ได้

E[payoff] = ∫ payoff(S) × f(S) dS

= "ซ้อน probability density บน payoff chart"
= พื้นที่ถ่วงน้ำหนัก = Expected Value ของ trade

ในทางปฏิบัติ (discrete):
EV = Σ P(state_i) × payoff(state_i)

📖 อ่านสูตรว่า: "ค่าคาดหวังของ payoff เท่ากับ อินทิกรัลของ payoff ที่ S คูณ ความหนาแน่น f ที่ S ดีเอส" — ∫ … dS คือ "บวกทุกค่า S ที่เป็นไปได้" แบบต่อเนื่อง ส่วน Σ บรรทัดล่างคือแบบนับเป็นก้อน · โครงที่ต้องเห็น: ค่าเฉลี่ยถ่วงน้ำหนัก — น้ำหนักคือความน่าจะเป็น ต้องรวมกันได้ 1 · เช็คตัวอย่างข้างล่าง: 0.40 + 0.35 + 0.25 = 1.00 ✓ · กับดักการอ่าน: E[·] คือค่าเฉลี่ยระยะยาว ไม่ใช่ค่าที่จะเกิดจริง และไม่บอกอะไรเรื่องการกระจาย · ตัวห้อย i ใน state_i คือ "อันที่เท่าไร" ไม่ใช่เวลา · dS ท้ายอินทิกรัลบอกว่าบวกไปตามแกน S ไม่ใช่ตัวคูณ

ตัวอย่าง: Bull Call Spread 100/110, net premium = 5

สมมติ probability distribution:
P(S < 100) = 40% → payoff = -5
P(100 ≤ S ≤ 110) = 35% → payoff เฉลี่ย ≈ 0 (midpoint)
P(S > 110) = 25% → payoff = +15

EV = 0.40×(-5) + 0.35×(0) + 0.25×(15) = -2 + 0 + 3.75 = +฿1.75
→ EV > 0 → trade นี้มี edge (ถ้า probability estimate ถูก)

Kelly Criterion — "ลงทุนเท่าไรต่อ trade"

f* = (b×p - q) / b

b = odds (ได้เท่าไรต่อ 1 ที่เสี่ย)
p = probability ชนะ
q = 1-p = probability แพ้

ตัวอย่าง: trade ที่ชนะ 60% ของเวลา, ชนะได้ 2x ที่เสี่ยง
f* = (2×0.6 - 0.4) / 2 = (1.2-0.4)/2 = 0.4 = 40%

ในทางปฏิบัติ: ใช้ Half-Kelly (20%)
เพราะ probability estimate ไม่แม่นยำ 100% → ลดขนาดเพื่อความปลอดภัย

📖 อ่านสูตรว่า: "เอฟ-สตาร์ เท่ากับ บี คูณ พี ลบ คิว ทั้งหมดหารด้วย บี" — ดอกจันบน f แปลว่า "ค่าที่ดีที่สุด" (optimal) ไม่ใช่การคูณ · โครงที่ต้องเห็น: ตัวเศษ bp − q คือ edge ต่อหนึ่งหน่วยที่เสี่ยง ตัวส่วน b คือ odds → สัดส่วน = edge/odds · ลอง b = 1, p = q = 0.5 → (0.5 − 0.5)/1 = 0 → ไม่ควรวางเลย ✓ · กับดักการอ่าน: b ต้องเป็น "กำไรสุทธิต่อ 1 ที่เสี่ยง" (ชนะได้ 2x → b = 2) ไม่ใช่ odds ทศนิยมแบบเจ้ามือที่รวมทุน · สูตรถือว่ารู้ p แน่ — ความไม่แน่นอนของ p ไม่อยู่ในสูตร นี่คือเหตุผลของ Half-Kelly

ระวัง: สูตรนี้ใช้ได้แค่ binary outcomes!

สูตร f* = (bp-q)/b สมมติว่า ผลลัพธ์มีแค่ 2 แบบ: ชนะได้ b หรือแพ้เสีย 1
สำหรับ options ที่มี payoff แบบ continuous (spreads, condors) → ต้องใช้ generalized Kelly: f* = argmax E[log(1 + f×R)]
ในทางปฏิบัติ: ใช้สูตร binary เป็น upper bound แล้วลดด้วย Half-Kelly

ในโลกจริง probability เป็น estimate ไม่ใช่ fact
ถ้า estimate ผิดแค่ 5% → Full Kelly อาจทำให้เจ๊งได้
กฎ: ใช้ Half-Kelly หรือ Quarter-Kelly เสมอ
