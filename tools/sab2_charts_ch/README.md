# สเปกกราฟต่อบทของเล่ม 2 (ปลั๊กอินของ `tools/sab_charts.py --book sab2`)

## กฎสีทั้งเล่ม (Colour rule · ใช้กับทุกกราฟใหม่และกราฟที่แก้)

สีเดียวต้องแปลว่าเรื่องเดียวทั้งเล่ม · ใช้ `C` ใน `tools/sab_charts.py` (เฉดอ่อน/เข้มประกาศเป็นค่าคงที่ในปลั๊กอินของบท)

| เรื่อง | สี |
|---|---|
| **ช่วงเวลา (Periods)** | ช่วงเลือก (formation) = น้ำเงิน `blue` · ช่วงตรวจ (validation) = ส้ม `amber` · ช่วงทดสอบสุดท้าย (final test) = ม่วง `purple` |
| **โลก (Worlds)** | ข้อมูลจริงที่อยู่เดี่ยว ๆ = น้ำเงิน (ถ้าภาพแบ่งช่วงด้วย ใช้สีของช่วงแทน) · 🎲 โลกจำลอง**มี**เชือก = เขียว `green` · 🎲 โลกจำลอง**ไม่มี**เชือก (เดินสุ่ม) = เทา `grey` · เชือกขาด / Regime Change = แดง `red` |
| **ขา (Legs)** | ขา A = น้ำเงิน · ขา B = ส้ม (แบบเล่ม 1) · ใช้เฉพาะกราฟที่พูดเรื่องขา |
| **วิธีของเล่ม vs ทางลัด** | วิธีของเล่ม = น้ำเงิน · ทางลัด/วิธีที่โกง = ส้ม |
| **ผลที่เป็นเงิน (Signed results)** | กำไร = เขียว · ขาดทุน = แดง · ใช้เฉพาะแท่งที่เป็นผลเงิน |
| **ชุดที่เป็นลำดับ (Graded series)** | ระดับต้นทุน · ความยาวหน้าต่าง · เส้นเข้า 1/1.5/2/2.5 · ค่า SD ของ Kalman · ฯลฯ = ไล่เฉดสีเดียวจากอ่อนไปเข้ม (เทาอ่อน → เทาเข้ม หรือ ฟ้า → น้ำเงินเข้ม) **ห้ามใช้สีไฟจราจร** เขียว/ส้ม/แดง |
| **เส้นอ้างอิง (Reference lines)** | Mean · ค่าวิกฤต · เส้นโชค · ค่าจริงที่รู้คำตอบ · เส้น ±2 · เส้นเลื่อนขั้น = `ink` หรือ `muted` เส้นประ |
| **จุดเน้น (Highlight)** | ม่วง `purple` (จุด วง ป้ายที่ชี้ ไม่ใช่เส้นข้อมูลหลัก) |

ถ้ากราฟเข้าได้สองกฎ เลือกกฎที่ตรงกับสิ่งที่ผู้อ่านกำลังเทียบในภาพนั้น และต้องตรงกับคำในย่อหน้า `.readfig` "อ่านภาพ:" ·
เมื่อเปลี่ยนสี แก้คำบอกสีใน `.readfig` คำบรรยาย (`cap`) และ `alt` ให้ตรงกันเสมอ (สีน้ำเงิน · ฟ้า · ส้ม · เขียว · แดง · เทา · เทาเข้ม · ม่วง)

## วิธีเขียนปลั๊กอิน

โฟลเดอร์นี้ว่างโดยตั้งใจ (โครงเฟส 1) · ไฟล์ `chNN.py` หนึ่งไฟล์ต่อบท ใช้ `from sab_charts import *` แบบเล่ม 1
(`tools/sab_charts_ch/README.md`) · คีย์กราฟขึ้นต้นด้วย `sab2-` · ตัวคั่นในหน้า `<!--CHART:sab2-คีย์--><!--/CHART:sab2-คีย์-->`

```python
from sab_charts import *  # noqa: F401,F403

@chart("sab2-phi-ladder")
def _phi_ladder(fig):
    c = fig["ch04"]
    parts = bars(["20 วัน", "60 วัน", "250 วัน"], c["phi"], "φ ที่ประมาณได้")
    return wrap(760, 320, "คำอธิบายภาพสำหรับโปรแกรมอ่านหน้าจอ", parts, "คำบรรยาย", "จำลอง")
```

กราฟของเล่ม 1 (คีย์ `sab-*`) ไม่ถูกโหลดเมื่อรันด้วย `--book sab2` · กราฟอ่านตัวเลขจาก `docs/sab2-figures.json` เท่านั้น
