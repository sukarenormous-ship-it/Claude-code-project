บทที่ 1: Arbitrage คืออะไร?

1.1 นิยาม

Arbitrage = การทำกำไรจากความแตกต่างของราคาสินทรัพย์เดียวกัน โดยไม่มีความเสี่ยงและไม่ใช้เงินทุนสุทธิ (หรือใช้น้อยมาก)

ตัวอย่างง่ายที่สุด

ร้านทอง A ขายทองแท่ง ฿30,000 / บาท
ร้านทอง B รับซื้อทองแท่ง ฿30,500 / บาท
→ ซื้อที่ A ฿30,000 → ขายที่ B ฿30,500 → กำไร ฿500 ทันที ไม่มีความเสี่ยง

Arb อยู่รอบตัว — ไม่ใช่แค่ในตลาดหุ้น!
  • ตั๋วคอนเสิร์ต: ซื้อตั๋วราคาหน้าเว็บ ฿2,000 → ขายต่อวันงาน ฿5,000 (แต่เสี่ยง: คอนเสิร์ตอาจยกเลิก)
  • iPhone ข้ามประเทศ: ซื้อญี่ปุ่น ฿28,000 → ขายไทย ฿32,000 (แต่มี: ค่าส่ง ฿500 + ภาษี ฿1,000 + เวลา 5 วัน)
  • Bitcoin ข้าม Exchange: ซื้อ Bitkub ฿2,100,000 → ขาย Binance ฿2,103,000 (แต่: ค่าถอน + เวลาโอน 10 นาที ราคาอาจเปลี่ยน)

สังเกต: ทุกตัวอย่างมี "แต่" — ค่าธรรมเนียม เวลา ความเสี่ยง → นี่คือเหตุผลที่ arb ไม่ได้ "ฟรี" จริงๆ

1.2 No-Arbitrage Principle

ถ้ามี Arbitrage opportunity → คนจะรีบทำ → ราคาจะ converge จนหมดโอกาส

  • ซื้อที่ A มาก → ราคา A ขึ้น (demand สูง)
  • ขายที่ B มาก → ราคา B ลง (supply สูง)
  • จนกว่า A ≈ B → Arb หายไป
No-Arbitrage Principle

"ในตลาดที่ทำงานปกติ Arbitrage opportunity จะหายไปอย่างรวดเร็ว เพราะ arbitrageurs เข้ามาทำกำไรจนราคา converge"

ผลลัพธ์: ถ้าสมมติว่าไม่มี arb → เราสามารถ หาราคาที่ถูกต้อง ของทุกสินทรัพย์ได้ (No-Arbitrage Pricing)

1.3 Law of One Price

"สินทรัพย์ที่ให้ payoff เดียวกันทุกสถานการณ์ → ต้องมีราคาเดียวกัน"

  • ทองที่ร้าน A = ทองที่ร้าน B → ราคาต้องเท่ากัน
  • Long Call + Short Put + Bond = Stock → ราคาต้องเท่ากัน (Put-Call Parity!)
  • SET50 Futures ≈ SET50 Spot × e^((r-d)T) → ราคาต้องสอดคล้องกัน
วิธีใช้ Law of One Price หา Arb

ทุกครั้งที่เห็นสินทรัพย์ ถามตัวเองว่า:
"มีวิธีอื่นสร้าง payoff เดียวกันไหม? ถ้ามี ราคาเท่ากันไหม?"
ถ้าราคาต่างกัน → อาจมี Arb!

  2. ทำไมราคาทองร้าน A กับร้าน B ต่างกันได้ ทั้งที่เป็นทองเหมือนกัน? อะไรทำให้ราคา converge?

1.5 บันไดสามขั้นของคำว่า Arbitrage — แน่ · แน่เมื่อ N → ∞ · แน่เมื่อ T → ∞

🚶 อ่านเป็นภาษาคนก่อน: คำว่า arbitrage ในตำราและในชื่อกลยุทธ์ไม่ได้แปลว่าสิ่งเดียวกัน · แบบแรกคือของจริงตาม §1.1 — กำไรแน่ ต้นทุนศูนย์ วันนี้ · อีกสองแบบเป็นคำกล่าวเชิงลิมิต: "ถ้ามีสินทรัพย์มากพอ ความเสี่ยงจะหายไป" (ลิมิตวิ่งไปทางจำนวนสินทรัพย์ N) กับ "ถ้าถือนานพอ โอกาสขาดทุนจะเข้าใกล้ศูนย์" (ลิมิตวิ่งไปทางเวลา T) · ทั้งสองแบบมีชื่อทางการ และทั้งสองแบบบอกสิ่งเดียวกันเมื่อ N กับ T เป็นเลขจำกัดอย่างในบัญชีจริง: สิ่งที่คุณถือคือความเสี่ยง ไม่ใช่ arb · หัวข้อนี้คือสะพานระหว่างเล่มนี้ (arb ของจริง) กับชุด stat-arb และ 2·D (arb ที่มีคำว่า statistical นำหน้า)

ขั้นชื่ออะไรต้องเป็นศูนย์ลิมิตวิ่งไปทางไหนเมื่อเลขจำกัด คุณถืออะไรบ้านในคลัง

2Asymptotic arbitrage

3Statistical arbitrage
Hogan, Jarrow, Teo & Warachka 2004		โอกาสที่กำไรสะสมติดลบ → 0T → ∞ เวลาที่ถือโอกาสขาดทุน ณ T จำกัด และโอกาสหมดตัวก่อนถึง T2 · D §9.1 pairs · ชุด stat-arb · Taxonomy Lv.4
ขั้น 2 — พอร์ตน้ำหนักเท่ากัน N ตัว แต่ละตัวมี noise เฉพาะตัว ε ที่ SD = σ_ε และเป็นอิสระกัน
    SD ของ noise รวม = σ_ε / √N   → 0 เมื่อ N → ∞   (ส่วนที่มาจากปัจจัยร่วมไม่หาย)

ขั้น 3 — กำไรสะสม v(T) ของกลยุทธ์ต้นทุนศูนย์ ต้องเป็นไปตาม
    v(0) = 0   ·   E[v(T)] > 0 เมื่อ T → ∞   ·   P(v(T) < 0) → 0 เมื่อ T → ∞
    ถ้ากำไรรายวันอิสระ ค่าเฉลี่ย μ SD σ:   P(v(T) < 0) = N(−(μ/σ)·√T)

📖 อ่านสูตรว่า: บรรทัดขั้น 2 อ่านว่า "ซิกมา-เอปไซลอน หารด้วย รากที่สองของเอ็น" — ε (เอปไซลอน) คือ residual ของ factor model ใน 2 · A §2.2 ส่วนที่ปัจจัยร่วมอธิบายไม่ได้ · √N อยู่ตัวหารเพราะ variance ของค่าเฉลี่ยของ N ตัวอิสระคือ σ²/N (สูตรเดียวกับ SE ของค่าเฉลี่ยใน 2 · C §6.2) · โครงที่ต้องเห็น: ขั้น 3 มีสามเงื่อนไข อ่านเรียงว่า "เริ่มจากศูนย์ · กำไรคาดหวังบวก · โอกาสติดลบไปศูนย์" — ตัวที่สามคือคำว่า arbitrage และมันมีคำว่า "เมื่อ T → ∞" ห้อยอยู่เสมอ · บรรทัดสุดท้าย N(·) คือ CDF ของ normal (ตัวเดียวกับ N(d) ในเล่ม Payoff — ไม่ใช่จำนวนสินทรัพย์ N ของขั้น 2 · สัญลักษณ์ชนกันในหัวข้อเดียว จึงต้องอ่านจากบริบท) · μ/σ คือ Sharpe ต่อหน่วยเวลา และ √T คือเหตุผลที่ต้องรอนาน: ความน่าจะเป็นลดตามรากที่สองของเวลา ไม่ใช่ตามเวลา · กับดักการอ่าน: ทั้งสองสูตรสมมติคำว่า "อิสระ" — ε ของหุ้นต่างตัวไม่สัมพันธ์กัน และกำไรแต่ละวันไม่สัมพันธ์กัน · วันที่ตลาดพัง ε ของทุกตัวไปทางเดียวกันและกำไรทุกวันติดลบพร้อมกัน สูตรทั้งสองจึงมองโลกดีเกินจริงในวันที่สำคัญที่สุด (ประเด็นเดียวกับ คิดแบบ Quant Part 4 เรื่องหาง) · ต้นฉบับของ Hogan และคณะมีเงื่อนไขที่สี่ทางเทคนิคเรื่อง variance ต่อเวลา ซึ่งไม่กระทบใจความสามข้อนี้

❌ สิ่งที่คำว่า "arbitrage" ในชื่อทำให้คนลืม

ลิมิตไม่ได้บอกทาง — P(v(T) < 0) → 0 พูดถึงจุดปลาย ไม่ได้พูดถึงหลุมระหว่างทาง · ที่ T = 100 วัน กำไรคาดหวัง 10% แต่ SD ของกำไรสะสมก็ 10% เท่ากัน ทางเดินที่ลงไปแตะ −10% ก่อนกลับมาเป็นบวกจึงเป็นเรื่องปกติ และถ้าขนาดไม้ทำให้ −10% นั้นคือหมดตัว คุณจะไม่อยู่ถึงลิมิต · นี่คือเหตุที่ คิดแบบ Quant Part 7 กับ Kelly ใน 2 · E §11.2 ต้องมาก่อนคำว่า arbitrage เสมอ

μ ต้องอยู่ครบ T — สูตรสมมติว่า edge วันแรกกับวันที่ 1,000 เท่ากัน · ของจริง edge เสื่อม (stat-arb: edge หาย หรือแค่ดวงซวย) และความสัมพันธ์ที่ pairs พึ่งขาดกลางทาง (2 · D §9.3) · เมื่อ μ เปลี่ยนเครื่องหมาย เงื่อนไขข้อสามพังทันที และการถือต่อ "เพราะมันคือ arb ในระยะยาว" กลายเป็นการเพิ่มขนาดของความผิด

N มากไม่ช่วยถ้า ε ไม่อิสระ — 30%/√100 = 3% ใช้ได้เมื่อ residual 100 ตัวไม่สัมพันธ์กัน · ในวิกฤต residual ทุกตัววิ่งไปทางเดียวกัน (correlation ของทุกอย่างพุ่งเข้าหา 1) ตัวหาร √N หายไปชั่วคราวในวันที่ต้องการมันที่สุด · LTCM ปี 1998 คือกรณีที่ทั้งสองลิมิตพังพร้อมกัน: convergence trade จำนวนมากที่ "ต้องบรรจบเมื่อ T → ∞" แต่ funding หมดก่อน และ "กระจายทั่วโลกแล้ว" แต่ทุกตำแหน่งขาดทุนพร้อมกัน — ทฤษฎีของ Quant · Part 3 การ์ด Limits to Arbitrage (Shleifer-Vishny 1997) อธิบายกลไกนี้เต็ม

✅ วิธีใช้บันไดนี้ในการพูดและการคิด

ก่อนเรียกอะไรว่า arb ให้ถามว่า "ลิมิตวิ่งไปทางไหน" · ถ้าคำตอบคือ "ไม่มีลิมิต" นั่นคือ Lv.1 ของ บทที่ 7 และคุณจะเจอมันไม่บ่อย · ถ้าคำตอบคือ N หรือ T ให้พูดเลขจำกัดออกมาแทนคำว่า arb: "ระบบ Sharpe ต่อวัน 0.1 ถือครบไตรมาส 63 วัน โอกาสไตรมาสติดลบ 21.4%" เป็นประโยคที่ตรวจได้ (แทน T = 63 ในสูตรข้างบน) และตั้งขนาดไม้ได้ ส่วน "statistical arbitrage" เป็นชื่อประเภทกลยุทธ์ ไม่ใช่คำอธิบายความเสี่ยง · นี่คือกฎเดียวกับกล่อง "อย่าเรียก Lv.3+ ว่า arbitrage" ในบทที่ 7 แต่คราวนี้มีเหตุผลทางคณิตศาสตร์รองรับว่าทำไม

บทที่ 2: เครื่องมือพื้นฐาน

2.1 Short Selling — ยืมมาขาย

"ซื้อถูกขายแพง" ทุกคนเข้าใจ แต่ Arb ต้องทำได้ทั้ง 2 ทิศ — ต้อง "ขายก่อนซื้อ" ได้ด้วย

Short Selling: ยืมหุ้นมา → ขาย → ซื้อคืนทีหลัง (หวังว่าราคาจะลง)
กำไร = ราคาขาย - ราคาซื้อคืน - ค่ายืม (borrow cost)

📖 อ่านสูตรว่า: "กำไร เท่ากับ ราคาขาย ลบ ราคาซื้อคืน ลบ ค่ายืม" · โครงที่ต้องเห็น: กำไรของ long คือ "ราคาขาย ลบ ราคาซื้อ" เหมือนกัน แต่ short แค่สลับลำดับเวลา — ขายก่อน ซื้อทีหลัง เครื่องหมายของกำไรจึงพลิกตามทิศราคา · กับดักการอ่าน: พจน์ที่สามไม่มีใน long — ค่ายืมเป็นต้นทุนที่เกิดเฉพาะฝั่ง short และคิดตามเวลาที่ถือ ยิ่งรอราคาลงนาน พจน์นี้ยิ่งกินกำไร

ทำไม Short Selling สำคัญสำหรับ Arb?

Arb ส่วนใหญ่ต้องทำ 2 ขาพร้อมกัน: ซื้อที่ถูก + ขายที่แพง
ถ้า "ที่แพง" คือสินทรัพย์ที่ยังไม่มี → ต้อง short sell
เช่น Conversion: Long Stock + Long Put + Short Call ← ต้อง "ขาย" Call ที่ไม่มี

ความเสี่ยงของ Short Selling
  • ขาดทุนไม่จำกัด: ราคาขึ้นได้ไม่มีเพดาน แต่คุณต้องซื้อคืน
  • Margin Call: ถ้าราคาขึ้นมาก broker อาจบังคับให้วางเงินเพิ่มหรือปิดสถานะ
  • Recall Risk: เจ้าของหุ้นอาจขอคืนเมื่อไรก็ได้ → ต้องหาหุ้นยืมใหม่หรือปิดสถานะ
  • Borrow Cost: ต้องจ่ายค่ายืมหุ้นทุกวัน → กิน profit ของ arb

บทที่ 3: คณิตศาสตร์ของ Arbitrage

3.1 No-Arbitrage Pricing

ถ้าสมมติว่าไม่มี arb → เราสามารถหาราคาที่ถูกต้องของทุกสินทรัพย์ได้

หลักการ

ถ้า Portfolio A และ Portfolio B ให้ payoff เท่ากันทุกสถานการณ์ ณ เวลา T:
→ ราคาวันนี้ต้องเท่ากัน
ถ้าไม่เท่ากัน → ซื้อถูก ขายแพง = Arbitrage

3.2 Replication Principle

"ราคาที่ถูกต้องของ X = ต้นทุนในการสร้าง X ขึ้นมาเอง (replicate)"

สินทรัพย์ XReplicate ด้วยสมการ

CallLong Stock + Long Put - BondC = S + P - PV(K)
Bond (PV(K))Long Stock + Long Put + Short CallPV(K) = S + P - C
ForwardLong Call + Short PutF = C - P (+ financing)

3.3 Bounds & Inequalities

แม้ไม่รู้ราคา exact แต่รู้ขอบเขตที่ราคาต้องอยู่ภายใน:

Call Bounds: max(0, S - Ke⁻ʳᵀ) ≤ C ≤ S
Put Bounds: max(0, Ke⁻ʳᵀ - S) ≤ P ≤ Ke⁻ʳᵀ
Spread: 0 ≤ C(K₁) - C(K₂) ≤ (K₂-K₁)e⁻ʳᵀ เมื่อ K₁ < K₂
Butterfly: C(K₁) - 2C(K₂) + C(K₃) ≥ 0 (Convexity)

📖 อ่านสูตรว่า: "ค่ามากสุดระหว่างศูนย์กับ เอส ลบ เค อี ยกกำลังลบอาร์ที น้อยกว่าหรือเท่ากับ ซี น้อยกว่าหรือเท่ากับ เอส" · โครงที่ต้องเห็น: ทุกบรรทัดเป็นอสมการ — บอกรั้ว ไม่บอกตำแหน่ง · บรรทัด Butterfly คือ "ผลต่างของผลต่าง": [C(K₃) − C(K₂)] − [C(K₂) − C(K₁)] ≥ 0 ถ้า C เป็นเส้นตรงใน K และ strike ห่างเท่ากัน ค่านี้เป็น 0 พอดี ความโค้งทำให้เป็นบวก · กับดักการอ่าน: C(K₁) วงเล็บหลัง C คือ "Call ที่ strike K₁" ไม่ใช่คูณ · ตัวห้อย 1, 2, 3 เป็นหมายเลข strike เรียงจากต่ำไปสูง ไม่ใช่เวลา · max(0, ·) เลือกค่าเดียวทิ้งอีกค่า จึงไม่มีทางติดลบ · e⁻ʳᵀ ต้องใช้ T เป็นปี

วิธีใช้ Bounds หา Arb
  1. คำนวณ bounds ก่อนดูราคาจริง
  2. ดูราคาจริง → อยู่ในหรือนอก bounds?
  3. นอก bounds = Arb ที่พิสูจน์ได้ทางคณิตศาสตร์ [Exact Identity]
  4. ใกล้ขอบ bounds = อาจเป็น Near-Arb หลังหักค่าธรรมเนียม

3.4 Put-Call Parity — สมการเริ่มต้นของทุกอย่าง

C + K·e⁻ʳᵀ = P + S

📖 อ่านสูตรว่า: "ซี บวก เค คูณ อี ยกกำลังลบอาร์ที เท่ากับ พี บวก เอส" — Call บวกเงินสดที่จะโตเป็น K พอดีวันหมดอายุ เท่ากับ Put บวกหุ้น · โครงที่ต้องเห็น: "ราคาเดียวกันสองทาง" — สองพอร์ตให้ payoff เหมือนกันทุกกรณี ราคาวันนี้จึงต้องเท่ากัน ต่างเมื่อไรคือกำไร · ลองแทน r = 0 สูตรย่อเป็น C + K = P + S อ่านง่ายที่สุด · กับดักการอ่าน: e⁻ʳᵀ คือตัวลดค่า (ยกกำลังลบ = หาร) แปลง K ในอนาคตเป็นบาทวันนี้ น้อยกว่า 1 เสมอเมื่อ r > 0 · r เป็น % ต่อปี ดังนั้น T ต้องเป็นปี (6 เดือน = 0.5) · อ่านที่มาเต็มได้ที่ เล่ม 1 Part I §2.2 และ §3.7

e⁻ʳᵀ คืออะไร?

e⁻ʳᵀ = "ตัวคูณลดค่า" (discount factor) — แปลงเงินในอนาคตเป็นมูลค่าวันนี้
ตัวอย่าง: K=100, r=5%, T=1 ปี → K·e⁻ʳᵀ = 100 × 0.9512 = ฿95.12
หมายความว่า: เงิน ฿100 ในอีก 1 ปี = เงิน ฿95.12 วันนี้ (เพราะฝาก 95.12 ดอกเบี้ย 5% จะได้ 100 พอดี)
อ่านละเอียดเพิ่มเติมในเล่ม "คณิตศาสตร์สำหรับ Options" บทที่ 3

สมการนี้คือ Law of One Price ของ Options (สำหรับ European Options ที่ไม่มี dividend, สมมติ short sell ได้และกู้ยืมที่ rate r ได้):

  • ซ้าย (Long Call + Bond) ให้ payoff = ขวา (Long Put + Stock) ทุกสถานการณ์
  • ถ้าซ้าย ≠ ขวา → ซื้อฝั่งถูก ขายฝั่งแพง = Conversion/Reversal Arbitrage
  • เป็น [Exact Identity] — จริงเสมอ ไม่มีเงื่อนไข (European options)
Epistemology Label: [Exact Identity]

Put-Call Parity เป็นความจริงทางคณิตศาสตร์ — ไม่ขึ้นกับ model, regime, หรือ platform
ต่างจาก "Funding rate จะกลับมา" ซึ่งเป็นแค่ [Heuristic] — จะเรียนการจำแนกในบทที่ 6

ลองคิดดู (บท 3)
  1. C=12, P=7, S=100, K=100, r=2%, T=1 → PV(K) = 100×e⁻⁰·⁰² = 98.02 → ซ้าย=12+98.02=110.02 ขวา=7+100=107 → มี arb ไหม? ทำอย่างไร?
  2. Call K=90 ราคา ฿15, Call K=100 ราคา ฿16 → ผิดปกติตรงไหน? (คำใบ้: monotonicity)

เฉลย: 1. ซ้าย>ขวา ฿3.02→Conversion (ซื้อขวา ขายซ้าย) 2. C(90)=15 < C(100)=16 → ผิด monotonicity! K ต่ำกว่าต้องแพงกว่า→ซื้อ C(90) ขาย C(100)
