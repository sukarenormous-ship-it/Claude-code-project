# เกณฑ์ตรวจสำนวนภาษา — Stat Arb for Non Quant · เล่ม 1

ใช้กับรอบตรวจสำนวนหลังเล่มผ่านรีวิวเนื้อหาแล้ว · เป้าหมาย: อ่านลื่นแบบหนังสือไทยที่คนทั่วไปอ่านจบ ไม่ใช่โน้ตย่อ
**ไม่เปลี่ยนเนื้อหา ตัวเลข กลไก หรือข้อสรุป** — แก้เฉพาะวิธีพูด

## ปัญหาที่พบบ่อยในเล่มนี้ (พร้อมตัวอย่างจริง)

1. **ภาษาโทรเลข — ตัดคำเชื่อมจนต้องเดา** (ปัญหาหลัก เกิดจากเบียดงบคำ)
   - เดิม: "คู่ไม่มีเชือก ไม่มีอะไรดึงระยะห่างกลับ คู่มีเชือก ระยะห่างถูกดึงกลับทุกวัน"
   - ดีขึ้น: "คู่ที่ไม่มีเชือกไม่มีอะไรดึงระยะห่างกลับ ส่วนคู่ที่มีเชือก ระยะห่างจะถูกดึงกลับทุกวัน"
   - เติม: ที่ · ซึ่ง · ส่วน · แต่ · เพราะ · จึง · คือ · ก็ · จะ — เท่าที่จำเป็นให้ประโยคมีประธาน–กริยา–ความสัมพันธ์ชัด
2. **ประโยคยาวต่อกันด้วยการเว้นวรรคอย่างเดียว** จนไม่รู้ว่าความคิดหนึ่งจบตรงไหน → แบ่งเป็นสองสามประโยค หรือขึ้นย่อหน้าใหม่ · หนึ่งย่อหน้าหนึ่งความคิด
3. **ใช้ "·" แทนคำเชื่อมในร้อยแก้ว** → ในย่อหน้าบรรยายให้ใช้คำเชื่อมหรือแยกประโยค · "·" เก็บไว้ใช้ในรายการสั้น ตาราง ป้าย คำบรรยายภาพ และใบงาน
4. **สำนวนแปล / คำแข็ง**: "ของจริงชั้นนี้" · "ได้ของ" (= คำสั่งได้รับการจับคู่ → "คำสั่งได้ครบ/ได้ราคา") · "ชี้ทางให้ถามต่อ" · "ถือเป็นการ…" · "ทำการ…" · "มีความ…" เกินจำเป็น · "ซึ่งมันคือ" → เลือกคำที่คนไทยพูดจริง
5. **คำนามเรียงต่อกันยาว** เช่น "ข้อกำหนดกลยุทธ์คู่การ์ดบทนี้ช่วงนี้" → กระจายเป็นวลีที่มีคำบุพบท/คำเชื่อม
6. **🚶 กลางย่อหน้า**: กล่อง/บรรทัด "🚶 อ่านเป็นภาษาคน:" ควรเป็นประโยคที่อ่านลื่นในตัว ไม่ใช่สรุปแบบโน้ต
7. **ระดับภาษาไม่คงที่**: เสียงเล่าเป็นกลางแบบหนังสือ (ไม่ใช่ภาษาแชตและไม่เป็นทางการแบบตำรา) · มินใช้ "เขา" · "คุณ" เฉพาะใน 🛑/✍️ (ตามคู่มือ) · หลีกเลี่ยง "ครับ/ค่ะ" ในเสียงเล่า (บทพูดของตัวละครในฉากใช้ได้)
8. **คำอังกฤษปน**: เว้นวรรครอบคำอังกฤษ · ศัพท์เทคนิคใช้กฎ CLAUDE.md: `English Term (คำแปลไทยตามตาราง)` ครั้งแรกต่อบท แล้วใช้อังกฤษต่อ · ห้ามกลับไปใช้ชื่อเดิมของเล่ม (แรงดึงกลับ · ระยะแกว่งปกติ · ค่าคาดหมาย · ของที่ได้ · ขนาดที่รับได้) ในร้อยแก้ว
9. **ตัวเลขในประโยค**: เลขกับหน่วยอ่านได้ไม่สะดุด เช่น "เสีย 15.98 ดอลลาร์" หรือ "เสีย 15.98" เมื่อหน่วยชัดแล้ว · ลบใช้ "−" (U+2212) ตามที่มี · ไม่ขึ้นประโยคด้วยตัวเลขเปล่า ๆ ถ้าทำให้งง
10. **วรรคตอนไทย**: ไม่ใช้จุด (.) ท้ายประโยคไทย · ไม่ใช้ ! ซ้อน · เครื่องหมายคำพูด " " ให้คู่กัน · ไม่มีเว้นวรรคซ้อน · ไม่เว้นวรรคหน้า ๆ และ ฯ ผิดที่

## กติกาเหล็ก (ห้ามละเมิด)

- ห้ามเปลี่ยนตัวเลข ห้ามแตะ `data-key` · `data-hook` · `data-claim` · `<!--src:-->` · `<!--CHART:-->` · id · class · markup ของ ✍️ / 📖 / ใบงาน / บัตร (ตัวตรวจพึ่ง)
- `data-hook` ของ .pq สะพานต้องยังปรากฏตรงตัวในฉากเปิดของบทถัดไป — ถ้าแก้ประโยคในฉากเปิด ต้องคงวลี hook ไว้ (ดู `tools/sab_bible.json`)
- ศัพท์ตาม CLAUDE.md และคำต้องห้าม (เล่มเดิม · ถอยสู่ค่าเฉลี่ย นอก data-allow · ไม่มีความเสี่ยง นอกเครื่องหมายคำพูด · seed บนเส้นทางหลัก · ส่วนต่าง สำหรับคู่ในบท 8+ ยกเว้นในวงเล็บคำแปลหลังศัพท์อังกฤษ) ยังบังคับ
- งบคำยังบังคับ: เส้นทางหลัก 1,750–2,300 · ทั้งหน้า ≤ 3,500 · หลายบทชิดเพดานแล้ว → **เติมคำเชื่อมได้เมื่อตัดคำซ้ำ/คำฟุ่มเฟือยที่อื่นพอกัน** (ลำดับตัด: ประโยคซ้ำความ → วงเล็บอธิบายที่บอกไปแล้ว → คำบรรยายกราฟยาว → ข้อความในใบงาน/🔎) · ห้ามตัดคำอธิบายกลไก
- ห้ามแก้ข้อความใน SVG ด้วยมือ (มาจาก `tools/sab_charts_ch/chNN.py`) — ถ้าป้าย/คำบรรยายกราฟสำนวนแย่ แก้ในไฟล์ปลั๊กอินนั้นแล้วรัน `--fill --scope`

## ตรวจหลังแก้ (ต่อบท)

```bash
python3 tools/sab_charts.py --fill --scope partN
python3 tools/sab_check_figures.py --scope partN
python3 tools/sab_qa.py --scope partN --final
node tools/sab_wordcount.mjs partN
```
และหลังแก้ครบทุกบทในชุด: `node tools/sab_render_check.mjs <หน้าที่แก้>`
