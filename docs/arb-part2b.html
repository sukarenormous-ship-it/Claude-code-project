Arbitrage ไม่ใช่ขาว-ดำ (มี/ไม่มี) แต่เป็น spectrum — จาก "แน่นอน 100%" ไปจนถึง "เดาอย่างมีหลักการ"

7.1 Position Sizing: Kelly Criterion

f* = (b×p - q) / b

b = odds (จ่ายเท่าไรต่อ 1 บาทที่เสี่ยง)
p = probability of winning
q = 1 - p = probability of losing

ในทางปฏิบัติ: ใช้ Half-Kelly (f*/2) เพราะ overestimate edge ง่ายกว่า underestimate

📖 อ่านสูตรว่า: "เอฟ-ดาว เท่ากับ บี คูณ พี ลบ คิว ทั้งหมดหารด้วย บี" — สัดส่วนของทุนที่ควรวางในแต่ละครั้ง · โครงที่ต้องเห็น: "ส่วนเกิน หารด้วย สเกล" — เศษ b·p − q คือกำไรคาดหวังต่อ 1 บาทที่เสี่ยง (edge) ส่วนคือขนาดรางวัล · ทดสอบ: เดิมพันยุติธรรม b·p = q ให้ f* = 0 ไม่เล่น · b = 1 (จ่ายเท่าตัว) ให้ f* = p − q ตรงตัว · กับดักการอ่าน: ดาว * คือ "ค่าที่ดีที่สุด" ไม่ใช่คูณ · q ไม่ใช่ตัวแปรอิสระ q = 1 − p เสมอ · b คือ "กำไรต่อ 1 บาทที่เสี่ยง" ตามนิยามในกล่อง ไม่ใช่ decimal odds ที่รวมทุนคืน · f* ติดลบ = อย่าเล่น ไม่ใช่ให้ short · เหตุที่ใช้ครึ่งเดียวอยู่ที่ เล่ม 2 · E §11.2–§11.3

ตัวอย่าง

Merger arb: Spread = ฿2.50 ถ้า deal สำเร็จ, เสีย ฿15 ถ้า fail
b = 2.50/15 = 0.167, p = 85%, q = 15%
f* = (0.167×0.85 - 0.15) / 0.167 = (0.142 - 0.15) / 0.167 = -0.05 → ไม่คุ้ม!
ถ้า p = 92%: f* = (0.167×0.92 - 0.08) / 0.167 = 0.074/0.167 = 0.44 → ใช้ 22% ของพอร์ต (Half-Kelly)

ลองคิดดู (บท 7)

Merger arb: spread ฿3 ถ้า deal สำเร็จ, เสีย ฿20 ถ้า fail → b=3/20=0.15, p=90% → Kelly f* = (0.15×0.9-0.1)/0.15 = ? คุ้มไหม?
เฉลย: f*=(0.135-0.1)/0.15 = 0.233 → Half-Kelly = 11.7% ของพอร์ต → คุ้ม แต่ size เล็ก

บทที่ 8: Non-Negative Design Principle

จาก quant-arb-engine: วิธีออกแบบ trade ที่ ขาดทุนสูงสุด = 0 (หรือใกล้ 0) by design

หลักการ

Non-Negative Structure = Locked Edge (core) + Income Layers (bounded loss)

กฎ: Max loss ของ income layers ทั้งหมดรวมกัน ≤ Locked Edge เสมอ

8.1 อะไรคือ Locked Edge?

InstrumentLocked?ทำไมEpistemology
Conversion (ครบทุกขา)✅ YesPCP [Exact Identity][Exact]
Dated Futures Basis✅ YesConverge at expiry[Exact]
Box Spread (European)✅ Yes= PV(width)[Exact]
Cross-Platform PM (same resolver)✅ YesYes+No=$1[Exact]
Funding Rate carry❌ NoRate flip ได้ทุกเมื่อ[Heuristic]
Credit Spread (VRP)❌ Noมี max loss scenario[Heuristic]
PM Tail Fade❌ NoTail event = full loss[Heuristic]

8.2 Sizing Rule

N_max = Locked_Edge / Max_Loss_Per_Contract

ตัวอย่าง: Locked Edge = ฿100, ขาย Put ที่ max loss = ฿25 ต่อสัญญา
N_max = 100 / 25 = 4 สัญญา (ขายมากกว่านี้ = ไม่ non-negative แล้ว!)

📖 อ่านสูตรว่า: "เอ็นแม็กซ์ เท่ากับ edge ที่ล็อกไว้ หารด้วย ขาดทุนสูงสุดต่อสัญญา" · โครงที่ต้องเห็น: อัตราส่วนหน่วยเดียวกัน — บาท หารด้วย บาทต่อสัญญา เหลือหน่วย "สัญญา" · 100/25 = 4 พอดี ถ้าได้ 4.7 ต้องปัดลงเป็น 4 เพราะสัญญาที่ 5 ทำให้ผลรวมติดลบได้ · กับดักการอ่าน: ขีดล่างใน Locked_Edge เชื่อมคำให้เป็นชื่อตัวแปรเดียว ไม่ใช่ตัวห้อย · Max_Loss ต้องเป็นขาดทุนกรณีเลวร้ายสุดของขา income ไม่ใช่ขาดทุนเฉลี่ย ไม่งั้นเงื่อนไข non-negative ไม่จริง

8.3 Complexity Tax

ทุกขาที่เพิ่มมีต้นทุน

Marginal cost ต่อขา ≈ 0.05-0.1% (fee + spread) + monitoring effort
กฎ: เพิ่ม N ขา → net edge ต้องเพิ่ม > N × marginal cost
ถ้าไม่ → ลดขาให้เหลือน้อยที่สุด → simple beats complex

9.4 Stage 5: VERIFY — 4 Gates

Gate 1: NUMBERS → Net profit > 0 หลังหักทุก cost?
Gate 2: BASELINE → ดีกว่า "ทำอะไรง่ายที่สุด" ไหม? (เช่น ฝาก Earn)
Gate 3: FEASIBILITY → Liquidity, settlement, margin พอไหม?
Gate 4: DATA → ข้อมูลครบ verified หมดไหม?

0 unverified → RECOMMENDATION
1 unverified → CONDITIONAL
2+ unverified → CANDIDATE (ยังไม่แนะนำ)
Baseline Comparison — ต้องทำทุกครั้ง!

"ทำ 3 ขา net 6% vs ฝาก Earn 1 ขา net 4%" → ถามว่า: 2% เพิ่มคุ้มกับความซับซ้อน 3 ขาไหม?
ถ้าไม่คุ้ม → ทำ Earn อย่างเดียว → simple wins

Stage 6b: MONITOR — หลัง execute ต้องทำอะไร?

1. ตั้ง Alert: ถ้า spread กว้างขึ้นเกิน threshold → แจ้งเตือน
2. Daily P&L check: ตรงกับที่คาดไหม? ถ้าผิดปกติ → investigate
3. Exit triggers: Spread converge ถึง target → ปิด | Regime เปลี่ยน → ปิด | Max holding period ครบ → ปิด
4. Journal: บันทึกทุก trade: ทำไมเข้า, ทำไมออก, กำไร/ขาดทุน, บทเรียน

10.2 Mental Models — กรอบคิดที่ช่วยเห็น Arb

Model 1: "สร้างเองได้ = รู้ราคา"

เห็นราคา → "สร้าง payoff เดียวกันด้วยวิธีอื่น cost เท่าไร?" → ถ้า cost ≠ ราคา → opportunity

Model 2: "ข้อมูลขัดแย้ง = โอกาส"

Prediction Market บอก 70% แต่ Options Implied Prob บอก 50% → ใครผิด? → investigate → trade

Model 3: "อะไรต้องเท่ากัน? เช็คแล้วจริงไหม?"

Daily Scan: PCP ✓ Box ✓ Basis ✓ Butterfly ✓ Monotonicity ✓ → ถ้าอันไหนไม่ผ่าน → dig deeper

Model 4: "ถ้าดีเกินไป พลาดอะไร?"

เจอ "arb 5% ต่อวัน" → Devil's Advocate 6 ข้อ → มักพบว่ามี hidden cost หรือ risk
