Feasibility First — "ตรวจก่อน trade"

แนวคิด: ทำไม payoff chart สวยแต่ trade ไม่ได้?

🚶 อ่านเป็นภาษาคนก่อน: ทุก payoff chart ที่วาดมาทั้งเล่มนี้ใช้ mid price (ราคากลาง) ซึ่งเป็นราคาสมมติที่ไม่มีใครเทรดได้จริง — ในสนามจริงคุณซื้อที่ ask (แพงกว่า) และขายที่ bid (ถูกกว่า) เสมอ ถ้าช่องว่างระหว่างสอง ราคานี้กว้าง กำไรที่เห็นบนกราฟอาจหายไปทั้งหมดก่อนจะเริ่มเทรดด้วยซ้ำ

🧮 ตัวอย่างการใช้งาน: Iron Condor "สวย"

Mid price: เก็บ premium ฿2.00 → max profit ฿2.00, max loss ฿8.00

แต่ถ้า execute จริง (4 legs × bid-ask spread ฿0.05):

Actual premium = 2.00 − 4×0.05 = ฿1.80

Slippage กิน 10% ของ max profit ไปแล้ว!

Baseline Test — บทเรียนสำคัญที่สุด

ก่อนเพิ่ม leg ที่ 3 ให้ถามก่อนว่า: "มันชนะ Bull Spread ธรรมดาจริงไหม?"

ตัวอย่าง: Iron Condor 4 legs → net premium ฿1.80 (หลังหัก costs) เทียบกับ Bull Call Spread 2 legs → net premium เท่ากัน ฿1.80 แต่ max profit สูงกว่า

→ ทำไมต้อง trade 4 legs ถ้า 2 legs ให้ผลดีกว่า? Complexity ต้องพิสูจน์ตัวเอง — ถ้า simple version ชนะ อย่าใช้ complex version

Anti-Pattern Library — "5 กับดักที่ดูดีแต่พัง"

🚶 อ่านเป็นภาษาคนก่อน: ทุก anti-pattern ต่อไปนี้เริ่มต้นด้วยกราฟหรือตัวเลขที่ดูน่าตื่นเต้นเสมอ — ratio สวย ได้เงินฟรี กำไรบ่อย ก่อนจะเจาะให้เห็นว่าต้นทุนหรือความเสี่ยงที่ซ่อนอยู่กินกำไรนั้นไปหมดหรือมากกว่านั้น

ทุก anti-pattern มีสิ่งเหมือนกัน: payoff chart ดูสวย แต่ reality ทำลาย edge

Anti-Pattern 1: "Beautiful Butterfly"

กับดัก: risk/reward 10:1 บน chart

สิ่งที่เห็น: Butterfly max profit ฿10, max loss ฿1 → ratio 10:1 สุดยอด!

สิ่งที่ซ่อน: 4 legs × bid-ask ฿0.05 = ฿0.20 → 20% ของ max profit หายไป และ probability ที่ราคาจบ "ตรง" center strike = ต่ำมาก (~5-10%)

EV จริง: 0.07 × (10−0.20) + 0.93 × (−1) = 0.686 − 0.93 = −0.244 → ขาดทุน!

บทเรียน: Risk/reward ratio สูง + probability ต่ำ = อาจมี negative EV

Anti-Pattern 2: "Calendar Spread Mirage"

กับดัก: "ได้ theta ฟรี"

สิ่งที่เห็น: ขาย front-month เก็บ theta, ถือ back-month ที่ยังมี value

สิ่งที่ซ่อน: Skew shift ระหว่าง expiry → IV ของ front อาจเพิ่มเร็วกว่า back โดยเฉพาะก่อน earnings/events → "theta ที่ได้" ถูก vega กิน

บทเรียน: Calendar Spread เดิมพันกับ term structure ไม่ใช่แค่ theta

Anti-Pattern 3: "Iron Condor in Low Vol"

กับดัก: "กำไร 80% ของเวลา"

สิ่งที่เห็น: VIX = 12, ขาย Iron Condor → เก็บ premium เล็ก ๆ ทุกเดือน

สิ่งที่ซ่อน: Premium เล็ก = reward เล็ก แต่ risk คงเดิม (width − premium) — 1 gap move ลบกำไร 8 เดือน → survivorship bias ทำให้ backtest ดูดี

บทเรียน: "กำไรบ่อย" ≠ "กำไรในระยะยาว" → คำนวณ EV ก่อนเสมอ (บทที่ 8)

สองกับดักที่ผ่านมาซ่อนต้นทุนไว้ในตัวเลข ส่วนสองกับดักถัดไปซ่อนความเสี่ยงไว้ในโครงสร้างของ position เอง:

Anti-Pattern 4: "Ratio Spread Free Money"

กับดัก: "ได้ premium ฟรี"

สิ่งที่เห็น: 1×2 Ratio Call Spread → net credit (ได้เงินตอนเปิด trade)

สิ่งที่ซ่อน: Net slope = −1 → unlimited loss ทางขวา! ถ้าราคาพุ่ง → Short 2 Calls ขาดทุนเร็วกว่า Long 1 Call ได้กำไร และ Margin call บังคับปิดตอนราคาสูงสุด = worst execution

บทเรียน: "ฟรี" ในตลาดไม่มีจริง → เช็ค net slope เสมอ (บทที่ 15)

Anti-Pattern 5: "Synthetic Arb Illusion"

กับดัก: "PCP violation = free money"

สิ่งที่เห็น: C + PV(K) ≠ P + S → violation ฿0.50!

สิ่งที่ซ่อน:

  • ใช้ mid price → executable price ต่างกัน (bid/ask กิน ฿0.30)
  • Early exercise risk (American options)
  • Pin risk ที่ strike
  • Borrow cost สำหรับ short stock
Net: ฿0.50 − ฿0.30 (spread) − ฿0.15 (borrow) = +฿0.05 → แทบไม่คุ้ม commission

บทเรียน: PCP violation บน screen ≠ executable arb → ต้องหัก costs ทั้งหมดก่อน

Anti-Pattern Summary

ทุก anti-pattern มีรูปแบบเดียวกัน:

  1. Payoff chart ดูดี → แต่ใช้ mid price
  2. Risk/reward ratio สวย → แต่ probability ไม่เอื้อ
  3. "ได้เงินฟรี" → แต่มี hidden risk ที่ chart ไม่แสดง

วิธีป้องกัน: ใช้ 5 Feasibility Checks ทุกครั้ง

Payoff chart ที่สวยที่สุด มักซ่อนต้นทุนที่แพงที่สุด — ทุก anti-pattern ในบทนี้เริ่มต้นด้วยกราฟที่ดูดีเกินจริงเสมอ

Execution Reality — "Edge ตายตรง bid/ask"

🚶 อ่านเป็นภาษาคนก่อน: ต่อให้ผ่าน 5 Feasibility Checks และรู้จัก anti-pattern ทั้ง 5 แบบแล้ว การ execute จริงยังมีวินัยที่ต้องทำตามเสมอ เพราะ order ที่ fill ผิดจังหวะแค่ไม่กี่วินาที ก็ทำให้ position ที่ปลอดภัยในทฤษฎีกลายเป็นความเสี่ยงจริงได้

กฎ 4 ข้อสำหรับ execution

กฎ 1: ซื้อ protective leg ก่อนเสมอ

เมื่อเปิด multi-leg strategy → ซื้อ protection ก่อน ขาย premium ทีหลัง

ถ้าขายpremium ก่อนแล้วตลาดขยับ → คุณมี naked position ชั่วคราว

ตัวอย่าง Iron Condor: ซื้อ wings (Long Put + Long Call) ก่อน → ค่อยขาย short legs

กฎ 2: ห้ามขาย naked ก่อนมี protection

Short Call ที่ไม่มี Long Call คุ้มกัน = unlimited risk แม้แค่ 1 วินาที

"แค่จะเปิดพร้อมกัน" → ไม่พร้อมกันจริงถ้า fill ไม่พร้อม

กฎ 3: ใช้ Limit Order เท่านั้น

Market Order สำหรับ options = ยอมรับราคาอะไรก็ได้ → อันตรายมาก โดยเฉพาะ illiquid strikes → bid-ask อาจกว้าง 20-50%

Limit Order: ตั้งราคาที่ยอมรับได้ → ไม่ fill ก็ไม่เป็นไร (ดีกว่า fill ที่ราคาแย่)

กฎ 4: monitor dynamic edge

Edge ที่เห็นตอน scan → อาจหายไปก่อน execute

ถ้า edge < 2× transaction cost → ไม่คุ้มเสี่ยง

ถ้าต้องรีบ fill → น่าจะเป็น edge ที่ทุกคนเห็นพร้อมกัน → อาจไม่ใช่ edge จริง

Structured Products — "ถอดรหัสผลิตภัณฑ์การเงิน"

🚶 อ่านเป็นภาษาคนก่อน: ผลิตภัณฑ์การเงินที่นักลงทุนไทยเจอบ่อย ไม่ว่าชื่อจะฟังดูซับซ้อนแค่ไหน ถอดออกมาแล้วก็คือ building blocks เดิมที่เรียนมาทั้งเล่มนี้ประกอบกันเท่านั้น

Equity-Linked Note (ELN)

ELN = Zero-Coupon Bond + Long Call

ถ้าราคาหุ้นลง → ได้เงินต้นคืน (bond component)  ·  ถ้าราคาหุ้นขึ้น → ได้เงินต้น + upside participation (call component)

Payoff chart: flat ทางซ้าย (เงินต้นคืน) → slope ขึ้นทางขวา (upside)

Convertible Bond

Convertible Bond = Straight Bond + Long Call

ถ้าราคาหุ้นต่ำ → ถือเป็น bond ปกติ (ได้ดอกเบี้ย + เงินต้น)  ·  ถ้าราคาหุ้นสูง → แปลงเป็นหุ้น (exercise the embedded call)

คล้าย ELN แต่มี coupon payments ระหว่างทาง

Risk Reversal — slope diagram

Risk Reversal = Short Put(K₁) + Long Call(K₂) โดย K₁ < K₂
วิธีวิเคราะห์ slope
  1. ก่อน K₁: slope +1 (จาก Short Put)
  2. K₁ ถึง K₂: slope 0 (Short Put หมดผล, Call ยังไม่เริ่ม)
  3. หลัง K₂: slope +1 (จาก Long Call)

Shape: ชันขึ้น → แบน → ชันขึ้น = "S-curve"

Net premium ≈ 0 (ถ้าเลือก strikes ให้ premium match) = zero-cost directional bet

Seagull — 3 legs สำหรับ FX hedging

Seagull = Bull Call Spread(K₂,K₃) + Short Put(K₁) โดย K₁ < K₂ < K₃
= Long Call(K₂) + Short Call(K₃) + Short Put(K₁)
วิธีวิเคราะห์ slope
  1. ก่อน K₁: slope +1 (Short Put)
  2. K₁ ถึง K₂: slope 0
  3. K₂ ถึง K₃: slope +1 (Long Call)
  4. หลัง K₃: slope 0 (Short Call cancel)

Net premium ≈ 0 (Short Put premium ชดเชย Bull Call Spread cost)

Shape: ขาดทุนถ้าลงแรง → flat → กำไรจำกัด → flat

ใช้ใน: FX hedging เมื่อต้องการ zero-cost + capped upside

Case Studies — "จาก belief → reject → redesign → final"

🚶 อ่านเป็นภาษาคนก่อน: เอาทุกเครื่องมือจากบทนี้ทั้งบท (feasibility checks, anti-pattern awareness, cross-market comparison) มาใช้จริงกับ 4 สถานการณ์ตัวอย่าง — ตั้งแต่ belief เริ่มต้น จนถึงว่าจะ trade หรือไม่ trade

Case 1: "Bullish but Capped" — ขึ้นแต่ไม่ทะลุ

Belief: "หุ้น XYZ จะขึ้นจาก 100 ไป 115 แต่ไม่น่าทะลุ 120"

Step 1 — แปลง belief → payoff: ต้องการกำไรถ้าขึ้น 100→115, ไม่ต้องการ exposure หลัง 120 → slope 0 → +1 at 100 → 0 at 120 = Bull Call Spread 100/120

Step 2 — Feasibility Check:

  • ✓ Bid/Ask: net debit ฿7.00 (mid ฿6.50 + spread ฿0.50) → max profit = 20−7 = ฿13
  • ✓ Baseline: ดีกว่า Long Call เปล่า (ลด cost, ลด vega risk)
  • ✓ Liquidity: ทั้ง 100 และ 120 strike มี volume
  • ✓ Stress: max loss = ฿7 (debit) → รับได้
  • ✓ Margin: debit trade → ไม่ต้อง margin

→ ผ่านทุกข้อ → TRADE

Step 3 — ทำไมไม่ใช้ Butterfly? Butterfly 100/110/120 → net debit ฿2 แต่ max profit เฉพาะ S=110 → probability ต่ำ ส่วน BCS → max profit ทั้งช่วง 120+ → Baseline Test: BCS ชนะ Butterfly

Case 2: "Protective Put + PM No" — hedge แบบ cross-market

Belief: "ถือหุ้น XYZ ฿100 อยากป้องกัน downside"

Option A: Long Put(90) → cost ฿3 → ป้องกันทุกบาทต่ำกว่า 90

Option B: PM Above No(90) → cost $0.25 → ถ้าราคาต่ำกว่า 90 ได้ $1 (สมมติอัตราแลกเปลี่ยน $1 ≈ ฿35 ในตัวอย่างนี้)

เปรียบเทียบ: ถ้า S จบที่ 70 → Put payoff ฿20 (หลังหักค่าตั๋ว ฿3 = ชดเชย stock loss ฿30 → net loss ฿13)

ถ้า S จบที่ 70 → PM No ได้ $1 = ฿35 → ชดเชย loss ฿30 ของ stock ได้พอดี แต่ถ้า S จบที่ 50 → stock loss ฿50, Put payoff ฿40 (ชดเชยตามสัดส่วน) แต่ PM ยังได้แค่ $1 คงที่ (ไม่ scale ตาม loss)

บทเรียน: PM (binary) ชดเชยได้ในบาง scenario แต่ ไม่ scale กับ loss → PM เหมาะเป็น income layer หรือ boundary repair ไม่ใช่ primary hedge

สองเคสแรกอยู่ในตลาด options ล้วน ๆ — สองเคสถัดไปข้ามไปตลาดอื่นที่เรียนไว้ใน Part IV เพื่อแสดงว่าหลักการเดียวกันใช้ข้ามตลาดได้จริง:

Case 3: "PM Range ที่พังเพราะ Overround"

Belief: "BTC จะอยู่ระหว่าง $90K-$100K สิ้นเดือน"

Strategy: ซื้อ PM Range Yes($90K-$100K) ที่ $0.35 — ถ้าถูก → ได้ $1 → profit $0.65 (186% return!)

แต่ตรวจ Overround: Range $80-90K: $0.20 + Range $90-100K: $0.35 + Range $100-110K: $0.30 + Range $110K+: $0.20 = sum $1.05 → overround 5%

Probability จริงของ $90-100K ≈ 0.35/1.05 = 33.3% (ไม่ใช่ 35%)
EV = 0.333 × ($1−$0.35) + 0.667 × (−$0.35) = 0.217 − 0.233 = −$0.017

→ Negative EV! Overround กิน edge ทั้งหมด

บทเรียน: ตรวจ overround ก่อนซื้อ PM → ถ้า sum > $1.03 → ระวัง

Case 4: "Funding Arb ที่ไม่ใช่ Arb"

Belief: "Funding rate = +0.05%/8hr = 'free yield'"

Strategy: Long spot + Short perp → เก็บ funding rate — Annualized = 0.05% × 3 × 365 = 54.75%/year! → ดู arb สุด ๆ

แต่ reality:

  • Funding rate เปลี่ยนได้ทุก 8 ชั่วโมง → อาจ flip เป็นลบ
  • เมื่อ flip → คุณ จ่าย funding แทนที่จะได้
  • ตอน funding สูง = ตลาด euphoria → crash probability สูง
  • ถ้า crash → spot loss + potential liquidation บน perp

Payoff analysis: Funding = conditional payoff ที่ขึ้นกับ regime ไม่ใช่ fixed yield = option-like payoff: ได้ตอน regime A, เสียตอน regime B → ไม่ใช่ arb → เป็น carry trade ที่มี regime risk

บทเรียน: "yield" ที่ดูฟรี = conditional payoff → ต้องวิเคราะห์ว่า condition จะ flip เมื่อไร
