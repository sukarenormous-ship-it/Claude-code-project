  • 🟢 ทางลัด (ขาดทุนอยู่ อยากรู้สาเหตุก่อน): คำตอบสั้นสามข้อด้านล่าง → ตอนที่ 1 → ตอนที่ 5 → ตอนที่ 8 แล้วย้อนไปตอนที่ 2–4 เมื่อเจอคำที่ยังไม่ชัด

สไลด์ที่เรียนมามีแปดแผ่น ทุกแผ่นถูกต้อง แต่แต่ละแผ่นข้ามคำถามสำคัญไปหนึ่งข้อ ชุดนี้แกะทีละแผ่น เติมคำถามที่หายไป แล้วให้คุณตรวจคำตอบด้วยมือตัวเอง ทั้งเรื่องมีภาพเดียวที่ใช้ตลอด คือ สายจูงยืดได้ (อธิบายสั้น ๆ ในหัวข้อ 🐕 ด้านล่าง)

คำตอบสั้นสามข้อที่คุณถามไว้

1 · ทำไม backtest ถึงขาดทุน

ผลขาดทุนแบบเดียวกันมาจากคนละโรคได้ จึงต้องตรวจตามลำดับที่ควรสงสัยก่อน ซึ่งเป็นลำดับด่านของคลินิกในตอนที่ 5 ตัวเลขทั้งหมดเป็น ข้อมูลจำลอง

  1. ไม่มีสายจูง: คู่ที่ผลตอบแทนเกาะกันแน่น (correlation ราว 0.9) แต่ไม่มีแรงดึงกลับได้ Sharpe เฉลี่ยราว 0.0 และกำไรแค่ราว 50% ของโลก คือโยนเหรียญที่ต้องจ่ายค่าผ่านทางทุกครั้ง
  2. คัดคู่แล้วให้คะแนนด้วยข้อมูลชุดเดียวกัน: สิบคู่ที่คัดด้วย Sharpe ของช่วงคัด (train) ได้ราว 2.3 แต่ในช่วงสอบ (test) เหลือราว 1 และถ้าสระมีแต่คู่ปลอม ราว 1.6 หดเหลือราว 0
  3. นาฬิกาเพี้ยน: โค้ดที่นับผลผิดแท่งทำให้คู่ที่มีสายจูงจริงได้ Sharpe ราว 0.6 แทนราว 1.6 ส่วนการมองอนาคตทำให้คู่ปลอมดูดี (0.7 แทน 0.0) จึงเพี้ยนได้ทั้งสองทาง
  4. ค่าผ่านทางแพงกว่ากำไรต่อไม้: สเปรดแคบ σ 0.5% ได้ Sharpe ราว 1.7 ก่อนต้นทุน แต่เหลือ −0.3 ที่ 20 bps ต่อขา กฎ walk-forward ต้องการ σ ราว 3.0 เท่าของ c แค่เพื่อเท่าทุน
  5. ดวง: แม้คู่แข็งแรงเต็มที่ ปีหนึ่งมีราว 3.4 ไม้ และ Sharpe ของปีเดียวแกว่งตั้งแต่ราว 0.4 ถึง 2.8

backtest ขาดทุนไม่ได้แปลว่าแพ้ มันบอกว่าป่วยตรงไหน ถ้าตรวจตามลำดับ: สายจูง → นาฬิกา → ค่าผ่านทาง → ดวง

→ อ่านต่อ ตอนที่ 5 คลินิก backtest · กำแพงระหว่างช่วงคัดกับช่วงสอบอยู่ใน ตอนที่ 8 · การประกอบ ε ให้ถูกอยู่ใน ตอนที่ 3

2 · ใช้มากกว่าสองสินทรัพย์ หรือทำเป็นพอร์ต ช่วยไหม และหลักการคืออะไร

ช่วยได้ ถ้ามีสายจูงอยู่แล้ว และช่วยด้วยสามเหตุผลที่ต่างกัน: A ตะกร้า หลายขาในสเปรดเดียว ทำให้สเปรดสะอาดขึ้น · B หลายสเปรดในพอร์ต (ความกว้าง หรือ breadth) ทำให้ผลรวมสม่ำเสมอขึ้น · C ทั้งสองอย่าง คือส่วนเหลือจากปัจจัย (factor residual)

ความกว้างเป็นตัวคูณ ไม่ใช่ตัวสร้าง สเปรดที่เป็นอิสระต่อกันและมี Sharpe 0.5 สิบเส้นรวมกันได้ราว 1.58 แต่ถ้ามันมักยืดพร้อมกัน (correlation ระหว่างสเปรด ρ ราวสามในสิบ) จะชนเพดาน S/√ρ ราว 0.91 ไม่ว่าจะเพิ่มกี่เส้น

ขอบที่เป็นลบก็ถูกคูณเหมือนกัน ในจักรวาลจำลองที่ไม่มีสายจูง สิบคู่ได้ Sharpe ราว 0.0 ส่วนพอร์ตส่วนเหลือจากปัจจัยได้ราว −0.8 หลังต้นทุน

พอร์ตส่วนเหลือจากปัจจัยชนะสิบคู่เฉพาะเมื่อสายจูงแข็งหรือปานกลางและต้นทุนต่ำ (สายจูงปานกลาง 1.6 เทียบ 1.3 · สายจูงอ่อน 0.1 เทียบ 0.3) เพราะมันหมุนเงินราว 14.2 เท่าต่อปี ขณะที่สิบคู่หมุนราว 4.4 เท่า ความนำจึงหายไปเมื่อต้นทุนต่อขาขึ้นไปราว 7 bps

สำหรับคนทุนน้อย บันไดคือ คู่แข็งหนึ่งคู่ → หุ้นเทียบตะกร้า → 10–30 สเปรดที่ผ่านทีละตัว → ส่วนเหลือจากปัจจัย และอย่าข้ามขั้น

→ อ่านต่อ ตอนที่ 6 มากกว่าสองตัว · ตลาดที่มีสายจูงแข็งกว่าคู่หุ้นอยู่ใน ตอนที่ 7

3 · เริ่มตรงไหนพรุ่งนี้

เริ่มจากไฟล์ฝึกมือที่เรารู้เฉลย ยังไม่ต้องแตะข้อมูลจริง เปิด terminal ที่โฟลเดอร์รากของ repo (ที่มีโฟลเดอร์ tools/) แล้วรันสี่คำสั่งนี้ตามลำดับ ทายผลก่อนรันทุกครั้งแล้วจดลงสมุด

python3 tools/statarb_lab.py make-demo demo.csv
python3 tools/statarb_lab.py check demo.csv --y Y_good --x X_good
python3 tools/statarb_lab.py scan demo.csv
python3 tools/statarb_lab.py basket demo.csv --y Y_good --basket X_good,X_drift,X_fake

รัน check ให้ครบทั้งสี่คู่ (good · drift · break · fake) และไปต่อเมื่อทายถูกทั้งสี่ และอธิบายได้ว่าแต่ละ ⚠️ ❌ มาจากอะไร สัปดาห์ถัดไปค่อยเลือกคู่จริงหนึ่งคู่ที่มีเหตุผลทางเศรษฐกิจผูกไว้ เขียนการ์ดจดกฎก่อนเปิดดูครึ่งหลัง แล้ว check ครั้งเดียวด้วยต้นทุนจริงของคุณ (ใส่ต้นทุนต่อขาต่อเที่ยวของคุณเอง: ค่าคอม + ภาษี + ครึ่งหนึ่งของ spread + ค่ายืมขา short — ดูจากใบยืนยันการซื้อขาย ตัวเลข 20 ด้านล่างเป็นแค่ตัวอย่าง):

python3 tools/sas_snippets/p8_power.py my.csv AAA BBB
python3 tools/statarb_lab.py check my.csv --y AAA --x BBB --cost-bps 20

🐕 สายจูงยืดได้ ในห้าประโยค

  1. ราคาสองตัวเหมือนหญิงเมาที่เดินกลับบ้านกับสุนัขของเธอ ต่างฝ่ายต่างเดินสุ่ม เดาไม่ได้ว่าจะไปทางไหน
  2. แต่ระยะห่างระหว่างทั้งสอง (ε) ไม่ไปไกลเรื่อย ๆ ยิ่งห่างยิ่งถูกดึงกลับแรง ส่วนสองคนที่แค่บังเอิญเดินไปทางเดียวกันไม่มีแรงนี้
  3. ภาพนี้มาจาก Murray (1994) “A Drunk and Her Dog” ใน The American Statistician ซึ่งใช้มันอธิบาย cointegration แบบเดียวกับที่ทางเดินของคนเมาใช้อธิบาย random walk
  4. ในเรื่องต้นฉบับสุนัขไม่ได้ถูกจูง ทั้งสองเรียกหากัน แล้วต่างฝ่ายต่างขยับเข้าหากันบางส่วน ซึ่ง Murray เรียกว่ากลไก error correction
  5. “สายจูงยืดได้” จึงเป็นชื่อเล่นของเราสำหรับแรงดึงกลับนั้น ซึ่งต้องเป็นแรงทางเศรษฐกิจที่อธิบายได้ (เราเรียกอีกชื่อว่า สมอ) และทั้งชุดคือการถามว่าสายนี้มีจริงไหม ยังอยู่ไหม และกำไรต่อรอบชนะค่าผ่านทางไหม
