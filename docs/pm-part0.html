Payoff Mastery

Part 0: First 30 Minutes — "วาดตามมือ"
อ่านสูตร payoff กี่รอบก็ลืม — แต่ถ้าวาดมันด้วยมือตัวเองสักครั้ง จะไม่มีวันลืมรูปทรงอีกเลย 4 ขั้นตอนต่อไปนี้ใช้เวลา 30 นาที แต่เป็นรากฐานของทุก Part ที่เหลือในเล่มนี้

🟢 มือใหม่: ทำตาม 4 ขั้นตอนวาดให้ครบ แล้วเล่น Flash Cards จนตอบไว — ข้ามกล่อง 🧠 มุมที่มองต่างได้ก่อน · 🔵 มีพื้นบ้างแล้ว: อ่านครบทุกกล่อง โดยเฉพาะโจทย์ข้อ 5 เรื่อง EV ที่มือใหม่มักพลาด

เล่มนี้ทั้งเล่มพูดด้วย "ภาษาภาพ" — ทุก strategy ที่จะเจอต่อจากนี้ถูกอธิบายผ่านรูปทรงของกราฟ payoff ไม่ใช่ชื่อที่ต้องท่องจำ ถ้าวาดไม่เป็นตั้งแต่ต้น ทุก Part ถัดไปจะกลายเป็นการท่องศัพท์ที่ลืมง่ายและไม่เชื่อมโยงกัน แต่ถ้าวาดเป็นก่อน คุณจะ "เห็น" ว่ากลยุทธ์ 2 ขาที่กำไรตอนราคาขึ้นกับกลยุทธ์ที่กำไรตอนราคาลง เป็นรูปทรงเดียวกันที่กลับด้าน หรือกลยุทธ์ 4 ขาก็แค่เอากลยุทธ์ 2 ขาสองแบบนั้นมาต่อกัน — ไม่ต้องท่องชื่อ แค่จำรูปทรงเป็นเลโก้ที่ต่อกันได้ (ชื่อจริงของแต่ละรูปทรงจะเจอในตาราง Flash Cards ท้าย Part นี้)

ก่อนเริ่ม: คำศัพท์ 3 ตัวที่ต้องรู้

S₀, Sₜ, K — แค่ 3 ตัว
  • S₀ = ราคาหุ้น (หรือสินทรัพย์) ตอนนี้ (วันที่เปิด trade)
  • Sₜ = ราคาหุ้น ตอนหมดอายุ (อนาคต — ไม่รู้ว่าจะเป็นเท่าไร)
  • K = ราคาใช้สิทธิ (Strike Price) — จุดที่ option เริ่ม "ทำงาน"

Payoff chart ใช้ Sₜ เป็นแกน X (ราคาตอนหมดอายุ) → ทุกจุดบนกราฟตอบคำถามเดียวกันเสมอ: "ถ้าราคาจบที่ Sₜ นี้ ผมกำไรหรือขาดทุนเท่าไร?"

Payoff vs Profit — ห้ามสับสน!

🚶 อ่านเป็นภาษาคนก่อน: ลองนึกภาพตั๋วเข้างาน — Payoff คือเงินรางวัลที่ได้จากงานนั้น ยังไม่หักค่าตั๋ว ส่วน Profit คือเงินที่เหลือเข้ากระเป๋าจริงหลังหักค่าตั๋ว (premium) ไปแล้ว สองคำนี้ต่างกันแค่ "หักค่าตั๋วหรือยัง" แต่คนจำนวนมากพลาดเพราะปนสองคำนี้เข้าด้วยกัน

Payoff = ผลตอบแทน ก่อนหัก ค่า premium
  Long Call payoff = max(Sₜ − K, 0)
Profit = ผลตอบแทน หลังหัก ค่า premium
  Long Call profit = max(Sₜ − K, 0) − premium

Premium ไม่เปลี่ยน shape/slope ของกราฟ — มันแค่เลื่อนทั้งเส้นขึ้นหรือลง:

จุดสำคัญ: Kink อยู่ที่ K แต่ Break-even อยู่ที่ K+P

Premium เลื่อนกราฟลง → จุดหักศอก (kink) ยังอยู่ที่ K=100 เหมือนเดิม แต่ จุดคุ้มทุน (break-even) ขยับไปที่ 105

ทุกกราฟในหนังสือนี้แสดง Profit (หลังหัก premium แล้ว) ยกเว้นระบุเป็นอย่างอื่น

🧠 มุมที่มือใหม่กับมือเก๋ามองต่าง

มือใหม่เห็น: "ราคาทะลุ K ปุ๊บ ผมกำไรแล้ว" (ดูจาก kink)
มือเก๋าเห็น: ทะลุ K แค่แปลว่า เริ่มขาดทุนน้อยลง — ต้องทะลุถึง K+P (break-even) ก่อนถึงจะเริ่มมีกำไรจริง ความสับสนนี้เป็นสาเหตุอันดับต้น ๆ ที่มือใหม่คำนวณจุดคุ้มทุนผิด

"First 30 Minutes" — 4 ขั้นตอน วาด Payoff Chart เป็น

ขั้นตอนที่ 1: วาด Long Call

Long Call = "สิทธิซื้อ" → จ่าย premium ฿5 เพื่อมีสิทธิซื้อที่ K=100

🚶 อ่านเป็นภาษาคนก่อน: เหมือนซื้อตั๋วเข้าเล่นเกม ถ้าราคาไม่ทะลุ K เกมจบคุณเสียแค่ค่าตั๋ว (premium) แต่ถ้าราคาทะลุ K ทุก ๆ 1 บาทที่ราคาขึ้นต่อจากนั้น คือกำไรของคุณเต็ม ๆ 1 บาท

วิธีวาด (ทำตามนี้)
  1. ลากเส้นแนวนอนที่ระดับ −5 (ขาดทุนเท่า premium) จากซ้ายจนถึง K=100
  2. ที่ K=100 หักเส้นขึ้น slope +1 (ทุก ฿1 ที่ราคาขึ้น = กำไร ฿1)
  3. เส้นตัดศูนย์ที่ K+P = 105 = break-even

ขั้นตอนที่ 2: พลิกเป็น Short Call

Short = กลับหัว Long → ไม่ต้องจำใหม่ แค่พลิกกราฟ!

🚶 อ่านเป็นภาษาคนก่อน: เอากราฟ Long Call ที่เพิ่งวาดไปพลิกกลับหัวลงล่าง (เหมือนพลิกโต๊ะ) — ตรงไหนที่เมื่อกี้คุณได้กำไร ตอนนี้คุณเสีย และตรงไหนที่เมื่อกี้เสีย ตอนนี้คุณได้ เพราะคุณสลับข้างจาก "คนซื้อสิทธิ" เป็น "คนขายสิทธิ"

ขั้นตอนที่ 2.5: วาด Long Put + Short Put

Long Put = "สิทธิขาย" → จ่าย premium เพื่อมีสิทธิขายที่ K — กำไรเมื่อราคาลง

🚶 อ่านเป็นภาษาคนก่อน: Long Put ตรงข้ามกับ Long Call ทุกอย่าง — Call กำไรตอนราคาขึ้นเหนือ K ส่วน Put กำไรตอนราคาลงต่ำกว่า K เหมือนวาดกราฟเดิมแล้วส่องกระจก (สลับซ้าย-ขวา)

วิธีวาด Long Put
  1. ลากเส้นแนวนอนที่ −P ทางขวา ของ K (ไม่ได้ใช้สิทธิ = เสีย premium)
  2. ที่ K หักเส้น ลง slope −1 ไปทางซ้าย (ยิ่งราคาลง ยิ่งกำไร)
  3. Break-even = K − P

Short Put = พลิก Long Put → ชันขึ้นทางซ้าย แบนทางขวา ("รับ premium แต่แบก downside ทั้งหมด" — รูปทรงเดียวกับ Covered Call)

ขั้นตอนที่ 3: รวม 2 ขา → Bull Call Spread

Long Call(100) + Short Call(110) → วาดทีละขา แล้วบวกรวม:

🚶 อ่านเป็นภาษาคนก่อน: เหมือนเอากราฟ 2 แผ่นมาวางซ้อนกันแล้วบวกความสูงของแต่ละจุด — ช่วงที่ทั้งสองเส้นยังแบน รวมกันก็ยังแบน แต่ช่วงที่ Long Call เริ่มชันขึ้นในขณะที่ Short Call ยังไม่หัก ผลรวมจะชันขึ้นตามไปด้วย จนกว่า Short Call จะเริ่มหักลงมาหักล้างกัน ผลลัพธ์สุดท้ายคือรูปทรง "แบน-ขึ้น-แบน"

วิธีวาด
  1. วาด Long Call(100) เส้นประ: แบน → หักขึ้นที่ 100
  2. วาด Short Call(110) เส้นประ: แบน → หักลงที่ 110
  3. บวก y-values ทุกจุด → ได้เส้นทึบ: แบน → ขึ้น → แบน = Bull Call Spread!

ขั้นตอนที่ 4: อ่านกลับ — เห็นรูป → บอกชื่อได้

ตอนนี้ดูรูป "แบน → ขึ้น → แบน" → คุณรู้ทันทีว่า = Bull Spread — นี่คือทักษะที่สำคัญที่สุดในเล่มนี้: อ่านรูปทรงแล้วบอกชื่อกลยุทธ์ได้ทันที โดยไม่ต้องท่องสูตร

🎯 3 อย่างที่ต้องจำจากขั้นตอนทั้ง 4
  • วาด Long Call จากสูตรได้: แบนที่ −P → หักขึ้นที่ K
  • Short = พลิกหัว Long เสมอ — ไม่ต้องจำสูตรใหม่
  • รวมหลายขา = บวก y-values ทุกจุด แล้ว "อ่านรูปกลับ" เป็นชื่อ strategy ได้

ทุกอย่างในหนังสือนี้ต่อจากนี้ใช้ 3 ทักษะนี้ซ้ำแล้วซ้ำอีก

🧭 นิสัยคิด: 3 คำถามที่ต้องถามทุกครั้งที่เจอกราฟใหม่

เจอกราฟ payoff หน้าไหนก็ตาม ถามตัวเอง 3 ข้อนี้เสมอ:

  • แบนตรงไหน?
  • หักที่ไหน? (K อยู่ตรงไหน)
  • ชันขึ้นหรือลง? (slope เท่าไร)

ตอบ 3 ข้อนี้ได้ครบ แปลว่าอ่านกราฟนั้นเป็นแล้ว

✍️ ลองทำเอง: ก่อนไปต่อ ปิดหนังสือแล้ววาด Long Call, Short Call, และ Bull Call Spread ใหม่ด้วยมือตัวเองบนกระดาษ — ถ้าวาดครบ 3 รูปได้ภายใน 2 นาทีโดยไม่ดูเฉลย แปลว่าพร้อมไปต่อ

"ได้ยินวาดได้" — โจทย์ 5 ข้อ

อ่านโจทย์ → วาดกราฟในหัว (หรือบนกระดาษ) ก่อนดูเฉลย

โจทย์ 1: "ซื้อ Long Put K=100, premium=6"

คิด: Long Put = ชันลงทางซ้าย, แบนทางขวา

เฉลย: แบนที่ −6 หลัง K → ชันลง (slope −1) ก่อน K → BE = K−P = 94 → กำไรสูงสุดที่ S=0 = 100−6 = ฿94

โจทย์ 2: "ทำ Bear Put Spread: Long Put(110) ฿8, Short Put(100) ฿3"

คิด: Bear = ลง, Spread = จำกัดทั้งกำไรและขาดทุน → "แบน → ลง → แบน"

เฉลย: net debit = 8−3 = ฿5 → max loss = −5 (ราคาเกิน 110) → max profit = (110−100)−5 = +5 (ราคาต่ำกว่า 100)

โจทย์ 3: "ทำ Long Straddle K=100, Call premium=5, Put premium=5"

คิด: Straddle = V-shape → ขาดทุนถ้านิ่ง, กำไรถ้าผันผวน

เฉลย: trough ที่ K=100, max loss = −10 (2×premium) → BE = 90 และ 110 → กำไรไม่จำกัดทั้งสองทิศ

โจทย์ 4: "คิดว่าราคาจะนิ่งอยู่ระหว่าง 90-110 → ออกแบบ payoff"

คิด: กำไรตรงกลาง ขาดทุนสองข้าง → "ที่ราบสูง" = Iron Condor

เฉลย: Long Put(85) + Short Put(90) + Short Call(110) + Long Call(115) — เขียนย่อ LP(85) + SP(90) + SC(110) + LC(115) → เก็บ premium ถ้าราคาอยู่ระหว่าง 90-110

ตัวย่อ LP/SP/SC/LC = Long Put / Short Put / Short Call / Long Call จะใช้เขียนย่อแบบนี้ตลอดทั้งเล่ม

📉 เมื่อทฤษฎีพังจริง — โจทย์ 5: "เพื่อนบอกว่า 'ขาย Iron Condor ได้ 80% ของเวลา = easy money'"

คิด: Payoff ≠ Prediction! กำไรบ่อย ≠ กำไรระยะยาว

เฉลย: 80% ชนะ ฿2 + 20% แพ้ ฿8 → EV = 0.8×2 + 0.2×(−8) = 1.6−1.6 = 0 → ไม่มี edge เลย ต่อให้ "ชนะบ่อย" ก็ตาม

"ก่อนดูกราฟ ต้องคิด EV ด้วยเสมอ" — ชนะบ่อยไม่ได้แปลว่ามี edge ถ้าตอนแพ้ครั้งเดียวกินคืนกำไรที่สะสมมาทั้งหมด
