ตอน ก ขาที่สามด้วยมือ · 1 — สองเงื่อนไขพร้อมกัน: เหรียญ D ที่ beta 2 ทำให้มูลค่าสุทธิและ beta exposure เป็นศูนย์ทั้งคู่

เริ่มจากปัญหาที่เล่ม 1 ทิ้งไว้ มินถือ A มูลค่า 1,000 ดอลลาร์ และ short B มูลค่า 1,000 ดอลลาร์ ทวนก่อนว่า Beta (ค่าเบต้า) ที่เล่ม 1 บท 8 สอนบอกว่าเหรียญขยับกี่เท่าของตลาด A มี beta 1.5 ส่วน B มี beta 1

คู่นี้มีมูลค่าสุทธิศูนย์ เพราะซื้อ 1,000 และขาย 1,000 แต่แรงตลาดของสองขาไม่เท่ากัน ขา A รับแรงตลาด 1.5 × 1,000 หรือ 1,500 ส่วนขา B คืนแรงตลาดได้แค่ 1,000 จึงเหลือ beta exposure 500 ถ้าตลาดลง 4% คู่นี้จะเสีย −20 ดอลลาร์ ทั้งที่ไม่มีอะไรเกิดกับเชือกเลย

เล่ม 1 ลองแก้ด้วยการเพิ่มขา B เป็น 1,500 ดอลลาร์ แรงตลาดหายไปก็จริง แต่มูลค่าสุทธิกลายเป็น −500 คือแก้ข้อหนึ่งแล้วอีกข้อพัง ด้วยเหรียญแค่สองตัว เราตั้งขนาดได้แค่ขาเดียว (ขา A ตรึงไว้ที่ 1,000) จึงทำให้เป็นศูนย์ได้ทีละเงื่อนไขเท่านั้น

ทีนี้เพิ่มเหรียญที่สามชื่อ D ซึ่งมี beta 2 เรามีสองขาที่ตั้งขนาดได้ คือขา B กับขา D จึงเขียนเงื่อนไขได้สองข้อ ใช้เครื่องหมายบวกแทนการถือซื้อและเครื่องหมายลบแทน short

สิ่งที่เพิ่งทำคือการลากเส้นที่ใช้ตัวอธิบายมากกว่าหนึ่งตัวพร้อมกัน เรียกว่า Multiple Regression (การถดถอยหลายตัวแปร) หลักการเดิมทุกอย่างของบท 1 คือหาน้ำหนักชุดที่ทำให้ผลรวมกำลังสองของระยะพลาดต่ำสุด ต่างกันแค่ชามมีหลายมิติ ตัวอย่างนี้ง่ายเพราะ dB กับ dD ไม่เกี่ยวกันเลย ข้อมูลจริงไม่เคยเป็นแบบนั้น เครื่องจึงต้องหาน้ำหนักทุกตัวพร้อมกัน ที่มาเป็นสมการสองบรรทัดอยู่ใน 🔎 ท้ายบท

🚶 อ่านเป็นภาษาคนก่อน: X ของตะกร้าคือส่วนของ A ที่เหลือหลังหักส่วนที่ตาม B และส่วนที่ตาม D ออกแล้ว น้ำหนักแต่ละตัวคือจำนวนที่หักออกต่อการขยับหนึ่งหน่วยของเหรียญนั้น

X ของตะกร้า = log A − ค่าตัดแกน − น้ำหนักของ B × log B − น้ำหนักของ D × log D

อ่านสมการ: วันที่ 5 dA เป็น 5 หักส่วนที่ตาม B คือ 0.5 × 4 เท่ากับ 2 และส่วนที่ตาม D คือ 0.5 × 4 เท่ากับ 2 เหลือ X ของตะกร้า 1 ตรงกับตาราง (ค่าตัดแกนหายไปเพราะเราวัดจาก Mean ไว้แล้ว)

น้ำหนักบน log ราคาแปลเป็นเงินได้ตามบท 2 คือเป็นสัดส่วนของเงิน ถ้าถือ A 1,000 ดอลลาร์ ต้อง short B 0.5 × 1,000 หรือ 500 ดอลลาร์ และ short D อีก 500 ดอลลาร์ ตะกร้าชุดนี้บังเอิญมีมูลค่าสุทธิ 0 เพราะน้ำหนักรวมกันได้หนึ่งพอดี การถดถอยไม่ได้สัญญาเรื่องนี้ ตะกร้าจริงในตอน ค จะไม่เป็นกลางต่อมูลค่าเลย

import sab2_stats as S
dB = [-2, 4, -2, -2, 4, -2]
dD = [-6, -4, -2, 2, 4, 6]
dA = [-3, -1, -3, 1, 5, 1]
pair = S.ols(dB, dA)                       # คู่ A บน B (บท 1)
bask = S.ols_multi([dB, dD], dA)           # ตะกร้า A บน B กับ D
ssr = lambda r: sum(e * e for e in r["residuals"])
print(round(pair["slope"], 2), round(ssr(pair), 2))
print(round(bask["coef"][1], 2), round(bask["coef"][2], 2), round(ssr(bask), 2))

เส้นนั้นหาได้แบบเดียวกับบท 3 คือสร้างโลกที่ไม่มีเชือกเลย ให้ทุกเหรียญเดินสุ่มอิสระกัน ยาวเท่าช่วงเลือก แล้วถดถอยเหรียญแรกบนเหรียญที่เหลือ ทดสอบ X ที่ได้ ทำซ้ำหลายพันโลก ค่าที่มีโลกเพียง 5% ทำได้ติดลบกว่า คือเส้น 5% ของจำนวนเหรียญนั้น

อ่านภาพ: แกนนอนคือจำนวนเหรียญในตะกร้า (นับเหรียญซ้ายด้วย) แกนตั้งคือค่าสถิติ แท่งยาวลงคือเส้น 5% ยิ่งยาวยิ่งผ่านยาก เส้นประเขียวคือเส้นของคู่ที่บท 3 ใช้ เส้นประแดงคือค่าสถิติของตะกร้าเก้าเหรียญที่ต้นส่งมา

ในภาพนี้ให้ดูว่าแท่งยาวขึ้นทุกครั้งที่เพิ่มเหรียญ จาก −3.32 ที่สองเหรียญ ไปถึง −5.39 ที่เก้าเหรียญ และเส้นแดงอยู่ใต้เส้นเขียวแต่ยังไม่ถึงปลายแท่งม่วง สรุปได้ว่าตะกร้าของต้นผ่านเส้นของคู่ แต่ไม่ผ่านเส้นของจำนวนเหรียญที่ตัวเองใช้

แท่งของสองเหรียญได้ −3.32 ใกล้กับ −3.34 ของตารางที่บท 3 ใช้ ส่วนแท่งของสามเหรียญได้ −3.75 ตรงกับตารางที่ตีพิมพ์ชุดเดียวกับที่บท 3 ใช้ (ของ MacKinnon) ที่ −3.75 การที่สองทางตรงกันบอกว่าโลกจำลองของเราวัดเส้นได้ถูก ตารางที่ตีพิมพ์มีถึงแค่ไม่กี่เหรียญ ตะกร้าที่ใหญ่กว่านั้นเล่มนี้ใช้โลกจำลองอย่างเดียว

กลับมาที่ตะกร้าของต้น เขาถดถอย BTC บนอีกแปดเหรียญที่ไม่ใช่ LTC ได้ค่าสถิติ −5.02 ซึ่งติดลบกว่าเส้นคู่ −3.34 มากจริง แต่ตะกร้าของเขามี 9 เหรียญ เส้น 5% ของเก้าเหรียญคือ −5.39 และในโลกเดินสุ่มที่ไม่มีเชือกเลย มีราว 14% ที่ทำได้ดีกว่า −5.02 ค่า p ของตะกร้านี้จึงราว 0.14 ไม่ผ่าน คำถามข้อแรกของพี่ฝนได้คำตอบแล้ว

การถดถอยแบบนี้ยังมีจุดอ่อนอีกสองข้อที่ควรรู้ ข้อแรกเหมือนบท 1 คือผลขึ้นกับว่าเหรียญไหนอยู่ซ้าย ตะกร้าสามเหรียญจึงทดสอบได้สามทิศ และแต่ละทิศให้ค่าสถิติไม่เท่ากัน ข้อสองคือมันหาเชือกได้ทีละเส้น ถ้าสามเหรียญมีเชือกสองเส้นพร้อมกัน เช่น A กับ B ผูกกัน และ B กับ D ก็ผูกกันด้วย การถดถอยจะเห็นแค่ส่วนผสมของสองเส้นนั้น

นักวิจัยจึงมีการทดสอบอีกแบบที่มองทุกเหรียญพร้อมกันโดยไม่ต้องเลือกเหรียญซ้าย และตอบว่าในกลุ่มนี้มีเชือกอิสระกี่เส้น ในสามเหรียญคำตอบเป็นได้ศูนย์ หนึ่ง หรือสองเส้น การทดสอบนี้เรียกว่า Johansen Test (การทดสอบโจแฮนเซน) มันมีตารางเส้นตัดสินของตัวเอง ซึ่งก็เลื่อนตามจำนวนเหรียญเช่นกัน เพราะเหตุผลเดียวกับเหรียญมั่ว E

เครื่องมือของเล่มยังไม่มี Johansen บทนี้จึงสอนเป็นแนวคิด แล้วใช้การถดถอยหลายตัวแปรที่คิดตามได้ด้วยมือ คู่กับเส้นตัดสินของจำนวนเหรียญที่ถูกต้อง และทดสอบทั้งสามทิศพร้อมนับว่าเป็นการทดสอบสามครั้ง ผู้ที่เขียนโค้ดเรียก Johansen ได้จากไลบรารี statsmodels (คำสั่งชื่อ coint_johansen) แต่ควรลองกับโลกที่รู้คำตอบของตอน ค ก่อนเชื่อผลกับข้อมูลจริง

💻 ทำด้วย Python 
from sab2_realdata import load_closes
import sab2_stats as S
_, f = load_closes("formation")
L = {c: S.logs(p) for c, p in f.items()}
others = [c for c in L if c not in ("BTC", "LTC")]   # แปดเหรียญ
eg = S.engle_granger_multi(L["BTC"], [L[c] for c in others])
pair_line = S.adf_crit(730, 2)["5%"]                 # เส้นของคู่ (บท 3)
sim = S.adf_pvalue_sim(eg["stat"], 731, worlds=1000, n_vars=9)
print(round(eg["stat"], 2), round(pair_line, 2))
print(round(sim["crit"]["5%"], 2), round(sim["pvalue"], 2))
# ผลที่ต้องได้: −5.02 · −3.34 · −5.39 · 0.14

import math
from sab2_realdata import load_closes
import sab2_stats as S
from sab2_engine import run_basket
_, f = load_closes("formation")
_, v = load_closes("validation")
y, xs = "XRP", ["BTC", "BNB"]
L = lambda p: S.logs(p)
eg = S.engle_granger_multi(L(f[y]), [L(f[x]) for x in xs])
w, m, s = eg["weights"], S.mean(eg["residuals"]), S.sd(eg["residuals"])
z = [(math.log(v[y][t]) - sum(wi * math.log(v[x][t]) for wi, x in zip(w, xs))
      - eg["intercept"] - m) / s for t in range(len(v[y]))]
p0 = f[y][-1]                                    # ราคาวันสุดท้ายของช่วงเลือก
units = [1.0] + [-wi * p0 / f[x][-1] for wi, x in zip(w, xs)]
r = run_basket([v[y]] + [v[x] for x in xs], units, z, sets=500 / p0)
print(round(eg["stat"], 2), round(r["net"], 1), round(r["costs"], 1))

สมการก้นชามเมื่อมีสองเหรียญที่ใช้อธิบาย ให้ X เท่ากับ dA − b × dB − d × dD ที่ก้นชาม ผลรวมของ X × dB และผลรวมของ X × dD ต้องเป็นศูนย์ทั้งคู่ ซึ่งเขียนเป็นสมการสองบรรทัดได้คือ b × Σ dB² + d × Σ dB·dD = Σ dB·dA และ b × Σ dB·dD + d × Σ dD² = Σ dD·dA

เมื่อ Σ dB·dD เป็นศูนย์แบบหกวันสอน สองบรรทัดแยกกันได้ และได้ b เท่ากับ 24 ÷ 48 กับ d เท่ากับ 56 ÷ 112 ทันที ข้อมูลจริงต้องแก้สองบรรทัดพร้อมกัน (หรือ k บรรทัดเมื่อมี k เหรียญ) ซึ่งคือสิ่งที่ ols_multi และ LINEST ทำ

Johansen ทำอะไร แทนที่จะถดถอยเหรียญหนึ่งบนเหรียญที่เหลือ Johansen ดูการขยับรายวันของทุกเหรียญพร้อมกัน แล้วหาว่ามีกี่ทิศทาง (กี่ชุดน้ำหนัก) ที่ระดับราคาในทิศนั้นถูกดึงกลับ คำตอบคือจำนวนเชือกอิสระ เช่นศูนย์ หนึ่ง หรือสองในสามเหรียญ ผลไม่ขึ้นกับว่าเหรียญไหนอยู่ซ้าย และให้น้ำหนักของทุกเชือกพร้อมกัน ข้อเสียคือคิดด้วยมือไม่ได้ และไวต่อจำนวน lag ที่เลือก เล่มนี้จึงยังไม่ใช้กับตัวเลข

ทำไมเส้นตัดสินเลื่อน ในโลกที่ไม่มีเชือก การถดถอยบน k เหรียญเลือกน้ำหนักที่ทำให้ X แคบที่สุดจากทุกทางที่เป็นไปได้ ยิ่ง k มาก ยิ่งมีทางให้เลือกมาก X ที่ได้จึงดูนิ่งกว่าเส้นเดินสุ่มทั่วไป ค่ามัธยฐานของค่าสถิติในโลกเดินสุ่มเลื่อนจาก −2.09 ที่สองเหรียญ ไปถึง −4.2 ที่เก้าเหรียญ ตารางของ MacKinnon ที่บท 3 ใช้มีค่าสำหรับหลายเหรียญด้วย เช่นเส้น 1% ของสามเหรียญคือ −4.31

ตะกร้าที่ผ่านด้วย PCA อีกวิธีที่พบบ่อยคือหา PCA ของ log ราคาแล้วใช้ทิศที่แกว่งน้อยที่สุดเป็นน้ำหนักของตะกร้า วิธีนี้ไม่ต้องเลือกเหรียญซ้ายเช่นกัน แต่ทิศที่แกว่งน้อยที่สุดในช่วงเลือกคือทิศที่ "ดูนิ่งที่สุด" โดยการเลือก จึงมีปัญหาเหรียญมั่วแบบเดียวกัน และต้องใช้เส้นตัดสินจากโลกจำลองที่ทำขั้นตอนเดียวกันทุกขั้น
