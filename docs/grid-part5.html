Sizing & Risk: Kelly Criterion สำหรับ Grid

การกำหนดขนาด Position อย่างเหมาะสมด้วย Kelly Criterion และ Fractional Kelly — สมดุลระหว่างการเติบโตของ Portfolio กับ Drawdown ที่ยอมรับได้
🔄

กำลังเตรียมเนื้อหา...

Part นี้อยู่ระหว่างการเขียน — กลับมาตรวจสอบเร็วๆ นี้

เนื้อหาในตอนนี้จะครอบคลุม

  • Kelly Criterion คืออะไร: สูตรหา Optimal Bet Size เพื่อ Maximize Growth Rate
  • การแปลง Kelly เข้าสู่ Grid Context: Grid ไม่ใช่ Binary Bet
  • Fractional Kelly (f* × 0.25–0.5): ลด Variance โดยยอมสละ Growth บางส่วน
  • การประมาณ Win Rate และ Win/Loss Ratio จาก Grid Backtest
  • Kelly สำหรับ Multiple Simultaneous Grid: แบ่ง Capital ระหว่าง Grid หลาย Pair
  • Maximum Drawdown Constraint: กำหนด Kelly ให้ Max DD ไม่เกิน X%
  • Volatility-adjusted Sizing: ลด Size เมื่อ Vol สูงขึ้น
  • Portfolio-level Risk: Correlation ระหว่าง Grid ต่างๆ ใน Portfolio
  • ตัวอย่างการคำนวณ: จาก Backtest Stats สู่ Kelly Fraction จริง
