บทที่ 1: พื้นฐาน — อ่าน Payoff Chart ให้เป็น

Payoff Chart คืออะไร?

Payoff Chart (กราฟผลตอบแทน) คือกราฟที่แสดง กำไรหรือขาดทุนสุทธิ ของตำแหน่ง Options ณ วันหมดอายุ (expiration) โดยเทียบกับราคาสินทรัพย์อ้างอิง (underlying asset) ที่เป็นไปได้ทุกระดับ กราฟนี้เป็นเครื่องมือสำคัญที่สุดในการทำความเข้าใจ Options เพราะมันแปลงสูตรที่ซับซ้อนให้กลายเป็นภาพที่เข้าใจได้ทันที

องค์ประกอบของกราฟ

  • แกน X (แนวนอน) = ราคาสินทรัพย์อ้างอิง ณ วันหมดอายุ (S) — แสดงทุกสถานการณ์ราคาที่เป็นไปได้
  • แกน Y (แนวตั้ง) = กำไร/ขาดทุนสุทธิ (Profit/Loss) — ค่าบวกคือกำไร ค่าลบคือขาดทุน
  • เส้นศูนย์ (Zero Line) = เส้นแนวนอนที่ Y = 0 แบ่งกราฟเป็นโซนกำไร (ด้านบน) และโซนขาดทุน (ด้านล่าง)
  • จุดคุ้มทุน (Break-even Point) = จุดที่เส้น Payoff ตัดกับเส้นศูนย์ — ณ จุดนี้ไม่กำไรไม่ขาดทุน

องค์ประกอบสำคัญที่ต้องรู้

Strike Price (ราคาใช้สิทธิ์) — K

คือราคาที่ตกลงไว้ล่วงหน้าว่าจะซื้อ/ขายสินทรัพย์อ้างอิง เป็นจุดที่กราฟ "หักศอก" (kink point) เพราะเป็นจุดที่พฤติกรรมของ Option เปลี่ยนจาก out-of-the-money เป็น in-the-money

Premium (ค่าพรีเมียม) — P

คือราคาที่ผู้ซื้อจ่ายให้ผู้ขายเพื่อได้สิทธิ์ ถือเป็น ต้นทุน ของผู้ซื้อ (จุดเริ่มต้นบนแกน Y จะอยู่ที่ -Premium) และเป็น รายได้ ของผู้ขาย (จุดเริ่มต้นบนแกน Y จะอยู่ที่ +Premium)

Break-even Point (จุดคุ้มทุน)

สำหรับ Call Option: Break-even = K + P (ราคาต้องขึ้นไปเกิน Strike + Premium จึงจะเริ่มกำไร)
สำหรับ Put Option: Break-even = K - P (ราคาต้องลงต่ำกว่า Strike - Premium จึงจะเริ่มกำไร)

Intrinsic Value (มูลค่าแท้จริง)

คือส่วนที่ Option อยู่ In the Money — มูลค่าที่จะได้จริงถ้าใช้สิทธิ์ตอนนี้
Call Intrinsic = max(0, S - K) | Put Intrinsic = max(0, K - S)

Time Value (มูลค่าเวลา)

Time Value = Premium - Intrinsic Value = "ความหวัง" ที่ว่าราคาอาจจะเคลื่อนเข้ามาใน In the Money ก่อนหมดอายุ ยิ่งเหลือเวลามาก Time Value ยิ่งสูง

จำไว้!

Payoff Chart ณ วันหมดอายุ: Time Value = 0 ดังนั้นเส้น Payoff จะเป็น เส้นตรงหักศอก เสมอ (piecewise linear) ไม่มีเส้นโค้ง! ความเรียบง่ายนี้ทำให้เราวิเคราะห์ได้ง่าย

บทที่ 2: Building Blocks — 4 ตำแหน่งพื้นฐาน

กลยุทธ์ Options ทุกอย่างในโลกนี้สร้างจากการรวมกันของ 4 ตำแหน่งพื้นฐาน ถ้าเข้าใจ 4 ตำแหน่งนี้อย่างถ่องแท้ คุณจะสามารถวิเคราะห์กลยุทธ์ใดก็ได้

2.1 Long Call — ซื้อสิทธิ์ซื้อ

หลักการ: คุณจ่ายเงิน (Premium) เพื่อซื้อ สิทธิ์ (ไม่ใช่ภาระผูกพัน) ในการซื้อสินทรัพย์อ้างอิงในราคา K ภายในวันหมดอายุ ใช้เมื่อคุณเชื่อว่าราคาจะ ขึ้น

สูตร Payoff

Payoff = max(0, S - K) - Premium

ถ้า S ≤ K: Payoff = -Premium (ไม่ใช้สิทธิ์ เสียแค่ค่า Premium)
ถ้า S > K: Payoff = S - K - Premium (ใช้สิทธิ์ซื้อที่ K แล้วขายที่ S)

รายการค่า
Max Profit (กำไรสูงสุด)ไม่จำกัด (Unlimited) — ราคาขึ้นได้ไม่มีเพดาน
Max Loss (ขาดทุนสูงสุด)Premium — จำกัดแค่เงินที่จ่ายไป
Break-evenK + Premium
รูปร่างแบนที่ -P ทางซ้ายของ K แล้วลาดขึ้น 45°
เปรียบเทียบ: "ตั๋วรถไฟ"

ลองนึกว่าคุณซื้อตั๋วรถไฟราคา P บาท ถ้ารถไฟออก (ราคาขึ้นเกิน K) คุณก็ได้โดยสารไปด้วยกับขบวนราคาที่พุ่งขึ้น กำไรไม่จำกัด! แต่ถ้ารถไฟไม่ออก (ราคาไม่ถึง K) คุณก็เสียแค่ค่าตั๋ว — จบ ไม่เจ็บตัวมาก

คำถามชวนคิด

ถ้า Premium แพงมาก จุด Break-even จะยิ่งห่างจาก K — หมายความว่าราคาต้องขึ้นมากกว่าจึงจะเริ่มกำไร คุณยังอยากซื้อไหม? นี่คือเหตุผลที่ Premium (และ Implied Volatility) สำคัญมาก

2.2 Short Call — ขายสิทธิ์ซื้อ

หลักการสำคัญ: Short = พลิก Long กลับหัว (mirror through zero line) คุณ ขาย สิทธิ์ซื้อให้คนอื่น แล้วรับ Premium เป็นรายได้ คุณมี ภาระผูกพัน ที่จะต้องขายสินทรัพย์ที่ราคา K ถ้าผู้ซื้อใช้สิทธิ์

สูตร Payoff

Payoff = Premium - max(0, S - K) = -1 × Long Call Payoff

รายการค่า
Max ProfitPremium — ได้แค่ค่า Premium ที่รับมา
Max Lossไม่จำกัด (Unlimited!) — อันตรายมาก!
Break-evenK + Premium
เปรียบเทียบ: "บริษัทประกัน"

คุณเป็นเหมือนบริษัทประกัน เก็บเบี้ย (Premium) ทุกปี ส่วนใหญ่ลูกค้าไม่เคลม (ราคาไม่ขึ้นเกิน K) คุณก็ได้กำไรเรื่อยๆ แต่ถ้าเกิดเหตุร้ายแรง (ราคาพุ่งสูงมาก) คุณอาจต้องจ่ายมหาศาล ความเสี่ยงไม่จำกัด!

คำเตือน

Naked Short Call (ขาย Call โดยไม่มีสินทรัพย์อ้างอิง) ถือเป็นตำแหน่งที่มีความเสี่ยงสูงที่สุดใน Options เพราะขาดทุนได้ไม่จำกัด นักลงทุนมือใหม่ไม่ควรใช้!

2.3 Long Put — ซื้อสิทธิ์ขาย

หลักการ: คุณจ่ายเงิน (Premium) เพื่อซื้อ สิทธิ์ในการขาย สินทรัพย์อ้างอิงในราคา K ภายในวันหมดอายุ ใช้เมื่อคุณเชื่อว่าราคาจะ ลง

สูตร Payoff

Payoff = max(0, K - S) - Premium

ถ้า S ≥ K: Payoff = -Premium (ไม่ใช้สิทธิ์ เสียแค่ค่า Premium)
ถ้า S < K: Payoff = K - S - Premium (ซื้อที่ S ในตลาด แล้วใช้สิทธิ์ขายที่ K)

รายการค่า
Max ProfitK - Premium — กำไรสูงสุดเมื่อราคาลงไปเป็น 0
Max LossPremium — จำกัดแค่เงินที่จ่ายไป
Break-evenK - Premium
รูปร่างลาดลงจากซ้าย (slope -1) แล้วแบนที่ -P ทางขวาของ K
เปรียบเทียบ: "ประกันอัคคีภัย"

Long Put เหมือนซื้อประกันไฟไหม้ คุณจ่ายเบี้ยประกัน (Premium) ทุกปี ถ้าบ้านไม่ไหม้ (ราคาไม่ลง) คุณเสียแค่เบี้ย แต่ถ้าบ้านไหม้ (ราคาร่วง) ประกันจ่ายชดเชย — ยิ่งเสียหายมาก ยิ่งได้คืนมาก

คำถามชวนคิด

ทำไม Max Profit ของ Long Put ไม่ใช่ "ไม่จำกัด" เหมือน Long Call? เพราะราคาสินทรัพย์ต่ำสุดได้แค่ 0 ดังนั้น Max Profit = K - Premium (เมื่อ S = 0)

2.4 Short Put — ขายสิทธิ์ขาย

หลักการ: ใช้หลัก "พลิกกราฟ" เดียวกับ Short Call คุณขายสิทธิ์ขายให้คนอื่น รับ Premium แต่มีภาระผูกพันที่จะต้อง ซื้อ สินทรัพย์ที่ราคา K ถ้าผู้ซื้อใช้สิทธิ์

สูตร Payoff

Payoff = Premium - max(0, K - S) = -1 × Long Put Payoff

รายการค่า
Max ProfitPremium — ได้แค่ค่า Premium ที่รับมา
Max LossK - Premium — ขาดทุนสูงสุดเมื่อราคาลงไปเป็น 0
Break-evenK - Premium
เปรียบเทียบ: "รับจ้างซื้อหุ้น"

Short Put เหมือนคุณบอกว่า "ถ้าหุ้นลงมาถึง K ผมยินดีซื้อ" แล้วมีคนจ่ายเงินให้คุณเพื่อรับประกันนั้น ถ้าหุ้นไม่ลง — ได้เงินฟรี ถ้าหุ้นลง — ก็ต้องซื้อจริงตามที่รับปาก

ตารางสรุป 4 ตำแหน่งพื้นฐาน

ตำแหน่ง Max Profit Max Loss Break-even รูปร่าง ใช้เมื่อ
Long Call Unlimited Premium K + P แบน แล้วลาดขึ้น คาดว่าราคาขึ้น
Short Call Premium Unlimited K + P แบน แล้วลาดลง คาดว่าราคาไม่ขึ้น
Long Put K - P Premium K - P ลาดลง แล้วแบน คาดว่าราคาลง
Short Put Premium K - P K - P ลาดขึ้น แล้วแบน คาดว่าราคาไม่ลง

2.5 Put-Call Parity — ความสัมพันธ์ระหว่าง Call กับ Put

สมการ Put-Call Parity

C + PV(K) = P + S

หรือเขียนแบบเต็ม: C + K·e-rT = P + S

โดยที่ C = ราคา Call, P = ราคา Put (Strike เดียวกัน, หมดอายุเดียวกัน), S = ราคาสินทรัพย์ปัจจุบัน, K = Strike, r = อัตราดอกเบี้ย, T = เวลาจนหมดอายุ

พิสูจน์ ณ วันหมดอายุ

สร้าง 2 Portfolio แล้วดูว่าให้ผลลัพธ์เท่ากัน:

  • Portfolio A: Long Call + เงินสด K (ฝากธนาคาร)
  • Portfolio B: Long Put + Long Stock (S)

กรณี S > K (ราคาขึ้น):

  • Portfolio A: ใช้สิทธิ์ Call ได้ (S - K) + เงินสด K = S
  • Portfolio B: Put ไม่มีค่า (0) + หุ้น S = S

กรณี S < K (ราคาลง):

  • Portfolio A: Call ไม่มีค่า (0) + เงินสด K = K
  • Portfolio B: ใช้สิทธิ์ Put ได้ (K - S) + หุ้น S = K

ทั้งสองกรณีให้ผลลัพธ์ = max(S, K) เท่ากัน! ดังนั้นวันนี้ราคาต้องเท่ากัน: C + PV(K) = P + S

ความหมายเชิงลึก

Call กับ Put คือ เหรียญเดียวกัน สองด้าน — ถ้ารู้ราคา Call ก็คำนวณราคา Put ได้ และกลับกัน ถ้าสมการไม่เท่ากัน จะเกิด Arbitrage Opportunity (โอกาสทำกำไรโดยไม่มีความเสี่ยง)

หมายเหตุสำคัญ

Put-Call Parity ใช้ได้กับ European Options เท่านั้น (ใช้สิทธิ์ได้แค่วันหมดอายุ) สำหรับ American Options (ใช้สิทธิ์ได้ก่อนหมดอายุ) จะเป็นอสมการแทน

2.6 Synthetic Positions — ตำแหน่งสังเคราะห์

จาก Put-Call Parity เราสามารถจัดรูปสมการใหม่เพื่อสร้าง ตำแหน่งสังเคราะห์ (Synthetic) ที่ให้ Payoff เหมือนกับตำแหน่งจริง:

จัดรูปจาก: C + PV(K) = P + S

Synthetic Long Stock = Long Call + Short Put (Strike & Expiry เดียวกัน)
    S = C - P + PV(K)

Synthetic Long Call = Long Stock + Long Put
    C = S + P - PV(K)

Synthetic Long Put = Short Stock + Long Call
    P = C - S + PV(K)

ทำไมต้องใช้ Synthetic?

  • ต้นทุนต่ำกว่า: บางครั้ง Synthetic ถูกกว่าตำแหน่งจริง เนื่องจากความแตกต่างของ bid-ask spread
  • ยืมหุ้นไม่ได้: ถ้าต้องการ Short Stock แต่ยืมหุ้นไม่ได้ ใช้ Synthetic Short Stock (Short Call + Long Put) แทน
  • Arbitrage: ถ้าราคา Synthetic ไม่เท่ากับราคาจริง สามารถทำกำไรจากส่วนต่างได้

บทที่ 3: หลักการรวม — การบวก Payoff

หลักการบวก Payoff (Payoff Addition Principle)

Payoff รวม = ∑ Payoff แต่ละขา ณ ทุกจุดราคา

กลยุทธ์ Options ทุกกลยุทธ์ ไม่ว่าจะซับซ้อนแค่ไหน ล้วนเกิดจากการ บวกเส้น Payoff ของแต่ละขา (leg) เข้าด้วยกัน ณ ทุกจุดราคา ไม่มีเวทมนตร์ใดในกลยุทธ์ Options — ทุกอย่างคือการบวกเส้นตรง!

วิธีวิเคราะห์รูปร่างจากความชัน (Slope Analysis)

แทนที่จะคำนวณทีละจุด เราสามารถวิเคราะห์ ความชัน (slope) ของแต่ละส่วนได้เร็วกว่า:

ตำแหน่ง ผลต่อ Slope ณ จุดไหน
Long Call (K) +1 ต่อ slope ที่ Strike K (เริ่มเพิ่มทางขวา)
Short Call (K) -1 ต่อ slope ที่ Strike K (เริ่มลดทางขวา)
Long Put (K) +1 ต่อ slope ที่ Strike K (ทางซ้ายของ K มี slope -1 พอผ่าน K ไปทางขวากลายเป็น 0)
Short Put (K) -1 ต่อ slope ที่ Strike K (ทางซ้ายของ K มี slope +1 พอผ่าน K ไปทางขวากลายเป็น 0)
เคล็ดลับ: อ่านรูปร่างจาก Slope

เริ่มจากซ้ายสุดของกราฟ แล้วเดินไปทางขวา ทุกครั้งที่ผ่าน Strike:

  • Long Call ที่ K → slope เพิ่ม +1
  • Short Call ที่ K → slope ลด -1
  • Long Put ที่ K → slope เพิ่ม +1 (ทางซ้ายของ K มี slope -1 ซึ่งหายไปเมื่อผ่าน K)
  • Short Put ที่ K → slope ลด -1 (ทางซ้ายของ K มี slope +1 ซึ่งหายไปเมื่อผ่าน K)

สรุปสั้น ๆ: Long Option ทุกตัวเพิ่ม slope +1 ที่ Strike ของมัน และ Short Option ทุกตัวลด slope -1 ไม่ว่าจะเป็น Call หรือ Put สิ่งที่ Put ต่างออกไปคือ slope ตั้งต้นที่ซ้ายสุดของกราฟ: Long Put แต่ละตัวทำให้เริ่มที่ -1 และ Short Put แต่ละตัวทำให้เริ่มที่ +1 (ถ้ามีแต่ Call ซ้ายสุดเริ่มที่ 0)

วิธีนี้ช่วยให้คุณวาดรูปร่าง Payoff ได้โดยไม่ต้องคำนวณทุกจุด!

ตัวอย่าง: Bull Call Spread ด้วย Slope Analysis

Long Call K₁=100 + Short Call K₂=110:

  • ซ้ายสุด (S < 100): slope = 0 (ยังไม่ผ่าน strike ใด)
  • ผ่าน K₁=100 (Long Call): slope = 0 + 1 = +1 (ลาดขึ้น)
  • ผ่าน K₂=110 (Short Call): slope = +1 - 1 = 0 (แบนอีกครั้ง)

ผลลัพธ์: แบน → ลาดขึ้น → แบน = รูปร่าง "บันไดขึ้น" !

บทที่ 4: Named Strategies — "พจนานุกรม" ที่ต้องรู้

เมื่อเข้าใจหลักการรวม Payoff แล้ว มาดูกลยุทธ์ที่มีชื่อเรียกกันทั่วไป แต่ละกลยุทธ์คือ การรวม 4 ตำแหน่งพื้นฐาน ในรูปแบบต่างๆ เท่านั้น

4.1 Bull Call Spread — "บันไดขึ้น"

ส่วนประกอบ

Long Call K₁ + Short Call K₂ (โดย K₂ > K₁)

แนวคิด: คุณเชื่อว่าราคาจะขึ้นแต่ ไม่มากเกินไป จึงซื้อ Call ที่ Strike ต่ำ (เพื่อทำกำไรจากขาขึ้น) แล้วขาย Call ที่ Strike สูง (เพื่อลดต้นทุน แลกกับการจำกัดกำไรสูงสุด)

Net Premium = P₁ - P₂ (จ่ายสุทธิ เพราะ P₁ > P₂)
Max Profit = (K₂ - K₁) - Net Premium
Max Loss = Net Premium
Break-even = K₁ + Net Premium
รายการค่า
Max Profit(K₂ - K₁) - Net Premium
Max LossNet Premium (จำกัด)
Break-evenK₁ + Net Premium
มุมมองตลาดModerately Bullish (ราคาจะขึ้นปานกลาง)

4.2 Bear Put Spread — "บันไดลง"

ส่วนประกอบ

Long Put K₂ + Short Put K₁ (โดย K₂ > K₁)

แนวคิด: "กระจกสะท้อน" ของ Bull Call Spread คุณเชื่อว่าราคาจะลงแต่ไม่มากเกินไป ซื้อ Put ที่ Strike สูง แล้วขาย Put ที่ Strike ต่ำเพื่อลดต้นทุน

Net Premium = P₂ - P₁ (จ่ายสุทธิ เพราะ Put ที่ K₂ แพงกว่า)
Max Profit = (K₂ - K₁) - Net Premium
Max Loss = Net Premium
Break-even = K₂ - Net Premium
รายการค่า
Max Profit(K₂ - K₁) - Net Premium
Max LossNet Premium (จำกัด)
Break-evenK₂ - Net Premium
มุมมองตลาดModerately Bearish (ราคาจะลงปานกลาง)

4.3 Long Straddle — รูป "V"

ส่วนประกอบ

Long Call K + Long Put K (Strike เดียวกัน)

แนวคิด: คุณเชื่อว่าราคาจะ เคลื่อนไหวมาก แต่ไม่รู้ว่าจะขึ้นหรือลง เช่น ก่อนประกาศงบ, ก่อนการเลือกตั้ง, ก่อนการตัดสินใจนโยบาย

Total Premium = PCall + PPut
Max Loss = Total Premium (เกิดที่ S = K พอดี)
Max Profit = Unlimited (ขาขึ้น) หรือ K - Total Premium (ขาลง)
BE บน = K + Total Premium
BE ล่าง = K - Total Premium
รายการค่า
Max Profitไม่จำกัด (ขาขึ้น) / K - Total Premium (ขาลง)
Max LossTotal Premium (ณ S = K)
BE บนK + Total Premium
BE ล่างK - Total Premium
มุมมองตลาดHigh Volatility คาดการณ์ (ไม่รู้ทิศทาง)
ข้อควรระวัง

Straddle มีต้นทุนสูง (ซื้อทั้ง Call และ Put) ดังนั้นราคาต้องเคลื่อนไหว มากพอ ที่จะเกินจุด Break-even ทั้งสองด้าน ถ้าราคานิ่ง คุณจะขาดทุนจาก Time Decay ทั้ง 2 ขา!

4.4 Long Strangle — รูป "V กว้าง / U"

ส่วนประกอบ

Long Put K₁ + Long Call K₂ (K₁ < K₂, ทั้งคู่ OTM)

แนวคิด: เหมือน Straddle แต่ ถูกกว่า เพราะซื้อ OTM Options แลกกับต้องการการเคลื่อนไหวราคามากกว่าจึงจะกำไร

ต้นทุน (Premium)สูงกว่าต่ำกว่า
Max LossTotal PremiumTotal Premium (ต่ำกว่า)

4.5 Iron Condor — "ที่ราบสูง"

ส่วนประกอบ (4 ขา)

Bull Put Spread + Bear Call Spread

= Long Put K₁ + Short Put K₂ + Short Call K₃ + Long Call K₄

(K₁ < K₂ < K₃ < K₄ โดยปกติ K₂ และ K₃ ใกล้ ATM)

Bull Put Spread คือ Long Put K₁ + Short Put K₂ ส่วน Bear Call Spread คือ Short Call K₃ + Long Call K₄

แนวคิด: คุณเชื่อว่าราคาจะ นิ่ง อยู่ในกรอบ K₂ ถึง K₃ รับ Premium จากการขาย แล้วซื้อ Options ด้านนอกเพื่อจำกัดความเสี่ยง

Net Credit = Premium รับ (Short Put K₂ + Short Call K₃) - Premium จ่าย (Long Put K₁ + Long Call K₄)
Max Profit = Net Credit (เมื่อ K₂ ≤ S ≤ K₃)
Max Loss = Width of spread - Net Credit = (K₂ - K₁) - Net Credit
BE ล่าง = K₂ - Net Credit
BE บน = K₃ + Net Credit
รายการค่า
Max ProfitNet Credit
Max Loss(K₂ - K₁) - Net Credit (จำกัด!)
มุมมองตลาดNeutral / Low Volatility
ข้อดีDefined risk ทั้ง 2 ด้าน, Probability of profit สูง

4.6 Butterfly Spread — "เต็นท์"

ส่วนประกอบ

Long Call K₁ + Short 2× Call K₂ + Long Call K₃

(K₁ < K₂ < K₃ โดย K₂ = (K₁+K₃)/2 คือจุดกึ่งกลาง)

แนวคิด: คุณมั่นใจว่าราคาจะ จบตรงจุดเดียว (K₂ พอดี) กำไรสูงสุดเกิดที่ K₂ และลดลงอย่างรวดเร็วเมื่อออกห่าง

พิสูจน์ด้วย Slope Analysis

  • S < K₁: slope = 0
  • ผ่าน K₁ (Long Call): slope = 0 + 1 = +1
  • ผ่าน K₂ (Short 2× Call): slope = +1 - 2 = -1
  • ผ่าน K₃ (Long Call): slope = -1 + 1 = 0

ผลลัพธ์: แบน → ขึ้น → ลง → แบน = รูป "เต็นท์" หรือ "หมวก"!

Net Premium = P₁ - 2×P₂ + P₃ (จ่ายสุทธิ)
Max Profit = (K₂ - K₁) - Net Premium (ณ S = K₂)
Max Loss = Net Premium
BE ล่าง = K₁ + Net Premium
BE บน = K₃ - Net Premium
รายการค่า
Max Profit(K₂ - K₁) - Net Premium (ณ S = K₂ พอดี)
Max LossNet Premium (จำกัด)
มุมมองตลาดNeutral / Pin to specific price

บทที่ 5: Greeks — อะไรทำให้ Payoff เปลี่ยนก่อนหมดอายุ

จนถึงตอนนี้เราดูแต่ Payoff ณ วันหมดอายุ (เส้นตรงหักศอก) แต่ในโลกจริง Options มีมูลค่าที่เปลี่ยนแปลงทุกวัน Greeks คือตัวเลขที่บอกว่า ราคา Option จะเปลี่ยนอย่างไร เมื่อปัจจัยต่างๆ เปลี่ยน

5.1 Payoff ก่อน vs หลังหมดอายุ

  • ณ วันหมดอายุ: เส้นตรงหักศอก (intrinsic value only) — Time Value = 0
  • ก่อนหมดอายุ: เส้นโค้งมน (intrinsic + time value) — เส้นจะอยู่ สูงกว่า เส้นหมดอายุเสมอ
  • ยิ่งเหลือเวลามาก เส้นโค้งยิ่งอยู่สูงกว่า เพราะ Time Value ยิ่งมาก
Black-Scholes Model

คือสูตรที่คำนวณเส้นโค้งก่อนหมดอายุ โดยใช้ 5 ตัวแปร:

  1. S — ราคาสินทรัพย์อ้างอิงปัจจุบัน
  2. K — Strike Price
  3. T — เวลาจนหมดอายุ (ปี)
  4. σ — Volatility (ความผันผวน)
  5. r — อัตราดอกเบี้ยปลอดความเสี่ยง

5.2 Delta (Δ) — ความชันของ Payoff Curve

นิยาม

Δ = ∂V/∂S ≈ การเปลี่ยนของราคา Option เมื่อราคาสินทรัพย์เปลี่ยน ฿1

  • Call Delta: อยู่ระหว่าง 0 ถึง +1 (ATM ≈ 0.5)
  • Put Delta: อยู่ระหว่าง -1 ถึง 0 (ATM ≈ -0.5)
  • Deep ITM → Delta ≈ ±1 (เคลื่อนไหวเกือบเท่าสินทรัพย์อ้างอิง)
  • Deep OTM → Delta ≈ 0 (แทบไม่เคลื่อนไหว)
ใช้ทำอะไร?
  • ประมาณการเปลี่ยนแปลงราคา: ถ้า Delta = 0.6 และหุ้นขึ้น ฿10 → Option ขึ้นประมาณ ฿6
  • Hedge Ratio: ถ้าถือ 1 สัญญา Call (Δ = 0.6) ต้อง Short หุ้น 0.6 หุ้นเพื่อ Hedge (Delta Neutral)
  • ความน่าจะเป็นโดยประมาณ: Delta ≈ ความน่าจะเป็นที่ Option จะ ITM ณ วันหมดอายุ

5.3 Gamma (Γ) — อัตราเปลี่ยนของ Delta

นิยาม

Γ = ∂Δ/∂S = ∂²V/∂S²

Gamma คือ "อนุพันธ์อันดับ 2" — บอกว่า Delta เปลี่ยนเร็วแค่ไหนเมื่อราคาสินทรัพย์เปลี่ยน

  • Gamma สูงสุด ที่ ATM — Delta เปลี่ยนเร็วที่สุดบริเวณนี้
  • Gamma ต่ำ เมื่อ Deep ITM หรือ Deep OTM — Delta แทบไม่เปลี่ยน
  • Gamma สูง = ต้อง rebalance hedge บ่อย (ต้นทุน hedging สูง)
  • ยิ่งใกล้หมดอายุ Gamma ยิ่งสูงที่ ATM — เส้นโค้งยิ่งแหลมคม เปลี่ยนจาก OTM เป็น ITM ได้อย่างรวดเร็ว
จำง่ายๆ

Delta บอก "ความเร็ว" ของราคา Option, Gamma บอก "ความเร่ง" ของ Delta เหมือนรถยนต์: Delta = ความเร็ว, Gamma = คันเร่ง

5.4 Theta (Θ) — Time Decay

นิยาม

Θ = ∂V/∂t = มูลค่าที่หายไปทุกวัน

  • Theta เป็นลบ สำหรับ Long Options — ค่า Option ลดลงทุกวันที่ผ่านไป
  • Theta เป็นบวก สำหรับ Short Options — ได้ประโยชน์จาก time decay
  • Time decay เร็วขึ้นแบบ non-linear เมื่อใกล้หมดอายุ — ช่วง 30 วันสุดท้ายสูญเสียเร็วที่สุด
  • Theta สูงสุดที่ ATM (เพราะ Time Value สูงสุดที่ ATM)
"Time Decay เป็นเพื่อนของคนขาย เป็นศัตรูของคนซื้อ"

ผู้ขาย Options ได้เปรียบจากเวลาที่ผ่านไป — ทุกวันที่นอนหลับ Option ที่ขายไว้ก็ลดค่าลง เข้ากระเป๋าเรื่อยๆ ส่วนผู้ซื้อต้องแข่งกับเวลา ราคาต้องเคลื่อนไหวเร็วพอที่จะชนะ Time Decay

5.5 Vega (ν) — ผลกระทบจากความผันผวน

นิยาม

ν = ∂V/∂σ = การเปลี่ยนราคา Option เมื่อ Volatility เปลี่ยน 1%

  • Vega สูงสุดที่ ATM — Options ที่ ATM ไวต่อความผันผวนมากที่สุด
  • Long Options มี Vega บวก — ได้ประโยชน์เมื่อ volatility สูงขึ้น
  • Short Options มี Vega ลบ — ได้ประโยชน์เมื่อ volatility ลดลง
  • ยิ่งเหลือเวลามาก Vega ยิ่งสูง (Options ไกลหมดอายุไวต่อ vol มากกว่า)

Implied Volatility vs Historical Volatility

  • Historical Volatility (HV): ความผันผวนที่เกิดขึ้นจริงในอดีต (วัดจากข้อมูลราคาที่ผ่านมา)
  • Implied Volatility (IV): ความผันผวนที่ตลาด "คาดการณ์" ในอนาคต (คำนวณกลับจากราคา Option ในตลาด)
  • ถ้า IV > HV: ตลาดคาดว่าจะผันผวนมากกว่าปกติ → Options แพง
  • ถ้า IV < HV: ตลาดคาดว่าจะผันผวนน้อยกว่าปกติ → Options ถูก

บทที่ 6: Advanced Combinations — เปลี่ยนจำนวนและเวลา

จนถึงตอนนี้เราใช้ Options ที่มี จำนวน contracts เท่ากัน และ หมดอายุพร้อมกัน แต่ถ้าเปลี่ยน 2 ตัวแปรนี้จะเกิดรูปร่าง Payoff ใหม่ที่น่าสนใจ

6.1 Ratio Spreads — "ถ้าจำนวน Contracts ไม่เท่ากันล่ะ?"

ตัวอย่าง: 1×2 Ratio Call Spread

Long 1 Call K₁ + Short 2 Call K₂ (K₂ > K₁)

แนวคิด: เหมือน Bull Call Spread แต่ขาย Call มากกว่าที่ซื้อ ทำให้อาจได้ Credit (ไม่ต้องจ่ายเงิน) แต่แลกกับความเสี่ยงที่ไม่จำกัดทางด้านบน

Slope Analysis

  • S < K₁: slope = 0
  • ผ่าน K₁ (Long 1 Call): slope = 0 + 1 = +1
  • ผ่าน K₂ (Short 2 Call): slope = +1 - 2 = -1

ผลลัพธ์: แบน → ขึ้น → ลง (ลงไม่มีเพดาน!) = รูปร่างเหมือน "เต็นท์ข้างเดียว" ที่ด้านขวามีความเสี่ยงไม่จำกัด

ขาที่ขายมากกว่า (Short 2 Call) มี 1 ขาที่ไม่ได้ถูก cover ดังนั้นถ้าราคาพุ่งสูงมาก จะขาดทุนไม่จำกัด! Quantity (จำนวน contracts) เป็นอีกตัวแปรที่เปลี่ยนรูปร่าง Payoff ได้ — และอาจเปลี่ยนจาก defined risk เป็น unlimited risk

6.2 Back Ratio Spread — กลับด้าน Ratio

ตัวอย่าง: 1×2 Back Ratio Call Spread

Short 1 Call K₁ + Long 2 Call K₂ (K₂ > K₁)

แนวคิด: กลับด้าน Ratio Spread ปกติ — ซื้อมากกว่าขาย ทำให้ กำไรไม่จำกัด กลับมาทางด้านบน แต่มีช่วง "Dead Zone" ที่ขาดทุน

Slope Analysis

  • S < K₁: slope = 0
  • ผ่าน K₁ (Short 1 Call): slope = 0 - 1 = -1
  • ผ่าน K₂ (Long 2 Call): slope = -1 + 2 = +1

6.3 Calendar Spread — "ถ้าวันหมดอายุต่างกันล่ะ?"

ส่วนประกอบ

Short Option (หมดอายุใกล้) + Long Option (หมดอายุไกล)

Strike เดียวกัน แต่ต่างวันหมดอายุ!

แนวคิด: เดิมพันกับ Theta (Time Decay) ขาใกล้จะสูญเสีย Time Value เร็วกว่าขาไกล ดังนั้นเมื่อเวลาผ่านไป ส่วนต่างของ Time Value จะเพิ่มขึ้น = กำไร

ความแตกต่างสำคัญ

Calendar Spread ไม่สามารถวิเคราะห์แบบ "at-expiry payoff" ตรงๆ ได้ เพราะ ณ วันที่ขาใกล้หมดอายุ ขาไกล ยังไม่หมดอายุ — ต้องใช้ Theoretical Price (Black-Scholes) ในการประเมินมูลค่าขาไกล ณ วันนั้น

  • กำไรสูงสุดเมื่อ S = K (ณ วันที่ขาใกล้หมดอายุ) เพราะ Time Value ของขาไกลสูงสุดที่ ATM
  • ขาดทุนเมื่อราคาเคลื่อนไหวไกลจาก K มากเกินไป
  • Payoff เปลี่ยนตามเวลาที่ผ่านไป (ไม่คงที่เหมือน at-expiry strategies)
  • ได้ประโยชน์จาก Implied Volatility ที่สูงขึ้น (Vega บวก)

หลักการ: Hedge = เปลี่ยนรูปร่าง Payoff ของตำแหน่งที่มีอยู่

Protective Put — "ซื้อประกัน"

ส่วนประกอบ

Long Stock + Long Put

จำกัดขาดทุนไว้ที่ (K - S₀ + Premium) ขณะที่ยังมีกำไรไม่จำกัดทางขาขึ้น เหมือนถือหุ้นแล้วซื้อประกันราคา — จ่ายเบี้ยประกัน (Put Premium) แลกกับความอุ่นใจ

Covered Call — "ขายแรงกดดัน"

ส่วนประกอบ

Long Stock + Short Call

เก็บ Premium จาก Call ที่ขาย แลกกับการจำกัดกำไรสูงสุดที่ K ใช้เมื่อคิดว่าหุ้นจะไม่ขึ้นมากนัก — เปลี่ยน "ความหวังว่าจะขึ้นสูงๆ" เป็น "รายได้ที่แน่นอน"

Collar — "ใส่ปลอกคอ"

ส่วนประกอบ

Long Stock + Long Put K₁ + Short Call K₂ (K₁ < S₀ < K₂)

จำกัดทั้งขาดทุน (ด้วย Put) และกำไร (ด้วย Short Call) เหมือน "ใส่ปลอกคอ" ให้ Payoff — ใช้ Premium จาก Short Call มาจ่ายค่า Long Put (อาจได้ Zero-Cost Collar)

  6. Greeks บอกว่า Payoff เปลี่ยนอย่างไรก่อนหมดอายุ — Delta, Gamma, Theta, Vega คืออาวุธที่ต้องรู้

ภาค 2: เทรดบน Payoff Chart

บทที่ 1–8 ใช้ Payoff Chart อ่านกลยุทธ์ Options ภาคนี้ใช้เครื่องมือเดียวกันอ่านกลยุทธ์ที่ ไม่มี Option เลยสักตัว เริ่มจาก Grid Trading ซึ่งนิยมมากในตลาด BTC และ ETH

ตัวเลขราคาในบทนี้เป็น ค่าสมมติ เพื่อให้คิดเลขง่าย ไม่ใช่ราคาตลาดจริง

Grid Trading คือการวาง Limit Order ไว้เป็นชั้น ๆ ตามระดับราคา ราคาลงถึงชั้นไหนก็ซื้อ ราคาขึ้นถึงชั้นไหนก็ขาย คนส่วนใหญ่มองมันเป็น "บอทเก็บกำไรรอบสั้น" แต่ถ้าวาดออกมาเป็น Payoff Chart จะเห็นว่ามันคือ การขาย Option เป็นขั้นบันได ซึ่งทำให้เรายืมความรู้ทั้งหมดจากบทที่ 2–5 มาใช้กับ Grid ได้ทันที

ศัพท์ตลาดที่ใช้ตลอดภาค 2
  • Spot: การซื้อขายเหรียญจริง จ่ายเงินเต็มจำนวน ถือได้น้อยสุดคือศูนย์ ถือติดลบไม่ได้
  • Limit Order: คำสั่งที่ระบุราคาไว้ล่วงหน้า แล้วรอให้ราคาตลาดมาถึง
  • Perpetual Futures: สัญญาที่ราคาวิ่งตามเหรียญและไม่มีวันหมดอายุ เปิดได้ทั้งฝั่งซื้อ (Long) และฝั่งขาย (Short) Payoff เป็นเส้นตรงเหมือนการถือหรือขายสินทรัพย์ในบทที่ 2.6 ภาคนี้เรียกสั้น ๆ ว่า Futures
  • Margin และ Leverage: Margin คือเงินประกันที่วางเพื่อเปิดสถานะ Futures ส่วน Leverage คือมูลค่าสถานะหารด้วย Margin
  • Liquidation: การถูกบังคับปิดสถานะเมื่อขาดทุนกิน Margin จนเกือบหมด
  • Funding: เงินที่ฝั่ง Long กับฝั่ง Short ของ Perpetual Futures จ่ายให้กันเป็นระยะ เมื่อ Funding เป็นบวก ฝั่ง Long เป็นผู้จ่าย

9.4 พจนานุกรม Grid → Option

คำสั่งซื้อแบบ Limit ที่ราคา K คือการบอกตลาดว่า "ใครอยากขายให้ฉันที่ K มาได้เลย" ซึ่งเป็นภาระแบบเดียวกับคน Short Put ที่ Strike K (บทที่ 2.4) และกำไรก็ถูกจำกัดแบบเดียวกัน: ชั้นที่ซื้อที่ K ถูกตั้งขายที่ K + g เสมอ กำไรของชั้นนั้นจึงไม่เกิน u × g เหมือน Short Put ที่กำไรไม่เกิน Premium ส่วนขาลงขาดทุนได้ลึกเท่ากัน

สองอย่างนี้ไม่ได้เหมือนกันทุกประการ ข้อต่างมี 3 ข้อ และจะกลับมาสำคัญในบทที่ 11:

  • Limit Order ไม่ได้รับ Premium ล่วงหน้า รายได้มาจาก Grid Profit ซึ่งต้องรอให้ราคาแกว่ง
  • Limit Order ทำงานทันทีที่ราคาแตะ ส่วน Short Put ตัดสินกันที่ราคา ณ วันหมดอายุเท่านั้น
  • Limit Order ไม่มีวันหมดอายุ

Grid ทั้งชุดจึงแปลได้ดังนี้:

ประเภท Gridของในมือเทียบเท่ารูปร่าง
Spot Grid / Futures Long Grid ราคาลงยิ่งถือมาก ราคาขึ้นจนของหมด Short Put หลาย Strike เรียงเป็นขั้น (Short Put Ladder) แบนด้านบน โค้งลงด้านล่าง
Futures Short Grid ราคาขึ้นยิ่ง Short มาก Short Call Ladder แบนด้านล่าง โค้งลงด้านบน
Neutral Grid Long ใต้ราคาเริ่ม Short เหนือราคาเริ่ม Short Put Ladder + Short Call Ladder = Short Strangle หลายคู่ซ้อนกัน โค้งคว่ำทั้งสองด้าน
Grid กลางกรอบ = Covered Call Ladder

บอทส่วนใหญ่เริ่มกลางกรอบ โดยซื้อของไว้ก่อนเพื่อตั้งขายชั้นบน เช่น กรอบ 90,000–110,000 เริ่มที่ 100,000 ซื้อไว้ 0.05 BTC ตั้งขายที่ 102k ถึง 110k และตั้งซื้อที่ 98k ถึง 90k ต่อจากนี้เรียก Grid ตัวนี้ว่า Grid กลางกรอบ เพื่อแยกจาก Grid หลักที่เริ่มโดยไม่มีของ

  • ราคาขึ้นถึง 110,000: ขายของตั้งต้นหมดทีละชั้น กำไร 0.01 × (2,000 + 4,000 + 6,000 + 8,000 + 10,000) = +300 USD และไม่เพิ่มอีกแม้ราคาไปต่อ
  • ราคาลงถึง 90,000: ถือ 0.10 BTC ของตั้งต้นขาดทุน 0.05 × 10,000 = 500 บวกขาดทุนของ 5 ชั้นที่ซื้อเพิ่มอีก 200 รวม -700 USD

ครึ่งบนคือ "ถือของ + ขายทำกำไรเป็นชั้น" ซึ่งก็คือ Covered Call และถ้ากลับเครื่องหมายของ Synthetic Long Put ในบทที่ 2.6 (Short Stock + Long Call) จะได้ว่า Long Stock + Short Call = Short Put กราฟทั้งเส้นจึงยังเป็น Short Put Ladder ตัวเดิม เพียงแต่จุดเริ่มต้นย้ายมาอยู่กลางโค้ง

Neutral Grid คือ Short Strangle หลายคู่ซ้อนกันเป็นขั้น เมื่อเส้น Grid ถี่มาก รูปรวมจะโค้งมนใกล้กับ Short Straddle ก่อนหมดอายุ (บทที่ 5.1) ต่อจากนี้จึงเทียบกับ Short Straddle เมื่อพูดถึง Greeks

ตัวอย่าง Neutral Grid บน ETH

สมมติ ETH เริ่มที่ 3,000 USD ใช้ Futures วาง Grid ห่างกัน 50 USD ชั้นละ 0.1 ETH ด้านละ 5 ชั้น ซื้อเมื่อราคาลง Short เมื่อราคาขึ้น กำไรต่อรอบ = 0.1 × 50 = 5 USD

เส้นแดงคือ Floating P&L มีหน้าตาเหมือน Short Strangle ที่ไม่ได้รับ Premium เส้นเขียวประคือกราฟเดียวกันหลังเก็บ Grid Profit ได้ 6 รอบ กราฟทั้งเส้น ยกตัวขึ้น 30 USD และจุดคุ้มทุนขยับออกไปที่ 2,800 กับ 3,200 นี่คือกลไกเดียวกับที่ Premium ยกกราฟ Short Strangle ขึ้นเหนือศูนย์ ต่างกันที่ Grid ต้องรอให้ราคาแกว่งจึงจะได้เงินก้อนนี้

9.6 สูตรหลักและกฎ √n

อ่านเป็นภาษาคนก่อน: ทุกก้าวที่ราคาเดิน Grid ได้ "แต้ม" ครึ่งรอบ ไม่ว่าจะเดินขึ้นหรือลง แต่ยิ่งราคาจบห่างจากจุดเริ่ม Grid ยิ่งเสียแต้ม และเสียแบบ ยกกำลังสอง ไกล 2 เท่าเสีย 4 เท่า

P&L รวม = (u × g / 2) × (n - k²)

n = จำนวนก้าวทั้งหมดที่ราคาเดิน (นิยามของก้าวอยู่ในหัวข้อ 9.1)
k = จำนวนช่องที่ราคาตอนจบห่างจากจุดเริ่ม

สูตรนี้คือผลรวมของสองก้อนในหัวข้อ 9.3 ซึ่งคิดแยกกันได้:

จำนวนรอบที่ครบ = (n - k) / 2
Grid Profit = u × g × (n - k) / 2
Floating P&L = -u × g × k(k - 1) / 2

ตรวจกับตัวอย่างในหัวข้อ 9.3: u × g = 20 USD ราคาเดิน n = 8 ก้าว จบห่างจากจุดเริ่ม k = 2 ช่อง

  • จำนวนรอบ = (8 - 2) / 2 = 3 รอบ ได้ Grid Profit 60 USD
  • Floating P&L = -20 × (2 × 1) / 2 = -20 USD
  • รวม = 10 × (8 - 4) = +40 USD ตรงกับที่นับมือ
ขอบเขตของสูตร
  • ใช้กับ Grid ที่ เริ่มโดยไม่มีของในมือ ขนาดและระยะห่างเท่ากันทุกชั้น และราคายังอยู่ในกรอบ ตัวเลขยังไม่หักค่าธรรมเนียม
  • ถ้าเริ่มด้วยของตั้งต้น เช่น Grid กลางกรอบในหัวข้อ 9.4 ให้บวกกำไรขาดทุนของเหรียญก้อนนั้นเพิ่ม คือ ของตั้งต้น × (ราคาตอนจบ - ราคาเริ่ม) จุดคุ้มทุนจะไม่อยู่ที่ √n อีกต่อไป
  • Grid หลักมีแต่ฝั่งซื้อ จึงนับเฉพาะก้าวที่เกิดในกรอบ คือระหว่าง 90,000 ถึง 100,000
  • n กับ k เป็นเลขคู่ทั้งคู่หรือเลขคี่ทั้งคู่เสมอ เพราะก้าวที่ไม่ใช่การเดินสุทธิต้องจับคู่กันเป็นรอบ
  • ที่มาของสูตรอยู่ใน Appendix
กฎ √n — จุดคุ้มทุนของ Grid

Grid กำไรเมื่อ k² < n หรือพูดอีกแบบ:

ราคาเดิน n ก้าว → กำไรถ้าจบห่างจากจุดเริ่มน้อยกว่า √n ช่อง

เดิน 25 ก้าว ต้องจบห่างน้อยกว่า 5 ช่อง เดิน 100 ก้าว ต้องจบห่างน้อยกว่า 10 ช่อง ถ้าจบห่างเท่ากับ √n พอดีจะเท่าทุน

กราฟนี้คือ Payoff Chart ของ Grid ในอีกมุมหนึ่ง แกนนอนเปลี่ยนจากราคาเป็น "ระยะที่ราคาจบห่างจากจุดเริ่ม" และรูปร่างเป็นพาราโบลาคว่ำ ซึ่งเป็นรูปเดียวกับ Short Straddle ก่อนหมดอายุ เส้นลากต่อเนื่องเพื่อให้เห็นรูป จุดที่เกิดได้จริงเมื่อ n = 36 คือ k ที่เป็นเลขคู่

ความจริงที่ต้องรู้: Grid ไม่ได้มีกำไรในตัวเอง

ถ้าราคาเดินแบบสุ่มล้วน ๆ (Random Walk) คือแต่ละก้าวมีโอกาสขึ้นหรือลงเท่ากัน ค่าเฉลี่ยของ k² จะเท่ากับ n พอดี กำไรคาดหวังของ Grid จึง เท่ากับศูนย์ ก่อนค่าธรรมเนียม และติดลบหลังค่าธรรมเนียม

ลองกับการโยนเหรียญ 4 ครั้ง ให้หัวคือขึ้น 1 ช่อง และก้อยคือลง 1 ช่อง ผลที่เป็นไปได้มี 16 แบบ: จบห่าง 0 ช่อง 6 แบบ ห่าง 2 ช่อง 8 แบบ ห่าง 4 ช่อง 2 แบบ ค่าเฉลี่ยของ k² = (0 × 6 + 4 × 8 + 16 × 2) / 16 = 4 ซึ่งเท่ากับ n พอดี

ตัวอย่างเดียวกันบอกอีกเรื่องหนึ่ง: Grid กำไร 6 แบบ เท่าทุน 8 แบบ และขาดทุนแค่ 2 แบบ แต่ 2 แบบนั้นขาดทุนมากพอจะลบกำไรของ 6 แบบจนหมด Grid จึง ชนะบ่อยครั้งละน้อย และแพ้นาน ๆ ครั้งแต่หนัก แม้ในตลาดที่ไม่มีอะไรให้เก็บ ผลกำไรช่วงสั้น ๆ จึงยังไม่ใช่หลักฐานว่า Grid ได้เปรียบ

Grid ทำเงินได้เฉพาะเมื่อตลาด แกว่งกลับมากกว่าการเดินสุ่ม (mean-reverting) และเสียเงินเมื่อตลาดเป็นเทรนด์มากกว่าการเดินสุ่ม การเปิด Grid จึงเป็นการเดิมพันว่าตลาดจะอยู่ในกรอบ ไม่ใช่เครื่องผลิตเงิน

9.8 ต้นทุนจริงของ Grid

ค่าธรรมเนียม

ทุกรอบต้องจ่ายค่าธรรมเนียม 2 ข้าง (ซื้อ 1 ขาย 1) สมมติค่าธรรมเนียมข้างละ 0.1%:

  • มูลค่าต่อชั้น = 0.01 BTC × 100,000 = 1,000 USD
  • ค่าธรรมเนียมต่อรอบ = 2 × 0.1% × 1,000 = 2 USD
  • กำไรสุทธิต่อรอบ = 20 - 2 = 18 USD
จุดเท่าทุนของหนึ่งรอบ: g / S = 2 × อัตราค่าธรรมเนียม
ที่ 0.1% ต่อข้าง และ BTC = 100,000 → g = 200 USD

ระยะห่างที่ใช้จริงต้องกว้างกว่าจุดเท่าทุนนี้หลายเท่า ใน Grid หลัก g / S = 2% คือ 10 เท่าของค่าธรรมเนียมรวม 0.2% ค่าธรรมเนียมจึงกินกำไรต่อรอบไป 10%

เงินทุนและต้นทุนอื่น

  • เงินที่ต้องกัน (Spot): ผลรวมของคำสั่งซื้อทุกชั้น ในตัวอย่างหลัก = 0.01 × (98,000 + 96,000 + 94,000 + 92,000 + 90,000) = 4,700 USD เงินก้อนนี้นอนรออยู่เฉย ๆ จนกว่าราคาจะลงถึง
  • Funding (Perpetual Futures): ฝั่งที่ถืออยู่อาจต้องจ่ายหรือได้รับ Funding เป็นระยะ สมมติ Funding 0.01% ทุก 8 ชั่วโมง โดยฝั่ง Long เป็นผู้จ่าย ของเต็มมือ 0.05 BTC มูลค่าประมาณ 5,000 USD จะจ่ายประมาณ 1.5 USD ต่อวัน หรือราว 11% ต่อปีของมูลค่าสถานะ ในช่วงตลาดร้อนแรง Funding ขึ้นได้หลายเท่าของระดับนี้ และกลับเป็นลบได้ในช่วงตลาดร่วง ซึ่งทำให้ฝั่ง Short เป็นผู้จ่าย
  • Leverage: ลดเงินที่ต้องกัน แต่เพิ่มราคา Liquidation เข้ามาในกราฟ ซึ่งเป็นเรื่องของบทที่ 10

10.2 กำหนดขนาดจากงบขาดทุน

อ่านเป็นภาษาคนก่อน: คนส่วนใหญ่ตั้ง Grid โดยเริ่มจาก "มีเงินเท่าไร" แล้วหารจำนวนชั้น วิธีที่ Payoff Chart แนะนำกลับกัน คือเริ่มจาก "ยอมเสียได้เท่าไร ณ จุดที่จะเลิก" แล้วย้อนหาขนาดต่อชั้น

จุดที่จะเลิกเรียกว่า ราคา Stop คือราคาที่ตั้งใจจะปิดทุกอย่าง (รายละเอียดในหัวข้อ 10.3) และจำนวนเงินที่ยอมเสีย ณ จุดนั้นเรียกว่า งบขาดทุน งบนี้ไม่ใช่ Max Loss แบบ Option ในภาค 1 เพราะถ้าราคาเคลื่อนเร็วจนปิดไม่ทัน จะเสียมากกว่างบได้

สำหรับ Grid ฝั่งซื้อ m ชั้นที่เริ่มโดยไม่มีของในมือ เช่น Grid หลัก ขาดทุนลอยตัวที่ราคา Stop (ซึ่งอยู่ที่หรือใต้กรอบล่าง L) คือ:

ขาดทุนที่ Stop = u × [ g × m(m - 1) / 2 + m × (L - Stop) ]

u = งบขาดทุน / [ g × m(m - 1) / 2 + m × (L - Stop) ]

ก้อนแรกในวงเล็บคือขาดทุนสะสมตอนราคาถึงกรอบล่าง ซึ่งก็คือสูตร Floating P&L ในบทที่ 9.6 เมื่อ k = m ก้อนที่สองคือขาดทุนเพิ่มของเหรียญเต็มมือ m ชั้น ระหว่างกรอบล่างถึงจุด Stop

ถ้า Grid เริ่มด้วยของตั้งต้น ต้องบวกขาดทุนของเหรียญก้อนนั้นเพิ่ม คือ ของตั้งต้น × (ราคาเริ่ม - Stop) เช่น Grid กลางกรอบที่ตั้ง Stop 88,000 ด้วย u = 0.01 จะขาดทุน 300 + 0.05 × 12,000 = 900 USD ไม่ใช่ 300 USD

ตัวอย่าง: หา u ของ Grid หลัก

ทุน 10,000 USD ยอมเสียได้ 3% ต่อ Grid หนึ่งตัว = 300 USD ใช้ Grid หลัก (ซื้อ 5 ชั้น 98k ถึง 90k ห่างกัน 2,000 USD) ตั้ง Stop ที่ 88,000

  • ก้อนแรก: 2,000 × (5 × 4 / 2) = 20,000
  • ก้อนที่สอง: 5 × (90,000 - 88,000) = 10,000
  • u = 300 / 30,000 = 0.01 BTC ต่อชั้น

ตรวจกลับ: ที่ 88,000 ขาดทุน 200 + 0.05 × 2,000 = 300 USD พอดี และใช้เงินซื้อเต็มทุกชั้น 4,700 USD หรือ 47% ของทุน

กรอบกว้างขึ้นไม่ได้แปลว่าปลอดภัยขึ้น

ขาดทุนที่กรอบล่างโตตาม m(m - 1) / 2 ซึ่งโตในอัตราเดียวกับ m ยกกำลังสอง ถ้าขยาย Grid หลักจาก 5 ชั้นเป็น 10 ชั้น (ลงไปถึง 80,000) ด้วยขนาดต่อชั้นเท่าเดิม ขาดทุนที่กรอบล่างจะเพิ่มจาก 200 เป็น 900 USD ชั้นเพิ่ม 2 เท่า แต่ขาดทุนเพิ่ม 4.5 เท่า

การขยายกรอบจึงเป็นการเลื่อนจุดเจ็บออกไปและทำให้มันใหญ่ขึ้น ถ้าจะขยายกรอบต้องลด u ลงตามสูตรข้างบนเสมอ

10.3 Stop-loss บน Payoff Chart

Stop-loss คือคำสั่งปิดทุกอย่างเมื่อราคาถึงจุดที่กำหนด บนกราฟมันทำหน้าที่ ตัดหางให้แบน ขาดทุนหยุดที่ระดับเดียวไม่ว่าราคาจะลงต่อแค่ไหน

รูปที่ได้คล้ายรูป "บันไดขึ้น" ของ Bull Call Spread ในบทที่ 4.1 ที่จมอยู่ใต้ศูนย์ทั้งเส้น แต่ Stop มีจุดอ่อน 2 ข้อที่ Option ไม่มี:

จุดอ่อนเกิดอะไรตัวอย่าง
Gap / Slippageราคากระโดดข้ามจุด Stop คำสั่งได้ราคาแย่กว่าที่ตั้งตั้ง 88k แต่ได้ 85k เสีย 450 แทน 300 (1.5 เท่า)
Whipsawราคาแตะ Stop แล้วเด้งกลับ ขาดทุนถูกรับรู้ไปแล้ว และ Grid ปิดไปแล้วแตะ 88k เสีย 300 แล้วราคากลับไป 100k โดยไม่มีเราอยู่

ตลาดคริปโตเปิดตลอด 24 ชั่วโมง จึงไม่มี Gap ข้ามคืนแบบตลาดหุ้น คำว่า Gap ในภาคนี้หมายถึงช่วงที่ราคาเคลื่อนเร็วจนคำสั่งจับคู่ไม่ทัน เช่น ช่วงที่สถานะ Leverage จำนวนมากถูกบังคับปิดต่อเนื่องกัน หรือช่วงที่ระบบของตลาดทำงานช้า

Stop ไม่ได้มีแบบเดียว และไม่ใช่การรับประกัน
  • Stop-Market: เมื่อถึงราคาที่ตั้ง จะปิดที่ราคาตลาดทันที ได้ปิดแน่ แต่ราคาอาจแย่กว่าที่ตั้ง
  • Stop-Limit: เมื่อถึงราคาที่ตั้ง จะส่งคำสั่ง Limit ราคาไม่แย่กว่าที่กำหนด แต่ถ้าราคาร่วงผ่านไปเร็ว คำสั่งจะไม่ถูกจับคู่เลย และสถานะยังอยู่ครบ
  • ราคาที่ใช้กระตุ้น: บางตลาดให้เลือกระหว่างราคาซื้อขายล่าสุดกับราคาอ้างอิงของตลาด (Mark Price) ราคาซื้อขายล่าสุดถูกกระตุ้นจากการร่วงชั่วครู่ได้ง่ายกว่า
  • Stop ที่ตั้งในบอทเป็นการตั้งค่าของระบบ ควรอ่านเงื่อนไขของตลาดที่ใช้ว่าเมื่อ Stop ทำงานแล้วบอทขายของให้หรือไม่ และขายด้วยคำสั่งแบบใด

Stop หนึ่งครั้งเท่ากับกี่รอบ

ตัวเลขที่ควรรู้ก่อนเปิด Grid คืออัตราส่วนระหว่างขาดทุนที่ Stop กับกำไรสุทธิต่อรอบ ใน Grid หลัก กำไรสุทธิต่อรอบคือ 18 USD (หลังค่าธรรมเนียม จากบทที่ 9.8):

จำนวนรอบที่ต้องเก็บเพื่อชดเชย Stop 1 ครั้ง = 300 / 18 ≈ 17 รอบ

ถ้าโดยเฉลี่ยเก็บได้ไม่ถึง 17 รอบก่อนโดน Stop หนึ่งครั้ง Grid ตัวนี้ขาดทุนในระยะยาว และตัวเลขนี้ ไม่ได้ดีขึ้นจากการขยับ Stop ถ้าราคาเดินสุ่ม จำนวนรอบที่คาดว่าจะเก็บได้ก่อนโดน Stop หนึ่งครั้งคือ 300 / 20 = 15 รอบพอดี เพราะกำไรคาดหวังก่อนค่าธรรมเนียมเป็นศูนย์ตามบทที่ 9.6 ซึ่งน้อยกว่า 17 รอบที่ต้องใช้ ส่วนต่าง 2 รอบคือค่าธรรมเนียม

การขยับ Stop ให้ใกล้ขึ้นลดขาดทุนต่อครั้ง แต่ทำให้โดน Stop บ่อยขึ้นในสัดส่วนเดียวกัน Stop จึงเปลี่ยนได้แค่ว่าจะแพ้บ่อยครั้งละน้อย หรือแพ้นาน ๆ ครั้งแต่มาก สิ่งที่ทำให้ Grid คุ้มจริงมี 3 อย่างเท่านั้น คือตลาดที่แกว่งกลับมากกว่าการเดินสุ่ม ค่าธรรมเนียมที่ต่ำเมื่อเทียบกับ g หรือการไม่เปิดเมื่อสองอย่างแรกไม่มี

วาง Stop ตรงไหน
  • วาง ใต้กรอบล่าง เว้นระยะอย่างน้อย 1 ช่อง ถ้าวางที่กรอบล่างพอดี ชั้นสุดท้ายจะซื้อแล้วโดน Stop ทันที
  • ระดับ Stop ต้องมาจากงบขาดทุนในหัวข้อ 10.2 ไม่ใช่จากความรู้สึกว่า "ราคาไม่น่าลงถึง"
  • คิดเผื่อราคาที่ได้แย่กว่าที่ตั้งไว้ในงบ โดยคิดเป็น % ของราคา คูณกับของเต็มมือ เช่น เผื่อ 3% ของราคา 88,000 กับของ 0.05 BTC เท่ากับเผื่อเพิ่มประมาณ 130 USD

10.4 Hedge Delta: เปลี่ยนความชันของทั้งกราฟ

ผลรวมสมมาตรสองด้าน เป็นรูป Short Strangle แบบเดียวกับ Neutral Grid ในบทที่ 9.4 สิ่งที่ได้และเสีย:

  • ได้: ขาดทุนที่กรอบล่างลดจาก 700 เหลือ 200 และหางล่างชันน้อยลงครึ่งหนึ่ง
  • เสีย: กำไร 300 ที่กรอบบนกลายเป็นขาดทุน 200 และเกิดหางบนขึ้นมาใหม่ ซึ่งขาดทุนไม่มีพื้นเหมือนหางล่าง
ความเสี่ยงของขา Hedge
  • เงินอยู่คนละกระเป๋า: กำไรจากการขาย Spot ไม่ได้ไปค้ำขา Short โดยอัตโนมัติ ต้องวาง Margin ให้ขา Short แยกต่างหาก และขานี้มีราคา Liquidation ของตัวเอง
  • เหนือกรอบบนไม่มีของเหลือ: เมื่อ Grid ขายหมดแล้ว ขา Short ไม่มีอะไรรองรับ ต้องตั้ง Stop ฝั่งซื้อคืน (Buy Stop) ไว้เหนือกรอบบน และวาง Margin ให้รอดถึงจุดนั้น
  • Funding: ขา Short ได้รับเมื่อ Funding เป็นบวก และต้องจ่ายเมื่อ Funding เป็นลบ ซึ่งมักเกิดในช่วงตลาดร่วง
  • ขา Hedge หายเองได้: ในวันที่ตลาดเคลื่อนไหวรุนแรง ตลาด Futures บางแห่งมีกลไกบังคับลดสถานะของฝั่งที่กำไร (Auto-Deleveraging) ขา Short อาจถูกปิดโดยที่เราไม่ได้สั่ง เหลือแต่ Grid ที่ไม่มี Hedge ในเวลาที่ต้องการมันที่สุด
Hedge ได้แค่ความชัน ไม่ได้ความโค้ง

Futures มี Payoff เป็นเส้นตรง การบวกเส้นตรงเข้าไปเปลี่ยนได้แค่ความชัน กราฟยังโค้งคว่ำเท่าเดิม คือยังเป็น Short Gamma เท่าเดิม ถ้าไล่ Hedge Delta ให้เป็นศูนย์ทุกครั้งที่ราคาขยับ จะเท่ากับสั่งซื้อขายสวนทางกับ Grid ทุกคำสั่ง ผลคือไม่เหลือ Grid เลย

การลดความโค้งต้องใช้สิ่งที่มีความโค้งในตัวเอง ทางตรงที่สุดคือลดขนาด Grid (ลด u หรือเพิ่ม g) หรือซื้อ Option ซึ่งเป็นเรื่องของบทที่ 11

กฎ √n จากบทที่ 9.6 ใช้ย้อนดูอดีตได้ว่าตลาดช่วงที่ผ่านมาเป็นมิตรกับ Grid หรือไม่ วิธีทำคือเอาราคาย้อนหลังมานับด้วย g ที่จะใช้จริง:

  1. นับ n = จำนวนก้าวที่ราคาเดินในช่วงเวลาที่ดู ตามนิยามในบทที่ 9.1 โดยสมมติว่ามีเส้น Grid ต่อเนื่องไม่จำกัดกรอบ
  2. นับ k = จำนวนช่องที่ราคาปลายช่วงห่างจากราคาต้นช่วง
  3. เทียบ k² กับ n
ผลที่ได้ตลาดช่วงนั้นเป็นแบบไหนความหมายต่อ Grid
k² น้อยกว่า n มากแกว่งกลับ (mean-reverting)Grid ได้กำไร
k² ใกล้เคียง nใกล้การเดินสุ่มเท่าทุนก่อนค่าธรรมเนียม ขาดทุนหลังค่าธรรมเนียม
k² มากกว่า nเป็นเทรนด์Grid ขาดทุน

ตัวอย่าง: 30 วันที่ผ่านมา ราคาเดิน 40 ก้าว ถ้าจบห่างจากต้นช่วง 8 ช่อง (k² = 64) ช่วงนั้นเป็นเทรนด์และ Grid ขาดทุน ถ้าจบห่าง 2 ช่อง (k² = 4) ช่วงนั้น Grid ได้กำไร

แต่กำไรช่วงเดียวยังสรุปไม่ได้ว่าตลาดแกว่งกลับจริง เพราะแม้ราคาเดินสุ่มล้วน ๆ 40 ก้าว ก็จบห่างไม่เกิน 2 ช่องได้ประมาณ 36% ของครั้ง และมี k² น้อยกว่า n ประมาณ 73% ของครั้ง ช่วงเวลาเดียวจึงเป็นตัวอย่างเพียงตัวเดียว ควรดูหลายช่วงที่ไม่ซ้อนกันก่อนสรุป

ตัวกรองไม่ใช่ตัวทำนาย

ผลของช่วงที่ผ่านมาไม่รับประกันช่วงถัดไป ตลาดที่แกว่งในกรอบมานานมักจบด้วยการทะลุกรอบแรง ๆ ตัวกรองจึงใช้ได้ดีในทาง ปิด มากกว่าทางเปิด คือเมื่อ k² เริ่มมากกว่า n ในช่วงล่าสุด ให้ถือเป็นสัญญาณลดขนาดหรือหยุด Grid ส่วนการที่ k² น้อยกว่า n ไม่ได้แปลว่าเปิดแล้วจะปลอดภัย

10.8 Leverage และราคา Liquidation

เมื่อทำ Grid บน Futures ด้วย Leverage จะมีเส้นใหม่เพิ่มบนกราฟ คือราคา Liquidation ซึ่งหาได้จาก Payoff Chart โดยตรง: Liquidation เกิดเมื่อขาดทุนลอยตัวกิน Margin ที่วางไว้จนหมด (ค่าประมาณ ในทางปฏิบัติจะโดนเร็วกว่านี้ เพราะตลาดกำหนดเงินประกันขั้นต่ำที่ต้องเหลืออยู่เสมอ เรียกว่า Maintenance Margin)

Grid หลักบน Futures มีขาดทุนใต้กรอบล่างเท่ากับ 200 + 0.05 × (90,000 - ราคา) ตั้ง Stop ที่ 88,000 (ขาดทุน 300) ตารางคิดจาก 2 บรรทัดนี้:

Leverage ตอนของเต็มมือ = มูลค่าของเต็มมือ 4,700 USD / Margin
ราคา Liquidation: แก้ 200 + 0.05 × (90,000 - ราคา) = Margin
เช่น Margin 1,000 → 0.05 × (90,000 - ราคา) = 800 → ราคา = 74,000
Margin ที่วางLeverage ตอนของเต็มมือราคา Liquidation โดยประมาณระยะจาก Stop (88,000) ถึง Liquidation
1,000 USDประมาณ 4.7 เท่า74,000ประมาณ 16% ของราคา Stop ทำงานก่อน
400 USDประมาณ 12 เท่า86,000ประมาณ 2% ราคาร่วงเร็วครั้งเดียวก็ถึง
300 USDประมาณ 16 เท่า88,0000% ทับจุด Stop พอดี Stop ไม่มีความหมาย
หลักการวาง Margin

ราคา Liquidation ต้องอยู่ ไกลกว่า จุด Stop เสมอ และให้วัดระยะนั้นเป็น % ของราคา ไม่ใช่เป็นจำนวนเท่าของขาดทุน เพราะ Grid ที่แคบมีขาดทุนที่ Stop เล็กมาก Margin ที่ดูเหมือนมากกว่าขาดทุนหลายเท่าอาจให้ระยะเพียง 1–2% ซึ่ง BTC เคลื่อนไหวได้ภายในวันเดียว

คำถามที่ควรถามคือ: ถ้า Stop พลาด ราคาต้องไปต่ออีกกี่ % จึงจะโดน Liquidation และระยะนั้นมากกว่าที่ราคาเคยเคลื่อนในวันที่แย่ที่สุดหรือไม่ ถ้าโดน Liquidation ก่อน Stop แปลว่าตลาดเป็นคนเลือกจุดออกแทนเรา และมักได้ราคาแย่กว่า

สองเรื่องที่ทำให้ราคา Liquidation ต่างจากที่คำนวณ
  • Margin แบบแยกกับแบบรวม: แบบแยก (Isolated) จำกัดขาดทุนไว้ที่เงินประกันของสถานะนั้น แบบรวม (Cross) ใช้เงินทั้งบัญชีค้ำ ราคา Liquidation จึงไกลกว่า แต่ถ้าโดนจะเสียได้ทั้งบัญชี
  • ราคาที่ใช้ตัดสิน: Liquidation ใช้ราคาอ้างอิงของตลาด (Mark Price) ซึ่งอาจไม่ตรงกับราคาที่คำสั่ง Stop ใช้กระตุ้น

10.10 หลาย Grid พร้อมกัน

เมื่อเปิดหลาย Grid ให้ใช้หลักบวก Payoff จากบทที่ 3 กับทั้งพอร์ต โดยแปลงทุกอย่างเป็น USD ก่อน:

  • งบขาดทุนรวม = ผลบวกของขาดทุนที่ Stop ของทุก Grid อย่าหักลดด้วยเหตุผลว่ากระจายความเสี่ยงแล้ว เพราะในวันที่ตลาดคริปโตร่วงแรง BTC กับ ETH มักลงพร้อมกัน ทุก Grid จะถึงกรอบล่างในวันเดียวกัน
  • Delta รวมเป็น USD = ผลบวกของ (จำนวนเหรียญ × ราคา) ของทุก Grid ตัวเลขนี้บอกว่าตอนนี้พอร์ตเดิมพันทิศทางอยู่เท่าไร
  • ของเต็มมือรวมเป็น USD คือความชันของหางรวม ใช้ตัวเลขนี้คำนวณ Margin และราคา Liquidation ของทั้งบัญชี ไม่ใช่ราย Grid

การกระจายที่ได้ผลจริงสำหรับ Grid คือกระจาย ช่วงเวลาและระดับราคา เช่น เปิดคนละช่วง คนละกรอบ มากกว่ากระจายเหรียญที่เคลื่อนไหวไปด้วยกัน

10.11 สรุปและแบบฝึกหัด

Checklist ก่อนเปิด Grid
  1. งบขาดทุน: ยอมเสียได้เท่าไรต่อ Grid ตัวนี้ และรวมทุก Grid แล้วเป็นเท่าไร
  2. ขนาดต่อชั้น: คำนวณ u จากงบขาดทุนและจุด Stop ไม่ใช่จากเงินที่มี และนับขาดทุนของเหรียญตั้งต้นด้วยถ้ามี
  3. Stop: อยู่ใต้กรอบล่าง รู้ว่าเป็น Stop แบบใด และคิดเผื่อราคาที่ได้แย่กว่าที่ตั้งแล้ว ถ้ามีขา Short ต้องมี Stop เหนือกรอบบนด้วย
  4. อัตราส่วน Stop ต่อรอบ: ต้องเก็บกี่รอบเพื่อชดเชย Stop หนึ่งครั้ง และเป็นไปได้จริงหรือไม่
  5. ความชัน: ต้องการ Delta เป็นบวก เป็นกลาง หรือ Hedge บางส่วน
  6. แผนหลุดกรอบ: เขียนทางออกของทั้งด้านล่างและด้านบนไว้แล้ว
  7. Margin: ราคา Liquidation อยู่ไกลกว่าจุด Stop โดยวัดระยะเป็น % ของราคา และรู้ว่าใช้ Margin แบบแยกหรือแบบรวม
  8. Stress Test: ไล่ตาราง Scenario แล้ว และรู้ว่ากรณีไหนที่แผนป้องกันไม่ได้

  2. จากข้อ 1 ถ้าราคา Gap ลงไปถึง 2,600 ก่อนที่ Stop จะได้ราคา จะเสียจริงเท่าไร และเป็นกี่เท่าของงบ
  3. Spot Grid ตัวหนึ่งถือของตั้งแต่ 0 ถึง 2 ETH ต้อง Short Futures เท่าไรจึงจะได้ Neutral Grid และหลัง Hedge แล้ว Delta ที่กรอบบนเป็นเท่าไร
  4. Grid ตัวหนึ่งขาดทุน 450 USD เมื่อโดน Stop และได้กำไรสุทธิรอบละ 9 USD ต้องเก็บกี่รอบเพื่อชดเชย Stop หนึ่งครั้ง

ศัพท์ใหม่ในบทนี้
  • งบขาดทุน: ขาดทุนตามแผน ณ ราคา Stop ซึ่งเกินได้ถ้าปิดสถานะไม่ทัน
  • Gap / Slippage: ราคาเคลื่อนเร็วจนคำสั่งจับคู่ไม่ทัน ทำให้ได้ราคาแย่กว่าที่ตั้ง
  • Stop-Market / Stop-Limit: Stop ที่ปิดด้วยราคาตลาด กับ Stop ที่ปิดด้วยคำสั่ง Limit
  • Maintenance Margin: เงินประกันขั้นต่ำที่ต้องเหลืออยู่ ถ้าต่ำกว่านี้จะโดน Liquidation
  • Auto-Deleveraging: กลไกของตลาด Futures ที่บังคับลดสถานะของฝั่งที่กำไรในภาวะตลาดรุนแรง
  • Whipsaw: ราคาแตะจุด Stop แล้วกลับตัว ทำให้ขาดทุนโดยที่ทิศทางเดิมถูก
  • Roll: ปิด Grid เดิมแล้วเปิดใหม่ที่กรอบอื่น
  • Martingale: การเพิ่มขนาดทุกครั้งที่ราคาสวนทาง
  • Liquidation: การถูกบังคับปิดสถานะเมื่อ Margin ไม่พอ
  • Stress Test: การไล่คำนวณผลลัพธ์ในกรณีเลวร้ายก่อนเกิดจริง
บทถัดไป

เครื่องมือทุกตัวในบทนี้มีจุดร่วมกัน คือไม่มีตัวไหนกัน Gap ได้ และไม่มีตัวไหนลดความโค้งของกราฟได้โดยไม่ลดขนาด Grid บทที่ 11 จะนำ Option จริงเข้ามาเสริม: ซื้อ Option กันหาง เปลี่ยนชั้นไกลเป็น Short Option และเลือกเครื่องมือโดยเทียบ Implied Volatility กับ Realized Volatility

บทที่ 10 จบด้วยข้อจำกัด 2 ข้อของเครื่องมือฝั่ง Grid: ไม่มีตัวไหนกัน Gap ได้ และไม่มีตัวไหนลดความโค้งของกราฟได้โดยไม่ลดขนาด Grid ทั้งสองข้อแก้ได้ด้วย Option เพราะ Option เป็นเครื่องมือเดียวที่ให้ ความโค้งเป็นบวก โดยรู้ต้นทุนล่วงหน้า และคุ้มครองได้แม้ราคาเคลื่อนเร็วจนปิดสถานะไม่ทัน บทนี้ปล่อยให้ Grid ทำงานตามเดิม แล้วนำ Option จากบทที่ 2–6 มาวางซ้อน

11.2 ซื้อปีกกันหางล่าง: Grid + Long Put

ปีก (Wings) คือ Option ที่ซื้อไว้นอกกรอบเพื่อจำกัดขาดทุนที่หาง ทำหน้าที่เหมือนประกัน Premium ที่จ่ายซื้อปีกจึงเรียกว่า ค่าปีก

ใช้ Grid หลักตัวเดิม: ซื้อ 5 ชั้นที่ 98k ถึง 90k ชั้นละ 0.01 BTC ของเต็มมือ 0.05 BTC แทนที่จะตั้ง Stop ที่ 88,000 ให้ ซื้อ Put Strike 88,000 จำนวน 0.05 BTC จ่าย Premium 68.5 USD

ส่วนประกอบ

Grid ซื้อ 5 ชั้น (= Short Put Ladder) + Long Put K = 88,000 จำนวนเท่าของเต็มมือ

ใต้ 88,000 ของในมือ 0.05 BTC ขาดทุนเท่าไร Put 0.05 BTC ก็กำไรเท่านั้น ความชันรวมเป็นศูนย์ กราฟจึงแบน

กราฟทั้งเส้นเลื่อนลง 68.5 USD (ค่าปีก) แลกกับการที่ขาดทุน ณ วันหมดอายุมีพื้นอยู่ที่ -368.5 USD ไม่ว่าราคาจะลงเร็วหรือช้า เทียบกับ Stop ในบทที่ 10.3:

Put แพ้ Stop ในวันปกติเพราะต้องจ่ายค่าปีกทุกเดือน และชนะใน 2 กรณีที่ Stop ป้องกันไม่ได้ คือ Gap กับ Whipsaw เพราะ Put ไม่บังคับให้ปิด Grid

พื้นนี้เป็นผล ณ วันหมดอายุของ Put และจริงเมื่อ Grid เป็น Spot ที่ไม่ใช้ Leverage ถ้าเป็น Futures Grid ที่ใช้ Leverage Grid อาจโดน Liquidation ระหว่างทางก่อนที่ Put จะจ่าย เงื่อนไขนี้อธิบายในหัวข้อ 11.4

ค่าปีกเท่ากับกี่รอบ

ค่าปีก 68.5 USD ต่อ 30 วัน เทียบกับกำไรสุทธิ 18 USD ต่อรอบ เท่ากับ ประมาณ 4 รอบต่อเดือน ที่ต้องเก็บเพื่อจ่ายค่าปีก ถ้า Grid เก็บได้ต่ำกว่านี้เป็นประจำ การซื้อปีกเต็มจำนวนจะกินกำไรหมด

Stop จ่ายครั้งเดียวตอนโดน ส่วน Put เป็นค่าใช้จ่ายประจำที่ต้องต่ออายุ และ ค่าต่ออายุแพงขึ้นหลังราคาลง เช่น ถ้า Put ตัวแรกหมดอายุตอนราคาอยู่ที่ 85,000 จะได้เงินคืน 150 USD แต่ Put Strike 88,000 ตัวใหม่อายุ 30 วันราคาประมาณ 330 USD ส่วนต่าง 180 USD คือค่าปีกของเดือนถัดไป มากกว่าเดือนแรกประมาณ 2.6 เท่า

ผลพลอยได้: ปีกเป็น Long Vega

กราฟข้างบนคือผล ณ วันหมดอายุ แต่จากบทที่ 5.5 Long Put มี Vega เป็นบวก เมื่อตลาดร่วงแรง IV มักพุ่งขึ้น มูลค่าของ Put ก่อนหมดอายุจึงเพิ่มเร็วกว่าที่กราฟนี้บอก ปีกจึงช่วยได้ตั้งแต่วันที่ตลาดเริ่มร่วง ไม่ต้องรอถึงวันหมดอายุ

ปีกจ่ายเงินตอนหมดอายุ แต่ขา Futures ถูกคิดกำไรขาดทุนทุกขณะ ถ้าขา Futures โดน Liquidation ก่อน ปีกจะคุ้มครองสิ่งที่ไม่มีอยู่แล้ว

ตัวอย่าง: วาง Margin ให้ขา Short 900 USD ขานี้จะโดน Liquidation ที่ราคาประมาณ 118,000 ถ้าราคาพุ่งไปถึงระดับนั้นแล้วกลับมาจบที่ 100,000 ณ วันหมดอายุ Call จะหมดค่า และผลรวมคือขา Short -900 · Grid +300 จากการขายขาขึ้น และ -200 จากของที่ซื้อกลับขาลง · ค่าปีก -205.5 รวมขาดทุน ประมาณ 1,000 USD ไม่ใช่ 405.5 USD

  • พื้นจึงจริงเมื่อ Grid เป็น Spot ที่ไม่ใช้ Leverage หรือวาง Margin ของขา Futures ให้รอดถึงราคาไกลที่สุดที่อาจเกิดก่อนวันหมดอายุ หรือใช้ตลาดที่คิด Margin รวมทุกขาในบัญชีเดียว (Portfolio Margin)
  • การเปลี่ยนจาก Stop มาเป็นปีกจึงต้องใช้ Margin มากขึ้น ไม่ใช่น้อยลง
  • Funding ของขา Short ตลอด 30 วันไม่ได้รวมอยู่ใน 405.5 USD

สำหรับ Spot Grid ที่ไม่ได้ Hedge หางบนไม่ใช่ขาดทุนแต่เป็นการตกรถ การซื้อ Call เหนือกรอบบนจึงเป็นทางเลือก ไม่ใช่ความจำเป็น ถ้าซื้อ กราฟด้านบนจะเชิดขึ้นแทนที่จะแบน

11.5 ลดความโค้งที่ลำตัว: Grid + Long Straddle

อ่านเป็นภาษาคนก่อน: หัวข้อนี้ไม่ได้ดูกราฟ ณ วันหมดอายุเหมือนสองหัวข้อก่อน แต่ดูเส้นโค้งก่อนหมดอายุแบบบทที่ 5.1 ซึ่ง Long Straddle เป็นรูปตัว U โค้งหงาย ไม่ใช่ตัว V ส่วน Grid โค้งคว่ำ เมื่อวางซ้อนกันในขนาดที่พอดี ความโค้งหักล้างกัน สิ่งที่เหลือคือการแข่งกันระหว่างเงิน 2 ก้อน: รายได้จากการแกว่งที่ Grid ได้ทุกก้าว กับ Time Decay ที่ Straddle เสียทุกวัน

เส้นรวมเกือบแบนตลอดกรอบ ความโค้งหายไป (เส้นเอียงขึ้นทางขวาเล็กน้อย เพราะ Straddle ที่ Strike เท่ากับราคาปัจจุบันมี Delta เป็นบวกอยู่เล็กน้อย) คำนวณกับ Neutral Grid (u = 0.01 BTC, g = 2,000 USD) และ Straddle อายุ 30 วัน:

  • ถ้าตลาดผันผวนจริง 40% ราคาเดินประมาณ 1.1 ก้าวต่อวัน Grid ได้ประมาณ 11 USD ต่อวัน แพ้ Time Decay

  • ใช้เงินมาก: Premium 1,030 USD มากกว่าขาดทุนที่กรอบล่างของ Grid เอง (200 USD) หลายเท่า แบบนี้จึงเป็นการเปลี่ยนเดิมพัน จาก "ตลาดจะอยู่ในกรอบ" เป็น "ตลาดจะผันผวนกว่าที่ Option ตั้งราคาไว้"

11.6 ขยายจุดดี: เปลี่ยนคำสั่งซื้อชั้นไกลเป็น Short Put

สภาวะความหมายแนวทาง

  • IV ต่ำกว่า RV: โดยทั่วไป IV มักสูงกว่า RV ที่เกิดตามมา เพราะผู้ขาย Option ต้องการค่าตอบแทนจากการรับความเสี่ยง ช่วงที่ IV ต่ำกว่า RV ย้อนหลังมักเกิดหลังตลาดเพิ่งผันผวนแรง และตลาดคาดว่าความผันผวนจะลดลง Option จึงอาจไม่ได้ถูกจริง
  • ต้นทุนการซื้อขาย: ส่วนต่างราคาเสนอซื้อ–ขายและค่าธรรมเนียมของ Option กินส่วนต่างระหว่าง RV กับ IV ได้ทั้งหมด โดยเฉพาะกับ Grid + Long Straddle ขนาดเล็ก

11.9 แผนตามวงจรชีวิตของ Grid

ช่วงสิ่งที่ทำ
ก่อนเปิด ทำ Checklist บทที่ 10.11 แล้วเพิ่ม 3 ข้อ: วัด RV เทียบ IV, เลือกแบบปีกและ Strike, คำนวณว่าค่าปีกเท่ากับกี่รอบต่อเดือน
เลือกอายุของปีก สำหรับปีกกันหาง อายุยาว (2–3 เดือน) จ่ายมากกว่าตอนซื้อ แต่เสีย Time Decay ต่อวันน้อยกว่าและไม่ต้องต่ออายุบ่อย สำหรับ Grid + Long Straddle การเลือกอายุไม่ได้เปลี่ยน Time Decay ต่อวัน (ดูหัวข้อ 11.5)
ระหว่างทาง ต่ออายุปีก (Roll) ก่อนหมดอายุ ไม่ปล่อยให้มีช่วงที่ไม่มีปีก ค่าต่ออายุแพงขึ้นหลังราคาลง (ดูหัวข้อ 11.2) และถ้าย้ายกรอบของ Grid ต้องย้าย Strike ของปีกตาม
หลุดกรอบล่าง (ของเต็มมือ) ถ้ามี Put: ขาดทุนถูกจำกัดแล้ว เลือกได้ว่าจะปิดทั้งชุดหรือถือต่อโดยมีพื้น ถ้าถือของต่อ ขาย Call บนของที่ถืออยู่ (Covered Call) เพื่อรับ Premium ระหว่างรอได้ แต่ ต้องหยุด Grid หรือยกเลิกคำสั่งขายของจำนวนเดียวกันก่อน มิฉะนั้นเมื่อราคาเด้ง Grid จะขายของออกไป และ Call ที่ขายไว้จะไม่มีของรองรับ
หลุดกรอบบน (ของหมด) ขาย Put ที่ราคาที่ยินดีซื้อของกลับ (Cash-Secured Put) ได้ Premium ระหว่างรอราคาย่อ แทนการไล่ซื้อ ถ้าราคาลงต่ำกว่า Strike จะรับขาดทุนเท่ากับการซื้อที่ราคานั้น
Covered Call บนของที่ติด: เลือก Strike ให้ไม่ต่ำกว่าต้นทุน

ใน Grid หลัก ของเต็มมือ 0.05 BTC มีต้นทุนเฉลี่ย 94,000 USD ถ้าขาย Call ที่ Strike ต่ำกว่าต้นทุน เช่น 90,000 แล้วราคาเด้งกลับแรง ต้องจ่ายส่วนต่างเหนือ Strike ทั้งหมด กำไรของเหรียญที่ถือจึงถูกจำกัดไว้ที่ Strike ซึ่งต่ำกว่าต้นทุน เท่ากับล็อกขาดทุนไว้เอง Strike ที่ไม่ต่ำกว่าต้นทุนเฉลี่ยได้ Premium น้อยกว่า แต่ไม่ปิดทางฟื้น

11.10 ข้อจำกัดเชิงปฏิบัติ

เรื่องสิ่งที่ต้องรู้
ขนาดสัญญาขนาดขั้นต่ำของ Option ต่างกันตามตลาด โดยทั่วไปอยู่ในช่วงประมาณ 0.01 ถึง 0.1 BTC ต่อคำสั่ง ซึ่งมักใหญ่กว่าขนาดต่อชั้นของ Grid รายย่อย ตัวอย่างในบทนี้ใช้ 0.05 BTC เพื่อให้ต่อเนื่องกับบทก่อน ในการใช้จริงต้องตรวจสเปกสัญญาปัจจุบันของตลาดที่ใช้ แล้วออกแบบขนาด Grid ให้ของเต็มมือลงตัวกับสัญญาขั้นต่ำ
การชำระราคาไม่มีการส่งมอบเหรียญ ตลาดจ่ายเฉพาะส่วนต่าง Short Put ในหัวข้อ 11.6 จึงไม่ได้ "รับของ" จริง ถ้าต้องการของต้องซื้อเองในตลาด Spot และสกุลที่ใช้ชำระต่างกันตามตลาดและชนิดสัญญา บางแบบชำระเป็น BTC หรือ ETH บางแบบชำระเป็น Stablecoin ถ้าหลักประกันเป็นเหรียญ มูลค่าหลักประกันจะลดลงพร้อมกับที่ Short Put ขาดทุน
Option บน ETFOption บนกองทุน ETF ของ BTC ในตลาดหุ้นสหรัฐเป็นอีกแบบหนึ่ง ใช้สิทธิ์ก่อนหมดอายุได้และส่งมอบหน่วยกองทุนจริง ไม่อยู่ในขอบเขตของบทนี้
ค่าธรรมเนียมของ Optionมักคิดจากมูลค่าสินทรัพย์อ้างอิง ไม่ใช่จาก Premium จึงสูงเมื่อเทียบกับ Option ที่ราคาถูก สมมติคิด 0.03% ของ 100,000 USD คือ 30 USD ต่อ 1 BTC เทียบกับ Premium 330 USD ของ Put Strike 80,000 เท่ากับประมาณ 9% และกลยุทธ์หลายขาอย่าง Butterfly ต้องจ่ายทุกขา
สภาพคล่องStrike ที่ไกลและอายุที่ไม่ใช่รอบหลักมีส่วนต่างราคาเสนอซื้อ–ขายกว้าง ต้นทุนจริงของปีกจึงสูงกว่าราคากลาง
SkewIV ของแต่ละ Strike ไม่เท่ากัน ตารางราคาต้นบทใช้ IV เท่ากันทุก Strike ซึ่งเป็นการทำให้ง่าย
ราคาอ้างอิงOption ชำระตามดัชนีราคาของตลาด Option ซึ่งอาจต่างจากราคาในตลาดที่ Grid ทำงานอยู่ ช่วงตลาดผันผวนส่วนต่างนี้กว้างขึ้นได้
Margin ของฝั่งขายShort Put และ Short Call ต้องวาง Margin และ Margin ที่ต้องใช้เพิ่มขึ้นเมื่อราคาวิ่งสวนหรือ IV พุ่ง ต้องนับรวมในการคำนวณ Liquidation ของทั้งบัญชี (บทที่ 10.8)
ต้นทุนสะสมในปีที่ตลาดเงียบ ค่าปีกที่จ่ายทุกเดือนโดยไม่ได้ใช้จะกิน Grid Profit ไปเรื่อย ๆ เป็นต้นทุนที่ต้องยอมรับตั้งแต่ต้น
การเข้าถึงและคู่สัญญาตลาดที่มี Futures และ Option ของคริปโตส่วนใหญ่อยู่ต่างประเทศ ผู้อ่านในไทยต้องตรวจกฎของสำนักงาน ก.ล.ต. และสถานะของแพลตฟอร์ม ณ เวลาที่จะใช้ และควรนับความเสี่ยงที่ตลาดล้มหรือระงับการถอน กับความเสี่ยงที่ Stablecoin หลุดมูลค่า ไว้ในงบขาดทุนด้วย

12.1 กฎการถอด: คำสั่ง 2 ชนิด ให้จุดหักมุม 2 แบบ

จากบทที่ 9.2 ความชันของกราฟคือของในมือ ดังนั้น ทุกจุดที่ความชันเปลี่ยน ต้องมีคำสั่งหนึ่งตัววางอยู่ และขนาดของคำสั่งเท่ากับขนาดที่ความชันเปลี่ยน คำสั่งมี 2 ชนิด ให้จุดหักมุมคนละทิศ:

ชนิดคำสั่งพฤติกรรมจุดหักมุมที่ได้เทียบ Option
Limit Order ซื้อเมื่อราคาลงถึง ขายเมื่อราคาขึ้นถึง (สวนราคา) หักคว่ำ: เดินไปทางขวาแล้วความชันลดลง Short Option ที่ Strike นั้น
Stop Order ซื้อเมื่อราคาขึ้นถึง ขายเมื่อราคาลงถึง (ตามราคา) หักหงาย: เดินไปทางขวาแล้วความชันเพิ่มขึ้น Long Option ที่ Strike นั้น
วิธีถอด 4 ขั้น
  1. วาดรูป Payoff ที่ต้องการเป็นเส้นตรงต่อกันเป็นช่วง ๆ
  2. อ่านความชัน ของแต่ละช่วง ซึ่งคือของในมือที่ต้องถือเมื่อราคาอยู่ในช่วงนั้น ความชันของช่วงที่ราคาปัจจุบันอยู่คือของที่ต้องถือตั้งต้น
  3. หาผลต่าง ของความชันที่แต่ละจุดหักมุม โดยไล่จากซ้ายไปขวาเสมอ ขนาดของผลต่างคือขนาดคำสั่ง ถ้าความชันลดลงเป็นจุดหักคว่ำ ถ้าเพิ่มขึ้นเป็นจุดหักหงาย
  4. เลือกคำสั่ง ตามตำแหน่งของจุดหักมุมเทียบกับราคาปัจจุบัน:
    • ใต้ราคาปัจจุบัน: หักคว่ำใช้ Buy Limit · หักหงายใช้ Sell Stop
    • เหนือราคาปัจจุบัน: หักคว่ำใช้ Sell Limit · หักหงายใช้ Buy Stop
สิ่งที่การถอดไม่ได้ให้มาฟรี

ชุดคำสั่งให้รูป Floating P&L ตรงตามที่วาด แต่ P&L จริงมีอีกก้อนที่ขึ้นกับเส้นทางราคาเสมอ:

  • จุดหักคว่ำ (Limit) ได้เงินเพิ่มทุกครั้งที่ราคาแกว่งผ่าน เหมือน Grid Profit
  • จุดหักหงาย (Stop) เสียเงินทุกครั้งที่ราคาแกว่งผ่าน เรียกว่า Whipsaw และเสียเพิ่มเมื่อราคา Gap

ก้อนนี้คือสิ่งที่มาแทน Premium ของ Option รูปโค้งคว่ำได้รับ รูปโค้งหงายต้องจ่าย

คำสั่งแต่ละตัวทำงานครั้งเดียว ถ้าต้องการให้รูปคงอยู่เมื่อราคากลับมา ต้องตั้งคำสั่งกลับทิศใหม่ทุกครั้ง: Limit ตั้งกลับห่างไป 1 ช่อง ซึ่งได้กำไร 1 รอบ ส่วน Stop ตั้งกลับที่ระดับเดิม ซึ่งเป็นที่มาของ Whipsaw

Stop-loss คือ Reverse Grid ชั้นเดียว

ถือ BTC อยู่ 1 หน่วย แล้วตั้ง Sell Stop ไว้ใต้ราคา กราฟที่ได้คือ "แบนด้านล่าง ลาดขึ้นด้านบน" ซึ่งเป็นรูปของ Long Call และตาม Synthetic Positions ในบทที่ 2.6 ก็คือ Long Stock + Long Put

Stop-loss จึงเป็น Long Put สังเคราะห์ ที่ไม่ต้องจ่าย Premium ล่วงหน้า แต่จ่ายเป็น Whipsaw ทุกครั้งที่โดน Stop แล้วราคากลับ และไม่คุ้มครองเมื่อราคา Gap นี่คือเหตุผลเชิงโครงสร้างของตารางเทียบ Stop กับ Put ในบทที่ 11.2

12.4 อ่านกลยุทธ์อื่นด้วย Payoff Chart

ใช้คำถามเดียวกับทุกกลยุทธ์: เมื่อราคาเปลี่ยน ของในมือเปลี่ยนอย่างไร ถ้าราคาลงแล้วถือเพิ่ม กราฟโค้งคว่ำ ถ้าราคาขึ้นแล้วถือเพิ่ม กราฟโค้งหงาย

กลยุทธ์ของในมือเมื่อราคาเปลี่ยนรูป Payoffสิ่งที่กราฟบอก
Take-profit เป็นชั้น (ถือของแล้วทยอยขาย) ราคาขึ้น ถือน้อยลง โค้งคว่ำ มีเพดาน คือ Covered Call Ladder ครึ่งบนของ Spot Grid
ซื้อถัวตามราคา (ทยอยซื้อเมื่อราคาลง ไม่ตั้งขาย) ราคาลง ถือเพิ่ม และไม่ลดเมื่อราคากลับ โค้งคว่ำช่วงขาลง แล้วเป็นเส้นตรง คือ Grid ที่ไม่มี Take-profit ไม่ได้ Grid Profit แต่ได้ขาขึ้นเต็มจำนวนถ้าราคากลับ
Martingale แบบคูณสอง (เพิ่มขนาดเป็นเท่าตัวเมื่อราคาสวน) ราคาลง ถือเพิ่มเร็วขึ้นเรื่อย ๆ โค้งคว่ำที่ชันขึ้นทุกชั้น Short Gamma ที่โตตามความลึก ดูตัวเลขด้านล่าง
Rebalancing 50/50 (ปรับสัดส่วนเหรียญกับเงินสดให้เท่ากันเสมอ) ราคาขึ้นขายออก ราคาลงซื้อเพิ่ม โค้งคว่ำรูป √S คือ Grid ต่อเนื่องที่ไม่มีกรอบ ได้เงินจากการแกว่งเหมือน Grid
Pyramiding (เพิ่มขนาดเมื่อกำไร) ราคาขึ้น ถือเพิ่ม โค้งหงาย คือ Reverse Grid ฝั่งเดียว เสีย Whipsaw เมื่อราคากลับ
Trend-following / Breakout ราคาทะลุขึ้นแล้วซื้อ ทะลุลงแล้วขาย โค้งหงายสองด้าน คือ Long Straddle สังเคราะห์ จ่ายด้วยสัญญาณหลอก

การซื้อถัวตามเวลา (DCA ทุกเดือนไม่ว่าราคาเท่าไร) ไม่อยู่ในตาราง เพราะของในมือขึ้นกับเวลา ไม่ได้ขึ้นกับราคา จึงวาดเป็น Payoff Chart ตามราคาไม่ได้

12.5 AMM: Grid ที่ละเอียดจนเป็นเส้นโค้ง

AMM (Automated Market Maker) คือตลาดที่ไม่มีสมุดคำสั่งซื้อขาย ผู้ฝากนำเหรียญสองชนิดมากองรวมกันเรียกว่า Pool เช่น ETH กับ Stablecoin ซึ่งเป็นเหรียญที่ตรึงมูลค่าไว้กับ USD แล้วให้คนอื่นมาแลกกับ Pool ตามราคาที่สูตรกำหนด ผู้ฝากเรียกว่า Liquidity Provider (LP) และได้ค่าธรรมเนียมจากทุกการแลก

การเป็น LP คือ Grid ที่ระยะห่างระหว่างชั้นเล็กจนเป็นเส้นต่อเนื่อง Pool ขาย ETH ออกเมื่อราคาขึ้นและรับ ETH เข้าเมื่อราคาลงโดยอัตโนมัติ สำหรับ Pool แบบพื้นฐานที่สุดซึ่งไม่จำกัดกรอบราคา (เรียกว่า Constant Product):

มูลค่าของ LP = มูลค่าเริ่มต้น × √(S / S₀)
มูลค่าถ้าถือเฉย ๆ = มูลค่าเริ่มต้น × (1 + S / S₀) / 2
Impermanent Loss = 2√x / (1 + x) - 1   โดย x = S / S₀

กราฟนี้แกนตั้งเป็นมูลค่ารวม ไม่ใช่ P&L เหมือนกราฟก่อนหน้า เส้นโค้งของ LP อยู่ใต้เส้นตรงของการถือเฉย ๆ ทุกจุดยกเว้นจุดเริ่ม ส่วนแรเงาคือ Impermanent Loss ซึ่งเป็น Floating P&L รูปโค้งคว่ำแบบเดียวกับ Grid: ราคาไป 2 เท่าหรือเหลือครึ่งหนึ่ง ตามหลังการถือเฉย ๆ 5.7% ราคาไป 4 เท่าหรือเหลือหนึ่งในสี่ ตามหลัง 20%

ตัวเลขนี้เทียบกับการถือเฉย ๆ ไม่ใช่ขาดทุนเป็นเงิน ถ้าราคาเหลือครึ่งหนึ่ง มูลค่าของ LP ลดลงประมาณ 29% ขณะที่การถือเฉย ๆ ลดลง 25%

LP ที่เลือกช่วงราคาได้มีรูป Payoff เดียวกับ Spot Grid คือ Short Put Ladder ที่ละเอียดมาก แนวคิดของบทที่ 10 และ 11 จึงนำมาใช้ได้: คำนวณขาดทุนที่ขอบล่างก่อนฝาก ช่วงยิ่งแคบ Gamma ยิ่งติดลบมาก (ได้ค่าธรรมเนียมเข้มข้นขึ้นและ Impermanent Loss เร็วขึ้น) และกันหางได้ด้วย Long Put เหมือนกัน

แต่การเทียบนี้เป็นการเทียบรูปร่าง ข้อต่างที่ต้องรู้มี 3 ข้อ:

  • รายได้ไม่ได้มาจากการแกว่งโดยตรง: Grid ได้กำไร 1 ช่องทุกรอบโดยโครงสร้าง ส่วน LP ซื้อและขายบนเส้นโค้งเดียวกัน ถ้าไม่มีค่าธรรมเนียม LP จะไม่ได้อะไรจากการแกว่งเลย ส่วนต่างนั้นตกเป็นของผู้ที่เข้ามาแลกเพื่อปรับราคาของ Pool ให้ตรงกับตลาด สำหรับ Pool ไม่จำกัดกรอบ ส่วนที่เสียไปนี้อยู่ที่ประมาณ σ² / 8 ของมูลค่า Pool ต่อปี เช่น ที่ความผันผวน 50% คือประมาณ 3% ต่อปี
  • ค่าธรรมเนียมขึ้นกับสิ่งที่คุมไม่ได้: ได้มากหรือน้อยขึ้นกับปริมาณการแลก อัตราค่าธรรมเนียมของ Pool และส่วนแบ่งของเราในช่วงราคานั้น และต้องมากกว่าส่วนที่เสียไปในข้อแรกจึงจะคุ้ม
  • ไม่มีคำสั่ง Stop ในตัว: การออกต้องทำเองหรือใช้เครื่องมือเสริม และยังมีค่าธรรมเนียมเครือข่ายกับความเสี่ยงของสัญญาอัจฉริยะเพิ่มเข้ามา

12.6 Grid ที่ปรับตัวได้ และ Grid บนอัตราส่วนราคา

รูปแบบทำอะไรความหมายบน Payoff Chartข้อควรระวัง
g ตามความผันผวน ตลาดผันผวนมากตั้ง g กว้าง ผันผวนน้อยตั้งแคบ รักษาจำนวนก้าวต่อวันให้ใกล้เคียงเดิม และลด Gamma เมื่อตลาดแรง การเปลี่ยน g กลางทางคือการ Roll ต้องรับรู้ P&L ของชุดเดิม
Trailing Grid เลื่อนกรอบตามราคาโดยอัตโนมัติ Roll Up หรือ Roll Down ทุกครั้งที่ราคาหลุดกรอบ (บทที่ 10.6) เลื่อนตามขาลงคือรับรู้ขาดทุนซ้ำ ๆ เลื่อนตามขาขึ้นคือซื้อคืนแพงขึ้นเรื่อย ๆ
Grid ไม่มีกรอบบน ขายทีละส่วนเมื่อราคาขึ้น โดยไม่เคยขายหมด ใกล้เคียง Rebalancing ในหัวข้อ 12.4 ไม่มีเพดาน กำไรต่อรอบเล็กลง และหางล่างยังอยู่ครบ
Grid บนอัตราส่วนราคาของสองสินทรัพย์ ทำ Grid บนอัตราส่วนของสองสินทรัพย์ เช่น ETH/BTC โดย Long ตัวหนึ่ง Short อีกตัว กราฟเดิมทุกอย่าง แต่แกนนอนเป็นอัตราส่วน ไม่ใช่ราคา อัตราส่วนมักผันผวนน้อยกว่าราคาเดี่ยว แต่ไม่ได้แกว่งกลับเสมอ ETH/BTC เคยลดลงต่อเนื่องหลายปี จากประมาณ 0.08 ในปี 2022 เหลือต่ำกว่า 0.02 ในปี 2025 Grid บนอัตราส่วนในช่วงนั้นจะถือฝั่งที่แพ้เต็มมือ

ทุกรูปแบบในตารางยังเป็น Short Gamma เหมือนเดิม การปรับตัวเปลี่ยนได้ว่าความโค้งอยู่ตรงไหนและมากแค่ไหน แต่ไม่เปลี่ยนเครื่องหมายของมัน

สรุปบทที่ 12 และภาค 2

  2. Limit คือ Short Option ที่ได้เงินจากการแกว่ง Stop คือ Long Option ที่จ่ายด้วย Whipsaw
  3. Reverse Grid คือกระจกเงาของ Grid กฎ √n เป็นเส้นแบ่งว่าตลาดช่วงนั้นเป็นของฝั่งไหน

  5. ไม่มีรูป Payoff ไหนได้มาฟรี ความโค้งทุกแบบมีเงินก้อนหนึ่งมาคู่กันเสมอ ไม่จ่ายล่วงหน้าก็ทยอยจ่ายระหว่างทาง

ศัพท์ใหม่ในบทนี้
  • Limit Order: คำสั่งที่ทำงานเมื่อราคามาถึงในทิศที่ได้ราคาดีขึ้น (ซื้อถูกลง ขายแพงขึ้น)
  • Stop Order: คำสั่งที่ทำงานเมื่อราคาทะลุระดับในทิศที่ได้ราคาแย่ลง (ซื้อแพงขึ้น ขายถูกลง)

  • Pyramiding: การเพิ่มขนาดเมื่อสถานะมีกำไร

Appendix: สูตรสำคัญ

Put-Call Parity

C + K·e-rT = P + S

Black-Scholes Model

Call: C = S·N(d₁) - K·e-rT·N(d₂)

Put: P = K·e-rT·N(-d₂) - S·N(-d₁)

โดยที่:
d₁ = [ln(S/K) + (r + σ²/2)T] / (σ√T)
d₂ = d₁ - σ√T

N(x) = Cumulative Standard Normal Distribution
N'(x) = Standard Normal PDF = (1/√2π) · e-x²/2

Greeks Formulas

Delta:
ΔCall = N(d₁)
ΔPut = N(d₁) - 1

Gamma:
Γ = N'(d₁) / (S · σ · √T)

Theta:
ΘCall = -S·N'(d₁)·σ / (2√T) - r·K·e-rT·N(d₂)
ΘPut = -S·N'(d₁)·σ / (2√T) + r·K·e-rT·N(-d₂)
(ค่าข้างต้นเป็น per year, หาร 365 เพื่อได้ daily theta)

Vega:
ν = S · N'(d₁) · √T
(ค่าข้างต้นเป็น per 100%, หาร 100 เพื่อได้ per 1% change)

Payoff Formulas (ณ วันหมดอายุ)

Long Call: max(0, S - K) - Premium
Short Call: Premium - max(0, S - K)
Long Put: max(0, K - S) - Premium
Short Put: Premium - max(0, K - S)

หลักการ: Short Payoff = -1 × Long Payoff (เสมอ)

สูตร P&L ของ Grid (บทที่ 9)

สูตร: P&L รวม = (u × g / 2) × (n - k²)

จำนวนรอบที่ครบ = (n - k) / 2
Grid Profit = u × g × (n - k) / 2
Floating P&L = -u × g × k(k - 1) / 2

ถ้ามีของตั้งต้น q₀: บวกเพิ่ม q₀ × (ST - S₀)

u = ขนาดต่อชั้น · g = ระยะห่างระหว่างเส้น Grid · n = จำนวนก้าวที่ราคาเดิน · k = จำนวนช่องที่ราคาจบห่างจากจุดเริ่ม · S₀ = ราคาเริ่ม · ST = ราคาตอนจบ

เงื่อนไข: Grid เริ่มโดยไม่มีของในมือ ขนาดและระยะห่างเท่ากันทุกชั้น ราคายังอยู่ในกรอบ และยังไม่หักค่าธรรมเนียม n กับ k เป็นเลขคู่ทั้งคู่หรือเลขคี่ทั้งคู่เสมอ

ที่มา: ให้ราคาเดินรวม n ก้าว และจบห่างจากจุดเริ่ม k ช่อง

  • ใน n ก้าวนั้น มี k ก้าวที่เป็นการเดินสุทธิออกจากจุดเริ่ม ที่เหลือ n - k ก้าวจับคู่กันเป็นรอบซื้อ–ขายได้ (n - k) / 2 รอบ รอบละ u × g
  • เหรียญที่ยังถืออยู่ k ชั้น ซื้อมาที่ระยะ 1, 2, ..., k ช่องจากจุดเริ่ม ตอนราคาอยู่ห่าง k ช่อง แต่ละชั้นขาดทุน k - 1, k - 2, ..., 0 ช่อง รวมเป็น k(k - 1) / 2 ช่อง ช่องละ u × g
  • บวกสองก้อน: (u × g / 2) × [ (n - k) - k(k - 1) ] = (u × g / 2) × (n - k²)

รูปแบบต่อเนื่อง: ผลรวมของระยะที่ราคาเดินแต่ละก้าวยกกำลังสองคือ n × g² ซึ่งเป็นค่าประมาณของ Quadratic Variation (QV) ของราคา ยิ่งเส้น Grid ถี่ยิ่งใกล้ค่าจริง และ (ST - S₀)² เท่ากับ k² × g² สูตรจึงเขียนได้อีกแบบว่า

P&L ≈ u × [ QV - (ST - S₀)² ] / (2g)

สูตรอื่นของภาค 2

จำนวนก้าวต่อวัน (บทที่ 9.6): n ต่อวัน ≈ (σวัน × S / g)²   โดย σวัน = σปี / √365

วัด RV จาก Grid (บทที่ 11.8): RV ต่อปี ≈ (g / S) × √(n ต่อวัน × 365)

โอกาสที่ราคาแตะระดับ L ภายในเวลา T (บทที่ 11.8): ≈ 2 × N( ln(L / S) / (σ√T) ) สำหรับ L ที่ต่ำกว่า S

Grid แบบเรขาคณิต ใส่เงินเท่ากันทุกชั้น (บทที่ 9.7): Floating P&L แปรผันตาม ln(S / S₀) - (S - S₀) / S₀

AMM แบบ Constant Product (บทที่ 12.5): มูลค่า LP = มูลค่าเริ่มต้น × √(S / S₀)

ln คือลอการิทึมธรรมชาติ และ N( ) คือ Cumulative Standard Normal Distribution ตัวเดียวกับในสูตร Black-Scholes ข้างบน สูตรจำนวนก้าวและโอกาสแตะเป็นค่าประมาณที่ไม่คิดแนวโน้มของราคา
