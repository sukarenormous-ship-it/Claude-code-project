ศัพท์: Sharpe ratio = ผลตอบแทนส่วนเกินต่อความเสี่ยง 1 หน่วย · Sortino = Sharpe ที่นับเฉพาะความเสี่ยงขาลง · CAPM = โมเดลบอกว่า β เท่านี้ควรได้ผลตอบแทนเท่าไร · Alpha = ส่วนที่เก่งเกินกว่าความเสี่ยงที่รับ · Kelly = สูตรหาขนาดเดิมพันที่โตเร็วสุด · Drawdown = ตกจากยอดสูงสุดกี่ %

เปิดเรื่อง: มี edge ชนะ 55% แล้วยังเจ๊งได้ยังไง

สมมติมีเกมที่คุณได้เปรียบจริง — โยนเหรียญเอนเอียงที่ออกหัว 55% ได้เงินเท่าที่เดิมพัน ออกก้อย 45% เสียเท่าที่เดิมพัน · เล่น 200 ครั้ง · คำถามเดียว: ควรเดิมพันครั้งละกี่ % ของเงินที่มี?

  • เดิมพัน 10% → เงินโตเป็น 2.72 เท่า
  • เดิมพัน 25% → ขาดทุนเหลือ 0.26 เท่า ทั้งที่ยังชนะ 55% เหมือนเดิม

บทที่ 10: วัดผลตอบแทนต่อความเสี่ยง

ก่อนจะตอบว่า "ลงเท่าไร" ต้องตอบก่อนว่า "กลยุทธ์นี้ดีแค่ไหนจริง ๆ" · และผลตอบแทนดิบไม่เคยตอบคำถามนั้นได้

10.1 Sharpe Ratio — ผลตอบแทนต่อความเสี่ยง 1 หน่วย

🚶 อ่านเป็นภาษาคนก่อน: ถ้ากองทุนหนึ่งได้ 18% แต่เหวี่ยงหนักมาก กับอีกกองได้ 10% แต่นิ่ง — ใครเก่งกว่า? · คำตอบคือต้องหารด้วยความเสี่ยงที่รับไป · แล้วต้องหักผลตอบแทนที่ได้ฟรีอยู่แล้ว (พันธบัตร) ออกก่อน เพราะนั่นไม่ใช่ฝีมือใคร

Sharpe = (ผลตอบแทน − ผลตอบแทนปลอดความเสี่ยง) / σ = (R − r_f) / σ อ่านว่า: "รับความเสี่ยง 1 หน่วย ได้ผลตอบแทนส่วนเกินกี่หน่วย"
🧮 เดินเลขจริง — กองทุน 3 กอง (r_f = 2%)
กองทุนผลตอบแทนσSharpeอ่านว่า
A หุ้นโต18%30%(18−2)/30 = 0.53ได้เยอะ แต่แลกด้วยความเสี่ยงเยอะกว่า
B สมดุล10%8%(10−2)/8 = 1.00คุ้มค่าความเสี่ยงที่สุด
C ตราสารหนี้5%4%(5−2)/4 = 0.75ปลอดภัยแต่ส่วนเกินน้อย

B ได้ผลตอบแทนน้อยกว่า A เกือบครึ่ง แต่ Sharpe สูงเป็นเท่าตัว · เพราะถ้าคุณอยากได้ผลตอบแทนเท่า A คุณแค่ใช้ leverage กับ B — กู้มาลงเพิ่มให้ความเสี่ยงเท่า A แล้วจะได้ผลตอบแทนมากกว่า A ด้วยซ้ำ · Sharpe จึงเป็นตัววัดคุณภาพ ส่วนขนาดค่อยปรับด้วย leverage ทีหลัง

🔧 เกณฑ์คร่าว ๆ ที่ใช้กันในวงการ
Sharpeตีความ
< 0.5อ่อน — อาจไม่คุ้มค่าเหนื่อย
0.5 – 1.0ปกติของกองทุนหุ้นทั่วไป
1.0 – 2.0ดีมาก
> 2.0สงสัยไว้ก่อน — มักมาจาก backtest ที่ overfit หรือหางที่ยังไม่ระเบิด

แถวสุดท้ายสำคัญ: เล่ม 2 · C §6.7 เตือนเรื่อง overfitting ไว้แล้ว · Sharpe สูงผิดปกติจาก backtest คือธงแดง ไม่ใช่ธงเขียว

10.2 กับดักของ Sharpe — 3 จุดที่มันโกหกคุณได้

❌ กับดักที่ 1 — Sharpe มองไม่เห็นความเบ้

Sharpe ใช้ σ ซึ่งลงโทษการเหวี่ยงขึ้นเท่ากับการเหวี่ยงลง · แต่ไม่มีใครกลัววันที่กำไรเยอะเกินคาด · ลองดูสองกลยุทธ์ที่ผลตอบแทนและ σ เท่ากันเป๊ะ:

A สมมาตรB เบ้ซ้าย
ผลตอบแทน/ปี20.2%20.2%
σ/ปี19.0%19.0%
Sharpe0.950.95 ← เท่ากันเป๊ะ
Sortino1.630.65 ← ต่างลิบ
ความเบ้ (skew)−0.02−2.78
วันแย่ที่สุด−3.9%−6.5%
วันดีที่สุด+3.8%+1.4%

B คือโปรไฟล์ "เก็บเหรียญหน้ารถบดถนน" — กำไรเล็ก ๆ บ่อย ๆ แล้วขาดทุนหนักเป็นครั้งคราว · เป็นโปรไฟล์เดียวกับการขาย option ดิบ ๆ ที่ เล่ม 1 Part IV เตือนไว้ · Sharpe บอกว่าทั้งคู่ดีเท่ากัน — Sharpe คิดผิด

ทางแก้: ใช้ Sortino ควบคู่ — สูตรเดียวกันแต่หารด้วย "σ ของเฉพาะวันที่ติดลบ" จึงไม่ลงโทษการเหวี่ยงขึ้น

Sortino = (R − r_f) / σ_ขาลง ← นับเฉพาะวันที่ผลตอบแทนติดลบ
❌ กับดักที่ 2 — การแปลงเป็นรายปีทำให้ Sharpe ดูดีเกินจริง

Sharpe รายวันแปลงเป็นรายปีด้วยการคูณ √252 (เพื่อนเก่า σ√T จาก Part II) · แต่สูตรนี้ตั้งอยู่บนสมมติฐานว่าผลตอบแทนแต่ละวันเป็นอิสระต่อกัน

กลยุทธ์ที่มี autocorrelation (เช่น ถือสินทรัพย์สภาพคล่องต่ำที่ราคาปรับช้า) จะดู σ ต่ำผิดปกติ → Sharpe พองขึ้นแบบไม่จริง · นี่คือเหตุผลที่กองทุนบางประเภทโชว์ Sharpe สูงลิ่วในยามปกติ แล้วพังในวันที่ต้องขายจริง

❌ กับดักที่ 3 — Sharpe ไม่รู้จักหางหนา

σ วัดการเหวี่ยงเฉลี่ย · เล่ม 2 · C §7.5 แสดงแล้วว่าสองชุดที่ σ เท่ากันมีวันแย่สุดต่างกันได้ 3 เท่า · Sharpe จึงมองไม่เห็นความเสี่ยงหาง ต้องดู Expected Shortfall และ max drawdown (§11.5) ควบคู่เสมอ

🐍 Python — Sharpe · Sortino · และพิสูจน์ว่า Sharpe มองไม่เห็นความเบ้
# pip install numpy
import numpy as np

rng = np.random.default_rng(5)
n, sd, mu = 1000, 0.012, 0.0008

# สร้าง 2 ชุดที่บังคับให้ mean กับ SD เท่ากันเป๊ะ
A = rng.normal(0, 1, n); A = (A - A.mean())/A.std()                # สมมาตร
B = np.where(rng.random(n) < 0.90,
             rng.normal(0.45, 0.35, n),                             # กำไรเล็ก 90%
             rng.normal(-4.0, 1.2, n))                              # ขาดทุนใหญ่ 10%
B = (B - B.mean())/B.std()
A, B = A*sd + mu, B*sd + mu

def ratios(x, rf=0.02):
    ann = x.mean()*252
    total_sd = x.std()*np.sqrt(252)                # σ ทั้งหมด → Sharpe
    down_sd  = x[x < 0].std()*np.sqrt(252)         # ★ σ เฉพาะวันติดลบ → Sortino
    return ann, (ann-rf)/total_sd, (ann-rf)/down_sd

for name, x in [("A สมมาตร", A), ("B เบ้ซ้าย", B)]:
    r, sharpe, sortino = ratios(x)
    print(f"{name}: ผลตอบแทน {r:.1%} | Sharpe {sharpe:.2f} | Sortino {sortino:.2f} | แย่สุด {x.min():.1%}")
# A สมมาตร: ผลตอบแทน 20.2% | Sharpe 0.95 | Sortino 1.63 | แย่สุด -3.9%
# B เบ้ซ้าย: ผลตอบแทน 20.2% | Sharpe 0.95 | Sortino 0.65 | แย่สุด -6.5%
print("→ Sharpe เท่ากันเป๊ะ แต่ Sortino ต่างกัน 2.5 เท่า")

10.3 CAPM — ผลตอบแทนเท่าไรถึงจะ "สมกับความเสี่ยง"

🚶 อ่านเป็นภาษาคนก่อน: ถ้าคุณรับความเสี่ยงตลาดมากกว่าคนอื่น คุณควรได้ผลตอบแทนมากกว่าเป็นธรรมดา — นั่นไม่ใช่ฝีมือ · CAPM คือสูตรที่บอกว่า "ด้วย β เท่านี้ คุณควรได้เท่าไร" เพื่อให้เราแยก "เก่งจริง" ออกจาก "แค่เสี่ยงมาก"

E[R] = r_f + β × (R_ตลาด − r_f) ↑ ↑ ↑ ได้ฟรี ความไวต่อตลาด ค่าตอบแทนของการรับความเสี่ยงตลาด (จาก เล่ม 2·A) (market risk premium)
🧮 ตาราง — r_f = 2% · market risk premium = 7%
βคำนวณควรได้ผลตอบแทนแปลว่า
0.52% + 0.5×7%5.5%นิ่งกว่าตลาดครึ่งหนึ่ง
1.02% + 1.0×7%9.0%เท่าตลาดพอดี
1.52% + 1.5×7%12.5%เหวี่ยงกว่าตลาด 1.5 เท่า
2.02% + 2.0×7%16.0%เหวี่ยงเป็น 2 เท่า

10.4 Alpha — แยก "เก่งจริง" ออกจาก "เสี่ยงมาก"

💎 ตัวเลขที่เปลี่ยนวิธีอ่านผลงานกองทุนไปเลย

กองทุนหนึ่งโฆษณาว่า "ปีนี้ทำได้ 14% ชนะตลาดที่ได้ 9%" · ฟังดูเก่งมาก · แต่พอดู β ของกองนี้พบว่าเท่ากับ 1.5

CAPM บอกว่าด้วย β=1.5 ควรได้ = 2% + 1.5 × 7% = 12.5% alpha = ผลตอบแทนจริง − ที่ควรได้ = 14% − 12.5% = +1.5%

แปลว่าจาก "ชนะตลาด 5 จุด" ที่โฆษณา · 3.5 จุดมาจากการรับความเสี่ยงมากขึ้นเฉย ๆ (ใครก็ทำได้แค่กู้เงินมาซื้อดัชนี) · เหลือฝีมือจริงแค่ 1.5 จุด

และถ้าปีหน้าตลาดตก 20% กองนี้จะตกราว 30% — β ที่ให้กำไรพิเศษตอนขาขึ้น จะคืนกลับหมดตอนขาลง

🎯 3 อย่างที่ต้องจำจากบทที่ 10
  • ผลตอบแทนดิบไม่มีความหมาย จนกว่าจะหารด้วยความเสี่ยง — ดู Sharpe ก่อนเสมอ
  • Sharpe มองไม่เห็นความเบ้และหางหนา — ใช้ Sortino + max drawdown ควบคู่ (Sharpe เท่ากันได้ทั้งที่วันแย่สุดต่างกันเกือบ 2 เท่า)
  • alpha = ผลงานจริง − ที่ควรได้ตาม β — "ชนะตลาด" ส่วนใหญ่คือ β ปลอมตัวมา
รู้แล้วว่ากลยุทธ์ดีแค่ไหน · เหลือคำถามเดียวที่แพงที่สุด — แล้วควรลงเงินเท่าไร

บทที่ 11: ขนาดสถานะ และการเอาตัวรอด

11.1 Volatility Drag — ทำไมค่าเฉลี่ยถึงโกหก

🚶 อ่านเป็นภาษาคนก่อน: จำกับดักที่เปิดเล่ม 1 Part I ได้ไหม — ฿100 ตก 50% แล้วขึ้น 50% เหลือ ฿75 · "ค่าเฉลี่ย" ของ −50% กับ +50% คือ 0% แต่ความจริงคือขาดทุน 25% · ปรากฏการณ์นี้มีชื่อและมีสูตร

อัตราเติบโตจริง (geometric) ≈ μ − σ²/2 ↑ "ภาษีความผันผวน" ที่หักออกเสมอ
🧮 ยิ่งเหวี่ยง ยิ่งถูกหักหนัก (μ = 10% เท่ากันทุกแถว)
σμ − σ²/2เติบโตจริงถูกหักไป
15%10% − 1.12%8.88%1.12%
30%10% − 4.50%5.50%4.50%
50%10% − 12.50%−2.50%12.50%

แถวสุดท้ายคือหัวใจ: ผลตอบแทนคาดหวังเป็นบวก 10% แต่เงินจริงหดลงทุกปี เพราะความผันผวนสูงเกินไป

💎 นี่คือเทอมเดียวกับที่เจอใน Black-Scholes

ดูสูตร μ − σ²/2 ให้ดี · มันคือเทอมเดียวกับ (r − σ²/2) ที่เป็น drift ของ log-price ในโลก risk-neutral ซึ่ง Part V ใช้ทั้งใน d₂ และในสูตร Monte Carlo

ตอนนั้นมันเป็นแค่ "เทอมแก้ของ Ito" ที่โผล่มาจากคณิตศาสตร์ · ตอนนี้คุณเห็นความหมายทางการเงินของมันแล้ว: มันคือภาษีที่ความผันผวนเก็บจากเงินของคุณ · เล่ม 1 กับเล่ม 2 บรรจบกันตรงนี้

11.2 Kelly Criterion — สูตรหาขนาดที่โตเร็วที่สุด

Kelly Criterion Kelly 1956 ★★★ ต้องรู้จัก

🎯 Thesis

"มี edge อย่างเดียวไม่พอ · ขนาดเดิมพันที่ทำให้เงินโตเร็วที่สุดมีค่าเดียว — ต่ำกว่านั้นโตช้า สูงกว่านั้นโตช้าลงเช่นกัน และถ้าสูงมากพอจะพาไปหมดตัวทั้งที่ยังได้เปรียบ"

🚶 อ่านเป็นภาษาคนก่อน: Kelly ไม่ได้หาขนาดที่ทำให้กำไรเฉลี่ยสูงสุด (คำตอบนั้นคือ "ลงทั้งหมด" ซึ่งพาไปหมดตัว) · มันหาขนาดที่ทำให้อัตราเติบโตระยะยาวสูงสุด — คือดูว่าเส้นทางส่วนใหญ่จบตรงไหน ไม่ใช่ค่าเฉลี่ยที่ถูกลากด้วยเส้นทางโชคดีไม่กี่เส้น

เดิมพันแบบชนะ/แพ้: f* = (p·(b+1) − 1) / b p = โอกาสชนะ · b = อัตราจ่าย (ชนะได้ b เท่าของที่เดิมพัน) ตัวอย่าง: p = 55%, b = 1 → f* = (0.55×2 − 1)/1 = 10% ของพอร์ต แบบต่อเนื่อง (สินทรัพย์): f* = μ / σ²
✅ อ่านกราฟนี้ให้ขึ้นใจ
  • เส้นโค้งขึ้นแล้วลง — เดิมพันมากขึ้นไม่ได้ดีขึ้นเสมอ
  • ยอดอยู่ที่ f* = 10% (Kelly) — โตเร็วที่สุด
  • ตัดศูนย์ที่ 20% = 2 เท่าของ Kelly พอดี — จุดที่เดิมพันหนักจนกำไรระยะยาวเป็นศูนย์ ทั้งที่ยังชนะ 55% ทุกครั้ง
  • เกินจากนั้นติดลบ — ยิ่งเดิมพันหนัก ยิ่งจนลงเรื่อย ๆ
  • สังเกตว่า ฝั่งซ้ายของยอดชันน้อยกว่าฝั่งขวา — เดิมพันน้อยไปเสียโอกาสนิดหน่อย เดิมพันมากไปเสียหายหนัก · ถ้าไม่แน่ใจ ให้พลาดไปทางน้อย
🐍 Python — จำลอง 10,000 เส้นทาง เทียบขนาดเดิมพัน
# pip install numpy
import numpy as np

p, b = 0.55, 1.0                              # ชนะ 55% จ่าย 1:1
kelly = (p*(b+1) - 1)/b
print(f"Kelly f* = {kelly:.0%}")               # Kelly f* = 10%

rng = np.random.default_rng(42)
N, T = 10_000, 200                             # 10,000 เส้นทาง × 200 งวด
wins = rng.random((N, T)) < p                  # สุ่มผลแพ้ชนะล่วงหน้าทั้งกริด

for frac in [0.02, 0.05, 0.10, 0.25, 0.40]:
    w = np.ones(N)
    for t in range(T):
        w *= np.where(wins[:, t], 1 + frac, 1 - frac)   # ★ ทบต้นแบบคูณ
    print(f"เดิมพัน {frac:.0%}: มัธยฐาน {np.median(w):6.2f} เท่า | "
          f"จบต่ำกว่าครึ่งทุน {(w < 0.5).mean():.1%}")
# เดิมพัน  2%: มัธยฐาน   1.43 เท่า | จบต่ำกว่าครึ่งทุน 0.0%
# เดิมพัน  5%: มัธยฐาน   2.12 เท่า | จบต่ำกว่าครึ่งทุน 1.8%
# เดิมพัน 10%: มัธยฐาน   2.72 เท่า | จบต่ำกว่าครึ่งทุน 11.1%   ← Kelly สูงสุด
# เดิมพัน 25%: มัธยฐาน   0.26 เท่า | จบต่ำกว่าครึ่งทุน 58.0%   ← ขาดทุน!
# เดิมพัน 40%: มัธยฐาน   0.00 เท่า | จบต่ำกว่าครึ่งทุน 91.0%   ← หมดตัว
🎯 3 อย่างที่ต้องจำเรื่อง Kelly
  • Kelly ให้อัตราเติบโตสูงสุด ไม่ใช่กำไรเฉลี่ยสูงสุด — มันหาเส้นทางที่คนส่วนใหญ่จะเจอ
  • เกิน 2 เท่าของ Kelly = เติบโตติดลบ ทั้งที่ยังมี edge
  • พลาดไปทางน้อยดีกว่าทางมาก — เพราะกราฟฝั่งขวาชันกว่าฝั่งซ้ายมาก

11.3 ทำไมมืออาชีพถึงใช้ half-Kelly

ดูตารางจำลองอีกครั้ง เทียบเฉพาะ Kelly เต็มกับครึ่ง:

half-Kelly (5%)Kelly เต็ม (10%)ต่างกัน
เงินปลายทาง (มัธยฐาน)2.12 เท่า2.72 เท่าKelly ดีกว่า 28%
โอกาสจบต่ำกว่าครึ่งทุน1.8%11.1%Kelly เสี่ยงกว่า 6 เท่า
✅ ทำไมยอมแลก

ยอมเสียกำไร 28% เพื่อลดโอกาสเจ็บหนักลง 6 เท่า — แต่เหตุผลจริงลึกกว่านั้น:

  • Kelly ต้องรู้ p และ b เป๊ะ ๆ · ในตลาดจริงเราประมาณ μ กับ σ เอา และมี estimation error เสมอ (เล่ม 2 · C §6.4)
  • ถ้าประเมิน edge สูงเกินไป 2 เท่า → คุณกำลังเดิมพันที่ 2×Kelly โดยไม่รู้ตัว = เติบโตเป็นศูนย์
  • half-Kelly ให้ที่เผื่อพลาด: ประเมินผิดไป 2 เท่าก็ยังอยู่ที่ Kelly พอดี
  • ความเจ็บระหว่างทาง (drawdown) ของ Kelly เต็มสูงจนคนส่วนใหญ่ทนไม่ไหวและเลิกกลางคัน — กลยุทธ์ที่ทนไม่ไหวคือกลยุทธ์ที่ใช้ไม่ได้
❌ ข้อจำกัดของ Kelly ในตลาดจริง
  • สมมติว่ารู้ความน่าจะเป็น — ตลาดจริงไม่มีใครรู้ · ทุกอย่างเป็นค่าประมาณจากอดีต
  • สมมติว่าผลแต่ละครั้งอิสระต่อกัน — แต่ตลาดมี volatility clustering (Part IV) วันแย่มาเป็นพวง
  • f* = μ/σ² มักออกมาเกิน 100% (เช่น μ=8%, σ=20% → f* = 200% = ใช้ leverage 2 เท่า) · สูตรไม่รู้ว่าคุณกู้ไม่ได้ขนาดนั้น และไม่รู้จักหางหนา
  • ไม่รู้จัก drawdown — Kelly มองแต่ปลายทาง ไม่สนว่าระหว่างทางจะเจ็บแค่ไหน

สรุปวิธีใช้จริง: คำนวณ Kelly เป็นเพดานบน แล้วลงจริงที่ 1/4 ถึง 1/2 ของนั้น · ถือว่า Kelly คือ "เส้นที่ห้ามข้าม" ไม่ใช่ "เป้าที่ต้องไปให้ถึง"

11.4 Drawdown — ตัววัดที่คนรู้สึกจริง

🚶 อ่านเป็นภาษาคนก่อน: σ กับ Sharpe เป็นตัวเลขนามธรรม · แต่ drawdown คือ "ตอนนี้เงินคุณต่ำกว่าจุดสูงสุดที่เคยเห็นกี่ %" ซึ่งเป็นสิ่งที่คนรู้สึกจริงและเป็นสาเหตุที่คนเลิกกลางคัน

❌ ความอสมมาตรที่โหดร้าย — ขาดทุนกับกำไรไม่เท่ากัน

นี่คือกับดัก "−50% แล้ว +50%" จาก Part I ในรูปแบบที่เจ็บที่สุด · ยิ่งขาดทุนลึก ยิ่งกลับยากแบบทวีคูณ — และนี่คือเหตุผลทางคณิตศาสตร์ที่ "อย่าขาดทุนหนัก" สำคัญกว่า "ทำกำไรเยอะ"

🧮 อ่านกราฟนี้ — กลยุทธ์ที่ "ดี" ก็ยังเจ็บ

กลยุทธ์นี้กำไรรวม +97% ในช่วงที่จำลอง (Sharpe 0.83 ถือว่าดี) · แต่ระหว่างทาง:

  • Max Drawdown = −35.2% — เงินหายไปกว่าหนึ่งในสามจากจุดสูงสุด
  • ใช้เวลา 151 วันจากยอดถึงก้น — เห็นเงินลดลงทุกเดือนติดต่อกันครึ่งปี
  • อีก 424 วันกว่าจะกลับเท่าทุนเดิม — รวม 575 วัน ที่เปิดพอร์ตมาแล้วเห็นตัวเลขแดง
  • ต้องทำกำไร 54% เพื่อกลับจากหลุม −35.2%

คนส่วนใหญ่เลิกกลางทาง · และการเลิกตอนก้นบึ้งคือการเปลี่ยน drawdown ชั่วคราวให้เป็นขาดทุนถาวร · นี่คือเหตุผลที่ต้องเลือกขนาดสถานะที่ตัวเอง "ทนได้" ไม่ใช่ขนาดที่ "โตเร็วสุด"

🐍 Python — คำนวณ Max Drawdown และเวลาฟื้นตัว
# pip install numpy
import numpy as np

rng = np.random.default_rng(17)
r = rng.normal(0.0006, 0.013, 1000)            # ผลตอบแทนรายวัน 1000 วัน

equity = np.cumprod(1 + r)                     # เส้นเงินทุน
peak   = np.maximum.accumulate(equity)         # ★ ยอดสูงสุดที่เคยเห็น ณ แต่ละวัน
dd     = equity/peak - 1                       # ★ drawdown = ต่ำกว่ายอดกี่ %

print(f"กำไรรวม        = {(equity[-1]-1):+.0%}")        # กำไรรวม        = +97%
print(f"Sharpe         = {(r.mean()*252-0.02)/(r.std()*np.sqrt(252)):.2f}")
# Sharpe         = 0.83
print(f"Max Drawdown   = {dd.min():.1%}")                # Max Drawdown   = -35.2%

# เวลาที่ใช้: ยอด → ก้น → กลับเท่าทุน
bottom = int(dd.argmin())
top    = int(np.argmax(equity[:bottom+1]))
recov  = int(np.where(equity[bottom:] >= equity[top])[0][0])
print(f"ยอด→ก้น {bottom-top} วัน · ก้น→เท่าทุน {recov} วัน · รวม {bottom-top+recov} วัน")
# ยอด→ก้น 151 วัน · ก้น→เท่าทุน 424 วัน · รวม 575 วัน
print(f"ต้องกำไร {1/(1+dd.min())-1:.0%} เพื่อกลับเท่าทุน")
# ต้องกำไร 54% เพื่อกลับเท่าทุน

11.5 Stress Test — ถามคำถามที่ σ ตอบไม่ได้

🚶 อ่านเป็นภาษาคนก่อน: σ, VaR, Sharpe ล้วนคำนวณจากอดีต · แต่วันที่ทำให้พอร์ตตายมักเป็นวันที่ไม่เคยเกิดในข้อมูลของคุณ · stress test คือการเลิกถามข้อมูลแล้วถามตรง ๆ ว่า "ถ้าเกิดเหตุการณ์ X ขึ้น พอร์ตนี้เหลือเท่าไร"

คำถามเครื่องมือจุดบอด
วันปกติเหวี่ยงแค่ไหนσไม่รู้จักหาง
วันแย่ 5% ขาดทุนเท่าไรVaRไม่บอกว่าเลยเส้นไปแย่แค่ไหน
ถ้าเลยเส้นไปแล้ว เฉลี่ยแย่แค่ไหนExpected Shortfallยังอิงข้อมูลอดีตอยู่ดี
ถ้าเกิดเหตุที่ไม่เคยเกิดล่ะStress testต้องเดาสถานการณ์เอง
✅ วิธีทำจริง — 3 คำถามที่ต้องตอบได้ก่อนลงเงิน
  1. "ถ้าตลาดตก 20% ในวันเดียว พอร์ตเหลือเท่าไร" — ใช้ β จาก §10.3 คูณตรง ๆ เป็นจุดเริ่มต้น (β=1.5 → คาดว่าตก ~30%)
  2. "ถ้า correlation ทุกตัวพุ่งเป็น 1 พร้อมกัน" — คำนวณ wᵀΣw ใหม่โดยตั้ง ρ=1 ทุกคู่ · นี่คือสิ่งที่เกิดจริงตอน crash และทำให้ diversification หายไปพอดีตอนที่ต้องการมันที่สุด (เล่ม 2 · B)
  3. "ถ้าสภาพคล่องหาย ขายไม่ได้ 3 วัน" — สำหรับพอร์ตที่มี leverage ข้อนี้มักเป็นข้อที่ฆ่าจริง

ถ้าคำตอบข้อไหนคือ "หมดตัว" หรือ "โดนบังคับปิด" — ขนาดสถานะใหญ่เกินไป ไม่ว่า Sharpe จะสวยแค่ไหน

🧠 มุมที่มองต่าง — เป้าหมายไม่ใช่กำไรสูงสุด

มือใหม่เห็น: "หากลยุทธ์ที่ให้ผลตอบแทนสูงที่สุด"
คนที่อยู่รอดมานานเห็น: เป้าหมายคืออยู่ในเกมให้นานพอให้ edge ทำงาน · กลยุทธ์ที่ให้ 30%/ปี แต่มีโอกาส 10% ที่จะหมดตัว ด้อยกว่ากลยุทธ์ที่ให้ 12%/ปี แล้วอยู่รอดแน่นอน — เพราะศูนย์คูณอะไรก็เป็นศูนย์ และคุณไม่มีโอกาสเล่นรอบสอง

✍️ ลองทำเอง

คุณประเมินว่ากลยุทธ์หนึ่งมี μ = 12%/ปี และ σ = 25%/ปี · (1) Kelly บอกให้ลงเท่าไร (ใช้ f* = μ/σ²) · (2) ผลลัพธ์นั้นสมเหตุสมผลไหม และควรทำยังไงต่อ

ดูเฉลย

(1) f* = 0.12/0.25² = 0.12/0.0625 = 1.92 = 192% ของพอร์ต (ต้องกู้มาเกือบเท่าตัว)

(2) ไม่สมเหตุสมผลที่จะทำตาม ด้วย 3 เหตุผล: (ก) μ ที่ประมาณมาไม่แน่นอนสูงมาก — ถ้า μ จริงเป็น 6% ไม่ใช่ 12% คุณกำลังเดิมพันที่ 2×Kelly = เติบโตศูนย์ · (ข) สูตรไม่รู้จักหางหนา ซึ่งวันเดียวที่แรงพอจะบังคับปิดสถานะที่มี leverage · (ค) drawdown ระหว่างทางจะทนไม่ไหว

ทำต่อ: ใช้ Kelly เป็นเพดาน แล้วลงจริงที่ 1/4 ของนั้น ≈ 48% หรือน้อยกว่า · แล้วตรวจด้วย stress test ว่าถ้าตลาดตก 20% ในวันเดียวยังรอดไหม

🎯 3 อย่างที่ต้องจำจากบทที่ 11
  • ความผันผวนเก็บภาษีคุณเสมอ — เติบโตจริง ≈ μ − σ²/2 · σ สูงพอทำให้ผลตอบแทนบวกกลายเป็นเงินหด
  • ขนาดสถานะสำคัญกว่าการเลือกถูก — edge 55% ยังเจ๊งได้ถ้าลงหนักเกิน 2×Kelly
  • drawdown คือสิ่งที่ทำให้คนเลิก — เลือกขนาดที่ทนได้ ไม่ใช่ขนาดที่โตเร็วสุด
สรุป เล่ม 2 · E — ตอนนี้คุณ
  • วัดคุณภาพกลยุทธ์ด้วย Sharpe และรู้ว่ามันโกหกตรงไหน (ความเบ้ · การแปลงรายปี · หางหนา)
  • ใช้ Sortino จับโปรไฟล์ "เก็บเหรียญหน้ารถบดถนน" ที่ Sharpe มองไม่เห็น
  • แยก alpha ออกจาก β ด้วย CAPM — รู้ว่า "ชนะตลาด" ส่วนใหญ่คือแค่รับความเสี่ยงมากขึ้น
  • เข้าใจ volatility drag และเห็นว่ามันคือเทอมเดียวกับ σ²/2 ใน Black-Scholes
  • คำนวณ Kelly และรู้ว่าทำไมต้องลงแค่เศษส่วนของมัน
  • อ่าน drawdown และ stress test เป็น — และรู้ว่าอยู่รอดสำคัญกว่าโตเร็ว
