บทที่ 10: Butterfly — "เต็นท์แหลม"

🚶 อ่านเป็นภาษาคนก่อน: Butterfly คือการเดิมพันว่าราคาจะนิ่งอยู่ตรงกลาง — ซื้อ Call ราคาถูกสองข้าง แล้วขาย Call ตรงกลางสองสัญญาทับไว้ ผลคือกำไรสูงสุดถ้าราคาปิดตรงกลางเป๊ะ และขาดทุนจำกัดถ้าราคาหลุดไปทางใดทางหนึ่งไกล ๆ

Long Call Butterfly: +1 Call K₁, −2 Call K₂, +1 Call K₃

วิธีวิเคราะห์ slope (K₁=90, K₂=100, K₃=110)
  1. ก่อน K₁: slope = 0 (แบน)
  2. ที่ K₁: +1 → slope เปลี่ยนเป็น +1 (ชันขึ้น)
  3. ที่ K₂: −2 → slope เปลี่ยนเป็น +1−2 = −1 (ชันลง)
  4. ที่ K₃: +1 → slope เปลี่ยนเป็น −1+1 = 0 (แบน)

Net slope ปลายขวา = 0 → bounded! ปลอดภัยทั้งสองด้าน

รูปร่าง: แบน → ขึ้น → ลง → แบน = "เต็นท์" peak ที่ K₂ — สมมติ net debit ของกลยุทธ์นี้ = ฿3 จะได้ peak = width(K₂−K₁=10) − net(3) = +7 (ดูที่มาของสูตรนี้แบบเต็มในบทที่ 14)

Net profit (หลังหัก premium)

🚶 อ่านเป็นภาษาคนก่อน: ถ้าราคา Call ตรงกลาง (K₂) แพงกว่าค่าเฉลี่ยของสองข้าง (K₁,K₃) มากเกินไป จะมีคนซื้อ Butterfly ได้ "ราคาติดลบ" คือได้เงินตั้งแต่เข้า trade พร้อมยังมีโอกาสกำไรเพิ่มอีก ซึ่งเป็นไปไม่ได้ในตลาดที่มีประสิทธิภาพ — นี่คือเหตุผลที่ราคา Call ต้อง "โค้งนูน" ตามลำดับ strike เสมอ เรียกเงื่อนไขนี้ว่า convexity condition

Butterfly Convexity Condition

C(K₁) − 2C(K₂) + C(K₃) ≥ 0 (สำหรับ strikes ที่ห่างเท่ากัน)

ถ้า < 0 → Arbitrage! ซื้อ butterfly ได้ "ฟรี" → เป็นไปไม่ได้ในตลาดปกติ

✍️ ลองทำเอง

Butterfly K₁=95, K₂=100, K₃=105, net premium=2 → กำไรสูงสุดเท่าไร? Break-even กี่จุด?

เฉลย: width = K₂−K₁ = 5 → Max profit = width−net = 5−2 = ฿3 (ที่ K₂ พอดี) → Break-even 2 จุด: K₁+net = 95+2 = 97 และ K₃−net = 105−2 = 103

🎯 3 อย่างที่ต้องจำ
  • Butterfly slope: +1, −2, +1 → net = 0 → bounded ทั้งสองด้าน
  • กำไรสูงสุดที่ K₂ พอดี → ต้องแม่นยำมาก
  • Butterfly ≥ 0 = convexity condition → ถ้าผิด = arbitrage

บทที่ 11: Iron Condor — "ที่ราบสูงตรงกลาง"

🚶 อ่านเป็นภาษาคนก่อน: Iron Condor คือ Butterfly ที่ยืด peak ให้กลายเป็นที่ราบกว้างขึ้น — แทนที่จะได้กำไรสูงสุดแค่จุดเดียว คุณได้กำไรสูงสุดตลอดทั้งช่วงราคา ถ้าราคาปิดอยู่ในกรอบนั้น

Iron Condor = Bull Put Spread(K₁,K₂) + Bear Call Spread(K₃,K₄)
= +Put K₁, −Put K₂, −Call K₃, +Call K₄
วิธีวิเคราะห์ slope (K₁ < K₂ ≤ K₃ < K₄)
  1. +1 ที่ K₁ (แบน → ขึ้น)
  2. −1 ที่ K₂ (ขึ้น → แบน, เข้าสู่ช่วงกำไรสูงสุด)
  3. −1 ที่ K₃ (แบน → ลง)
  4. +1 ที่ K₄ (ลง → แบน)

Net slope = 0 → bounded ✓ — รูปร่าง: แบน(ขาดทุน) → ขึ้น → แบน(กำไร) → ลง → แบน(ขาดทุน) = "ที่ราบสูงตรงกลาง"

Max profit = net premium received  ·  Max loss = (K₂−K₁) − net premium (= ความกว้างของ spread ฝั่งใดฝั่งหนึ่ง ลบ premium)

Net profit (หลังหัก premium)

📉 เมื่อทฤษฎีพังจริง: "Short Strangle ที่มีปีก" — ยังอันตราย!

Iron Condor = Short Strangle + Long Wings (ปีกป้องกัน) — Max loss จำกัด (= width − premium) แต่ เสียเต็ม max loss ทันทีเมื่อราคา gap ผ่านปีก

Payoff chart ดูสวย — แต่จำไว้จากบทที่ 8: payoff ≠ prediction! "Iron Condor กำไร 80% ของเวลา" = 20% ที่เหลือเสียหนักพอจะล้างกำไรทั้งหมด

🎯 3 อย่างที่ต้องจำ
  • Iron Condor = "เดิมพันว่าราคาจะนิ่ง" → กำไรจำกัด ขาดทุนจำกัด
  • ทุก strategy ที่ "กำไรบ่อย" = เสียหนักเมื่อเสีย → check Expected Value!
  • ดู payoff chart อย่างเดียวไม่พอ → ต้องรู้ probability distribution ด้วย

บทที่ 12: Calendar + Diagonal — "มิติของเวลา"

ทุกอย่างที่ผ่านมา = same expiry — บทนี้เพิ่มมิติ "เวลา" เข้ามา

🚶 อ่านเป็นภาษาคนก่อน: ขาย option ระยะสั้นที่กำลังจะหมดอายุเร็ว ๆ นี้ พร้อมซื้อ option ระยะยาวที่ strike เดียวกันเก็บไว้ — ระยะสั้นเสียมูลค่าจาก time decay เร็วกว่าระยะยาวมาก คุณจึงกำไรจากความต่างของความเร็วในการเสียมูลค่านั้น

Calendar Spread = Short near-term + Long far-term (same strike)
→ กำไรจาก time decay ที่ near-term หมดค่าเร็วกว่า far-term
Diagonal Spread = Calendar + ต่าง strike
→ ผสมมิติเวลา + ทิศทาง

Net profit (หลังหัก premium)

สำคัญ: ใช้ BS theoretical price ไม่ใช่ at-expiry payoff

Calendar Spread payoff ณ วันหมดอายุของขาระยะสั้น ไม่ใช่เส้นตรงหักศอก — เป็นเส้นโค้ง เพราะขาระยะยาวยังมี time value เหลืออยู่ → ต้องใช้ราคาตามโมเดล Black-Scholes (BS)

(ถ้ายังไม่รู้จัก BS ในรายละเอียด → ดูเล่มคณิตศาสตร์ บทที่ 7 และ 15)

✍️ ลองทำเอง

ทำไม Calendar Spread payoff ตอนขาระยะสั้นหมดอายุถึงไม่ใช่เส้นตรงหักศอกเหมือน strategy อื่นในเล่มนี้?

เฉลย: เพราะขาที่เหลือ (far-term) ยังไม่หมดอายุ จึงยังมี time value เหลืออยู่ ต้องคำนวณด้วยราคาตามโมเดล (BS) ไม่ใช่ payoff เชิงเรขาคณิตแบบ at-expiry เหมือนขาอื่น ๆ ที่หมดอายุพร้อมกันหมด

🎯 3 อย่างที่ต้องจำ
  • Calendar Spread กำไรจาก ความต่างของความเร็ว time decay ไม่ใช่ทิศทางราคา
  • Payoff ตอน near-term หมดอายุเป็นเส้นโค้ง ไม่ใช่เส้นหักศอก เพราะขา far-term ยังมี time value
  • ต้องใช้ราคาตามโมเดล BS ประเมิน ไม่ใช่คำนวณ at-expiry ตรง ๆ

บทที่ 13: Ratio Spreads — "ปืนที่บรรจุกระสุน"

🚶 อ่านเป็นภาษาคนก่อน: ซื้อ 1 สัญญาแต่ขาย 2 สัญญาทับ — ตอนแรกดูเหมือนได้ premium มาฟรีเพราะขายมากกว่าซื้อ แต่ถ้าราคาพุ่งไกลเกินไป สัญญาที่ขาย 2 ตัวจะเริ่มขาดทุนเร็วกว่าที่สัญญาซื้อ 1 ตัวจะทำกำไรได้ทัน

1×2 Ratio Call Spread = Long 1 Call K₁ + Short 2 Call K₂
Slope: +1 at K₁, −2 at K₂ → net slope = +1−2 = −1 ≠ 0
→ UNBOUNDED loss ด้านขวา!
🧮 ตัวอย่างการใช้งาน

Long 1 Call(K₁=100) จ่าย ฿4, Short 2 Call(K₂=110) รับสัญญาละ ฿3 (รวม ฿6) → net premium รับ = 6−4 = +2 (เครดิต)

ที่ K₂=110 (peak): profit = +2 + (110−100)×1 = +12 — จุดคุ้มทุนบน (หลัง peak) = 110 + 12 = 122

แต่ถ้าราคาพุ่งเกิน 122 ไปเรื่อย ๆ เช่น S=150: profit = 12 − (150−110) = 12−40 = −28 ขาดทุนไม่จำกัดจริง ๆ

Net profit (หลังหัก premium)

⚠️ Net slope ≠ 0 = Unlimited Risk!

Ratio Spread ดูเหมือน "ได้ premium ฟรี" เพราะ Short 2 ชดเชย Long 1

แต่ ถ้าราคาพุ่งขึ้นมาก → Short 2 ขาดทุนเร็วกว่า Long 1 ได้กำไร → ขาดทุนไม่จำกัด!

กฎ: เช็ค net slope ที่ปลายขวาเสมอ → ถ้า ≠ 0 → unlimited risk!

ระวังเสมอ: net slope ที่ปลายกราฟ ≠ 0 คือสัญญาณอันตรายที่สำคัญที่สุดในเล่มนี้ — ไม่ว่า strategy จะดูฉลาดหรือดู "ได้เปรียบ" แค่ไหนก็ตาม

🚶 อ่านเป็นภาษาคนก่อน: กลับด้านกัน — แทนที่จะขายมากกว่าซื้อ ให้ซื้อมากกว่าขาย ผลคือความเสี่ยงไม่จำกัดย้ายไปอยู่ฝั่งกำไรแทน เหมาะกับมุมมองที่มั่นใจว่าราคาจะพุ่งแรงมาก ๆ

Back Ratio = Short 1 Call K₁ + Long 2 Call K₂ → net slope = −1+2 = +1 → unlimited profit!
🎯 3 อย่างที่ต้องจำ
  • Ratio Spread = จำนวนสัญญาซื้อ/ขายไม่เท่ากัน → net slope มักไม่เป็น 0
  • 1×2 Ratio (ขายมากกว่าซื้อ) = unlimited loss ด้านที่ slope ≠ 0
  • Back Ratio (ซื้อมากกว่าขาย) = กลับด้าน ได้ unlimited profit แทน

บทที่ 14: วิธีต่อเลโก้ขั้นสูง — Payoff Algebra

🚶 อ่านเป็นภาษาคนก่อน: ทุก payoff รูปทรงไหนก็ตาม สร้างได้ด้วย 3 ขั้นตอนเดียวกันเสมอ — เขียนสิ่งที่อยากได้เป็นสมการทีละช่วง จับคู่กับ leg ที่รู้จักอยู่แล้วจากบทก่อน ๆ แล้วเลือกตัวที่ถูกที่สุดมาประกอบ

3 ขั้นตอน: Belief → Piecewise → Instruments

วิธีทำ
  1. เขียน "สิ่งที่อยากได้" เป็น piecewise function
  2. จับคู่กับ building blocks ที่รู้จัก (slope analysis ย้อนกลับ)
  3. เลือก instruments ที่ถูกที่สุด

ตัวอย่าง: "กำไรถ้าราคาอยู่ระหว่าง 90-110 ไม่เสียเกิน ฿3"

🧮 ตัวอย่างการใช้งาน
S < 90: payoff = −3 (flat)
90 ≤ S ≤ 100: payoff = −3 + (S−90) → ที่ S=90: −3, ที่ S=100: +7 (peak!)
100 < S ≤ 110: payoff = +7 − (S−100) → ที่ S=110: −3
S > 110: payoff = −3 (flat)

Slope changes: +1 at 90, −2 at 100, +1 at 110 → = Butterfly! (ตัวเลขชุดเดียวกับบทที่ 10)

Net premium = ฿3, Max profit = width − net = 10 − 3 = ฿7

กฎ: รูปเดียว สูตรเดียว

Payoff ที่มี n จุดหักศอก + net slope ปลาย = 0 → ต้องใช้ พอดี n option legs (minimal representation)

ถ้า net slope ≠ 0 → ต้องเพิ่ม stock หรือ bond อีก 1 ตัว — ไม่ต้องกลัวว่า "พลาดคำตอบที่ดีกว่า" คำตอบมีเดียว!

Transaction Costs — Reality Check

ยิ่งหลายขา ยิ่งแพง

ทุก leg = commission + bid-ask spread + slippage

ตัวอย่างสมมติ: Iron Condor 4 ขา, commission ฿10/ขา + half-spread ฿15/ขา = ฿25/ขา × 4 = ฿100 รวม — ถ้า max profit ของ position นี้คือ ฿300 ต้นทุนนี้ก็กินไปแล้ว 33%

กฎ: คำนวณ costs จริงของ broker ตัวเองก่อนเสมอ → ถ้า costs กินสัดส่วนใหญ่ของ max profit → อาจไม่คุ้ม

ลองเอาทุกอย่างจากบทนี้มารวมกันในโจทย์เดียว — ทั้ง piecewise, การจับคู่ leg, และการเช็คว่าคุ้มค่าธรรมเนียมไหม:

✍️ ลองทำเอง (บท 14)

"อยากได้กำไร ฿500 ถ้า S > 2500, ไม่อยากเสียเกิน ฿200" → สร้าง payoff?

เฉลย: Piecewise = {−200 ถ้า S≤2500, +500 ถ้า S>2500} → jump +700 ที่ 2500 → = Digital Call × 700 หรือประมาณด้วย Call Spread ช่วงแคบมาก ๆ ระหว่าง 2500 กับ 2500+ε (ε = ตัวเลขเล็กมาก เช่น 0.01) แล้วคูณ 700/ε เพื่อให้ jump มีขนาดถูกต้อง
