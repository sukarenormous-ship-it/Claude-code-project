บทที่ 18: Pairs Trading

Stat Arb เริ่มต้นจากแนวคิดง่ายๆ: "หุ้น 2 ตัวที่เคลื่อนไหวด้วยกัน → เมื่อแยกจากกัน → เข้าเทรด"

18.1 Correlation vs Cointegration

CorrelationCointegration
วัดอะไรทิศทางเหมือนกันไหมระยะห่างคงที่ไหม
ปัญหา2 หุ้นอาจ drift ออกจากกันตลอดกาลSpread กลับหาค่าเฉลี่ย
ตัวอย่างBTC กับ ETH: correlated แต่ ratio เปลี่ยนเรื่อยๆCoke vs Pepsi: spread mean-reverts
ใช้กับ Arb?ไม่พอ!ต้องใช้ตัวนี้!
Engle-Granger Cointegration Test
  1. Regress A vs B: A = α + β×B + ε
  2. ทดสอบ residuals (ε) ว่า stationary ไหม (ADF test)
  3. ถ้า ε stationary → A กับ B cointegrated → Spread = A - β×B จะ mean-revert!

18.2 Trading the Spread

Spread = Price_A - β × Price_B
Z-score = (Spread - Mean) / StdDev

Entry: Z > +2 → Short Spread (Short A, Long β×B)
Entry: Z < -2 → Long Spread (Long A, Short β×B)
Exit: Z ≈ 0 → Close ทั้งสองขา
Stop: |Z| > 4 → Cut loss (structural break?)

📖 อ่านสูตรว่า: "สเปรด เท่ากับ ราคาเอ ลบ เบต้าคูณราคาบี" และ "ซี-สกอร์ เท่ากับ สเปรด ลบ ค่าเฉลี่ย หารด้วย ส่วนเบี่ยงเบนมาตรฐาน" · โครงที่ต้องเห็น: บรรทัดแรกคือพอร์ต (ถือ A หนึ่งหน่วย short B จำนวน β หน่วย) · บรรทัดสองคือ "ระยะห่างจากค่าเฉลี่ย หารด้วยสเกล" — เศษกับส่วนเป็นบาททั้งคู่ Z จึงไร้หน่วย · กับดักการอ่าน: β ตรงนี้คือความชันจาก regression A บน B (โครง Σ(x−x̄)(y−ȳ)/Σ(x−x̄)²) ไม่ใช่ beta ตลาด · Mean กับ StdDev เป็นค่าประมาณจากหน้าต่างที่เลือก (มี hat ซ่อนอยู่) เปลี่ยนหน้าต่าง Z เปลี่ยน · |Z| > 4 ทิ้งทิศ — ห่างมากทางไหนก็ตัด · ที่มาอยู่ที่ เล่ม 2 · D §9.1–§9.2

บทที่ 19: Mean Reversion

19.1 Ornstein-Uhlenbeck Process

เปรียบเทียบ: "ยางยืด"

ลองนึกว่า spread ถูกผูกด้วยยางยืดกับค่าเฉลี่ย μ — ยิ่งดึงออกไกล ยิ่งถูกดึงกลับแรง
θ = ความแข็งของยาง (สูง = กลับเร็ว), σ = ลมที่พัดให้แกว่ง (noise)

dX = θ(μ - X)dt + σdW

θ = speed of mean reversion (ยิ่งสูง ยิ่งกลับเร็ว)
μ = long-run mean (ค่าที่ดึงดูดกลับ)
σ = volatility

Half-life = ln(2) / θ ← "นานแค่ไหนกว่า spread จะกลับครึ่งทาง"

📖 อ่านสูตรว่า: "ดีเอ็กซ์ เท่ากับ ธีตาคูณ (มิว ลบ เอ็กซ์) ดีที บวก ซิกมา ดีดับเบิลยู" · โครงที่ต้องเห็น: สูตรอ้างตัวเอง (AR(1) แบบเวลาต่อเนื่อง) — ขนาดแรงดึงเป็นสัดส่วนกับระยะห่างจาก μ · ทดสอบ: X = μ แรงดึงเป็น 0 เหลือแต่ลม · X > μ พจน์แรกติดลบ ดึงลง · Half-life = ln2/θ: θ = 0.1 ต่อวันให้ 0.693/0.1 ≈ 6.9 วัน · กับดักการอ่าน: d ไม่ใช่ตัวแปร อ่านว่า "การเปลี่ยนแปลงเล็กๆ ของ" · W คือ Brownian motion (สุ่ม) ไม่ใช่ความมั่งคั่ง · θ กับ σ ต้องอยู่ในหน่วยเวลาเดียวกับ dt — θ ต่อวันให้ half-life เป็นวัน · θ ตัวนี้ไม่ใช่ Theta ของ options · ต่อจาก เล่ม 2 · D §8.4½

ตัวอย่าง

ถ้า Half-life = 5 วัน → spread กลับครึ่งทางใน 5 วัน → ดีมาก trade ได้
ถ้า Half-life = 60 วัน → ช้าเกินไป → tie up capital นาน → อาจไม่คุ้ม

19.2 Kalman Filter — Dynamic Hedge Ratio

ปัญหา: β (hedge ratio) เปลี่ยนตามเวลา → ใช้ rolling regression ไม่ดีพอ
Kalman Filter: อัพเดท β แบบ real-time ตามข้อมูลใหม่ → adaptive pairs trading

19.3 Regime Detection

เมื่อไร Mean Reversion ใช้ไม่ได้?

Trending market → spread ไม่ mean-revert → ขาดทุนต่อเนื่อง
Structural break → cointegration หาย (M&A, sector change)
ต้องมี regime detection: ถ้าตลาดเปลี่ยน → หยุดเทรด pairs

บทที่ 20: Factor-Based Statistical Arbitrage

20.1 จาก Pairs สู่ Portfolio

เทรด 1 คู่ → diversify ด้วยหลายคู่ → สร้าง portfolio ของ pairs trades
→ single-pair risk ลดลง → more consistent returns

20.2 Factor Models

Return_i = α_i + β₁×Market + β₂×Size + β₃×Value + ... + ε_i

α (alpha) = ส่วนที่ model อธิบายไม่ได้ = edge ที่เราหา!
β×Factor = systematic risk → hedge ออกได้

📖 อ่านสูตรว่า: "ผลตอบแทนของหุ้น i เท่ากับ อัลฟา i บวก เบต้าหนึ่งคูณตลาด บวก เบต้าสองคูณขนาด บวก เบต้าสามคูณมูลค่า … บวก เอปไซลอน i" · โครงที่ต้องเห็น: regression หลายตัวแปร E[R_i | factors] — เส้นตรงเส้นเดียว แต่หลังขีดมีหลายตัว · α คือค่าตัดแกน (ส่วนที่เหลือโดยเฉลี่ย) ε คือส่วนที่เหลือรายวัน ที่เฉลี่ยเป็นศูนย์ — α จึงเป็น edge ส่วน ε เป็นเสียง · กับดักการอ่าน: ตัวห้อยสองระบบในสูตรเดียว — i ใน R_i, α_i, ε_i คือ "หุ้นตัวที่ i" ส่วน 1, 2, 3 ใน β คือ "factor ตัวที่เท่าไร" ไม่มีตัวไหนเป็นเวลา · β ตรงนี้คือความไวต่อ factor ไม่ใช่ hedge ratio ของบท 18 · การขยายจาก 1 ตัวแปรเป็นหลายตัวอยู่ที่ เล่ม 2 · A §2.2

20.3 Market-Neutral Portfolio

Portfolio beta = 0 (ตลาดขึ้น/ลงไม่กระทบ)
Long stocks ที่มี positive alpha + Short stocks ที่มี negative alpha
→ กำไรจาก alpha เท่านั้น ไม่ขึ้นกับทิศตลาด [Lv.4 Structured]
PCA Factors (จาก คณิตศาสตร์สำหรับ Options เล่ม 2 · A §1.4)

ใช้ Eigenvalues ของ Covariance Matrix → หา principal components
PC1 ≈ market factor, PC2 ≈ sector rotation, PC3 ≈ size/value
→ Hedge ทีละ factor → เหลือแค่ alpha

บทที่ 21: Machine Learning ใน Stat Arb

21.1 Feature Engineering

สร้าง features จากข้อมูลดิบ: momentum, mean-reversion signals, vol ratios, order flow

21.2 Walk-Forward Cross-Validation

Time Series ≠ Regular Data!

ห้ามใช้ random K-fold → data leakage (ใช้อนาคตทำนายอดีต)
ต้องใช้ Walk-Forward: train on past → test on next period → roll forward

21.3 Overfitting — ศัตรูตัวฉกาจ

ถ้า backtest Sharpe = 5.0 → 99% overfitted
ถ้า backtest Sharpe = 1.5 → อาจจริง → ทดสอบ out-of-sample

กฎ: Simple models > Complex models (ส่วนใหญ่)
Linear regression มักชนะ neural network ใน finance
เรื่องจริง: Pairs Trading — Royal Dutch Shell A vs B (1907-2005)

Shell มีหุ้น 2 classes (Dutch=A, English=B) สัดส่วน 60:40 → ราคาควรเป็น 60:40 ตลอด
จริงๆ: ratio เบี่ยงเบน ±15% เป็นประจำ → pairs traders ทำกำไรหลายทศวรรษ
แต่ LTCM ก็เทรดคู่นี้แล้วเจ็บ เพราะ ratio กว้างขึ้นก่อน converge → margin call
บทเรียน: Pairs ที่ดีที่สุดก็มี timing risk — ต้อง size ให้รอดถึงวัน converge

ลองคิดดู (บท 18-21)
  1. หุ้น A กับ B มี correlation = 0.95 → ใช้ pairs trading ได้ไหม? ทำไม?
  2. Spread มี half-life = 3 วัน vs 90 วัน → อันไหนดีกว่าสำหรับ pairs trading?

เฉลย: 1. Correlation สูงไม่พอ! ต้องทดสอบ cointegration — ถ้าไม่ cointegrated spread อาจ drift ไปเรื่อยๆ 2. 3 วันดีกว่ามาก — กลับเร็วกว่า tie up capital น้อยกว่า
