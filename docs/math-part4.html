1.1 Vector และ Dot Product = ผลตอบแทนพอร์ต

🚶 อ่านเป็นภาษาคนก่อน: vector ก็แค่ "รายการตัวเลขเรียงกัน" เช่นสัดส่วนพอร์ต · dot product (·) คือ "จับคู่คูณกันแล้วบวก" ซึ่งบังเอิญ = weighted average = ผลตอบแทนพอร์ตพอดี

w = [0.3, 0.5, 0.2] ← สัดส่วน 3 หุ้น (30/50/20%) r = [0.05, −0.02, 0.08] ← ผลตอบแทนแต่ละหุ้น w · r = 0.3(0.05) + 0.5(−0.02) + 0.2(0.08) = 0.021 = 2.1%

📖 อ่านสูตรว่า: "ดับเบิลยู ดอท อาร์" = "น้ำหนักตัวที่หนึ่งคูณผลตอบแทนตัวที่หนึ่ง บวก น้ำหนักตัวที่สองคูณผลตอบแทนตัวที่สอง … จนครบทุกตัว" · วงเล็บเหลี่ยม [ … ] คือ "รายการที่ลำดับสำคัญ" — ตัวที่ 1 ของ w ต้องคู่กับตัวที่ 1 ของ r เสมอ · โครงที่ต้องเห็น: จุด · ตัวเดียวซ่อน "คูณเป็นคู่แล้วบวก" ไว้ — นี่คือ weighted average ที่เขียนย่อ และเขียนด้วยซิกมาได้ว่า Σᵢ wᵢrᵢ ซึ่งเป็นชั้นแรกของผลรวมสองชั้น Σᵢ Σⱼ wᵢwⱼCovᵢⱼ ใน 1.3 · กับดักการอ่าน: จุด · ระหว่าง vector สองตัวคือ dot product ไม่ใช่การคูณธรรมดา และผลลัพธ์เป็นเลขตัวเดียว ไม่ใช่ vector

1.2 Matrix และ Covariance Matrix

🚶 อ่านเป็นภาษาคนก่อน: matrix คือ "ตารางตัวเลข" · ตารางที่สำคัญสุดคือ Covariance Matrix (Σ) — ช่องแนวทแยงเก็บความเสี่ยงของแต่ละตัว (variance) ช่องนอกแนวทแยงเก็บ "คู่ไหนไปด้วยกันแค่ไหน" (covariance)

Correlation Matrix ของหุ้น 3 ตัว: A B C A [ 1.0 0.7 0.2 ] ← A กับ B ไปด้วยกันสูง (0.7) B [ 0.7 1.0 0.3 ] C [ 0.2 0.3 1.0 ] ← แนวทแยง = ตัวเองกับตัวเอง = 1

📖 อ่านสูตรว่า: อ่านช่องด้วยกฎ "แถวก่อน คอลัมน์ทีหลัง" — ช่อง (A, B) = แถว A คอลัมน์ B = 0.7 คือ "A กับ B สัมพันธ์กัน 0.7" · โครงที่ต้องเห็น: ตารางนี้สมมาตร (ช่อง (A,B) = ช่อง (B,A)) เพราะ "A ไปกับ B" กับ "B ไปกับ A" คือเรื่องเดียวกัน · กับดักการอ่าน: แนวทแยงเป็น 1 เสมอใน correlation matrix แต่ใน covariance matrix Σ แนวทแยงจะเป็น σ² ของแต่ละตัว — มองแนวทแยงก่อนก็รู้ทันทีว่ากำลังดูตารางแบบไหน

1.3 Portfolio Variance — wᵀΣw

Portfolio Variance Markowitz 1952 ★★★ ต้องรู้จัก

🎯 Thesis

"ความเสี่ยงของพอร์ตทั้งก้อน = ผลรวมของ (สัดส่วนคู่หนึ่ง × ความเสี่ยงร่วมของคู่นั้น) ทุกคู่ — เขียนย่อเป็นสูตรเดียวว่า σ²ₚ = wᵀΣw"

🚶 อ่านเป็นภาษาคนก่อน: อย่าเพิ่งกลัวสัญลักษณ์ wᵀΣw มันแค่แปลว่า "ไล่ทุกคู่ (i, j) เอาน้ำหนักสองตัวคูณกับความเสี่ยงร่วมของคู่นั้น แล้วบวกให้หมด" · คู่ที่เป็นตัวเดียวกัน (i=i) ให้ variance ของตัวเอง · คู่ต่างตัว (i≠j) ให้ covariance — ยิ่ง covariance ต่ำ/ลบ ยิ่งดึงความเสี่ยงรวมลง

σ²ₚ = wᵀ Σ w = Σᵢ Σⱼ wᵢ wⱼ Covᵢⱼ w = vector น้ำหนัก · Σ = covariance matrix

📖 อ่านสูตรว่า: "ซิกมากำลังสอง ห้อยพี เท่ากับ ดับเบิลยูทรานสโพส ซิกมา ดับเบิลยู" · ᵀ ตัวเล็กบนขวาอ่านว่า "ทรานสโพส" = พลิก vector จากแนวตั้งเป็นแนวนอนเพื่อให้คูณกันได้ ไม่ได้เปลี่ยนค่าใด ๆ · ตัวห้อย p แปลว่า "ของพอร์ต" ไม่ใช่เวลา · กับดักการอ่าน: บรรทัดนี้มี Σ สองตัวคนละความหมาย — Σ ตัวใหญ่ที่ยืนเดี่ยวกลางสูตรคือเมทริกซ์ covariance ส่วน Σᵢ Σⱼ ที่มีตัวห้อยคือ "ผลรวมไล่ทุก i และทุก j" · โครงที่ต้องเห็น: ผลรวมสองชั้น = "ไล่ทุกคู่" — 3 หุ้นได้ 9 พจน์ (รวมคู่ที่ i = j ซึ่งให้ variance ของตัวเอง) ตรงกับ 🚶 ข้างบนคำต่อคำ

🧮 เดินเลขจริง — หุ้น 2 ตัว w = [0.6, 0.4]

Σ = [ 0.04 0.01 ; 0.01 0.09 ] (σ₁²=0.04 คือ σ₁=20% · σ₂²=0.09 คือ σ₂=30% · Cov=0.01)

σ²ₚ = 0.6²(0.04) + 2(0.6)(0.4)(0.01) + 0.4²(0.09) = 0.0144 + 0.0048 + 0.0144 = 0.0336 σₚ = √0.0336 = 18.3%

💎 เฉลย hook — Diversification

σ₁ = 20%, σ₂ = 30% แต่พอร์ต σ = 18.3% ต่ำกว่าทั้งคู่ เพราะ covariance ต่ำ (0.01) · เทอมกลาง 2w₁w₂Cov เล็ก ทำให้ผลรวมไม่พุ่ง · ถ้าสองหุ้นสวนทางกัน (Cov ลบ) พอร์ตจะยิ่งนิ่งลงไปอีก — นี่คือ "ของฟรี" ที่เกิดจาก covariance ไม่ใช่จากการเดาทิศ

🧠 มุมที่มองต่าง

มือใหม่เห็น: "อยากพอร์ตเสี่ยงน้อย ก็เลือกแต่หุ้นเสี่ยงน้อย"
คนจัดพอร์ตเห็น: หุ้นเสี่ยงสูงตัวหนึ่งที่ "สวนทาง" กับพอร์ต อาจลดความเสี่ยงรวมได้มากกว่าหุ้นนิ่ง ๆ ที่ไปทางเดียวกับทุกตัว — ความเสี่ยงตัวเดี่ยวไม่สำคัญเท่า "มันเข้ากับพอร์ตยังไง"

✍️ ลองทำเอง

ถ้า Cov ระหว่างสองหุ้นเป็น 0 (ไม่สัมพันธ์กันเลย) แทน 0.01 · σ²ₚ และ σₚ จะเป็นเท่าไร? (w = [0.6, 0.4] เท่าเดิม)

ดูเฉลย

σ²ₚ = 0.0144 + 0 + 0.0144 = 0.0288 · σₚ = √0.0288 = 16.97% ≈ 17% — ยิ่งต่ำลงอีกเมื่อ Cov = 0 (ไม่มีความเสี่ยงร่วมเลย)

🐍 พอมีหลายหุ้น มือเริ่มไม่ไหว — ให้ matrix ทำแทน · 3 หุ้นมี 9 คู่, 10 หุ้นมี 100 คู่ · แต่ w @ Σ @ w ใน numpy คือบรรทัดเดียวไม่ว่ากี่ตัว · นี่คือเหตุผลที่ต้องรู้จัก matrix จริง ๆ:

🐍 Python — wᵀΣw พอร์ต 3 หุ้น (สร้าง Σ จาก σ + correlation)
import numpy as np

w  = np.array([0.5, 0.3, 0.2])           # น้ำหนัก 3 หุ้น (รวม = 1)
sd = np.array([0.20, 0.15, 0.30])        # σ ของแต่ละหุ้น
Corr = np.array([[1.0, 0.3, 0.2],        # เมทริกซ์ correlation
                 [0.3, 1.0, 0.5],
                 [0.2, 0.5, 1.0]])

Sig = np.outer(sd, sd) * Corr            # Σ = σᵢσⱼρᵢⱼ (covariance matrix)
var = w @ Sig @ w                        # ★ wᵀΣw — บรรทัดเดียว!
print(f"ความเสี่ยงพอร์ต = {np.sqrt(var)*100:.2f}%")   # ความเสี่ยงพอร์ต = 15.31%

# เทียบกับ "ถ้าไม่มี diversification" (เฉลี่ยถ่วงน้ำหนัก σ ตรง ๆ)
print(f"เฉลี่ยถ่วง σ    = {(w @ sd)*100:.2f}%")        # เฉลี่ยถ่วง σ    = 20.50%
✅ อ่านผลลัพธ์

พอร์ตเสี่ยงจริง 15.31% — ต่ำกว่า "เฉลี่ยถ่วง σ" (20.50%) ถึง 5 จุด · ส่วนต่างนี้คือ diversification ที่ covariance มอบให้ · ถ้าหุ้นทุกตัว correlation = 1 (ไปด้วยกันเป๊ะ) เลขสองอันจะเท่ากันเป๊ะ (ไม่มีของฟรี) · w @ Sig @ w ทำงานเหมือนกันหมดไม่ว่า 3 หรือ 300 หุ้น — นี่คือพลังของการเขียนเป็น matrix

🎯 3 อย่างที่ต้องจำ
  • wᵀΣw แค่ "ไล่ทุกคู่ เอาน้ำหนัก×ความเสี่ยงร่วม แล้วบวก"
  • ความเสี่ยงพอร์ตขึ้นกับ covariance ไม่ใช่แค่ σ ของแต่ละตัว
  • covariance ต่ำ/ลบ = diversification = ความเสี่ยงรวมหด

1.4 Eigenvalues และ PCA — "ทิศทางหลักของตลาด"

🚶 อ่านเป็นภาษาคนก่อน: ในข้อมูลยุ่ง ๆ หลายมิติ มักมี "ทิศทางหลัก" ไม่กี่ทิศที่ข้อมูลชอบเคลื่อนไปด้วยกัน · eigenvector (v) = ทิศทางหลักนั้น · eigenvalue (λ) = ทิศนั้นสำคัญแค่ไหน (อธิบาย variance ได้กี่ %) · PCA (Principal Component Analysis — การวิเคราะห์องค์ประกอบหลัก) คือการหา v กับ λ ของ covariance หรือ correlation matrix แล้วเก็บไว้แค่ทิศที่ λ ใหญ่

C v = λ v (v = eigenvector · λ = eigenvalue) % ที่ทิศ i อธิบาย = λᵢ / (λ₁ + λ₂ + … + λₙ) ผลรวม λ = trace(C) = n ถ้า C เป็น correlation matrix

📖 อ่านสูตรว่า: บรรทัดแรก "ซี คูณ วี เท่ากับ แลมบ์ดา คูณ วี" — ข้างซ้ายคือเมทริกซ์คูณเวกเตอร์ (ได้เวกเตอร์ใหม่) ข้างขวาคือตัวเลขตัวเดียวคูณเวกเตอร์เดิม · ประโยคเต็มคือ "มีทิศ v ที่เมทริกซ์ C ทำกับมันแค่ยืดให้ยาวขึ้น λ เท่า ไม่บิดไปทางอื่น" · โครงที่ต้องเห็น: ถ้า C คือ covariance matrix ของบทนี้ λ ก็คือ variance ของพอร์ตที่ถือน้ำหนัก v — เพราะ vᵀCv = λ·vᵀv = λ เมื่อ v ยาว 1 ซึ่งคือสูตร wᵀΣw ของ §1.3 ตัวเดิม · ทิศที่ λ ใหญ่สุดจึงคือ "พอร์ตที่เหวี่ยงแรงสุด" = ทิศที่ตลาดชอบขยับ · กับดักการอ่าน: λ (แลมบ์ดา) ตรงนี้คือ eigenvalue ไม่ใช่ตัวคูณ Lagrange ของ เล่ม 2 · B §4.2 และไม่ใช่ λ ของ EWMA · ตัวห้อยของ v₁, v₂ คือลำดับทิศเรียงตาม λ ไม่ใช่เวลา · เครื่องหมายของ v เลือกได้ตามใจ — ถ้า v เป็น eigenvector แล้ว −v ก็เป็นด้วย (คูณ −1 ทั้งสองข้างของสมการ) โปรแกรมแต่ละตัวจึงให้เครื่องหมายไม่เหมือนกัน · ตัวเลข % ต่างกันตามว่าใส่ covariance หรือ correlation matrix: covariance ให้ตัวแปรที่ σ ใหญ่มีน้ำหนักมาก correlation ทำให้ทุกตัวหนักเท่ากัน — ตัวอย่างในหน้านี้ใช้ correlation

🧮 เดินเลขจริง — 2 ช่วงอายุ ทำมือได้ครบทุกขั้น

ดอกเบี้ย 2 ปี กับ 10 ปี มี correlation 0.8 → C = [[1, 0.8], [0.8, 1]] · ขั้น 1 — หา λ จากเงื่อนไข det(C − λI) = 0 (ดีเทอร์มิแนนต์ของ C ลบ λ คูณ identity matrix เท่ากับศูนย์ — คือเงื่อนไขที่สมการ Cv = λv มีคำตอบ v ที่ไม่ใช่ศูนย์):

(1 − λ)(1 − λ) − 0.8 × 0.8 = 0 → (1 − λ)² = 0.64 → 1 − λ = ±0.8 λ₁ = 1.8 λ₂ = 0.2 ผลรวม 2.0 = trace(C) ✓ PC1 อธิบาย 1.8 / 2.0 = 90% PC2 อธิบาย 0.2 / 2.0 = 10%

📖 อ่านสูตรว่า: "หนึ่งลบแลมบ์ดา ยกกำลังสอง ลบ ศูนย์จุดแปดยกกำลังสอง เท่ากับศูนย์" — ดีเทอร์มิแนนต์ของ 2×2 คือ "ทแยงหลักคูณกัน ลบ ทแยงรองคูณกัน" · โครงที่ต้องเห็น: สำหรับ 2×2 ที่แนวทแยงเป็น 1 จะได้ λ = 1 ± ρ เสมอ — ρ ใหญ่แปลว่าทิศแรกกินเกือบหมด (ρ = 0.95 → 97.5% / 2.5%) ρ = 0 → 50 / 50 ไม่มีทิศหลัก · กับดักการอ่าน: I คือ identity matrix (เลข 1 บนแนวทแยง ศูนย์ที่อื่น) ไม่ใช่ตัวแปร · "− λI" คือลบ λ ออกจากแนวทแยงเท่านั้น

ขั้น 2 — หา v แทน λ₁ = 1.8 ลงในแถวแรกของ Cv = λv: 1·v₁ + 0.8·v₂ = 1.8·v₁ → 0.8·v₂ = 0.8·v₁ → v₁ = v₂ → ปรับให้ยาว 1 ได้ v = [1, 1]/√2 = [0.71, 0.71] · ตรวจ: C·[1, 1] = [1.8, 1.8] = 1.8·[1, 1] ✓ · แทน λ₂ = 0.2: v₁ + 0.8·v₂ = 0.2·v₁ → v₂ = −v₁ → v = [1, −1]/√2 = [0.71, −0.71] · ตรวจ: C·[1, −1] = [0.2, −0.2] = 0.2·[1, −1] ✓

อ่านผล: PC1 = [0.71, 0.71] คือ "2 ปีกับ 10 ปีขึ้นพร้อมกันเท่า ๆ กัน" = Level กิน 90% · PC2 = [0.71, −0.71] คือ "2 ปีขึ้น 10 ปีลง" = Slope กิน 10% · และ λ ทั้งสองคือ variance จริงของสองพอร์ต: long ทั้งคู่ (น้ำหนัก v₁) เหวี่ยง 1.8 ส่วน long 2 ปี short 10 ปี (น้ำหนัก v₂) เหวี่ยง 0.2 — ตรวจด้วย wᵀΣw ของ §1.3: (1 + 1 + 2 × 0.8)/2 = 1.8 และ (1 + 1 − 2 × 0.8)/2 = 0.2 ✓ · spread trade จึงเหวี่ยงน้อยกว่าพอร์ตทิศเดียว 9 เท่า — นี่คือเหตุผลเชิงตัวเลขที่ curve trade ใช้ leverage ได้มากกว่า outright

🧮 ตัวอย่างจริง — PCA ของ yield curve หลายช่วงอายุ

อัตราดอกเบี้ยมีหลายช่วงอายุ (3 เดือน, 1 ปี, …, 30 ปี) ดูเหมือนหลายสิบตัวแปร · แต่ PCA บนความเคลื่อนไหวของทั้งเส้นพบว่า (ผลคลาสสิกของ Litterman-Scheinkman 1991 ที่งานหลัง ๆ ทำซ้ำได้ตลอด) 3 ทิศทางหลักอธิบายได้ราว 98% — ตัวเลขแม่นขึ้นกับช่วงเวลาและช่วงอายุที่ใช้ แต่ลำดับและขนาดคร่าว ๆ เหมือนกันทุกตลาด:

  • PC1 = Level (~90%): ดอกเบี้ยทุกช่วงขึ้น/ลงพร้อมกัน — v ทุกตัวเครื่องหมายเดียวกัน อย่าง [0.71, 0.71] ข้างบน
  • PC2 = Slope (~8%): สั้นกับยาวแยกทาง (ชัน/แบน) — v เปลี่ยนเครื่องหมายหนึ่งครั้งจากสั้นไปยาว อย่าง [0.71, −0.71]
  • PC3 = Curvature (~2%): กลางโค้งต่างจากปลาย — v เปลี่ยนเครื่องหมายสองครั้ง

จากหลายสิบมิติ เหลือแค่ 3 ตัวเลขที่มีความหมาย → hedge ง่ายขึ้นมหาศาล · เสาหลัก · Part 1 ต่อเรื่องนี้ไปถึงการเทรด curve จริง

🐍 ทำแบบเดียวกับ 2×2 แต่ 5 ช่วงอายุ — กลับเมทริกซ์ 5×5 ด้วยมือไม่คุ้ม ให้ np.linalg.eigh ทำขั้น 1–2 ให้ในบรรทัดเดียว · ใส่ correlation matrix (ไม่ใช่ covariance) เพื่อให้ทุกช่วงอายุหนักเท่ากัน:

🐍 Python — PCA: eigenvalue → % ที่แต่ละทิศอธิบายได้
import numpy as np

# correlation matrix ของการเปลี่ยนแปลงดอกเบี้ย 5 ช่วงอายุ (สั้น→ยาว) — ตัวเลขสมมติแบบที่เห็นจริง
C = np.array([[1.00, 0.95, 0.88, 0.80, 0.72],
              [0.95, 1.00, 0.96, 0.90, 0.83],
              [0.88, 0.96, 1.00, 0.97, 0.92],
              [0.80, 0.90, 0.97, 1.00, 0.97],
              [0.72, 0.83, 0.92, 0.97, 1.00]])

vals, vecs = np.linalg.eigh(C)      # eigh = สำหรับเมทริกซ์สมมาตร · คืน λ เรียงจากเล็กไปใหญ่
vals = vals[::-1]                   # เรียงจากใหญ่ไปเล็ก
pct  = vals / vals.sum() * 100      # แต่ละทิศอธิบาย variance กี่ % · vals.sum() = 5 = trace

for i, p in enumerate(pct, 1):
    print(f"PC{i}: {p:5.2f}%   (สะสม {np.cumsum(pct)[i-1]:5.2f}%)")
# PC1: 91.29%   (สะสม 91.29%)   ← Level: ทุกช่วงขยับพร้อมกัน
# PC2:  7.25%   (สะสม 98.54%)   ← Slope: สั้น vs ยาว
# PC3:  0.87%   (สะสม 99.41%)   ← Curvature
# PC4:  0.38%   (สะสม 99.78%)
# PC5:  0.22%   (สะสม 100.00%)
✅ อ่านผลลัพธ์

ดอกเบี้ย 5 ช่วงอายุ (จริง ๆ มีเป็นสิบ) ถูกย่อเหลือ 3 ทิศ ที่อธิบายได้ 99.4% · PC1 อย่างเดียวกิน 91% — นั่นคือเหตุผลที่เทรดเดอร์พันธบัตร hedge "duration" (= exposure ต่อ Level) เป็นอย่างแรก · PC4–PC5 (0.38%, 0.22%) มักถูกเรียกว่า noise และตัดทิ้งตอนสร้างโมเดลความเสี่ยง — แต่อย่าอ่านว่า "ไม่มีค่า": relative-value trade จำนวนมากอาศัยแกนเล็ก ๆ เหล่านี้พอดี เพราะมันคือส่วนที่คนส่วนใหญ่ไม่ hedge (เสาหลัก · Part 1 ขยายประเด็นนี้) · เปลี่ยนแค่เมทริกซ์ที่ใส่ ก็ใช้วิธีเดียวกันย่อ volatility surface, พอร์ตหุ้น หรือ factor อะไรก็ได้

✍️ ลองทำเอง

รันโค้ดข้างบน แล้วดู vecs[:, -1] (eigenvector ของ PC1 — คอลัมน์สุดท้ายเพราะ eigh เรียงจากเล็กไปใหญ่) และ vecs[:, -2] (PC2) · คาดเดาก่อน: ค่า 5 ตัวของ PC1 ควรมีเครื่องหมายเดียวกันทั้งหมด (Level = ทุกช่วงขยับทางเดียวกัน) ส่วน PC2 ควรเปลี่ยนเครื่องหมายหนึ่งครั้งจากสั้นไปยาว (Slope)

ดูเฉลย

PC1 = [−0.43, −0.45, −0.46, −0.46, −0.44] — ลบหมดและขนาดใกล้กัน = ทุกช่วงอายุขยับพร้อมกัน ✓ · เครื่องหมายลบไม่ได้แปลว่า "ลง": numpy เลือกเครื่องหมายให้ตามใจ (กับดักในกล่อง 📖) กลับเป็น [0.43, …, 0.44] ก็คือ eigenvector ตัวเดียวกัน · PC2 = [−0.66, −0.33, 0.05, 0.35, 0.57] — จากลบไปบวก เปลี่ยนเครื่องหมายครั้งเดียวตรงช่วงกลาง = สั้นกับยาวไปคนละทาง ✓ (Slope) · ถ้าดูต่อ PC3 = [−0.56, 0.41, 0.50, 0.11, −0.51] เปลี่ยนเครื่องหมายสองครั้ง = ปลายสองข้างกับกลางไปคนละทาง (Curvature)

เชื่อมกับ Options

PCA ใช้ย่อ volatility surface (σ ของทุก strike × ทุกอายุ) ให้เหลือ factor ไม่กี่ตัว — ทิศแรกมักเป็น "ทั้ง surface ขึ้นลงพร้อมกัน" ทิศสองคือ skew เปลี่ยน ทิศสามคือ term structure เปลี่ยน · โครงเดียวกับ Level / Slope / Curvature ของดอกเบี้ย

1.4½ PCA กับ OLS — ข้อมูลชุดเดียว ได้เส้นคนละเส้น

🚶 อ่านเป็นภาษาคนก่อน: ทั้ง PCA (§1.4) และ regression (§2.1 ข้างหน้า) "ลากเส้นผ่านกลุ่มจุด" เหมือนกัน คนจึงมักคิดว่าได้เส้นเดียวกัน · ไม่ใช่ — ต่างกันที่ สั่งให้ย่อระยะแบบไหน: OLS ย่อระยะแนวตั้ง (ผิดพลาดได้เฉพาะ Y เพราะถือว่า X รู้แน่) ส่วน PC1 ย่อระยะตั้งฉากกับเส้น (ทั้ง X และ Y ผิดพลาดได้เท่ากัน) · จุดชุดเดียวกันจึงให้ความชันคนละค่า และยิ่งจุดกระจายห่างเส้นมาก สองเส้นก็ยิ่งแยกจากกัน · ภาพข้างล่างใช้ข้อมูลจำลอง 22 จุดที่รู้ความชันจริง (0.7) เพื่อให้เห็นว่าเส้นไหนเข้าใกล้ความจริง

OLS (Y บน X): minimize Σ(yᵢ − ŷᵢ)² → ความชัน β = Cov(X,Y)/Var(X) PC1 = TLS: minimize Σdᵢ² (dᵢ ตั้งฉากกับเส้น) → ความชัน = v₂/v₁ ของ eigenvector ตัวแรก ข้อมูลจำลอง 22 จุดในภาพ (สร้างด้วย y = 0.7x + noise · ป้ายแกนสมมติเป็น BTC/ETH): OLS (Y บน X) = 0.75 · PC1 (TLS) = 1.13 · OLS สลับข้าง (X บน Y แล้วกลับ) = 1.58

📖 อ่านสูตรว่า: "ดีไอ" คือระยะจากจุดที่ i ไปยังเส้น วัดตั้งฉาก (มุมฉากเล็ก ๆ ในภาพขวา) ส่วน yᵢ − ŷᵢ คือระยะดิ่งลงตามแกน Y (เส้นประในภาพซ้าย) · "วีสอง หาร วีหนึ่ง" คือส่วนประกอบ Y หารส่วนประกอบ X ของ eigenvector — ความชันของทิศที่ variance มากสุด · โครงที่ต้องเห็น: สองสูตรต่างกันแค่ "ระยะอะไร" แต่ให้เส้นคนละเส้น เพราะ OLS มีแกนที่ถือว่าไม่ผิด (X) ส่วน PCA ไม่มี — และ OLS ที่สลับแกนก็ให้เส้นที่สาม · เส้น PC1 อยู่ระหว่าง OLS สองแบบเสมอเมื่อความสัมพันธ์เป็นบวก (0.75 < 1.13 < 1.58) · กับดักการอ่าน: "ความชัน 0.75" ใน OLS มีหน่วย "% ของ Y ต่อ 1% ของ X" ใช้เป็น hedge ratio ได้ตรง ๆ · ความชันของ PC1 ขึ้นกับสเกลของแกน — ถ้า Y วัดเป็น bp แทน % เส้น PC1 จะเปลี่ยนทิศ แต่เส้น OLS ให้คำตอบเดิมแค่คูณ 100 · ภาพนี้จึงต้องวาดสองแกนสเกลเดียวกัน

❌ พังเมื่อไร — เลือกวิธีตามความสวย ไม่ใช่ตามว่า "ใครผิดพลาดได้"
  • ใช้ PC1 เป็น hedge ratio เพราะ "ดูสมมาตรกว่า" — ถ้าคำถามคือ "ETH ขยับกี่ % เมื่อ BTC ขยับ 1%" นั่นคือคำถามแบบ Y บน X ที่ X เป็นตัวตั้ง OLS คือคำตอบ (0.75) · PC1 (1.13) ตอบคำถามอื่น: "ทิศที่คู่นี้เคลื่อนไปด้วยกัน" ซึ่งไม่มีใครเป็นตัวตั้ง
  • ใช้ OLS กับสองขาที่ผิดพลาดพอกัน — ใน pairs trading ราคาหุ้น A กับ B ต่างก็มี noise ฝั่งตัวเอง OLS จะให้ β เอียงเข้าหาศูนย์ (attenuation) และสลับข้างแล้วได้อีกค่า — ในภาพนี้ 0.75 กับ 1.58 ห่างกันกว่าเท่าตัวทั้งที่ X ไม่มี noise เลย (ความชันจริง 0.7 จึงอยู่ข้าง OLS ไม่ใช่ตรงกลาง) ถ้าทั้งสองขามี noise พอกัน ค่าจริงจะไปอยู่ระหว่างสองเส้นแทน · 2 · D §9.1½ เดินเลขเรื่องนี้เต็ม ๆ และเพิ่ม Box-Tiao (เลือก β ให้ spread กลับตัวเร็วสุด) เป็นอีกวิธี
  • ลืมว่า PC1 ไวต่อสเกล — PCA บน covariance ของตัวแปรที่หน่วยต่างกันจะให้ทิศแรกเป็น "ตัวแปรที่หน่วยใหญ่สุด" เสมอ นี่คือเหตุผลที่ §1.4 ป้อน correlation matrix ไม่ใช่ covariance

สิ่งที่ภาพนี้อยากให้จำ: ก่อนลากเส้น ถามก่อนว่าใครผิดพลาดได้ — X แน่นอน → OLS · ทั้งคู่ผิดพลาดเท่ากัน → TLS/PC1 · ทั้งคู่ผิดพลาดแต่ไม่เท่ากัน → ไม่มีวิธีไหนถูกจากสูตรอย่างเดียว ต้องรู้สัดส่วน noise (2 · D §9.1½)

1.5 Positive Definite — ทำไม covariance matrix "ผิดเพี้ยน" ไม่ได้

🚶 อ่านเป็นภาษาคนก่อน: เพราะ σ²ₚ = wᵀΣw คือ variance ซึ่งติดลบไม่ได้ covariance matrix ที่ถูกต้องต้องให้ wᵀΣw ≥ 0 ทุกน้ำหนัก w (เรียกว่า positive semi-definite) · ถ้าคำนวณแล้วได้ค่าลบ = ข้อมูลมีข้อผิดพลาด (เช่น correlation ที่ประเมินมาไม่สอดคล้องกัน)

1.6 Factor or Noise? — PCA คืน "ทิศทางหลัก" ให้เสมอ แม้ไม่มีอะไรอยู่

🚶 อ่านเป็นภาษาคนก่อน: §1.4 จบด้วยภาพสวย: yield curve ย่อเหลือ Level / Slope / Curvature · แต่มีคำถามค้างที่ต้องตอบก่อนเอา PCA ไปใช้กับข้อมูลที่ไม่รู้คำตอบล่วงหน้า — ถ้าโยนตัวเลขสุ่มล้วน 5 ชุดเข้าไป PCA ก็ยังคืน PC1, PC2 พร้อมเปอร์เซ็นต์และรูปแบบเครื่องหมายให้เหมือนกัน เพราะ eigenvalue 5 ตัวของข้อมูลจำกัดไม่มีวันเท่ากันพอดี ตัวที่ใหญ่สุดย่อมดู "สำคัญ" และเวกเตอร์ของมันย่อมมีลวดลายบางอย่าง · หัวข้อนี้ตอบว่าจะแยก "โครงสร้างจริง" จาก "ลวดลายที่ความสุ่มสร้างให้ฟรี" ได้อย่างไร ด้วยวิธีเดียวที่ใช้ทั่วคลังนี้: สร้างฐานจากความสุ่มก่อน แล้วดูว่าของจริงเกินฐานไหม (สถานี ② "ถามฐานก่อนเสมอ" ของ NQ Part 3 ในภาษาเมทริกซ์)

ข้อมูลสุ่มล้วน p ตัวแปร n วัน: eigenvalue ของ correlation matrix ไม่ใช่ 1 ทั้งหมด ขอบบนของ noise (Marchenko-Pastur): λ₊ = (1 + √(p/n))² ขอบล่าง λ₋ = (1 − √(p/n))² p = 5, n = 250: λ₊ = (1 + √0.02)² = (1 + 0.1414)² = 1.303 λ₋ = 0.737 parallel analysis (Horn 1965 · ฉบับเปอร์เซ็นไทล์ 95 ของ Glorfeld 1995): รับ PC ที่ k เมื่อ λₖ (ของจริง) > เปอร์เซ็นไทล์ 95 ของ λₖ (จากข้อมูลสุ่ม p × n ชุดเดียวกัน) ปอกทีละชั้น: หลังรับ PC1 แล้ว variance ที่เหลือ = p − λ₁ กระจายบน p − 1 มิติ ฐานของ λ₂ = (p − λ₁)/(p − 1) × เปอร์เซ็นไทล์ 95 ของ λ₁ ของข้อมูลสุ่ม (p − 1) × n

📖 อ่านสูตรว่า: "แลมบ์ดา-บวก เท่ากับ หนึ่ง บวก รากที่สองของ พี หาร เอ็น ทั้งหมดยกกำลังสอง" — p คือจำนวนตัวแปร (ช่วงอายุ, หุ้น, ปัจจัย) n คือจำนวนวัน · ตัวห้อย + และ − คือขอบบนกับขอบล่าง ไม่ใช่เครื่องหมายของค่า · โครงที่ต้องเห็น: ถ้าไม่มีโครงสร้างเลย eigenvalue ทุกตัว "ควร" เป็น 1 (correlation matrix ที่เป็น identity) แต่ด้วยข้อมูลจำกัดมันกระจายอยู่ในช่วง [λ₋, λ₊] และช่วงนี้กว้างตาม √(p/n) — ตัวแปรมากหรือวันน้อย ช่วงยิ่งกว้าง ความสุ่มยิ่งสร้าง "ทิศทางหลัก" ปลอมได้ใหญ่ · ที่ p/n → 0 (วันมากไม่จำกัด) ทั้งสองขอบหุบเข้าหา 1 คือความจริงที่ eigenvalue ทุกตัวเท่ากัน · โครงคือ "ค่าจริง 1 + ส่วนเผื่อที่หดตาม 1/√n" ตัวเดียวกับ ค่าประมาณ ± SE · กับดักการอ่าน: λ₊ เป็นผลลัพธ์เชิงลิมิต (p และ n → ∞ โดย p/n คงที่) กับ p = 5 มันเป็นแค่ค่าประมาณ — เปอร์เซ็นไทล์ 95 จากการสุ่มจริง ๆ (parallel analysis) จึงเป็นตัวที่ใช้ตัดสิน และตัวเลขสองตัวนี้จะไม่เท่ากันพอดี · "เปอร์เซ็นไทล์ 95" แปลว่าข้อมูลสุ่มล้วน 1 ใน 20 ชุดจะข้ามเส้นนี้ได้เองโดยไม่มีโครงสร้าง — เกณฑ์นี้จึงมี false positive (ผลบวกลวง — เห็นโครงสร้างที่ไม่มี) 5% ฝังอยู่โดยนิยาม (เรื่องเดียวกับ p < 0.05 ใน 2 · C §6.2) · §1.4 เรียกจำนวนตัวแปรว่า n ในหัวข้อนี้เปลี่ยนเป็น p เพราะต้องเก็บ n ไว้ให้จำนวนวัน — ผลรวม eigenvalue จึงเท่ากับ p ตรงนี้ · ทำไมต้อง "ปอกทีละชั้น": eigenvalue รวมกันได้ p เสมอ ถ้า PC1 กินไป 2.4 จาก 5 ที่เหลือสี่ตัวถูกบีบให้เล็ก การเทียบ λ₂ ของจริงกับ λ₂ ของข้อมูลสุ่มที่ไม่มี PC1 ใหญ่จึงไม่ยุติธรรม ต้องปรับฐานให้เหลือ variance เท่ากันก่อน

🐍 Python — parallel analysis แบบปอกทีละชั้น (ตัวเลขทุกตัวในหัวข้อนี้มาจากโค้ดนี้)
import numpy as np

def eig_corr(X):                                   # eigenvalue ของ correlation matrix เรียงใหญ่→เล็ก
    v = np.linalg.eigvalsh(np.corrcoef(X.T))
    return v[::-1]

def noise_p95(p, n, sims=1000, seed=1):            # เปอร์เซ็นไทล์ 95 ของ λ₁ จากข้อมูลสุ่ม p × n
    rng = np.random.default_rng(seed)
    return np.percentile([eig_corr(rng.standard_normal((n, p)))[0] for _ in range(sims)], 95)

def n_factors(X):                                  # ★ ปอกทีละชั้น: รับ PC k เมื่อ λ_k > ฐานของ variance ที่เหลือ
    n, p = X.shape
    lam = eig_corr(X); used = 0.0
    for k in range(p - 1):
        dims = p - k
        base = (p - used) / dims * noise_p95(dims, n)
        print(f"PC{k+1}: λ = {lam[k]:.3f}  ฐาน = {base:.3f}  {'✓' if lam[k] > base else '✗'}")
        if lam[k] <= base:
            return k
        used += lam[k]
    return p - 1

rng = np.random.default_rng(0)
noise = rng.standard_normal((250, 5))
print("สุ่มล้วน:", n_factors(noise), "ปัจจัย")
# PC1: λ = 1.281  ฐาน = 1.265  ✓
# PC2: λ = 1.111  ฐาน = 1.135  ✗
# สุ่มล้วน: 1 ปัจจัย            ← false positive 5% ตัวจริง — ต้องเช็กความนิ่งต่อ

def half_cos(X, k):                                # เกณฑ์ที่สอง: |cos| ของ PC k ระหว่างสองครึ่ง
    h = len(X) // 2
    w1 = np.linalg.eigh(np.corrcoef(X[:h].T))[1][:, ::-1][:, k]
    w2 = np.linalg.eigh(np.corrcoef(X[h:].T))[1][:, ::-1][:, k]
    return abs(w1 @ w2)
print(f"สุ่มล้วน PC1 |cos| = {half_cos(noise, 0):.3f}")   # 0.374 — ทิศไม่นิ่ง = noise

2.1 Simple Linear Regression = Beta

Regression → Beta OLS ★★★ ต้องรู้จัก

🚶 อ่านเป็นภาษาคนก่อน: ลากเส้นตรงเส้นเดียวผ่านกลุ่มจุดข้อมูลให้ "ใกล้ทุกจุดที่สุด" (ระยะห่างยกกำลังสองรวมน้อยสุด = least squares) · ความชันของเส้นนั้น = β = "ตลาดขยับ 1 หน่วย หุ้นขยับกี่หน่วย"

y = α + βx β = Cov(X, Y) / Var(X) ← ความชัน α = ȳ − β·x̄ ← จุดตัดแกน y Least Squares: minimize Σ(yᵢ − α − βxᵢ)²

📖 อ่านสูตรว่า: "วาย เท่ากับ อัลฟา บวก เบต้าเอ็กซ์" — α คือค่าของ y ตอน x = 0 (จุดตัดแกน) · β คือ "x เพิ่ม 1 หน่วยแล้ว y เพิ่มเท่าไร" (ความชัน) · "เบต้า เท่ากับ โคแวเรียนซ์ของเอ็กซ์กับวาย หารด้วย แวเรียนซ์ของเอ็กซ์" · โครงที่ต้องเห็น: β = Cov/Var คือ "ส่วนที่ y ขยับตาม x หารด้วยส่วนที่ x ขยับเอง" — โครงเดียวกับ Σ(x−x̄)(y−ȳ)/Σ(x−x̄)² ที่กางออกในกล่อง 🧮 ถัดไป และเป็นโครงของทุก regression ในคลัง · บรรทัดสุดท้าย "minimize Σ(…)²" อ่านว่า "เลือก α, β ที่ทำให้ผลรวมของระยะห่างยกกำลังสองน้อยที่สุด" — สิ่งในวงเล็บคือ residual (y จริง ลบ y ที่เส้นทำนาย) ยกกำลังสองเพื่อให้ผิดบวกกับผิดลบไม่หักล้างกัน · กับดักการอ่าน: ขีดบน x̄, ȳ คือค่าเฉลี่ย ไม่ใช่ "ไม่" · ตัวห้อย i ใน Σ(yᵢ − α − βxᵢ)² คือ "จุดข้อมูลที่ i" ไม่ใช่เวลา

เชื่อมกับ Options
  • β (Beta) ของหุ้น = ความชัน regression ของ return หุ้น vs ตลาด · β = 1.5 → หุ้นเหวี่ยงกว่าตลาด 1.5 เท่า
  • Hedge Ratio = ความชัน regression ของราคา option vs หุ้นอ้างอิง ≈ Delta (เพื่อนเก่าจากเล่ม 1 Part III)
🧮 คิดด้วยมือ — หา Beta จากผลตอบแทน 6 เดือน

ผลตอบแทนรายเดือน · ตลาด X = [+3, −2, +5, −1, +2, −4]% · หุ้น Y = [+5, −4, +7, 0, +2, −7]% · β = Cov(X,Y)/Var(X)

x̄ = (3−2+5−1+2−4)/6 % = 0.5% , ȳ = (5−4+7+0+2−7)/6 % = 0.5% Cov(X,Y) = Σ(xᵢ−x̄)(yᵢ−ȳ)/(n−1) = 0.001770 Var(X) = Σ(xᵢ−x̄)²/(n−1) = 0.001150 β = Cov/Var = 0.001770 / 0.001150 = 1.54 α = ȳ − β·x̄ = 0.005 − 1.54×0.005 = −0.0027

📖 อ่านสูตรว่า: ขีดบน x̄ อ่านว่า "เอ็กซ์บาร์" = ค่าเฉลี่ยของ x ทุกจุด · (xᵢ − x̄) = "จุดที่ i ห่างจากค่าเฉลี่ยเท่าไร" (deviation) · โครงที่ต้องเห็น: Σ(xᵢ−x̄)(yᵢ−ȳ) = "เอาส่วนเบี่ยงเบนของ x กับของ y ที่เดือนเดียวกันคูณกัน แล้วบวกทุกเดือน" — เดือนที่ทั้งคู่บวกหรือทั้งคู่ลบให้พจน์บวก เดือนที่สวนทางกันให้พจน์ลบ นี่คือที่มาของคำว่า "ไปด้วยกันไหม" · กับดักการอ่าน: ตัวห้อย i คือ "เดือนที่ i" (ไล่ 1 ถึง 6) ใช้ตัวเดียวกันทั้ง x และ y เพื่อจับคู่ให้ตรงเดือน · n−1 ในตัวหารอยู่ทั้งเศษและส่วน จึงตัดกันหมดและไม่กระทบ β ตามที่ 💡 ด้านล่างอธิบาย

β = 1.54 → หุ้นตัวนี้เหวี่ยงกว่าตลาด ~1.5 เท่า (high-beta)

💡 ตรงนี้หารด้วย n−1 ไม่ใช่ n ต่างจากสูตร Cov/Var ใน Part II ที่หารด้วย n · สองแบบนี้คือ "ตัวอย่าง" กับ "ประชากร" ถูกทั้งคู่ · และสำหรับ β ไม่มีผลเลย เพราะตัวหารตัวเดียวกันอยู่ทั้งเศษและส่วนจึงตัดกันหมด (รายละเอียดเรื่อง ddof อยู่ที่ เล่ม 2 · C §7.1)

ทำมือได้ 6 จุด · ข้อมูลจริงเป็นพัน ๆ วัน ให้ numpy ทำ — และแถม R² มาด้วยว่าเส้นนี้อธิบายหุ้นได้ดีแค่ไหน:

🐍 Python — หา Beta + Alpha + R² จากข้อมูลจริง
import numpy as np

mkt = np.array([0.03, -0.02, 0.05, -0.01, 0.02, -0.04])   # ผลตอบแทนตลาด (X)
stk = np.array([0.05, -0.04, 0.07,  0.00, 0.02, -0.07])   # ผลตอบแทนหุ้น (Y)

# วิธีตรงตามสูตร: β = Cov/Var
beta  = np.cov(mkt, stk, ddof=1)[0,1] / np.var(mkt, ddof=1)
alpha = stk.mean() - beta*mkt.mean()
print(f"Beta = {beta:.4f}   Alpha = {alpha:.5f}")   # Beta = 1.5391   Alpha = -0.00270

# วิธีลัด: polyfit ดีกรี 1 (ได้ [ความชัน, จุดตัด] = [β, α])
beta2, alpha2 = np.polyfit(mkt, stk, 1)
print(f"polyfit → β={beta2:.4f}, α={alpha2:.5f}")    # polyfit → β=1.5391, α=-0.00270

# R² = เส้นนี้อธิบาย variance ของหุ้นได้กี่ %
pred = alpha + beta*mkt
r2 = 1 - ((stk-pred)**2).sum() / ((stk-stk.mean())**2).sum()
print(f"R-squared = {r2:.4f}")                       # R-squared = 0.9626  (เส้นฟิตดีมาก)
✅ อ่านผลลัพธ์

β = 1.54 ตรงกับที่คิดมือ · α ≈ 0 (หุ้นไม่ได้ให้ผลตอบแทนเกินตลาดอย่างมีนัย) · R² = 0.96 แปลว่าการขยับของหุ้น ~96% อธิบายได้ด้วยตลาด เหลือ 4% เป็นเรื่องเฉพาะตัว · β นี้เอาไป hedge ได้ทันที: ถือหุ้นนี้ ฿1M อยากตัดความเสี่ยงตลาด → short ดัชนี ฿1.54M (β×มูลค่า)

❌ พังเมื่อไร — จุดเดียวคุมทั้งเส้น (outlier · วัน jump · หน้าต่างเลื่อน)

least squares ให้น้ำหนักตามระยะยกกำลังสอง จุดที่อยู่ไกลจึงมีเสียงดังกว่าเพื่อนมหาศาล — และ β ที่ "ดูน่าเชื่อถือบนหน้าจอ" อาจมาจากจุดเดียว · ลองเติมเดือนที่ 7 ให้ข้อมูล 6 เดือนข้างบน: ตลาด −6% วันประกาศงบ หุ้นร่วง −20%

6 เดือน: β = 1.54 R² = 0.96 7 เดือน: X = [+3, −2, +5, −1, +2, −4, −6]% Y = [+5, −4, +7, 0, +2, −7, −20]% β = 2.16 R² = 0.87 hedge หุ้น ฿1M: short ดัชนี ฿2.16M แทน ฿1.54M → ต่างกัน ฿624,000 จากจุดข้อมูลจุดเดียว

📖 อ่านสูตรว่า: เดือนที่ 7 อยู่ไกลจากค่าเฉลี่ยทั้งสองแกน (x₇ − x̄ ติดลบมาก และ y₇ − ȳ ติดลบมาก) พจน์ (x₇ − x̄)(y₇ − ȳ) ใน Cov จึงเป็นบวกก้อนใหญ่ก้อนเดียวที่ดัน β ขึ้น · โครงที่ต้องเห็น: ใน Cov/Var ทั้งเศษและส่วนโตตามระยะยกกำลังสอง — จุดที่ห่าง 3 เท่ามีน้ำหนัก 9 เท่า · กับดักการอ่าน: R² ที่ลดจาก 0.96 เป็น 0.87 ยังดูดี — R² ไม่เตือนเรื่องนี้ ต้องดูกราฟ (2 · C §5.2 สอนจับ outlier กับ leverage point ด้วยตา และวิธี "ตัดจุดนั้นออกแล้วคำนวณใหม่")

แบบที่เจอบ่อยกว่าในงานจริง — β บนหน้าต่างเลื่อน: คำนวณ β ด้วยข้อมูล 60 วันล่าสุดทุกวัน (rolling) · วันที่ 120 ตลาดร่วง −7% หุ้นร่วง −20% (วันเดียว) · จำลองด้วย β จริง 1.2 ทั้งปี:

🐍 Python — rolling β 60 วัน เมื่อวัน jump เข้าและออกจากหน้าต่าง
import numpy as np
rng = np.random.default_rng(11)
T, W, J = 250, 60, 120
mkt = rng.normal(0, 0.01, T)                          # ตลาด σ 1%/วัน
stk = 1.2*mkt + rng.normal(0, 0.008, T)               # β จริง = 1.2 ทั้งปี
mkt[J], stk[J] = -0.07, -0.20                          # วันที่ 120: วัน jump

def beta(x, y): return np.cov(x, y, ddof=1)[0,1] / np.var(x, ddof=1)
rb = {d: beta(mkt[d-W+1:d+1], stk[d-W+1:d+1]) for d in range(W-1, T)}
for d in (J-1, J, J+W-1, J+W):
    print(f"β วันที่ {d} = {rb[d]:.2f}")
# β วันที่ 119 = 1.30   ← ก่อน jump (ประมาณ 1.2 + noise)
# β วันที่ 120 = 2.00   ← วัน jump เข้าหน้าต่าง: เด้งวันเดียว
# β วันที่ 179 = 2.06   ← ยังค้างสูงตลอด 60 วัน ทั้งที่ตลาดกลับมาปกติแล้ว
# β วันที่ 180 = 1.18   ← วัน jump หลุดจากหน้าต่าง: ตกวันเดียว
print(f"ตัดวันที่ 120 ทิ้งได้ {beta(mkt[J-W+1:J], stk[J-W+1:J]):.2f}")
# ตัดวันที่ 120 ทิ้งได้ 1.30   ← 59 วันที่เหลือให้ค่าเดิม

β กระโดดจาก 1.30 เป็น 2.00 ในวันเดียว แล้วค้างราว 2.0 นาน 60 วัน แล้วตกกลับ 1.18 ในวันที่ 180 — ทั้งสองครั้งตลาดไม่ได้เปลี่ยนอะไรเลย สิ่งที่เกิดคือวัน jump เข้าและออกจากหน้าต่าง · คนที่ hedge ตาม β รายวันจะ short ดัชนีเกินจริงเกือบ 70% ตลอดสองเดือน แล้ว "ปรับกลับ" ในวันที่ไม่มีข่าวอะไร · นี่คือรูปธรรมของประโยคที่คลังนี้พูดซ้ำ: โมเดลไม่ได้พัง — เราเอาตัวเลขของมันไปใช้ผิด

แล้วทำอย่างไร: (1) ก่อนเชื่อ β ให้ทำ leave-one-out: ตัดทีละจุดแล้วดูว่า β เปลี่ยนเกิน 10% ไหม (2 · C §5.2) · (2) ถามว่าวัน jump คือ "ข้อมูลผิด" หรือ "เหตุการณ์จริง" — วัน crash คือข้อมูลจริงที่บอกว่าในวันเลวร้าย β ของหุ้นนี้สูงกว่าปกติ ไม่ควรลบ แต่ควรรายงานสองค่า (β วันปกติ กับ β วันวิกฤต) แทนค่าเดียว · (3) ถ้าอยากได้ค่าที่จุดเดียวลากได้ยาก ใช้ตัวประมาณ robust (2 · C §5.2 การ์ด Robust regression) · (4) rolling window ให้ดูกราฟ β ตามเวลาเสมอ — ขั้นบันไดที่ขึ้นแล้วลงห่างกันพอดี W วันคือลายเซ็นของหน้าต่าง ไม่ใช่ของตลาด

2.2 Multiple Regression → Factor Models

Multiple Regression → Factor Model OLS หลายตัวแปร ★★★ ต้องรู้จัก

🎯 Thesis

"β ตัวเดียวจาก regression กับตลาดบอกว่าหุ้นขยับตามตลาดเท่าไรรวมทุกเหตุผล — multiple regression แยกเหตุผลออกจากกัน: β แต่ละตัวคือ 'x ตัวนี้เพิ่ม 1 แล้ว y เปลี่ยนเท่าไร เมื่อตรึงตัวอื่นไว้' ราคาที่ต้องจ่ายคือ ถ้าตัวแปรสองตัวเกือบเป็นตัวเดียวกัน β จะระเบิด"

❓ ทำไมต้องรู้จัก

hedge ด้วย β ตัวเดียวจาก 2.1 คือการ short ดัชนีก้อนเดียว · แต่ถ้าหุ้นเหวี่ยงเพราะ "ขนาดบริษัท" หรือ "ความถูกแพง" ด้วย ตลาดขึ้นแต่หุ้นเล็กร่วง พอร์ตที่ hedge แค่ตลาดก็ยังเจ็บ · multiple regression ให้ hedge ratio ทีละปัจจัย และเป็นสูตรตัวเดียวกับที่ เล่ม 2 · F จะเอาไปใส่ค่าปรับ (Ridge/Lasso) ต่อ

🚶 อ่านเป็นภาษาคนก่อน: ถ้าผลตอบแทนหุ้นขึ้นกับหลายปัจจัย (ตลาด + ขนาดบริษัท + มูลค่า) ก็ใส่หลายตัวแปร · แก้ทีเดียวด้วย matrix (นี่คือที่ Linear Algebra บทที่ 1 กลับมาใช้)

y = β₀ + β₁x₁ + β₂x₂ + … + βₙxₙ + ε รูปเมทริกซ์: β = (XᵀX)⁻¹ Xᵀy

📖 อ่านสูตรว่า: บรรทัดแรก "วาย เท่ากับ เบต้าศูนย์ บวก เบต้าหนึ่งเอ็กซ์หนึ่ง บวก … บวก เอปไซลอน" · กับดักการอ่าน: ตัวห้อย 1, 2, …, n ที่ x และ β คือหมายเลขปัจจัย (ตลาด, ขนาด, มูลค่า) ไม่ใช่เวลา · β₀ คือ α ของสูตรเดิมที่เปลี่ยนชื่อ · ε (เอปไซลอน) = ส่วนที่ทุกปัจจัยรวมกันยังอธิบายไม่ได้ (residual) · บรรทัดสอง "เบต้า เท่ากับ เอ็กซ์ทรานสโพสเอ็กซ์ ยกกำลังลบหนึ่ง เอ็กซ์ทรานสโพสวาย" — ⁻¹ อ่านว่า "อินเวอร์ส" = "หารด้วยเมทริกซ์" · โครงที่ต้องเห็น: XᵀX ทำหน้าที่ Var(X) และ Xᵀy ทำหน้าที่ Cov(X, y) — นี่คือ β = Cov/Var ตัวเดิมที่เขียนให้รับหลายปัจจัยพร้อมกัน ถ้า X มี x ตัวเดียว (บวกคอลัมน์ค่าคงที่สำหรับ β₀) ความชันที่ได้จะเท่ากับสูตร Cov/Var ใน 2.1 เป๊ะ

🧮 เดินเลขจริง — 8 เดือน 3 ปัจจัย (แทนค่าลงในเมทริกซ์จนถึงคำตอบ)

ผลตอบแทนรายเดือน (%): ตลาด x₁ = [+3, −2, +5, −1, +2, −4, +1, +3] · ขนาด x₂ = [+1, +2, −1, 0, +3, −2, +1, −1] · มูลค่า x₃ = [−1, +1, +2, +1, −2, 0, −1, +2] · หุ้น y = [+4.6, −1.0, +6.2, −0.6, +4.1, −6.3, +1.9, +2.3]

"ปัจจัย" แต่ละตัวคือผลตอบแทนของพอร์ตหนึ่งพอร์ต ไม่ใช่ตัวเลขบัญชี: ปัจจัยขนาด = ผลตอบแทนหุ้นเล็ก ลบ หุ้นใหญ่ ในเดือนนั้น · ปัจจัยมูลค่า = หุ้นถูก (book-to-market สูง) ลบ หุ้นแพง — แบบเดียวกับ SMB และ HML ของ Fama-French (กล่อง 📍 ข้างล่าง) · เดือนที่ x₂ = +2 คือเดือนที่หุ้นเล็กชนะหุ้นใหญ่ 2%

ขั้น 1 — สร้าง X: 8 แถว (เดือน) × 4 คอลัมน์ [1, x₁, x₂, x₃] · คอลัมน์แรกเป็นเลข 1 ทั้งหมดเพื่อให้ β₀ (จุดตัดแกน) มีที่ยืน

ขั้น 2 — XᵀX และ Xᵀy (ผลรวมของผลคูณทุกคู่คอลัมน์ Σxᵢxⱼ และผลรวมของแต่ละคอลัมน์คูณ y):

XᵀX = [ 8 7 3 2 ] Xᵀy = [ 11.2 ] [ 7 69 6 5 ] [ 89.6 ] [ 3 6 21 −10 ] [ 20.9 ] [ 2 5 −10 16 ] [ 0.7 ]

📖 อ่านสูตรว่า: ช่อง (2,2) = 69 คือ Σx₁² "ตลาดกระจายแค่ไหน" — บทบาทของ Var(X) ใน 2.1 · ช่อง (2,3) = 6 คือ Σx₁x₂ "ตลาดกับขนาดไปด้วยกันแค่ไหน" (ยังไม่ได้ลบค่าเฉลี่ย เพราะคอลัมน์เลข 1 จัดการให้) · Xᵀy ช่องที่ 2 = 89.6 คือ Σx₁y "ตลาดกับหุ้นไปด้วยกันแค่ไหน" — บทบาทของ Cov(X, y) · โครงที่ต้องเห็น: ตาราง XᵀX สมมาตรและแนวทแยงเป็นบวกเสมอ เหมือน covariance matrix ของบทที่ 1 — เพราะมันคือ covariance matrix ของปัจจัย (คูณ n และยังไม่ลบค่าเฉลี่ย) · กับดักการอ่าน: (2,2), (2,3) คือ "แถวที่ คอลัมน์ที่" ในตาราง ไม่ใช่เวลา — และแถว 1 คือคอลัมน์เลข 1 แถว 2 จึงคือปัจจัยที่ 1

ขั้น 3 — แก้ β = (XᵀX)⁻¹ Xᵀy (กลับเมทริกซ์ 4×4 ทำมือได้แต่ยาว ให้ numpy ทำ):

β₀ = 0.055% β₁ (ตลาด) = 1.230 β₂ (ขนาด) = 0.670 β₃ (มูลค่า) = 0.072 R² = 0.986 · SE = [0.246, 0.080, 0.179, 0.203] · t = [0.22, 15.4, 3.75, 0.35]

📖 อ่านสูตรว่า: β₁ = 1.230 อ่านว่า "ตลาดขึ้น 1% โดยที่ขนาดและมูลค่าไม่ขยับ หุ้นขึ้น 1.23%" — วงเล็บ "โดยที่…ไม่ขยับ" คือสิ่งที่ β ตัวเดียวใน 2.1 ไม่มี · t = 15.4 ของตลาดกับ t = 0.35 ของมูลค่าอ่านด้วยโครงเดียวกัน (ค่าประมาณ ÷ SE ของตัวเอง โดย SE คือความไม่แน่นอนของค่าประมาณนั้น — สอนเต็มใน เล่ม 2 · C §6.2): ปัจจัยมูลค่าใน 8 เดือนนี้แยกจากศูนย์ไม่ออก · กับดักการอ่าน: ตัวห้อย 0, 1, 2, 3 คือหมายเลขปัจจัย ไม่ใช่เวลา · R² 0.986 กับ n = 8 และ 4 พารามิเตอร์ สูงได้ง่ายเกินไป (2.3 จะเตือน)

❌ พังเมื่อไร — เติมปัจจัยที่เกือบซ้ำกับตัวเดิม แล้ว β ระเบิด (multicollinearity)

ลองเติมปัจจัยที่สี่ "growth" ที่นิยามให้เกือบเป็นด้านกลับของ "มูลค่า": x₄ = −x₃ บวกเสียงเล็ก ๆ ±0.1 → x₄ = [+1.1, −1.1, −2.0, −0.9, +1.9, +0.1, +1.0, −2.1] (ρ ระหว่าง x₃ กับ x₄ = −0.998) แล้วรัน regression ใหม่ด้วย y เดิม:

ก่อนเติม: β₃ (มูลค่า) = 0.072 SE = 0.20 หลังเติม: β₃ (มูลค่า) = 6.045 SE = 2.22 · β₄ (growth) = 5.765 SE = 2.14 β₁ (ตลาด) = 1.251 · β₂ (ขนาด) = 0.925 — ตัวอื่นก็เลื่อนตาม

📖 อ่านสูตรว่า: บรรทัดสองอ่านว่า "เบต้าสาม เท่ากับ หกจุดศูนย์สี่ห้า เอสอี สองจุดสองสอง" — ตัวเลขหลัง SE คือความไม่แน่นอนของค่าประมาณ ไม่ใช่ค่าที่สอง · สัมประสิทธิ์สองตัวที่ใหญ่พอกัน (6.0 กับ 5.8) บนปัจจัยที่เกือบตรงข้ามกัน หมายความว่าโมเดล "ลบกันเอง" — 6.045 × มูลค่า + 5.765 × growth = 0.28 × มูลค่า + 5.765 × (มูลค่า + growth) — พจน์แรกคือของจริงที่เหลือบนปัจจัยร่วม พจน์หลังคือสัมประสิทธิ์มหึมาที่ไปคูณกับความต่างเล็ก ๆ (±0.1%) ระหว่างสองปัจจัย นั่นคือเสียง · โครงที่ต้องเห็น: ใน (XᵀX)⁻¹ การกลับเมทริกซ์ที่มีสองคอลัมน์เกือบซ้ำกัน คือการ "หารด้วยเลขที่เกือบเป็นศูนย์" — SE จึงพองจาก 0.20 เป็น 2.2 (สิบเท่า) โดยที่ y และสามปัจจัยเดิมไม่ได้เปลี่ยนแม้แต่ตัวเดียว · นี่คือปัญหาที่ เล่ม 2 · C §6.6 ตั้งชื่อ และ เล่ม 2 · F §14.2 แก้ด้วย Ridge

✅ ใช้ได้เมื่อไร

  • จำนวนเดือน n มากกว่าจำนวนพารามิเตอร์หลายเท่า — n = 8 กับ 4 พารามิเตอร์คือตัวอย่างสอน ไม่ใช่ตัวอย่างใช้จริง
  • β นิ่งในหน้าต่างที่ใช้ — ถ้า β เลื่อน ดู เล่ม 2 · D §9.4
🔍 ศัพท์ที่คนสลับกันบ่อย — multiple ≠ multivariate

Multiple regression = y ตัวเดียว x หลายตัว — คือหัวข้อนี้ทั้งหัวข้อ · Multivariate regression = y หลายตัวพร้อมกัน (เช่น ΔA และ ΔB) บนตัวแปรทางขวาชุดเดียวกัน — คือ VAR/VECM ของ เล่ม 2 · D §9.5 · ข่าวดี: เมื่อ X ชุดเดียวกัน OLS ของ multivariate regression ก็คือ multiple regression ทีละสมการ β ที่ได้เท่ากันทุกตัว ไม่มีสูตรใหม่ต้องเรียน (§9.5 ใช้ข้อนี้ตรง ๆ: regress ΔB บน X แล้ว regress ΔA บน X เดิม) · สิ่งที่ multivariate เพิ่มคือยอมให้ residual ของสมการต่าง ๆ สัมพันธ์กัน ซึ่งสำคัญตอนทดสอบสมมติฐานข้ามสมการ ไม่ใช่ตอนหา β

ทฤษฎีจบตรงนี้ ที่เหลือคือให้คอมพิวเตอร์กลับเมทริกซ์แทนเรา:

🐍 Python — multiple regression ด้วย numpy (ข้อมูลเดียวกับที่คิดมือ)
import numpy as np

mkt  = np.array([ 3,-2, 5,-1, 2,-4, 1, 3]) / 100     # x₁ ตลาด
size = np.array([ 1, 2,-1, 0, 3,-2, 1,-1]) / 100     # x₂ ขนาด
val  = np.array([-1, 1, 2, 1,-2, 0,-1, 2]) / 100     # x₃ มูลค่า
stk  = np.array([4.6,-1.0,6.2,-0.6,4.1,-6.3,1.9,2.3]) / 100

X = np.column_stack([np.ones(8), mkt, size, val])     # คอลัมน์เลข 1 = ที่ยืนของ β₀
beta = np.linalg.solve(X.T @ X, X.T @ stk)            # ★ (XᵀX)⁻¹Xᵀy โดยไม่กลับเมทริกซ์ตรง ๆ
print("β =", beta.round(4))
# β = [0.0006 1.2295 0.6701 0.0715]   ← β₀ เป็นทศนิยม (0.055% = 0.00055)

pred = X @ beta
r2 = 1 - ((stk - pred)**2).sum() / ((stk - stk.mean())**2).sum()
print(f"R² = {r2:.4f}")                                # R² = 0.9862

# เทียบ: ตลาดอย่างเดียว
b1, a1 = np.polyfit(mkt, stk, 1)
print(f"β ตลาดอย่างเดียว = {b1:.4f}")                  # β ตลาดอย่างเดียว = 1.2692
✅ อ่านผลลัพธ์

β ตลาด 1.23 กับ β ขนาด 0.67 คือ hedge ratio สองตัว: ถือหุ้นนี้ ฿1M → short ดัชนีตลาด ฿1.23M และ short พอร์ตปัจจัยขนาด ฿0.67M (= short หุ้นเล็ก ฿0.67M พร้อม long หุ้นใหญ่ ฿0.67M เพราะปัจจัยนี้คือ "เล็กลบใหญ่") จึงจะนิ่งต่อทั้งสองปัจจัย · ถ้า hedge แค่ตลาด ฿1.27M ตามสูตร 2.1 พอร์ตจะยังเหลือความแปรปรวนที่อธิบายไม่ได้ราว 8.5% ของเดิม (1 − R² = 1 − 0.915) ซึ่งส่วนใหญ่คือปัจจัยขนาดบริษัท · np.linalg.solve คือวิธีที่ควรใช้จริง — การกลับเมทริกซ์ตรง ๆ ด้วย inv ขยายความคลาดเคลื่อนเมื่อคอลัมน์เกือบซ้ำกัน ซึ่งคือสถานการณ์ในกล่อง ❌ พอดี

🧠 มุมที่มองต่าง

มือใหม่เห็น: "ใส่ปัจจัยเพิ่มยิ่งดี R² ยิ่งสูง"
คนจัดพอร์ตเห็น: ทุกปัจจัยที่เติมคือหนึ่ง hedge ที่ต้องทำจริงและมีต้นทุน และถ้าปัจจัยใหม่เกือบซ้ำของเดิม สิ่งที่ได้ไม่ใช่ความรู้เพิ่ม แต่คือ β ที่พองและพลิกได้ทุกครั้งที่ข้อมูลเปลี่ยนนิดเดียว — จำนวนปัจจัยที่ใช้ได้จริงในทางปฏิบัติมักนับได้ด้วยนิ้วมือข้างเดียว

📍 ปัจจุบันใช้จริง · 📚 ต้นฉบับ

สมการเดียวกันนี้คือ Fama-French 3-factor model — ตลาด (Mkt−RF), ขนาด (SMB = Small Minus Big), มูลค่า (HML = High Minus Low book-to-market) — ซึ่ง ทฤษฎีของ Quant · Part 2 เล่าว่ามันมาแทน CAPM ได้อย่างไร · โต๊ะจัดพอร์ตใช้ regression แบบนี้สองทาง: (1) วัดว่าพอร์ตแบกความเสี่ยงปัจจัยไหนอยู่โดยไม่รู้ตัว (2) hedge ปัจจัยที่ไม่ต้องการออกด้วย ETF หรือ futures ที่ใกล้ปัจจัยนั้นที่สุด · ในงานจริงปัจจัยมีหลายสิบตัวและใช้ Ridge ของ เล่ม 2 · F §14.2 กดปัญหาในกล่อง ❌

📚 Fama, E. & French, K. (1993) "Common risk factors in the returns on stocks and bonds" — นิยาม SMB, HML และแสดงว่าสามปัจจัยอธิบายผลตอบแทนหุ้นได้ดีกว่า β ตัวเดียว

🎯 3 อย่างที่ต้องจำ

2.3 R² และ Overfitting

🚶 อ่านเป็นภาษาคนก่อน: R² บอกว่า "โมเดลอธิบาย variance ของข้อมูลได้กี่ %" (0–1) · แต่ R² สูงเกินไปจากโมเดลซับซ้อน = สัญญาณอันตราย overfitting
