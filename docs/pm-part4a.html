PM Payoff Atlas — "ทุกรูปร่างของ Prediction Market"

Prediction Market (PM) คือ digital option — จ่ายเต็มจำนวนหรือไม่จ่ายเลย ($0 หรือ $1)
ต่างจาก Options ที่จ่ายแบบ linear (ยิ่งราคาห่าง strike ยิ่งได้มาก)

กฎสำคัญ: Binary ≠ Linear

PM จ่าย $1 หรือ $0 เสมอ — ไม่ว่าราคาจะเลย threshold ไป ฿1 หรือ ฿1,000
Options จ่าย ตามระยะห่าง จาก strike → ยิ่งห่าง ยิ่งได้
ห้ามใช้แทนกัน โดยไม่เข้าใจความต่างนี้!

1. PM Above Yes — "ราคาจะเกิน K ไหม?"

Payoff = $1 ถ้า S > K ณ วัน resolve, $0 ถ้า S ≤ K
Options equivalent: Digital Call ≈ tight Bull Call Spread(K, K+ε) ÷ ε

📖 อ่านสูตรว่า: "Payoff เท่ากับ หนึ่งดอลลาร์ ถ้า S มากกว่า K · ศูนย์ ถ้าไม่" — ฟังก์ชันสองค่าที่กระโดดตรง K · โครงที่ต้องเห็น: ต่างจาก max(S − K, 0) ที่จ่ายตามระยะห่าง — ตัวนี้จ่ายเท่าเดิมไม่ว่าจะเกินไป 1 หรือ 1,000 · บรรทัดสองอ่านไว้แล้วใน Part IV บท 15: ÷ ε ทำให้สเปรดแคบจ่ายสูงสุด 1 พอดี · กับดักการอ่าน: "S ≤ K" รวมกรณีเท่ากันไว้ฝั่ง $0 — จบตรง K พอดีคือ No

2. PM Above No — "ราคาจะไม่เกิน K"

Payoff = $1 ถ้า S ≤ K, $0 ถ้า S > K
= กลับด้านของ Above Yes
Options equivalent: Digital Put

สำคัญ: Above No เป็น BINARY ไม่ใช่ Linear!
Above No ≠ Long Put → Long Put จ่ายมากขึ้นเมื่อราคาลงแรง แต่ PM No จ่ายเท่าเดิม ($1)
ข้อผิดพลาดที่พบบ่อย

Wrong: "PM No ราคาแค่ 20¢ ถูกกว่า Put → ใช้ PM No hedge downside"
Right: PM No เป็น binary ($0/$1) แต่ loss จาก spot/options เป็น linear
→ PM ใช้เป็น boundary repair หรือ income layer ได้ แต่ ไม่ใช่ hedge ของ linear exposure

3. PM Range Yes — "ราคาจะอยู่ในช่วง L-U ไหม?"

Payoff = $1 ถ้า L ≤ S ≤ U, $0 ถ้า S < L หรือ S > U
= Long Digital Call(L) + Short Digital Call(U)
≈ tight Bull Call Spread(L) + tight Bear Call Spread(U)

สำคัญ: Range Yes = สี่เหลี่ยม (flat $1) ≠ Butterfly = สามเหลี่ยม (peak ตรงกลาง)

📖 อ่านสูตรว่า: "Payoff เท่ากับ หนึ่งดอลลาร์ ถ้า L น้อยกว่าหรือเท่ากับ S น้อยกว่าหรือเท่ากับ U" — เงื่อนไขซ้อน L ≤ S ≤ U อ่านว่า "S อยู่ระหว่าง L กับ U" · โครงที่ต้องเห็น: payoff = ผลรวมของขา: Digital Call(L) จ่าย 1 เมื่อ S > L และ Short Digital Call(U) จ่าย −1 เมื่อ S > U · ลอง S ระหว่าง L กับ U → 1 − 0 = 1 ✓ · S > U → 1 − 1 = 0 ✓ · S < L → 0 − 0 = 0 ✓ · ≈ บรรทัดสามใช้สมมติฐานเดียวกับข้อ 1: สเปรดต้องแคบมากจึงใกล้บันไดดิ่ง · กับดักการอ่าน: ที่ขอบ S = L พอดี Digital Call(L) ตามนิยามข้อ 1 ยังจ่าย 0 แต่ Range Yes จ่าย 1 — บรรทัดสองตรงกันทุกจุดยกเว้นจุดเดียวนี้ ต้องดูกฎ resolve ของตลาดจริง

4. PM Range No — "ราคาจะอยู่นอกช่วง L-U"

Payoff = $1 ถ้า S < L หรือ S > U, $0 ถ้า L ≤ S ≤ U
= complement ของ Range Yes
= "เดิมพันว่าราคาจะผันผวน" (คล้าย Strangle แต่เป็น binary)

5. PM Parity: Yes + No = $1 เสมอ

นี่คือ Put-Call Parity ของ Prediction Market

Above Yes(K) + Above No(K) = $1 ทุกค่าของ S
Range Yes(L,U) + Range No(L,U) = $1 ทุกค่าของ S

ถ้า Ask(Yes) + Ask(No) < $1 → Instant Arbitrage!
ถ้า Ask(Yes) + Ask(No) > $1 → ส่วนต่าง = market maker margin

📖 อ่านสูตรว่า: "เยส บวก โน เท่ากับ หนึ่งดอลลาร์ ทุกค่าของ S" · โครงที่ต้องเห็น: เอกลักษณ์ (identity) — สองขาที่รวมกันแล้วตัวแปรสุ่ม S หายไป เหลือค่าคงที่ เหมือน Conversion ใน Part I บท 4 ที่ S + P − C = PV(K) · ลอง S > K: 1 + 0 = 1 · S ≤ K: 0 + 1 = 1 · กับดักการอ่าน: บรรทัดที่เทียบ Ask(Yes) + Ask(No) กับ $1 คือเรื่องราคาที่ซื้อได้จริง ไม่ใช่ payoff — เอกลักษณ์รับประกันว่า payoff รวมเป็น 1 แน่ ถ้าซื้อได้ต่ำกว่า 1 จึงล็อกกำไร

6. Multi-Bracket PM — "ปูกระเบื้อง probability"

ซื้อ Range Yes ในทุกช่วงที่ครอบคลุม:
Range Yes(0-80) + Range Yes(80-90) + Range Yes(90-100) + Range Yes(100-110) + Range Yes(110+)
= ผลรวม $1 เสมอ (Generalized Parity)

เหมือน: "ปูกระเบื้องราคา" — ทุกช่วงครอบคลุม ไม่มีช่องว่าง
= complete set of digital call spreads

7. PM Staircase — "สร้าง Linear จาก Binary"

ซื้อ Above Yes ที่หลาย strikes ห่างกัน $d → ได้ บันไดขั้น ที่ประมาณ linear payoff

ซื้อ Above Yes ที่ K=90, 95, 100, 105, 110 (ห่างกัน $5)
แต่ละอันจ่าย $1 → รวมกัน:
S < 90: payoff = $0 (ไม่มีอันไหน trigger)
90 < S < 95: payoff = $1 (แค่ Yes(90) trigger)
95 < S < 100: payoff = $2
100 < S < 105: payoff = $3
105 < S < 110: payoff = $4
S > 110: payoff = $5

= บันไดที่ประมาณ slope = 1/5 = $0.20 ต่อ $1 ที่ราคาขึ้น
ยิ่ง $d เล็ก → ยิ่งเหมือน linear → PM equivalent ของ Synthetic Forward!

📖 อ่านสูตรว่า: "S มากกว่า 110 payoff เท่ากับ ห้าดอลลาร์" — แต่ละบรรทัดคือช่วงราคา และค่าคือจำนวนสัญญาที่ถูก trigger แล้ว × $1 (ตรง 110 พอดี Yes(110) ยังไม่จ่าย ได้แค่ $4 ตามกฎข้อ 1) · โครงที่ต้องเห็น: ผลรวมของบันไดขั้นเดียวหลายอัน = บันไดใหญ่ · ความชันเฉลี่ย = $1 ต่อ $5 ที่ราคาขึ้น = 1/5 = 0.20 — ตัวเศษคือเงินที่เพิ่มต่อขั้น ตัวส่วนคือระยะห่างสไตรก์ d · กับดักการอ่าน: "ประมาณ linear" มีสมมติฐาน: ต้อง d → 0 บันไดจึงกลายเป็นเส้นตรง ที่ d = 5 มันยังเป็นบันได — ระหว่างขั้น payoff ไม่ขยับเลย

8. Touch vs Close

คุณสมบัติTouch MarketClose Market
Resolutionราคาแตะ K ครั้งเดียวก็ resolveราคา ณ วันหมดอายุเท่านั้น
Path dependencyใช่ — ขึ้นกับ path ระหว่างทางไม่ — ดูแค่จุดสุดท้าย
ProbabilityP(touch) ≥ P(close) เสมอP(close) ≤ P(touch)
ราคา Yesแพงกว่า (probability สูงกว่า)ถูกกว่า
Options equivalentOne-Touch Option (exotic)Digital Option (European)
ใช้เมื่อเชื่อว่าราคาจะแตะ K ระหว่างทางเชื่อว่าราคาจะจบเหนือ K
ระวัง: Touch ≠ Close → ราคาต่างกัน

PM "BTC touch $100K" ราคา $0.75 แต่ PM "BTC close above $100K" ราคา $0.55
Gap $0.20 ไม่ใช่ arb — เป็น resolution premium ที่สะท้อน path vs point probability
