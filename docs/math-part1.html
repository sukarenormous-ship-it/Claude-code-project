บทที่ 1: เครื่องมือพื้นฐาน — "ภาษาที่ใช้พูดเรื่อง Options"

ก่อนจะเข้าใจ Options (ออปชัน) ได้ คุณต้องอ่าน "ภาษา" ที่ใช้พูดเรื่อง Options ให้ออกก่อน บทนี้จะสอนเครื่องมือคณิตศาสตร์พื้นฐานที่ปรากฏในทุกสูตรของ Options

1.1 เปอร์เซ็นต์และอัตราส่วน

เปอร์เซ็นต์การเปลี่ยนแปลง (% Change) คือเครื่องมือที่ใช้บ่อยที่สุดในการเงิน:

% Change = (ค่าใหม่ - ค่าเก่า) / ค่าเก่า × 100

ตัวอย่าง: หุ้นจาก ฿100 → ฿120 → % Change = (120-100)/100 × 100 = +20%

ข้อผิดพลาดที่พบบ่อยที่สุด

"ตก 50% แล้วขึ้น 50% = กลับที่เดิม" ← ผิด!
หุ้น ฿100 ตก 50% = ฿50 แล้วขึ้น 50% = ฿50 × 1.5 = ฿75 ไม่ใช่ ฿100!
ต้องขึ้น 100% จาก ฿50 ถึงจะกลับมา ฿100

ราคาลดลงต้องขึ้นกลับตัวอย่าง (เริ่ม ฿100)
-10%+11.1%฿90 → ต้องขึ้น ฿10/฿90 = 11.1%
-25%+33.3%฿75 → ต้องขึ้น ฿25/฿75 = 33.3%
-50%+100%฿50 → ต้องขึ้น ฿50/฿50 = 100%
-75%+300%฿25 → ต้องขึ้น ฿75/฿25 = 300%
-90%+900%฿10 → ต้องขึ้น ฿90/฿10 = 900%
เชื่อมกับ Options

ความไม่สมมาตรนี้คือเหตุผลที่ Options ใช้ log return (ผลตอบแทนเชิงลอการิทึม) แทน simple return (ผลตอบแทนเชิงเส้น) — log return สมมาตร: ขึ้น 10% แล้วลง 10% (log) กลับที่เดิมพอดี จะเรียนละเอียดในบท 3.6

Risk/Reward Ratio: ในการเทรด Options เราวัดว่า "เสี่ยงเท่าไหร่เพื่อได้เท่าไหร่" เช่น Max Loss = ฿5, Max Profit = ฿15 → Risk/Reward = 1:3 หมายความว่าทุก ฿1 ที่เสี่ยง อาจได้ ฿3 กลับมา

1.2 ฟังก์ชันและกราฟ

Function (ฟังก์ชัน) คือ "กล่องดำ" ที่รับค่าเข้า (input) แล้วให้ค่าออก (output) เขียนว่า f(x) อ่านว่า "f ของ x"

เปรียบเทียบ: เครื่องทำกาแฟ

ใส่เมล็ดกาแฟ (input = x) → เครื่องบด (function = f) → ได้กาแฟ (output = f(x))
ใส่เมล็ดต่างกัน ได้กาแฟรสต่างกัน แต่ เมล็ดเดียวกันได้รสเดียวกันเสมอ — นี่คือหลักการของฟังก์ชัน

พิกัด (x, y): ทุกจุดบนกราฟมีตำแหน่ง — x คือตำแหน่งแนวนอน, y คือตำแหน่งแนวตั้ง

ตัวอย่าง: f(x) = 2x - 100

x (input)f(x) = 2x - 100 (output)จุดบนกราฟ
02(0) - 100 = -100(0, -100)
502(50) - 100 = 0(50, 0) ← ตัดแกน x!
1002(100) - 100 = 100(100, 100)
เชื่อมกับ Options

Payoff(S) = max(0, S - K) - Premium (Payoff = ผลตอบแทน ณ วันหมดอายุ, Premium = ค่าพรีเมียม) คือฟังก์ชันที่รับ "ราคาหุ้น S" แล้วคืน "กำไร/ขาดทุน" — ทุก Payoff Chart คือกราฟของฟังก์ชันนี้!

1.3 เส้นตรงและความชัน (Slope)

สมการเส้นตรง: y = mx + b โดย m = ความชัน (Slope), b = จุดตัดแกน y (y-intercept)

Slope = Δy / Δx = (y₂ - y₁) / (x₂ - x₁) = "ขึ้นเท่าไหร่ ต่อเดินไปเท่าไหร่"
Slopeความหมายใน Options
m = +1ขึ้น ฿1 ต่อทุก ฿1 ที่เพิ่มLong Call หลัง Strike
m = -1ลง ฿1 ต่อทุก ฿1 ที่เพิ่มShort Call หลัง Strike
m = 0แบนราบ ไม่เปลี่ยนPayoff ก่อน Strike (flat zone)
m = +0.5ขึ้น ฿0.50 ต่อ ฿1Delta ≈ 0.5 (ATM option)
เชื่อมกับ Options

Payoff ของ Long Call (สถานะซื้อสิทธิ์ซื้อ) หลัง Strike (ราคาใช้สิทธิ์) มี slope = +1 (กำไรเพิ่ม ฿1 ต่อราคาที่ขึ้น ฿1)
Short Call (สถานะขายสิทธิ์ซื้อ) มี slope = -1 (ขาดทุนเพิ่ม ฿1 ต่อราคาที่ขึ้น ฿1)
Delta (เดลตา ความไวต่อราคาสินทรัพย์อ้างอิง) ของ Option ก็คือ slope ของ payoff curve — จะเรียนในบท 7

1.4 ฟังก์ชัน max() และ min()

max(a, b) = เลือกค่าที่มากกว่า เช่น max(3, 7) = 7, max(-5, 2) = 2

max(0, x) มีความหมายพิเศษมาก = "ถ้า x เป็นลบ ให้เป็น 0 แทน"

xmax(0, x)อธิบาย
-200x เป็นลบ → ตัดเป็น 0
-50x เป็นลบ → ตัดเป็น 0
00จุดหักศอก!
+1010x เป็นบวก → ใช้ค่า x
+2525x เป็นบวก → ใช้ค่า x
เชื่อมกับ Options

max(0, S - K) = Intrinsic Value (มูลค่าที่แท้จริง) ของ Call Option
ถ้า S < K → Option หมดค่า = 0 (ไม่ใช้สิทธิ์)
ถ้า S > K → Option มีค่า = S - K (ใช้สิทธิ์ซื้อที่ K ขายที่ S)
นี่คือที่มาของกราฟ "หักศอก" ใน Payoff Chart!

1.5 ค่าสัมบูรณ์และการกลับเครื่องหมาย

ค่าสัมบูรณ์ |x| = ระยะห่างจาก 0 เช่น |5| = 5, |-5| = 5 กราฟเป็นรูป V

หลักการกลับเครื่องหมาย: ถ้า f(x) เป็นกราฟหนึ่ง แล้ว -f(x) คือกราฟเดียวกันพลิกกลับหัวผ่านเส้นศูนย์

เชื่อมกับ Options

Short position (สถานะขาย) = -1 × Long position (สถานะซื้อ) ทุกจุด ไม่ต้องจำรูปร่างใหม่! แค่พลิกกราฟ
Long Call (กำไรไม่จำกัด ขาดทุนจำกัด) → พลิก → Short Call (กำไรจำกัด ขาดทุนไม่จำกัด)

1.6 Piecewise Functions — ฟังก์ชันแบ่งช่วง

Piecewise Function (ฟังก์ชันแบ่งช่วง) = ฟังก์ชันที่ใช้สูตรต่างกันในแต่ละช่วงของ x

ตัวอย่าง: Bull Call Spread (สเปรดซื้อแบบกระทิง) (K₁ = 90, K₂ = 110, Net Premium = 5)

Payoff = {
  -5                   ถ้า S < 90
  S - 90 - 5           ถ้า 90 ≤ S ≤ 110
  110 - 90 - 5 = 15    ถ้า S > 110
}
เชื่อมกับ Options

ทุกกลยุทธ์ Options เป็น piecewise linear function!
Long Call = 2 ช่วง | Spread (สเปรด) = 3 ช่วง | Iron Condor (ไอรอนคอนดอร์) = 5 ช่วง | Butterfly (บัตเตอร์ฟลาย) = 5 ช่วง
ถ้าเข้าใจ piecewise function = เข้าใจ payoff chart ของทุกกลยุทธ์

ตารางสัญลักษณ์ที่จะเจอตลอดทั้งเล่ม:

สัญลักษณ์ชื่อความหมายตัวอย่างใน Options

สรุปบทที่ 1

ตอนนี้คุณ:

บทที่ 2: พีชคณิตและสมการ — "จัดรูป Put-Call Parity ได้เอง"

Put-Call Parity (ความเท่าเทียมระหว่างพุตและคอล) คือสมการที่สำคัญที่สุดในโลก Options — ถ้าคุณจัดรูปสมการได้ คุณจะ "สร้าง" Synthetic Positions (สถานะสังเคราะห์) ได้ทุกตำแหน่ง บทนี้สอนพีชคณิตที่จำเป็นสำหรับเรื่องนั้น

2.1 สมการเชิงเส้น 1 ตัวแปร

หลักการ: ทำอะไรกับข้างหนึ่ง ต้องทำเหมือนกันกับอีกข้าง

ตัวอย่าง: หา Break-even ของ Long Call
Payoff = 0 เมื่อไหร่?
0 = S - K - P
S = K + P     ← ย้าย K และ P ไปอีกข้าง

ถ้า K = 100, P = 5 → Break-even = 100 + 5 = 105
ฝึกทำ: หา Break-even (จุดคุ้มทุน) ของ Long Put (สถานะซื้อสิทธิ์ขาย)

Payoff = max(0, K - S) - P
ที่ break-even: K - S - P = 0 → S = K - P
ถ้า K = 100, P = 3 → Break-even = 100 - 3 = 97

2.2 การจัดรูปสมการ — Put-Call Parity

สมการ Put-Call Parity:

C + PV(K) = P + S

เมื่อ C = ราคา Call (สิทธิ์ซื้อ), P = ราคา Put (สิทธิ์ขาย), S = ราคาหุ้น, PV(K) = Present Value (มูลค่าปัจจุบัน) ของ Strike

จากสมการเดียว เราสามารถจัดรูปใหม่เพื่อหาทุกตัวแปร:

ต้องการหาจัดรูปสมการความหมาย
SS = C - P + PV(K)Synthetic Long Stock = Long Call + Short Put + Bond
CC = P + S - PV(K)Synthetic Long Call = Long Put + Long Stock - Bond
PP = C - S + PV(K)Synthetic Long Put = Long Call + Short Stock + Bond
PV(K)PV(K) = P + S - CSynthetic Bond = Long Put + Long Stock + Short Call
เชื่อมกับ Options

ทุก Synthetic Position มาจากการ "ย้ายข้าง" สมการ Put-Call Parity!
ไม่ต้องจำว่า Synthetic Stock ประกอบจากอะไร — แค่จัดรูปสมการก็ได้คำตอบ
นี่คือพลังของพีชคณิตใน Options

2.3 ระบบสมการเชิงเส้น

บางครั้งต้องแก้หลายสมการพร้อมกัน:

ตัวอย่าง: Zero-Cost Collar (คอลลาร์ต้นทุนศูนย์)

ต้องการหาว่าควรขาย Call ที่ Premium เท่าไหร่ เพื่อให้ค่า Collar = 0
สมการ: Premium(Put ที่ซื้อ) = Premium(Call ที่ขาย)
ถ้า Put K₁=95 มี Premium = 3 → ต้องหา Call ที่ Premium = 3 เช่นกัน → ค้นหา Strike ที่ให้ Premium = 3

วิธี Substitution: แก้ตัวแปรหนึ่งจากสมการแรก แล้วแทนเข้าสมการที่สอง

สมการที่ 1: x + y = 10
สมการที่ 2: 2x - y = 5

จาก (1): y = 10 - x
แทนใน (2): 2x - (10 - x) = 5 → 3x = 15 → x = 5
แทนกลับ: y = 10 - 5 = 5
คำตอบ: (x, y) = (5, 5)

2.4 อสมการ (Inequalities)

อสมการ ใช้สัญลักษณ์ <, >, ≤, ≥ แทนที่จะเป็น =

กฎสำคัญ: คูณหรือหารด้วยจำนวนลบ → ต้องกลับทิศเครื่องหมาย!

ถ้า -2x > 6 → หารทั้งสองข้างด้วย -2 → x < -3 (เครื่องหมายกลับ!)

เชื่อมกับ Options

American Put-Call Parity เป็นอสมการ ไม่ใช่สมการ:
S - K ≤ C - P ≤ S - K·e-rT
เพราะ American Options (ออปชันแบบอเมริกัน ใช้สิทธิ์ได้ทุกวันก่อนหมดอายุ) สามารถใช้สิทธิ์ก่อนหมดอายุได้ → early exercise (การใช้สิทธิ์ก่อนกำหนด) value ทำให้ความเท่ากันพอดี (equality) กลายเป็นช่วง (inequality)

สรุปบทที่ 2

ตอนนี้คุณ:
✓ แก้สมการหา Break-even ได้
✓ จัดรูป Put-Call Parity ได้ → หา Synthetic Position ทุกแบบ
✓ แก้ระบบสมการเพื่อหาค่าที่เหมาะสม
✓ เข้าใจอสมการ (American Options inequality)

→ พร้อมอ่านบทเรียน Put-Call Parity และ Synthetic Positions แล้ว!

บทที่ 3: เลขยกกำลัง ลอการิทึม ดอกเบี้ย — "เข้าใจ PV(K)"

ทำไมต้องเรียนเรื่องนี้? เพราะใน Put-Call Parity มีตัว PV(K) = K × e-rT — ถ้าไม่เข้าใจ e, ln, ดอกเบี้ยทบต้น ก็อ่าน PV(K) ไม่ออก

3.1 เลขยกกำลัง (Exponents)

an = คูณ a ด้วยตัวเอง n ครั้ง เช่น 23 = 2×2×2 = 8

กฎสูตรตัวอย่าง
คูณฐานเดียวกันam × an = am+n23 × 24 = 27 = 128
หารฐานเดียวกันam / an = am-n25 / 22 = 23 = 8
ยกกำลังซ้อน(am)n = amn(23)2 = 26 = 64
ยกกำลัง 0a0 = 150 = 1, 1000 = 1
ยกกำลังลบa-n = 1/an2-3 = 1/8 = 0.125
เชื่อมกับ Options

(1+r)n คือสูตรดอกเบี้ยทบต้น — ฐานของ PV(K) ที่จะเรียนต่อไป

3.2 Geometric Series (อนุกรมเรขาคณิต)

Geometric Series: a + ar + ar2 + ar3 + ... + arn-1

ผลรวม = a × (1 - rn) / (1 - r)    เมื่อ r ≠ 1

ตัวอย่าง: ฝากเงินปีละ 1,000 บาท ดอกเบี้ย 5% ทบต้น 5 ปี

ปีฝากมูลค่ารวมปลายปี
11,0001,000 × 1.05 = 1,050
21,000(1,050 + 1,000) × 1.05 = 2,153
31,000(2,153 + 1,000) × 1.05 = 3,310
41,000(3,310 + 1,000) × 1.05 = 4,526
51,000(4,526 + 1,000) × 1.05 = 5,802

ฝากรวม 5,000 แต่ได้ 5,802 — ส่วนเกิน 802 คือ "ดอกเบี้ยทบต้น" ที่ดอกเบี้ยออกดอกเบี้ย!

3.3 ดอกเบี้ยเชิงเดี่ยว vs ทบต้น

Simple Interest (ดอกเบี้ยเชิงเดี่ยว): ดอกเบี้ยคิดจากเงินต้นเท่านั้น

FV = PV × (1 + r × t)

Compound Interest (ดอกเบี้ยทบต้น): ดอกเบี้ยคิดจากเงินต้น + ดอกเบี้ยสะสม

ทบต้นรายปี:    FV = PV × (1 + r)n
ทบต้นรายเดือน: FV = PV × (1 + r/12)12n
ทบต้นรายวัน:   FV = PV × (1 + r/365)365n

เปรียบเทียบ: ฝาก 10,000 บาท ดอกเบี้ย 10% ต่อปี เป็นเวลา 10 ปี

วิธีคิดดอกเบี้ยสูตรผลลัพธ์กำไร
เชิงเดี่ยว10,000(1 + 0.1×10)20,000+10,000
ทบต้นรายปี10,000(1.1)1025,937+15,937
ทบต้นรายเดือน10,000(1+0.1/12)12027,070+17,070
ทบต้นรายวัน10,000(1+0.1/365)365027,179+17,179
Continuous10,000 × e0.1×1027,183+17,183
สังเกต

ยิ่งทบต้นถี่ขึ้น (ปี → เดือน → วัน) ค่ายิ่งเพิ่มขึ้น แต่เพิ่มน้อยลงเรื่อยๆ จนเข้าใกล้ค่าหนึ่ง — ค่านั้นคือ Continuous Compounding (การทบต้นต่อเนื่อง) = ert

3.4 จำนวน e และ Continuous Compounding

จำนวน e ไม่ได้เป็นตัวเลขลอยๆ — มันมาจากดอกเบี้ยทบต้น!

ถ้าทบต้น n ครั้งต่อปี ดอกเบี้ย 100%: FV = 1 × (1 + 1/n)n
เมื่อ n → ∞ ค่านี้เข้าใกล้ e = 2.71828...

Continuous Compounding:

FV = PV × erT    (ค่าอนาคต)
PV = FV × e-rT   (ค่าปัจจุบัน = "discount")
เชื่อมกับ Options — PV(K) ใน Put-Call Parity!

PV(K) = K × e-rT

ตัวอย่าง: Strike K = 100, อัตราดอกเบี้ย r = 5%, เวลา T = 1 ปี
PV(K) = 100 × e-0.05×1 = 100 × 0.9512 = 95.12

หมายความว่า: ถ้ามีเงิน 95.12 บาทวันนี้ ฝากดอกเบี้ย 5% ต่อปี → วันหมดอายุจะมี 100 บาทพอดี
ตอนนี้คุณอ่าน PV(K) ใน Put-Call Parity ออกแล้ว!

3.5 Logarithm (ลอการิทึม)

ln(x) คือ "ฟังก์ชันย้อนกลับ" ของ ex — ถ้า ey = x แล้ว y = ln(x)

ค่า xln(x)ตรวจสอบ: eln(x) = x
10e0 = 1 ✓
e ≈ 2.7181e1 = e ✓
e2 ≈ 7.3892e2 ✓
102.303e2.303 ≈ 10 ✓
1004.605e4.605 ≈ 100 ✓

กฎสำคัญของ ln:

ln(a × b) = ln(a) + ln(b)   ← คูณกลายเป็นบวก!
ln(a / b) = ln(a) - ln(b)   ← หารกลายเป็นลบ!
ln(an) = n × ln(a)       ← ยกกำลังกลายเป็นคูณ!
กฎ ln ที่สำคัญที่สุดสำหรับ Finance

ln(a/b) = ln(a) - ln(b) ← นี่คือที่มาของ log return!
log return = ln(S₁/S₀) = ln(S₁) - ln(S₀)

3.6 Simple Return vs Log Return

นี่คือเรื่องที่สำคัญมากสำหรับ Options เพราะ Black-Scholes (แบบจำลองแบล็ก-โชลส์) ใช้ log return

Simple Return: R = (S₁ - S₀) / S₀ = S₁/S₀ - 1
Log Return:    r = ln(S₁ / S₀) = ln(S₁) - ln(S₀)
การเคลื่อนไหวSimple ReturnLog Returnต่าง
฿100 → ฿110+10.00%+9.53%ใกล้เคียง
฿100 → ฿150+50.00%+40.55%เริ่มต่าง
฿100 → ฿200+100.00%+69.31%ต่างมาก
฿100 → ฿90-10.00%-10.54%ใกล้เคียง
฿100 → ฿50-50.00%-69.31%สมมาตรกับ +100%!

ทำไม Log Return ดีกว่า? 3 เหตุผล:

เหตุผลที่ 1: บวกกันข้ามเวลาได้

Simple return: ฿100 → ฿110 (+10%) → ฿99 (-10%) ≠ 0% (ได้ -1%!)
Log return: ln(110/100) + ln(99/110) = ln(99/100) = -1.005% ← บวกกันได้ถูกต้อง!
r(0→2) = r(0→1) + r(1→2) ← Simple return ทำแบบนี้ไม่ได้

เหตุผลที่ 2: สมมาตร

ขึ้น 50% (simple) แล้วลง 50% ≠ กลับที่เดิม (ได้ ฿75)
ขึ้น 40.55% (log) แล้วลง 40.55% (log) = กลับที่เดิมพอดี!
สังเกต: log return ของ +100% = +69.31% = เท่ากับ |log return ของ -50%| = 69.31%

เหตุผลที่ 3: เป็น Normal Distribution ได้

Simple return มีขอบล่างที่ -100% (ราคาไม่ติดลบ) → ไม่สมมาตร → ไม่เป็น Normal
Log return อยู่ในช่วง (-∞, +∞) → สมมาตร → เป็น Normal Distribution (การแจกแจงปกติ) ได้!
→ ถ้า log return ~ Normal แล้ว ราคาหุ้น ~ Lognormal (การแจกแจงล็อกนอร์มัล) (จะเรียนในบท 6)

• การจัดรูปสมการ → Synthetic Positions (บทที่ 2)
