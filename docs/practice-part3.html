3.1 Thesis — pair คือกรณีพิเศษ (rank-1)

🚶 อ่านเป็นภาษาคนก่อน — อุปมา "น้ำขึ้นน้ำลง"

นึกถึงเรือหลายลำจอดในอ่าว · น้ำขึ้น เรือลอยสูงหมดทุกลำ · น้ำลง เรือต่ำหมด — "น้ำ" คือ common factor (ตลาด/sector) ที่ทำให้ทุกลำขยับพร้อมกัน

สิ่งที่คุณอยากเดิมพันจริง ๆ ไม่ใช่ "น้ำขึ้นหรือลง" (นั่นคือความเสี่ยงตลาดที่เราไม่อยากถือ) — แต่คือ "เรือลำไหนลอยสูง/ต่ำกว่าที่ตัวเรือมันควรจะเป็น หลังหักระดับน้ำออกแล้ว" · ส่วนที่เหลือหลังหักน้ำ = residual = สิ่งที่เทรดได้จริง

Part I–II สอนโลก "ทีละคู่" — แต่ทำไมหุ้น 2 ตัวถึงเดินด้วยกัน? ไม่ใช่เวทมนตร์เฉพาะคู่ แต่เพราะมันลอยตามน้ำเดียวกัน (โหลด factor เดียวกัน)

แนวคิดแกน

ผลตอบแทนหุ้นแต่ละตัว = ส่วนที่มาจาก common factor (ระดับน้ำที่ทุกตัวแชร์) + ส่วน idiosyncratic (เฉพาะเรือลำนั้น)

r_i = β_i1·F_1 + β_i2·F_2 + ... + ε_i
└──── common factor (น้ำ) ────┘ └ residual (เฉพาะตัว) ┘

"spread" ที่เทรดได้จริง = ε_i — ส่วนที่ factor อธิบายไม่ได้

เมื่อคุณจับคู่ A กับ B แล้ว long-short — จริง ๆ คุณกำลังสร้าง portfolio ที่หักน้ำออกด้วยมือ โดยใช้เรือแค่ 2 ลำ · PCA / eigenportfolio (Avellaneda-Lee 2010) ทำสิ่งเดียวกันแต่หักน้ำจากเรือทั้งอ่าวพร้อมกัน อย่างเป็นระบบ

"Pair trading คือ portfolio หักน้ำที่มีแค่ 2 ลำ — ทำไมต้องหยุดที่ 2?"

🔖 ทบทวนพื้นฐาน — 3 คำที่ต้องรู้จักก่อนไปต่อ

Part นี้มีศัพท์ใหม่แน่นพอ ๆ กับ Part I — สรุปสั้น ๆ ไว้ก่อน ถ้างงระหว่างอ่านกลับมาที่นี่ได้เสมอ

Common factor ("น้ำ")

ปัจจัยร่วมที่ทำให้หุ้นหลายตัวขยับไปด้วยกัน (ตลาดโดยรวม, sector, style) — ไม่ใช่ความสัมพันธ์เฉพาะคู่ แต่เป็นสิ่งที่หุ้นทุกตัวในกลุ่มแชร์ร่วมกัน เหมือนระดับน้ำที่ยกเรือทุกลำพร้อมกัน

Residual (ส่วนเฉพาะตัว)

ส่วนของผลตอบแทนที่เหลือหลังหักน้ำออกแล้ว — คือสิ่งที่ทำให้หุ้นตัวนี้ต่างจากเพื่อนในกลุ่มเดียวกัน · นี่คือสิ่งที่เราจะเทรดจริง ๆ (แทนที่จะเทรด "spread ของคู่")

s-score

residual ที่ถูกแปลงให้อยู่ในหน่วยมาตรฐานเดียวกัน (กี่ SD ห่างจากปกติ) — ทำให้เทียบหุ้นนับร้อยตัวบนมาตรวัดเดียวกันได้ทันที แทนที่จะต้องเลือกทีละคู่

✍️ เช็คความเข้าใจ
  1. "น้ำ" กับ residual ต่างกันตรงไหน? (น้ำ = ส่วนร่วมที่ทุกตัวแชร์ · residual = ส่วนที่เหลือเฉพาะตัวหลังหักน้ำ)
  2. ทำไม s-score ถึงทำให้ "ไม่ต้องเลือกคู่" ได้? (เพราะมันเทียบทุกหุ้นบนมาตรวัดเดียวกัน ให้คะแนนได้ทั้ง universe พร้อมกัน ไม่ต้องจับคู่ทีละคู่)

3.2 หัก common factor — 3 วิธี (ง่าย → ซับซ้อน)

วิธี 1 — Sector/Market ETF hedge รายย่อยทำได้วันนี้

🚶 ทำยังไง (ง่ายสุด)

regress หุ้นบน ETF ของ sector มัน (หรือ SET50/ตลาด) → "น้ำ" คือ ETF · residual ที่เหลือคือส่วนเฉพาะตัวหุ้น → เทรด mean-reversion ของ residual นั้น · ต้องการแค่ 1 regression

r_หุ้น = α + β × r_ETF + ε → เทรด mean-reversion ของ ε

ในตลาดที่ factor structure ยัง under-modeled (ไทย/SEA) แค่หัก sector ETF ก็อาจพอ ← จุดที่รายย่อยได้เปรียบ (Part 0 ชั้น D)

วิธี 2 — Statistical factors via PCA

ให้ข้อมูลหา "น้ำ" เอง — PCA บนผลตอบแทนทั้ง universe → ทิศที่ทุกตัวขยับพร้อมกันมากสุด = "ตลาด" + "sector" โดยไม่ต้องตั้งชื่อ · residual = สิ่งที่เหลือหลังหักทิศหลัก ๆ (Avellaneda-Lee)

วิธี 3 — Fundamental factors

Fama-French / sector dummies / style factors — โยง theory-part2 เล่ม A (factor models) แทนเขียนซ้ำทฤษฎี

3.3 The s-score — แทน "เลือกคู่ + z-score"

🚶 อ่านเป็นภาษาคนก่อน

แทนที่จะถามว่า "คู่นี้ spread ห่างกี่ SD" (z-score ของคู่) — เราถามทีละหุ้นว่า "residual ของหุ้นนี้ (หลังหักน้ำ) ห่างจากค่าปกติกี่ SD" แล้วให้คะแนน (s-score) ทุกตัวในกระดาน

เรือที่ลอยต่ำผิดปกติหลังหักน้ำ = ถูกไป → long · ลอยสูงผิดปกติ = แพงไป → short

idiosyncratic residual → โมเดลเป็น OU (ยางยืดดึงกลับ)
s-score = (residual − ค่าเฉลี่ย) / SD ← มาตรฐานเดียว เทียบได้ทุกตัว

s < −s_open → long · s > +s_open → short · |s| เล็ก → ปิด
✅ ตอบคำถามที่ค้างไว้: "cut-off จำเป็นไหม"

position = f(s-score) ข้ามทุกชื่อ → ไม่มีการ "เลือกคู่" เลย · แทน hard cut-off เลือก/ทิ้งแบบ ใช่/ไม่ใช่ → ใช้ การจัดอันดับต่อเนื่องทั้ง universe · cut-off ใน Part II จึงเป็น "baseline ที่ทุกคนรู้" ไม่ใช่หัวใจ

3.4 Cross-sectional mean reversion

🚶 ทำยังไง

พอมี s-score ทุกตัว → เรียงอันดับทั้ง universe → long ก้นตาราง (ถูกสุด) / short หัวตาราง (แพงสุด) · portfolio นี้ "หักน้ำ" ไปแล้วในตัว (factor-neutral) · และเป็นหลายเดิมพันเล็ก ๆแทนคู่เดียวลึก → กระจายความเสี่ยงดีกว่า (โยง edge map ชั้น A/D)

3.5 ★ ประเด็นทอง — common factor คือ "ความเสี่ยง"

📉 ทำไม pairs ไร้เดียงสาระเบิดตอนวิกฤต

ถ้าคุณไม่หักน้ำให้สะอาด — "pair/residual" ของคุณคือ การเดิมพันทิศทางตลาดที่ปลอมตัวมา · คุณคิดว่าคุณ neutral แต่จริง ๆ แอบถือความเสี่ยงตลาด/sector อยู่

ตลาดปกติมองไม่เห็น — แต่พอวิกฤตมา น้ำเคลื่อนแรง (ตลาดถล่มพร้อมกัน) "spread" ที่ควรกลับ กลับพุ่งหนี เพราะจริง ๆ มันคือ directional bet มาตลอด

"เข้าใจ common factor ไม่ได้ให้ edge — แต่มันกัน 'edge ปลอม': การเดิมพันทิศทางที่คุณนึกว่าเป็น spread"
🔍 วิธีเช็คว่า residual "สะอาด" จริง (ทำได้เอง)

เอา residual ที่คุณจะเทรด ไป regress กลับบน factor → ค่า β ที่ได้ควร ≈ 0 · ถ้ายังมี β เหลือ = ยังมีความเสี่ยงตลาดซ่อนอยู่ = ยังหักน้ำไม่หมด

ε_ที่จะเทรด → regress บน [ตลาด, sector] → β ควร ≈ 0
ถ้า β ≠ 0 → ยังแอบถือ factor อยู่ → ยังไม่สะอาด
✍️ ลองคิดเอง

คุณเทรด "spread ธนาคาร A − ธนาคาร B" แล้วพบว่ามันขาดทุนหนักทุกครั้งที่ SET ตก — แต่ ADF/half-life ก่อนหน้าดูดีหมด · เกิดอะไรขึ้น? (เฉลย: hedge ไม่สะอาด — spread ยังแอบมี β ต่อตลาดเหลืออยู่ = factor bet ปลอมตัว · ลอง regress spread กลับบน SET ดู β น่าจะ ≠ 0)

🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: "spread พุ่งหนี = ซวย เจอ structural break"
quant เห็น: บ่อยครั้ง spread ไม่ได้ break — มันแค่เผยว่าคุณถือ factor bet มาตลอด และ factor เพิ่งเคลื่อน · ปัญหาไม่ได้อยู่ที่ตลาด อยู่ที่การ hedge ที่ไม่สะอาดตั้งแต่แรก

3.6 ชั้น DL/ML residual — รู้ไว้ + กับดัก (ไม่ใช่ชวนแข่ง)

frontier ของงานวิจัยคือเอา residual (หลังหักน้ำ) ไปป้อนโมเดล non-linear ให้หา pattern

Deep Learning Statistical Arbitrage (Guijarro-Ordóñez, Pelger, Zanotti)

ขั้นตอน: factor (PCA/IPCA) → residual → CNN/transformer หา pattern · เป็นงาน top-journal (Management Science) ตัวแทน "ชั้น B" ของแผนที่ Edge

❌ ซื่อสัตย์: ทำไมรายย่อยไม่ควรไล่แข่งชั้นนี้
  • แออัดสุด — กองใหญ่ทุ่มทรัพยากรตรงนี้
  • overfit หนัก — feature เยอะ พารามิเตอร์เยอะ backtest สวยแต่ live หด
  • สู้ compute/data ไม่ได้ · สอนเป็น "รู้ว่ามี + กับดัก" ไม่ใช่พระเอก

3.7 แล้ว retail edge อยู่ไหน (ต้องซื่อสัตย์)

⚠️ ความจริงที่ต้องยอมรับ

factor-residual stat arb ก็ crowded ในตลาด liquid — Avellaneda-Lee เองโชว์ว่า Sharpe เสื่อมลงหลังราว 2002 · แปลว่า ไม่มี edge เหลือใน วิธี selection ใด ๆ แล้ว — pairs · cointegration · copula · PCA · DL ตายเท่ากันหมดในบ่อใหญ่

✅ edge จริงย้ายไป (รายย่อยเล่นได้)
  • บ่อที่ factor ยัง under-modeled — Thai/SEA/crypto: คนยังไม่ได้ map "น้ำ" ดี ๆ แค่หัก sector ETF ก็อาจพอ
  • cost/capacity/access (ชั้น D)
  • วินัย + regime (ชั้น C)
⚠️ ที่ไม่ควรไปแย่ง
  • PCA-residual บน US large-cap — กองใหญ่ครอง
  • DL signal — สู้ compute ไม่ได้
  • ไล่หา "วิธี selection ที่ดีกว่า" — มันตายหมดแล้ว
"เลิกถามว่าคู่ไหนสวย — ถามว่า residual อะไรที่เหลือหลังหักสิ่งที่ทุกคนถืออยู่แล้ว และใครยังไม่ได้หักมัน"

สรุป Part III + สะพานสู่ Part IV

✓ 3 อย่างที่ต้องจำจาก Part III
  1. pair = กรณีพิเศษ rank-1 — spread จริงคือ residual หลังหักน้ำ (common factor); PCA หักน้ำทั้งอ่าวพร้อมกัน
  2. common factor = ความเสี่ยง — ไม่หักให้สะอาด = การเดิมพันทิศทางปลอมตัว → เช็คด้วย regress residual กลับบน factor
  3. ไม่มี edge ในวิธี selection แล้ว — edge อยู่ที่บ่อ (factor under-modeled) + cost + วินัย ไม่ใช่โมเดล

ทั้ง β ของ pair (Part I) และ factor loading ของ residual (Part III) มีปัญหาเดียวกัน: มันเปลี่ยนตามเวลา — ระดับน้ำเปลี่ยน ความไวของเรือต่อน้ำก็เปลี่ยน · เราต้องการเครื่องมือที่อัปเดตมันแบบ real-time โดยไม่รู้อนาคตและไม่กระตุกตาม noise — นั่นคือ Kalman filter ที่ Part IV จะลงลึกจริง

"β เปลี่ยน · factor loading ก็เปลี่ยน — ใครจะอัปเดตมันให้ทันโดยไม่หลอกตัวเอง?"
📖 ศัพท์ใหม่ในตอนนี้
  • Common factor — "ระดับน้ำ" ที่ทำให้หุ้นหลายตัวขยับพร้อมกัน (ตลาด/sector/style)
  • Idiosyncratic residual — ส่วนเฉพาะตัวหุ้นหลังหักน้ำ (ส่วนที่เทรด)
  • Eigenportfolio (PCA) — portfolio ตามทิศที่ข้อมูลขยับพร้อมกันมากสุด = statistical factor
  • s-score — residual ที่ standardize แล้ว ใช้เป็นสัญญาณข้ามทั้ง universe
  • Factor-neutral — portfolio ที่ไม่มี exposure สุทธิต่อ common factor
  • Factor bet ปลอมตัว — spread ที่แอบมี factor exposure เหลือ (ยังไม่สะอาด)
