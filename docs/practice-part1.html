Part I — บันได β: หา hedge ratio ยังไง (โลกทีละคู่)
β (hedge ratio) คือหัวใจของทุก spread — Part นี้ไต่บันได 4 ขั้นจาก OLS → TLS/PCA → Rolling → Kalman พร้อมตอบคำถามที่คนพลาดบ่อยสุด: ทำไม OLS ที่ทุกคนใช้ ถึงใช้ได้แค่บางสถานการณ์ · แยก price vs return ให้ขาด · และแปลง β เป็นออร์เดอร์จริงบนกระดานไทย

บันได β — เพราะ hedge ratio ไม่ใช่ตัวเลขตายตัว

ก่อนจะเทรด spread ได้ ต้องตอบคำถามเดียวให้ได้ก่อน: ถือขา 2 ข้างในอัตราส่วนเท่าไร? ถ้าซื้อหุ้น A 1 หุ้น ต้อง short หุ้น B กี่หุ้น จึงจะได้ "ส่วนต่าง" (spread) ที่นิ่งพอจะเทรด — ตัวเลขนั้นคือ β

คนส่วนใหญ่หยิบ OLS มาแล้วจบ แต่ β ที่ดีในโลกจริงเปลี่ยนตามเวลา และวิธีประมาณมันมีหลายขั้น เหมือนบันได — แต่ละขั้นแก้จุดอ่อนของขั้นก่อน

ขั้น 0: OLS β คงที่ ประมาณครั้งเดียว (ง่ายสุด)
ขั้น 1: TLS / PCA แก้ปัญหา "ทั้งสองขามี noise"
ขั้น 2: Rolling OLS β เดินตามเวลาแบบหน้าต่างเลื่อน
ขั้น 3: Kalman β เดินแบบจำอดีต + optimal (→ Part IV)

เป้าหมายของ Part นี้ไม่ใช่ให้คุณ "ใช้ Kalman เป็น" (ใครก็ใช้เป็น — Part 0 บอกแล้วว่านั่นไม่ใช่ edge) แต่ให้คุณรู้ว่าแต่ละขั้นเชื่ออะไร พังเมื่อไร และเลือกใช้ตัวไหนเมื่อไร

1.1 OLS — จุดตั้งต้นที่ทุกคนเริ่ม

OLS (Ordinary Least Squares) หา β ที่ทำให้ผลรวมของ error ยกกำลังสองน้อยที่สุด

y = α + β·x + ε
β = Cov(y, x) / Var(x)

spread = y − β·x ← สิ่งที่เราจะเทรด (residual ε นั่นเอง)
🚶 อ่านเป็นภาษาคนก่อน

OLS ลากเส้นตรงผ่านกลุ่มจุด (x, y) โดยพยายามให้เส้น "ใกล้จุดทุกจุดในแนวตั้งที่สุด" — β คือความชันของเส้นนั้น · spread คือระยะที่จุดจริงห่างจากเส้น (ส่วนที่เส้นอธิบายไม่ได้)

มันเร็ว · เข้าใจง่าย · มีในทุกไลบรารี และในหลายกรณีก็ พอใช้ — ปัญหาคือ "หลายกรณี" ไม่ใช่ "ทุกกรณี" และตรงนี้แหละที่คนพลาด

1.2 ทำไม OLS "ใช้ได้แค่บางสถานการณ์" — 2 จุดพัง

จุดพัง 1 — ไม่สมมาตร (asymmetric)

regress A บน B ได้ β ตัวหนึ่ง · regress B บน A แล้วกลับหน่วย ได้ อีกค่า ที่ไม่เท่ากัน — ทั้งที่ควรเป็นความสัมพันธ์เดียวกัน! OLS "เลือกข้าง" ว่าตัวไหนเป็นตัวแปรตาม แล้วผลก็ขึ้นกับการเลือกนั้น

จุดพัง 2 — Errors-in-Variables (EIV / attenuation bias)

OLS สมมติว่า x ไม่มี noise (แม่นเป๊ะ) — แต่ในตลาดจริง ราคาขาขวาก็มี noise เท่า ๆ ขาซ้าย พอ x มี noise, OLS จะประมาณ |β| ต่ำกว่าจริงอย่างเป็นระบบ (เอนเข้าหา 0) เรียกว่า attenuation bias

β̂_OLS ≈ β_จริง × Var(x*) / [Var(x*) + Var(noise_x)]
└──── ตัวคูณ < 1 เสมอเมื่อ x มี noise ────┘
🧮 ตัวอย่างเชิงตัวเลข (สมมติ เพื่อให้เห็นภาพ)

ถ้าความสัมพันธ์จริง β = 1.00 และราคาขา x มี noise variance = 20% ของ signal:
β̂_OLS ≈ 1.00 × 1 / (1 + 0.20) ≈ 0.83
→ คุณจะ hedge น้อยไป 17% โดยไม่รู้ตัว → spread ที่ได้ยังแบก directional risk ค้างอยู่

📖 เชิงประวัติ: attenuation bias นี้ Frisch ชี้ไว้ตั้งแต่ยุค 1930s — ไม่ใช่ของใหม่ แต่คนเทรดสมัยใหม่ลืมมันบ่อยมาก

1.3 ★ จุดพลิกความเข้าใจ — price (level) vs return

ตรงนี้คือ เพชรของ Part I — สิ่งที่คอร์สทั่วไปไม่บอก และเป็นคำตอบจริงว่าทำไม "OLS แย่" ถึงเป็นความเชื่อที่ถูกครึ่งเดียว

★ ประเด็นหลัก

EIV/attenuation ที่เพิ่งเล่า เกิดกับ return regression (regress ผลตอบแทน on ผลตอบแทน) — แต่ ไม่เกิดกับ cointegration ที่ regress ราคา on ราคา เพราะมีปรากฏการณ์ชื่อ super-consistency

🚶 super-consistency คืออะไร (ภาษาคน)

เมื่อหุ้น 2 ตัว cointegrate กันจริง (ราคาเป็น I(1)) OLS บนราคาจะลู่เข้าหา β จริงเร็วมาก — เร็วระดับ T (จำนวนข้อมูล) แทนที่จะเป็น √T ตามปกติ · ผลคือ EIV bias หายไปเองเมื่อข้อมูลมากพอ (Stock 1987) · OLS บนราคาจึง "ดีเกินคาด" ในบริบท cointegration

Price / Level (Cointegration)Return (Correlation / Factor)
regress อะไรราคา on ราคาผลตอบแทน on ผลตอบแทน
β หมายถึงอัตราส่วนที่ทำให้ combo stationaryexposure/ความไว ณ ขณะนั้น
ตอบคำถาม"spread จะกลับไหม""ตอนนี้ neutral ต่อ factor ไหม"
OLS ใช้ได้ไหม✅ ดี (super-consistent) — refine ด้วย FM-OLS/DOLS เรื่อง finite-sample⚠️ EIV จริง → TLS/PCA/Kalman ช่วย
ใช้ผิดแล้วพังยังไงถ้าไม่ cointegrate = spurious regressionlevel ลอยห่างได้ แม้ return co-move
📉 spurious regression — กับดักที่ฆ่ามือใหม่

ถ้าคุณ regress ราคา 2 ตัวที่ไม่ cointegrate กัน — R² จะสูง t-stat จะเด่น ดูเหมือนเจอความสัมพันธ์ทอง — แต่มันปลอมทั้งหมด residual ไม่ stationary "spread" ไม่มีวันกลับ มันจะลากออกไปเรื่อย ๆ จนพอร์ตพัง (Granger & Newbold 1974) · บทเรียน: R² สูงบนราคา ≠ tradable — ต้องทดสอบ stationarity ของ residual เสมอ (Part II)

🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: "OLS มี bias → OLS แย่ → ทิ้ง"
quant เห็น: bias มีจริงเฉพาะบริบท — OLS บน return แย่ แต่ OLS บนราคาที่ cointegrate กลับดีเยี่ยม คำถามที่ถูกไม่ใช่ "OLS ดีหรือแย่" แต่คือ "ฉันกำลัง regress อะไร on อะไร"

1.4 แปลง β เป็นออร์เดอร์จริง — 3 ความ "neutral" ที่คนสับสน

β เป็นแค่อัตราส่วน พอถึงเวลาส่งคำสั่งจริงต้องแปลงเป็นจำนวนหุ้น/มูลค่า และตรงนี้มี 3 อย่างที่คนปนกันจนพัง

ความ neutralหมายความว่าได้อะไร / ไม่ได้อะไร
Share-ratioถือ B จำนวน β หุ้น ต่อ A 1 หุ้น (มาจาก cointegration)✅ ทำให้ spread กลับ · ❌ มักไม่ dollar-neutral
Dollar-neutrallong/short มูลค่าเท่ากัน✅ คุม gross exposure · ❌ ไม่การันตี residual ที่ cointegrate
Beta-neutralnet exposure ต่อ market/factor = 0= อาณาเขต Part III (factor)
📉 กับดัก: spread ที่แอบมีความเสี่ยงซ่อน

Share-ratio จาก cointegration โดยทั่วไป ไม่ dollar-neutral และ ไม่ market-beta-neutral → "spread" ของคุณอาจแบก net dollar + net market beta อยู่โดยไม่รู้ · แต่ถ้าคุณฝืนบังคับให้ dollar-neutral = ทำลายความสัมพันธ์ cointegration ที่ทำให้มันกลับ · นี่คือรากของ "factor bet ปลอมตัว" ที่จะเจาะใน Part III

หลักที่ต้องปัก

เลือกก่อนว่าจะให้ neutral ต่ออะไร (spread reversion? dollar? market beta?) — แล้วหน่วยจะตามมา · ปกติได้ไม่ครบทั้งสาม · stat arb เลือก reversion ก่อน แล้วคุม factor แยกต่างหาก (Part III)

🖥️ ลงลึกหน้าจอเทรดจริง — โดยเฉพาะกระดานไทย
  • ปัดเป็นจำนวนเต็ม: β·(จำนวนหุ้น) มักไม่ลงตัว → ปัดเศษ = hedge เพี้ยน โดยเฉพาะขาราคาสูง + ทุนน้อย (ไม่มี fractional share)
  • board lot ไทย = 100 หุ้น: ต้องสั่งเป็นล็อต → β·100 อาจไม่ลงตัวเป็นล็อต = จุดที่ทฤษฎีชนหน้าจอจริง
  • rebalance = ต้นทุน: พอ β อัปเดต (rolling/Kalman) ต้องปรับจำนวนหุ้น → เสียค่าคอมฯ ทุกครั้ง (โยง Part VI/VIII)

1.5 ขั้น 1 — TLS / Deming / PCA รู้ · ใช้เป็น · รู้ว่าพังตอนไหน

ถ้า EIV เกิดเพราะ OLS สมมติว่า x ไม่มี noise — ทางแก้คือใช้วิธีที่ยอมรับว่า ทั้งสองขามี noise นั่นคือ TLS (Total Least Squares) / Deming regression

🚶 อ่านเป็นภาษาคนก่อน

OLS วัดระยะห่างจากเส้นในแนวตั้ง (สมมติ error อยู่ที่ y เท่านั้น) · TLS วัดระยะตั้งฉากกับเส้น (ยอมรับ error ทั้ง x และ y) → สมมาตร + แก้ EIV

เชื่อมกับ PCA

TLS ของ 2 สินทรัพย์ = eigenvector ตัวแรกของ covariance matrix พอดี (ทิศที่ข้อมูลแกว่งมากสุด) → นี่คือสะพานสู่ eigenportfolio / PCA hedge ที่ Avellaneda-Lee (2010) ใช้จริง และเป็นแกนของ Part III

❌ TLS พังเมื่อไร (ส่วนที่คนไม่สอน)
  • δ ผิด → แย่กว่า OLS: TLS ไม่ได้ลบ bias มันแค่แลก bias หนึ่งด้วย สมมติฐานหนึ่ง — คืออัตราส่วน noise variance 2 ขา (δ) · Deming ปกติสมมติ δ=1 (noise เท่ากัน) ถ้าจริง ๆ ขาหนึ่ง noisy กว่ามาก → TLS เพี้ยนกว่า OLS อีก
  • ไวต่อ outlier: ระยะตั้งฉากทำให้จุดหลุดโด่งดึงเส้นแรงกว่าเดิมในบางเคส
✅ สรุปกฎเลือก OLS vs TLS
  • regress ราคา (cointegration) → OLS ดีอยู่แล้ว (super-consistent) · จะเนียนขึ้นใช้ FM-OLS/DOLS
  • regress return (hedge/factor) → EIV จริง → TLS/PCA ช่วย ถ้าประเมิน δ ได้ · ไม่งั้น Kalman (ขั้น 3) จัดการให้ดีกว่า

1.6 ขั้น 2 — Rolling / Expanding OLS

β จริงเปลี่ยนตามเวลา — วิธีง่ายสุดคือคำนวณ OLS ใหม่บน "หน้าต่างเลื่อน" (rolling window) แต่มันมี tradeoff ที่ต้องเข้าใจ

หน้าต่างสั้น
  • ✅ ไว ตาม β ที่เปลี่ยนทัน
  • ❌ jitter — β กระตุกตาม noise
  • ❌ rebalance บ่อย = ค่าคอมฯ พุ่ง
หน้าต่างยาว
  • ✅ นิ่ง β ไม่กระตุก
  • ❌ ช้า ตาม β ที่เปลี่ยนไม่ทัน
  • ❌ edge effect: จุดหลุดออกจากหน้าต่างทำให้ β กระโดด
⚠️ กับดัก look-ahead ตอน refit

ถ้า refit β โดยเผลอใช้ข้อมูลอนาคต (เช่นคำนวณ mean/std ของ spread จากทั้ง sample) = โกงตัวเอง backtest สวยแต่ live พัง · rolling ต้องใช้เฉพาะข้อมูลถึง ณ จุดนั้นเท่านั้น

Rolling OLS คือสะพานสู่ขั้นสุดท้าย — เพราะจริง ๆ แล้ว Kalman filter = rolling regression ที่ "จำ" อดีตอย่างเหมาะสมและถ่วงน้ำหนักแบบ optimal แทนที่จะตัดข้อมูลเก่าทิ้งดื้อ ๆ ที่ขอบหน้าต่าง

1.7 ขั้น 3 — Kalman (ยอดบันได) → เจาะลึก Part IV

state: β_t = β_{t−1} + w_t (β เดินแบบ random walk)
observation: y_t = β_t · x_t + v_t (ราคาที่เห็น = β×x + noise)

Q = variance ของ w → "β เปลี่ยนเร็วแค่ไหน"
R = variance ของ v → "เชื่อราคาล่าสุดแค่ไหน"

Kalman อัปเดต β ทุกวันแบบ real-time โดยใช้เฉพาะข้อมูลอดีต (causal — ไม่ look-ahead) และคุม drawdown ได้นิ่งกว่า rolling-OLS ที่กระตุก · อัตราส่วน Q/R คือปุ่มเดียวที่สำคัญสุด

⏭️ ทำไมยังไม่ลงลึกตรงนี้

Kalman มีเรื่องต้องระวังเยอะ — จูน Q/R ยังไงไม่ให้ overfit · จะรู้ได้ยังไงว่า overfit · β ควรเป็น random walk จริงไหม — ทั้งหมดนี้เป็นหัวใจของ Part IV เต็ม ๆ ที่นี่แค่ให้เห็นว่ามันคือปลายทางของบันได β

สรุป Part I + สะพานสู่ Part II

✓ 3 อย่างที่ต้องจำจาก Part I
  1. "OLS แย่" ถูกครึ่งเดียว — แย่กับ return regression (EIV) แต่ดีเยี่ยมกับ cointegration บนราคา (super-consistent)
  2. แยก price vs return ให้ขาด — ราคา→"spread กลับไหม" · return→"neutral ไหม" · ปนกัน = spurious regression หรือ hedge หลอก
  3. β เป็นแค่อัตราส่วน — เลือกก่อนว่าจะ neutral ต่ออะไร แล้วหน่วยตามมา; ระวัง hidden exposure + board lot

ตอนนี้เรามี β แล้ว และรู้ว่าจะเชื่อมันแค่ไหน — คำถามถัดไปคือ คู่ไหนถึงคู่ควรเทรดตั้งแต่แรก? ทุกคนใช้ correlation + cointegration test ชุดเดียวกัน สแกนหุ้นชุดเดียวกัน...

"ทุกคนมีเครื่องมือคัดคู่เหมือนกันเป๊ะ — แล้วเราจะต่างตรงไหน?"
📖 ศัพท์ใหม่ในตอนนี้
  • Hedge ratio (β) — อัตราส่วนถือ 2 ขาเพื่อสร้าง spread
  • EIV / attenuation bias — OLS ประมาณ |β| ต่ำไปเมื่อ x มี noise
  • Super-consistency — OLS บนราคาที่ cointegrate ลู่เข้าเร็วระดับ T → EIV หายเชิง asymptotic
  • Spurious regression — regress ราคาที่ไม่ cointegrate ได้ผลดูดีแต่ปลอม
  • TLS / Deming — regression ที่ยอมรับ noise ทั้ง 2 ขา (วัดระยะตั้งฉาก)
  • Share/Dollar/Beta-neutral — 3 ความหมายของ "ปรับสมดุลขา" ที่ห้ามสับสน
