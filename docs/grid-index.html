Grid คือ Grid — Enhancement ไม่ใช่ Magic

ศัพท์ที่ใช้ในกล่องนี้ (อธิบายละเอียดเต็มใน Part 0): alpha = กำไรส่วนเกินที่มาจากความได้เปรียบจริง ไม่ใช่แค่โชคดีหรือถือเฉยๆ · H (Hurst Exponent) = ตัววัดว่าราคามีแนวโน้ม "กลับสู่ค่ากลาง" แค่ไหน (H<0.5 = mean-reverting) · DD (Drawdown) = ขนาดการขาดทุนจากจุดสูงสุด · Sharpe (ratio) = ผลตอบแทนต่อหน่วยความเสี่ยง ยิ่งสูงยิ่งดี

Grid trading framework มี alpha จริง เฉพาะในตลาดที่ mean-revert จริง (H < 0.5 — ในตลาดสุ่มแท้ grid เปล่ามี expected value = 0 พอดี ดู Part 0 §0.4) + บังคับวินัยการซื้อขาย — แต่ทุก enhancement (indicator, zone trick, martingale) ช่วยปรับ คุณภาพของ equity curve มากกว่าเพิ่ม total return อย่างมีนัย

ในตลาดที่เหมาะสม แม้โยนหัวก้อยเพื่อเลือกว่าจะเปิด order หรือไม่ — Grid framework ก็ยังสร้างกำไรได้ใกล้เคียงเดิม เพราะ alpha มาจากการดักจับ mean-reversion ของสนามนั้น ไม่ได้มาจาก indicator ที่ใส่เพิ่ม Indicator ช่วยลด DD และทำให้ Sharpe ดีขึ้น — ไม่ใช่สร้าง alpha ใหม่จากอากาศ
