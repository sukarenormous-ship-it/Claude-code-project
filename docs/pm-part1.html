Payoff Mastery

Part I: Put-Call Parity — สมการเดียวที่อธิบายทุกอย่าง
บทที่ 1-4: ทบทวน Payoff Charts → Put-Call Parity → 6 Synthetics → Conversion/Box Spread — ปูจากศูนย์จนจัดรูป PCP หลับตาได้
🧭 เส้นทางอ่าน

🟢 มือใหม่: อ่าน 4 building blocks + สูตร PCP + ตัวอย่างตัวเลข ให้แม่นก่อน — ข้ามพิสูจน์เชิงลึกได้ · 🔵 มีพื้นบ้างแล้ว: อ่านครบ โดยเฉพาะบทที่ 3 (Synthetics) และกับดัก Box Spread ในบทที่ 4 ที่พังได้ถ้าใช้ option ผิดประเภท

❓ ทำไมสมการเดียวนี้ถึงสำคัญขนาดนั้น

Put-Call Parity ไม่ใช่แค่สูตรอีกอันให้ท่อง — มันคือกฎเหล็กที่บังคับให้ตลาด options ทั้งตลาดสอดคล้องกันเอง ถ้า Call, Put, หุ้น และพันธบัตรราคาไม่ลงตัวตามสมการนี้ จะมีคนทำกำไรฟรีได้ทันทีโดยไม่เสี่ยงอะไรเลย เมื่อเข้าใจสมการเดียวนี้ คุณจะสร้าง (synthesize) ทุกตำแหน่งได้จากอีก 3 ตำแหน่งที่เหลือ — นี่คือกุญแจที่ทำให้ desk เทรด options มืออาชีพมองเห็น "ทางลัด" ที่คนทั่วไปมองไม่เห็น

หมายเหตุ: ทุกกราฟ payoff ในบทนี้แสดง Net profit (หลังหัก premium) ยกเว้นระบุเป็นอย่างอื่น

บทที่ 1: ทบทวน Payoff Chart — "แผนที่ของทุก trade"

🚶 อ่านเป็นภาษาคนก่อน: ทุก strategy ที่ซับซ้อนที่สุดในเล่มนี้ ถูกสร้างจาก 4 ท่าพื้นฐานนี้เท่านั้น — เหมือนสีพื้นฐาน 4 สีที่ผสมกันเป็นสีอื่นได้ทั้งหมด ถ้าจำ 4 ท่านี้แม่น การเรียน strategy ใหม่ทุกอันต่อจากนี้จะเร็วขึ้นมาก เพราะมันคือการเอา 4 ท่านี้มาต่อกันในรูปแบบต่าง ๆ เท่านั้น

4 Building Blocks (K=100, Premium=5)

Short = พลิก Long กลับหัว (mirror ผ่านเส้นศูนย์)

จำแค่ 2 รูป (Call shape + Put shape) แล้วพลิกสำหรับ Short → ได้ครบ 4 ตำแหน่ง

✍️ ลองทำเอง (บท 1)

K=100, P=8 → Long Call BE = ? Max Loss = ? | Long Put BE = ? Max Loss = ?

เฉลย: LC BE=108, Max Loss=−8 | LP BE=92, Max Loss=−8

🎯 3 อย่างที่ต้องจำ
  • มี 4 building blocks: Long/Short Call + Long/Short Put
  • Short = พลิก Long → จำแค่ 2 รูป
  • ทุก strategy ที่ซับซ้อนกว่านี้ = 4 blocks นี้ประกอบกัน

บทที่ 2: Put-Call Parity — "สมการที่ทรงพลังที่สุด"

🚶 อ่านเป็นภาษาคนก่อน: ฝั่งหนึ่งคือ "ซื้อสิทธิซื้อ + วางเงินสดเผื่อจ่ายตอน K" อีกฝั่งคือ "ซื้อสิทธิขาย + ถือหุ้นจริง" — สองวิธีนี้หน้าตาต่างกันมาก แต่ให้ผลลัพธ์สุดท้ายเหมือนกันเป๊ะทุกสถานการณ์ที่ราคาอาจจบ ดังนั้นราคาวันนี้ของทั้งสองฝั่งก็ต้องเท่ากันด้วย ไม่งั้นจะมีคนทำกำไรฟรีได้โดยไม่เสี่ยงอะไรเลย

C + K·e⁻ʳᵀ = P + S
e⁻ʳᵀ คืออะไร? (สำหรับผู้อ่านใหม่)

e⁻ʳᵀ = "ตัวคูณลดค่า" — แปลงเงินอนาคตเป็นมูลค่าวันนี้

K=100, r=5%, T=0.5 ปี → K·e⁻ʳᵀ = 100 × e⁻⁰·⁰²⁵ = ฿97.53

= "ฝาก ฿97.53 วันนี้ ดอกเบี้ย 5% → 6 เดือนหลังได้ ฿100 พอดี" = PV(K)

พิสูจน์ PCP ด้วย Payoff Chart

ฝั่งซ้าย: Long Call + Bond (เงินสด K ณ วันหมดอายุ)

ถ้า S > K: ใช้สิทธิ Call ซื้อหุ้นที่ K, จ่าย K จาก Bond → ได้หุ้นมูลค่า S → รวมได้ S
ถ้า S ≤ K: Call หมดค่า + มีเงินสด K → ได้ K
→ ฝั่งซ้ายได้ = max(S, K)

ฝั่งขวา: Long Put + Stock

ถ้า S > K: Put หมดค่า + มีหุ้นมูลค่า S → ได้ S
ถ้า S ≤ K: ใช้สิทธิ Put ขายที่ K + หุ้น → ได้ K
→ ฝั่งขวาได้ = max(S, K)
ทั้งสองฝั่ง = max(S, K) เสมอ!

ไม่ว่าราคาจะจบที่ไหน ทั้งสองฝั่งให้ผลเท่ากัน → ราคาวันนี้ต้องเท่ากัน

นี่คือ Put-Call Parity: C + PV(K) = P + S — Exact Identity ที่จริงเสมอสำหรับ European Options

ตัวอย่างตัวเลข

🧮 ตัวอย่างการใช้งาน
S=100, K=100, r=5%, T=0.5, C=8.50, P=5.80
ฝั่งซ้าย: C + PV(K) = 8.50 + 97.53 = 106.03
ฝั่งขวา: P + S = 5.80 + 100 = 105.80
ต่าง = 0.23 → Violation! แต่หลังหักต้นทุนการเทรดจริงอาจไม่เหลือกำไร (ดูบท 4)
⚠️ Phantom Arb — ระวัง!

ถ้าลืมใส่ e⁻ʳᵀ แล้วคำนวณ C + K (แทนที่จะเป็น C + K·e⁻ʳᵀ):

C + K = 8.50 + 100 = 108.50 vs P + S = 105.80 → ต่าง ฿2.70!

แยกส่วนต่าง ฿2.70 นี้ออกเป็น 2 ก้อน: ก้อนแรกคือ K − PV(K) = 100 − 97.53 = ฿2.47 ที่มาจากการลืม discount ล้วนๆ (ไม่ใช่กำไรจริง) ก้อนที่สองคือส่วนที่เหลือ 2.70 − 2.47 = ฿0.23 ซึ่งตรงกับ Violation จริงที่คำนวณไว้ข้างบน — สรุปคือ ฿2.47 คือ phantom arb ที่เกิดจากการลืม discount เท่านั้น arb จริงมีแค่ ฿0.23 (ถ้ามี) นี่คือความผิดพลาดที่พบบ่อยที่สุดของ PCP

ลืม PV(K) ครั้งเดียว = เห็น "กำไรฟรี" ที่ไม่มีอยู่จริง — ก่อนตื่นเต้นกับส่วนต่างราคา ให้ถามก่อนเสมอว่า discount แล้วหรือยัง
PCP ใช้ได้เมื่อไร?
  • ✅ European Options (ใช้สิทธิได้แค่วันหมดอายุ) — สมการเท่ากันเป๊ะ
  • ⚠️ American Options → กลายเป็น inequality ไม่ใช่ equality (เพราะมี early exercise แทรก)
  • ⚠️ มี Dividend → ต้องปรับสมการเป็น C + PV(K) = P + S − PV(Dividends)
✍️ ลองทำเอง (บท 2)

C=12, P=7, S=100, K=100, r=2%, T=1 → PV(K) = 100×e⁻⁰·⁰² = 98.02 → ฝั่งซ้าย = ? ฝั่งขวา = ? มี violation ไหม? ถ้ามีทำอะไร?

เฉลย: ฝั่งซ้าย = 12+98.02 = 110.02, ฝั่งขวา = 7+100 = 107.00 → violation ฿3.02 → ฝั่งซ้ายแพงกว่า → ทำ Conversion (ซื้อฝั่งขวา ขายฝั่งซ้าย)

🎯 3 อย่างที่ต้องจำ
  • C + PV(K) = P + S — จริงเสมอสำหรับ European Options
  • อย่าลืม PV(K)! ใช้ K·e⁻ʳᵀ ไม่ใช่ K เฉย ๆ — ลืมแล้วจะเห็น phantom arb ฿2.47
  • ทั้งสองฝั่ง = max(S,K) ที่วันหมดอายุ → payoff เท่ากัน → ราคาวันนี้ต้องเท่ากัน

บทที่ 3: Synthetic Positions — "จัดรูป PCP = สร้างทุกอย่าง"

🚶 อ่านเป็นภาษาคนก่อน: เพราะ C + B = P + S (B = PV(K)) เป็นสมการเดียวที่จริงเสมอ คุณจึงย้ายข้างสมการนี้ไปมาได้อิสระ — ต้องการตัวไหนก็แยกตัวนั้นไว้ฝั่งเดียว แล้วที่เหลือคือ "ส่วนผสม" ที่สร้างมันขึ้นมาได้ ไม่ต้องท่องสูตรทั้ง 6 แบบแยกกัน

จากสมการเดียว C + B = P + S จัดรูปใหม่ได้ 6 Synthetics (3 คู่ Long/Short):

คู่ที่ 1: Synthetic Stock

Synthetic Long Stock = Long Call + Short Put + Bond
S = C − P + B
Synthetic Short Stock = Short Call + Long Put − Bond
−S = −C + P − B
ใช้เมื่อไร?
  • ยืมหุ้นไม่ได้ (short sell ban) → สร้าง Synthetic Short Stock แทน
  • ต้องการ stock exposure แบบมี leverage แต่ไม่อยากซื้อหุ้นจริง → ใช้ Synthetic Long Stock

คู่ที่ 2: Synthetic Call

Synthetic Long Call = Long Stock + Long Put − Bond
C = S + P − B
Synthetic Short Call = Short Stock + Short Put + Bond
−C = −S − P + B

คู่ที่ 3: Synthetic Put

Synthetic Long Put = Long Call + Short Stock + Bond
P = C − S + B
Synthetic Short Put = Short Call + Long Stock − Bond
−P = −C + S − B
กฎทอง: "ถ้าไม่มี X → สร้างจาก Y + Z"

ไม่ต้องจำ 6 สูตร — แค่จัดรูป C + B = P + S แล้วแยกตัวที่ต้องการไปอยู่ฝั่งซ้าย

ทุก Synthetic payoff "same shape" กับของจริง (ต่างกันแค่ค่าคงที่จาก financing)

✍️ ลองทำเอง (บท 3)
  1. ต้องการ Short Put แต่ broker ไม่อนุญาต → สร้าง Synthetic ยังไง?
  2. Synthetic Long Stock ราคา ฿98 แต่หุ้นจริงราคา ฿100 → ทำอะไรได้?

เฉลย ข้อ 1: −P = −C + S − B → Short Call + Long Stock − Bond

เฉลย ข้อ 2: ซื้อ Synthetic ฿98 ขาย Stock จริง ฿100 = กำไร ฿2 (ถ้าหลังหักต้นทุนยังเหลือ)

🎯 3 อย่างที่ต้องจำ
  • 6 Synthetics ทั้งหมดมาจากการจัดรูปสมการเดียว C + B = P + S
  • กฎทอง "ไม่มี X → สร้างจาก Y + Z" — ไม่ต้องท่องทั้ง 6 สูตร
  • Synthetic ทุกตัว shape เหมือนของจริงเป๊ะ ต่างแค่ต้นทุน financing

บทที่ 4: Conversion, Reversal, Box Spread

4.1 Conversion = "ล็อคกำไรจาก PCP Violation"

🚶 อ่านเป็นภาษาคนก่อน: ถือหุ้นจริง (เผื่อราคาขึ้น) + มีสิทธิขาย (เผื่อราคาลง) + ขายสิทธิซื้อทิ้ง (เก็บ premium) — ไม่ว่าราคาจะขึ้นหรือลง ผลลัพธ์ถูกล็อคไว้แน่นอนแล้ว เหมือนแปลง options ให้กลายเป็นพันธบัตรที่จ่ายเงินคงที่

Conversion = Long Stock + Long Put + Short Call
= S + P − C = PV(K) = Bond
→ Payoff = คงที่ทุกสถานการณ์ = risk-free profit (ถ้ามี violation)

ใช้ Conversion เมื่อฝั่งซ้ายของ PCP (Call + Bond) แพงกว่าฝั่งขวา (Put + Stock) — เพราะ Conversion คือการ "ขาย" ฝั่งซ้ายที่แพง (Short Call) แล้ว "ซื้อ" ฝั่งขวาที่ถูก (Long Put + Long Stock)

4.2 Reversal = "กลับด้าน Conversion"

🚶 อ่านเป็นภาษาคนก่อน: ทำทุกอย่างตรงข้ามกับ Conversion เป๊ะ — ขายหุ้นจริงแทนถือ, ขายสิทธิขายแทนซื้อ, ซื้อสิทธิซื้อแทนขาย ใช้ตอนที่ฝั่งขวาของ PCP (Put+Stock) แพงกว่าฝั่งซ้าย (Call+Bond) แทนที่จะเป็นตรงข้าม (คือตรงข้ามกับเงื่อนไขของ Conversion ด้านบน ที่ฝั่งซ้ายแพงกว่า)

Reversal = Short Stock + Short Put + Long Call
= −S − P + C = −PV(K)
→ ใช้เมื่อ PCP violation ไปทางตรงข้ามกับ Conversion (เช่นในโจทย์บทที่ 2 ที่ฝั่งซ้ายแพงกว่า — Conversion คือคำตอบ ถ้าฝั่งขวาแพงกว่าแทน Reversal คือคำตอบ)

4.3 Box Spread = "สร้าง Bond จาก Options"

🚶 อ่านเป็นภาษาคนก่อน: เอา spread สองฝั่ง (ฝั่งกำไรตอนราคาขึ้น + ฝั่งกำไรตอนราคาลง) มาต่อกัน ผลคือ payoff คงที่เท่ากับความกว้างระหว่าง 2 strikes เสมอ ไม่ว่าราคาจะจบตรงไหน — เหมือนสร้าง "พันธบัตรสังเคราะห์" จาก options ล้วน ๆ

Box Spread = Bull Call Spread(K₁,K₂) + Bear Put Spread(K₁,K₂)
= PV(K₂ − K₁) — Exact Identity
🧮 ตัวอย่างการใช้งาน
K₁=90, K₂=110, r=5%, T=0.25
Fair Box = (110−90) × e⁻⁰·⁰¹²⁵ = 20 × 0.9876 = ฿19.75
ถ้า Box ซื้อได้ ฿18.50 → กำไร ฿1.25 risk-free!
📉 เมื่อทฤษฎีพังจริง: Box ≠ Bond ถ้าเป็น American Options!

Box Spread = PV(width) เฉพาะ European Options เท่านั้น

ถ้าใช้ American → ขา short อาจถูก exercise ก่อนหมดอายุ → "Bond" ที่ควรจะนิ่งก็แตกได้

กรณี Reddit 2019: ผู้ใช้รายหนึ่งทำ Box Spread บน Robinhood ด้วย American options → ขาดทุน $58,000 เพราะ Box "แตก" จากการถูก early exercise บทเรียน: ตรวจ exercise style ก่อนเสมอ!

4.4 Dividend Arbitrage

🚶 อ่านเป็นภาษาคนก่อน: PCP มาตรฐานสมมติว่าหุ้นไม่มีเงินปันผลระหว่างทาง — ถ้ามี ปันผลนั้นทำให้ราคาหุ้นหลัง ex-div ต่ำลงตามมูลค่าปันผล ซึ่งกระทบราคา Call/Put ที่อ้างอิงหุ้นนั้นด้วย

ก่อนวัน ex-div: American Call อาจคุ้มที่จะ exercise ก่อนกำหนดเพื่อรับ dividend แทนที่จะถือ option ต่อไปเฉย ๆ

ถ้า options ไม่ได้ price early-exercise premium ไว้พอ → ซื้อ Call ราคาถูก → exercise ก่อน ex-div → ได้ dividend ไปด้วย นี่คือเหตุผลที่ PCP เวอร์ชันมี dividend ต้องหัก PV(Dividends) ออกจากฝั่งขวาตามที่กล่าวไว้ในบทที่ 2

✍️ ลองทำเอง (บท 4)

Box Spread: K₁=95, K₂=105, r=3%, T=0.5 → Fair = ? ถ้าซื้อได้ ฿9.50 → กำไรเท่าไร?

เฉลย: Fair = 10 × e⁻⁰·⁰¹⁵ = 10 × 0.9851 = ฿9.85 → ซื้อ ฿9.50 → กำไรวันนี้ (PV) = ฿9.85 − ฿9.50 = ฿0.35 (สมมติว่าเป็น European option — คือส่วนต่างระหว่าง fair value ที่คำนวณได้กับราคาที่ซื้อจริง)

🎯 3 อย่างที่ต้องจำ
  • Conversion = S + P − C = Bond → ล็อคกำไรจาก PCP violation
  • Box Spread = PV(K₂−K₁) → สร้าง "พันธบัตร" จาก Options (European เท่านั้น!)
  • ตรวจ exercise style ก่อนเสมอ — American Box ≠ Bond (บทเรียน Reddit $58,000)

Premium = ค่าตั๋วของสิทธิ option · Break-even = จุดคุ้มทุน · PV(K) / discount factor = มูลค่าปัจจุบันของเงิน K ในอนาคต · Put-Call Parity (PCP) = C+PV(K)=P+S · Exact Identity = จริงเสมอสำหรับ European Options (American กลายเป็น inequality) · European/American Options = ใช้สิทธิได้เฉพาะวันหมดอายุ/ก่อนหมดอายุก็ได้ · Bond = ในบริบทนี้คือ PV(K) (เงินสด/พันธบัตรมูลค่า K ที่ discount แล้ว) · Synthetic Stock/Call/Put = ตำแหน่งที่สร้างเลียนแบบของจริงจาก 3 ส่วนประกอบที่เหลือ · Conversion = Long Stock+Long Put+Short Call (ล็อคกำไร) · Reversal = กลับด้าน Conversion · Box Spread = Bull Call Spread+Bear Put Spread = พันธบัตรสังเคราะห์ · Phantom Arb = ส่วนต่างราคาปลอมที่เกิดจากลืม discount · ex-div = วันแรกที่ราคาหุ้นไม่รวมสิทธิรับปันผลแล้ว
