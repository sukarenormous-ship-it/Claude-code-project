ก่อนจะสร้าง payoff ได้อิสระ ต้อง อ่านกราฟเป็น ก่อน — นี่คือ 5 กฎที่ต้องจำ

พื้นฐาน: S₀, Sₜ, K และ Payoff vs Profit

นิยามสำคัญ

S₀ = ราคา underlying ตอนเริ่ม (วันที่เปิด trade)

Sₜ = ราคา underlying ตอน expiry (วันหมดอายุ) — นี่คือแกน X ของ payoff chart

K = strike price (ราคาใช้สิทธิ) — จุดหักศอกบน chart

Payoff chart ใช้ Sₜ เทียบกับ K ไม่ใช่ S₀ → S₀ อาจเท่ากับ K ตอนเริ่ม แต่ Sₜ ไปอยู่ตรงไหนก็ได้

Payoff ≠ Profit — ห้ามสับสน!

Payoff = ผลตอบแทนก่อนหัก premium  ·  Profit = ผลตอบแทนหลังหัก premium

Long Call payoff = max(Sₜ − K, 0)
Long Call profit = max(Sₜ − K, 0) − premium

Premium ไม่เปลี่ยน shape/slope — แค่เลื่อนกราฟขึ้นหรือลง ทุกกราฟในหนังสือนี้แสดง profit (หักpremiumแล้ว) ยกเว้นระบุเป็นอย่างอื่น

5 กฎอ่าน Payoff Chart

Rule 1: แกน X = Sₜ ณ expiry

กราฟแสดง "ถ้าราคาจบที่ Sₜ → กำไร/ขาดทุนเท่าไร" — ไม่ใช่ราคาวันนี้ ไม่ใช่ระหว่างทาง

Rule 2: จุดหักศอกทุกจุด = strike หรือ threshold

ทุกจุดที่เส้นหักเปลี่ยนทิศ = มี option leg ที่ strike นั้น → จำนวนจุดหัก = จำนวน legs ขั้นต่ำ

สองกฎแรกบอกว่า "ดูตรงไหน" — กฎถัดไปบอกว่า "ดูอย่างไร" ซึ่งเป็นจุดที่มือใหม่ส่วนใหญ่พลาด:

Rule 3: อ่านเป็นช่วงราคา ไม่ใช่แค่จุด K

อย่าดูแค่ "ที่ K₁ หักขึ้น, ที่ K₂ หักลง" — ให้แบ่งกราฟเป็นช่วง แล้วดู net slope ของแต่ละช่วง:

  • ก่อน K₁ → slope เท่าไร?
  • K₁ ถึง K₂ → slope เท่าไร?
  • K₂ ถึง K₃ → slope เท่าไร?
  • หลัง K₃ → slope เท่าไร?
Rule 4: Call active ทางขวา, Put active ทางซ้าย
Legทำงานฝั่งไหนSlope contribution
Long Callขวาของ K (Sₜ > K)+1
Short Callขวาของ K (Sₜ > K)−1
Long Putซ้ายของ K (Sₜ < K)−1
Short Putซ้ายของ K (Sₜ < K)+1

Option ไม่ได้มีผลแค่ตรง strike — มันมีผลทั้งฝั่ง (ซ้ายหรือขวา)

รู้ว่าแต่ละขา active ฝั่งไหนแล้ว ทีนี้มาดูกรณีที่ทำให้คนอ่านกราฟผิดบ่อยที่สุด — เส้นแบนที่ไม่ได้แปลว่า "ไม่มีอะไรเกิดขึ้น":

Rule 5: เส้นแบนเกิดได้ 2 แบบ
  • แบบ 1: ไม่มีขาไหนทำงานเลย (เช่น ช่วงกลางของ Iron Condor ระหว่าง K₂-K₃)
  • แบบ 2: มีหลายขาทำงาน แต่ slope หักล้างกัน (เช่น ช่วงก่อน K₁ ของ Iron Condor: LP slope −1 + SP slope +1 = 0)

ถ้ากราฟแบน แต่คุณเดาว่ามี Long Put → ต้องมี Short Put มาหักล้าง

Tail Slope Check — จับ risk ได้ใน 2 วินาที

ดูปลายซ้ายและปลายขวาของกราฟ:

  • ปลายซ้ายแบน (slope 0) = downside bounded หรือมีขาหักล้างกัน → ขาดทุนจำกัด
  • ปลายขวาแบน (slope 0) = upside bounded หรือมีขาหักล้างกัน → กำไรจำกัด
  • ปลายขวา slope ≠ 0 = unlimited exposure! (+slope = unlimited profit, −slope = unlimited loss)
  • ปลายซ้าย slope ≠ 0 = tail exposure ฝั่งลง! (+slope = กำไรเมื่อ crash, −slope = ขาดทุนเมื่อ crash)

กฎ: ดูปลายทั้งสองก่อนเสมอ → ถ้า slope ≠ 0 ที่ปลายไหน = มี unlimited risk/reward ที่นั่น

Worked Example: Iron Condor อ่านเป็นช่วง

Iron Condor = LP(K₁) + SP(K₂) + SC(K₃) + LC(K₄)

ช่วงราคาActive legsNet slopeความหมาย
Sₜ < K₁LP(K₁) + SP(K₂)−1 + 1 = 0หักล้างกัน → แบน (max loss)
K₁ < Sₜ < K₂SP(K₂)+1เส้นไต่ขึ้น
K₂ < Sₜ < K₃ไม่มีขา active0กำไรแบน (max profit)
K₃ < Sₜ < K₄SC(K₃)−1เส้นไหลลง
Sₜ > K₄SC(K₃) + LC(K₄)−1 + 1 = 0หักล้างกัน → แบน (max loss)
สังเกต: ช่วง "แบน" 3 ช่วง เกิดคนละสาเหตุ!
  • ก่อน K₁: แบนเพราะ 2 ขาหักล้างกัน (LP −1 + SP +1 = 0)
  • K₂ ถึง K₃: แบนเพราะ ไม่มีขาไหนทำงาน
  • หลัง K₄: แบนเพราะ 2 ขาหักล้างกัน (SC −1 + LC +1 = 0)

ถ้าดูแค่ "จุดหัก" จะไม่เห็นความแตกต่างนี้ → ต้องดูเป็นช่วง!

Gross Payoff vs Net Deployable Payoff

กราฟสวย ≠ เทรดได้จริง

กราฟ payoff ที่เราวาด = Gross Payoff (theoretical) — สิ่งที่ได้จริง = Net Deployable Payoff = Gross หักด้วย:

  • Premium: ต้นทุนเปิด trade (bid/ask ไม่ใช่ mid!)
  • Bid-ask spread: ซื้อที่ ask, ขายที่ bid → ทุก leg มี cost
  • Fees/Commission: ค่าธรรมเนียมต่อ contract
  • Slippage: ราคาอาจขยับก่อน fill
  • Margin cost: เงินที่ต้องวางค้ำ → opportunity cost
  • Execution risk: legs อาจ fill ไม่พร้อมกัน

กฎ: ใช้ bid สำหรับขาที่ขาย, ask สำหรับขาที่ซื้อ → ถ้ายัง profit = edge จริง

บทที่ 15: General Slope Decomposition — "Slope อิสระ"

แนวคิด: ทำไม slope ±1 ไม่พอ?

ที่ผ่านมาทุกตัวอย่างใช้ 1 contract ต่อ leg → slope เปลี่ยนแค่ ±1 เสมอ แต่ในความเป็นจริง: slope = quantity × direction

🚶 อ่านเป็นภาษาคนก่อน: ถ้า 1 สัญญาให้ slope ±1 การมี 3 สัญญาก็แค่คูณ 3 — slope ไม่ได้ถูกจำกัดแค่ −1/0/+1 อีกต่อไป มันเป็นตัวเลขอะไรก็ได้ตามจำนวนสัญญาที่คุณถือ

ซื้อ 3 Calls ที่ K=100 → slope change = +3 (ไม่ใช่แค่ +1)
ขาย 2 Puts ที่ K=90 → slope change = −2 ที่ K=90

กฎ: Δslope = (จำนวน contracts) × (ทิศทาง: Long=+1, Short=−1)

5-Step Decomposition Algorithm

Algorithm: จาก payoff shape → position
  1. เดินจากซ้ายสุด → จด initial slope (s₀)
  2. ที่ทุกจุดหักศอก K_i → คำนวณ Δs_i = slope_after − slope_before
  3. ถ้า Δs_i > 0 → Long |Δs_i| Calls ที่ K_i  ·  ถ้า Δs_i < 0 → Short |Δs_i| Calls ที่ K_i
  4. s₀ > 0 → Long s₀ หุ้น  ·  s₀ < 0 → Short |s₀| หุ้น  ·  s₀ = 0 → ไม่ต้องมีหุ้น
  5. Y-intercept (ค่า payoff ที่ซ้ายสุด) → กำหนดตำแหน่ง bond/cash

วิธีอ่านที่ถูกต้อง: ดูเป็น "ช่วง" ไม่ใช่แค่ "จุดหัก"

ข้อผิดพลาดที่พบบ่อยที่สุด

Wrong: "ที่ K₁ เส้นหักขึ้น, ที่ K₂ เส้นหักลง" → จบ

Right: "ช่วงก่อน K₁ slope เท่าไร? ช่วง K₁-K₂ slope เท่าไร? ช่วงหลัง K₂ slope เท่าไร?"

เพราะ option ไม่ได้มีผลแค่ตรง strike — มันมีผลทั้ง "ฝั่งซ้าย" หรือ "ฝั่งขวา" ของ strike

กฎ Active Zone

Call ทำงานทาง "ขวา" ของ K:
Long Call = +slope ทางขวา (S > K)
Short Call = −slope ทางขวา (S > K)
ทางซ้ายของ K → Call ไม่มีผล (slope = 0)
Put ทำงานทาง "ซ้าย" ของ K:
Long Put = −slope ทางซ้าย (S < K)
Short Put = +slope ทางซ้าย (S < K)
ทางขวาของ K → Put ไม่มีผล (slope = 0)
ระวังสับสน: Slope Contribution ≠ Slope Change (Δs)

Slope contribution = slope ที่ leg นั้น "เพิ่ม" ในช่วงที่มัน active — เช่น Long Put: slope −1 ทางซ้าย (ยิ่ง S ลง ยิ่งกำไร)

Slope change (Δs) = slope หลัง K ลบ slope ก่อน K — เช่น Long Put: Δs = 0 − (−1) = +1 (slope "เพิ่มขึ้น" ที่ K เพราะ Put หยุดทำงาน)

ทั้งสองเป็นเรื่องเดียวกัน ดูจากคนละมุม: Contribution บอกว่า "leg นี้ทำอะไรในช่วงที่มัน active" ส่วน Δs บอกว่า "เส้นหักศอกตรง K อย่างไร" — ใช้อันไหนก็ได้ แต่ อย่าผสมกัน ในการวิเคราะห์เดียวกัน

ตัวอย่าง: ฝั่งซ้ายของ Iron Condor ทำไมถึง "แบน"?

Long Put(90) + Short Put(100) → ดูว่าแต่ละขา active ตรงไหน:

ช่วงราคาLong Put 90Short Put 100รวม slope
S < 90−1 (active)+1 (active)0 (หักล้าง!)
90 < S < 1000 (หมดผล)+1 (active)+1 (ขึ้น)
S > 100000 (ไม่มีผล)
ทำไมก่อน K₁ ถึงแบน? — คำตอบที่แท้จริง

ก่อน K₁ ทั้งสอง Put ทำงานพร้อมกัน: Long Put(90) = slope −1 + Short Put(100) = slope +1 → รวม = 0

เส้นแบนไม่ได้แปลว่า "ไม่มีอะไรทำงาน" — แต่มี 2 ขาทำงานหักล้างกัน! กฎ: เส้นแบนเกิดได้ 2 แบบ:

  • ไม่มีขาไหนทำงานเลย (เช่น ช่วงหลัง K₂)
  • มีหลายขาทำงาน แต่ slope หักล้างกัน (เช่น ช่วงก่อน K₁)
วิธีอ่าน Payoff ที่ถูกต้อง

อย่าเริ่มจาก "ที่ K หักขึ้น/ลง" → ให้เริ่มจาก:

  1. ช่วงก่อน K₁ slope เท่าไร?
  2. ช่วง K₁-K₂ slope เท่าไร?
  3. ช่วง K₂-K₃ slope เท่าไร?
  4. ...(ทำต่อจนสุดกราฟ)

แล้วค่อยถาม: "อะไรทำให้ slope เปลี่ยนจากช่วงนี้ไปช่วงถัดไป?" ถ้ากราฟแบน แต่คุณเดาว่ามี Long Put → ต้องมี Short Put มาหักล้าง

PCP เป็นเครื่องมือแปลง Payoff Chart

🚶 อ่านเป็นภาษาคนก่อน: Put-Call Parity ไม่ใช่แค่สูตรท่องจำ — มันเป็น เครื่องมือ transform ที่แปลง payoff chart จาก construction หนึ่งไปอีกแบบหนึ่งได้ เหมือนแปลงหน่วยเงินตราไปมาโดยมูลค่าที่แท้จริงไม่เปลี่ยน

PCP: C + PV(K) = P + S

จัดใหม่ได้ 4 แบบ:
① C = P + S − PV(K) → เห็น Call = เห็น Put+Stock (ลบ bond)
② P = C − S + PV(K) → เห็น Put = เห็น Call−Stock (บวก bond)
③ S = C − P + PV(K) → เห็น Stock = เห็น Call−Put (บวก bond)
④ PV(K) = P − C + S → เห็น Bond = เห็น Put−Call+Stock
🧮 ตัวอย่างการใช้งาน: แปลง Iron Condor ให้เห็นด้วย Calls ล้วน

Iron Condor = +Put(K₁), −Put(K₂), −Call(K₃), +Call(K₄) — ใช้ PCP แปลง Puts → Calls:

+Put(K₁) = +Call(K₁) − S + PV(K₁)
−Put(K₂) = −Call(K₂) + S − PV(K₂)

แทนค่า: +Call(K₁) − Call(K₂) − Call(K₃) + Call(K₄) + [PV(K₁) − PV(K₂)]

= Bull Call Spread(K₁,K₂) + Bear Call Spread(K₃,K₄) + bond adjustment

Payoff shape เดียวกัน! ต่างแค่ค่าคงที่จาก PV(K) — ยืนยันหลักการ "Same Shape, Different Cost"

ประโยชน์จริงของ PCP + Payoff Chart
  1. เลือก construction ที่ถูกที่สุด: แปลงไปมา → เปรียบเทียบ debit/credit
  2. เห็นว่า strategy "ซับซ้อน" = strategy "ง่าย" ที่แปลงแล้ว: Covered Call = Short Put + Bond (ผ่าน PCP); Collar = Risk Reversal + Stock (ผ่าน PCP)
  3. Reverse Engineering ได้ 2 ทาง: ถอดเป็น Calls ล้วน หรือ Puts ล้วน แล้วเลือกที่เข้าใจง่ายกว่า
  4. ตรวจ arbitrage: ถ้า 2 constructions ให้ shape เดียวกันแต่ราคาต่างกัน → อาจมี edge

ตัวอย่างที่ 1: ทบทวน — Bull Call Spread

Target: slope 0 → +1 at 100 → 0 at 110 (flat ทั้งสองข้าง)
s₀ = 0 → ไม่ต้องมีหุ้น
Δs at 100: +1 → Long 1 Call(100)
Δs at 110: −1 → Short 1 Call(110)
= Bull Call Spread 100/110

ตัวอย่างที่ 2: Slope อิสระ — "3x Leveraged Cap"

โจทย์: "อยากได้ 3 เท่าของ upside ถ้าราคาขึ้นจาก 100 ถึง 110 แต่ cap หลัง 110"

Target: slope 0 → +3 at 100 → 0 at 110
s₀ = 0 → ไม่ต้องมีหุ้น
Δs at 100: +3 → Long 3 Calls(100)
Δs at 110: −3 → Short 3 Calls(110)
= 3× Bull Call Spread 100/110
Max profit = 3 × (110−100) − net premium = 30 − net
Max loss = net premium

ตัวอย่างที่ 3: Asymmetric — slope ไม่สมมาตร

โจทย์: slope 0 → +2 at 95 → −3 at 105 → +1 at 115 → 0

s₀ = 0 → ไม่ต้องมีหุ้น
Δs at 95: +2 → Long 2 Calls(95)
Δs at 105: −3 → Short 3 Calls(105)
Δs at 115: +1 → Long 1 Call(115)
Net slope = +2−3+1 = 0 → bounded ✓

= "Asymmetric Butterfly" — peak เอียงซ้าย

ตัวอย่างที่ 4: Initial slope ≠ 0 — ต้องมีหุ้น

Target: slope +2 → +1 at 100 → 0 at 110
s₀ = +2 → Long 2 Stock
Δs at 100: +1−2 = −1 → Short 1 Call(100)
Δs at 110: 0−1 = −1 → Short 1 Call(110)

= Long 2 Stock + Short 1 Call(100) + Short 1 Call(110)
= "Enhanced Covered Call" แบบ 2 strikes
กฎสรุป
  1. Slope = Quantity × Direction → ไม่จำกัดแค่ ±1
  2. Σ|Δs_i| = จำนวน option legs ขั้นต่ำ, + |s₀| ถ้าต้องมีหุ้น
  3. Net slope ปลายขวา = 0 → bounded; ≠ 0 → unbounded risk/profit
  4. Y-intercept → กำหนดว่า net debit หรือ net credit

Put vs Call: เลือกใช้อย่างไร?

Algorithm ข้างบนใช้ Call เท่านั้น — แต่ในทางปฏิบัติ Put ให้ slope change เดียวกัน

กฎ: slope change ที่ K
Long Call(K) → Δs = +1 (slope เพิ่มขึ้น)
Long Put(K) → Δs = +1 (slope เพิ่มขึ้นเหมือนกัน!)

Short Call(K) → Δs = −1
Short Put(K) → Δs = −1 (เหมือนกัน!)
ถ้า slope change เหมือนกัน ทำไมต้องเลือก?

เพราะ ผลก่อนถึง strike ต่างกัน: Long Call(100) มี slope 0 ก่อน K, slope +1 หลัง K ส่วน Long Put(100) มี slope −1 ก่อน K, slope 0 หลัง K

ทั้งคู่เปลี่ยน slope +1 ที่ K แต่ Put มี slope −1 ทางซ้ายด้วย → ส่งผลต่อ initial slope

หลักปฏิบัติ: ใช้ OTM options (ถูกกว่า, liquidity ดีกว่า) ถ้า K > S ปัจจุบัน ใช้ Call, ถ้า K < S ปัจจุบัน ใช้ Put — และใช้ PCP เปลี่ยนได้เสมอ: Long Call + Short Put + Bond = Long Stock

ตัวอย่าง: สร้าง payoff เดียวกัน 2 วิธี

Bull Spread 90/110 ด้วย Calls: Long Call(90) + Short Call(110) → net debit
Bull Spread 90/110 ด้วย Puts: Long Put(90) + Short Put(110) → net credit

Payoff shape เดียวกันทุกประการ! ต่างแค่ debit vs credit (ผ่าน PCP: ต่างกันค่าคงที่ PV(K₂−K₁) เท่านั้น)

รูปร่างเดียวกัน ≠ ต้นทุนเดียวกัน

🚶 อ่านเป็นภาษาคนก่อน: "shape เดียวกัน" หมายถึงเฉพาะผลลัพธ์ตอนหมดอายุ — แต่ระหว่างทางมีต้นทุนแฝงหลายอย่างที่ทำให้ 2 วิธีที่ให้ payoff เหมือนกันเป๊ะ กลับมีราคาจริงต่างกัน นี่คือหลักการที่หลายคนมองข้าม

หลักการ: "Same Shape, Different Cost"

ทุก payoff shape สร้างได้ หลายวิธี — แต่ละวิธีมีต้นทุนต่างกัน:

  • Debit vs Credit: Bull Call Spread (จ่ายก่อน) vs Bull Put Spread (ได้ก่อน)
  • Financing cost: Synthetic Stock ต้องจ่ายดอกเบี้ยบน PV(K)
  • Bid-ask spread: OTM options มี spread แคบกว่า ITM → ถูกกว่า execute
  • Margin: บาง construction ใช้ margin มากกว่า → ต้นทุนซ่อน

Bull Spread 90/110 — วิธี A (Calls): Long Call(90) ฿12 + Short Call(110) ฿4 → net debit ฿8

วิธี B (Puts): Short Put(110) ฿9 + Long Put(90) ฿3 → net credit ฿6

ทำไมราคาต่างกัน ถ้า shape เหมือนกัน?

เพราะ "shape เดียวกัน" หมายถึง ณ วันหมดอายุเท่านั้น — ก่อนถึงวันนั้นมีปัจจัยเหล่านี้แทรก:

  • Interest rate: debit strategy ต้อง "จ่ายก่อน" → มี opportunity cost
  • Dividend: ถือหุ้นจริงได้ปันผล, synthetic ไม่ได้
  • IV Skew: Put OTM กับ Call OTM มี implied vol ต่างกัน → premium ต่างกัน
  • Early exercise: American options อาจถูก exercise ก่อน → risk ต่างกัน
  • Margin: Short Put ต้องวาง margin, Covered Call ใช้หุ้นค้ำ → ต้นทุนเงินทุนต่างกัน

กฎ: คำนวณต้นทุนทุกวิธีก่อนเลือก → เลือกวิธีที่ถูกที่สุด (all-in cost ต่ำสุด)

Checklist: เลือกวิธีสร้าง payoff ที่ดีที่สุด
  1. Net debit/credit: จ่ายน้อยที่สุด หรือได้มากที่สุด
  2. Bid-ask costs: OTM options มักถูกกว่า → ใช้ OTM ถ้าได้
  3. Margin requirement: ต้นทุนเงินทุนที่ต้องวางไว้
  4. Liquidity: volume สูง → fill ง่าย → slippage น้อย
  5. Early exercise risk: American short options มี assignment risk → อาจต้องเลี่ยง
  6. Dividend: ถ้ามีปันผลระหว่างทาง → ถือหุ้นจริงอาจดีกว่า synthetic

การผสม Put + Call อิสระ — Quantity เท่าไรก็ได้

ไม่จำเป็นต้องใช้แค่ Call หรือแค่ Put — ผสมกันได้อย่างอิสระ ทั้ง type, strike, และ quantity

หลักการ: slope ก่อนและหลัง strike ของ Put vs Call
  • Long Call(K): slope 0 ก่อน K → slope +1 หลัง K (เพิ่มทางขวา)
  • Long Put(K): slope −1 ก่อน K → slope 0 หลัง K (เพิ่มทางซ้าย)
  • Short Call(K): slope 0 ก่อน K → slope −1 หลัง K
  • Short Put(K): slope +1 ก่อน K → slope 0 หลัง K

สำคัญ: Put ส่งผลต่อ slope ก่อน strike (ทางซ้าย) ด้วย — ต่างจาก Call ที่ส่งผลแค่หลัง strike

ตัวอย่าง: LC(100) + 4×SP(100) + SC(100) — ผสมทุกแบบ

แยกวิเคราะห์ slope ทีละตัว:

Long Call(100): ก่อน 100 slope=0 | หลัง 100 slope=+1
4× Short Put(100): ก่อน 100 slope=4×(+1)=+4 | หลัง 100 slope=0
Short Call(100): ก่อน 100 slope=0 | หลัง 100 slope=−1

รวม: ก่อน 100: 0+4+0 = +4  ·  หลัง 100: +1+0+(−1) = 0

Payoff shape: slope +4 ทางซ้าย → แบน (slope 0) หลัง K=100
= ราคายิ่งต่ำ ยิ่งขาดทุนเร็ว (4 เท่า!) แต่ถ้าราคาอยู่เหนือ K → เก็บ premium

net slope ปลายขวา = 0 → bounded ทางขวา
แต่ทางซ้าย slope = +4 → ถ้าราคาลงแรง ขาดทุนหนักมาก (4x leverage!)
ระวัง: 4× Short Put = ขาดทุน 4 เท่า!

ถ้าราคาลง ฿10 → ขาดทุน ฿40 (ไม่ใช่ ฿10) — Quantity ทวีคูณ risk ไม่ใช่แค่ profit

ก่อนเพิ่ม quantity ต้องถามเสมอ: "ถ้าราคาลง 20% ผมรับได้ไหม?"

ตัวอย่าง: LC(110) + 2×SP(90) + SC(120) — ต่าง strikes

วิเคราะห์ slope ทีละ region:

Region 1 (S < 90): 2×SP(90) slope = +2 → slope = +2
Region 2 (90 ≤ S < 110): SP หมดผล → slope = 0
Region 3 (110 ≤ S < 120): LC(110) เริ่ม → slope = +1
Region 4 (S ≥ 120): SC(120) เริ่ม → slope = +1−1 = 0

Slope profile: +2 → 0 → +1 → 0  ·  Kinks: 90 (Δs=−2), 110 (Δs=+1), 120 (Δs=−1)
Net slope = 0 → bounded ✓

Shape: ชันลงทางซ้าย (ขาดทุน 2x ถ้าราคาต่ำกว่า 90) → แบน → ขึ้นเล็กน้อย → แบน
= "เก็บ premium ถ้าราคาอยู่ในช่วง 90-120 + bonus upside 110-120"
🎯 กฎทอง: ผสมได้อิสระ แต่ต้องเข้าใจ slope ทุก region
  1. แยกวิเคราะห์ slope ก่อน/หลัง strike ของทุกตัว
  2. รวม slope ทุก region → ได้ payoff shape
  3. ตรวจ net slope ปลายทั้งสองข้าง → bounded หรือ unbounded?
  4. Quantity ทวีคูณทั้ง profit และ risk → ระวัง!
🎯 3 สิ่งที่ต้องจำ (บท 15)
  • Slope = Quantity × Direction → สร้าง slope อะไรก็ได้ ไม่จำกัด ±1
  • ผสม Put+Call อิสระ → วิเคราะห์ slope ทุก region → ผลลัพธ์อ่านได้จาก slope profile
  • Quantity ทวีคูณ risk ด้วย → 4×SP = ขาดทุน 4 เท่า → ตรวจ downside ก่อนเสมอ
Slope ไม่ใช่แค่ +1/0/−1 อีกต่อไป — มันคือจำนวนสัญญาคูณทิศทาง ยิ่งคูณมาก ยิ่งได้ทั้งกำไรและความเสี่ยงมากตามไปด้วยเสมอ

บทที่ 16: Reverse Engineering — "เห็น Chart สร้าง Position"

แนวคิด: ทักษะสำคัญที่สุด

🚶 อ่านเป็นภาษาคนก่อน: บทที่ 15 สอนให้สร้าง payoff จาก position ที่กำหนด — บทนี้ทำย้อนกลับ: เห็น payoff chart ก่อน แล้วถอดกลับเป็น position ทันที ถ้าทำได้ แปลว่าคุณไม่ได้แค่ท่องชื่อ strategy แต่เข้าใจ payoff จริง ๆ

ไม่ต้องจำชื่อ strategy — แค่อ่าน slope แล้วแปลง

5-Step Reverse Engineering Method

วิธีถอด: จาก chart → position
  1. หาจุดหักศอก (kink points) ทั้งหมด
  2. วัด slope ในแต่ละ region (นับช่องบนกราฟ)
  3. คำนวณ Δs = slope_after − slope_before ที่ทุก kink
  4. ใช้ Decomposition Algorithm (บทที่ 15)
  5. ตรวจสอบ — สร้างกลับแล้วได้ shape เดิมไหม?

RE ตัวอย่าง 1: Butterfly (ทบทวน)

Chart: flat(−3) → +1 at 90 → −2 at 100 → +1 at 110 → flat(−3)

Step 1: kinks at 90, 100, 110
Step 2: slopes = 0, +1, −1, 0
Step 3: Δs = +1, −2, +1
Step 4: Long 1 Call(90), Short 2 Calls(100), Long 1 Call(110)
Step 5: ✓ net slope = 0, peak at 100 = −3+10 = +7 → ถ้า net premium = 3 → peak = +7 ✓
= Long Call Butterfly 90/100/110

RE ตัวอย่าง 2: Asymmetric Ratio — ตัวอย่างที่มีข้อผิดพลาดโดยตั้งใจ!

ตัวอย่างนี้ตั้งใจให้มีจุดที่ไม่ consistent → เพื่อฝึก Step 5 (verify)

Chart ที่โจทย์บอก: เริ่มต้นแบนที่ −5 (ก่อน 95) → Δs=+2 ที่ 95 → Δs=−3 ที่ 105 → Δs=+1 ที่ 115 → โจทย์กำหนดว่าหลัง 115 ต้องกลับมาแบนที่ −5 เท่าเดิม

Step 1: kinks at 95, 105, 115
Step 2: slopes = 0, +2, −1, 0
Step 3: Δs = +2, −3, +1
Step 4: Long 2 Calls(95), Short 3 Calls(105), Long 1 Call(115)
Step 5 (verify): เดินตามตัวเลขจริง —
  At 95: −5, slope +2 → at 105: −5+2(10) = +15 (peak)
  At 105: slope −1 → at 115: +15+(−1)(10) = +5
  หลัง 115: slope 0 → แบนที่ +5

แต่โจทย์บอกว่าแบนขวาต้องเป็น −5! ไม่ตรงกับที่คำนวณได้ (+5) → เจอข้อผิดพลาดแล้ว
บทเรียน: ตรวจเสมอ (Step 5)!

Reverse Engineering ต้อง verify ทุกครั้ง — สร้างกลับแล้วค่าต้องตรงกับที่โจทย์กำหนด

ถ้าไม่ตรงอย่างในตัวอย่างนี้ แปลว่าโจทย์ตั้งค่า y-intercept ไม่สอดคล้องกับ slope ที่ให้มา (ถ้าจะให้ปลายขวาเป็น −5 จริง ต้องเริ่มต้นที่ −15 ไม่ใช่ −5)

ต้องกลับไปเช็ค Step 1-4 ใหม่ทุกครั้งที่ตัวเลขไม่ลงตัว

RE ตัวอย่าง 3: Covered Call จากกราฟ

Chart: slope +1 ตลอดทางซ้าย → 0 at 100 (flat หลัง 100)

Step 1: kink ที่ 100 เท่านั้น
Step 2: slopes = +1 (ก่อน 100), 0 (หลัง 100)
Step 3: Δs at 100 = 0−1 = −1
Step 4: Short 1 Call(100), s₀ = +1 → Long 1 Stock
= Long Stock + Short Call(100) = Covered Call!

RE ตัวอย่าง 4: ดูเหมือน Risk Reversal? — ถอดให้ดี!

Chart: flat(−3) → +1 at 90 → +1 at 110 → slope +2 ต่อไป

Step 1: kinks at 90, 110
Step 2: slopes = 0, +1, +2
Step 3: Δs at 90 = +1, Δs at 110 = +1
Step 4: s₀ = 0 → ไม่ต้องมีหุ้น

แต่ Δs ที่ 90 = +1 → Long Call(90)? หรือ Long Put(90)?

ลองใช้ Call ทั้งคู่: Long 1 Call(90) + Long 1 Call(110) → net slope = +2 ≠ 0 → unbounded ✓ ตรงกับโจทย์

ลองใช้ Put+Call แทน: Short 1 Put(90) ให้ Δs = −1 ที่ 90 ... ไม่ตรงกับที่โจทย์ต้องการ (+1)

คำตอบที่ถูก: Long Call(90) + Long Call(110) = 2 Long Calls ที่ strikes ต่างกัน
(Risk Reversal ตัวจริง = Short Put + Long Call → ต้องมี initial slope +1 จาก Short Put ก่อน 90 ซึ่งไม่ตรงกับ s₀=0 ในโจทย์นี้)
Wrong Way / Right Way

Wrong: "จำชื่อ strategy ก่อน แล้วค่อยดูว่า payoff เป็นอย่างไร"

Right: "ดู payoff shape ก่อน → ถอดเป็น slopes → แปลงเป็น legs → ชื่อมาทีหลัง"

ชื่อ strategy เป็นแค่ "ชื่อเล่น" ของ slope pattern — สิ่งที่สำคัญคือ slope decomposition
