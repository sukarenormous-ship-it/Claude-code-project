บทที่ 1: พื้นฐาน — อ่าน Payoff Chart ให้เป็น

Payoff Chart คืออะไร?

Payoff Chart (กราฟผลตอบแทน) คือกราฟที่แสดง กำไรหรือขาดทุนสุทธิ ของตำแหน่ง Options ณ วันหมดอายุ (expiration) โดยเทียบกับราคาสินทรัพย์อ้างอิง (underlying asset) ที่เป็นไปได้ทุกระดับ กราฟนี้เป็นเครื่องมือสำคัญที่สุดในการทำความเข้าใจ Options เพราะมันแปลงสูตรที่ซับซ้อนให้กลายเป็นภาพที่เข้าใจได้ทันที

องค์ประกอบของกราฟ

  • แกน X (แนวนอน) = ราคาสินทรัพย์อ้างอิง ณ วันหมดอายุ (S) — แสดงทุกสถานการณ์ราคาที่เป็นไปได้
  • แกน Y (แนวตั้ง) = กำไร/ขาดทุนสุทธิ (Profit/Loss) — ค่าบวกคือกำไร ค่าลบคือขาดทุน
  • เส้นศูนย์ (Zero Line) = เส้นแนวนอนที่ Y = 0 แบ่งกราฟเป็นโซนกำไร (ด้านบน) และโซนขาดทุน (ด้านล่าง)
  • จุดคุ้มทุน (Break-even Point) = จุดที่เส้น Payoff ตัดกับเส้นศูนย์ — ณ จุดนี้ไม่กำไรไม่ขาดทุน

องค์ประกอบสำคัญที่ต้องรู้

Strike Price (ราคาใช้สิทธิ์) — K

คือราคาที่ตกลงไว้ล่วงหน้าว่าจะซื้อ/ขายสินทรัพย์อ้างอิง เป็นจุดที่กราฟ "หักศอก" (kink point) เพราะเป็นจุดที่พฤติกรรมของ Option เปลี่ยนจาก out-of-the-money เป็น in-the-money

Premium (ค่าพรีเมียม) — P

คือราคาที่ผู้ซื้อจ่ายให้ผู้ขายเพื่อได้สิทธิ์ ถือเป็น ต้นทุน ของผู้ซื้อ (จุดเริ่มต้นบนแกน Y จะอยู่ที่ -Premium) และเป็น รายได้ ของผู้ขาย (จุดเริ่มต้นบนแกน Y จะอยู่ที่ +Premium)

Break-even Point (จุดคุ้มทุน)

สำหรับ Call Option: Break-even = K + P (ราคาต้องขึ้นไปเกิน Strike + Premium จึงจะเริ่มกำไร)
สำหรับ Put Option: Break-even = K - P (ราคาต้องลงต่ำกว่า Strike - Premium จึงจะเริ่มกำไร)

Intrinsic Value (มูลค่าแท้จริง)

คือส่วนที่ Option อยู่ In the Money — มูลค่าที่จะได้จริงถ้าใช้สิทธิ์ตอนนี้
Call Intrinsic = max(0, S - K) | Put Intrinsic = max(0, K - S)

Time Value (มูลค่าเวลา)

Time Value = Premium - Intrinsic Value = "ความหวัง" ที่ว่าราคาอาจจะเคลื่อนเข้ามาใน In the Money ก่อนหมดอายุ ยิ่งเหลือเวลามาก Time Value ยิ่งสูง

จำไว้!

Payoff Chart ณ วันหมดอายุ: Time Value = 0 ดังนั้นเส้น Payoff จะเป็น เส้นตรงหักศอก เสมอ (piecewise linear) ไม่มีเส้นโค้ง! ความเรียบง่ายนี้ทำให้เราวิเคราะห์ได้ง่าย

บทที่ 2: Building Blocks — 4 ตำแหน่งพื้นฐาน

กลยุทธ์ Options ทุกอย่างในโลกนี้สร้างจากการรวมกันของ 4 ตำแหน่งพื้นฐาน ถ้าเข้าใจ 4 ตำแหน่งนี้อย่างถ่องแท้ คุณจะสามารถวิเคราะห์กลยุทธ์ใดก็ได้

2.1 Long Call — ซื้อสิทธิ์ซื้อ

หลักการ: คุณจ่ายเงิน (Premium) เพื่อซื้อ สิทธิ์ (ไม่ใช่ภาระผูกพัน) ในการซื้อสินทรัพย์อ้างอิงในราคา K ภายในวันหมดอายุ ใช้เมื่อคุณเชื่อว่าราคาจะ ขึ้น

สูตร Payoff

Payoff = max(0, S - K) - Premium

ถ้า S ≤ K: Payoff = -Premium (ไม่ใช้สิทธิ์ เสียแค่ค่า Premium)
ถ้า S > K: Payoff = S - K - Premium (ใช้สิทธิ์ซื้อที่ K แล้วขายที่ S)

รายการค่า
Max Profit (กำไรสูงสุด)ไม่จำกัด (Unlimited) — ราคาขึ้นได้ไม่มีเพดาน
Max Loss (ขาดทุนสูงสุด)Premium — จำกัดแค่เงินที่จ่ายไป
Break-evenK + Premium
รูปร่างแบนที่ -P ทางซ้ายของ K แล้วลาดขึ้น 45°
เปรียบเทียบ: "ตั๋วรถไฟ"

ลองนึกว่าคุณซื้อตั๋วรถไฟราคา P บาท ถ้ารถไฟออก (ราคาขึ้นเกิน K) คุณก็ได้โดยสารไปด้วยกับขบวนราคาที่พุ่งขึ้น กำไรไม่จำกัด! แต่ถ้ารถไฟไม่ออก (ราคาไม่ถึง K) คุณก็เสียแค่ค่าตั๋ว — จบ ไม่เจ็บตัวมาก

คำถามชวนคิด

ถ้า Premium แพงมาก จุด Break-even จะยิ่งห่างจาก K — หมายความว่าราคาต้องขึ้นมากกว่าจึงจะเริ่มกำไร คุณยังอยากซื้อไหม? นี่คือเหตุผลที่ Premium (และ Implied Volatility) สำคัญมาก

2.2 Short Call — ขายสิทธิ์ซื้อ

หลักการสำคัญ: Short = พลิก Long กลับหัว (mirror through zero line) คุณ ขาย สิทธิ์ซื้อให้คนอื่น แล้วรับ Premium เป็นรายได้ คุณมี ภาระผูกพัน ที่จะต้องขายสินทรัพย์ที่ราคา K ถ้าผู้ซื้อใช้สิทธิ์

สูตร Payoff

Payoff = Premium - max(0, S - K) = -1 × Long Call Payoff

รายการค่า
Max ProfitPremium — ได้แค่ค่า Premium ที่รับมา
Max Lossไม่จำกัด (Unlimited!) — อันตรายมาก!
Break-evenK + Premium
เปรียบเทียบ: "บริษัทประกัน"

คุณเป็นเหมือนบริษัทประกัน เก็บเบี้ย (Premium) ทุกปี ส่วนใหญ่ลูกค้าไม่เคลม (ราคาไม่ขึ้นเกิน K) คุณก็ได้กำไรเรื่อยๆ แต่ถ้าเกิดเหตุร้ายแรง (ราคาพุ่งสูงมาก) คุณอาจต้องจ่ายมหาศาล ความเสี่ยงไม่จำกัด!

คำเตือน

Naked Short Call (ขาย Call โดยไม่มีสินทรัพย์อ้างอิง) ถือเป็นตำแหน่งที่มีความเสี่ยงสูงที่สุดใน Options เพราะขาดทุนได้ไม่จำกัด นักลงทุนมือใหม่ไม่ควรใช้!

2.3 Long Put — ซื้อสิทธิ์ขาย

หลักการ: คุณจ่ายเงิน (Premium) เพื่อซื้อ สิทธิ์ในการขาย สินทรัพย์อ้างอิงในราคา K ภายในวันหมดอายุ ใช้เมื่อคุณเชื่อว่าราคาจะ ลง

สูตร Payoff

Payoff = max(0, K - S) - Premium

ถ้า S ≥ K: Payoff = -Premium (ไม่ใช้สิทธิ์ เสียแค่ค่า Premium)
ถ้า S < K: Payoff = K - S - Premium (ซื้อที่ S ในตลาด แล้วใช้สิทธิ์ขายที่ K)

รายการค่า
Max ProfitK - Premium — กำไรสูงสุดเมื่อราคาลงไปเป็น 0
Max LossPremium — จำกัดแค่เงินที่จ่ายไป
Break-evenK - Premium
รูปร่างลาดลงจากซ้าย (slope -1) แล้วแบนที่ -P ทางขวาของ K
เปรียบเทียบ: "ประกันอัคคีภัย"

Long Put เหมือนซื้อประกันไฟไหม้ คุณจ่ายเบี้ยประกัน (Premium) ทุกปี ถ้าบ้านไม่ไหม้ (ราคาไม่ลง) คุณเสียแค่เบี้ย แต่ถ้าบ้านไหม้ (ราคาร่วง) ประกันจ่ายชดเชย — ยิ่งเสียหายมาก ยิ่งได้คืนมาก

คำถามชวนคิด

ทำไม Max Profit ของ Long Put ไม่ใช่ "ไม่จำกัด" เหมือน Long Call? เพราะราคาสินทรัพย์ต่ำสุดได้แค่ 0 ดังนั้น Max Profit = K - Premium (เมื่อ S = 0)

2.4 Short Put — ขายสิทธิ์ขาย

หลักการ: ใช้หลัก "พลิกกราฟ" เดียวกับ Short Call คุณขายสิทธิ์ขายให้คนอื่น รับ Premium แต่มีภาระผูกพันที่จะต้อง ซื้อ สินทรัพย์ที่ราคา K ถ้าผู้ซื้อใช้สิทธิ์

สูตร Payoff

Payoff = Premium - max(0, K - S) = -1 × Long Put Payoff

รายการค่า
Max ProfitPremium — ได้แค่ค่า Premium ที่รับมา
Max LossK - Premium — ขาดทุนสูงสุดเมื่อราคาลงไปเป็น 0
Break-evenK - Premium
เปรียบเทียบ: "รับจ้างซื้อหุ้น"

Short Put เหมือนคุณบอกว่า "ถ้าหุ้นลงมาถึง K ผมยินดีซื้อ" แล้วมีคนจ่ายเงินให้คุณเพื่อรับประกันนั้น ถ้าหุ้นไม่ลง — ได้เงินฟรี ถ้าหุ้นลง — ก็ต้องซื้อจริงตามที่รับปาก

ตารางสรุป 4 ตำแหน่งพื้นฐาน

ตำแหน่ง Max Profit Max Loss Break-even รูปร่าง ใช้เมื่อ
Long Call Unlimited Premium K + P แบน แล้วลาดขึ้น คาดว่าราคาขึ้น
Short Call Premium Unlimited K + P แบน แล้วลาดลง คาดว่าราคาไม่ขึ้น
Long Put K - P Premium K - P ลาดลง แล้วแบน คาดว่าราคาลง
Short Put Premium K - P K - P ลาดขึ้น แล้วแบน คาดว่าราคาไม่ลง

2.5 Put-Call Parity — ความสัมพันธ์ระหว่าง Call กับ Put

สมการ Put-Call Parity

C + PV(K) = P + S

หรือเขียนแบบเต็ม: C + K·e-rT = P + S

โดยที่ C = ราคา Call, P = ราคา Put (Strike เดียวกัน, หมดอายุเดียวกัน), S = ราคาสินทรัพย์ปัจจุบัน, K = Strike, r = อัตราดอกเบี้ย, T = เวลาจนหมดอายุ

พิสูจน์ ณ วันหมดอายุ

สร้าง 2 Portfolio แล้วดูว่าให้ผลลัพธ์เท่ากัน:

  • Portfolio A: Long Call + เงินสด K (ฝากธนาคาร)
  • Portfolio B: Long Put + Long Stock (S)

กรณี S > K (ราคาขึ้น):

  • Portfolio A: ใช้สิทธิ์ Call ได้ (S - K) + เงินสด K = S
  • Portfolio B: Put ไม่มีค่า (0) + หุ้น S = S

กรณี S < K (ราคาลง):

  • Portfolio A: Call ไม่มีค่า (0) + เงินสด K = K
  • Portfolio B: ใช้สิทธิ์ Put ได้ (K - S) + หุ้น S = K

ทั้งสองกรณีให้ผลลัพธ์ = max(S, K) เท่ากัน! ดังนั้นวันนี้ราคาต้องเท่ากัน: C + PV(K) = P + S

ความหมายเชิงลึก

Call กับ Put คือ เหรียญเดียวกัน สองด้าน — ถ้ารู้ราคา Call ก็คำนวณราคา Put ได้ และกลับกัน ถ้าสมการไม่เท่ากัน จะเกิด Arbitrage Opportunity (โอกาสทำกำไรโดยไม่มีความเสี่ยง)

หมายเหตุสำคัญ

Put-Call Parity ใช้ได้กับ European Options เท่านั้น (ใช้สิทธิ์ได้แค่วันหมดอายุ) สำหรับ American Options (ใช้สิทธิ์ได้ก่อนหมดอายุ) จะเป็นอสมการแทน

2.6 Synthetic Positions — ตำแหน่งสังเคราะห์

จาก Put-Call Parity เราสามารถจัดรูปสมการใหม่เพื่อสร้าง ตำแหน่งสังเคราะห์ (Synthetic) ที่ให้ Payoff เหมือนกับตำแหน่งจริง:

จัดรูปจาก: C + PV(K) = P + S

Synthetic Long Stock = Long Call + Short Put (Strike & Expiry เดียวกัน)
    S = C - P + PV(K)

Synthetic Long Call = Long Stock + Long Put
    C = S + P - PV(K)

Synthetic Long Put = Short Stock + Long Call
    P = C - S + PV(K)

ทำไมต้องใช้ Synthetic?

  • ต้นทุนต่ำกว่า: บางครั้ง Synthetic ถูกกว่าตำแหน่งจริง เนื่องจากความแตกต่างของ bid-ask spread
  • ยืมหุ้นไม่ได้: ถ้าต้องการ Short Stock แต่ยืมหุ้นไม่ได้ ใช้ Synthetic Short Stock (Short Call + Long Put) แทน
  • Arbitrage: ถ้าราคา Synthetic ไม่เท่ากับราคาจริง สามารถทำกำไรจากส่วนต่างได้

บทที่ 3: หลักการรวม — การบวก Payoff

หลักการบวก Payoff (Payoff Addition Principle)

Payoff รวม = ∑ Payoff แต่ละขา ณ ทุกจุดราคา

กลยุทธ์ Options ทุกกลยุทธ์ ไม่ว่าจะซับซ้อนแค่ไหน ล้วนเกิดจากการ บวกเส้น Payoff ของแต่ละขา (leg) เข้าด้วยกัน ณ ทุกจุดราคา ไม่มีเวทมนตร์ใดในกลยุทธ์ Options — ทุกอย่างคือการบวกเส้นตรง!

ตัวอย่างการคำนวณ: Bull Call Spread

สมมติ: Long Call K=100, P=8 + Short Call K=110, P=3

ราคา ณ หมดอายุ (S) Long Call 100
(max(0,S-100)-8)		 Short Call 110
(3-max(0,S-110))		 Payoff รวม

95-8+3-5
100-8+3-5
105-3+30 (BE!)

วิธีวิเคราะห์รูปร่างจากความชัน (Slope Analysis)

แทนที่จะคำนวณทีละจุด เราสามารถวิเคราะห์ ความชัน (slope) ของแต่ละส่วนได้เร็วกว่า:

ตำแหน่ง ผลต่อ Slope ณ จุดไหน
Long Call (K) +1 ต่อ slope ที่ Strike K (เริ่มเพิ่มทางขวา)
Short Call (K) -1 ต่อ slope ที่ Strike K (เริ่มลดทางขวา)
Long Put (K) +1 ต่อ slope (ทางซ้าย) ที่ Strike K (ยิ่งไปซ้ายยิ่งชัน = slope -1 จากขวาไปซ้าย)
Short Put (K) -1 ต่อ slope (ทางซ้าย) ที่ Strike K
เคล็ดลับ: อ่านรูปร่างจาก Slope

เริ่มจากซ้ายสุดของกราฟ แล้วเดินไปทางขวา ทุกครั้งที่ผ่าน Strike:

  • Long Call ที่ K → slope เพิ่ม +1
  • Short Call ที่ K → slope ลด -1
  • Long Put ที่ K → slope ลด -1 (เพราะ put มี slope -1 ทางซ้ายของ K ซึ่งหายไปทางขวา)
  • Short Put ที่ K → slope เพิ่ม +1

วิธีนี้ช่วยให้คุณวาดรูปร่าง Payoff ได้โดยไม่ต้องคำนวณทุกจุด!

ตัวอย่าง: Bull Call Spread ด้วย Slope Analysis

Long Call K₁=100 + Short Call K₂=110:

  • ซ้ายสุด (S < 100): slope = 0 (ยังไม่ผ่าน strike ใด)
  • ผ่าน K₁=100 (Long Call): slope = 0 + 1 = +1 (ลาดขึ้น)
  • ผ่าน K₂=110 (Short Call): slope = +1 - 1 = 0 (แบนอีกครั้ง)

ผลลัพธ์: แบน → ลาดขึ้น → แบน = รูปร่าง "บันไดขึ้น" !

บทที่ 4: Named Strategies — "พจนานุกรม" ที่ต้องรู้

เมื่อเข้าใจหลักการรวม Payoff แล้ว มาดูกลยุทธ์ที่มีชื่อเรียกกันทั่วไป แต่ละกลยุทธ์คือ การรวม 4 ตำแหน่งพื้นฐาน ในรูปแบบต่างๆ เท่านั้น

4.1 Bull Call Spread — "บันไดขึ้น"

ส่วนประกอบ

Long Call K₁ + Short Call K₂ (โดย K₂ > K₁)

แนวคิด: คุณเชื่อว่าราคาจะขึ้นแต่ ไม่มากเกินไป จึงซื้อ Call ที่ Strike ต่ำ (เพื่อทำกำไรจากขาขึ้น) แล้วขาย Call ที่ Strike สูง (เพื่อลดต้นทุน แลกกับการจำกัดกำไรสูงสุด)

Net Premium = P₁ - P₂ (จ่ายสุทธิ เพราะ P₁ > P₂)
Max Profit = (K₂ - K₁) - Net Premium
Max Loss = Net Premium
Break-even = K₁ + Net Premium
รายการค่า
Max Profit(K₂ - K₁) - Net Premium
Max LossNet Premium (จำกัด)
Break-evenK₁ + Net Premium
มุมมองตลาดModerately Bullish (ราคาจะขึ้นปานกลาง)

4.2 Bear Put Spread — "บันไดลง"

ส่วนประกอบ

Long Put K₂ + Short Put K₁ (โดย K₂ > K₁)

แนวคิด: "กระจกสะท้อน" ของ Bull Call Spread คุณเชื่อว่าราคาจะลงแต่ไม่มากเกินไป ซื้อ Put ที่ Strike สูง แล้วขาย Put ที่ Strike ต่ำเพื่อลดต้นทุน

Net Premium = P₂ - P₁ (จ่ายสุทธิ เพราะ Put ที่ K₂ แพงกว่า)
Max Profit = (K₂ - K₁) - Net Premium
Max Loss = Net Premium
Break-even = K₂ - Net Premium
รายการค่า
Max Profit(K₂ - K₁) - Net Premium
Max LossNet Premium (จำกัด)
Break-evenK₂ - Net Premium
มุมมองตลาดModerately Bearish (ราคาจะลงปานกลาง)

4.3 Long Straddle — รูป "V"

ส่วนประกอบ

Long Call K + Long Put K (Strike เดียวกัน)

แนวคิด: คุณเชื่อว่าราคาจะ เคลื่อนไหวมาก แต่ไม่รู้ว่าจะขึ้นหรือลง เช่น ก่อนประกาศงบ, ก่อนการเลือกตั้ง, ก่อนการตัดสินใจนโยบาย

Total Premium = PCall + PPut
Max Loss = Total Premium (เกิดที่ S = K พอดี)
Max Profit = Unlimited (ขาขึ้น) หรือ K - Total Premium (ขาลง)
BE บน = K + Total Premium
BE ล่าง = K - Total Premium
รายการค่า
Max Profitไม่จำกัด (ขาขึ้น) / K - Total Premium (ขาลง)
Max LossTotal Premium (ณ S = K)
BE บนK + Total Premium
BE ล่างK - Total Premium
มุมมองตลาดHigh Volatility คาดการณ์ (ไม่รู้ทิศทาง)
ข้อควรระวัง

Straddle มีต้นทุนสูง (ซื้อทั้ง Call และ Put) ดังนั้นราคาต้องเคลื่อนไหว มากพอ ที่จะเกินจุด Break-even ทั้งสองด้าน ถ้าราคานิ่ง คุณจะขาดทุนจาก Time Decay ทั้ง 2 ขา!

4.4 Long Strangle — รูป "V กว้าง / U"

ส่วนประกอบ

Long Put K₁ + Long Call K₂ (K₁ < K₂, ทั้งคู่ OTM)

แนวคิด: เหมือน Straddle แต่ ถูกกว่า เพราะซื้อ OTM Options แลกกับต้องการการเคลื่อนไหวราคามากกว่าจึงจะกำไร

เปรียบเทียบ Straddle vs Strangle

รายการLong StraddleLong Strangle
StrikesCall & Put ที่ K เดียวกันPut ที่ K₁ < Call ที่ K₂
ต้นทุน (Premium)สูงกว่าต่ำกว่า
Max LossTotal PremiumTotal Premium (ต่ำกว่า)
BE ห่างจาก ATMน้อยกว่ามากกว่า
ต้องการความผันผวนปานกลางมาก
Probability of Profitสูงกว่าต่ำกว่า

4.5 Iron Condor — "ที่ราบสูง"

ส่วนประกอบ (4 ขา)

Bull Put Spread + Bear Call Spread

= Short Put K₁ + Long Put K₂ + Short Call K₃ + Long Call K₄

(K₁ < K₂ < K₃ < K₄ โดยปกติ K₂ และ K₃ ใกล้ ATM)

หรือแบบง่าย: Long Put K₁ + Short Put K₂ + Short Call K₃ + Long Call K₄

แนวคิด: คุณเชื่อว่าราคาจะ นิ่ง อยู่ในกรอบ K₂ ถึง K₃ รับ Premium จากการขาย แล้วซื้อ Options ด้านนอกเพื่อจำกัดความเสี่ยง

Net Credit = Premium รับ (Short Put K₂ + Short Call K₃) - Premium จ่าย (Long Put K₁ + Long Call K₄)
Max Profit = Net Credit (เมื่อ K₂ ≤ S ≤ K₃)
Max Loss = Width of spread - Net Credit = (K₂ - K₁) - Net Credit
BE ล่าง = K₂ - Net Credit
BE บน = K₃ + Net Credit
รายการค่า
Max ProfitNet Credit
Max Loss(K₂ - K₁) - Net Credit (จำกัด!)
มุมมองตลาดNeutral / Low Volatility
ข้อดีDefined risk ทั้ง 2 ด้าน, Probability of profit สูง

4.6 Butterfly Spread — "เต็นท์"

ส่วนประกอบ

Long Call K₁ + Short 2× Call K₂ + Long Call K₃

(K₁ < K₂ < K₃ โดย K₂ = (K₁+K₃)/2 คือจุดกึ่งกลาง)

แนวคิด: คุณมั่นใจว่าราคาจะ จบตรงจุดเดียว (K₂ พอดี) กำไรสูงสุดเกิดที่ K₂ และลดลงอย่างรวดเร็วเมื่อออกห่าง

พิสูจน์ด้วย Slope Analysis

  • S < K₁: slope = 0
  • ผ่าน K₁ (Long Call): slope = 0 + 1 = +1
  • ผ่าน K₂ (Short 2× Call): slope = +1 - 2 = -1
  • ผ่าน K₃ (Long Call): slope = -1 + 1 = 0

ผลลัพธ์: แบน → ขึ้น → ลง → แบน = รูป "เต็นท์" หรือ "หมวก"!

Net Premium = P₁ - 2×P₂ + P₃ (จ่ายสุทธิ)
Max Profit = (K₂ - K₁) - Net Premium (ณ S = K₂)
Max Loss = Net Premium
BE ล่าง = K₁ + Net Premium
BE บน = K₃ - Net Premium
รายการค่า
Max Profit(K₂ - K₁) - Net Premium (ณ S = K₂ พอดี)
Max LossNet Premium (จำกัด)
มุมมองตลาดNeutral / Pin to specific price

บทที่ 5: Greeks — อะไรทำให้ Payoff เปลี่ยนก่อนหมดอายุ

จนถึงตอนนี้เราดูแต่ Payoff ณ วันหมดอายุ (เส้นตรงหักศอก) แต่ในโลกจริง Options มีมูลค่าที่เปลี่ยนแปลงทุกวัน Greeks คือตัวเลขที่บอกว่า ราคา Option จะเปลี่ยนอย่างไร เมื่อปัจจัยต่างๆ เปลี่ยน

5.1 Payoff ก่อน vs หลังหมดอายุ

  • ณ วันหมดอายุ: เส้นตรงหักศอก (intrinsic value only) — Time Value = 0
  • ก่อนหมดอายุ: เส้นโค้งมน (intrinsic + time value) — เส้นจะอยู่ สูงกว่า เส้นหมดอายุเสมอ
  • ยิ่งเหลือเวลามาก เส้นโค้งยิ่งอยู่สูงกว่า เพราะ Time Value ยิ่งมาก
Black-Scholes Model

คือสูตรที่คำนวณเส้นโค้งก่อนหมดอายุ โดยใช้ 5 ตัวแปร:

  1. S — ราคาสินทรัพย์อ้างอิงปัจจุบัน
  2. K — Strike Price
  3. T — เวลาจนหมดอายุ (ปี)
  4. σ — Volatility (ความผันผวน)
  5. r — อัตราดอกเบี้ยปลอดความเสี่ยง

5.2 Delta (Δ) — ความชันของ Payoff Curve

นิยาม

Δ = ∂V/∂S ≈ การเปลี่ยนของราคา Option เมื่อราคาสินทรัพย์เปลี่ยน ฿1

  • Call Delta: อยู่ระหว่าง 0 ถึง +1 (ATM ≈ 0.5)
  • Put Delta: อยู่ระหว่าง -1 ถึง 0 (ATM ≈ -0.5)
  • Deep ITM → Delta ≈ ±1 (เคลื่อนไหวเกือบเท่าสินทรัพย์อ้างอิง)
  • Deep OTM → Delta ≈ 0 (แทบไม่เคลื่อนไหว)
ใช้ทำอะไร?
  • ประมาณการเปลี่ยนแปลงราคา: ถ้า Delta = 0.6 และหุ้นขึ้น ฿10 → Option ขึ้นประมาณ ฿6
  • Hedge Ratio: ถ้าถือ 1 สัญญา Call (Δ = 0.6) ต้อง Short หุ้น 0.6 หุ้นเพื่อ Hedge (Delta Neutral)
  • ความน่าจะเป็นโดยประมาณ: Delta ≈ ความน่าจะเป็นที่ Option จะ ITM ณ วันหมดอายุ

5.3 Gamma (Γ) — อัตราเปลี่ยนของ Delta

นิยาม

Γ = ∂Δ/∂S = ∂²V/∂S²

Gamma คือ "อนุพันธ์อันดับ 2" — บอกว่า Delta เปลี่ยนเร็วแค่ไหนเมื่อราคาสินทรัพย์เปลี่ยน

  • Gamma สูงสุด ที่ ATM — Delta เปลี่ยนเร็วที่สุดบริเวณนี้
  • Gamma ต่ำ เมื่อ Deep ITM หรือ Deep OTM — Delta แทบไม่เปลี่ยน
  • Gamma สูง = ต้อง rebalance hedge บ่อย (ต้นทุน hedging สูง)
  • ยิ่งใกล้หมดอายุ Gamma ยิ่งสูงที่ ATM — เส้นโค้งยิ่งแหลมคม เปลี่ยนจาก OTM เป็น ITM ได้อย่างรวดเร็ว
จำง่ายๆ

Delta บอก "ความเร็ว" ของราคา Option, Gamma บอก "ความเร่ง" ของ Delta เหมือนรถยนต์: Delta = ความเร็ว, Gamma = คันเร่ง

5.4 Theta (Θ) — Time Decay

นิยาม

Θ = ∂V/∂t = มูลค่าที่หายไปทุกวัน

  • Theta เป็นลบ สำหรับ Long Options — ค่า Option ลดลงทุกวันที่ผ่านไป
  • Theta เป็นบวก สำหรับ Short Options — ได้ประโยชน์จาก time decay
  • Time decay เร็วขึ้นแบบ non-linear เมื่อใกล้หมดอายุ — ช่วง 30 วันสุดท้ายสูญเสียเร็วที่สุด
  • Theta สูงสุดที่ ATM (เพราะ Time Value สูงสุดที่ ATM)
"Time Decay เป็นเพื่อนของคนขาย เป็นศัตรูของคนซื้อ"

ผู้ขาย Options ได้เปรียบจากเวลาที่ผ่านไป — ทุกวันที่นอนหลับ Option ที่ขายไว้ก็ลดค่าลง เข้ากระเป๋าเรื่อยๆ ส่วนผู้ซื้อต้องแข่งกับเวลา ราคาต้องเคลื่อนไหวเร็วพอที่จะชนะ Time Decay

5.5 Vega (ν) — ผลกระทบจากความผันผวน

นิยาม

ν = ∂V/∂σ = การเปลี่ยนราคา Option เมื่อ Volatility เปลี่ยน 1%

  • Vega สูงสุดที่ ATM — Options ที่ ATM ไวต่อความผันผวนมากที่สุด
  • Long Options มี Vega บวก — ได้ประโยชน์เมื่อ volatility สูงขึ้น
  • Short Options มี Vega ลบ — ได้ประโยชน์เมื่อ volatility ลดลง
  • ยิ่งเหลือเวลามาก Vega ยิ่งสูง (Options ไกลหมดอายุไวต่อ vol มากกว่า)

Implied Volatility vs Historical Volatility

  • Historical Volatility (HV): ความผันผวนที่เกิดขึ้นจริงในอดีต (วัดจากข้อมูลราคาที่ผ่านมา)
  • Implied Volatility (IV): ความผันผวนที่ตลาด "คาดการณ์" ในอนาคต (คำนวณกลับจากราคา Option ในตลาด)
  • ถ้า IV > HV: ตลาดคาดว่าจะผันผวนมากกว่าปกติ → Options แพง
  • ถ้า IV < HV: ตลาดคาดว่าจะผันผวนน้อยกว่าปกติ → Options ถูก

ตาราง Greeks สรุป

Greek Long Call Short Call Long Put Short Put
Delta (Δ) +0 ถึง +1 -1 ถึง 0 -1 ถึง 0 +0 ถึง +1
Gamma (Γ) + (บวก) - (ลบ) + (บวก) - (ลบ)
Theta (Θ) - (ลบ) เสียเวลา + (บวก) ได้เวลา - (ลบ) เสียเวลา + (บวก) ได้เวลา
Vega (ν) + (บวก) ได้ vol - (ลบ) เสีย vol + (บวก) ได้ vol - (ลบ) เสีย vol
สรุป Greeks ง่ายๆ
  • Long Options: Delta ตามทิศ, Gamma +, Theta -, Vega + (ได้ประโยชน์จาก vol แต่เสียเวลา)
  • Short Options: ตรงข้ามหมด — Gamma -, Theta +, Vega - (ได้เวลาแต่เสีย vol)

บทที่ 6: Advanced Combinations — เปลี่ยนจำนวนและเวลา

จนถึงตอนนี้เราใช้ Options ที่มี จำนวน contracts เท่ากัน และ หมดอายุพร้อมกัน แต่ถ้าเปลี่ยน 2 ตัวแปรนี้จะเกิดรูปร่าง Payoff ใหม่ที่น่าสนใจ

6.1 Ratio Spreads — "ถ้าจำนวน Contracts ไม่เท่ากันล่ะ?"

ตัวอย่าง: 1×2 Ratio Call Spread

Long 1 Call K₁ + Short 2 Call K₂ (K₂ > K₁)

แนวคิด: เหมือน Bull Call Spread แต่ขาย Call มากกว่าที่ซื้อ ทำให้อาจได้ Credit (ไม่ต้องจ่ายเงิน) แต่แลกกับความเสี่ยงที่ไม่จำกัดทางด้านบน

Slope Analysis

  • S < K₁: slope = 0
  • ผ่าน K₁ (Long 1 Call): slope = 0 + 1 = +1
  • ผ่าน K₂ (Short 2 Call): slope = +1 - 2 = -1

ผลลัพธ์: แบน → ขึ้น → ลง (ลงไม่มีเพดาน!) = รูปร่างเหมือน "เต็นท์ข้างเดียว" ที่ด้านขวามีความเสี่ยงไม่จำกัด

ความเสี่ยง

ขาที่ขายมากกว่า (Short 2 Call) มี 1 ขาที่ไม่ได้ถูก cover ดังนั้นถ้าราคาพุ่งสูงมาก จะขาดทุนไม่จำกัด! Quantity (จำนวน contracts) เป็นอีกตัวแปรที่เปลี่ยนรูปร่าง Payoff ได้ — และอาจเปลี่ยนจาก defined risk เป็น unlimited risk

6.2 Back Ratio Spread — กลับด้าน Ratio

ตัวอย่าง: 1×2 Back Ratio Call Spread

Short 1 Call K₁ + Long 2 Call K₂ (K₂ > K₁)

แนวคิด: กลับด้าน Ratio Spread ปกติ — ซื้อมากกว่าขาย ทำให้ กำไรไม่จำกัด กลับมาทางด้านบน แต่มีช่วง "Dead Zone" ที่ขาดทุน

Slope Analysis

  • S < K₁: slope = 0
  • ผ่าน K₁ (Short 1 Call): slope = 0 - 1 = -1
  • ผ่าน K₂ (Long 2 Call): slope = -1 + 2 = +1

เปรียบเทียบ Ratio vs Back Ratio

รายการRatio Spread (1:2)Back Ratio (1:2)
ขาที่มากกว่าShortLong
ความเสี่ยงทางขวาไม่จำกัดไม่จำกัด (กำไร!)
ต้นทุนอาจได้ Creditอาจต้องจ่าย Debit
เหมาะกับคาดว่าราคาจะขึ้นเล็กน้อยคาดว่าราคาจะขึ้นมาก

6.3 Calendar Spread — "ถ้าวันหมดอายุต่างกันล่ะ?"

ส่วนประกอบ

Short Option (หมดอายุใกล้) + Long Option (หมดอายุไกล)

Strike เดียวกัน แต่ต่างวันหมดอายุ!

แนวคิด: เดิมพันกับ Theta (Time Decay) ขาใกล้จะสูญเสีย Time Value เร็วกว่าขาไกล ดังนั้นเมื่อเวลาผ่านไป ส่วนต่างของ Time Value จะเพิ่มขึ้น = กำไร

ความแตกต่างสำคัญ

Calendar Spread ไม่สามารถวิเคราะห์แบบ "at-expiry payoff" ตรงๆ ได้ เพราะ ณ วันที่ขาใกล้หมดอายุ ขาไกล ยังไม่หมดอายุ — ต้องใช้ Theoretical Price (Black-Scholes) ในการประเมินมูลค่าขาไกล ณ วันนั้น

  • กำไรสูงสุดเมื่อ S = K (ณ วันที่ขาใกล้หมดอายุ) เพราะ Time Value ของขาไกลสูงสุดที่ ATM
  • ขาดทุนเมื่อราคาเคลื่อนไหวไกลจาก K มากเกินไป
  • Payoff เปลี่ยนตามเวลาที่ผ่านไป (ไม่คงที่เหมือน at-expiry strategies)
  • ได้ประโยชน์จาก Implied Volatility ที่สูงขึ้น (Vega บวก)

6.4 Diagonal Spread — ผสมทั้งเวลาและทิศทาง

ส่วนประกอบ

= Calendar Spread + ต่าง Strike

บทที่ 7: ประยุกต์ใช้ — คิดจาก Scenario

ในทางปฏิบัติ เราไม่ได้เริ่มจากกลยุทธ์แล้วหาสถานการณ์ แต่เริ่มจาก มุมมองตลาด แล้วเลือกกลยุทธ์ที่เหมาะสม

7.1 "คิดว่าราคาจะขึ้น"

กลยุทธ์ ต้นทุน Max Loss Max Profit Time Decay Break-even
Long Call Premium (ปานกลาง) Premium Unlimited ศัตรู (Theta -) K + P
Bull Call Spread Net Premium (ต่ำกว่า) Net Premium (K₂-K₁) - Net ปานกลาง K₁ + Net
Long Stock ราคาหุ้นเต็ม (สูงมาก) ราคาหุ้นทั้งหมด Unlimited ไม่มีผล ราคาซื้อ
Trade-off ที่ต้องคิด
  • Long Call: ต้นทุนต่ำ กำไรไม่จำกัด แต่มี Time Decay กัดกินทุกวัน
  • Bull Call Spread: ต้นทุนต่ำสุด Time Decay น้อยกว่า แต่กำไรจำกัด
  • Long Stock: ไม่มี Time Decay แต่ต้นทุนสูงมากและเสี่ยงเต็มราคาหุ้น

Short Straddle ให้ Premium สูงสุดแต่มีความเสี่ยง ไม่จำกัด ทั้งสองด้าน! Iron Condor และ Butterfly ปลอดภัยกว่ามากเพราะเป็น Defined Risk — รู้ล่วงหน้าว่าขาดทุนสูงสุดเท่าไร

7.4 "ต้องการ Hedge"

หลักการ: Hedge = เปลี่ยนรูปร่าง Payoff ของตำแหน่งที่มีอยู่

Protective Put — "ซื้อประกัน"

ส่วนประกอบ

Long Stock + Long Put

จำกัดขาดทุนไว้ที่ (K - S₀ + Premium) ขณะที่ยังมีกำไรไม่จำกัดทางขาขึ้น เหมือนถือหุ้นแล้วซื้อประกันราคา — จ่ายเบี้ยประกัน (Put Premium) แลกกับความอุ่นใจ

Covered Call — "ขายแรงกดดัน"

ส่วนประกอบ

Long Stock + Short Call

เก็บ Premium จาก Call ที่ขาย แลกกับการจำกัดกำไรสูงสุดที่ K ใช้เมื่อคิดว่าหุ้นจะไม่ขึ้นมากนัก — เปลี่ยน "ความหวังว่าจะขึ้นสูงๆ" เป็น "รายได้ที่แน่นอน"

Collar — "ใส่ปลอกคอ"

ส่วนประกอบ

Long Stock + Long Put K₁ + Short Call K₂ (K₁ < S₀ < K₂)

จำกัดทั้งขาดทุน (ด้วย Put) และกำไร (ด้วย Short Call) เหมือน "ใส่ปลอกคอ" ให้ Payoff — ใช้ Premium จาก Short Call มาจ่ายค่า Long Put (อาจได้ Zero-Cost Collar)

Greek สูตร ความหมาย Long Option Short Option สูงสุดเมื่อ

เมื่อสินทรัพย์เปลี่ยน ฿1		 Call: +, Put: - Call: -, Put: + Deep ITM (±1)

หลักการสำคัญ 7 ข้อ — บทสรุป

  1. Payoff = ผลรวมของแต่ละขา — ไม่มีเวทมนตร์ ทุกอย่างคือการบวกเส้นตรง
  2. Short = พลิก Long กลับหัว — กำไรเป็นขาดทุน ขาดทุนเป็นกำไร (mirror through zero)
  3. Put-Call Parity: C + PV(K) = P + S — Call กับ Put คือเหรียญเดียวกัน สองด้าน
  4. Quantity เปลี่ยนรูปร่างได้ — Ratio Spreads สร้างมิติใหม่ แต่ระวังความเสี่ยงที่ไม่จำกัด
  5. เวลาเพิ่มมิติ — Calendar/Diagonal Spreads ทำให้ Payoff เปลี่ยนตามเวลา ไม่คงที่
  6. Greeks บอกว่า Payoff เปลี่ยนอย่างไรก่อนหมดอายุ — Delta, Gamma, Theta, Vega คืออาวุธที่ต้องรู้
  7. ไม่มีกลยุทธ์ที่ดีที่สุด มีแต่กลยุทธ์ที่เหมาะที่สุดกับมุมมองของคุณ — เลือกจาก Scenario ไม่ใช่จากชื่อ

Appendix: สูตรสำคัญ

Put-Call Parity

C + K·e-rT = P + S

Black-Scholes Model

Call: C = S·N(d₁) - K·e-rT·N(d₂)

Put: P = K·e-rT·N(-d₂) - S·N(-d₁)

โดยที่:
d₁ = [ln(S/K) + (r + σ²/2)T] / (σ√T)
d₂ = d₁ - σ√T

N(x) = Cumulative Standard Normal Distribution
N'(x) = Standard Normal PDF = (1/√2π) · e-x²/2

Greeks Formulas

Delta:
ΔCall = N(d₁)
ΔPut = N(d₁) - 1

Gamma:
Γ = N'(d₁) / (S · σ · √T)

Theta:
ΘCall = -S·N'(d₁)·σ / (2√T) - r·K·e-rT·N(d₂)
ΘPut = -S·N'(d₁)·σ / (2√T) + r·K·e-rT·N(-d₂)
(ค่าข้างต้นเป็น per year, หาร 365 เพื่อได้ daily theta)

Vega:
ν = S · N'(d₁) · √T
(ค่าข้างต้นเป็น per 100%, หาร 100 เพื่อได้ per 1% change)

Payoff Formulas (ณ วันหมดอายุ)

Long Call: max(0, S - K) - Premium
Short Call: Premium - max(0, S - K)
Long Put: max(0, K - S) - Premium
Short Put: Premium - max(0, K - S)

หลักการ: Short Payoff = -1 × Long Payoff (เสมอ)
