บทที่ 7: แคลคูลัส — "ภาษาของ Greeks"

Greeks (ค่ากรีก) ทุกตัวคือ Derivative (อนุพันธ์) ของราคา Option (ออปชัน) — ถ้าไม่รู้จักแคลคูลัส (Calculus) ก็ไม่เข้าใจ Greeks อย่างลึกซึ้ง

7.1 Limit (ลิมิต) — แนวคิด "เข้าใกล้"

lim(x→a) f(x) = "เมื่อ x เข้าใกล้ a ค่า f(x) เข้าใกล้เท่าไหร่?"

ตัวอย่าง: lim(x→0) sin(x)/x = 1
x = 0.1 → sin(0.1)/0.1 = 0.9983
x = 0.01 → sin(0.01)/0.01 = 0.99998
x = 0.001 → 0.9999998 → เข้าใกล้ 1!
ทำไมต้องรู้?

Derivative นิยามจาก limit — "ถ้าเปลี่ยน x นิดเดียว y เปลี่ยนเท่าไหร่?"
นี่คือแนวคิดเดียวกับ Delta (เดลตา ความไวต่อราคาสินทรัพย์อ้างอิง): "ถ้าราคาหุ้นเปลี่ยน ฿1 ราคา Option เปลี่ยนเท่าไหร่?"

7.2 Derivative (อนุพันธ์) — อัตราการเปลี่ยนแปลง

f'(x) = อัตราการเปลี่ยนแปลงของ f(x) ณ จุด x = slope (ความชัน) ของเส้นสัมผัส (tangent line)

f'(x) = lim(h→0) [f(x+h) - f(x)] / h

กฎพื้นฐาน:

f(x)f'(x)ชื่อกฎ
xnn × xn-1Power Rule
c (ค่าคงที่)0Constant Rule
c × f(x)c × f'(x)Constant Multiple
f(x) + g(x)f'(x) + g'(x)Sum Rule
exex← อนุพันธ์ของตัวเอง!
ln(x)1/x
เชื่อมกับ Options — Delta!

Delta (Δ) = ∂V/∂S = derivative ของราคา Option (V) เทียบกับราคาหุ้น (S)
= "ถ้าราคาหุ้นขึ้น ฿1 ราคา Option เปลี่ยนเท่าไหร่?"
= slope ของ payoff curve ณ จุดนั้น

7.3 อนุพันธ์ของ ex — ทำไม e สำคัญมาก

d/dx (ex) = ex ← อนุพันธ์ของตัวเอง!
d/dx (eax) = a × eax (Chain Rule)
ทำไมจึงสำคัญใน Finance?

erT คือ compound interest (ดอกเบี้ยทบต้น) → d/dT(erT) = r × erT
หมายความว่า: "อัตราการเติบโตของเงินที่ทบต้น = r × เงินปัจจุบัน"
ยิ่งเงินมาก ยิ่งโตเร็ว — นี่คือ exponential growth (การเติบโตแบบเลขชี้กำลัง)!

7.4 Chain Rule — กฎลูกโซ่

ถ้า y = f(g(x)) แล้ว dy/dx = f'(g(x)) × g'(x)

ตัวอย่าง: y = e-rT หา dy/dT

ให้ u = -rT → y = eu
dy/dT = dy/du × du/dT = eu × (-r) = -r × e-rT
เชื่อมกับ Options

Chain Rule (กฎลูกโซ่) คือพื้นฐานของ Ito's Lemma (บทตั้งของอิโต) (บท 14) — "chain rule ของโลกสุ่ม" ที่ใช้ derive (อนุมาน) สูตร Black-Scholes (แบบจำลองแบล็ก-โชลส์)

7.5 Partial Derivatives — อนุพันธ์ย่อย

เมื่อฟังก์ชันมีหลายตัวแปร: ∂f/∂x = "เปลี่ยน x ค้าง y" (treat y as constant)

ตัวอย่าง: f(x, y) = x²y + 3xy

∂f/∂x = 2xy + 3y    (treat y เป็นค่าคงที่)
∂f/∂y = x² + 3x     (treat x เป็นค่าคงที่)
เชื่อมกับ Options — Greeks ทุกตัว!

ราคา Option V ขึ้นกับหลายตัวแปร: V(S, t, σ, r) ดังนั้น:

Greekสูตรความหมายเปลี่ยนอะไร ค้างอะไร
Δ Delta∂V/∂Sราคาเปลี่ยนเท่าไหร่ต่อหุ้นขยับ ฿1เปลี่ยน S, ค้าง t,σ,r
Θ Theta∂V/∂tราคาเปลี่ยนเท่าไหร่ต่อวันเปลี่ยน t, ค้าง S,σ,r
ν Vega∂V/∂σราคาเปลี่ยนเท่าไหร่ต่อ σ เปลี่ยน 1%เปลี่ยน σ, ค้าง S,t,r
ρ Rho∂V/∂rราคาเปลี่ยนเท่าไหร่ต่อดอกเบี้ยเปลี่ยนเปลี่ยน r, ค้าง S,t,σ

7.6 อนุพันธ์อันดับ 2 — Gamma

f''(x) = อนุพันธ์ของอนุพันธ์ = อัตราการเปลี่ยนแปลงของ slope

Gamma (Γ) = ∂²V/∂S² = ∂(Delta)/∂S
= "Delta เปลี่ยนเท่าไหร่ เมื่อราคาหุ้นเปลี่ยน ฿1"
ทำไม Gamma สำคัญ?

• Gamma สูง = Delta เปลี่ยนเร็ว = ต้อง rehedge บ่อย
• Gamma สูงสุดที่ ATM → Options ที่ ATM ต้องการ hedging มากที่สุด
• Long Gamma = กำไรจาก volatility, Short Gamma = เสียจาก volatility

7.7 อินทิกรัล (Integration) เบื้องต้น

∫f(x)dx = "พื้นที่ใต้กราฟ" = กระบวนการย้อนกลับของ derivative

∫xn dx = xn+1/(n+1) + C
∫ex dx = ex + C
∫(1/x) dx = ln|x| + C
เชื่อมกับ Options

• CDF ของ Normal = ∫ PDF → N(d) = ∫ ของ bell curve = "พื้นที่ใต้กราฟทางซ้าย"
• Expected Value ของ continuous dist = ∫ x × f(x) dx
• ราคา Option = ∫ payoff × probability density = Expected Payoff

7.8 Taylor Series — ประมาณค่า

f(x+h) ≈ f(x) + f'(x)×h + ½f''(x)×h² + ...
เชื่อมกับ Options — Delta-Gamma Approximation!

เปลี่ยน S เป็น S+ΔS:
ΔV ≈ Delta × ΔS + ½ × Gamma × (ΔS)²

term แรก (Delta×ΔS) = ประมาณเชิงเส้น
term ที่สอง (½Gamma×ΔS²) = correction สำหรับความโค้ง
นี่คือ Taylor expansion 2 term ใช้ใน risk management ทุกวัน!
