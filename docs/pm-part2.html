บทที่ 5: 2-Step Slope Method — "วิธีวาด Payoff ที่เร็วที่สุด"

🚶 อ่านเป็นภาษาคนก่อน: แทนที่จะจำรูปทรงเป็นสิบ ๆ ชื่อ ให้มองทุก payoff เป็น "เส้นเดินทาง" — เริ่มที่ระดับหนึ่งทางซ้ายสุด แล้วเดินไปทางขวา ทุกครั้งที่เจอ strike ให้ปรับความชัน (slope) ตามกฎง่าย ๆ 4 ข้อ วิธีนี้สร้าง payoff อะไรก็ได้ไม่จำกัดจำนวนขา โดยไม่ต้องจำชื่อ strategy สักชื่อเดียว

วิธี 2 ขั้นตอน

Step 1: หา Starting Level = net premium จ่าย/รับ (กำหนด y ที่ปลายซ้ายสุด)

Step 2: เดินจากซ้ายไปขวา ทุก strike ที่เจอ → ปรับ slope ตามกฎ:

Option Legปรับ Slope ที่ Strikeตัวอย่าง
Long Call(K)+1slope เปลี่ยนจาก 0→+1
Short Call(K)−1slope เปลี่ยนจาก 0→−1
Long Put(K)+1slope เปลี่ยนจาก −1→0
Short Put(K)−1slope เปลี่ยนจาก +1→0

ตัวอย่าง: Bull Call Spread (Long Call K₁=90, Short Call K₂=110, Net Premium=5)

🧮 ตัวอย่างการใช้งาน — เดินทีละขั้น

Step 1: Net premium จ่าย = −5 → starting level (ปลายซ้าย) = −5

Step 2: เดินจากซ้ายไปขวา:

  • ก่อน K₁=90: slope = 0 → แบนที่ −5
  • ที่ K₁=90: Long Call → slope +1 → slope เปลี่ยนเป็น 0+1 = +1
  • ที่ K₂=110: Short Call → slope −1 → slope เปลี่ยนเป็น +1−1 = 0
  • หลัง K₂: slope = 0 → แบนที่ −5+(110−90)×1 = +15

ผลลัพธ์: แบน(−5) → ชัน(+1) → แบน(+15) = Bull Call Spread!

Net profit (หลังหัก premium)

กฎทอง: Net Slope ที่ปลายขวา

ถ้า net slope = 0 → payoff bounded (จำกัด) → ดี!

ถ้า net slope ≠ 0 → payoff unbounded (ไม่จำกัด) → ระวัง!

🎯 3 อย่างที่ต้องจำ
  • Step 1: Starting level = net premium (ปลายซ้าย)
  • Step 2: เดินขวา ปรับ slope ที่ทุก strike
  • Net slope = 0 → bounded | ≠ 0 → unbounded (unlimited risk!)

บทที่ 6: 2-Leg Strategies — Spreads + Straddle/Strangle

🚶 อ่านเป็นภาษาคนก่อน: ทุก strategy ในบทนี้ใช้แค่ 2-Step Slope Method จากบทที่แล้ว เอา 2 ขามาต่อกัน — ถ้าคิดว่าราคาจะไปทางเดียว (ขึ้นหรือลง) พอประมาณ ใช้ Spread; ถ้าคิดว่าราคาจะขยับแรงแต่ไม่รู้ทิศ ใช้ Straddle/Strangle

Directional Spreads

StrategyLegsBeliefMax ProfitMax Loss
Bull Call Spread+Call K₁, −Call K₂ขึ้นพอประมาณ(K₂−K₁)−NetNet Premium
Bear Put Spread+Put K₂, −Put K₁ลงพอประมาณ(K₂−K₁)−NetNet Premium

Volatility Strategies

StrategyLegsBeliefMax ProfitMax Loss
Long Straddle+Call K, +Put Kผันผวนมาก (ไม่รู้ทิศ)ไม่จำกัดPremium ทั้งคู่
Long Strangle+Put K₁, +Call K₂ผันผวนมาก (ถูกกว่า)ไม่จำกัดPremium ทั้งคู่

Net profit (หลังหัก premium)

✍️ ลองทำเอง

หุ้น K=100: ซื้อ Long Call(105) จ่าย ฿4 และ Long Put(95) จ่าย ฿3 (Long Strangle) — Break-even สองจุดคืออะไร? กำไรเมื่อไร?

เฉลย: Net premium = 4+3 = ฿7 → BE บน = 105+7 = 112, BE ล่าง = 95−7 = 88 → กำไรถ้าราคาหลุดออกนอกช่วง 88-112 ไปทางใดทางหนึ่ง

📉 เมื่อทฤษฎีพังจริง: Short Strangle — "ดูเหมือน easy money"

Short Strangle payoff chart ดูเหมือน "เก็บ premium สบาย ๆ ถ้าราคาไม่ขยับมาก"

แต่: gap down/up ผ่าน strike → ขาดทุนไม่จำกัด → XIV 2018: ผลิตภัณฑ์ short volatility เสียมูลค่า ~96% ภายในคืนเดียว แล้วถูกยกเลิก

กฎ: payoff chart ที่สวยที่สุด อาจเป็น trade ที่อันตรายที่สุด

🎯 3 อย่างที่ต้องจำ
  • Spread = จำกัดทั้งกำไรและขาดทุน → safe แต่ upside จำกัด
  • Straddle/Strangle = เดิมพัน volatility → ซื้อ = จ่าย premium, ขาย = เก็บ premium
  • Short vol ดูเหมือน easy money → จนกว่าจะไม่ easy

บทที่ 7: Combinations + "Covered Call = Short Put"

Covered Call = Long Stock + Short Call

🚶 อ่านเป็นภาษาคนก่อน: ถือหุ้นไว้เฉย ๆ (เผื่อราคาขึ้น) แต่ขายสิทธิซื้อทับไว้ (เก็บ premium ไปก่อน) — ถ้าราคาขึ้นเกิน K คุณต้องขายหุ้นให้คนอื่นที่ราคา K จึงพลาดกำไรส่วนที่เกินไป

Profit = (Sₜ − S₀) + C − max(Sₜ−K, 0)
= min(Sₜ, K) − S₀ + C
= "ได้ premium (C) แต่ cap upside ที่ K"

Short Put (naked)

Profit = P − max(K−Sₜ, 0)
= "เก็บ premium แต่รับ downside ทั้งหมด"

Net profit (หลังหัก premium)

★ Insight สำคัญที่สุดของบทนี้

Covered Call payoff = Short Put payoff — SAME SHAPE! (ต่างกันแค่ค่าคงที่ PV(K))

คนส่วนใหญ่คิดว่า Covered Call = "conservative" แต่ Short Put = "reckless" ทั้งที่มี risk profile เหมือนกันทุกประการ!

ถ้าคุณไม่กล้าขาย Naked Put → คุณก็ไม่ควรเขียน Covered Call (แต่คนทำกันทุกวัน)

เสียงจากสนาม — Market Maker (20 ปี)

"The same people who would never sell a naked put happily write covered calls every week. They have identical payoff profiles."

แปล: คนกลุ่มเดียวกันที่ไม่กล้าขาย naked put กลับเขียน covered call ทุกสัปดาห์อย่างสบายใจ — ทั้งที่ payoff profile เหมือนกันเป๊ะ

Pin Risk + Assignment Risk

ความเสี่ยงที่ "Short = พลิก Long" ไม่ได้บอก

Pin Risk: ราคาปิดที่ Strike พอดี → ไม่รู้จะถูก exercise หรือไม่ → uncertainty

Assignment Risk (American): Short option อาจถูก exercise ก่อนหมดอายุได้ทุกเมื่อ (โดยเฉพาะก่อน ex-div)

→ Payoff chart ไม่แสดง risks เหล่านี้! มันแสดงแค่ผลลัพธ์ ณ วันหมดอายุ

Collar + Risk Reversal

🚶 อ่านเป็นภาษาคนก่อน: Collar คือการ "ซื้อประกัน" (Put ป้องกันขาลง) แล้วเอาเงินค่าประกันมาจาก "ขายสิทธิ upside" (Short Call) — ถ้า premium สองฝั่งพอดีกัน ต้นทุนสุทธิ = 0

Collar = Long Stock + Long Put(K₁) + Short Call(K₂)
= "ป้องกัน downside ที่ K₁ + cap upside ที่ K₂"
Risk Reversal = Long Call(K₂) + Short Put(K₁)
= "Synthetic forward ที่มี gap ระหว่าง K₁ กับ K₂"

Net profit (หลังหัก premium)

🎯 3 อย่างที่ต้องจำ
  • Covered Call = Short Put (same shape) → "conservative" ≠ "safe"
  • Pin Risk + Assignment Risk ซ่อนอยู่ → payoff chart ไม่แสดง
  • Collar = "ซื้อประกัน + ขายสิทธิ upside" → zero-cost ถ้า premium match

บทที่ 8: "Payoff ≠ Prediction" — บทที่ช่วยชีวิต

ถึงตรงนี้คุณวาด payoff chart ได้คล่องแล้ว — แต่ต้องหยุดก่อน แล้วเข้าใจสิ่งนี้ให้ลึกซึ้ง:

★ Payoff Chart ไม่ใช่ Prediction!

Payoff chart แสดง: "ถ้าราคาจบที่ X ผลลัพธ์เป็น Y"

Payoff chart ไม่ได้แสดง: "ราคาจะจบที่ X ด้วยความน่าจะเป็นเท่าไร"

Bull Call Spread ดูเหมือน "กำไรถ้าขึ้น" — แต่ตลาดก็รู้ว่ามันอาจขึ้น! ราคา option ที่คุณจ่าย = ตลาดคิดว่าโอกาสขึ้นเท่าไรแล้ว

คุณกำไรจริง ก็ต่อเมื่อขึ้นมากกว่าที่ตลาดคาด — ไม่ใช่แค่ "ขึ้น"

เสียงจากสนาม — MIT Professor (25 ปี)

"The payoff diagram is a map of terminal payoffs under each scenario, with no probability attached. That distinction saves careers."

แปล: Payoff chart คือแผนที่แสดง "ถ้า...แล้ว..." ไม่มีความน่าจะเป็นแนบมา — เข้าใจตรงนี้ช่วยชีวิตได้

สองเสียงนี้พูดตรงกันจากคนละมุม — และนี่คือประโยคที่ควรติดผนังห้องเทรดของทุกคน:

Payoff chart บอกว่า "ถ้าเกิด X จะได้ Y" — มันไม่เคยบอกว่า X จะเกิดหรือไม่ ลืมข้อนี้ครั้งเดียว พอร์ตพัง
✍️ ลองทำเอง (บท 8)

คุณเห็น Iron Condor payoff — กว้าง ๆ สบาย ๆ "ราคาอยู่ในกรอบ = กำไร ฿2,000 ออกนอกกรอบ = เสีย ฿8,000" คำถาม: นี่เป็น "good trade" หรือไม่? ขาดข้อมูลอะไร?

เฉลย: ขาดความน่าจะเป็น! ถ้า P(อยู่ในกรอบ)=70% → EV = 0.7×2000 + 0.3×(−8000) = 1400−2400 = −฿1,000 = ขาดทุนคาดหวัง! Payoff chart สวย ≠ trade ดี

🎯 3 อย่างที่ต้องจำ
  • Payoff chart = แผนที่ ไม่ใช่ prediction — ไม่มี probability
  • ตลาดรู้เท่าคุณ → premium ที่จ่าย = ตลาดคิดว่าโอกาสเท่าไรแล้ว
  • Payoff chart สวย ≠ trade ดี → ต้องคำนวณ Expected Value ด้วย!

อ่าน Payoff (3 ข้อตัวอย่าง)

✍️ ลองทำเอง

ข้อ 1: เส้นแบนที่ −3 จนถึง K=100 แล้วชันขึ้น slope +1 → คืออะไร?

เฉลย: Long Call K=100, P=3

ข้อ 2: เส้นชันขึ้นจากซ้าย slope +1 จนถึง K=95 แล้วแบนที่ +2 → คืออะไร?

เฉลย: Short Put K=95, P=2

ข้อ 3: แบน(−5) → ชัน(+1) ที่ K₁=90 → แบน(+15) ที่ K₂=110 → คืออะไร?

เฉลย: Bull Call Spread K₁=90, K₂=110, Net Premium=5

สร้าง Payoff (3 ข้อตัวอย่าง)

✍️ ลองทำเอง

ข้อ 1: "กำไรถ้าลง ขาดทุนจำกัดที่ ฿4" → สร้าง payoff?

เฉลย: Long Put, P=4

ข้อ 2: "กำไรจำกัด ฿10 ถ้าขึ้น, ขาดทุนจำกัด ฿5 ถ้าลง" → สร้าง?

เฉลย: Bull Call Spread ที่ width=15, net premium=5

ข้อ 3: "กำไรถ้าราคาเคลื่อนไหวมากไม่ว่าทิศไหน" → สร้าง?

เฉลย: Long Straddle หรือ Long Strangle

🎯 3 อย่างที่ต้องจำ

  • สร้าง: Belief → piecewise → เลือก legs ที่ให้ slope ตรงตามต้องการ
