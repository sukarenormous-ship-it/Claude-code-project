Drill Level 1: อ่าน Payoff (10 ข้อ)

1. แบน(-3) → slope+1 ที่ K=100 → คืออะไร? → Long Call K=100, P=3
2. slope-1 จากซ้าย → แบน(+4) ที่ K=95 → คืออะไร? → Short Put K=95, P=4
3. แบน(-5) → +1 ที่ 90 → -1 ที่ 110 → แบน(+15) → คืออะไร? → Bull Call Spread 90/110
4. V-shape จุดต่ำสุดที่ K=100 → คืออะไร? → Long Straddle K=100
5. ที่ราบสูง +2 ระหว่าง 90-110 ดิ่งลงสองข้าง → คืออะไร? → Iron Condor

Drill Level 2: สร้าง Payoff จาก Belief (10 ข้อ)

1. "ขึ้นไม่จำกัด เสียจำกัด ฿8" → Long Call P=8
2. "ขึ้นจำกัด ฿20 เสียจำกัด ฿5" → Bull Call Spread width=25, net=5
3. "กำไรถ้าราคานิ่ง ขาดทุนถ้าเคลื่อนไหว" → Short Straddle (⚠️ unlimited!)
4. "กำไรที่จุด S=100 พอดี ไม่เสียเกิน ฿2" → Butterfly K₂=100, net=2

Drill Level 3: Cross-Market Pricing (10 ข้อ)

1. PM "BTC>80K" = $0.72, Options implied = 65% → edge? → 7% gap แต่ต้องเช็ค touch/close + fees
2. Bookmaker odds 1.80 vs Options implied 60% → edge? → 1/1.80=55.6% vs 60% → Options แพงกว่า 4.4%

Drill Level 4: Portfolio Analysis (10 ข้อ)

1. Long Call K=100 + Short Call K=110 + Long Put K=90 → วาด combined payoff → max loss?
2. ถ้า portfolio มี delta=+200 gamma=-50 → ราคาขึ้น ฿5 → delta ใหม่ ≈ ?
   เฉลย: delta ≈ 200 + (-50×5) = -50 → พลิกจาก long เป็น short!

Drill Level 5: Reverse Engineering — 20★ Essential

ภารกิจ: ดู payoff ไม่มี label → ถอดให้หมด

เฉลย: inverted 180° ด้านล่างของแต่ละข้อ (พลิกหนังสือดู)

บทที่ 28: "Short Put DNA + แผนที่ ≠ ดินแดน"

เสียงจากสนาม — Senior Options Trader (20 ปี, $500M book)

"Every strategy — covered calls, iron condors, credit spreads — has short put DNA embedded in it. If you can't diagram a short put in your sleep, you have no business trading anything more complex."

แปล: ทุก strategy มี DNA ของ Short Put ซ่อนอยู่ — ถ้าวาด Short Put ไม่ได้หลับตา อย่าเทรดอะไรที่ซับซ้อนกว่านั้น

XIV 2018 — "แผนที่สวย แต่ดินแดนมีหน้าผา"

5 กุมภาพันธ์ 2018: ผลิตภัณฑ์ XIV (Short VIX) เสียมูลค่า ~96% ภายในคืนเดียว แล้วถูก Credit Suisse ยกเลิก
Payoff chart ของ short vol strategies ดูสวย — "เก็บ premium ทุกเดือน กำไรบ่อย"
แต่ chart ไม่แสดง: tail risk, gap risk, liquidity vanishing, correlation spike

"The payoff chart is the map, not the territory. The territory has cliffs the map doesn't print."

บทสรุปของเล่ม

Payoff Chart คือภาษาสากลของ Risk

ทุก financial product = payoff chart
ทุก payoff chart = ผลรวมของ building blocks
ทุก building block = สร้างได้หลายวิธีหลายตลาด

แต่จำไว้เสมอ:
• Payoff ≠ Prediction — ไม่มี probability
• Map ≠ Territory — มีหน้าผาที่แผนที่ไม่แสดง
• ทุก strategy มี Short Put DNA — ถ้าไม่เข้าใจ Short Put อย่าไปต่อ

"ถ้าวาด payoff ได้ = เข้าใจ risk ได้ = ตัดสินใจได้"
