บทที่ 9: PM → Options → Arb

Case แรก: เห็น PM (Prediction Market — ตลาดทำนายผล) price → แปลงเป็น option (ออปชัน) → เทียบราคา → หา edge (ส่วนได้เปรียบ)

ขั้นที่ 1 — Observe: PM "BTC > $100K by Dec" = $0.62
ขั้นที่ 2 — Translate: = Digital Call (ออปชันดิจิทัล — จ่ายคงที่) at $100K = Tight Bull Call Spread (สเปรดซื้อแบบกระทิง) ÷ width
ขั้นที่ 3 — Compare: PM = 62% vs Options implied (ความน่าจะเป็นโดยนัย) = 55% → gap 7%
ขั้นที่ 4 — Check: Resolution: PM ใช้ Binance price, Options ใช้ Deribit → ต่างกัน!
  PM = "touch" (แตะ $100K ครั้งเดียวก็ resolve) vs Options = "close" (ราคา ณ expiry)
  → Touch > Close probability → gap 7% อาจเป็นแค่ resolution premium (ส่วนเพิ่มราคาจากวิธีตัดสินผล)!
ขั้นที่ 5 — Net: ประเมิน resolution premium ≈ 4% → net edge ≈ 3%
  หัก fees 1% → net ≈ 2% → [Heuristic] → size เล็ก
ขั้นที่ 6 — Label: Lv.4 Structured — ไม่ใช่ arb จริง แต่มี statistical edge
3 สิ่งที่ต้องจำจากบท 9

1. PM price = implied probability → เทียบกับ Options implied ได้
2. Resolution mechanics (touch vs close) สร้าง spread ที่ดูเหมือน arb แต่อาจไม่ใช่
3. Pattern: "ของเดียวกัน ชื่อต่าง ตลาดต่าง → เทียบราคา"

บทที่ 10: Earn → Hidden Option → Near-Arb

Observe: Bybit Earn XAUT 11% APR (Annual Percentage Rate — อัตราผลตอบแทนต่อปี)
Translate: = Short Put (สถานะขายสิทธิ์ขาย) on Bybit solvency (ความสามารถชำระหนี้) + ได้ yield (ผลตอบแทน) + exposed to gold price
Separate risks: Gold price risk (hedge ได้) vs Platform risk (hedge ไม่ได้)
Hedge (ป้องกันความเสี่ยง): Short XAUT Perp (Perpetual — สัญญาต่อเนื่องไม่มีวันหมดอายุ) → ลบ gold risk → เหลือ platform risk + net yield
Net: 11% - 5% funding cost (ต้นทุน funding) = 6% delta-neutral (สถานะเป็นกลางต่อทิศทางราคา) yield
Baseline: USDT Earn 4% (1 ขา, ง่ายกว่า) → marginal 2% → คุ้ม 2 ขาไหม?
Label: Lv.3 Near-Arb [Heuristic] — rate อาจเปลี่ยน
Pattern: เห็น yield → ถามว่า "yield มาจากไหน?" → แยก risk → hedge risk ที่ไม่ต้องการ

บทที่ 11: Time-Structure Arb (Funding + Weekend Gap)

2 case ที่เกี่ยวกับ "เวลา":

Case A: Funding Rate (อัตราค่าธรรมเนียมการถือสถานะ สัญญา Perpetual) Carry (การถือเก็บส่วนต่าง)

Funding rate -0.03%/8hr = -0.09%/day = -32.9%/year
→ Long Perp (รับ funding) + Short Spot (ตลาดส่งมอบทันที, hedge) = delta neutral carry
→ [Heuristic] — rate อาจ flip ทุกเมื่อ

Case B: Weekend Gap (ช่องว่างราคาช่วงวันหยุด)

ทอง physical ปิดเสาร์-อาทิตย์ แต่ XAUT (crypto gold) trade 24/7
→ XAUT อาจ drift จาก fair value (มูลค่ายุติธรรม) เพราะไม่มี reference
→ ถ้า XAUT > physical fair → short XAUT, ปิดวันจันทร์
→ [Heuristic] — ข่าวแรงช่วง weekend อาจทำให้ไม่ใช่ mispricing
Pattern: ตลาดเปิด/ปิดต่างเวลา → reference gap → "ราคา drift กลับเมื่อ reference กลับมา"

บทที่ 12: Liquidation Cascade (การถูกบังคับปิดสถานะต่อเนื่อง) + Flash Loan (สินเชื่อแฟลช — กู้และคืนในธุรกรรมเดียว)

Case: Liquidation (การถูกบังคับปิดสถานะ) = Barrier Option (ออปชันแบบมีกำแพงราคา)

ราคาลง → liquidation → forced selling (การถูกบังคับขาย) → ราคาลงอีก → cascade
Hidden option: Barrier at each liquidation level → cascade = chain of barriers
Exploit: ซื้อเมื่อ cascade กำลังจบ (capitulation — ช่วงยอมแพ้เทขาย) → funding flip + Open Interest (OI — สถานะคงค้าง) ลดฮวบ = signal
Sidebar: Flash Loan — Capital-Free Lv.1

แนวคิด: ยืมเงิน $200M → ซื้อ-ขาย → คืนเงิน → ทั้งหมดใน 1 transaction (12 วินาที)
ถ้าคืนไม่ได้ → ทุกอย่างย้อนกลับเหมือนไม่เคยเกิด → ไม่เสียอะไรเลย!
= Pure Arb ตามนิยาม Lv.1 (ไม่ใช้ทุน ไม่มี risk) แต่ต้องเขียน code (Solidity)
สำหรับ manual trader: เข้าใจแนวคิดพอ ไม่ต้อง implement เอง

บทที่ 13: New Listing + Multi-Venue Combo

Case A: New Listing Gap

Token ใหม่ list มี Spot ก่อน Perp 1 สัปดาห์ → เมื่อ Perp เปิด basis (เบสิส — ส่วนต่างราคาสปอตกับฟิวเจอร์ส) มักกว้างมาก
→ Cash & Carry (ซื้อสปอตถือคู่ขายฟิวเจอร์ส) ใน 1-2 วันแรก → basis converge → profit
→ [Observed] — ต้องเร็ว + liquidity (สภาพคล่อง) ต่ำ = slippage (ส่วนต่างราคาที่คลาดเคลื่อน) สูง

Case B: Multi-Venue Combo (ETH Merge Template)

ตัวอย่าง (ปรับได้กับ protocol event อื่น):
1. PM: ซื้อ "Event happens before X date" = $0.82
2. CeFi (Centralized Finance — การเงินแบบรวมศูนย์): Short Perp รับ elevated funding rate
3. DeFi: ฝาก staked asset (สินทรัพย์ที่ stake ไว้) เป็น collateral (หลักประกัน) → ยืม stablecoin (เหรียญคงค่า) → fund PM
4. Options: ขาย OTM (Out-of-the-money — ราคาอยู่นอกเงิน) puts (IV (Implied Volatility — ความผันผวนแฝง) สูงช่วง event) → fund PM cost

Net: staking yield + funding + PM payout + vol premium (ส่วนเพิ่มจากความผันผวน) − costs
4 layers จาก 4 ตลาด รวมเป็น structure เดียว!
เสียงจากสนาม — DeFi Trader

"Impermanent Loss is selling a straddle you didn't know you sold."
แปล: Impermanent Loss (การขาดทุนชั่วคราวของผู้ให้สภาพคล่อง) — การเป็น LP (Liquidity Provider — ผู้ให้สภาพคล่อง) ใน DeFi = ขาย Straddle (สแตรดเดิล — ซื้อ Call+Put ที่ Strike เดียวกัน) โดยไม่รู้ตัว — ราคาขยับทิศไหนก็เสีย

Sidebar: MEV (Maximal Extractable Value — มูลค่าสูงสุดที่สกัดได้) — "Extraction Risk (ความเสี่ยงจากการถูกสกัดมูลค่า)"

MEV (Maximal Extractable Value): ใน DeFi ผู้สร้าง block สามารถเรียงลำดับ transactions ใหม่เพื่อ "ขโมย" arb ของคุณ
Sandwich attack (การโจมตีแบบแซนด์วิช): เห็น swap ของคุณ → front-run (แซงคิวซื้อก่อน, ดันราคา) → ปล่อยคุณซื้อแพง → back-run (ขายตามทำกำไร)
= Risk ประเภทใหม่ที่ TradFi (Traditional Finance — การเงินดั้งเดิม) ไม่มี: "Extraction Risk"
