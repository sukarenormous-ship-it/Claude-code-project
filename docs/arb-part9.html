32.1 Renaissance Technologies — Stat Arb (การเก็งกำไรเชิงสถิติ) ที่สำเร็จที่สุด

Medallion Fund: 66% avg gross return (ผลตอบแทนขั้นต้น)/year ก่อนหัก fees (ค่าธรรมเนียม) (1988-2018)

ใช้ math + physics + data science หาสัญญาณใน noise (สัญญาณรบกวน)
ทำ หลายพัน trades/วัน แต่ละ trade edge (ความได้เปรียบ) เล็กมาก → Law of Large Numbers (กฎว่าด้วยจำนวนมาก)
บทเรียน: small edge × many trades × low correlation (สหสัมพันธ์) = consistent returns

32.2 LTCM — ถูกต้องแต่ตาย (ดูรายละเอียดในบท 26)

สรุป: Bond convergence arb (การเก็งกำไรจากการลู่เข้าของราคาพันธบัตร) + 25:1 leverage (การใช้เลเวอเรจ — อัตราทด) = bankrupt (ล้มละลาย)

Strategy ถูกต้อง (bonds converged ภายหลัง) แต่ leverage สูงเกินไป → margin call (การเรียกเงินประกันเพิ่ม) → เสีย $4.6 billion
บทเรียน #1: Size < Survival. ถ้ารอดไม่ถึงวัน converge = ไม่มีประโยชน์

32.3 Knight Capital — software bug (ดูรายละเอียดในบท 26)

$440M loss ใน 45 นาที

Bug (ข้อผิดพลาดในโปรแกรม) ใน trading software ส่ง orders (คำสั่งซื้อขาย) ผิดพลาดเป็นล้านรายการ → ล้มละลาย
บทเรียน #2: Automated ต้องมี kill switch (สวิตช์หยุดฉุกเฉิน) + position limit (เพดานจำกัดขนาดสถานะ) + staging test (การทดสอบบนระบบจำลองก่อนใช้จริง)

32.5 บทเรียน 10 ข้อ

  1. Pure Arb (อาร์บิทราจบริสุทธิ์ไร้ความเสี่ยง) หายากมาก — ส่วนใหญ่เป็น Near-Arb (อาร์บิทราจเกือบไร้ความเสี่ยง) หรือ Bounded-Loss (ขาดทุนจำกัดเพดาน)
  2. Transaction costs (ต้นทุนการทำธุรกรรม) กิน edge — คิดก่อน execute เสมอ
  3. Leverage kills — ถูกต้อง + leverage สูง = ตายก่อนชนะ (LTCM)
  4. Simple > Complex — Baseline comparison (การเทียบกับวิธีพื้นฐานที่สุด) ทุกครั้ง
  5. Size < Survival — อยู่รอดก่อน กำไรทีหลัง
  6. Label your claims — Exact ≠ Heuristic ≠ Observed
  7. Automate with safeguards — kill switch + position limit (Knight Capital)
  8. Regime matters — strategy ที่ดีใน bull (ตลาดขาขึ้น) อาจแย่ใน bear (ตลาดขาลง)
  9. Diversify across strategies — ไม่ใช่แค่ across assets
  10. Keep learning — ตลาดเปลี่ยน edge หายไป ต้องหาใหม่ตลอด

Arb for Manual Traders — "ไม่มี bot ไม่มี API มีเงิน ฿50,000 ทำอะไรได้?"

ทำได้ (manual, เงินน้อย):

  • Earn + Hedge (Lv.3) → ฝาก stablecoin (เหรียญคริปโตที่ตรึงมูลค่า) ใน Earn promo + hedge ถ้าจำเป็น → ไม่ต้อง bot
  • Merger Arb (Lv.4) → ซื้อหุ้น target เมื่อ deal ประกาศ → ถือรอ → ไม่ต้องเร็ว
  • PM Cross-Platform (Lv.1) → ตรวจ Yes+No < $1 ด้วยตา → execute manual → เกิดไม่บ่อยแต่เจอ = กำไรแน่
  • Pairs Trading Z-score (Lv.4) → เช็ค z-score วันละครั้ง → rebalance weekly → ไม่ต้อง real-time

ทำไม่ได้ (ต้อง bot/infra):

  • PCP/Box Arb (Lv.1) → หายใน seconds → ต้อง automated
  • Triangular Forex → หายใน microseconds → ต้อง co-located server
  • Gamma Scalping (การเก็งกำไรจากการปรับเฮดจ์ตามแกมมา) → ต้อง rehedge (ปรับป้องกันความเสี่ยงใหม่) ทุกชั่วโมง → ต้อง alert system (ระบบแจ้งเตือน)

กฎสำหรับ manual trader: เริ่มจาก Lv.3-4 ที่ช้าพอ → สร้าง track record (ประวัติผลงาน) → ค่อยลงทุน infra (โครงสร้างพื้นฐาน) สำหรับ Lv.1-2
