# Brief สำหรับคณะออกแบบเล่มใหม่ — "Stat Arb for Non Quant" ฉบับปรับปรุงสำหรับมือใหม่

## โจทย์จากเจ้าของ (ข้อความจริง)
"วางแผนปรับปรุงหนังสือจาก file นี้ โดยต้องการมือใหม่ อ่านแล้วเข้าใจ เอาไปต่อยอด คิดได้ ทำได้ และเข้าใจธรรมชาติของกลยุทธ์ และใช้เครื่องมือเดิมที่เคยใช้เพื่อสร้างหนังสือเล่มใหม่"

5 เป้าหมาย: (1) understand อ่านแล้วเข้าใจ (2) think คิดได้เอง (3) do ทำได้/ลงมือได้ (4) extend เอาไปต่อยอด (5) nature เข้าใจธรรมชาติของกลยุทธ์ stat arb
ข้อบังคับ: ใช้ "เครื่องมือเดิม" ของคลังนี้สร้าง = สายพาน tools/nq_*.py + สกิล knowledge-book (ดูหัวข้อสายพานด้านล่าง)

## ผู้อ่าน
มือใหม่ = ซื้อขายเหรียญบน exchange เป็น · ใช้แค่ + − × ÷ % และอ่านกราฟเส้น · ไม่มีพื้นสถิติ/finance · ไม่เขียนโค้ด · อ่านไทยเป็นหลัก รู้ศัพท์อังกฤษเฉพาะที่เจอในแอปเทรด

## ปัญหาร่วมทั้งเล่ม (พบซ้ำแทบทุกบท)
1. **สูตรมาก่อนสัญชาตญาณ** — ln/exp (02.04, 09.03), Cov/Var (04.02), Σ/Ê/conditional (08.01), φ^H — ทั้งที่หน้าเปิดสัญญาว่าใช้แค่ + − × ÷ % ; ทศนิยม 8 ตำแหน่ง
2. **ศัพท์/แนวคิดแกนไม่เคยสอนในเล่ม** — beta (บท 4 ทั้งบทยืนบนมัน), correlation (บท 7), options (ตัวอย่างหลักบท 5), φ/AR(1) (บท 7, 9), fill, residual, exposure, OLS/PCA ; กล่องเปิดบทส่งไป "เล่มเดิม Quant for Non-Quant" ซึ่ง **ไม่มีในคลังนี้** (อ้างภาคเลขโรมัน I–XVIII ไม่ตรงชุดใด) ขัดคำสัญญา "ไม่ต้องอ่านเล่มเดิม"
3. **ป้าย "ลงลึก ข้ามได้" ผิดที่** — 09.02 เป็นที่เดียวที่นิยาม φ ที่แกนบท 7/9 ใช้; 10.01 มีตัวอย่างหลักของบท 10; 05.05/05.08 มีเนื้อที่โจทย์ใช้; 04.05 มีตัวอย่างหลักบท 4
4. **ไม่มีฉากเปิด/เรื่องเล่าต่อเนื่อง** — เปิดด้วยกรอบนามธรรม/ตาราง ; ชุดเลขกระโดด (บท 1 มี 8 ชุดไม่ต่อกัน) ; บท 3,4,5,8,9,10 ใช้สินทรัพย์สมมติ A/B/C/G แทนคริปโต
5. **ภาพ** — 22 รูปอังกฤษล้วน ป้ายทับเส้น บางรูปไม่ตรงข้อความ ; หลายบทแกนไม่มีภาพที่จำเป็น (การบรรจบของ spot–futures, เส้นทางจำลอง, สองกระเป๋าหลักประกัน)
6. **do อ่อนที่สุด** — ไม่มีแบบฟอร์มเปล่า/ใบงาน/สเปรดชีต/เครื่องมือกดเล่น ; โจทย์ใช้เลขเดิมของเนื้อบท ; "โค้ดตรวจตัวเลข" ใช้ไม่ได้กับคนไม่เขียนโค้ด ; ไม่มีขั้นอ่านค่าจากแอป/กติกา exchange จริง ; ไม่มีข้อมูลจริงเลย
7. **extend อ่อน** — "ต่อยอด" ในแผนเดิม = โมเดลยากขึ้น (copula/ML) ไม่ใช่ดัดแปลงไปคู่อื่น/ตลาดอื่น/ไอเดียอื่น ; ไม่มีเช็กลิสต์ย้ายตลาด ; แหล่งอ่านต่อเป็น paper อังกฤษระดับนักวิจัย
8. **nature กระจายเป็นเศษ** — "ใครอยู่อีกฝั่ง" ถามครั้งเดียว (01.04) ไม่ตอบ ; ไม่มีคำ capacity/crowding/drawdown ทั้งไฟล์ ; ไม่มีรูปร่างกำไรขาดทุนเทียบกลไก (ชนะบ่อยแพ้หนัก) ; วัตถุดิบดีมีอยู่แล้ว: 01.04 (+1 ที่ 99% / −120 ที่ 1%), 05.08 (ชนะ 65% แต่คาดหมาย −0.5), 06.05 (funding 4 เส้นทาง), 07.04 (ค้น 200 คู่), 08.03 (+16/+2/−21), tail_risk
9. **เอกสารคนทำเล่มปนของผู้อ่าน** — ฉบับ/CHANGELOG/สถานะขัดกัน/แม่แบบ/ระดับหลักฐาน/ตารางสัญลักษณ์ 19 แถวก่อนบท 0
10. **บทอ้วนเกิน** — บท 3 = 150 นาที, 03.09 อัดสองตัวอย่างใหญ่ 5,800 ตัวอักษร ; บท 1, 2, 3, 4, 5 ผู้ตรวจเสนอให้แยกเป็นสองตอน

- หลักของ Source Plan: สัญญาณ ≠ holdings ≠ กำไร · payoff เท่ากัน ≠ arbitrage · probability ≠ โอกาสกำไร · stop เป็น trigger ไม่ใช่เพดานขาดทุน · pause ≠ เลิกดูแลสถานะ

## ข้อเสนอที่ผู้ตรวจส่วนใหญ่ให้ตรงกัน
- เล่ม 1 (มือใหม่) = บท 0–10 ทำให้ครบ + ภาค "ก่อนใช้เงินจริง" ย่อจากแผนบท 15 (ทดสอบ), 16 (คำสั่งจริง/ต้นทุน), 17 (อ่านผลขาดทุน) + ส่วนเลขคณิตของ 13 (netting) และ 18 (no-trade buffer) + บท "ธรรมชาติของ stat arb" + บท "เอาไปต่อยอด" ; บท 11, 12, 14, 19, 20, Markowitz ของ 13, options → เล่ม 2 (ต่อยอด)
- แกนเรื่อง: C8 (BTC spot–dated futures–perp, คริปโตแท้ เลขคณิตล้วน) เป็นแกนหลัก + C1/C2 เล่าใหม่เป็น "คู่เหรียญหนึ่งคู่" ตั้งแต่เลือก→บัญชี→ทดสอบ→เสื่อม เป็นแกนรอง
- ทุกบท: ฉาก → ตัวเลขเล็ก → ภาพ → ชื่อ → (สูตรในกล่องลงลึกเท่านั้น) → กรอบคิด → ลงมือ → บัตรธรรมชาติ
- "บัตรธรรมชาติกลยุทธ์" ประจำกลไก/แนวทาง: กำไรจากอะไร · ใครอยู่อีกฝั่งและทำไมยอม · รูปร่างกำไรขาดทุน · อะไรต้องเป็นจริง · อะไรทำให้เลิกเชื่อ · ตายอย่างไร (crowding/capacity/regime) · ใช้ทุน/สภาพคล่องเท่าไร
- เครื่องมือกดเล่นที่ควรมี: carry ladder/ปิดก่อนหมดอายุ · funding 4 เส้นทาง + กฎออก · ระยะถึงราคา liquidation สองกระเป๋า · ตัวจำลองคู่ปลอม (selection bias) · φ/half-life เทียบเวลาแตะเป้า · stepper กฎออกบท 8 — เช็กซ้ำกับเครื่องมือเดิม (nq-tool-breakeven/samplesize/ruin/randomness, tool-carry-blowup, tool-deflated-sharpe, payoff-builder)
- อภิธานศัพท์ 3 ชั้น หัวคำไทย+อังกฤษ เลขบทแรกพบ ; ตรึงคำ: "ขา" = เครื่องมือในสถานะ, "ส่วนต่างราคาซื้อ-ขาย" (bid–ask) vs "spread ของคู่ (X)", "แรงดึงกลับ" (mean reversion) vs "ถอยสู่ค่าเฉลี่ย" (regression to mean ที่ nq-part1 ใช้)
- ข้อมูลจริง: ตัวอย่างสมมติยังเป็นแกนสอน + กล่อง "ข้อมูลจริง" (basis ตามวันหมดอายุ, ประวัติ funding, คู่จริง ≥500 วัน เช่น ETH/BTC หรือ staked/wrapped กับตัวแม่, bid/ask จริง) เก็บเป็นสแนปช็อตออฟไลน์ — คลังนี้ไม่มีข้อมูลดิบและ data/ ของ nq ไม่มีในเครื่อง ; ต้องได้ไฟล์จากเจ้าของหรือดึงจาก API สาธารณะในเครื่องที่มีเน็ต
