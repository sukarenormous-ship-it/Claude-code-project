# Style Guide — Typography ไทย + โครงสร้าง + การเขียน

บังคับใช้ทุกไฟล์ มาจากทีมบรรณาธิการ/ภาษา/i18n หลังผู้ใช้รายงานปัญหา "ประโยคขึ้นบรรทัดใหม่กลางคำ อ่านไม่ได้ใจความ"

## A. Line-break ภาษาไทย (เทคนิค — มีใน template แล้ว)

- **CSS body** (อยู่ใน template): `word-break:normal;word-break:auto-phrase;overflow-wrap:break-word;line-break:loose;text-wrap:pretty;hanging-punctuation:allow-end`
- **`<script>` ฝัง `<wbr>`** ก่อน `</body>` — ใช้ `Intl.Segmenter('th')` หาขอบเขตคำไทยแล้วฉีด `<wbr>`
  - ข้าม `.fm` / `code` / `script` (ไม่ยุ่งกับสูตร)
  - ใช้ `<wbr>` (copy สะอาด) **ไม่ใช่** `U+200B`
  - idempotent (มี guard `data-thwbr`) — รันซ้ำได้ปลอดภัย
  - **ห้ามแก้ script นี้** — คัดลอกจาก template ตามเดิม
- mobile: `.fm{font-size:.82em}` ลด horizontal scroll ของสูตร (อยู่ใน `@media` แล้ว)

## B. โครงสร้าง HTML (สำคัญสุดต่อการอ่าน)

- **รายการ (bullet/เลข ≥2 ข้อ) → ใช้ `<ul>/<ol><li>` เสมอ** — **ห้าม** จำลองด้วย `•` + `<br>`
- **ร้อยแก้วหลายย่อหน้าในกล่อง → `<p>` หลายอัน** ไม่ใช่ `<br><br>`
- **`<br>` เดี่ยวสงวนไว้เฉพาะ:** คู่ "คนทั่วไปเห็น/ผู้เชี่ยวชาญเห็น" ใน `.qv` และคู่บรรทัดสูตรใน `.fm` เท่านั้น
- **`.fm` เก็บเฉพาะสูตร** — คำอธิบายไทยยาว ๆ ย้ายออกมาเป็น `<p>/<ul>` (ไทยใน monospace อ่านยาก)
- **ทุกกล่อง `.fm` ที่มีสัญลักษณ์/ฟังก์ชันใหม่ ต้องตามด้วยบรรทัด `<p class="read"><strong>📖 อ่านสูตรว่า:</strong> …</p>`** สามส่วน: (1) อ่านออกเสียงเป็นภาษาไทยให้จบประโยค (2) "โครงที่ต้องเห็น" — สูตรนี้เป็นโครงไหนใน 5 โครงหลัก: อัตราส่วนหน่วยเดียวกัน (หน่วยหาย) · ตำแหน่งในช่วง (ค่า−ต่ำ)/(สูง−ต่ำ) · Σ(x−x̄)(y−ȳ)/Σ(x−x̄)² (β) · สูตรอ้างตัวเองเมื่อวาน (ความจำจาง) · ค่าประมาณ/SE (t) (3) กับดักการอ่าน (ขีดตั้ง | = given ไม่ใช่หาร · ตัวห้อยพารามิเตอร์ ≠ เวลา · |·| = ทิ้งทิศ · ≈ = มีสมมติฐาน) — กฎการอ่านทั้งหมดรวมที่ `notation.html` หมวด 0; CSS `.read` ดูตัวอย่างใน `nq-appendix-indicators.html` · เหตุผล: ผู้อ่านหลุดจากสูตรเพราะอ่านสัญลักษณ์ไม่ออก ไม่ใช่เพราะทฤษฎียาก
- ตารางห่อด้วย `.tw` (`overflow-x:auto`) เสมอ เพื่อ scroll บนมือถือ

> บทเรียน: `<br>` ปลอมที่จำลองรายการเคยทำให้บรรทัดไทยตัดกลางคำอ่านไม่ออก — commit `69b24ae` แปลง `<br>` ปลอม → `<ul>/<ol>/<p>` จริงทั้ง 6 ไฟล์เพื่อแก้

## C. การเขียน

- ประโยค **≤ ~2 บรรทัดจอ** — ถ้าต้องมี (1)(2)(3) ในประโยคเดียว = สัญญาณให้เปลี่ยนเป็น `<ul>`
- **em-dash `—` ≤ 1 ตัว/ประโยค**; ฝั่ง "quant/ผู้เชี่ยวชาญเห็น" ใน `.qv` **≤ ~2 ประโยค**
- **เว้นวรรครอบคำอังกฤษ/ตัวเลข**ที่แทรกในไทยเสมอ; ตัวคั่น inline มาตรฐาน = ` · `
- **ศัพท์เทคนิคคงอังกฤษ** — ครั้งแรกต่อ Part ใส่ไทยในวงเล็บ **หรือ** `<abbr title>` tooltip (อย่างใดอย่างหนึ่ง)
- tooltip (`<abbr title>`) **ห้ามมีศัพท์ที่ยังไม่นิยาม**

## D. ระบบศัพท์

- เก็บอังกฤษ + ไทยในวงเล็บครั้งแรก + `<abbr title>` tooltip
- ปิดทุก Part ด้วยกล่อง **"📖 ศัพท์ใหม่ในตอนนี้"** รวมศัพท์ทั้งหมดพร้อมนิยามสั้น
- glossary จัดชั้น: ชู "3 คำต้องจำก่อน" แยกจากที่เหลือ

## E. จังหวะ/ความหนาแน่น

- กล่องสีติดกัน **≤ 4 ต่อการ์ด** (เกินนั้นยุบเนื้อรองเป็นร้อยแก้ว) เพื่อคง visual hierarchy
- ทุก Part เนื้อหา: **≥1 `.pq`** คั่น section + **≥1 กล่องเคส 📉** "เมื่อทฤษฎีพังจริง" + ปิดด้วย **กล่องสรุป ✓** + **`.pq` สะพาน**สู่ Part ถัดไป
- reading-path banner (🟢 มือใหม่ / 🔵 มีพื้น) ด้านบนของทุกไฟล์
