5.1 Scatter Plot & Correlation — ρ แต่ละค่าหน้าตายังไง

🚶 อ่านเป็นภาษาคนก่อน: scatter plot คือเอาของสองอย่างมาวางบนแกน x กับ y แล้วจิ้มจุดทีละคู่ · ถ้าจุดเรียงเป็นแนวชัด = สองสิ่งนี้ไปด้วยกัน · ค่า correlation (ρ) คือการย่อ "ความเป็นแนว" นั้นให้เหลือตัวเลขเดียวระหว่าง −1 ถึง +1 (เจอครั้งแรกใน เล่ม 1 Part II)

❌ กับดักที่ 1 — ρ = 0 ไม่ได้แปลว่า "ไม่เกี่ยวกัน"

ดูใบขวาสุด · จุดเรียงเป็นรูปตัว U ชัดเจน รู้ x ปุ๊บทำนาย y ได้แทบเป๊ะ · แต่ค่า ρ ที่คำนวณได้คือ 0.000 พอดี

เพราะ correlation วัดเฉพาะความสัมพันธ์แบบเส้นตรงเท่านั้น · ครึ่งซ้ายลง ครึ่งขวาขึ้น หักล้างกันหมดพอดี · ρ = 0 แปลว่า "ไม่มีความสัมพันธ์เชิงเส้น" ไม่ใช่ "ไม่มีความสัมพันธ์" — ต้องดูกราฟถึงจะแยกออก

❌ กับดักที่ 2 — correlation ≠ causation

ρ สูงบอกแค่ว่า "สองสิ่งนี้ขยับไปด้วยกัน" ไม่ได้บอกว่าใครทำให้ใครขยับ · อาจมีปัจจัยที่สามขับทั้งคู่อยู่ (เช่น หุ้นสองตัวขึ้นพร้อมกันเพราะดอกเบี้ยลด ไม่ใช่เพราะเกี่ยวกันเอง) · ในการเทรด ความต่างนี้สำคัญมาก เพราะ hedge ที่อิง correlation ล้วนจะพังทันทีที่ปัจจัยที่สามเปลี่ยนพฤติกรรม

🐍 Python — พิสูจน์ว่ารูปตัว U ให้ ρ = 0
import numpy as np

x = np.linspace(-1.7, 1.7, 20)
y_line = x                       # เส้นตรง
y_u    = x**2                    # รูปตัว U — สัมพันธ์ชัดเจน แต่ไม่เป็นเส้นตรง

print(f"เส้นตรง : rho = {np.corrcoef(x, y_line)[0,1]:+.3f}")   # เส้นตรง : rho = +1.000
print(f"รูปตัว U: rho = {np.corrcoef(x, y_u)[0,1]:+.3f}")      # รูปตัว U: rho = +0.000
print("→ rho=0 แต่ y ทำนายได้จาก x เกือบสมบูรณ์")

🧮 วัดอำนาจของจุดเดียว — ลองตัดออกดู

วิธีตรวจที่ง่ายและตรงที่สุดคือ "ลบจุดนั้นออกแล้วคำนวณใหม่" ถ้าคำตอบเปลี่ยนเยอะ = จุดนั้นมีอำนาจเกินตัว

  • ชุดที่ 3 (มี outlier): β = 0.500 → ตัด outlier ออก เหลือ β = 0.345 · เปลี่ยนไป 31% เพราะจุดเดียว
  • ชุดที่ 4 (มี leverage point): ตัดจุดนั้นออก → x ที่เหลือเท่ากันหมด (= 8 ทุกตัว) · คำนวณความชันไม่ได้เลย — แปลว่าความชัน 0.500 ที่เห็น มาจากจุดเดียวล้วน ๆ
🐍 Python — ทดสอบว่าจุดเดียวมีอำนาจแค่ไหน
import numpy as np

x  = np.array([10,8,13,9,11,14,6,4,12,7,5], float)
y3 = np.array([7.46,6.77,12.74,7.11,7.81,8.84,6.08,5.39,8.15,6.42,5.73])

b_all, a_all = np.polyfit(x, y3, 1)
print(f"ใช้ข้อมูลครบ    : beta = {b_all:.3f}")     # ใช้ข้อมูลครบ    : beta = 0.500

keep = y3 < 12                                  # ตัดจุด outlier (y=12.74) ออก
b_cut, a_cut = np.polyfit(x[keep], y3[keep], 1)
print(f"ตัด outlier ออก : beta = {b_cut:.3f}")     # ตัด outlier ออก : beta = 0.345
print(f"เปลี่ยนไป {abs(b_cut-b_all)/b_all*100:.0f}% เพราะจุดเดียว")
# เปลี่ยนไป 31% เพราะจุดเดียว
✅ แล้วต้องทำยังไง

เจอจุดที่มีอำนาจสูง อย่าเพิ่งลบทิ้ง — ให้ถามก่อนว่ามันคืออะไร:

  • ข้อมูลผิด (พิมพ์ผิด, ราคาที่ยังไม่ปรับ split) → แก้หรือลบได้
  • เหตุการณ์จริง (วัน crash, วันประกาศงบ) → ห้ามลบ เพราะนั่นคือความเสี่ยงจริงที่คุณต้องรู้ · ให้รายงานผลทั้งแบบมีและไม่มีจุดนั้นแทน

5.3 Residual Plot — กราฟที่สำคัญที่สุดที่คนไม่ค่อยดู

อ่าน Residual Plot OLS diagnostics ★★★ ต้องรู้จัก

🎯 Thesis

"เส้น regression บอกสิ่งที่โมเดลจับได้ · residual บอกสิ่งที่โมเดลจับไม่ได้ — และความจริงที่เจ็บปวดมักซ่อนอยู่ในกองที่จับไม่ได้"

🚶 อ่านเป็นภาษาคนก่อน: residual = ค่าจริง − ค่าที่โมเดลทำนาย · เอามันมาพล็อตกับแกนนอน แล้วดูว่า "เหลือรูปแบบอะไรทิ้งไว้ไหม" · ถ้าโมเดลดี residual ควรกระจายสุ่มไร้รูปแบบรอบเส้นศูนย์ — เพราะทุกอย่างที่มีรูปแบบ โมเดลควรจับไปหมดแล้ว · ถ้ายังเห็นรูปแบบ = โมเดลยังพลาดอะไรอยู่

residual = y จริง − y ที่โมเดลทำนาย เป้าหมาย: กระจายสุ่มรอบ 0 · ไม่มีรูปทรง · ความกว้างสม่ำเสมอ
เห็นรูปแบบนี้แปลว่าทำยังไงต่อ
✅ สุ่มไร้รูปแบบโมเดลจับสิ่งที่จับได้หมดแล้วใช้ผลได้ตามปกติ
❌ โค้ง (U หรือ ∩)ความสัมพันธ์จริงไม่เป็นเส้นตรงเติมพจน์ x² · หรือใช้ log · หรือเปลี่ยนโมเดล
❌ กรวย (บานออก)heteroskedasticity — ความผันผวนของ error ไม่คงที่β ยังใช้ได้ แต่ SE/p-value ผิด → ใช้ robust SE (บทที่ 6)
❌ คลื่นautocorrelation — error วันนี้เกี่ยวกับเมื่อวานใช้ Newey-West SE · หรือใส่ตัวแปร lag (บทที่ 7)
💎 กรวยใบนั้น คุณเคยเจอมาแล้วในเล่ม 1

รูป "กรวยบานออก" คือภาพของ ความผันผวนที่ไม่คงที่ — และนั่นคือ volatility clustering ที่เล่ม 1 Part IV §8.2 สอนไว้เป๊ะ ๆ

ชื่อทางการของอาการนี้คือ heteroskedasticity · และถ้าเอาไปเทียบกับชื่อเต็มของโมเดลที่เราใช้พยากรณ์ σ จะเห็นว่า ARCH = AutoRegressive Conditional Heteroskedasticity — ตัว H ตัวนั้นคือคำนี้ · เล่ม 1 สอน GARCH ไปแล้วโดยไม่เคยบอกว่าชื่อมันแปลว่าอะไร ตอนนี้คุณรู้แล้ว: GARCH เกิดมาเพื่อจัดการกับ "กราฟกรวย" ใบนี้โดยเฉพาะ

🐍 Python — วาด residual plot ของข้อมูลตัวเอง
# pip install matplotlib numpy
import numpy as np
import matplotlib
matplotlib.use("Agg")            # บันทึกเป็นไฟล์ (ไม่ต้องมีหน้าจอ)
import matplotlib.pyplot as plt

rng = np.random.default_rng(11)
x = np.linspace(0, 1, 120)
y = 2 + 3*x + rng.normal(0, 0.15 + 0.9*x)    # จงใจให้ error บานตาม x

beta, alpha = np.polyfit(x, y, 1)
resid = y - (alpha + beta*x)                  # ★ หัวใจ: ค่าจริง − ค่าทำนาย

plt.figure(figsize=(6,3))
plt.axhline(0, color="gray", ls="--", lw=1)
plt.scatter(x, resid, s=14, color="#d97706")
plt.xlabel("x"); plt.ylabel("residual")
plt.tight_layout(); plt.savefig("residual.png", dpi=120)

# วัดเป็นตัวเลขด้วย: เทียบความกว้างของ residual ครึ่งแรก vs ครึ่งหลัง
half = len(x)//2
sd_left, sd_right = resid[:half].std(), resid[half:].std()
print(f"SD ครึ่งซ้าย = {sd_left:.3f}")        # SD ครึ่งซ้าย = 0.358
print(f"SD ครึ่งขวา = {sd_right:.3f}")        # SD ครึ่งขวา = 0.880
print(f"อัตราส่วน = {sd_right/sd_left:.1f} เท่า → กรวยชัดเจน")
# อัตราส่วน = 2.5 เท่า → กรวยชัดเจน
✅ อ่านผลลัพธ์

ไม่ต้องเดาจากตาอย่างเดียว — วัดได้ · residual ครึ่งขวากว้างกว่าครึ่งซ้าย 2.5 เท่า = กรวยของจริง · กฎนิ้วโป้ง: อัตราส่วนเกิน ~2 เท่าเมื่อไร ให้ถือว่ามี heteroskedasticity แล้วเปลี่ยนไปใช้ robust SE

✍️ ลองทำเอง

เปลี่ยนบรรทัดสร้างข้อมูลเป็น y = 2 + 3*x + rng.normal(0, 0.4, len(x)) (error กว้างคงที่) แล้วรันใหม่ · คาดเดาก่อน: อัตราส่วนควรใกล้เท่าไร?

ดูเฉลย

ได้ 1.14 (SD ซ้าย 0.353 · ขวา 0.403) — ใกล้ 1 มาก เพราะ error กว้างเท่ากันตลอด = homoskedastic · residual plot จะเป็นแถบสม่ำเสมอ ไม่บานเป็นกรวย ✓ · ที่ไม่ได้ 1.00 เป๊ะเพราะเป็นข้อมูลสุ่ม ค่าประมาณย่อมแกว่งเล็กน้อย

🎯 3 อย่างที่ต้องจำเรื่อง residual
  • residual ที่ดีต้องน่าเบื่อ — สุ่ม ไร้รูปแบบ ความกว้างสม่ำเสมอ
  • เห็นรูปทรง = โมเดลส่งสัญญาณว่ายังพลาดอะไรอยู่ (โค้ง/กรวย/คลื่น = คนละปัญหา คนละวิธีแก้)
  • กรวยไม่ทำให้ β ผิด แต่ทำให้ "ความมั่นใจใน β" ผิด — p-value จะหลอกคุณ (กางเต็มในบทที่ 6)

5.4 Correlation Heatmap — เห็นทั้งพอร์ตในภาพเดียว

อ่าน Correlation Heatmap Portfolio ★★★ ต้องรู้จัก

🚶 อ่านเป็นภาษาคนก่อน: พอร์ต 5 ตัวมีคู่ความสัมพันธ์ 10 คู่ · พอร์ต 20 ตัวมี 190 คู่ — อ่านเป็นตารางตัวเลขไม่ไหว · heatmap คือเอาตารางนั้นมาระบายสีแทนตัวเลข แล้วดูด้วยตาทีเดียวจบ · นี่คือหน้าตาของ covariance matrix (Σ) จาก เล่ม 2 · A ที่มองเห็นได้จริง

✅ อ่าน heatmap ใบนี้เป็นภาษาคน
  • แนวทแยงเป็น 1.00 เสมอ (ทุกอย่างสัมพันธ์กับตัวเองเต็มร้อย) — และตารางสมมาตรรอบแนวทแยง จึงอ่านแค่ครึ่งเดียวก็พอ
  • กรอบม่วง: TECH-A กับ TECH-B มี ρ = 0.86 — สูงมาก · ถือทั้งคู่แทบไม่ต่างจากถือตัวเดียวเป็นสองเท่า
  • BOND เป็นน้ำเงินทั้งแถว (−0.30, −0.26, −0.44) = สวนทางกับหุ้นทุกตัว · นี่คือของมีค่าที่สุดในพอร์ต เพราะช่วยพยุงตอนหุ้นร่วง
  • GOLD เกือบขาวหมด (−0.05, −0.02, 0.10) = แทบไม่เกี่ยวกับใครเลย — ก็มีประโยชน์ในแบบของมัน (ลดความเสี่ยงโดยไม่ผูกกับใคร)
❌ กับดักการทำ heatmap ที่เจอบ่อยที่สุด
  • ใช้ colormap สายรุ้ง (rainbow/jet) — ตาคนอ่านลำดับของสีรุ้งไม่ออก และมันสร้าง "ขอบปลอม" ที่ข้อมูลไม่มีจริง · correlation มีจุดกลางที่มีความหมาย (0) จึงต้องใช้ diverging colormap ที่ 0 = สีขาว/กลาง แล้วไล่ไปคนละทางสองข้าง (เช่น coolwarm, RdBu)
  • ไม่ล็อกสเกลสีที่ −1 ถึง +1 — ถ้าปล่อยให้ auto-scale ตามข้อมูล พอร์ตที่ correlation อยู่ 0.7–0.9 ทั้งหมดจะดูมีทั้งแดงทั้งน้ำเงิน ทั้งที่จริงสัมพันธ์กันสูงหมดทุกคู่ · ต้องกำหนด vmin=-1, vmax=1 เสมอ
  • ลืมว่า correlation เปลี่ยนตามเวลา — เลขในตารางคือค่าเฉลี่ยของช่วงที่เลือก · ตอนตลาด crash correlation ของหุ้นมักพุ่งเข้าหา 1 พร้อมกันหมด (ดู §5.5)
🐍 Python — วาด correlation heatmap ให้ถูกหลัก
# pip install matplotlib numpy
import numpy as np
import matplotlib; matplotlib.use("Agg")
import matplotlib.pyplot as plt

names = ["TECH-A","TECH-B","BANK","GOLD","BOND"]
C = np.array([[ 1.00, 0.86, 0.42,-0.05,-0.30],
              [ 0.86, 1.00, 0.38,-0.02,-0.26],
              [ 0.42, 0.38, 1.00, 0.10,-0.44],
              [-0.05,-0.02, 0.10, 1.00, 0.18],
              [-0.30,-0.26,-0.44, 0.18, 1.00]])

fig, ax = plt.subplots(figsize=(5,4))
im = ax.imshow(C, cmap="coolwarm", vmin=-1, vmax=1)   # ★ diverging + ล็อกสเกล
ax.set_xticks(range(5), names, rotation=45)
ax.set_yticks(range(5), names)
for i in range(5):
    for j in range(5):                                 # เขียนตัวเลขทับลงไปด้วย
        ax.text(j, i, f"{C[i,j]:.2f}", ha="center", va="center", fontsize=8)
fig.colorbar(im); fig.tight_layout(); fig.savefig("heatmap.png", dpi=120)

# อ่านเป็นตัวเลข: คู่ไหนสัมพันธ์สูงสุด (ไม่นับแนวทแยง)
iu = np.triu_indices(5, k=1)                           # เอาสามเหลี่ยมบน
pairs = sorted(zip(C[iu], [(names[i],names[j]) for i,j in zip(*iu)]), reverse=True)
for v,(a,b) in pairs[:3]:
    print(f"{a:7s} & {b:7s}: {v:+.2f}")
# TECH-A  & TECH-B : +0.86
# TECH-A  & BANK   : +0.42
# TECH-B  & BANK   : +0.38
print(f"\ncorrelation เฉลี่ยทั้งพอร์ต = {C[iu].mean():+.3f}")
# correlation เฉลี่ยทั้งพอร์ต = +0.087
🎯 3 อย่างที่ต้องจำเรื่อง heatmap
  • diverging colormap + ล็อก vmin/vmax ที่ −1..+1 เสมอ (ไม่งั้นสีหลอก)
  • มองหา "กลุ่มสีแดงติดกัน" = ของที่ซ้ำกันในพอร์ต ไม่ใช่การกระจายเสี่ยงจริง
  • ช่องสีน้ำเงิน คือของหายาก — สินทรัพย์ที่สวนทางคือตัวที่ทำให้ wᵀΣw หดลงจริง (เล่ม 2 · A)

5.5 🎓 เอาไปใช้จริง — จากกราฟสู่การตัดสินใจ

อ่านกราฟเป็นแล้วต้องจบที่ "แล้วยังไงต่อ" · สามสถานการณ์ที่ใช้ได้ทันที:

🧮 สถานการณ์ที่ 1 — "พอร์ตผมกระจายความเสี่ยงจริงหรือหลอก"

ทำ: วาด heatmap ของพอร์ตตัวเอง แล้วดู correlation เฉลี่ย (ไม่นับแนวทแยง)

  • เฉลี่ย > 0.7 → ถือ 10 ตัวก็เหมือนถือตัวเดียว · เพิ่มจำนวนหุ้นไม่ช่วยแล้ว ต้องหาของคนละประเภท
  • เฉลี่ย 0.3–0.7 → ปกติสำหรับหุ้นตลาดเดียวกัน
  • เฉลี่ย < 0.3 → กระจายได้ดี (พอร์ตตัวอย่างข้างบน = +0.087 ถือว่าดีมาก เพราะมีทั้งทองและพันธบัตร)

ต่อยอด: เอา Σ ก้อนนี้ไปเข้า Markowitz ใน เล่ม 2 · B เพื่อหาน้ำหนักที่ดีที่สุดได้เลย

🧮 สถานการณ์ที่ 2 — "Beta ที่ได้มา เอาไป hedge ได้ไหม"

ทำ: ก่อนใช้ β จาก เล่ม 2 · A ให้ดู 2 กราฟเสมอ

  • scatter → มีจุดไหนโดดเดี่ยวคุมเส้นอยู่ไหม (ลองตัดออกแล้วคำนวณใหม่ — ถ้า β เปลี่ยนเกิน ~20% อย่าเชื่อ)
  • residual plot → เป็นกรวยไหม · ถ้าใช่ β ยังพอใช้ได้ แต่ "ช่วงความมั่นใจ" ที่โปรแกรมรายงานจะแคบเกินจริง → ต้องใช้ robust SE (บทที่ 6)
🧮 สถานการณ์ที่ 3 — "correlation ที่เห็น จะอยู่ถึงพรุ่งนี้ไหม"

ทำ: อย่าดู correlation ค่าเดียวจากข้อมูลทั้งก้อน · ให้พล็อต rolling correlation (คำนวณจากหน้าต่างเลื่อน เช่น 60 วัน) แล้วดูว่ามันนิ่งหรือเหวี่ยง

สิ่งที่มักเห็น: correlation ระหว่างหุ้นที่ปกติอยู่ราว 0.3–0.5 พุ่งเข้าหา 0.9 ตอนตลาด crash · แปลว่าการกระจายเสี่ยงหายไปพอดีตอนที่คุณต้องการมันที่สุด — นี่คือเหตุผลที่กล่องเตือน "estimation error" ใน เล่ม 2 · B มีอยู่

🧠 มุมที่มองต่าง — กราฟไม่ใช่ของประดับรายงาน

มือใหม่เห็น: "วาดกราฟไว้ใส่สไลด์ให้ดูเป็นมืออาชีพ"
คนทำงานกับข้อมูลเห็น: กราฟคือเครื่องมือตรวจสอบที่ใช้ก่อนเชื่อตัวเลขใด ๆ · ลำดับที่ถูกคือ วาดกราฟ → เห็นปัญหา → เลือกโมเดล/แก้ข้อมูล → ค่อยคำนวณ · ไม่ใช่คำนวณเสร็จแล้วค่อยวาดกราฟไปแปะรายงาน

✍️ ลองทำเอง — ทดสอบตัวเอง

กลับไปดูภาพเปิดบท (Anscombe 4 ใบ) อีกครั้งโดยไม่ดูเฉลย · ถ้าคุณมีข้อมูลจริงแล้ววาด residual plot ออกมาได้หน้าตาเหมือนชุดที่ 2 คุณควรทำอะไรต่อ?

ดูเฉลย

ชุดที่ 2 = ความสัมพันธ์จริงเป็นเส้นโค้ง · residual จะออกมาเป็นรูป โค้ง (ใบขวาบนใน §5.3) · วิธีแก้ไม่ใช่ลบข้อมูล แต่คือ เปลี่ยนโมเดล — เติมพจน์ x² เข้าไป หรือแปลงตัวแปรด้วย log แล้ว fit ใหม่ · ถ้ายังใช้เส้นตรงต่อไป จะพยากรณ์ผิดเป็นระบบทั้งสองปลายของช่วงข้อมูล

สรุปบทที่ 5 — ตอนนี้คุณ
  • รู้ว่าสถิติชุดเดียวกันมาจากข้อมูลคนละเรื่องได้ (Anscombe) จึงดูกราฟก่อนเสมอ
  • อ่าน scatter ออก และรู้ว่า ρ=0 ไม่ได้แปลว่าไม่เกี่ยวกัน
  • จับ outlier กับ leverage point ได้ และรู้วิธีวัดอำนาจของมัน (ตัดออกแล้วคำนวณใหม่)
  • อ่าน residual plot 4 หน้าตา และรู้ว่าแต่ละแบบต้องแก้ยังไง
  • อ่าน heatmap ของพอร์ต และบอกได้ว่ากระจายเสี่ยงจริงหรือหลอก
กราฟบอกคุณว่า "ตัวเลขนี้เชื่อได้ไหม" — บทต่อไปบอกว่า "เชื่อได้แค่ไหน" เป็นตัวเลข
📖 อ่านต่อ — บทที่ 6: OLS ที่เชื่อถือได้

residual plot บอกเราว่า "กรวยแปลว่า p-value หลอก" — แต่ p-value คืออะไร และดูตรงไหน? · บทที่ 6 จะกาง standard error · t-stat · p-value · confidence interval และสอนอ่านตาราง summary() ของ statsmodels ทีละช่อง พร้อมวิธีแก้เมื่อเจอ heteroskedasticity ด้วย robust SE

📖 ศัพท์ใหม่ในตอนนี้

Anscombe's Quartet = ชุดข้อมูล 4 ชุดที่สถิติเหมือนกันแต่กราฟต่างกัน · Scatter plot = กราฟจุดสองแกน · Outlier = จุดที่ y หลุดจากแนว · Leverage point = จุดที่ x ไกลจากกลุ่มจนคุมเส้นได้ · Residual = ค่าจริง − ค่าที่โมเดลทำนาย · Heteroskedasticity = ความผันผวนของ error ไม่คงที่ (residual เป็นกรวย) · Homoskedastic = ตรงข้าม (ความกว้างสม่ำเสมอ) · Autocorrelation = error เกี่ยวพันข้ามเวลา (residual เป็นคลื่น) · Diverging colormap = ชุดสีที่มีจุดกลางมีความหมาย · Rolling correlation = correlation จากหน้าต่างเลื่อน
