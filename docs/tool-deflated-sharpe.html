ลองเอง: backtest ของคุณกำลังโกหกอยู่ไหม

อ่านจบ = ใช้เป็น ไม่ใช่แค่รู้จัก

คุณลองปรับกลยุทธ์ไป 50 แบบ แล้วเจอตัวที่ Sharpe = 2 ในการ backtest ดูเหมือนเจอขุมทรัพย์ — แต่ความจริงคือ ถ้าคุณลองหลายแบบพอ ความบังเอิญล้วน ๆ ก็สร้าง Sharpe สูง ๆ ให้คุณได้เอง โดยไม่มี edge จริงเลยสักนิด หน้านี้ให้คุณใส่ตัวเลขจริงของ backtest ตัวเองแล้วดูว่าเหลือ edge จริงแค่ไหนหลังหักโชค

ลองดันจำนวนกลยุทธ์ที่ลองขึ้นไปเรื่อย ๆ สิ่งที่คุณจะเห็นคือ "Sharpe ที่โชคสร้างได้" ไต่สูงขึ้นเรื่อย ๆ — เพราะยิ่งคุณสุ่มหลายครั้ง โอกาสที่ครั้งใดครั้งหนึ่งจะฟลุกสวยก็ยิ่งสูง พอมันแซง Sharpe ที่คุณเห็น แปลว่าผลงานทั้งหมดของคุณอธิบายได้ด้วยความบังเอิญ ไม่ต้องมี edge จริงเลย นี่คือสาเหตุที่กลยุทธ์ "เทพใน backtest" ส่วนใหญ่ตายทันทีที่เจอเงินจริง

ถ้าคุณลองมากพอ คุณจะเจอกลยุทธ์ที่ดูสมบูรณ์แบบเสมอ — คำถามไม่ใช่ "มันดีไหม" แต่คือ "ดีกว่าที่โชคให้ได้หรือเปล่า"

กฎที่คุณเพิ่งค้นเจอด้วยมือตัวเอง

หักโชคก่อนเชื่อ backtest เสมอ
Sharpe ที่โชคให้ ≈ SE × E[maxN] · · · SE ≈ √((1 + SR²/2) / ปี)
N คือจำนวนครั้งที่คุณลอง (นับให้ครบ — ทุกการปรับจูนคือหนึ่งครั้ง) ยิ่ง N สูง แท่งที่ต้องเอาชนะยิ่งสูง ก่อนอวดกลยุทธ์ไหนว่า "เจอ edge" ให้ถามตัวเองว่า ลองไปกี่แบบกว่าจะเจอตัวนี้ — ถ้าไม่ชนะแท่งนั้นชัด ๆ แปลว่ายังพิสูจน์ไม่ได้ว่าไม่ใช่โชค

ตัวคูณ E[maxN] คือค่าคาดหวังของ Sharpe ที่ สูงที่สุด จากการสุ่ม N ครั้ง ใช้สูตรของ Bailey & López de Prado (2014): (1−γ)·Z⁻¹(1−1/N) + γ·Z⁻¹(1−1/(N·e)) โดย γ ≈ 0.5772

นี่คือสิ่งที่แยกคนที่รอดในตลาดจริงออกจากคนที่หลงกับ backtest สวย ๆ: ไม่ใช่รู้จักคำว่า overfitting แต่คือมีตัวเลขแท่งที่ต้องเอาชนะกดใส่กลยุทธ์ตัวเองได้ทันที และรู้ว่ายิ่งจูนเยอะ ยิ่งต้องขี้ระแวงผลลัพธ์มากขึ้น ไม่ใช่น้อยลง

⚠️ เครื่องมือนี้ตั้งอยู่บนสมมติฐานอะไรบ้าง
  • ผลตอบแทนเป็น iid และแจกแจงปกติ — สูตร SE = √((1+SR²/2)/ปี) ใช้ได้กับกรณีนี้เท่านั้น ถ้ากลยุทธ์ของคุณมี negative skew (carry, ขายออปชัน, market making) SE จริงจะสูงกว่านี้ แปลว่า edge จริงเหลือน้อยกว่าที่หน้านี้บอก — ซึ่งเป็นบทเรียนหลักของทั้งเล่มพอดี
  • การลอง N ครั้งเป็นอิสระต่อกัน — ในความจริงการจูนพารามิเตอร์ใกล้ ๆ กันให้ผลสหสัมพันธ์สูง ทำให้ N ที่ "มีผลจริง" น้อยกว่าที่นับ ตัวเลขนี้จึงเป็นการประเมินแบบระมัดระวัง
  • ไม่รวมต้นทุนธุรกรรม — Sharpe ที่ใส่เข้ามาควรเป็นตัวเลขหลังหักค่าคอมมิชชัน สเปรด และ market impact แล้ว ไม่ใช่ตัวเลขดิบจาก backtest
  • ไม่ใช่ p-value — ผ่านแท่งนี้ไม่ได้แปลว่ากลยุทธ์ดี แค่แปลว่า "ยังไม่ถูกอธิบายทิ้งด้วยโชคจากการลองเยอะ" การยืนยัน out-of-sample ยังจำเป็นอยู่เสมอ

✍️ ลองเอง (เฉลยได้)

เพื่อนอวดกลยุทธ์ crypto ที่ Sharpe 3 จาก backtest 2 ปี บอกว่า "ลองปรับพารามิเตอร์อยู่เป็นร้อยแบบกว่าจะเจอตัวเทพนี้" — น่าเชื่อไหม?

ไม่น่าเชื่อ. SE ≈ √((1+3²/2)/2) = √(5.5/2) = √2.75 ≈ 1.66 · ตัวคูณ E[max] ที่ N=100 ≈ 2.53 · Sharpe ที่โชคให้ ≈ 1.66 × 2.53 ≈ 4.2 ซึ่งสูงกว่า Sharpe 3 ที่เขาอวดเสียอีก แปลว่าผลงานทั้งหมดอธิบายได้ด้วยโชคจากการลองร้อยแบบบนข้อมูลแค่ 2 ปี — edge จริงติดลบ ยิ่ง "ลองเยอะกว่าจะเจอ" ยิ่งเป็นสัญญาณอันตราย ไม่ใช่จุดขาย

หน้านี้ไม่ได้เล่าประวัติว่าใครคิด Deflated Sharpe Ratio ขึ้นมา — เพราะสิ่งที่ติดตัวคุณไปคือความรู้สึกตอนดันจำนวนกลยุทธ์ขึ้นแล้วเห็นแท่งสีแดงแซง edge ของตัวเอง และนิสัยถามว่า "ลองไปกี่แบบ" ก่อนเชื่อ backtest ใด ๆ
