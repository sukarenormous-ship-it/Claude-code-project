บทที่ 8: พยากรณ์ Volatility

σ ไม่คงที่ — มันเปลี่ยนทุกวัน และมักมาเป็น "กลุ่ม" ถ้าพยากรณ์ได้ดีขึ้นนิดเดียว ก็ได้เปรียบในการตีราคา option

8.1 วิเคราะห์ "ผลตอบแทน" ไม่ใช่ "ราคา"

🚶 อ่านเป็นภาษาคนก่อน: ราคาหุ้นมี trend (ลอยขึ้นเรื่อย ๆ) จึงวิเคราะห์ยาก เรียกว่า non-stationary · แต่ "ผลตอบแทน" (returns) วนอยู่รอบ ๆ 0 ด้วยค่าเฉลี่ยและความกว้างระยะยาวคงที่ เรียกว่า stationary (ความกว้างรายวันยังเปลี่ยนได้ ซึ่งคือเรื่องของ 8.2) — วิเคราะห์ได้ เราจึงทำงานกับ returns เสมอ

8.2 Volatility Clustering — "วันแย่มาเป็นพวง"

🚶 อ่านเป็นภาษาคนก่อน: Autocorrelation ถามว่า "ค่าวันนี้เกี่ยวกับค่าเมื่อวานไหม" · จุดสำคัญคือ ทิศทางของ return แทบทำนายไม่ได้ (autocorrelation ≈ 0) แต่ ขนาดของ return (r²) เกี่ยวข้องกันสูง — วันเหวี่ยงแรงมักตามด้วยวันเหวี่ยงแรง

8.3 EWMA — ให้น้ำหนักของใหม่มากกว่า

🚶 อ่านเป็นภาษาคนก่อน: Simple MA เฉลี่ยทุกวันในหน้าต่างเท่ากันหมด → ตอบสนองช้าและกระตุก (วันเก่าหลุดหน้าต่างทีเดียวค่ากระโดด) · EWMA ให้น้ำหนักวันล่าสุดมากกว่า จึงเกาะการเปลี่ยนแปลงได้ไวและเนียนกว่า

σ²ₜ = λ·σ²ₜ₋₁ + (1−λ)·r²ₜ₋₁ λ = decay factor (RiskMetrics ใช้ λ = 0.94 กับข้อมูลรายวัน) λ = 0.94 → น้ำหนักหายครึ่งใน ln 0.5 / ln 0.94 ≈ 11 วัน · เทียบเท่าหน้าต่าง 1/(1−λ) ≈ 17 วัน

📖 อ่านสูตรว่า: "ซิกมากำลังสอง ณ เวลาที เท่ากับ แลมบ์ดา คูณ ซิกมากำลังสองเมื่อวาน บวก วงเล็บ หนึ่งลบแลมบ์ดา คูณ ผลตอบแทนเมื่อวานกำลังสอง" · โครงที่ต้องเห็น: สูตรอ้างตัวเองเมื่อวาน (recursive) — น้ำหนัก λ กับ 1−λ รวมกันได้ 1 จึงเป็นค่าเฉลี่ยถ่วงน้ำหนักของ "ที่เคยเชื่อ" กับ "ที่เพิ่งเห็น" และ σ² เมื่อวานก็ซ่อน r² ของวันก่อนไว้ด้วยน้ำหนัก (1−λ)·λ ย้อนไป k วันเหลือ (1−λ)·λᵏ จางลงเรื่อย ๆ · ลอง λ = 1: σ² ไม่เปลี่ยนเลย ไม่ฟังข่าวใหม่ · λ = 0: σ² = r² เมื่อวานล้วน ไม่มีความจำ · กับดักการอ่าน: ตัวห้อย t, t−1 คือเวลา (วันนี้, เมื่อวาน) ไม่ใช่ลบหนึ่ง · สูตรทำงานบน σ² (variance) ต้องถอดรากจึงได้ σ · λ ตัวนี้คืออัตราจาง 0.94 คนละตัวกับ λ ในบทอื่นของคลัง (Kyle's lambda, hazard rate) ดู Notation

8.4 GARCH — โมเดลพยากรณ์ σ ที่ใช้จริงที่สุด

GARCH(1,1) Engle 1982 · Bollerslev 1986 ★★★ ต้องรู้จัก

🎯 Thesis

"σ² วันนี้ = ส่วนพื้นฐาน + สะเทือนจากข่าวเมื่อวาน + ความผันผวนเมื่อวานที่ส่งต่อมา — โมเดลนี้จับ volatility clustering ได้ในสามพจน์"

🚶 อ่านเป็นภาษาคนก่อน: GARCH เดา σ² ของพรุ่งนี้จาก 3 อย่าง: ค่าคงที่ (ω) ซึ่งร่วมกับ α, β กำหนดระดับระยะยาว ω/(1−α−β), ข่าวช็อกเมื่อวาน (r²ₜ₋₁), และ σ² เมื่อวานที่ส่งต่อ (persistence)

σ²ₜ = ω + α·r²ₜ₋₁ + β·σ²ₜ₋₁ ω = ส่วนพื้นฐาน · α = ข่าวเมื่อวานสะเทือนแค่ไหน · β = σ² เมื่อวานส่งต่อแค่ไหน ω > 0, α ≥ 0, β ≥ 0 และ α + β < 1 → σ กลับสู่ค่าเฉลี่ย (mean-revert)

📖 อ่านสูตรว่า: "ซิกมากำลังสองวันนี้ เท่ากับ โอเมกา บวก แอลฟา คูณ ผลตอบแทนเมื่อวานกำลังสอง บวก เบต้า คูณ ซิกมากำลังสองเมื่อวาน" · โครงที่ต้องเห็น: EWMA ที่เติมพื้น ω และปล่อยให้ α + β ไม่ต้องเท่ากับ 1 — ส่วนต่าง 1 − α − β คือแรงดึงกลับหาค่าเฉลี่ย · ลองสถานะนิ่ง (σ² วันนี้ = σ² เมื่อวาน = r² = σ²∞): σ²∞(1 − α − β) = ω → σ²∞ = ω/(1−α−β) ตรงกับกล่องเจาะลึกข้างล่าง (0.00002/0.05 = 0.0004) · กับดักการอ่าน: α, β ตรงนี้คือน้ำหนักของ GARCH ไม่ใช่ alpha/beta ของ CAPM ในบทพอร์ต — อักษรเดียวกัน คนละความหมาย · r²ₜ₋₁ คือผลตอบแทนเมื่อวานยกกำลังสอง ไม่ใช่อัตราดอกเบี้ย r (สมมติค่าเฉลี่ยของผลตอบแทนเป็นศูนย์ ตำราหลายเล่มและ notation จึงเขียน ε² แทน r²) · สมการนี้เป็นโมเดลของความกว้าง (Var) ไม่มีอะไรบอกทิศเลย

🔬 เจาะลึก (ข้ามได้) — ค่าเฉลี่ยระยะยาวของ σ

เมื่อ α + β < 1 ระดับ variance ระยะยาวคือ σ²∞ = ω / (1 − α − β) · ระวังหน่วย: นี่คือ σ² (variance) ไม่ใช่ σ — ถ้าอยากได้ σ ระยะยาวต้องถอดราก: σ∞ = √[ ω/(1−α−β) ]

🧮 เดินเลขจริง — GARCH ทำงานยังไง

สมมติ ω = 0.00002, α = 0.1, β = 0.85 (α+β = 0.95 < 1 → mean-revert)

  • ค่าเฉลี่ยระยะยาว: σ²∞ = 0.00002/(1−0.95) = 0.0004 → σ∞ = √0.0004 = 2%/วัน
  • ถ้าเมื่อวานหุ้นเหวี่ยงแรง r = −3% (r² = 0.0009) และ σ²เมื่อวาน = 0.0004: σ²วันนี้ = 0.00002 + 0.1(0.0009) + 0.85(0.0004) = 0.00045 → σ = 2.12%/วัน (สูงขึ้นเพราะเมื่อวานเหวี่ยง = volatility clustering)
🔧 กล่องบนได้ 2.12% แต่โค้ดข้างล่างได้ 2.96% — ช็อกเดียวกันหรือเปล่า

ไม่ใช่ช็อกเดียวกัน และทั้งสองตัวเลขถูก · กล่องบนเริ่มจาก σ² เมื่อวาน = 0.0004 (ระดับปกติ) แล้วใส่ r² = 0.0009 ที่เกิดขึ้นจริงแล้ว · ช็อกวันเดียวโดนคูณด้วย α = 0.1 จึงดัน σ ขึ้นแค่ 2.12%

โค้ดเริ่มจากจุดที่ σ² ของวันนี้พุ่งไปถึง 0.0009 แล้ว (โมเดลคาดว่าวันนี้เหวี่ยงราว 3% เช่นหลังช็อกติดกันหลายวัน) แล้วพยากรณ์ไปข้างหน้าโดยยังไม่รู้ผลตอบแทนของวันถัด ๆ ไป · เมื่อไม่รู้ r² ก็ใช้ค่าคาดหวังของมันแทน ซึ่งคือ σ² เอง · สองพจน์ α·r² + β·σ² จึงรวมเป็น (α + β)·σ² ตัวเดียว

E[σ²ₜ₊ₕ] = σ²∞ + (α + β)^(h−1) · (σ²ₜ₊₁ − σ²∞) half-life ของช็อก = ln 0.5 / ln(α + β) = ln 0.5 / ln 0.95 ≈ 13.5 วัน

📖 อ่านสูตรว่า: "ค่าคาดหวังของซิกมากำลังสองอีกเอชวัน เท่ากับ ระดับระยะยาว บวก (แอลฟาบวกเบต้า) ยกกำลัง (เอชลบหนึ่ง) คูณ ส่วนที่เกินระดับระยะยาวของพรุ่งนี้" · โครงที่ต้องเห็น: ส่วนเกินจากระดับปกติหดลงคงที่ 5% ทุกวัน (คูณ 0.95) เหมือนดอกเบี้ยทบต้นแบบถอยหลัง · half-life คือจำนวนวันที่ส่วนเกินเหลือครึ่งหนึ่ง · กับดักการอ่าน: สูตรนี้หดที่ σ² ไม่ใช่ที่ σ · และเป็นค่าคาดหวัง ไม่ใช่เส้นทางจริง วันจริงยังมีช็อกใหม่เข้ามาได้ทุกวัน

แปลงเป็นรายปีก่อนเทียบกับ IV: σ∞ = 2%/วัน × √252 ≈ 31.7%/ปี (สมมติผลตอบแทนรายวันอิสระกัน) · และเวลาเทียบกับ IV ของ option อายุ h วัน ต้องใช้ค่าเฉลี่ยของ σ² ที่พยากรณ์ไว้ตลอดอายุนั้น ไม่ใช่ σ ของพรุ่งนี้วันเดียว

พยากรณ์ต่อไปหลายวัน — หลังเกิดช็อก σ พุ่งขึ้นแล้วค่อย ๆ เด้งกลับหา σ∞=2% · GARCH บอกได้ว่าเด้งกลับเร็วแค่ไหน (ใช้สูตร E[σ²ₜ₊ₕ] ในกล่องข้างบน ตัวคูณ persistence α+β ต่อวัน):

🐍 Python — พยากรณ์เส้นทาง σ หลังเกิดช็อก
from math import sqrt

w, alpha, beta = 0.00002, 0.10, 0.85       # α+β = 0.95 → mean-revert
var_inf = w / (1 - alpha - beta)           # variance ระยะยาว
print(f"sigma_inf = {sqrt(var_inf)*100:.2f}%/วัน")   # sigma_inf = 2.00%/วัน

var = 0.0009                               # σ² ของวันนี้ = 0.0009 (โมเดลคาดว่าเหวี่ยง 3%) — ไม่ใช่ r²
for k in range(1, 8):
    var = w + (alpha + beta) * var         # พยากรณ์ E[σ²] วันถัดไป
    print(f"  วัน +{k}: sigma = {sqrt(var)*100:.2f}%/วัน")
#   วัน +1: sigma = 2.96%/วัน
#   วัน +2: sigma = 2.92%/วัน
#   วัน +3: sigma = 2.88%/วัน
#   วัน +4: sigma = 2.84%/วัน   ← ค่อย ๆ ไต่ลงหา 2.00%
#   วัน +5: sigma = 2.81%/วัน
#   วัน +6: sigma = 2.77%/วัน
#   วัน +7: sigma = 2.74%/วัน
✅ อ่านผลลัพธ์

σ ไม่ได้ดิ่งกลับ 2% ทันที — มันลากยาว เพราะ persistence สูง (α+β=0.95) · นี่คือ "volatility clustering" ในรูปตัวเลข: วันแย่มาเป็นพวง แล้วจางช้า ๆ · ยิ่ง α+β ใกล้ 1 ยิ่งจางช้า (σ ติดค้างที่ระดับสูงนานขึ้น)

❌ กับดักใหญ่ที่สุดของ Part นี้ — "GARCH < IV แปลว่าแพง ขายเลย"

อย่าเพิ่ง! นี่คือกับดักที่ทำให้คนขาย vol เจ๊งมานักต่อนัก:

  • IV มักสูงกว่า realized/GARCH เป็นปกติ (ชัดที่สุดใน option ของดัชนี · หุ้นรายตัวช่องว่างเล็กกว่าและบางช่วงติดลบ) — ช่องว่างนี้คือ Variance Risk Premium (VRP) ค่าจ้างที่คนขายประกันได้รับ ไม่ใช่ "ราคาผิด" ฉะนั้น "GARCH < IV" คือสภาพปกติ ไม่ใช่สัญญาณ
  • ขาย option ดิบ ๆ = short gamma/vega + หางความเสี่ยงมหาศาล (short call = ไม่จำกัด · short put = ใหญ่มากแต่มีเพดานที่หุ้นถึง 0) — เก็บเบี้ยเล็ก ๆ ได้เรื่อย ๆ แล้ววันหายนะกลืนทุกอย่าง (เจ๊งแบบ "เก็บเหรียญหน้ารถบดถนน")
  • edge จริงเกิดเมื่อช่องว่าง VRP กว้างหรือแคบผิดปกติเทียบกับอดีตของมันเอง — และต่อให้จะเล่น ก็ต้อง delta-hedge เพื่อแยกเอาเฉพาะ vol + คุมขนาดเผื่อหาง
✅ ใช้ให้ถูก — GARCH เทียบ IV ยังไง

ใช้ GARCH เป็น "จุดอ้างอิง" ว่า realized น่าจะราว ๆ เท่าไร แล้วดูว่า IV ตอนนี้ ห่างจากค่าปกติของช่องว่าง ไปทางไหน — ไม่ใช่แค่ "IV > GARCH ก็ขาย" · และตัดสินใจโดยรู้ตัวเสมอว่ากำลังรับความเสี่ยงหางแบบไหน

บทที่ 9: วิธีเชิงตัวเลข — หา Implied Volatility

บางสมการแก้ตรง ๆ ไม่ได้ ต้องให้คอมพิวเตอร์ค่อย ๆ ลองเข้าหาคำตอบ · ตัวอย่างสำคัญสุดคือ "หา IV" — กลับสูตร Black-Scholes เพื่อถามว่า "σ เท่าไรถึงให้ราคานี้"

9.1 Bisection — แบ่งครึ่งไปเรื่อย ๆ

🚶 อ่านเป็นภาษาคนก่อน: ถ้ารู้ว่าคำตอบอยู่ระหว่าง a กับ b ก็ลองจุดกึ่งกลาง แล้วถามว่าคำตอบอยู่ครึ่งซ้ายหรือขวา ตัดทิ้งครึ่งหนึ่งทุกรอบ — ช้าแต่ชัวร์

1. เลือก a, b ที่ f(a)·f(b) < 0 (คนละเครื่องหมาย → คำตอบคั่นกลาง) 2. m = (a+b)/2 ; ดูว่า f(m) เครื่องหมายเดียวกับฝั่งไหน แล้วหุบเข้าหาอีกฝั่ง 3. ทำซ้ำจน |b−a| เล็กพอ

📖 อ่านสูตรว่า: "เลือก เอ กับ บี ที่ เอฟของเอ คูณ เอฟของบี น้อยกว่าศูนย์" · โครงที่ต้องเห็น: ผลคูณติดลบ = สองค่าคนละเครื่องหมาย จึงมีจุดที่ f = 0 คั่นอยู่ระหว่างกลางแน่ · สำหรับ IV ฟังก์ชัน f คือ BS_Price(σ) − ราคาตลาด (ตามสูตร Newton ถัดไป) และคำตอบคือ σ ที่ทำให้ f = 0 · กับดักการอ่าน: |b − a| คือความกว้างของช่วง (ทิ้งเครื่องหมาย ไม่สนว่าใครใหญ่กว่า) · m = (a+b)/2 คือจุดกึ่งกลาง ไม่ใช่ความชัน m ของ Part I — ตัวอักษรเดียวกัน คนละบท

9.2 Newton-Raphson — ใช้ความชัน (Vega) พาเข้าเป้าเร็วกว่า

🚶 อ่านเป็นภาษาคนก่อน: แทนที่จะแบ่งครึ่งมั่ว ๆ ใช้ "ความชันของฟังก์ชัน ณ จุดปัจจุบัน" ลากเส้นตรงลงไปหาแกน แล้วกระโดดไปจุดนั้น — เข้าเป้าไวมาก · สำหรับ IV ความชันที่ว่าคือ Vega

σₙ₊₁ = σₙ − ( BS_Price(σₙ) − ราคาตลาด ) / Vega(σₙ)

📖 อ่านสูตรว่า: "ซิกมาตัวถัดไป เท่ากับ ซิกมาตัวปัจจุบัน ลบ วงเล็บ ราคาบีเอสที่ซิกมานี้ ลบ ราคาตลาด หารด้วย เวก้าที่ซิกมานี้" · โครงที่ต้องเห็น: สูตรอ้างตัวเอง (recursive) แต่ "ตัวก่อน" คือการเดาครั้งก่อน ไม่ใช่เมื่อวาน · ตัวแก้คืออัตราส่วน "ราคาที่พลาดไป (บาท)" ÷ "Vega (บาทต่อ 1 หน่วย σ)" → หน่วยบาทหาย เหลือ σ ที่ต้องขยับพอดี · ลองเดาถูกแล้ว: BS_Price = ราคาตลาด → ตัวเศษ 0 → σₙ₊₁ = σₙ หยุดนิ่ง ✓ · กับดักการอ่าน: ตัวห้อย n, n+1 คือรอบที่เท่าไรของการวนซ้ำ ไม่ใช่เวลา · Vega(σₙ) คือเรียกฟังก์ชัน ณ ค่าเดานั้น ต้องคิดใหม่ทุกรอบ · Vega ต้องเป็นหน่วย "ต่อ 1 หน่วย σ" (ไม่ใช่ต่อ 1%) ตามข้อควรระวังใน Part III 7.3

เชื่อมกับ Options — เบื้องหลังเลข IV บนจอ

Newton-Raphson ใช้ Vega เป็นความชัน → เข้าเป้าในราว 2–3 รอบ เมื่อ option ไม่ไกล ATM และค่าเริ่มไม่แย่ · option ไกล ATM หรือใกล้หมดอายุมี Vega เกือบเป็นศูนย์ Newton จะกระโดดเกินจน σ ติดลบหรือไม่ลู่เข้า ระบบจริงจึงมีตัวกัน (เช่นถอยกลับไปใช้ bisection เมื่อก้าวออกนอกกรอบ) · ทุกครั้งที่เห็น "IV = 25%" บนหน้าจอ เบื้องหลังคืออัลกอริทึมนี้กำลังกลับสูตร BS อยู่

9.3 🐍 Python — หา IV จริง ๆ (bisection vs Newton)

🚶 อ่านเป็นภาษาคนก่อน: เรารู้ราคาตลาด (เช่น 12.336 ของ Call S = K = 100 · r = 5% · T = 1 ปี ชุดเดียวกับภาพข้างบน) แต่ไม่รู้ σ · ทั้งสองวิธี "เดา σ แล้วเอาไปเข้าสูตร BS (Part V §11.3) ดูว่าได้ราคาตรงไหม" ต่างกันแค่วิธีปรับค่าเดา · เราจะยืนยันว่าทั้งคู่ได้ IV = 25% กลับมา (เพราะราคา 12.336 มาจาก σ=25%)

🧮 คิดด้วยมือ — bisection 3 รอบแรก

คำตอบอยู่ในช่วง σ ∈ [1%, 100%] แน่ ๆ · ลองจุดกึ่งกลางแล้วหุบเข้า:

1[0.01, 0.505]0.25812.62สูงไป → b=m

3[0.134, 0.258]0.19610.29ต่ำไป → a=m …

ช่วงหุบครึ่งทุกรอบ ค่อย ๆ บีบเข้าหา 0.25 — ช้าแต่ชัวร์

🐍 Python — IV ด้วย 2 วิธี (นิยาม BS ซ้ำในตัว รันได้เลย)
from math import log, sqrt, exp, erf, pi

def N(x):   return 0.5*(1 + erf(x/sqrt(2)))
def phi(x): return exp(-x*x/2)/sqrt(2*pi)

def bs_call(S, K, r, sig, T):
    d1 = (log(S/K) + (r + sig**2/2)*T)/(sig*sqrt(T)); d2 = d1 - sig*sqrt(T)
    return S*N(d1) - K*exp(-r*T)*N(d2)
def vega(S, K, r, sig, T):
    d1 = (log(S/K) + (r + sig**2/2)*T)/(sig*sqrt(T))
    return S*phi(d1)*sqrt(T)

S, K, r, T, mkt = 100, 100, 0.05, 1, 12.336   # ราคาตลาดที่เห็น

# --- วิธี 1: Bisection (แบ่งครึ่ง — ช้าแต่ชัวร์) ---
a, b = 0.01, 1.0
for _ in range(50):
    m = (a + b)/2
    if bs_call(S,K,r,m,T) > mkt: b = m
    else:                        a = m
print(f"bisection IV = {(a+b)/2*100:.2f}%")          # bisection IV = 25.00%

# --- วิธี 2: Newton-Raphson (ใช้ Vega — เร็วมาก) ---
sig = 0.50                                    # เดามั่ว ๆ เริ่มที่ 50%
for i in range(3):
    diff = bs_call(S,K,r,sig,T) - mkt
    print(f"  รอบ {i}: sig={sig*100:5.2f}%  ราคา={bs_call(S,K,r,sig,T):.3f}")
    sig = sig - diff/vega(S,K,r,sig,T)        # σ ← σ − (ราคาเกิน)/Vega
print(f"newton IV = {sig*100:.2f}%")
#   รอบ 0: sig=50.00%  ราคา=21.793
#   รอบ 1: sig=24.80%  ราคา=12.260   ← กระโดดเข้าเป้าเกือบสุดใน 1 ก้าว!
#   รอบ 2: sig=25.00%  ราคา=12.336
# newton IV = 25.00%

Bisection ต้องวน ~14 รอบกว่าจะแม่น 4 ตำแหน่ง (และหลายสิบรอบถ้าเอาระดับ machine precision) · Newton ใช้ 2 รอบ เพราะมันรู้ "ความชัน" (Vega) จึงกระโดดถูกทิศถูกระยะ — จาก 50% พุ่งลงมา 24.8% แล้วเก็บรายละเอียดอีกรอบเดียว · นี่คือเหตุผลที่ทุกแพลตฟอร์มใช้ Newton (หรือญาติของมัน) คำนวณ IV แบบ real-time · ค่าเริ่ม 50% ในโค้ดเป็นการเดามั่ว ๆ ที่ยังรอด เพราะ option นี้อยู่ที่ ATM · ค่าเริ่มที่ดีกว่าสำหรับ option ใกล้ ATM คือ σ₀ ≈ √(2π/T) × C/S = √(2π) × 12.336/100 ≈ 30.9% (Brenner–Subrahmanyam) ซึ่งเริ่มใกล้คำตอบกว่ามาก

10.1 Random Walk → Binomial Tree

🚶 อ่านเป็นภาษาคนก่อน: จินตนาการราคาหุ้นเดินทีละก้าว ก้าวละ "ขึ้นหรือลง" แบบสุ่ม · ต่อก้าวเยอะ ๆ เข้า เส้นทางรวมกลายเป็นการเดินสุ่มที่ทำนายทิศไม่ได้ แต่ทำนาย "ความกว้างของการกระจาย" ได้

Binomial: u = e^(σ√Δt) (ขึ้น) · d = 1/u (ลง) p* = (e^(rΔt) − d) / (u − d) ← risk-neutral probability

📖 อ่านสูตรว่า: "ยู เท่ากับ อี ยกกำลัง ซิกมารูทเดลตาที · ดี เท่ากับ หนึ่งส่วนยู · พีสตาร์ เท่ากับ อี ยกกำลัง อาร์เดลตาที ลบ ดี หารด้วย ยู ลบ ดี" · โครงที่ต้องเห็น: p* คือตำแหน่งในช่วง (ค่า − ต่ำ)/(สูง − ต่ำ) — ถามว่า "การโตแบบปลอดเสี่ยง erΔt อยู่ตรงไหนระหว่างขา d กับขา u" จึงอยู่ใน 0–1 ตราบที่ d < erΔt < u · ตัวอย่างข้างล่าง (เลือก u = 1.2, d = 0.8 เป็นเลขกลม ไม่ผูก d = 1/u) r = 0: e⁰ = 1 → (1 − 0.8)/(1.2 − 0.8) = 0.5 · กับดักการอ่าน: ดอกจันบน p* แปลว่า "ความน่าจะเป็นในโลก risk-neutral" ไม่ใช่การคูณ และไม่ใช่โอกาสจริงที่หุ้นจะขึ้น · Δt คือความยาวก้าว (Δ = การเปลี่ยนแปลง) ไม่ใช่ Delta Greek · u, d เป็นตัวคูณราคา (1.2 = ขึ้น 20%) ไม่ใช่ % และ d ตัวนี้ไม่ใช่ d₁, d₂ ของ Black-Scholes

🧮 เดินเลขจริง — ตั้งราคา Call ด้วย tree 1 ก้าว

S₀ = 100, r = 0, หนึ่งก้าว: ขึ้นไป 120 (u=1.2) หรือลงไป 80 (d=0.8) · ตัวอย่างนี้เลือก u, d เป็นเลขกลมเพื่อให้เดินเลขง่าย จึงไม่ได้ผูก d = 1/u ตามแบบ CRR ในกล่องข้างบน — สูตร p* ใช้ได้กับ u, d คู่ใดก็ได้ที่ d < e^(rΔt) < u

  • p* = (1 − 0.8)/(1.2 − 0.8) = 0.2/0.4 = 0.5 (โอกาส risk-neutral ที่หุ้นขึ้น)
  • Call K=100: ถ้าขึ้น payoff = 120−100 = 20 · ถ้าลง payoff = 0
  • ราคา Call = 0.5×20 + 0.5×0 = 10 (r=0 จึงไม่ต้องคิดลด)

เพิ่มจำนวนก้าวให้ถี่ขึ้นเรื่อย ๆ ราคานี้จะลู่เข้าหาราคา Black-Scholes พอดี · เงื่อนไข: u และ d ต้องหดตามความยาวก้าว (u = e^(σ√Δt) แบบ CRR ข้างล่าง) · ถ้าตรึง u = 1.2, d = 0.8 ไว้แล้วแค่เพิ่มก้าว ราคาจะไม่เข้าหา BS

เชื่อมกับ Options — ตั้งราคาด้วย tree
  1. สร้าง tree ราคาหุ้น n ก้าว
  2. คำนวณ payoff ที่ปลาย (วันหมดอายุ)
  3. ย้อนกลับทีละก้าว: V = e−rΔt·[ p*·V(ขึ้น) + (1−p*)·V(ลง) ]
  4. ค่าที่ node แรก = ราคา Option · เมื่อ n → ∞ → ลู่เข้า Black-Scholes

🐍 Python — tree หลายก้าว ลู่เข้า Black-Scholes จริง

🚶 อ่านเป็นภาษาคนก่อน: ที่พูดว่า "เพิ่มก้าวแล้วลู่เข้า BS" — พิสูจน์ได้ในโค้ดไม่กี่บรรทัด · ใช้ค่า u, d, p* แบบ CRR (Cox-Ross-Rubinstein) แล้วสร้าง tree ย้อนราคากลับมา · ลองกับ Call ATM ชุดเดิม (S=K=100, r=5%, σ=25%, T=1) ที่ BS ให้ 12.336:

🐍 Python — Binomial tree (CRR) → เทียบ Black-Scholes
import numpy as np
from math import exp, sqrt

S, K, r, sig, T = 100, 100, 0.05, 0.25, 1

def binomial_call(n):
    dt = T/n
    u  = exp(sig*sqrt(dt)); d = 1/u          # ขึ้น/ลง ต่อก้าว
    p  = (exp(r*dt) - d)/(u - d)             # โอกาส risk-neutral
    disc = exp(-r*dt)
    # ราคาหุ้นที่ปลาย tree (n ก้าว) แล้วคิด payoff
    ST = np.array([S * u**j * d**(n-j) for j in range(n+1)])
    V  = np.maximum(ST - K, 0)
    # ย้อนกลับทีละก้าว: มูลค่า = คิดลด(ค่าเฉลี่ย risk-neutral)
    for step in range(n, 0, -1):
        V = disc * (p*V[1:step+1] + (1-p)*V[0:step])
    return V[0]

for n in [1, 2, 5, 10, 50, 100, 500]:
    print(f"n={n:>4} ก้าว: Call = {binomial_call(n):.4f}")
# n=   1 ก้าว: Call = 14.5706   ← หยาบมาก
# n=   2 ก้าว: Call = 11.2110
# n=   5 ก้าว: Call = 12.7946
# n=  10 ก้าว: Call = 12.0923
# n=  50 ก้าว: Call = 12.2867

10.2 Risk-Neutral Pricing — ตั้งราคาโดยไม่ต้องรู้ทิศหุ้น

Risk-Neutral Pricing Harrison-Kreps 1979 · Harrison-Pliska 1981 ★★★ ต้องรู้จัก

🎯 Thesis

"เราตั้งราคา option ได้โดยไม่ต้องเดาว่าหุ้นจะขึ้นหรือลง — เพราะ payoff ของ option สร้างเลียนแบบได้ด้วยหุ้น + พันธบัตร ราคาจึงต้องเท่ากับต้นทุนของพอร์ตเลียนแบบนั้น"

🚶 อ่านเป็นภาษาคนก่อน: ถ้าคุณผสมหุ้นกับเงินกู้ให้ได้ผลตอบแทน "เหมือน option เป๊ะทุกกรณี" แล้ว option ก็ต้องราคาเท่ากับต้นทุนของส่วนผสมนั้น — ไม่งั้นมีอาร์บิทราจ · และต้นทุนนั้นไม่ขึ้นกับความน่าจะเป็นจริงที่หุ้นจะขึ้น เราเลยคำนวณในโลกจำลอง "risk-neutral" ที่ทุกอย่างโตด้วย r ได้เลย

Option Price = e^(−rT) × E*[ Payoff ] E* = ค่าคาดหวังในโลก risk-neutral (ใช้ p* ไม่ใช่ p จริง)

📖 อ่านสูตรว่า: "ราคาออปชัน เท่ากับ อี ยกกำลัง ลบอาร์ที คูณ ค่าคาดหวังในโลกริสก์นิวทรัลของเพย์ออฟ" · โครงที่ต้องเห็น: ตัวลดค่า × ค่าคาดหวัง — ต้นไม้หนึ่งก้าวข้างบนคือกรณีย่อย: E* = p*×(payoff ขาขึ้น) + (1−p*)×(payoff ขาลง) คือค่าเฉลี่ยถ่วงน้ำหนักด้วย p* · ลอง r = 0: e⁰ = 1 → ราคาคือค่าเฉลี่ยของ payoff ตรง ๆ (ตัวอย่าง = 10) · กับดักการอ่าน: ดอกจันบน E* คือป้ายบอกว่าใช้ความน่าจะเป็นชุดไหน (p*) ไม่ใช่การคูณ — E*[·] กับ E[·] ใต้ p จริงให้เลขคนละค่า และตัวหลังคือ "การพยากรณ์" ที่สูตรนี้ไม่ได้ใช้ · ไม่มี μ (ทิศจริงของหุ้น) ในสูตรเลย · เล่ม ทฤษฎีของ Quant Part IV เขียนตัวเดียวกันว่า EQ

🧠 มุมที่มองต่าง

มือใหม่เห็น: "ต้องเดาให้แม่นว่าหุ้นจะขึ้นแค่ไหน ถึงตั้งราคา option ได้"
คนตั้งราคาเห็น: "ทิศทางหุ้นไม่เกี่ยวเลย — สิ่งที่สำคัญคือ ต้นทุนการเลียนแบบ (hedge)" นี่คือการพลิกมุมที่ทำให้ทั้งอุตสาหกรรม derivatives เกิดขึ้นได้

10.3 Brownian Motion และ GBM

🚶 อ่านเป็นภาษาคนก่อน: Brownian motion W(t) คือ random walk เวอร์ชันต่อเนื่อง (ก้าวเล็กจิ๋วถี่ยิบ) · ก่อนดูสมการ จำแค่ 2 ตัว: dt = "ก้าวเวลาสั้นจิ๋วหนึ่งก้าว" · dW = "ก้าวสุ่มสั้นจิ๋วหนึ่งก้าว (ช็อกแบบ Brownian)" · สมการราคาหุ้นของ Black-Scholes เขียนว่า:

dS/S = μ dt + σ dW

📖 อ่านสูตรว่า: "ดีเอส ส่วน เอส เท่ากับ มิว ดีที บวก ซิกมา ดีดับเบิลยู" · dS/S คือ "% ที่ราคาขยับในช่วงเวลาจิ๋ว dt" · โครงที่ต้องเห็น: ทุกสมการรูป dx = (…)dt + (…)dW มีสองส่วนเสมอ — หน้า dt คือแรงที่คาดเดาได้ (drift) หน้า dW คือความสุ่ม ที่มีขนาดราว √dt · ลอง σ = 0: เหลือ dS/S = μ dt คือหุ้นโตเรียบ ๆ แบบทบต้นต่อเนื่อง S₀·eμt จาก Part I ไม่มีความเสี่ยงเลย · กับดักการอ่าน: d นำหน้าตัวแปรอ่านว่า "การเปลี่ยนแปลงจิ๋วของ…" ไม่ใช่ตัวคูณ และไม่ใช่ d ขาลงของ binomial ข้างบน · μ คือทิศจริงของหุ้น — จะหายไปตอนตั้งราคา (10.2) เหลือแต่ σ · dW สุ่มใหม่ทุกก้าว ค่าเฉลี่ย 0 ไม่ใช่ตัวเลขคงที่

อ่านเป็นภาษาคน: "% การเปลี่ยนราคา = แนวโน้ม + ช็อกสุ่ม"

  • μ dt = drift = แนวโน้มเฉลี่ย × เวลา (ส่วนที่คาดเดาได้)
  • σ dW = ความผันผวน × ช็อกสุ่มแบบ Brownian (ส่วนที่สุ่ม)
ทำไมเป็น dS/S (ไม่ใช่ dS)

เพราะ "% การเปลี่ยน" (dS/S) ในช่วงเวลาสั้นมากเป็น Normal ไม่ใช่ "การเปลี่ยนสัมบูรณ์" (dS) · ส่วนช่วงเวลาจำกัด ln S ต่างหากที่เป็น Normal (ค่าเฉลี่ย μ − σ²/2 ต่อปี) → ราคาจึงเป็น Lognormal (เชื่อมกับ Part II 6.4) → ราคา > 0 เสมอ

10.4 Ito's Lemma — Chain Rule ของโลกสุ่ม

Ito's Lemma Itō 1951 ★★★ ต้องรู้จัก

🚶 อ่านเป็นภาษาคนก่อน: จำ Chain Rule จาก Part III ได้ไหม? Ito's Lemma คือ Chain Rule เวอร์ชันโลกสุ่ม และมันมี "พจน์พิเศษ" โผล่เพิ่มมาหนึ่งตัว — พจน์ที่เกี่ยวกับ ความโค้ง (Gamma)

🟢 มือใหม่ข้ามสมการเต็มบรรทัดล่างได้ — อ่านกล่อง "ทำไมพจน์…ไม่หาย" กับ 🧠 ด้านล่าง ก็เก็บใจความครบแล้ว

dV = (∂V/∂t)dt + (∂V/∂S)dS + ½(∂²V/∂S²)(dS)² └─ พจน์พิเศษของโลกสุ่ม ─┘

📖 อ่านสูตรว่า: "ดีวี เท่ากับ อนุพันธ์ย่อยของวีเทียบที คูณ ดีที บวก อนุพันธ์ย่อยของวีเทียบเอส คูณ ดีเอส บวก ครึ่งของอนุพันธ์ย่อยอันดับสองของวีเทียบเอส คูณ ดีเอสกำลังสอง" · โครงที่ต้องเห็น: Taylor ของ Part III 7.6 ที่เพิ่มตัวแปรเวลา — อ่านเป็น Greeks: Θ·dt + Δ·dS + ½Γ·(dS)² · ถ้า V เป็นเส้นตรงใน S (Γ = 0) พจน์ที่สามหาย เหลือ Chain Rule ธรรมดา · กับดักการอ่าน: ∂ (ย่อย) คือขยับตัวแปรเดียวตรึงที่เหลือ ส่วน dV, dS ตัว d ธรรมดาคือการเปลี่ยนแปลงจิ๋วรวมทุกสาเหตุ — คนละตัว · (dS)² ไม่ใช่ศูนย์อย่างในแคลคูลัสปกติ เพราะ (dW)² = dt (ในความหมายของผลรวม: Var(ΔW) = Δt และผลรวมของ (ΔW)² ลู่เข้าหาเวลาที่ผ่านไป) ทำให้ (dS)² = σ²S²dt (กล่องถัดไป) · ∂²V/∂S² อ่านเป็นสัญลักษณ์เดียว "อันดับสอง" ไม่ใช่ ∂ กำลังสอง

🚶 ทำไมพจน์ ½(∂²V/∂S²)(dS)² ไม่หายไป

ในแคลคูลัสปกติ ระยะยกกำลังสอง (dt)² เล็กจนตัดทิ้งได้ · แต่ในโลกสุ่มมีกฎแปลกข้อหนึ่ง: (dW)² = dt (ไม่ใช่ 0!) — ช็อกสุ่มยกกำลังสองแล้วไม่หาย มันกลายเป็นเวลา · ผลคือ (dS)² = σ²S²dt ยังอยู่ → พจน์ Gamma จึงไม่หายไป

นี่คือเหตุผลเชิงลึกว่าทำไม Gamma ถึงสำคัญ — มันคือ "ค่าแก้" ที่โลกสุ่มบังคับให้ใส่ ไม่ใช่ของแถม

🧠 มุมที่มองต่าง

มือใหม่เห็น: Ito เป็นสมการน่ากลัวสำหรับนักคณิตศาสตร์
คนเทรดเห็น: Ito แค่บอกว่า "ความเหวี่ยงของหุ้นสร้างมูลค่าให้ของที่โค้ง (Gamma)" — มันคือคณิตของประโยค "ได้ Gamma จ่าย Theta" ที่เราเจอใน Part III

10.5 Black-Scholes PDE — ปลายทางที่ทุกอย่างมาบรรจบ

Black-Scholes PDE Black-Scholes-Merton 1973 ★★★ ต้องรู้จัก

🚶 อ่านเป็นภาษาคนก่อน: เอา Ito's Lemma มาผสมกับ "การ hedge จนไม่เหลือความเสี่ยงทิศทาง" แล้วจัดรูป จะได้สมการเดียวที่ผูก Greeks ทุกตัวเข้าด้วยกัน:

🟢 มือใหม่ไม่ต้องอ่านสมการเต็มก็ได้ — ตารางแปลแต่ละพจน์เป็น Greek ด้านล่าง คือใจความจริง (ข้ามสมการดิบไปได้เลย)

∂V/∂t + ½σ²S²(∂²V/∂S²) + rS(∂V/∂S) − rV = 0

📖 อ่านสูตรว่า: "อนุพันธ์ย่อยของวีเทียบที บวก ครึ่งซิกมากำลังสอง เอสกำลังสอง คูณ อนุพันธ์ย่อยอันดับสองของวีเทียบเอส บวก อาร์เอส คูณ อนุพันธ์ย่อยของวีเทียบเอส ลบ อาร์วี เท่ากับ ศูนย์" · โครงที่ต้องเห็น: Greeks ต่อกันเป็นประโยคเดียว "Θ + ½σ²S²Γ + rSΔ − rV = 0" (ตารางข้างล่าง) — ผลรวมเป็นศูนย์ แปลว่าไม่มีพจน์ไหนได้ฟรี · ลอง V = S (ถือหุ้นเปล่า): ∂V/∂t = 0, Γ = 0, Δ = 1 → 0 + 0 + rS − rS = 0 ✓ หุ้นเองก็เป็นคำตอบหนึ่งของสมการ · กับดักการอ่าน: ∂ คืออนุพันธ์ย่อย — ∂V/∂t ขยับเวลาโดยตรึง S · ½σ²S² คูณเฉพาะพจน์ Gamma ไม่ใช่ทั้งบรรทัด · ไม่มี μ ในสมการ — ทิศจริงของหุ้นถูก hedge ทิ้งไปแล้ว เหลือ σ กับ r · สมการเดียวกันอ่านละเอียดใน ทฤษฎีของ Quant Part IV

จัดรูปใหม่ได้เป็น: Θ + ½σ²S²Γ + rSΔ = rV

อ่านเป็นภาษาคน: สำหรับ Long Option โดยทั่วไป Theta เป็นลบ (เสียค่าเวลา · ยกเว้นเช่น Put ยุโรปลึก ITM) แต่พจน์ Gamma เป็นบวก (ได้จากความโค้ง) — ทั้งสองถ่วงกันเป็นส่วนใหญ่ (ส่วนที่เหลือคือเทอม carry rSΔ กับ discount −rV ในสมการเต็มข้างบน) · ใจความคือตลาดไม่ยอมให้มี "ของฟรี": อยากได้ Gamma ต้องจ่าย Theta · ประโยคเดสก์จาก Part III กลายเป็นสมการจริงตรงนี้

🎓 รวมร่าง: GARCH เจอ IV — อ่านให้เป็น ไม่ตกกับดัก

เอาเครื่องมือทั้ง Part มาตัดสินใจจริง โดยไม่ตกกับดัก "เห็นเลขแล้วขาย"

🧮 สถานการณ์

GARCH พยากรณ์ realized σ ≈ 18%/ปี · IV ของ option ตอนนี้ = 22% · ช่องว่าง = 4 จุด · เพื่อนชวน "ขาย option เก็บส่วนต่าง"

🧭 นิสัยคิด — 4 คำถามก่อนตัดสินใจ
  1. 4 จุดนี้ ปกติหรือผิดปกติ? VRP เฉลี่ยในอดีตของสินทรัพย์นี้กี่จุด? ถ้าปกติ ~4 จุดอยู่แล้ว → นี่ไม่ใช่ signal มันคือ "ราคาตลาดปกติ"
  2. ถ้าขาย ฉัน short อะไร? short vega + short gamma → ขาดทุนหนักถ้าตลาดเหวี่ยงแรง/กระโดด
  3. หางเป็นยังไง? ขายดิบ = เก็บเบี้ยเล็ก เสี่ยงหายนะใหญ่ · ต้อง delta-hedge เพื่อแยกเอาเฉพาะ vol และคุมขนาด
  4. GARCH เชื่อได้แค่ไหนตอนนี้? ช่วงตลาดสงบ σ mean-revert; ช่วงใกล้เหตุการณ์ (งบ/เลือกตั้ง) แบบจำลองพลาดง่าย

ข้อสรุป: "IV > GARCH" ลำพัง ไม่ใช่ เหตุผลพอที่จะขาย — เหตุผลคือ "ช่องว่างกว้างผิดปกติ + เราจัดการหางได้"

✍️ ลองทำเอง

ถ้า GARCH ให้ σ ≈ 30% แต่ IV = 24% (IV ต่ำกว่า realized ที่คาด) แปลว่าอะไร และควรคิดยังไงต่อ?

ดูเฉลย

IV ต่ำกว่าที่ realized น่าจะเป็น = ผิดปกติ (เพราะ VRP มักทำให้ IV สูงกว่า) → อาจเป็นจังหวะ "ซื้อ vol" (long option/long gamma) มากกว่าขาย · แต่ยังต้องเช็ก: GARCH กำลังมองข้ามอะไรไหม (เช่นข่าวที่จะทำให้จริง ๆ เหวี่ยงน้อยลง) และถ้าซื้อก็ต้องยอมจ่าย Theta ทุกวัน

สรุป Part IV — คุณทำอะไรได้แล้วบ้าง
  • พยากรณ์ σ ด้วย GARCH — และรู้ว่า "IV > GARCH" คือ VRP ปกติ ไม่ใช่ป้ายลดราคา
  • หา IV ด้วย Newton-Raphson (ใช้ Vega เป็นความชัน)
  • เข้าใจ Risk-Neutral Pricing — ตั้งราคาโดยไม่ต้องเดาทิศหุ้น
  • อ่าน Ito's Lemma ออก — ทำไม (dW)²=dt ทำให้ Gamma ไม่หาย
  • อ่าน BS PDE เป็นสมดุล Greeks: Θ + ½σ²S²Γ + rSΔ = rV
