บทที่ 8: Linear Algebra — "จัดการหลายตัวแปรพร้อมกัน"

เมื่อ portfolio มีหุ้น 50 ตัว, Options 20 สัญญา จัดการทีละตัวไม่ไหว — Matrix ทำให้คำนวณ risk ทั้งหมดพร้อมกันได้ในสูตรเดียว

8.1 Vectors — รายการตัวเลขเรียงกัน

🔍 อุปมา: รายการช้อปปิ้ง

ไปซูเปอร์มาร์เก็ต ซื้อ: ข้าว 2 kg, ไก่ 1 kg, ผัก 0.5 kg
Vector ของปริมาณ = [2, 1, 0.5]
Vector ของราคา = [30, 80, 20] (บาท/kg)
ยอดรวม = 2×30 + 1×80 + 0.5×20 = 60 + 80 + 10 = ฿150

นี่คือ Dot Product = ∑ (ปริมาณ × ราคา) — เป็นสูตรเดียวกับ Portfolio Return!

Portfolio weights: w = [0.3, 0.5, 0.2] ← หุ้น A, B, C สัดส่วน 30%, 50%, 20%
Returns: r = [0.05, −0.02, 0.08] ← return ของแต่ละหุ้น

Dot Product: w · r = Σ wᵢrᵢ
= 0.3(0.05) + 0.5(−0.02) + 0.2(0.08) = 0.015 − 0.010 + 0.016 = 2.1%
🔍 ทำไม Dot Product จึงเท่ากับ Portfolio Return?

Portfolio Return = "ผลรวมของ return แต่ละหุ้น ถ่วงน้ำหนักด้วยสัดส่วนที่ถือ"
= w₁r₁ + w₂r₂ + w₃r₃ = Dot Product w · r
Dot Product คือ weighted sum — ตรงกับนิยาม portfolio return ทุกประการ

เชื่อมกับ Options — Portfolio Delta

ถือ Call K=100 จำนวน 2 contracts (Delta 0.6), Short Put K=95 จำนวน 1 contract (Delta −0.4)
Position vector = [2, −1], Delta vector = [0.6, −0.4]
Portfolio Delta = 2(0.6) + (−1)(−0.4) = 1.2 + 0.4 = 1.6

8.2 Matrices — ตารางสัมพันธ์ระหว่างทุกคู่

🔍 อุปมา: ตารางระยะทางระหว่างเมือง

ลองนึกตารางระยะทาง กทม.–เชียงใหม่–ภูเก็ต–ขอนแก่น (4×4 table)
แต่ละช่อง [i][j] = ระยะทางจากเมือง i ไปเมือง j
Diagonal = 0 (ห่างตัวเอง = 0), สมมาตร [i][j] = [j][i]

Correlation Matrix ทำงานเหมือนกัน:
[i][j] = correlation ระหว่างหุ้น i กับหุ้น j, Diagonal = 1.0 (corr กับตัวเอง = 1)

Correlation Matrix ของหุ้น 3 ตัว:
     A B C
A [ 1.0 0.7 0.2 ]
B [ 0.7 1.0 0.3 ]
C [ 0.2 0.3 1.0 ]

Matrix Multiplication: A(m×n) × B(n×p) = C(m×p)

🔍 ทำไม Matrix คูณแบบนี้?

แต่ละ entry ของผลลัพธ์ C[i][j] = Dot Product ของแถว i ของ A กับคอลัมน์ j ของ B
เหมือนถามว่า "แถว i 'มองเห็น' คอลัมน์ j แค่ไหน"
เป็น generalization ของ dot product สู่ multi-dimensional calculation

เชื่อมกับ Options — Covariance Matrix

Covariance Matrix (Σ) เก็บ σᵢ² ทุกตัว + Cov(i,j) ทุกคู่ในตารางเดียว
ใช้คำนวณ Portfolio Variance ของหุ้น/Options กี่ตัวก็ได้ในสูตรเดียว

8.3 Portfolio Variance ในรูป Matrix — σ²_p = wᵀΣw

🔍 อุปมา: ผสมสีทาบ้าน

ผสมสีแดง 60% + สีน้ำเงิน 40% — ความเข้มของสีผสม ขึ้นกับ:
1. ความเข้มของแต่ละสี (variance ของแต่ละหุ้น)
2. ว่าสีผสมกันเป็นยังไง (covariance ระหว่างหุ้น)

ถ้าสีสองสีผสมกันได้ดี → สีผสมสว่าง (diversification ดี)
ถ้าสีสองสีตีกัน → สีผสมมืด (diversification ไม่ช่วย)

σ²_portfolio = wᵀ Σ w
🔍 ทำไม wᵀΣw?

ขยาย Var(w₁X₁ + w₂X₂) = w₁²σ₁² + w₂²σ₂² + 2w₁w₂Cov(X₁,X₂)
เขียนเป็น matrix: [w₁ w₂] × [σ₁² Cov; Cov σ₂²] × [w₁; w₂] = wᵀΣw ✓
สูตร matrix form compact กว่า และขยายเป็น n หุ้นได้ทันทีโดยไม่ต้องเขียนใหม่

ตัวอย่าง: หุ้น 2 ตัว, w = [0.6, 0.4]

1Covariance Matrix: Σ = [ 0.04 0.01 ; 0.01 0.09 ]
(σ₁ = 20% → σ₁² = 0.04, σ₂ = 30% → σ₂² = 0.09, Cov = 0.01)
2Σw = [0.04×0.6 + 0.01×0.4; 0.01×0.6 + 0.09×0.4] = [0.028; 0.042]
3wᵀ(Σw) = 0.6×0.028 + 0.4×0.042 = 0.0168 + 0.0168 = 0.0336
4σ_p = √0.0336 = 18.3% (ต่ำกว่า σ₁=20% และ σ₂=30% ทั้งคู่!)
สังเกต: Diversification ทำงาน!

σ₁=20%, σ₂=30% แต่ Portfolio σ=18.3% — ต่ำกว่าทั้งคู่!
เพราะ Covariance ต่ำ (0.01) → หุ้นไม่ได้เคลื่อนไหวพร้อมกันตลอด
ถ้า Cov = 0: σ_p = √(0.6²×0.04 + 0.4²×0.09) = √(0.0144+0.0144) = 17.0% (ต่ำกว่าอีก)

8.4 Matrix Inverse & การแก้ระบบ Ax=b — เมทริกซ์ผกผัน

🔍 อุปมา: การ "หาร" ของเมทริกซ์

ในตัวเลขธรรมดา ถ้า 5x = 20 เราหารด้วย 5 → x = 20/5 = 4
แต่เมทริกซ์ "หาร" ตรง ๆ ไม่ได้ — เราใช้การ คูณด้วย inverse (A⁻¹) แทน:
ถ้า Ax = b → x = A⁻¹b (เหมือน x = b ÷ A)

ประโยชน์: แก้ระบบสมการหลายตัวแปรพร้อมกัน — แทนที่จะแก้ทีละสมการ เขียนเป็น Ax=b แล้วคูณ A⁻¹ ครั้งเดียวจบ

A⁻¹A = I    ← inverse คูณ matrix เดิม = Identity (เหมือน "1" ของเมทริกซ์)

สำหรับ 2×2:   A = [ a b ; c d ]
det(A) = ad − bc    ← ตัวกำหนด (determinant)

A⁻¹ = 1/(ad − bc) × [ d −b ; −c a ]    ← สลับ a↔d, ใส่ลบหน้า b,c, หารด้วย det
ตัวอย่างคำนวณ: หา inverse ของ A = [ 2 1 ; 1 3 ]
1หา determinant: det = ad − bc = (2)(3) − (1)(1) = 6 − 1 = 5 (≠ 0 → invertible)
2สลับ diagonal และใส่ลบ: [ d −b ; −c a ] = [ 3 −1 ; −1 2 ]
3หารด้วย det: A⁻¹ = 1/5 × [ 3 −1 ; −1 2 ] = [ 0.6 −0.2 ; −0.2 0.4 ]
4ตรวจ A⁻¹A = I:
  แถว 1: (0.6×2 + −0.2×1), (0.6×1 + −0.2×3) = (1.2−0.2), (0.6−0.6) = (1, 0)
  แถว 2: (−0.2×2 + 0.4×1), (−0.2×1 + 0.4×3) = (−0.4+0.4), (−0.2+1.2) = (0, 1)
  → [ 1 0 ; 0 1 ] = I ✓
เชื่อมกับ Portfolio — ทำไม inverse จึงสำคัญ

• Markowitz optimal weights: น้ำหนัก portfolio ที่ดีที่สุด w* ต้องใช้ Σ⁻¹ (inverse ของ covariance matrix) — w* ∝ Σ⁻¹μ
• Regression: สูตร OLS β̂ = (XᵀX)⁻¹Xᵀy ก็ต้อง invert matrix (XᵀX)

ระวัง singular matrix: ถ้า det = 0 → matrix ไม่มี inverse → ไม่มีคำตอบเดียวที่แน่นอน
สาเหตุในโลกจริง: ข้อมูลซ้ำซ้อน/collinear (เช่น สองหุ้นเคลื่อนไหวเหมือนกันเป๊ะ ρ=1) → แถวหนึ่ง "เล่าเรื่องเดียวกัน" กับอีกแถว → ระบบแยกไม่ออก

โจทย์ฝึก §8.4

ฝึก. หา inverse ของ A = [ 4 3 ; 2 1 ] (ถ้ามี) แล้วตรวจว่า det ≠ 0 หรือไม่

ดูเฉลย
det = (4)(1) − (3)(2) = 4 − 6 = −2 (≠ 0 → invertible)
สลับ diagonal + ใส่ลบ: [ 1 −3 ; −2 4 ]
A⁻¹ = 1/(−2) × [ 1 −3 ; −2 4 ] = [ −0.5 1.5 ; 1 −2 ]
ตรวจ A⁻¹A: แถว 1 = (−0.5×4 + 1.5×2), (−0.5×3 + 1.5×1) = (−2+3), (−1.5+1.5) = (1, 0) ✓
แถว 2 = (1×4 + −2×2), (1×3 + −2×1) = (4−4), (3−2) = (0, 1) ✓ → I

8.5 Eigenvalues — ทิศทางหลักของข้อมูล

🔍 อุปมา: รูปร่างของก้อนเมฆ

ก้อนเมฆมีรูปร่างรี ยาวไปทางทิศตะวันออก-ตะวันตก
Eigenvector หลัก = ทิศทาง E-W (ที่ขยายออกมากที่สุด)
Eigenvalue = ขนาดที่ขยาย (ยาวแค่ไหน)

Covariance matrix ของ portfolio ก็มี "รูปร่าง" — Eigenvalue บอกว่ามิติไหนสำคัญ

ถ้า A·v = λ·v แล้ว v = eigenvector, λ = eigenvalue
(Matrix A คูณ vector v ได้ผลเป็น v เดิมคูณ scalar λ)
ตัวอย่างคำนวณ: หา eigenvalues ของ Σ = [ 4 2 ; 2 3 ]
1ตั้ง characteristic equation: det(Σ − λI) = 0
  Σ − λI = [ 4−λ 2 ; 2 3−λ ]
2หา determinant = 0: (4−λ)(3−λ) − (2)(2) = 0
  = 12 − 4λ − 3λ + λ² − 4 = λ² − 7λ + 8 = 0
3แก้สมการกำลังสอง: λ = (7 ± √(49−32))/2 = (7 ± √17)/2
  √17 ≈ 4.123 → λ₁ = (7+4.123)/2 ≈ 5.56,   λ₂ = (7−4.123)/2 ≈ 1.44
4หา eigenvector ของ λ₁ ≈ 5.56: แก้ (Σ − λ₁I)v = 0
  (4 − 5.56)v₁ + 2v₂ = 0 → −1.56 v₁ + 2 v₂ = 0 → v₂ = 0.78 v₁
  เลือก v₁ = 1 → v ≈ [1, 0.78] (ทิศทางหลักที่ข้อมูลกระจายมากที่สุด)
PCA Demo — Variance Explained จาก eigenvalue

สัดส่วน variance ที่ PC แต่ละตัวอธิบาย = λᵢ / Σλ

จากตัวอย่าง: λ₁+λ₂ = 5.56 + 1.44 = 7 (= trace = 4+3 ตามคาด)
• PC1: λ₁/(λ₁+λ₂) = 5.56/7 ≈ 79% ← PC แรกอธิบาย 79% ของ variance ทั้งหมด!
• PC2: λ₂/(λ₁+λ₂) = 1.44/7 ≈ 21%

เชื่อมกับ Vol Surface: นำตรรกะ λ-ratio นี้ไปใช้กับ covariance matrix ของ IV ทั้ง surface:
• PC1 = parallel shift (level) — IV ทั้ง surface ขึ้น/ลงพร้อมกัน (eigenvalue ใหญ่สุด)
• PC2 = slope/skew — ปลายหนึ่งขึ้น อีกปลายลง
• PC3 = curvature — กลางโป่ง/บุ๋ม
ผลรวม λ₁+λ₂+λ₃ มักได้ ≈ 99% ของ Σλ → "3 PC อธิบาย ~99%" — ตอนนี้คำกล่าวนี้มีที่มาชัดเจนแล้วจากสัดส่วน eigenvalue

โจทย์ฝึก §8.5

ฝึก. หา eigenvalues ของ Σ = [ 5 1 ; 1 5 ]

ดูเฉลย
det(Σ − λI) = (5−λ)² − (1)(1) = 0
→ (5−λ)² = 1 → 5−λ = ±1 → λ = 5 ∓ 1
λ₁ = 6,   λ₂ = 4
ตรวจ: λ₁+λ₂ = 10 = trace (5+5) ✓
PC1 อธิบาย 6/10 = 60% ของ variance
เชื่อมกับ Options — PCA ลด Dimension

PCA (Principal Component Analysis) ใช้ eigenvalues ของ Σ:
• Yield Curve: 3 PC แรกอธิบาย 99% (level, slope, curvature)
• Volatility Surface: ลด dimension จาก 100+ strikes/expiry เหลือ 5–10 factors
• Eigenvalue ใหญ่ = ทิศทางที่ข้อมูลกระจายมาก = risk factor สำคัญ

8.6 Positive Definite — Covariance Matrix ต้อง Valid

ทำไม Covariance Matrix ต้อง Positive Semi-Definite?

σ²_p = wᵀΣw ต้อง ≥ 0 เสมอ (variance เป็นลบไม่ได้ในโลกจริง!)
ถ้าสร้าง correlation matrix จากข้อมูลผิดพลาด อาจได้ matrix ที่ xᵀAx < 0 สำหรับบาง x
→ แปลว่า "portfolio บางชุดมี variance ลบ" → เป็นไปไม่ได้! → ต้อง fix matrix ก่อนใช้

สรุปบทที่ 8

✓ Vector = รายการตัวเลข, Dot Product = weighted sum = Portfolio Return
✓ Matrix = ตารางสัมพันธ์ทุกคู่ → Covariance Matrix
✓ σ²_p = wᵀΣw = สูตร Portfolio Variance ที่ใช้ได้กับ n หุ้นทันที
✓ Eigenvalues → PCA → ลด dimension ของ yield curve / vol surface
✓ Covariance Matrix ต้อง PSD → variance ไม่ติดลบ

บทที่ 9: Regression & Curve Fitting — "หา Beta และ Vol Surface"

Regression = "หาเส้นที่ fit ข้อมูลดีที่สุด" — ใช้หา Beta ของหุ้น, Hedge Ratio, และ fit Volatility Surface

9.1 Simple Linear Regression

🔍 อุปมา: เส้นที่ผ่านกลุ่มจุด

มีจุดข้อมูล 100 จุด (return ตลาด vs return หุ้น) — กระจายไปทั่ว
เราอยากหาเส้นตรงที่ "ใกล้จุดทุกจุดมากที่สุด"

"ใกล้ที่สุด" = ผลรวมของ (ระยะห่างแนวตั้ง)² น้อยที่สุด (Least Squares)
เส้นนั้นคือ Regression Line: y = α + βx

มีข้อมูล (xᵢ, yᵢ) → หา β = Cov(X,Y)/Var(X) → หา α = ȳ − β·x̄ → ได้เส้นที่ minimize error²
β = Cov(X,Y) / Var(X)    ← slope (= Beta ของหุ้น!)
α = ȳ − β × x̄          ← intercept (= Alpha ของหุ้น!)

Minimize: Σᵢ(yᵢ − α − βxᵢ)² ← OLS (Ordinary Least Squares)
🔍 ทำไม β = Cov(X,Y) / Var(X)?

เราอยากหา β ที่ minimize Σ(y − α − βx)² → ทำ derivative เทียบ β แล้ว set = 0
∂/∂β [Σ(y − α − βx)²] = −2Σx(y − α − βx) = 0
แก้ออกมาได้: β = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)² = Cov(X,Y) / Var(X) ✓

เชื่อมกับ Options — Beta และ Hedge Ratio

Beta ของหุ้น = slope ของ regression: return หุ้น = α + β × return ตลาด
β = 1.5 → หุ้นผันผวนมากกว่าตลาด 1.5 เท่า
Options Hedge Ratio: ถ้า regress การเปลี่ยนแปลงราคา option (ΔV) บนการเปลี่ยนแปลงราคา underlying (ΔS) เฉพาะช่วงสั้น ๆ (ΔS เล็ก) slope ที่ได้ ≈ Delta — แต่ระวัง: ถ้า ΔS ใหญ่ slope จะเพี้ยนเพราะ Gamma (Delta เปลี่ยน) และ Vega (σ เปลี่ยน) เข้ามาแทรก ดังนั้น regression slope ให้ delta แค่ local ไม่เท่ากับ analytic delta = ∂V/∂S เป๊ะ

9.2 Regression Diagnostics & Standard Errors — ตรวจสุขภาพโมเดล

🔍 อุปมา: ตรวจสุขภาพหลัง fit เส้น

fit เส้น regression เสร็จ แล้วได้ β สวย ๆ — อย่าเพิ่งเชื่อ!
เหมือนหมอที่ต้อง "ตรวจสุขภาพ" คนไข้ก่อนบอกว่าหายดี เราต้องตรวจ residuals (ส่วนที่โมเดลทายพลาด) ก่อน

ถ้า residuals "สุขภาพดี" (สุ่มกระจายไม่มีแบบแผน) → เชื่อโมเดลได้
ถ้า residuals มี pattern → โมเดลมีปัญหาซ่อนอยู่

Residual: eᵢ = yᵢ − ŷᵢ    ← ค่าจริง − ค่าที่โมเดลทาย

plot residual vs x → ควรเป็น random scatter รอบเส้น 0 (ไม่มีรูปทรง ไม่มีแนวโน้ม)
Heteroskedasticity — ความแปรปรวนไม่คงที่

ถ้า การกระจายของ residual โตขึ้นตาม x (เล็กตอน x น้อย, บานออกตอน x มาก เป็นรูปกรวย) → variance ไม่คงที่ = heteroskedasticity

เหตุ → ผล: β ยัง unbiased (ค่าเฉลี่ยยังถูก) แต่ standard error ผิด → t-stat และ confidence interval เชื่อไม่ได้
พบบ่อยมากใน financial returns เพราะ volatility clustering (ช่วงตลาดผันผวน residual ใหญ่, ช่วงสงบ residual เล็ก)

Autocorrelation — residual สัมพันธ์กันข้ามเวลา

ถ้า residual วันนี้ทำนาย residual พรุ่งนี้ได้ (correlated over time) → ละเมิดสมมติฐานว่า error เป็นอิสระ
ตรวจด้วย Durbin-Watson statistic (ค่าใกล้ 2 = ไม่มี autocorrelation; ใกล้ 0 = บวก; ใกล้ 4 = ลบ)
พบทั่วไปใน time-series returns → standard error ต่ำเกินจริง → คิดว่า β significant ทั้งที่จริงไม่

Standard error ของ β:
se(β) = σ_resid / (√n · σ_x)
  σ_resid = ส่วนเบี่ยงเบนของ residual,   n = จำนวนจุด,   σ_x = SD ของ x

t-stat = β / se(β)    → ถ้า |t| > 2 → β significant ทางสถิติ (95%)
ตัวอย่างคำนวณ: β significant ไหม?

สมมติได้ β = 1.5, se(β) = 0.3
t-stat = β / se(β) = 1.5 / 0.3 = 5.0
|t| = 5 > 2 → significant! β แตกต่างจาก 0 อย่างมีนัยสำคัญ — เชื่อได้ว่าหุ้นมี exposure กับตลาดจริง

โจทย์ฝึก §9.2

ฝึก. regression ให้ β = 0.8, se(β) = 0.5 — β นี้ significant หรือไม่?

ดูเฉลย
t-stat = β / se(β) = 0.8 / 0.5 = 1.6
|t| = 1.6 < 2 → NOT significant
แปลว่า: ด้วยข้อมูลชุดนี้ เราแยกไม่ออกว่า β ต่างจาก 0 จริงหรือเปล่า — อาจเป็นแค่ noise
(se ใหญ่เทียบกับ β → ความไม่แน่นอนสูง — ต้องการข้อมูลมากขึ้นเพื่อยืนยัน)

9.3 Multiple Regression — หลายปัจจัยพร้อมกัน

🔍 อุปมา: ราคาบ้านขึ้นกับหลายปัจจัย

ราคาบ้าน = α + β₁(พื้นที่ m²) + β₂(ห้องนอน) + β₃(ระยะจาก BTS)
ถ้าวิ่ง regression นี้ → รู้ว่า "พื้นที่เพิ่ม 1 m² เพิ่มราคาเท่าไหร่ โดยค้างปัจจัยอื่น"

ใน Finance: return หุ้น = α + β₁(market) + β₂(size) + β₃(value) + ε

y = β₀ + β₁x₁ + β₂x₂ + ... + βₙxₙ + ε

Matrix form: y = Xβ + ε
OLS solution: β̂ = (XᵀX)⁻¹ Xᵀy    ← ใช้ Linear Algebra!
เชื่อมกับ Options — Fama-French Factor Model

Return = β₁(Market) + β₂(SMB) + β₃(HML) + α
• Hedge Market risk ด้วย Index futures (β₁)
• Hedge Size risk ด้วย Small-cap vs Large-cap spread (β₂)
• ไม่ต้อง hedge ทีละหุ้น → hedge 3 factors ครอบ portfolio ทั้งหมด

9.4 Multicollinearity — ตัวแปรซ้ำซ้อน

🔍 อุปมา: พยานสองคนเล่าเรื่องเดียวกัน

ถ้ามีพยาน 2 คนในศาล แต่ทั้งคู่ เล่าเรื่องเดียวกันเป๊ะ — ผู้พิพากษาแยกไม่ออกว่าหลักฐานมาจากใคร "ทำ" จริง

factor model ก็เหมือนกัน: ถ้าสองปัจจัยเล่าเรื่องเดียวกัน (correlated สูง) โมเดล แยกไม่ออกว่าใครทำให้ return เปลี่ยน → β ของแต่ละตัว ไม่เสถียร (กระโดดไปมา)

เหตุ → ผล:
factors correlated สูง (เช่น 2 value factors P/B กับ P/E) → (XᵀX) near-singular (det ≈ 0)
→ ต้องคูณ (XᵀX)⁻¹ ที่ "ระเบิด" (ค่ามหาศาล)
→ β estimates มี variance มหาศาล → เปลี่ยนข้อมูลนิดเดียว β พลิกเครื่องหมาย (+ เป็น −)
Detection — VIF (Variance Inflation Factor)

วิธีตรวจ: regress ปัจจัย j กับปัจจัยที่เหลือ ได้ R²ⱼ แล้วคำนวณ
VIF_j = 1 / (1 − R²ⱼ)

• ถ้าปัจจัย j ทำนายไม่ได้จากตัวอื่น (R²ⱼ ≈ 0) → VIF ≈ 1 (ดี ไม่ซ้ำซ้อน)
• ถ้าปัจจัย j ถูกตัวอื่นทำนายได้เกือบหมด (R²ⱼ = 0.9) → VIF = 1/(1−0.9) = 10
กฎ: VIF > 10 → มีปัญหา multicollinearity ชัดเจน
อีกวิธี: ดู correlation matrix ของ factors โดยตรง — ถ้าคู่ไหน |ρ| > 0.8 ให้ระวัง

วิธีแก้ — ตัด/รวม หรือใช้ PCA (เชื่อมกับบทที่ 8)

• Drop: ทิ้งปัจจัยซ้ำซ้อนตัวหนึ่งทิ้งไป (เก็บตัวที่ตีความง่ายกว่า)
• Combine: รวมสองปัจจัยที่ซ้ำเป็นตัวเดียว (เช่นเฉลี่ย value score)
• PCA: แปลง factors ที่ correlated เป็น principal components ที่ orthogonal (ตั้งฉาก ไม่ correlated) โดยสร้าง — ตรงนี้ผูกกลับไปที่ §8.5 eigenvector ของ covariance matrix factors → กำจัดความซ้ำซ้อนได้ที่ราก

โจทย์ฝึก §9.4

ฝึก. regress ปัจจัย HML กับปัจจัยอื่น ๆ ได้ R² = 0.95 — VIF เท่าไหร่ และมีปัญหา multicollinearity ไหม?

ดูเฉลย
VIF = 1 / (1 − R²) = 1 / (1 − 0.95) = 1 / 0.05 = 20
VIF = 20 > 10 → มีปัญหา multicollinearity ชัดเจน
ปัจจัย HML ถูกปัจจัยอื่นทำนายได้ถึง 95% → ซ้ำซ้อนสูง
แก้: ตัด HML ทิ้ง, หรือรวมกับปัจจัยที่ซ้ำ, หรือใช้ PCA สร้าง factor ใหม่ที่ตั้งฉากกัน

9.5 R² — วัดความดีของ Model

🔍 อุปมา: พยากรณ์อากาศ

ถ้าพยากรณ์อากาศ "แม่น" 80% → R² = 0.80
ถ้าแม่นแค่ 20% → R² = 0.20
R² = "model อธิบายความแปรปรวนของข้อมูลได้กี่ %"

R² = 1.0: predict ได้แม่นขนาดนั้นคงไม่มีในโลก finance
R² = 0.30 สำหรับ daily stock return ถือว่าดีมากแล้ว!

R² = 1 − SS_residual / SS_total
= "สัดส่วนของ variance ที่ model อธิบายได้"
R²ความหมายตัวอย่างใน Finance
0.90–1.0ดีมากBond yield vs maturity (yield curve fit)
0.50–0.90พอใช้ได้Beta regression ของหุ้น large-cap
0.10–0.50อ่อนแต่ยังมีประโยชน์Vol smile fit ด้วยสูตร simple
<0.10แย่ปัจจัยอื่นสำคัญกว่า หรือ noise มาก

9.6 Curve Fitting — Fit Volatility Surface

🔍 อุปมา: วาดเส้นโค้งผ่านจุดข้อมูล

Volatility Smile: IV ของ options หลาย Strike ไม่เป็นเส้นตรง — มีรูปร่างเป็นรอยยิ้ม/เอียง
เราอยาก fit สูตรผ่านจุดข้อมูลเหล่านั้น เพื่อ interpolate IV ของ Strike กลางๆ

Simple: σ(K) = a + bK + cK² (polynomial degree 2)
Advanced: SVI, SABR model

Polynomial Regression:
σ(K, T) = a₀ + a₁K + a₂K² + a₃T + a₄KT + ...

ยิ่งเพิ่ม term มาก ยิ่ง fit ดี แต่ระวัง Overfitting!
Overfitting — กับดักของ Curve Fitting

Degree 2: σ(K) smooth, interpolate ได้ดี
Degree 10: ผ่านทุกจุดพอดี แต่ระหว่างจุด "ถล่ม" หรือ "พุ่ง" ขึ้นผิดปกติ
กฎ: ใช้ model ที่ง่ายที่สุดที่อธิบายข้อมูลได้ดีพอ — R² เพิ่มขึ้นน้อยมากเมื่อเพิ่ม degree → หยุด

เชื่อมกับ Options — Vol Surface Fitting

Market makers ใช้ SVI/SABR fit IV surface จาก quoted prices
→ ได้สูตร σ(K, T) ที่ smooth → interpolate IV ของ strike ที่ไม่มีใน chain
→ ใช้ price exotic options, calibrate hedging

สรุปบทที่ 9

✓ Simple Regression: y = α + βx, β = Cov/Var → Beta ของหุ้น
✓ Multiple Regression: Factor Models → hedge หลาย risk factor พร้อมกัน
✓ R² = สัดส่วนที่ model อธิบายได้ — R² สูงไม่ได้แปลว่าดีเสมอ (overfitting)
✓ Curve Fitting → fit Volatility Smile/Surface

ข้อ 1. Portfolio 3 assets: w = [0.5, 0.3, 0.2], returns = [8%, −2%, 5%]
คำนวณ Portfolio Return ด้วย Dot Product

ดูเฉลย
Portfolio Return = 0.5(0.08) + 0.3(−0.02) + 0.2(0.05)
= 0.040 − 0.006 + 0.010 = 0.044 = 4.4%

ข้อ 2. หุ้น 2 ตัว: w = [0.7, 0.3], σ₁ = 25%, σ₂ = 15%, ρ = 0.4
คำนวณ Portfolio Standard Deviation

ดูเฉลย
Cov(1,2) = ρ × σ₁ × σ₂ = 0.4 × 0.25 × 0.15 = 0.015
σ²_p = (0.7)²(0.25)² + (0.3)²(0.15)² + 2(0.7)(0.3)(0.015)
= 0.49×0.0625 + 0.09×0.0225 + 2×0.21×0.015
= 0.030625 + 0.002025 + 0.006300 = 0.038950
σ_p = √0.038950 ≈ 19.7%
(น้อยกว่า weighted average = 0.7×25+0.3×15 = 22% — diversification ทำงาน!)

ข้อ 3. ข้อมูล 5 ปี: Return ตลาด = [10%, −5%, 8%, −3%, 12%], Return หุ้น = [15%, −8%, 12%, −4%, 18%]
ประมาณ Beta ของหุ้น (ใช้ข้อมูล 5 จุด)

ดูเฉลย
Mean ตลาด (x̄) = (10−5+8−3+12)/5 = 22/5 = 4.4%
Mean หุ้น (ȳ) = (15−8+12−4+18)/5 = 33/5 = 6.6%
Cov(X,Y) = Σ(xᵢ−x̄)(yᵢ−ȳ)/5:
= [(10−4.4)(15−6.6)+(−5−4.4)(−8−6.6)+(8−4.4)(12−6.6)+(−3−4.4)(−4−6.6)+(12−4.4)(18−6.6)]/5
= [5.6×8.4 + (−9.4)(−14.6) + 3.6×5.4 + (−7.4)(−10.6) + 7.6×11.4]/5
= [47.04 + 137.24 + 19.44 + 78.44 + 86.64]/5 = 368.8/5 = 73.76
Var(X) = Σ(xᵢ−x̄)²/5 = [31.36+88.36+12.96+54.76+57.76]/5 = 245.2/5 = 49.04
Beta = 73.76/49.04 ≈ 1.50 (หุ้นผันผวนมากกว่าตลาด 1.5 เท่า)
