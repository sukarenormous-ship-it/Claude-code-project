Indicator Filter + Order Accumulation

ใช้ Technical Indicators กรอง Grid Order และเทคนิค Order Accumulation สะสม Position อย่างชาญฉลาดก่อนตลาดเคลื่อนไหว
🔄

กำลังเตรียมเนื้อหา...

Part นี้อยู่ระหว่างการเขียน — กลับมาตรวจสอบเร็วๆ นี้

เนื้อหาในตอนนี้จะครอบคลุม

  • แนวคิด Indicator Filter: อนุมัติ/ปฏิเสธ Grid Order ตามสัญญาณ Indicator
  • RSI Filter: หยุดวาง Buy Order เมื่อ RSI > 70, หยุดวาง Sell Order เมื่อ RSI < 30
  • MACD Filter: ใช้ MACD Crossover ยืนยันทิศทาง Grid
  • Volume Filter: กรอง Order ในช่วง Low Volume เพื่อหลีกเลี่ยง Fake Breakout
  • Order Accumulation Pattern: วาง Order หนาแน่นในโซน Support/Resistance
  • Cluster Accumulation: รวม Order หลายระดับเป็น Cluster เพื่อ Average Cost
  • Time-based Filter: หลีกเลี่ยงช่วงเวลาที่ Liquidity ต่ำ (เช่น ช่วง Weekend)
  • Multi-indicator Scoring: รวม Score จาก Indicator หลายตัวเพื่อตัดสินใจ
  • Backtest: Filter ช่วยเพิ่ม Win Rate และลด Drawdown อย่างไร
