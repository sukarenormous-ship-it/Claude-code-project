# กายวิภาคของ "การ์ดทฤษฎี" — 9 องค์ประกอบ

หัวใจของหนังสือคือ **การ์ด** (`.card`) หนึ่งใบ = หนึ่งแนวคิด/ทฤษฎี ทุกการ์ดระดับ ★★★ ต้องครบ 9 องค์ประกอบตามลำดับนี้ (มาจากคณะผู้เชี่ยวชาญ 4 เลนส์ที่รีวิว Part I ของเล่ม A):

| # | องค์ประกอบ | กล่อง/คลาส | หัวใจ |
|---|---|---|---|
| 1 | **🎯 Thesis** | `.bx .bp` | ประโยคเดียวที่จับหัวใจแนวคิด |
| 2 | **❓ ทำไมต้องรู้จัก** | `.why` (เส้นประ) | ถ้าไม่รู้จะพลาด/ต่อยอดอะไรไม่ได้ — ทำไม*ผู้อ่าน*ต้องเสียเวลา |
| 3 | **🔧 ใช้ทำอะไร** | `.bx .bb` | ประโยชน์ที่จับต้องได้ |
| 4 | **✅ ใช้ได้เมื่อไร** | `.bx .bg` | เงื่อนไข/สมมติฐานที่ทำให้ใช้ได้ |
| 5 | **❌ พังเมื่อไร** | `.bx .br` | failure mode **เชิงเทคนิค** |
| 6 | **⚖️ ข้อดี/ข้อเสีย** | `.ad` (2 คอลัมน์) | trade-off **เชิงปฏิบัติ** |
| 7 | **🧠 มุมที่มองต่าง** | `.qv` (ม่วง) | "คนทั่วไปเห็น X / ผู้เชี่ยวชาญเห็น Y" |
| 8 | **📍 ปัจจุบันใช้จริง** | `.bx` เทา | วันนี้ในสนามจริงใช้ยังไง (อัปเดตล่าสุด) |
| 9 | **📚 Papers** | `.bx` เทา | ต้นฉบับของแนวคิด |

## กฎเหล็ก 3 ข้อของการ์ด

1. **"พังเมื่อไร" (#5) ≠ "ข้อเสีย" (#6)** — #5 คือ failure mode เชิงเทคนิค (สูตรพังตอนไหน), #6 คือ trade-off เชิงปฏิบัติ (แลกอะไรกับอะไร) **ห้ามเขียนซ้ำกัน**
2. **สัญชาตญาณมาก่อนสูตรเสมอ** — เหนือกล่องสูตร (`.fm`) ทุกกล่องต้องมี `🚶 อ่านเป็นภาษาคนก่อน:` อธิบายสูตรเป็นภาษาคน
3. **ห้าม hallucinate paper/เกร็ด/ตัวเลข** — อ้างเฉพาะที่มีจริง; ไม่มั่นใจให้ตัดออกหรือใช้สำนวนกลาง

## องค์ประกอบเสริมของการ์ด ★★★ (มาตรฐาน v3/v4 — ปิดช่องว่าง "ใช้เป็น")

การ์ดที่สำคัญที่สุด (★★★) เพิ่มอีก 3 กล่องเพื่อให้ผู้อ่าน "ทำเป็น" ไม่ใช่แค่ "รู้จัก":

- **🧮 ตัวอย่างการใช้งาน (worked example)** — `.bx .ba` — เดินตัวเลขจริงทีละขั้น (เช่น carry+roll = 1.76%, duration → −17%)
- **✍️ ลองทำเอง** — โจทย์สั้นให้ผู้อ่านลงมือ
- **🎯 3 อย่างที่ต้องจำ** — `.bx .bg` — สรุปการ์ดเหลือ 3 บรรทัดที่ต้องไม่ลืม

## Mini-card (ย่อแบบ *ตั้งใจ*)

การ์ดระดับ ★–★★ ใช้ mini-card ได้: **Thesis + ทำไมต้องรู้ + พังเมื่อไร + มุมที่มองต่าง + Paper** — ย่อเพราะ*ตั้งใจ* ไม่ใช่เพราะตกหล่น

## ป้ายกำกับการ์ด (ในหัว `<h3>`)

```html
<h3>ชื่อแนวคิด <span class="yr">ปี/ที่มา</span> <span class="lvl must">★★★ ต้องรู้จัก</span></h3>
```

- **`.yr`** = ป้ายปี/ที่มา (pill สีดำ) เช่น `Macaulay 1938`, `รากฐาน FI`
- **`.lvl`** = เรตติ้งดาว: `★ น่ารู้` / `★★ ควรรู้` / `★★★ ต้องรู้จัก` (★★★ ใส่คลาส `must` ให้เป็นสีแดง)
- **Difficulty tier** (ถ้าใช้): L1 (intuition) / L2 (working) / L3 (theory) — กล่อง "เจาะลึก (ข้ามได้)" สำหรับ derivation

## จังหวะ/ความหนาแน่น (density) — สำคัญต่อ visual hierarchy

- **กล่องสีติดกัน ≤ 4 ต่อการ์ด** — เกินนั้นยุบเนื้อรองเป็นร้อยแก้ว
- ทุก Part เนื้อหา: ≥1 `.pq` คั่น section + ≥1 กล่องเคส 📉 "เมื่อทฤษฎีพังจริง" + ปิดด้วยกล่องสรุป ✓ + `.pq` สะพานสู่ Part ถัดไป
- ทุก Part ปิดด้วยกล่อง "📖 ศัพท์ใหม่ในตอนนี้" (บทปิดเล่มใช้ quick index แทนได้)
