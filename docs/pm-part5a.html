Black-Scholes — "สูตรที่บอกว่าเส้นโค้งอยู่ตรงไหน"

แนวคิด: ทำไมต้องรู้?

🚶 อ่านเป็นภาษาคนก่อน: Payoff chart ณ วันหมดอายุ = เส้นหักศอก (ตรงไปตรงมา) แต่ก่อนหมดอายุ = เส้นโค้ง เพราะยังมี "โอกาส" เหลืออยู่ที่ยังไม่ถูกตัดสิน — Black-Scholes คือสูตรที่บอกว่าเส้นโค้งนั้นอยู่ตรงไหนกันแน่ ณ เวลาใดเวลาหนึ่งก่อนหมดอายุ

Black-Scholes Call Price

C = S·N(d₁) − K·e⁻ʳᵀ·N(d₂)
d₁ = [ln(S/K) + (r + σ²/2)·T] / (σ·√T)
d₂ = d₁ − σ·√T
ความหมายแต่ละส่วน

S·N(d₁) = "ส่วนที่ได้จากหุ้น" → Delta × ราคาหุ้น → มูลค่าหุ้นที่ option "ครอบครอง"

K·e⁻ʳᵀ·N(d₂) = "ส่วนที่ต้องจ่าย" → PV ของ strike × probability ที่จะต้องจ่าย

N(d₂) = probability ที่ option จบ ITM (risk-neutral) → "โอกาสที่จะได้ใช้สิทธิ"

N(d₁) = Delta = hedge ratio → "ต้องถือหุ้นกี่หุ้นเพื่อ hedge option 1 สัญญา"

Black-Scholes Put Price

P = K·e⁻ʳᵀ·N(−d₂) − S·N(−d₁)

หรือจาก PCP: P = C − S + K·e⁻ʳᵀ (ง่ายกว่าคำนวณเอง)

ตัวอย่างคำนวณ

🧮 ตัวอย่างการใช้งาน — เดินทีละขั้น

ข้อมูล: S=100, K=100, r=5%, σ=20%, T=0.5 (6 เดือน)

Step 1: คำนวณ d₁
d₁ = [ln(100/100) + (0.05 + 0.04/2)×0.5] / (0.20×√0.5)
   = [0 + (0.05 + 0.02)×0.5] / (0.20×0.7071)
   = [0.035] / [0.1414]
   = 0.2475
Step 2: คำนวณ d₂
d₂ = 0.2475 − 0.1414 = 0.1061

Step 3: หา N(d₁) และ N(d₂) จากตาราง Normal Distribution — N(0.2475) ≈ 0.5977 (Delta), N(0.1061) ≈ 0.5422 (P(ITM))

Step 4: คำนวณ Call Price
C = 100×0.5977 − 100×e⁻⁰·⁰²⁵×0.5422
  = 59.77 − 97.53×0.5422
  = 59.77 − 52.88
  = ฿6.89
Step 5: คำนวณ Put Price (ผ่าน PCP)
P = 6.89 − 100 + 97.53 = ฿4.42

ตรวจสอบ PCP: C + PV(K) = 6.89 + 97.53 = 104.42  |  P + S = 4.42 + 100 = 104.42 ✓

🎯 3 อย่างที่ต้องจำ (BS)
  • N(d₂) = probability ITM → "โอกาสที่ option จะมีค่าเมื่อหมดอายุ"
  • N(d₁) = Delta → "ต้องถือหุ้นกี่หุ้นเพื่อ hedge"
  • BS ใช้ได้แค่ European + สมมติ vol คงที่ (จริง ๆ มี smile/skew)

Digital Option Pricing — "PM ควรราคาเท่าไร?"

🚶 อ่านเป็นภาษาคนก่อน: Digital Option จ่ายเต็มจำนวนถ้า ITM ไม่จ่ายเลยถ้าไม่ — ราคาที่ยุติธรรมของมันคือ probability ที่จะ ITM (ส่วน N(d₂) เดิม) คูณด้วยตัวลดค่าเงินตามเวลา ไม่มีส่วน S·N(d₁) เหมือน Call ปกติเพราะไม่ได้จ่ายตามระยะห่างจาก strike

Digital Call = e⁻ʳᵀ × N(d₂)
🧮 ตัวอย่างการใช้งาน (ข้อมูลเดิม)
e⁻⁰·⁰²⁵ × 0.5422 = 0.9753 × 0.5422 = $0.529

ความหมาย: PM Above Yes ที่ K=100 ควรมีราคา ≈ 53¢ (ถ้า price ด้วย BS) ถ้า PM ขาย 62¢ → PM แพงกว่า Options implied 9¢ → อาจมี edge (หรือ PM มีข้อมูลมากกว่า)

Greeks Formulas — "ตัวเลข exact"

จาก Part V เรียนว่า "Delta = slope, Gamma = curvature" แต่ไม่มีสูตร — ตอนนี้เพิ่มสูตร exact

Normal PDF: N'(x)

N'(x) = (1/√(2π)) × e⁻ˣ²/² ≈ 0.3989 × e⁻ˣ²/²
(ใช้ในสูตร Gamma, Theta, Vega)

Delta — "Option เปลี่ยนเท่าไรเมื่อหุ้นขยับ ฿1"

🚶 อ่านเป็นภาษาคนก่อน: Delta คือ slope ของเส้นโค้งราคาที่บท 22 พูดถึง แต่ตอนนี้มีเลขจริง — มันบังเอิญเท่ากับ N(d₁) ตัวเดียวกับที่ใช้ในสูตร Black-Scholes ไม่ใช่เรื่องบังเอิญ เพราะ Delta คือสัดส่วนของหุ้นที่ซ่อนอยู่ในราคา option นั่นเอง

Delta_Call = N(d₁) → ค่าอยู่ระหว่าง 0 ถึง +1
Delta_Put = N(d₁) − 1 → ค่าอยู่ระหว่าง −1 ถึง 0

ตัวอย่าง: Delta_Call = N(0.2475) = 0.5977 → หุ้นขึ้น ฿1 → Call ขึ้น ≈ ฿0.60

Delta_Put = 0.5977 − 1 = −0.4023 → หุ้นขึ้น ฿1 → Put ลง ≈ ฿0.40

Gamma — "Delta เปลี่ยนเร็วแค่ไหน"

🚶 อ่านเป็นภาษาคนก่อน: ถ้า Delta คือความชัน Gamma คือ "ความชันของความชัน" — สูงสุดตรงที่ราคาหุ้นอยู่ใกล้ strike พอดี (ATM) เพราะตรงนั้นคือจุดที่ยังไม่แน่ใจว่า option จะ ITM หรือไม่ ทำให้ Delta ไวต่อการเปลี่ยนแปลงราคามากที่สุด

Gamma = N'(d₁) / (S × σ × √T) (เท่ากันสำหรับ Call และ Put)

ตัวอย่าง: N'(0.2475) = 0.3989 × e^(−0.2475²/2) = 0.3989 × e⁻⁰·⁰³⁰⁶ = 0.3989 × 0.9698 = 0.3869

Gamma = 0.3869 / (100 × 0.20 × 0.7071) = 0.3869 / 14.14 = 0.0274 → หุ้นขึ้น ฿1 → Delta เปลี่ยนประมาณ 0.027

Theta — "Option เสียค่าเท่าไรต่อวัน"

🚶 อ่านเป็นภาษาคนก่อน: ทุกวันที่ผ่านไป เวลาที่เหลือให้ราคาขยับน้อยลง — "โอกาส" ที่ option ถืออยู่จึงมีมูลค่าน้อยลงตามไปด้วย Theta คือตัวเลขที่บอกว่าเสียมูลค่าไปวันละเท่าไรจากการที่เวลาเดินหน้าเพียงอย่างเดียว ไม่เกี่ยวกับราคาหุ้นขยับเลย

Theta_Call = −S×N'(d₁)×σ/(2√T) − r×K×e⁻ʳᵀ×N(d₂)

ส่วนแรก = time decay ของ optionality (ติดลบเสมอ)  ·  ส่วนสอง = ดอกเบี้ยบน exercise price

🧮 ตัวอย่างการใช้งาน (ต่อปี)
= −(100×0.3869×0.20)/(2×0.7071) − (0.05×100×0.9753×0.5422)
= −(7.738)/(1.4142) − (2.644)
= −5.472 − 2.644 = −8.12 ต่อปี
= −8.12/365 = −฿0.022 ต่อวัน

→ ทุกวันที่ถือ Call เสียค่าประมาณ ฿0.02

Vega — "Option เปลี่ยนเท่าไรเมื่อ vol เปลี่ยน 1%"

Vega = S × N'(d₁) × √T (เท่ากันสำหรับ Call และ Put)

ตัวอย่าง: 100 × 0.3869 × 0.7071 = 27.36 (ต่อ 100% vol) → ต่อ 1% vol: 27.36/100 = ฿0.274

→ ถ้า IV เพิ่มจาก 20% เป็น 21% → option ขึ้น ≈ ฿0.27

Breeden-Litzenberger — "Butterfly = ตัวดูด Probability"

🚶 อ่านเป็นภาษาคนก่อน: ราคา Butterfly ที่แคบลงเรื่อย ๆ จนความกว้างเข้าใกล้ศูนย์ กลายเป็นเครื่องมือวัด "ตลาดคิดว่าราคาจะจบตรงจุดนี้ด้วยความน่าจะเป็นเท่าไร" — เพราะ Butterfly คือความโค้งของราคา Call เทียบกับ strike ซึ่งทางคณิตศาสตร์เท่ากับอนุพันธ์อันดับสอง

f(K) = eʳᵀ × d²C/dK²

ความหมาย: ถ้าเราหาอนุพันธ์อันดับสองของราคา Call เทียบกับ Strike → ได้ risk-neutral probability density ที่ strike นั้น

ในทางปฏิบัติ: ราคา Butterfly ที่ width → 0 = ตลาดบอกว่า "probability ที่ราคาจะจบตรง K นี้ = เท่าไร"

เชื่อมโยงกลับ: Butterfly Convexity (บทที่ 10)

C(K₁) − 2C(K₂) + C(K₃) ≥ 0 (convexity condition)

Breeden-Litzenberger อธิบายว่า ทำไม: เพราะค่านี้ = probability density × width

Probability ≥ 0 เสมอ → Butterfly price ≥ 0 เสมอ → ถ้า < 0 = arbitrage!

Expected Payoff — "ปิดลูป Payoff ≠ Prediction"

บทที่ 8 สอนว่า "Payoff ≠ Prediction — payoff chart ไม่มี probability" ตอนนี้เรา ปิดลูป: ถ้ามี probability density → คำนวณ Expected Value ได้

E[payoff] = ∫ payoff(S) × f(S) dS

= "ซ้อน probability density บน payoff chart" = พื้นที่ถ่วงน้ำหนัก = Expected Value ของ trade

ในทางปฏิบัติ (discrete): EV = Σ P(state_i) × payoff(state_i)
🧮 ตัวอย่างการใช้งาน: Bull Call Spread 100/110, net premium = 5

Width = 110−100 = 10 → Max profit ที่ S>110 = width−net = 10−5 = +5 (ไม่ใช่ +15 — อย่าลืมหักด้วย net premium!)

สมมติ probability distribution:

P(S < 100) = 40% → payoff = −5
P(100 ≤ S ≤ 110) = 35% → payoff เฉลี่ย ≈ 0 (midpoint)
P(S > 110) = 25% → payoff = +5

EV = 0.40×(−5) + 0.35×(0) + 0.25×(5) = −2 + 0 + 1.25 = −฿0.75

→ EV < 0 → trade นี้ไม่มี edge ทั้งที่ตอนแรกดูน่าสนใจ (โอกาสชนะ 60% รวมกัน) — นี่คือเหตุผลที่ต้องคำนวณ EV จริง ไม่ใช่แค่ดู payoff chart สวย ๆ (ย้ำบทเรียนจากบทที่ 8)

Kelly Criterion — "ลงทุนเท่าไรต่อ trade"

🚶 อ่านเป็นภาษาคนก่อน: รู้ EV แล้วว่า trade มี edge หรือไม่ยังไม่พอ

ต้องรู้ด้วยว่าควรเดิมพันสัดส่วนเท่าไรของเงินทุนต่อครั้ง — เดิมพันมากไปแม้ edge จริงก็เจ๊งได้จาก variance เดิมพันน้อยไปก็โตช้าเกินจำเป็น

Kelly Criterion คือสูตรหาสัดส่วนที่เหมาะสมที่สุด

f* = (b×p − q) / b
b = odds (ได้เท่าไรต่อ 1 ที่เสี่ยง)
p = probability ชนะ
q = 1−p = probability แพ้
🧮 ตัวอย่างการใช้งาน

trade ที่ชนะ 60% ของเวลา, ชนะได้ 2x ที่เสี่ยง

f* = (2×0.6 − 0.4) / 2 = (1.2−0.4)/2 = 0.4 = 40%

ในทางปฏิบัติ: ใช้ Half-Kelly (20%) เพราะ probability estimate ไม่แม่นยำ 100% → ลดขนาดเพื่อความปลอดภัย

ระวัง: สูตรนี้ใช้ได้แค่ binary outcomes!

สูตร f* = (bp−q)/b สมมติว่า ผลลัพธ์มีแค่ 2 แบบ: ชนะได้ b หรือแพ้เสีย 1

สำหรับ options ที่มี payoff แบบ continuous (spreads, condors) → ต้องใช้ generalized Kelly: f* = argmax E[log(1 + f×R)]

ในทางปฏิบัติ: ใช้สูตร binary เป็น upper bound แล้วลดด้วย Half-Kelly เพราะในโลกจริง probability เป็น estimate ไม่ใช่ fact — ถ้า estimate ผิดแค่ 5% → Full Kelly อาจทำให้เจ๊งได้

กฎ: ใช้ Half-Kelly หรือ Quarter-Kelly เสมอ
