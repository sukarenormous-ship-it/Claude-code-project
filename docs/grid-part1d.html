Grid Trading Mastery · Part 1D

Asymmetric Hybrid Grid

เมื่อ Buy-Only ปลอดภัยเกินไป แต่ Bidirectional เสี่ยงเกินไป
ทางสายกลางที่คำนวณได้ — ตัวอย่าง: BTC/USDT บน Bybit (บัญชีเดียวกับที่ใช้มาตั้งแต่ Part 0)
แก่นของ Part นี้
ไม่ใช่ pure bidirectional และไม่ใช่ full hedge ตลอดเวลา — Asymmetric Hybrid ใช้ buy-only เป็นแกนหลักเสมอ, hedge เฉพาะ inventory ที่มีอยู่จริง, และเปิด short เป็นชั้นเล็กๆ ที่จำกัดขาดทุนไว้ล่วงหน้า เฉพาะตอนตลาด sideway ชัด

1D.1 ทำไมต้องมี Part นี้

อ่านมาถึงตรงนี้ คุณน่าจะรู้สึกอึดอัดอยู่อย่างหนึ่ง

Buy-Only (Part 1A) ปลอดภัยก็จริง แต่ตอนราคาขึ้นไม่หยุด grid ขายของทิ้งไปทีละไม้จนหมดมือ — ได้กำไรก็จริง แต่ "ตกรถ" ไปพร้อมกับกำไรก้อนนั้น ราคาพุ่งต่อไปอีกเท่าไหร่ ไม่ใช่ของคุณแล้ว

Bidirectional และ Grid Hedge (Part 1B/1C) แก้ปัญหานั้นได้ด้วยการเปิด short เก็บฝั่งขาขึ้นด้วย แต่ short ไม่มีเพดานขาดทุนทางทฤษฎี — ยิ่งป้องกัน "ตกรถ" มากเท่าไหร่ ยิ่งเปิดความเสี่ยงใหม่ที่ไม่มีขอบเขตมากเท่านั้น

คำถามที่ Part นี้ตอบคือ: มีทางกลางไหมที่ไม่ต้องเลือกสุดขั้ว?

จำ Zone Waterfall จาก Part 1A ได้ไหม — แบ่งทุนเป็น Active/Standby/Floor เพื่อไม่ให้เงินทั้งก้อนเสี่ยงพร้อมกัน แนวคิดเดียวกันนั้นใช้ได้กับการแบ่งชั้น "กลยุทธ์" ไม่ใช่แค่ "โซนราคา": เงินส่วนใหญ่อยู่ในสิ่งที่ปลอดภัยที่สุด (buy-only core) เงินส่วนหนึ่งกันไว้ป้องกันของที่มีอยู่จริงเท่านั้น (hedge ตาม inventory) และมีแค่เศษเสี้ยวเล็กๆ ที่ยอมเสี่ยงเพิ่มโดยรู้ล่วงหน้าแล้วว่าเสียได้สูงสุดเท่าไหร่ (short layer ที่มี budget ตายตัว)

หลักการเดียวที่ต้องจำ: short layer ใน Part นี้ไม่ได้มีไว้ "เดาทิศทาง" แต่มีไว้เก็บเกี่ยวตลาด sideway เพิ่ม โดยรู้คำตอบของคำถามนี้ ก่อน เปิดสักออเดอร์เดียว — "ถ้าผิดทางเต็มที่ จะเสียสูงสุดเท่าไหร่"

สามชั้นนี้ประกอบกันเป็น Asymmetric Hybrid Grid — 1D.2 แบ่งสัดส่วนให้ชัด, 1D.3 ต่อจากเกมเหรียญของ Shannon ใน Part 0 ว่าเมื่อราคาหลุดขอบควรเล่นเกมนั้นต่ออย่างไรให้ปลอดภัย, และ 1D.4 ให้ระบบสลับสถานะเองตามกฎที่ตั้งไว้ล่วงหน้า ไม่ต้องตัดสินใจสดหน้างาน

1D.2 สามชั้นของทุน

เทรดเดอร์คนเดิม ตอนนี้มีทุนรวม $20,000 ที่จะแบ่งเข้าสามชั้น — สัดส่วน default ที่ใช้ได้เลยถ้ายังไม่มีเหตุผลเฉพาะเจาะจงให้ปรับ:

ชั้นสัดส่วนจำนวนเงินหน้าที่
Buy-only core75%$15,000Close System ถึง floor (Part 1A) — วิ่งตลอดเวลา ไม่ปิดเว้นแต่หลุดขอบ
Hedge reserve20%$4,000Margin + buffer สำหรับ short perp ที่ hedge เฉพาะ inventory ที่ core ถืออยู่จริง (Part 1C)
Capped short layer5%$1,000Short เพิ่มเพื่อเก็บเกี่ยว sideway — เปิดเฉพาะตอน state อนุญาต (1D.4) และมี loss budget ตายตัว (Part 1B §1B.10)

สังเกตว่าตัวเลขในตารางไม่ใช่สูตรใหม่ — core มาจาก Close System ของ Part 1A ตรงๆ, hedge reserve มาจาก Margin+Buffer ของ Part 1C, capped short มาจาก Short Loss Budget ของ Part 1B บทนี้แค่บอกว่าสามอย่างนี้ควรอยู่ด้วยกันในสัดส่วนไหน ไม่ได้สอนวิธีคำนวณแต่ละชั้นซ้ำ — ถ้าลืมสูตรให้กลับไปอ่าน Part ที่เกี่ยวข้อง

กฎที่มักถูกทำผิด

ห้ามให้ hedge reserve หรือ capped short "กินเข้าไป" ใน core — ถ้า core ยังไม่ครบ $15,000 ตาม Close System ห้ามเอาเงินจากส่วนนั้นไปเปิด short เพิ่ม เพราะ core คือสิ่งที่ทำให้ระบบไม่มีวัน bust ไม่ว่าราคาจะลงแค่ไหน (ถ้าทุนพอ) — ชั้นอื่นเป็นแค่ส่วนเสริม ไม่ใช่สลับที่กับ core ได้

1D.3 เมื่อราคาหลุดขอบ — เล่นเกม Shannon ต่ออย่างไรให้ปลอดภัย

Part 0 เล่าเกมเหรียญของ Shannon ไว้แล้ว: กำไรของ grid มาจากการ "ไม่หยุด" ปรับสมดุล — ปัญหาคือ grid ธรรมดาหยุดเล่นทันทีที่ราคาหลุดขอบ คำถามของหัวข้อนี้คือ ถ้าไม่อยากหยุด จะเล่นต่ออย่างไรให้ปลอดภัย มีสามคำตอบ เรียงจากอนุรักษ์นิยมไปเสี่ยงมากขึ้น:

ทางที่ 1 — Terminate (baseline ไม่ใช่คำแนะนำ) ปิดทุกอย่างเมื่อหลุดขอบ ปลอดภัยสุดแต่ EV = 0 (พิสูจน์ไว้ใน Part 0) ทางที่ 2 — Reset ทั้งกระดาน หลุดขอบบน → เก็บทุน+กำไรคืน ตั้ง grid ใหม่ที่ราคาปัจจุบันเป็นศูนย์กลาง หลุดขอบล่าง → ไม่ขายทิ้ง ถือ inventory ต่อ ใช้กำไรสะสมเป็นทุนของ grid ใหม่ ทางที่ 3 — เลื่อนกระดานทีละนิด (Infinity) ขายของออกทีละนิดตลอดทางขาขึ้น รักษามูลค่า position ให้คงที่ ไม่ต้องรอถึงขอบแล้วรีเซ็ตทีเดียว — เหมือนบันไดเลื่อนที่ขยับตามราคาเอง

ทางที่ 2 คือสิ่งที่ทำให้เกม Shannon เล่นต่อได้ไม่มีที่สิ้นสุด (ตราบใดที่ยังมีเงินอยู่ในเกม) ส่วนทางที่ 3 คือกลไกที่ grid bot บางเจ้าใช้จริงบน exchange อยู่แล้ว (ดูอ่านต่อท้ายหัวข้อ) — ทั้งสองทางมีคนทดสอบอิสระมาแล้วทั้งบน BTC/ETH และ FX

แต่จำไว้ก่อนดีใจ

ทางที่ 2 และ 3 ไม่ได้ลบความเสี่ยง — มันแค่แปลงเป็น inventory risk ที่ Part 1C สอนวิธี hedge ไว้แล้ว การเลือกทางที่ 2/3 แทน Terminate จึงต้องมี hedge reserve (1D.2) พร้อมใช้งานเสมอ ไม่ใช่แค่หวังว่าราคาจะกลับ

อ่านต่อ (ไม่จำเป็นต้องอ่านเพื่อใช้เล่มนี้): Dempster, Evstigneev & Schenk-Hoppé, "Volatility-Induced Financial Growth" (2007) · Chen, Chen & Jang, arXiv:2506.11921 (2025) — ทางที่ 2 · KuCoin/Pionex Infinity Grid spec — ทางที่ 3 · Rundo et al., "GTSbot" (2019, Applied Sciences) และ Jia, "Feasibility of Grid Trading for Bitcoin" (2022) — หลักฐานอิสระว่า grid+filter แบบนี้ใช้ได้จริงทั้งใน FX และ BTC

1D.4 ห้าสถานะของระบบ

แทนที่จะตัดสินใจสดหน้างานทุกครั้ง ให้ระบบอยู่ในหนึ่งใน 5 สถานะเสมอ แล้วสลับสถานะตามกฎที่ตั้งไว้ล่วงหน้า (ผูกกับ Regime State Machine ของ Part 4):

Stateคำอธิบายอนุญาตให้ทำอะไร
BUY_ONLY_COREค่าเริ่มต้น — ยังไม่มีสัญญาณ sideway ชัดBUY grid + TP sell เท่านั้น ไม่มี naked short
HYBRID_SIDEWAYH < 0.50, ADX ต่ำ (Part 4 GRID ON)Core + hedge ตาม inventory + capped short layer
HEDGE_DEFENSIVEราคาลงแรง inventory เริ่มหนักHedge 80–100% ของ inventory, ห้ามเปิด short ใหม่
TREND_UP_MIGRATIONราคาหลุดขอบบน (breakout)ปิด short ทั้งหมด → เลือกทางที่ 2 หรือ 3 จาก 1D.3 → คำนวณ zone ใหม่
FULL_PAUSEDD halt (Part 5) หรือ API/data ผิดปกติยกเลิก order ใหม่ทั้งหมด, reconcile, รอสัญญาณ resume

เงื่อนไขเปลี่ยน state ทั้งหมดมาจาก signal ที่มีอยู่แล้ว ไม่มีตัวใหม่: Hurst/ADX/BB width จาก Part 4, DD threshold จาก Part 5, breakout detection จาก Donchian zone ของ Part 3

1D.5 Decision Tree

มี spot inventory อยู่แล้ว? → ใช้ hedge ratio 50–80% ตาม funding และ liquidation buffer (Part 1C) ยังไม่มี inventory และอยากเริ่มปลอดภัย? → เปิดแค่ BUY_ONLY_CORE ก่อน (Part 1A) รอ signal sideway ชัดค่อยเพิ่มชั้น ตลาด sideway/choppy ชัด (H < 0.50, ADX ต่ำ)? → HYBRID_SIDEWAY: short layer 25–40% ของ Q_long (Part 1B §1B.10) + hedge 50–80% ราคา breakout ขึ้น (หลุดขอบบน)? → TREND_UP_MIGRATION: หยุด short ใหม่ → ปิด short ตาม stop map (Part 1B §1B.12) → เลือกทางที่ 2 (reset) หรือ 3 (infinity) จาก 1D.3 ตลาด crash/downtrend? → HEDGE_DEFENSIVE: hedge inventory 80–100% → ห้ามเพิ่ม naked short โดยไม่มี risk budget funding ติดลบแรง หรือ DD ถึง halt threshold? → FULL_PAUSE: ลด/ปิด short และ hedge ที่ไม่จำเป็น → รอ resume signal (Part 5 §5.5)

1D.7 แบบฝึกหัด

แบบฝึกหัด Part 1D
ข้อ 1: ทุนรวม $30,000 — แบ่งตามสัดส่วน default ของ 1D.2 ได้เท่าไหร่ต่อชั้น?

คำตอบ:

Core (75%) = $22,500 · Hedge reserve (20%) = $6,000 · Capped short (5%) = $1,500

ข้อ 2: ราคาหลุดขอบบนแรงมาก แต่ hedge reserve ยังไม่พร้อม (เพิ่งใช้ไปกับเหตุการณ์ก่อนหน้า) — ควรเลือกทางที่ 2 หรือ 3 จาก 1D.3?

คำตอบ:

ไม่ควรเลือกทั้งคู่ทันที — กฎใน 1D.3 บอกว่าทางที่ 2/3 ต้องมี hedge reserve พร้อมใช้งานเสมอ ถ้ายังไม่พร้อม ให้กลับไปทางที่ 1 (Terminate) ชั่วคราว หรือรอเติม hedge reserve ก่อน — เลือกความปลอดภัยของ core เหนือกำไรที่อาจเสียไปจากการรอ

ข้อ 3: ระบบอยู่ใน HEDGE_DEFENSIVE — เปิด short layer ใหม่ได้ไหมถ้าเห็นโอกาส sideway สั้นๆ ระหว่างทาง?

คำตอบ:

ไม่ได้ — ตามตาราง 1D.4, HEDGE_DEFENSIVE อนุญาตแค่ hedge inventory ห้ามเปิด short ใหม่โดยเด็ดขาด แม้จะเห็น sideway สั้นๆ เพราะ state นี้ถูกออกแบบมาให้ระบบอนุรักษ์นิยมที่สุดระหว่างที่ตลาดยังไม่นิ่งพอ ต้องรอสัญญาณเปลี่ยนกลับเป็น HYBRID_SIDEWAY อย่างเป็นทางการก่อน
