Practical Quant: Stat Arb ที่ใช้ได้จริง

Part 0 — Kalman ไม่ใช่ edge: แล้ว edge อยู่ที่ไหน
เล่มนี้เป็น คู่มือลงมือ ต่อจากเล่ม 1 (สาย Arbitrage) — ไม่ใช่ท่องทฤษฎี แต่สอนให้ รันได้จริง มีตัวเลข ตัดสินใจเป็น และรอดในโลกที่ทุกคนถือเครื่องมือชุดเดียวกัน · Part 0 คือบทตั้งหลัก: ทำไม "ได้ Kalman" ไม่เท่ากับ "ได้เงิน" และ edge จริงย้ายไปอยู่ที่ไหน
🧭 เส้นทางอ่าน

🟢 มือใหม่: อ่าน "ความจริงที่ไม่ค่อยมีใครพูด" + แผนที่ Edge (ตาราง 4 ชั้น) + กล่องสรุป ✓ ก็พอเห็นภาพทั้งเล่ม · 🔵 มีพื้น: อ่านครบ โดยเฉพาะ 📉 "เมื่อ pairs เบสิกตาย" + 🧠 มุม quant + ไอเดียเสริม 4 ข้อ · เริ่มด่วน: ข้ามไปตาราง "แผนที่ Edge" แล้วค่อยย้อนกลับมา

ความจริงที่ไม่ค่อยมีใครพูดก่อนขายคอร์ส

ลองนึกภาพนี้: คุณ · ผม · กองทุนข้างบ้าน · และเด็กมหา'ลัยอีกพันคน — ทุกคนเปิด Python ตัวเดียวกัน ดึงข้อมูลหุ้นชุดเดียวกันจากแหล่งฟรีเดียวกัน สั่ง AI เขียนสแกนหาคู่ที่ cointegrate เหมือนกัน แล้วเสียบ Kalman filter ตัวเดียวกันจากไลบรารีเดียวกัน

คำถามคือ — ถ้าทุกคนทำเหมือนกันเป๊ะ กำไรจะมาจากไหน?

คำตอบที่ตรงไปตรงมาที่สุดในเล่มนี้ และเป็นเหตุผลที่มันมีอยู่: เครื่องมือประมาณค่า (OLS, TLS, Kalman) ไม่ใช่ alpha มันคือท่อประปา ทุกบ้านมีท่อประปา — การมีท่อไม่ได้แปลว่าคุณขายน้ำได้กำไร

"ถ้าใครก็รันได้ มันไม่ใช่ edge — by definition"
นิยามที่ต้องปักหมุดก่อนอ่านต่อ
  • Edge = สิ่งที่ทำให้คุณได้เปรียบ ที่คนอื่นไม่มี/ทำตามไม่ได้ง่าย ๆ
  • Table stakes (ค่าเข้าโต๊ะ) = สิ่งที่ต้องมีเพื่อเข้าเกม แต่ทุกคนก็มี → ไม่ทำให้ชนะ

Kalman filter ในปี 2026 คือ table stakes ไม่ใช่ edge · เล่มนี้จะสอนให้คุณทำท่อประปาให้ดี (Part I–V) แล้วชี้ว่าน้ำที่ขายได้กำไรจริงอยู่บ่อไหน (Part 0 นี้ + VI–IX)

ทำไม "ได้ Kalman" ไม่เท่ากับ "ได้เงิน"

นี่ไม่ใช่ความเห็น มันมีหลักฐานเชิงประจักษ์ กลยุทธ์ pairs trading แบบคลาสสิก — จับคู่หุ้นที่เดินด้วยกัน รอมันแยกจากกัน แล้วเทรดให้มันกลับ — เคยทำกำไรงามในยุค 1960s–1990s (งานชิ้นดังของ Gatev, Goetzmann & Rouwenhorst 2006 วัดได้ราว 1.3% ต่อเดือนจากคู่ท็อป) แต่พอความรู้แพร่ออกไป ทุกคนแห่ทำ กำไรก็ถูกกินหาย

📉 เมื่อ pairs เบสิกตาย — หลักฐาน

Do & Faff (2010) ตั้งคำถามตรง ๆ ในชื่องานว่า "Does Simple Pairs Trading Still Work?" คำตอบ: กำไรของกลยุทธ์เบสิกเสื่อมลงต่อเนื่อง และเมื่อหักต้นทุนธุรกรรมจริง กำไรส่วนใหญ่หายไป โดยเฉพาะในตลาดหุ้นใหญ่ที่ liquid สุด ๆ (US large-cap) ที่คู่แข่งหนาแน่นที่สุด

สาเหตุ 2 อย่างที่ต้องจำ: (1) crowding — คนแห่ทำสัญญาณเดียวกัน edge เจือจาง · (2) cost — กำไรบางบนกระดาษ ชนค่าคอมฯ + spread + ค่ายืมช็อต แล้วติดลบ

🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: "ได้โมเดลที่แม่นกว่า = ได้กำไรมากกว่า"
quant เห็น: โมเดลที่ใครก็ก๊อปได้จะถูก arbitrage จนกำไรเป็นศูนย์เสมอ — สิ่งที่เหลือรอดคือสิ่งที่ ก๊อปยาก: บ่อที่คนอื่นเข้าไม่ถึง · ต้นทุนที่คุณคุมได้ดีกว่า · และวินัยที่จะไม่เทรดตอนไม่ควรเทรด

แผนที่ Edge — edge ย้ายไปอยู่ที่ไหน

ถ้า edge ไม่ได้อยู่ที่ตัวโมเดล แล้วอยู่ที่ไหน? เราแบ่งได้เป็น 4 ชั้น เรียงจาก "แออัดสุด" (คนแย่งกันเยอะ กำไรบาง) ไป "ทนสุด" (คนมองข้าม กำไรเหลือ)

❓ ทำไมต้องรู้แผนที่นี้

เพราะเวลาส่วนใหญ่ของรายย่อยถูกผลาญไปกับชั้นที่ผิด — นั่งจูนโมเดลในชั้นที่กองทุนพันล้านครองอยู่แล้ว แทนที่จะไปเล่นชั้นที่ตัวเองได้เปรียบ รู้แผนที่ก่อน = ไม่เสียเวลาสู้ในสนามที่ตัวเองเสียเปรียบทรัพยากร

ชั้นedge อยู่ตรงไหนแออัด?รายย่อย
A. Selection
การค้นหาความสัมพันธ์		สแกน universe ใหญ่หา relationship ที่คนอื่นมองไม่เห็น — edge อยู่ที่ การค้นหา ไม่ใช่การเทรด🔥 กำลังร้อน✅ บ่อเล็ก
B. Signal
สัญญาณ/ฟีเจอร์		ดึง residual จาก factor model แล้วให้โมเดล non-linear (DL/ML) หา patternแออัดสุด
overfit ง่ายสุด		⚠️ ระวัง
C. Regime / Risk
รู้ว่าเมื่อไรไม่เทรด		ตัดทันตอนความสัมพันธ์พัง — เป็น วินัย ไม่ใช่สัญญาณให้ arbitrage → เสื่อมช้าสุด🟢 ต่ำ✅✅ ทนสุด
D. Structural / Niche
บ่อที่คู่แข่งบาง		เล่นที่ illiquid · small-cap · non-US · crypto — เล็กเกินกองใหญ่จะลง; กระจายหลายคู่🟢 ต่ำ–กลาง✅✅ เฉพาะรายย่อย

📖 กฎ meta ของการอ่านงานวิจัย: อะไรที่ตีพิมพ์แล้ว edge เฉพาะตัวมักหมดไปแล้ว — เราอ่าน paper เพื่อเอา ทิศทาง ที่ frontier เคลื่อน และ วิธีการ มาผลิต edge เอง ไม่ใช่ก๊อป alpha สำเร็จรูป (ซึ่งตายไปตั้งแต่วันตีพิมพ์)

✍️ ลองประเมินตัวเอง

ไอเดียเทรดที่คุณมีอยู่ตอนนี้ อยู่ชั้นไหนใน 4 ชั้น? · ถ้าอยู่ B (สัญญาณจากโมเดล/AI ที่ใครก็ทำได้) ลองถามตัวเองว่า "มีใครทำตามได้ง่าย ๆ ไหม" — ถ้าได้ นั่นไม่ใช่ edge · แล้วลองคิดว่าจะขยับไป C (วินัย) หรือ D (บ่อเล็ก) ได้ยังไง

ข้อสรุปเชิงกลยุทธ์ของทั้งเล่ม

✅ edge ที่ทนสำหรับรายย่อย = C + D
  • C (วินัย/regime): ทนเพราะเป็นพฤติกรรม ไม่ใช่สัญญาณ — ไม่มีใคร arbitrage "การที่คุณตัดขาดทุนทัน" ได้
  • D (niche): ทนเพราะกองใหญ่เข้าไม่ได้ (capacity เล็กเกินไป) — จุดแข็งเฉพาะของทุนน้อย
⚠️ edge ที่รายย่อยไม่ควรไปแย่ง = A/B
  • B (DL/ML): backtest สวยหรู แต่ live อ่อนกว่ามาก + overfit หนัก + สู้ compute กองใหญ่ไม่ได้
  • A (selection): เล่นได้ แต่เฉพาะ "บ่อเล็ก" ที่กองใหญ่ไม่สแกน — ไม่ใช่ไปแย่งคู่ US large-cap
"Kalman คือของฟรีที่ทุกคนมี — ความอยู่รอดของคุณอยู่ที่ 4 ชั้นที่เหลือ"

ไอเดียเสริม — 4 มุมที่เล่มนี้จะทดสอบ (ยังเป็นสมมติฐาน)

⚠️ อ่านตรงนี้ก่อน

4 ข้อข้างล่างเป็น สมมติฐาน ไม่ใช่ข้อเท็จจริงที่พิสูจน์แล้ว — ในเล่มนี้ทุกข้อจะมาพร้อม backtest จริงในโฟลเดอร์โค้ด (vol2-code/) ให้คุณรันเองเห็นเอง ไม่มีการเคลมตัวเลขลอย ๆ นี่คือเส้นแบ่งระหว่าง "หนังสือ practical" กับ "คอร์สขายฝัน"

  1. Estimator-disagreement เป็น risk gate — เมื่อ β จาก OLS · TLS · Kalman เริ่มไม่ตรงกัน = สัญญาณว่าความสัมพันธ์กำลังสั่น → ใช้เป็นสัญญาณเตือนภัยล่วงหน้า (ถูก · ใหม่ · ทำง่าย) → ลงลึกใน Part VII
  2. Fade the crowd — ทุกคนเข้าที่ z = 2 เหมือนกัน → พฤติกรรม forced-unwind ที่ threshold มาตรฐานคาดเดาได้ → จับจังหวะต่างเล็กน้อยเป็น edge อันดับสอง
  3. Access เป็น alpha จริงในไทย/SEA — บางที edge ไม่ใช่โมเดล แต่คือ สิทธิ์เข้าถึง: ยืมช็อตได้ไหม · broker ไหน · ภาษี — กองต่างชาติเข้าคู่เล็กในไทยไม่ได้ = ช่องของคุณ → Part VIII
  4. Horizon diversification — คู่เดียวรันหลาย timeframe แล้วรวมสัญญาณ (คนละ horizon decorrelate กัน) = Sharpe ดีขึ้นโดยไม่ต้องหาคู่ใหม่

สรุป Part 0 + สะพานสู่ Part I

✓ 3 อย่างที่ต้องจำจาก Part 0
  1. Estimator = ท่อประปา ไม่ใช่ alpha — Kalman คือ table stakes; ถ้าใครก็รันได้ มันไม่ใช่ edge
  2. edge ที่ทนสำหรับรายย่อย = C (วินัย/regime) + D (niche) — ไม่ใช่ A/B ที่กองใหญ่ครองอยู่
  3. อ่านงานวิจัยเพื่อเอาทิศทาง+วิธีการ ไม่ใช่ก๊อป alpha — ตีพิมพ์แล้ว = edge เฉพาะตัวหมดแล้ว

แต่ — และนี่สำคัญ — "ท่อประปาไม่ใช่ alpha" ไม่ได้แปลว่าท่อไม่สำคัญ ท่อรั่วก็ท่วมบ้าน ถ้าคุณประมาณ hedge ratio ผิด คุณจะถือความเสี่ยงที่ไม่ได้ตั้งใจ และ "spread" ที่คุณคิดว่าจะกลับ อาจไม่มีวันกลับ Part I จึงเริ่มจากคำถามพื้นฐานที่สุดที่คนพลาดบ่อยที่สุด:

"β มาจากไหน — แล้วทำไม OLS ที่ทุกคนใช้ ถึงใช้ได้แค่บางสถานการณ์?"
📖 ศัพท์ใหม่ในตอนนี้
  • Edge — ความได้เปรียบที่คนอื่นทำตามไม่ได้ง่าย ๆ (ตรงข้ามกับ table stakes)
  • Table stakes — สิ่งที่ต้องมีเพื่อเข้าเกม แต่ไม่ทำให้ชนะ (เพราะทุกคนมี)
  • Crowding — คนแห่ทำสัญญาณเดียวกันจน edge เจือจาง
  • Capacity — ปริมาณเงินสูงสุดที่กลยุทธ์รับได้ก่อนกำไรหด (ยิ่งเล็ก ยิ่งเป็นของรายย่อย)
  • Hedge ratio (β) — อัตราส่วนถือขา 2 ข้างเพื่อสร้าง spread (รายละเอียดใน Part I)
