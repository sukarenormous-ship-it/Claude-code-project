🧭 เส้นทางอ่าน — เล่มนี้ไม่ได้ให้ "ท่องสูตร" แต่ให้ "ใช้เป็น"

🟢 มือใหม่ (ไม่มีพื้นคณิต): อ่าน 🚶 กล่อง "อ่านเป็นภาษาคนก่อน" + 🧮 ตัวอย่าง + ✍️ ลองทำเอง + 🎯 3 อย่างที่ต้องจำ ก็พอ — กล่องสูตรเต็ม ๆ ข้ามไปก่อนได้ · 🔵 มีพื้นมาบ้าง: อ่านครบทุกกล่อง โดยเฉพาะ "เชื่อมกับ Options" ที่ผูกคณิตเข้ากับของจริง

📖 ก่อนเปิดบท 1 — ศัพท์ Options 9 คำที่ทั้งเล่มจะใช้

เล่มนี้สอน "คณิตศาสตร์ที่อยู่เบื้องหลัง Options" ฉะนั้นเราจะพูดถึงคำพวกนี้ตั้งแต่หน้าแรก อ่านผ่าน ๆ ให้คุ้นตาก่อน เดี๋ยวแต่ละคำจะค่อย ๆ ชัดเองเมื่อคณิตเข้าที่:

  • Option = สัญญาที่ให้ "สิทธิ์" (ไม่ใช่หน้าที่) ซื้อหรือขายหุ้นที่ราคาหนึ่ง ในอนาคต
  • Call = สิทธิ์ "ซื้อ" หุ้นที่ราคาตกลงไว้ (ได้กำไรเมื่อหุ้นขึ้น) · Put = สิทธิ์ "ขาย" (ได้กำไรเมื่อหุ้นลง)
  • Strike (K) = ราคาที่ตกลงจะซื้อ/ขายกันในสัญญา — ตัวเลขคงที่
  • Premium (P) = ค่าตัวสัญญา ราคาที่จ่ายเพื่อได้ Option มา 1 ใบ
  • Long = ฝั่ง "ซื้อ/ถือ" สัญญา · Short = ฝั่ง "ขาย" สัญญาให้คนอื่น
  • S = ราคาหุ้นจริงในตลาด (เคลื่อนไหวตลอด) — ตัวแปรหลักที่เราจะพล็อตกราฟตาม
  • exercise (ใช้สิทธิ์) = เลือกซื้อ/ขายตามสัญญา · expire (หมดอายุ) = ถึงวันสิ้นสุดสัญญา
  • ITM / ATM / OTM = สัญญากำลัง "มีกำไรถ้าใช้สิทธิ์ตอนนี้ / เท่าทุนพอดี (S≈K) / ยังขาดทุน"
  • Payoff Chart = กราฟ "กำไร/ขาดทุน (แกนตั้ง) เทียบกับราคาหุ้น S (แกนนอน)" — เป้าหมายของ Part I คืออ่านกราฟนี้ออก

เปิดเรื่อง: กับดัก "−50% แล้ว +50%"

ลองตอบเร็ว ๆ ในใจ: หุ้นตัวหนึ่งราคา ฿100 ร่วง 50% แล้ววันต่อมา เด้งกลับ +50% — ตอนนี้คุณเท่าทุนแล้วหรือยัง?

เกือบทุกคนตอบว่า "เท่าทุน" คำตอบนั้นผิด และความผิดนี้เอง คือประตูบานแรกสู่คณิตศาสตร์ของ Options ทั้งหมด

ทำไมถึงไม่เท่าทุน

฿100 ร่วง 50% เหลือ ฿50 · จากนั้นเด้ง +50% ได้ ฿50 × 1.5 = ฿75 ไม่ใช่ ฿100

จะกลับไป ฿100 หุ้นต้องเด้งจาก ฿50 ถึง +100% ไม่ใช่ +50% — ขาลงกับขาขึ้นไม่สมมาตรกัน

ราคาร่วงลงต้องเด้งกลับเท่าไรถึงเท่าทุนตัวอย่าง (เริ่ม ฿100)
−10%+11.1%฿90 → เด้ง ฿10/฿90 = 11.1%
−25%+33.3%฿75 → เด้ง ฿25/฿75 = 33.3%
−50%+100%฿50 → เด้ง ฿50/฿50 = 100%
−75%+300%฿25 → เด้ง ฿75/฿25 = 300%
−90%+900%฿10 → เด้ง ฿90/฿10 = 900%
ขาขึ้นกับขาลงไม่ใช่กระจกสะท้อนกัน — คณิตศาสตร์ของ Options เกิดมาเพื่อจัดการความไม่สมมาตรแบบนี้
เชื่อมกับ Options — ทำไมเรื่องนี้สำคัญ

เพราะความไม่สมมาตรนี้ Options จึงวัดการเคลื่อนไหวด้วย log return ไม่ใช่ % ธรรมดา — log return ทำให้ "ขึ้นแล้วลงเท่ากันได้กลับที่เดิมพอดี" (เราจะพิสูจน์ในหัวข้อ 3.6) และมันคือหน่วยที่สูตร Black-Scholes ใช้จริง

บทที่ 1: ภาษาที่ใช้พูดเรื่อง Options

ทุก Payoff Chart คือ "ประโยค" ที่เขียนด้วยเครื่องมือคณิต 5 ตัว: ฟังก์ชัน · ความชัน · max() · การพลิกเครื่องหมาย · ฟังก์ชันแบ่งช่วง บทนี้สอนให้อ่านทั้ง 5 ตัวออก แล้วหน้าถัดจากนี้คุณจะมองกราฟ Options เป็น "ประโยค" ไม่ใช่ "รอยหยึกหยัก"

1.1 Risk/Reward — ภาษาแรกของโต๊ะเทรด

เราเพิ่งเห็นแล้วว่า % ขาขึ้น-ขาลงไม่สมมาตร ในโลกจริงเทรดเดอร์เลยไม่ค่อยพูดเป็น % เดี่ยว ๆ แต่พูดเป็น Risk/Reward คือ "เสี่ยงเท่าไร เพื่อมีโอกาสได้เท่าไร"

🔧 ใช้ทำอะไร

ก่อนเข้าไม้ทุกครั้ง เทรดเดอร์ถามตัวเองว่า "ไม้นี้ Risk/Reward เท่าไร" ถ้า Max Loss = ฿5 และ Max Profit = ฿15 → Risk/Reward = 1:3 ทุก ฿1 ที่เสี่ยง มีโอกาสได้กลับ ฿3

🧠 มุมที่มองต่าง

มือใหม่เห็น: "ไม้นี้มีโอกาสกำไรกี่ %"
เทรดเดอร์เห็น: "ถ้าฉันผิด ฉันเสียเท่าไร เทียบกับถ้าฉันถูก" — เขาคิดขนาดของแพ้/ชนะก่อนคิดโอกาส เพราะจากกับดัก −50% เรารู้แล้วว่า "การขาดทุนหนักลากเรากลับได้ยากกว่าที่คิด"

1.2 ฟังก์ชัน — "กล่องที่ราคาหุ้นเดินเข้า แล้วกำไรเดินออก"

🚶 อ่านเป็นภาษาคนก่อน: ฟังก์ชันคือ "เครื่องจักร" ที่รับค่าเข้าไปหนึ่งตัว แล้วคายค่าออกมาหนึ่งตัวอย่างแน่นอน — ใส่เหมือนเดิม ได้เหมือนเดิมทุกครั้ง

🧮 เปรียบเทียบ: เครื่องชงกาแฟ

ใส่เมล็ดกาแฟ (input = x) → เครื่องบด+ชง (function = f) → ได้กาแฟ (output = f(x)) เมล็ดต่างกันได้รสต่างกัน แต่เมล็ดเดียวกันได้รสเดียวกันเสมอ นั่นคือหัวใจของฟังก์ชัน เขียนสั้น ๆ ว่า f(x) อ่านว่า "f ของ x"

ทุกจุดบนกราฟมีที่อยู่เป็นคู่ (x, y) — x คือตำแหน่งแนวนอน, y คือแนวตั้ง ลองป้อนเลขเข้าฟังก์ชัน f(x) = 2x − 100 แล้วดูว่าออกมาเป็นจุดอะไรบ้าง:

x (ใส่เข้า)f(x) = 2x − 100 (ออกมา)จุดบนกราฟ
02(0) − 100 = −100(0, −100)
502(50) − 100 = 0(50, 0) ← ตัดแกน x
1002(100) − 100 = 100(100, 100)
เชื่อมกับ Options

Payoff(S) = max(0, S − K) − Premium ก็คือฟังก์ชันแบบนี้ — ป้อน "ราคาหุ้น S" เข้าไป ได้ "กำไร/ขาดทุน" ออกมา ทุก Payoff Chart คือกราฟของฟังก์ชันหนึ่งตัว จุดที่เส้นตัดแกน x (เหมือน (50,0) ข้างบน) ก็คือ จุดคุ้มทุน (break-even) ของไม้นั้น

1.3 ความชัน (Slope) — "ขึ้นเร็วแค่ไหน"

🚶 อ่านเป็นภาษาคนก่อน: ความชันคือ "เดินไปทางขวา 1 ก้าว เส้นขยับขึ้นกี่ก้าว" ชันบวก = เส้นวิ่งขึ้น, ชันลบ = วิ่งลง, ชัน 0 = แบนราบ

m = Δy / Δx = (y₂ − y₁) / (x₂ − x₁)
ความชัน mอ่านว่าใน Options คือ
+1ขึ้น ฿1 ต่อทุก ฿1 ที่หุ้นขึ้นLong Call หลังเลย Strike
−1ลง ฿1 ต่อทุก ฿1 ที่หุ้นขึ้นShort Call หลังเลย Strike
0แบนราบ ไม่ขยับPayoff ช่วงก่อนถึง Strike
+0.5ขึ้น ฿0.50 ต่อ ฿1Delta ≈ 0.5 (option ATM)
เชื่อมกับ Options

Long Call หลัง Strike ชัน +1 (หุ้นขึ้น ฿1 กำไรขึ้น ฿1) · Short Call ชัน −1 · และ Delta ของ Option ก็คือความชันของ payoff นั่นเอง — เราจะเจอ Delta อีกครั้งในบทแคลคูลัส (Part III)

1.4 max() — เครื่องมือที่ทำให้กราฟ Options "หักศอก"

🚶 อ่านเป็นภาษาคนก่อน: max(a, b) แปลว่า "หยิบตัวที่มากกว่า" และตัวเอกของเราคือ max(0, x) ซึ่งแปลตรง ๆ ว่า "ถ้า x ติดลบ ให้กลายเป็น 0 แทน; ถ้า x เป็นบวก ก็ปล่อยไว้อย่างนั้น" มันคือปุ่ม "ห้ามติดลบ"

max(3, 7) = 7 · max(−5, 2) = 2 · max(0, −20) = 0 · max(0, 10) = 10
xmax(0, x)เกิดอะไรขึ้น
−200ติดลบ → ตัดเป็น 0
−50ติดลบ → ตัดเป็น 0
00จุดหักศอกพอดี
+1010เป็นบวก → ใช้ค่าเดิม
+2525เป็นบวก → ใช้ค่าเดิม
เชื่อมกับ Options — นี่คือหัวใจ

max(0, S − K) = มูลค่าที่แท้จริง (Intrinsic Value) ของ Call

  • ถ้า S < K → Option หมดค่า = 0 (ไม่ใช้สิทธิ์ ก็แค่ทิ้งไป)
  • ถ้า S > K → Option มีค่า = S − K (ใช้สิทธิ์ซื้อที่ K แล้วขายที่ราคาตลาด S)

ปุ่ม "ห้ามติดลบ" ของ max() นี่แหละ คือที่มาของรอยหักศอกในกราฟ Options ทุกใบ

✍️ ลองทำเอง

Long Call มี Strike K = 50, Premium P = 3 ถ้าวันหมดอายุหุ้นอยู่ที่ S = 58 คุณกำไรหรือขาดทุนเท่าไร? แล้วจุดคุ้มทุนอยู่ที่ราคาเท่าไร?

ดูเฉลย

Payoff = max(0, 58 − 50) − 3 = max(0, 8) − 3 = 8 − 3 = กำไร ฿5 · จุดคุ้มทุน = K + P = 50 + 3 = ฿53 (ต่ำกว่านี้เริ่มขาดทุน)

1.5 การพลิกเครื่องหมาย — "Short คือ Long กลับหัว"

🚶 อ่านเป็นภาษาคนก่อน: ถ้า f(x) เป็นกราฟหนึ่ง แล้ว −f(x) คือกราฟเดิมพลิกกลับหัวผ่านเส้นศูนย์ ที่ไหนเคยกำไรกลายเป็นขาดทุนเท่ากันเป๊ะ ที่ไหนเคยขาดทุนกลายเป็นกำไร

เชื่อมกับ Options

Short position = −1 × Long position ทุกจุด — ไม่ต้องจำรูปร่างใหม่เลย แค่พลิกกราฟ Long ที่รู้อยู่แล้ว Long Call (กำไรไม่จำกัด ขาดทุนจำกัดที่ค่า Premium) → พลิก → Short Call (กำไรจำกัด ขาดทุนไม่จำกัด)

1.6 ฟังก์ชันแบ่งช่วง (Piecewise) — "ต่อเลโก้เป็นทุกกลยุทธ์"

🚶 อ่านเป็นภาษาคนก่อน: ฟังก์ชันแบ่งช่วง คือฟังก์ชันที่ "เปลี่ยนสูตรตามช่วงของราคา" เหมือนบิลค่าไฟที่คิดคนละเรตตามหน่วยที่ใช้ ทุกกลยุทธ์ Options ประกอบจากท่อนตรงหลาย ๆ ท่อนต่อกัน — เหมือนต่อเลโก้

ตัวอย่าง: Bull Call Spread (ซื้อ Call ถูก K₁ = 90 + ขาย Call แพง K₂ = 110, จ่ายสุทธิ 5):

Payoff = −5 เมื่อ S < 90 = S − 90 − 5 เมื่อ 90 ≤ S ≤ 110 = 110 − 90 − 5 = 15 เมื่อ S > 110
เชื่อมกับ Options — นับช่วงเป็น

ทุกกลยุทธ์ Options เป็นฟังก์ชันแบ่งช่วงเชิงเส้น และกฎง่าย ๆ คือ จำนวนช่วง = จำนวน Strike + 1:

  • Long Call = 1 strike → 2 ช่วง
  • Bull Spread = 2 strike → 3 ช่วง
  • Butterfly = 3 strike → 4 ช่วง
  • Iron Condor = 4 strike → 5 ช่วง

เข้าใจ piecewise = อ่าน payoff chart ของทุกกลยุทธ์ออก แค่ไล่ทีละช่วง

✍️ ลองทำเอง

Iron Condor มี 4 Strike จะมีกี่ช่วง? แล้ว Straddle (ซื้อ Call + Put ที่ Strike เดียวกัน คือ 1 Strike) มีกี่ช่วง?

ดูเฉลย

Iron Condor = 4 + 1 = 5 ช่วง · Straddle มี 1 Strike → 2 ช่วง (รูป V — ลงก็ได้ ขึ้นก็ได้ ขาดทุนเฉพาะตอนนิ่ง)

บทที่ 2: พีชคณิต — จัด Put-Call Parity ได้เอง

มีสมการหนึ่งที่ถ้าคุณ "ย้ายข้าง" มันเป็น คุณจะสร้างสถานะเทียม (synthetic position) ได้ทุกแบบ โดยไม่ต้องท่องจำเลยสักตัว สมการนั้นคือ Put-Call Parity และบทนี้คือพีชคณิตเท่าที่จำเป็นเพื่อบังคับมันให้อยู่หมัด

2.1 สมการเชิงเส้น — หาจุดคุ้มทุนด้วยการย้ายข้าง

🚶 อ่านเป็นภาษาคนก่อน: กฎเดียวของการแก้สมการคือ "ทำอะไรกับข้างซ้าย ต้องทำเหมือนกันกับข้างขวา" เหมือนตราชั่งสองข้างที่ต้องสมดุลเสมอ จุดคุ้มทุนคือ "ราคาที่ทำให้กำไร = 0" เราแค่ตั้ง Payoff = 0 แล้วแก้หา S

Long Call: 0 = S − K − P → S = K + P ถ้า K = 100, P = 5 → คุ้มทุน = 105
✍️ ลองทำเอง — จุดคุ้มทุนของ Long Put

Long Put มี Payoff = max(0, K − S) − P ลองหาจุดคุ้มทุน (ตั้ง K − S − P = 0) ถ้า K = 100, P = 3

ดูเฉลย

K − S − P = 0 → S = K − P = 100 − 3 = 97 (Put กำไรเมื่อหุ้นลงต่ำกว่า 97)

2.2 Put-Call Parity — สมการที่สำคัญที่สุดในโลก Options

Put-Call Parity รากฐาน no-arbitrage ★★★ ต้องรู้จัก

🎯 Thesis

"ถือ Call บวกเงินสดก้อนหนึ่ง ให้ผลตอบแทนเหมือนกันเป๊ะกับถือ Put บวกหุ้น — เพราะทั้งสองทางรับประกันว่าตอนจบคุณจะมี 'หุ้น หรือ เงิน K อย่างต่ำ' เท่ากัน"

🚶 อ่านเป็นภาษาคนก่อน: ลองนึกถึง 2 พอร์ตในวันหมดอายุ

  • พอร์ต A = Call (Strike K) + เงินสดเท่ากับ K → ถ้าหุ้นขึ้นเกิน K ก็ใช้เงิน K ซื้อหุ้น; ถ้าหุ้นต่ำกว่า K ก็ถือเงิน K ไว้ → ได้ค่าที่มากกว่าระหว่าง "หุ้น" กับ "K"
  • พอร์ต B = Put (Strike K) + หุ้น 1 หุ้น → ถ้าหุ้นต่ำกว่า K ก็ใช้ Put ขายได้ K; ถ้าหุ้นสูงกว่า K ก็ถือหุ้นไว้ → ได้ค่าที่มากกว่าระหว่าง "หุ้น" กับ "K" เหมือนกันเป๊ะ

ตอนจบได้เท่ากันทุกกรณี ราคาวันนี้จึงต้องเท่ากันด้วย (ไม่งั้นมีช่องอาร์บิทราจ) นั่นคือที่มาของสมการ — เงินสด K วันนี้เขียนเป็นมูลค่าปัจจุบัน PV(K):

C + PV(K) = P + S

โดย C = ราคา Call · P = ราคา Put · S = ราคาหุ้น · PV(K) = มูลค่าปัจจุบันของเงิน K (จะกางในบทที่ 3)

🔧 ใช้ทำอะไร — ย้ายข้างได้ทุก Synthetic

สมการเดียวนี้ พอย้ายข้างก็ได้ "สูตรประกอบร่าง" ของทุกสถานะเทียม:

อยากได้ย้ายข้างเป็นแปลว่าประกอบจาก
SS = C − P + PV(K)Synthetic Stock = Long Call + Short Put + เงินฝาก
CC = P + S − PV(K)Synthetic Call = Long Put + Long Stock − กู้เงิน
PP = C − S + PV(K)Synthetic Put = Long Call + Short Stock + เงินฝาก
PV(K)PV(K) = P + S − CSynthetic Bond = Long Put + Long Stock + Short Call
🧮 ใช้จริงหน้างาน — อยากช็อตหุ้นที่ยืมไม่ได้

สมมติคุณอยากช็อตหุ้นตัวหนึ่ง แต่โบรกเกอร์ "ไม่มีของให้ยืม" (borrow แพงหรือหมด) ทำยังไง? ย้ายข้างหา −S:

−S = P − C − PV(K)

แปลว่า Long Put + Short Call + กู้เงิน ให้ผลเท่ากับการช็อตหุ้นเป๊ะ โดยไม่ต้องยืมหุ้นเลย — นี่คือ "Synthetic Short" ที่โต๊ะเทรดใช้จริงเวลาหุ้นยืมยาก

🧠 มุมที่มองต่าง

มือใหม่เห็น: Call กับ Put เป็นของคนละอย่าง ต้องท่องแยกกัน
คนในตลาดเห็น: Call, Put, หุ้น, พันธบัตร เป็น "ของสิ่งเดียวกันที่จัดเรียงต่างกัน" — รู้ราคา 3 ตัว คำนวณตัวที่ 4 ได้เสมอ ตลาดจึงบังคับให้ราคาทั้งสี่ล็อกเข้าหากันตลอดเวลา

🎯 3 อย่างที่ต้องจำ
  • Parity มาจาก "สองทางได้ผลเท่ากันตอนจบ" ไม่ใช่สูตรลอย ๆ ให้ท่อง
  • C + PV(K) = P + S — ย้ายข้างได้ทุก synthetic ไม่ต้องจำแยก
  • รู้ราคา 3 ตัว หาตัวที่ 4 ได้เสมอ

2.3 ระบบสมการ — Zero-Cost Collar

🚶 อ่านเป็นภาษาคนก่อน: บางทีเรามี "หลายเงื่อนไขต้องจริงพร้อมกัน" ก็แก้หลายสมการพร้อมกัน วิธีที่ง่ายสุดคือ แทนค่า (substitution) — แก้ตัวแปรหนึ่งจากสมการแรก แล้วยัดเข้าสมการที่สอง

🔧 ตัวอย่างจริง: Zero-Cost Collar

คุณถือหุ้นอยู่ อยากซื้อ Put กันขาลง แต่ไม่อยากจ่ายเงิน จึงขาย Call เอาเงินมาโปะพอดี เงื่อนไขคือ Premium(Put ที่ซื้อ) = Premium(Call ที่ขาย) → ถ้า Put K=95 ราคา 3 ก็ต้องหา Call ที่ Strike ซึ่งขายได้ราคา 3 เท่ากัน สุทธิเป็นศูนย์

สมการ 1: x + y = 10 สมการ 2: 2x − y = 5 จาก (1): y = 10 − x → แทนใน (2): 2x − (10 − x) = 5 3x = 15 → x = 5 , y = 5 → (x, y) = (5, 5)

2.4 อสมการ — เมื่อ "เท่ากันพอดี" กลายเป็น "ช่วง"

🚶 อ่านเป็นภาษาคนก่อน: อสมการใช้ <, >, ≤, ≥ แทน = มีกฎพิเศษข้อเดียวที่พลาดกันบ่อย: ถ้าคูณหรือหารด้วยจำนวนลบ ต้องกลับทิศเครื่องหมาย

❌ จุดพลาดที่พบบ่อย

−2x > 6 → หารสองข้างด้วย −2 → x < −3 (เครื่องหมายกลับทิศ ไม่ใช่ x > −3)

เชื่อมกับ Options — American Parity เป็น "ช่วง" ไม่ใช่ "เท่ากันเป๊ะ"

American Option (ใช้สิทธิ์ก่อนหมดอายุได้) ทำให้ parity กลายเป็นอสมการ (สำหรับหุ้นไม่จ่ายปันผล):

S − K ≤ C − P ≤ S − K·e−rT

สาเหตุคือ American Put อาจถูกใช้สิทธิ์ก่อนกำหนดได้ ความ "เท่ากันพอดี" จึงคลายเป็น "ช่วง"

📌 ตัว e−rT คือตัวคิดลดเงินตามเวลา เราจะกางให้เห็นเต็ม ๆ ในบทที่ 3 — ตอนนี้แค่รู้ว่ามันคือ "K เวอร์ชันลดค่าตามเวลา" ก็พอ

บทที่ 3: เลขยกกำลัง · ln · ดอกเบี้ย — ถอดรหัส PV(K)

เราค้างคำว่า PV(K) = K·e−rT ไว้ 2 บทแล้ว บทนี้จะตอบว่า e มาจากไหน (สปอยล์: มันโผล่ออกมาเองจากดอกเบี้ยทบต้น) ln คืออะไร และทำไม PV(K) ถึงเขียนแบบนั้น พอจบบทนี้ คุณจะอ่าน Put-Call Parity ออกครบทุกตัวอักษร

3.1 เลขยกกำลัง

หารฐานเดียวกันaᵐ / aⁿ = aᵐ⁻ⁿ2⁵ / 2² = 2³ = 8
ยกกำลังซ้อน(aᵐ)ⁿ = aᵐⁿ(2³)² = 2⁶ = 64

3.2 ดอกเบี้ยทบต้น — "ดอกเบี้ยที่ออกลูกเป็นดอกเบี้ย"

🚶 อ่านเป็นภาษาคนก่อน: ดอกเบี้ยเชิงเดี่ยว คิดจากเงินต้นอย่างเดียว ส่วนทบต้น คิดจาก "เงินต้น + ดอกที่สะสมมาแล้ว" ดอกเบี้ยจึงออกลูกเป็นดอกเบี้ยอีกที ยิ่งนานยิ่งทิ้งห่าง

เชิงเดี่ยว: FV = PV × (1 + r × t) ทบต้นรายปี: FV = PV × (1 + r)ⁿ ทบต้นรายเดือน: FV = PV × (1 + r/12)¹²ⁿ

3.4 ลอการิทึมคืออะไร — "คำถามย้อนกลับของเลขยกกำลัง"

🚶 อ่านเป็นภาษาคนก่อน: เลขยกกำลังถามว่า "2 ยกกำลัง 3 ได้เท่าไร" (ตอบ 8) · ลอการิทึมถามกลับด้านว่า "2 ต้องยกกำลังเท่าไรถึงได้ 8" (ตอบ 3) มันคือปุ่ม undo ของเลขยกกำลัง — ต่อยอดตรงจาก 3.1 ที่เพิ่งเรียน

logₐ(x) = "a ยกกำลังเท่าไรถึงได้ x" log₂(8) = 3 เพราะ 2³ = 8 log₁₀(1000) = 3 เพราะ 10³ = 1000 logₐ(1) = 0 เพราะ a⁰ = 1 (log ของ 1 = 0 ทุกฐาน)
🔤 อ่านว่าอะไร · ฐานที่เจอบ่อย
  • log อ่านว่า "ล็อก" · log₂(8) อ่านว่า "ล็อกฐานสองของแปด"

📜 มาจากไหน

John Napier คิดลอการิทึมขึ้นราวปี 1614 เพื่อ "เปลี่ยนการคูณเลขยาก ๆ ให้กลายเป็นการบวก" — ยุคก่อนมีเครื่องคิดเลข การคูณเลขหลายหลักเป็นงานหนัก log ช่วยย่อให้เหลือแค่เปิดตารางแล้วบวกกัน · พลังข้อนี้ยังอยู่จนวันนี้ (ดูกฎด้านล่าง)

Simple operations — 3 กฎของ log (พร้อมสัญชาตญาณ): log "ลดระดับ" การดำเนินการลงหนึ่งขั้นเสมอ

เวลาค่ากระโดดหลายเท่าตัว เราใช้สเกล log เพื่ออัดให้อ่านง่าย:

3.5 ln — ลอการิทึมธรรมชาติ (ฐาน e)

🚶 อ่านเป็นภาษาคนก่อน: ln ก็คือ log ที่ใช้ ฐาน e โดยเฉพาะ — loge(x) เขียนย่อว่า ln(x) มันตอบว่า "e ต้องยกกำลังเท่าไรถึงได้ x" และเป็นปุ่ม undo ของ eˣ ที่เรียนใน 3.3 (ถ้า ey = x แล้ว y = ln(x))

🔤 ln อ่านว่าอะไร · มาจากไหน

  • ตัวย่อ ln มาจากภาษาละติน logarithmus naturalis = "ลอการิทึมธรรมชาติ"
  • ทำไม e ถึง "ธรรมชาติ": เพราะ e โผล่ออกมาเองจากดอกเบี้ยทบต้น (3.3) การเติบโต/สลายตัวในธรรมชาติจึงวัดด้วยฐาน e เป็นธรรมดาที่สุด

ใช้มากในวิทย์ · วิศวะการเงิน (log return · Black-Scholes)

กฎ 3 ข้อของ log ใช้กับ ln ได้ตรง ๆ (แค่เปลี่ยนฐานเป็น e):

ln(a × b) = ln(a) + ln(b) ← คูณกลายเป็นบวก ln(a / b) = ln(a) − ln(b) ← หารกลายเป็นลบ ln(aⁿ) = n × ln(a)
กฎ ln ที่สำคัญที่สุดสำหรับการเงิน

ln(a/b) = ln(a) − ln(b) ← นี่คือที่มาของ log return:

log return = ln(S₁/S₀) = ln(S₁) − ln(S₀)

3.6 Simple Return vs Log Return — เฉลยกับดักหน้าแรก

Simple: R = (S₁ − S₀)/S₀ = S₁/S₀ − 1 Log: r = ln(S₁/S₀) = ln(S₁) − ln(S₀)

3 เหตุผลที่ Options เลือก log return
  • บวกข้ามเวลาได้: Simple +10% แล้ว −10% ได้ ฿99 (เพี้ยน −1%) · Log: ln(110/100) + ln(99/110) = ln(99/100) = −1.005% บวกกันตรง ๆ ถูกต้อง
  • สมมาตร (เฉลยกับดักหน้าแรก): log ของ +100% (=+69.31%) เท่ากับ |log ของ −50%| (=69.31%) เป๊ะ — ความไม่สมมาตรที่เปิดเล่มหายไปเมื่อเปลี่ยนเป็นหน่วย log
  • เป็น Normal ได้: Simple ติดขอบล่าง −100% จึงเบี้ยว · Log วิ่งได้ (−∞, +∞) สมมาตร → เป็น Normal → ราคาหุ้นเป็น Lognormal (เจอกันใน Part II)

3.7 สรุป PV/FV — อ่าน Parity ออกครบทุกตัว

PV = FV × e−rT | FV = PV × erT
เชื่อมกับ Options — ปิดวง Put-Call Parity

ตอนนี้คุณอ่านออกครบทุกตัวอักษร:

C + K·e−rT = P + S

  • C = ราคา Call (บท 1: ฟังก์ชัน)
  • K·e−rT = PV(K) = มูลค่าปัจจุบันของ Strike (บทนี้)
  • P = ราคา Put (บท 1: การพลิกเครื่องหมาย)
  • S = ราคาหุ้น · การย้ายข้าง → Synthetic Positions (บท 2)
🎯 3 อย่างที่ต้องจำจากบทที่ 3
  • e โผล่เองจากการทบต้นถี่ที่สุด — ไม่ใช่ตัวเลขลอย ๆ
  • PV(K) = K·e−rT = "เงิน K มองย้อนกลับมาเป็นค่าวันนี้"
  • log return สมมาตรและบวกข้ามเวลาได้ จึงเป็นหน่วยของ Black-Scholes

🎓 รวมร่าง: อ่าน Payoff Chart ด้วยมือเปล่า

ถึงเวลาเอาเครื่องมือทั้ง 5 ของบทที่ 1 มาใช้พร้อมกันจริง ๆ เป้าหมายของ Part I คือ "อ่าน payoff chart ออก" — และนี่คือ ลำดับ 4 ขั้นที่โต๊ะเทรดใช้อ่านกราฟทุกใบ ไม่ว่ากลยุทธ์จะซับซ้อนแค่ไหน:

🧭 นิสัยคิด — อ่าน payoff 4 ขั้น
  1. นับ Strike → รู้จำนวนช่วง (จำนวนช่วง = Strike + 1) และรู้ว่า "หักศอก" อยู่ตรงไหน
  2. อ่านความชันแต่ละช่วง (+1 ขาขึ้น · −1 ขาลง · 0 แบน) → รู้ว่าได้/เสียเร็วแค่ไหน
  3. หา max loss / max profit — ดูปลายกราฟทั้งสองข้างว่าตันที่เท่าไร หรือวิ่งไม่จำกัด
  4. หาจุดคุ้มทุน — ตั้ง Payoff = 0 แล้วแก้หา S (อาจมีมากกว่า 1 จุด)

ลองอ่านของจริง: Long Straddle (ซื้อ Call K=100 จ่าย 4 + ซื้อ Put K=100 จ่าย 3 → จ่ายรวม 7) เป็นไม้ที่ "เดิมพันว่าหุ้นจะวิ่งแรง ไม่ว่าขึ้นหรือลง":

🧮 อ่านทีละขั้น
  1. Strike: มี 1 จุด (K=100) → 2 ช่วง หักศอกที่ 100
  2. ความชัน: ซ้ายของ 100 ชัน −1 (หุ้นยิ่งลงยิ่งกำไร) · ขวาชัน +1 (หุ้นยิ่งขึ้นยิ่งกำไร) — รูปตัว V
  3. Max loss / profit: ขาดทุนสูงสุด = −7 (เบี้ยรวม) ตอนหุ้นนิ่งที่ 100 พอดี · กำไรวิ่งไม่จำกัดทั้งสองข้าง
  4. จุดคุ้มทุน: ตั้ง Payoff = 0 → S = 100 − 7 = 93 และ S = 100 + 7 = 107 (นอกช่วงนี้เริ่มกำไร)
✍️ ลองทำเอง — อ่าน Short Straddle

Short Straddle คือ "พลิกหัว" ของ Long Straddle (ขาย Call + ขาย Put ที่ K=100 รับเบี้ยรวม 7) ใช้ 4 ขั้นข้างบนอ่านมัน: กราฟหน้าตายังไง? กำไร/ขาดทุนสูงสุดเท่าไร? จุดคุ้มทุนอยู่ที่ไหน?

ดูเฉลย

รูป Λ กลับหัว (จากกฎ Short = พลิก Long) · กำไรสูงสุด = +7 ตอนหุ้นนิ่งที่ 100 · ขาดทุนไม่จำกัดทั้งสองข้าง · จุดคุ้มทุน 93 และ 107 เท่าเดิม (แค่กลับด้านกำไร/ขาดทุน) — คนขาย straddle คือคนเดิมพันว่า "หุ้นจะนิ่ง"

สรุป Part I — คุณทำอะไรได้แล้วบ้าง
  • อ่านฟังก์ชัน ความชัน และ max(0, S−K) = ที่มาของรอยหักศอก
  • รู้ว่า Short = พลิก Long กลับหัว และนับช่วง payoff จากจำนวน Strike
  • เข้าใจ Put-Call Parity จาก "สองทางได้ผลเท่ากัน" และย้ายข้างสร้าง synthetic ได้
  • ถอด PV(K) = K·e−rT ออก และรู้ว่าทำไม Options ใช้ log return
คุณอ่าน "ราคาวันหมดอายุ" ออกแล้ว — แต่ราคา Option วันนี้ ก่อนหมดอายุ มาจากไหน? คำตอบซ่อนอยู่ในคำว่า "ความน่าจะเป็น" และ "ความผันผวน" ที่ Part II จะเปิดออก
📖 ศัพท์ใหม่ในตอนนี้

Intrinsic Value = มูลค่าที่แท้จริงถ้าใช้สิทธิ์ตอนนี้ = max(0, S−K) · Break-even = ราคาที่กำไร = 0 · Slope/ความชัน = อัตราที่กราฟขึ้น · Piecewise = ฟังก์ชันที่เปลี่ยนสูตรตามช่วง · Synthetic position = สถานะที่ประกอบจากตัวอื่นให้ได้ผลเท่ากัน · PV(K) = มูลค่าปัจจุบันของ Strike = K·e−rT · Log return = ln(S₁/S₀) หน่วยผลตอบแทนแบบสมมาตร
