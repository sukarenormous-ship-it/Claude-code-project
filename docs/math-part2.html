4.2 ค่ากลาง — Mean, Median, Mode

🔍 อุปมา: เพื่อน 6 คนไปกินข้าว

เพื่อน 6 คนไปกินข้าว แต่ละคนจ่ายไปตาม "ผลตอบแทนรายวัน" ของหุ้นที่ถือ:
-5%, +2%, +8%, -1%, +3%, +50% (คนสุดท้ายโชคดีมากวันนั้น)

Mean = ถ้าเอาทุกอย่างมารวมกันแล้วหารเท่าๆ กัน → ได้คนละ +9.5% — แต่ไม่สะท้อนความจริงเลย!
Median = เรียงแถวแล้วดูคนตรงกลาง → ได้ +2.5% — ตัวเลขนี้จริงกว่ามาก

ตัวอย่าง: Daily returns 6 วัน: -5%, +2%, +8%, -1%, +3%, +50%

ค่ากลางวิธีคำนวณผลลัพธ์จุดเด่น/จุดด้อย
Mean (ค่าเฉลี่ย)(-5+2+8-1+3+50) / 6+9.5%ง่าย แต่ถูก outlier บิดเบือน
Median (มัธยฐาน)เรียง: -5,-1,2,3,8,50 → กลาง = (2+3)/2+2.5%ทนต่อ outlier — ภาพจริงมากกว่า
Mode (ฐานนิยม)ค่าที่ซ้ำบ่อยสุดไม่มีใช้กับ discrete data เท่านั้น
🔍 ทำไม Mean ถึงเขียนว่า Σxᵢ / n?

Σxᵢ = รวมทุกค่า = "เอาของทุกคนมากองรวมกัน"
/ n = หารจำนวนคน = "แบ่งให้เท่าๆ กัน"

สมการนี้ตอบว่า: "ถ้าแบ่งผลลัพธ์ให้เท่ากันทุกคน แต่ละคนจะได้เท่าไร?"
นั่นคือ Mean ตาม intuition พอดี

ระวัง: Outlier บิดเบือน Mean!

ค่า +50% ทำให้ Mean = 9.5% ซึ่ง สูงกว่าทุกวันที่เหลือ
ใน finance: ถ้า 1 วันใน 10 ปีกำไร 300% แต่วันอื่นๆ เฉลี่ย 0% → Mean ดูดีมาก แต่ Median ≈ 0%
→ ดู Median ควบคู่ Mean เสมอ

Weighted Average — ใช้กับ Portfolio

Weighted Mean = Σ(wᵢ × xᵢ)

พอร์ต: หุ้น A (40%, return +5%) + หุ้น B (60%, return -2%)
Portfolio Return = 0.4 × 5% + 0.6 × (−2%) = 2.0% − 1.2% = +0.8%

4.3 Variance และ Standard Deviation — "วัดความกระจาย"

🔍 อุปมา: นักยิงธนู 2 คน

นักยิงธนูสองคนยิง 5 ครั้ง เล็งเป้าตรงกลาง:
นักยิง A: ทุกลูกตกในวงแคบๆ รอบศูนย์กลาง (แม่น)
นักยิง B: ลูกกระจายไปทั่วเป้า (ไม่แม่น)

ทั้งคู่อาจมี Mean ≈ 0 (เฉลี่ยแล้วเล็งถูกตรงกลาง) แต่ Standard Deviation ต่างกันมาก
SD คือตัววัด "ความกระจาย" นั่นเอง

วัดระยะห่างแต่ละจุดจาก Mean → ยกกำลัง 2 (ทำให้เป็นบวก) → หาค่าเฉลี่ย = Variance → √ = Standard Deviation
$$ \sigma^2 = \frac{\sum(x_i - \mu)^2}{n} \qquad \sigma = \sqrt{\frac{\sum(x_i - \mu)^2}{n}} $$
หมายเหตุ: Population vs Sample Variance
สูตรนี้คือ population variance (÷n) ใช้เมื่อรู้ข้อมูลทั้งหมด — ใน finance จริงที่ใช้ข้อมูล historical (sample) ควรใช้ sample variance ÷(n−1) แทน เพื่อให้ unbiased estimator ความแตกต่างน้อยมากเมื่อ n ≥ 30
🔍 ทำไมต้องยกกำลัง 2? ทำไมไม่ใช้ |xᵢ − μ| ธรรมดา?

ปัญหาถ้าไม่ยกกำลัง 2: ค่าบวกและลบหักล้างกัน
เช่น ข้อมูล: +3%, -3% → ระยะห่างเฉลี่ย = (3 + (−3)) / 2 = 0 ← ผิด! ชัดเจนว่ามีความกระจาย

ทำไมไม่ใช้ |xᵢ − μ| (absolute value)? ทำได้ แต่ค่าสัมบูรณ์ไม่ smooth — ไม่มี derivative ที่ x=0
การ optimize และ calculus ยากกว่ามาก → นักคณิตศาสตร์เลือก (xᵢ−μ)² แทน

ทำไมต้อง √ ตอนสุดท้าย?
ถ้าข้อมูลเป็น % → (xᵢ−μ)² เป็น %² → Variance มีหน่วย %²
√Variance กลับมาเป็น % (หน่วยเดิม) → เปรียบเทียบกับ returns ได้โดยตรง

ตัวอย่างเปรียบเทียบ 2 หุ้น: μ ทั้งคู่ = 0%

หุ้น A returns: +1%, -1%, +2%, -2%
σ² = [(1−0)² + (−1−0)² + (2−0)² + (−2−0)²] / 4 = [1+1+4+4] / 4 = 2.5 (%²)
σ = √2.5 = 1.58% ← นิ่ง
หุ้น B returns: +10%, -8%, +12%, -14%
σ² = [(10)² + (8)² + (12)² + (14)²] / 4 = [100+64+144+196] / 4 = 126 (%²)
σ = √126 = 11.2% ← ผันผวนมาก!
เชื่อมกับ Options — σ คือ Volatility!

Standard Deviation ของ daily returns = Historical Volatility (HV)
หุ้น B (σ=11.2%/วัน) มี options แพงกว่าหุ้น A (σ=1.58%/วัน) มาก
เพราะ "ความไม่แน่นอนสูงกว่า" = "โอกาสที่ option จะ expire มีค่า" สูงกว่า
ยิ่ง σ สูง → ราคา option แพงขึ้นทุกประเภท

Variance = average squared distance from mean (arrows show each (xᵢ − μ))

4.4 Percentile และ Quartile

🔍 อุปมา: ผลสอบ ONET

ถ้าคุณอยู่ที่ Percentile 85 แปลว่า: นักเรียน 85% ทำคะแนนได้น้อยกว่าคุณ
ถ้าอยู่ที่ Percentile 5 แปลว่า: 95% ทำคะแนนได้มากกว่าคุณ ← กลุ่มที่แย่ที่สุด 5%

ใน finance: วันที่ "แย่ที่สุด 5%" คือ VaR (Value at Risk) ที่ 95%

Percentileชื่อความหมายใช้ใน Finance
P55th Percentileมีแค่ 5% ที่ต่ำกว่านี้VaR 95% (worst 5% days)
P25 (Q1)Quartile 125% ของข้อมูลต่ำกว่านี้ดู drawdown ช่วงล่าง
P50 (Q2)Medianกึ่งกลางผลตอบแทน "ทั่วไป"
P75 (Q3)Quartile 375% ต่ำกว่านี้ดู return ช่วงบน
เชื่อมกับ Options — VaR (Value at Risk)

VaR 95%, 1-day = P5 ของ daily returns
ตัวอย่าง: ถ้า VaR (95%, 1-day) = −3.2% บนพอร์ต ฿1 ล้าน
→ มีโอกาส 5% ที่จะเสีย ≥ ฿32,000 ในวันเดียว
→ นักวาง hedge ใช้ค่านี้ในการเลือก strike ของ protective put

4.5 Covariance และ Correlation

🔍 อุปมา: คนขายร่ม vs คนขายแว่นกันแดด

วันฝนตก: คนขายร่มขายดี (+), คนขายแว่นกันแดดขายไม่ดี (−)
วันแดดจัด: คนขายร่มขายไม่ดี (−), คนขายแว่นกันแดดขายดี (+)

ยอดขายทั้งคู่ สวนทางกันตลอด → Correlation = −1

ถ้าถือหุ้นบริษัทร่มกับหุ้นบริษัทแว่นกันแดด → พอร์ตนิ่งมาก = diversification ทำงาน!

$$ \text{Cov}(X,Y) = \frac{\sum(x_i - \mu_x)(y_i - \mu_y)}{n} \qquad \rho = \frac{\text{Cov}(X,Y)}{\sigma_x \cdot \sigma_y} \in [-1,\,+1] $$
🔍 ทำไม Correlation = Cov / (σₓ × σᵧ)?

Covariance มีปัญหา: ขนาดขึ้นอยู่กับหน่วยของข้อมูล
เช่น return เป็น % vs return เป็นสตางค์ → Cov ต่างกัน แต่ความสัมพันธ์จริงๆ เท่ากัน

การหาร σₓ × σᵧ คือ normalize (ปรับมาตรฐาน) → ทำให้ผลลัพธ์อยู่ระหว่าง −1 ถึง +1
ตีความได้ทันที ไม่ขึ้นกับหน่วย

ρความหมายตัวอย่าง
+1.0ขึ้น/ลงพร้อมกันเป๊ะหุ้น CPALL กับดัชนี SET50
+0.5ขึ้น/ลงทิศเดียวกัน แต่ไม่ตามหุ้นไทย 2 ตัวในอุตสาหกรรมต่างกัน
0.0ไม่สัมพันธ์กันหุ้นไทย กับราคาข้าวสาลีชิคาโก
−1.0สวนทางกันเป๊ะคนขายร่ม กับ คนขายแว่นกันแดด
เชื่อมกับ Options — Portfolio Variance

ยิ่ง ρ ต่ำ → diversification ลด risk ได้มากขึ้น
Portfolio Variance = Σᵢ Σⱼ wᵢwⱼσᵢσⱼρᵢⱼ
ถ้า ρ = −1: Var พอร์ตลดเป็นศูนย์ได้ (perfect hedge) → นี่คือหลักการของ options hedging!

Model Risk: Correlation พัง ตอน Stress — "Diversification หายไปเมื่อต้องการที่สุด"

Correlation ที่วัดในช่วงตลาดปกติ ไม่ valid ตอน crisis:
• ปี 2008: Correlation ระหว่าง asset classes ต่างๆ กระโดดขึ้นหา +1 พร้อมกัน (everything falls together)
• Diversification ที่คำนวณด้วย ρ = 0.3 อาจกลายเป็น ρ = 0.9 ในวันที่ตลาดร่วง
• ระวัง: wᵀΣw ที่ใช้ historical Σ จะ underestimate tail risk ในสถานการณ์ stress
แก้ไข: Stress test ด้วย correlation matrix จาก historical crisis periods (e.g., 2008, 2020 COVID)

บทที่ 5: ความน่าจะเป็น — "วัดความไม่แน่นอน"

Options คือการ "ซื้อขายความน่าจะเป็น" ราคา call สะท้อนโอกาสที่หุ้นจะขึ้น ราคา put สะท้อนโอกาสที่จะลง — ถ้าไม่เข้าใจ probability ก็ไม่เข้าใจว่า options แพงหรือถูก

5.1 ความน่าจะเป็นพื้นฐาน

🔍 อุปมา: พยากรณ์อากาศ

กรมอุตุฯ บอก "70% ฝนตกพรุ่งนี้" — นี่ไม่ได้แปลว่าพรุ่งนี้ฝนตก 70% ของวัน
แต่แปลว่า: ถ้าวันแบบนี้เกิดขึ้น 100 ครั้ง ฝนตกประมาณ 70 ครั้ง

ความน่าจะเป็นคือ "สัดส่วนในระยะยาว" ไม่ใช่คำทำนายแน่นอน 100%

$$ 0 \le P(A) \le 1 \qquad P(A^c) = 1 - P(A) $$
$$ P(A \cup B) = P(A) + P(B) - P(A \cap B) \qquad P(A \cap B) = P(A) \cdot P(B) \text{ (ถ้าอิสระ)} $$
ตัวอย่าง: Options Trade

ประเมินว่า P(หุ้นขึ้น > 5%) = 30%
P(หุ้นไม่ขึ้น > 5%) = 1 − 30% = 70% ← Call OTM expire ไร้ค่า

ถ้าวิเคราะห์ 2 หุ้น อิสระต่อกัน แต่ละตัว P(ขึ้น) = 60%:
P(ทั้งคู่ขึ้น) = 0.6 × 0.6 = 36%
P(อย่างน้อย 1 ตัวขึ้น) = 1 − P(ทั้งคู่ไม่ขึ้น) = 1 − 0.4×0.4 = 84%

5.2 Combinations C(n, k)

🔍 อุปมา: เลือกนักฟุตบอล

เลือกกองหน้า 2 คนจากผู้เล่น 5 คน (ไม่สนว่าใครเป็นตัวจริง/สำรอง แค่ใครอยู่ในทีม)
C(5,2) = 5! / (2! × 3!) = 120/12 = 10 วิธี

ถ้าสนลำดับ (ตัวจริงคนไหน): Permutation = 5×4 = 20 วิธี
ไม่สนลำดับ: Combination = 20/2! = 10 วิธี

$$ \binom{n}{k} = C(n,k) = \frac{n!}{k!\,(n-k)!} $$
nkC(n,k)ตัวอย่าง
5210เลือกหุ้น 2 ตัวจาก universe 5 ตัว
103120เลือก option 3 ตัวจาก 10 strike
426วันขึ้น 2 วันจาก 4 วัน (Binomial Tree)
เชื่อมกับ Options — Binomial Tree

C(n,k) คือหัวใจของ Binomial Distribution (บทถัดไป)
ใน Binomial Option Pricing: C(4,2) = 6 วิธีที่หุ้นจะขึ้น 2 ครั้งจาก 4 step
รวม payoff ทุก path × ความน่าจะเป็น → ราคา option

5.3 Conditional Probability และ Bayes' Theorem

🔍 อุปมา: ผล COVID Test

ก่อนตรวจ: P(ติดเชื้อ) = 1% (ความชุกในประชากร)
ตรวจได้ผล Positive (B) — ควรกังวลแค่ไหน?

สัญชาตญาณบอกว่า "ติดเชื้อแน่เลย!" แต่ถ้า test มี False Positive rate 5%
ความจริง: P(ติดเชื้อ | ผล Positive) ≈ 17% ไม่ใช่ 99%

Bayes ช่วยอัพเดทความเชื่อเมื่อได้ข้อมูลใหม่

$$ P(A \mid B) = \frac{P(A \cap B)}{P(B)} \qquad \text{(Bayes: } P(A\mid B) = \frac{P(B\mid A)\,P(A)}{P(B)}\text{)} $$
🔍 ทำไม Bayes ถึงเขียนแบบนี้?

เริ่มจากนิยาม: P(A|B) = P(A and B) / P(B)
และ: P(B|A) = P(A and B) / P(A)
ดังนั้น: P(A and B) = P(B|A) × P(A)
แทนเข้าสมการแรก: P(A|B) = P(B|A) × P(A) / P(B) ← ได้ Bayes!

ตัวอย่าง: อัพเดทมุมมองหลังข่าวกำไร

ก่อนประกาศ (prior): P(หุ้นขึ้น) = 50% — ยังไม่มีข้อมูล เดา 50/50
ได้ข่าวกำไรดีกว่าคาด (likelihood): P(กำไรดี|หุ้นขึ้น) = 70%, P(กำไรดี|หุ้นไม่ขึ้น) = 20%
P(กำไรดี) = 0.70×0.50 + 0.20×0.50 = 0.35 + 0.10 = 0.45
P(หุ้นขึ้น | กำไรดี) = 0.70×0.50 / 0.45 = 0.35/0.45 ≈ 78% ← อัพจาก 50% (prior) เป็น 78% (posterior)!

สังเกต: prior (50%), likelihood (70%), posterior (78%) เป็น 3 ค่าที่ต่างกัน — สิ่งที่ผลักให้มุมมองขยับขึ้นมากคือ likelihood ratio 70%/20% = 3.5 เท่า (ข่าวกำไรดี "ชี้" ไปทางหุ้นขึ้นแรง) ยิ่ง ratio สูง posterior ยิ่งเขยิบจาก prior มาก

5.4 Expected Value — "ค่าคาดหวัง"

🔍 อุปมา: เกมทอยเหรียญ

เกม: ทอยเหรียญ — หัวได้ +฿100, ก้อยเสีย −฿80
ควรเล่นไหม? ทอย 1,000 ครั้ง:
• หัว ~500 ครั้ง: ได้ 500 × ฿100 = +฿50,000
• ก้อย ~500 ครั้ง: เสีย 500 × ฿80 = −฿40,000
• กำไรสุทธิ: +฿10,000 / 1,000 ครั้ง = +฿10 ต่อครั้ง

นี่คือ Expected Value = +฿10 → ควรเล่น!

$$ E[X] = \sum_i x_i\,P(x_i) $$
$$ E[aX+b] = a\,E[X]+b \qquad E[X+Y] = E[X]+E[Y] \text{ (เสมอ)} $$
🔍 ทำไม E[X] = Σ xᵢ × P(xᵢ)?

คิดแบบ weighted average: แต่ละผลลัพธ์มีน้ำหนัก = ความน่าจะเป็น
ผลลัพธ์ที่เกิดบ่อย (P สูง) ควรมีน้ำหนักมาก
ผลลัพธ์ที่เกิดน้อย (P ต่ำ) ควรมีน้ำหนักน้อย

E[X] คือ ค่าเฉลี่ยถ่วงน้ำหนักด้วย probability ไม่ใช่ค่าเฉลี่ยธรรมดา

เชื่อมกับ Options — Expected Payoff

ราคา Call Option = \(e^{-rT}\) × E*[max(0, S_T − K)]
E* = expected value ภายใต้ risk-neutral probability
= "ถ้า option expire วันนี้ 1,000 ครั้ง แต่ละครั้ง payoff เฉลี่ยเท่าไร" → นั่นคือราคา!

5.5 Variance ของตัวแปรสุ่ม

$$ \text{Var}(X) = E[(X-\mu)^2] = E[X^2] - (E[X])^2 $$
$$ \text{Var}(aX+b) = a^2\,\text{Var}(X) \qquad \text{Var}(X+Y) = \text{Var}(X)+\text{Var}(Y)+2\,\text{Cov}(X,Y) $$
🔍 ทำไม Var(aX + b) = a²Var(X)?

b คือ "ขยับกราฟซ้าย/ขวา" — ไม่เปลี่ยนความกระจาย → Var ไม่เปลี่ยน
a คือ "ขยาย/ยุบ scale" — ถ้า scale กว้างขึ้น 2 เท่า ทุกระยะห่างกว้าง 2 เท่า
แต่ Var คิดจาก (xᵢ−μ)² → ระยะห่างยกกำลัง 2 → Var เพิ่ม a² เท่า

เชื่อมกับ Options — Portfolio Variance

Var(X+Y) = Var(X) + Var(Y) + 2·Cov(X,Y)
ขยายเป็น n หุ้น: σ²_p = wᵀ Σ w (matrix form — บท 8)
ถ้า Cov = 0 (uncorrelated): Portfolio Var = Var(X) + Var(Y) → diversification!

สรุปบทที่ 5

✓ Probability = "สัดส่วนในระยะยาว" ไม่ใช่คำทำนาย
✓ C(n,k) → จำนวน paths ใน Binomial Tree
✓ Bayes: อัพเดทความเชื่อจากข้อมูลใหม่ (กำไร, FOMC, ข่าว)
✓ E[X] = weighted average ของผลลัพธ์ → ราคา option = E* ของ payoff
✓ Var properties → เข้าใจ portfolio risk

ข้อ 3. P(หุ้นขึ้น) = 55%, P(IV ลด | หุ้นขึ้น) = 70%, P(IV ลด | หุ้นไม่ขึ้น) = 20%

บทที่ 6: Distributions — "รูปทรงของความไม่แน่นอน"

Distribution คือ "แผนที่" ของความน่าจะเป็น — บอกว่าค่าต่างๆ มีโอกาสเกิดมากน้อยแค่ไหน บทนี้สอน 4 distribution ที่สำคัญที่สุดใน options pricing

6.1 Binomial Distribution

🔍 อุปมา: ยิง penalty 5 ลูก

นักเตะมีโอกาสยิงได้ 70% ต่อลูก ยิง 5 ลูก
โอกาสยิงได้พอดี 3 ลูกคือเท่าไร?

• ต้องเลือกว่า 3 ลูกไหนจาก 5 ที่จะได้ → C(5,3) = 10 วิธี
• แต่ละวิธี: P = (0.7)³ × (0.3)² = 0.343 × 0.09 = 0.03087
• P(ยิงได้ 3 จาก 5) = 10 × 0.03087 = 30.87%

$$ P(X = k) = \binom{n}{k}\,p^k\,(1-p)^{n-k} $$
🔍 ทำไมสูตรถึงเขียนแบบนี้?

C(n,k) = จำนวนวิธีที่ k ครั้งจาก n ครั้งจะสำเร็จ (ลำดับไม่สำคัญ)
\(p^k\) = โอกาสสำเร็จ k ครั้ง (ทุกครั้งอิสระ → คูณกัน)
\((1-p)^{n-k}\) = โอกาสล้มเหลว n−k ครั้งที่เหลือ

รวม: "มีกี่วิธี" × "วิธีหนึ่งเป็นไปได้แค่ไหน" = ความน่าจะเป็นรวม

ตัวอย่าง: โยนเหรียญ (p=0.5) 4 ครั้ง

แผนภาพ: Binomial Distribution (n=4, p=0.5) — ความน่าจะเป็นแต่ละผลลัพธ์
เชื่อมกับ Options — Binomial Tree Pricing

ใน Cox-Ross-Rubinstein (CRR) model:
ราคาหุ้น step หนึ่ง ขึ้น u เท่า (prob p) หรือลง d เท่า (prob 1−p) = Binomial!
n steps → n→∞ → Binomial → Normal (CLT) → ได้ Black-Scholes

6.2 Normal Distribution — หัวใจของ Black-Scholes

🔍 อุปมา: ส่วนสูงนักเรียน

วัดส่วนสูงนักเรียน 1,000 คน:
• ส่วนใหญ่สูง 165–170 cm (กลุ่มใหญ่กองอยู่ตรงกลาง)
• น้อยคนที่สูง 140 cm หรือ 200 cm (หางทั้งสองข้างบาง)
• กราฟออกมาเป็นรูประฆัง = Normal Distribution

Daily returns ของหุ้นก็มีรูปร่างคล้ายกัน — ส่วนใหญ่เปลี่ยนแปลงน้อย วันที่ขึ้น/ลงมากนานๆ ถึงเจอ

Normal Distribution กำหนดโดย 2 ค่า:

  • μ (mean) = จุดศูนย์กลาง (ยอดระฆัง)
  • σ (standard deviation) = ความกว้างของระฆัง
$$ f(x) = \frac{1}{\sigma\sqrt{2\pi}}\,e^{-\frac{(x-\mu)^2}{2\sigma^2}} $$
🔍 ทำไมสูตรถึงดูซับซ้อน? แยกเป็น 2 ส่วน

ส่วนที่ 1: \(e^{-(x-μ)²/(2σ²)}\) — "รูปร่างระฆัง"
• (x−μ)² = ระยะห่างจาก mean ยกกำลัง 2 (เสมอ ≥ 0)
• ยิ่งห่างจาก mean → exponent ลบมาก → \(e^{-ใหญ่มาก}\) → ใกล้ 0 (หางบาง)
• x = μ: exponent = 0 → \(e^{0}\) = 1 → peak ที่ mean
• σ ใหญ่ → 2σ² ใหญ่ → e ลดลงช้า → ระฆังกว้าง

ส่วนที่ 2: 1/(σ√(2π)) — "scaling factor"
• √(2π) ≈ 2.507 มาจากการ integrate กราฟ Gaussian
• ทำให้พื้นที่ใต้กราฟทั้งหมด = 1 (นิยาม probability)

กฎ 68–95–99.7:

ช่วงครอบคลุมตัวอย่าง: หุ้น μ=0%, σ=20%/ปี
μ ± 1σ68.3%68% ของปี return อยู่ใน −20% ถึง +20%
μ ± 2σ95.4%95% อยู่ใน −40% ถึง +40%
μ ± 3σ99.7%99.7% อยู่ใน −60% ถึง +60%

6.3 Z-Score และ Standard Normal N(0,1)

🔍 อุปมา: GPS พิกัดสัมพัทธ์

แทนที่จะบอกว่า "คุณอยู่ที่ latitude 13.756° N" (ตัวเลขสัมบูรณ์)
ลองบอกว่า "คุณอยู่ห่างจากศูนย์กลางเมือง 3.2 กม." (ตัวเลขสัมพัทธ์)

Z-score เหมือนกัน: แทนที่จะพูดถึงค่าดิบ x
บอกว่า "x ห่างจาก mean กี่ standard deviation" → เทียบข้ามหุ้น ข้าม market ได้ทันที

$$ Z = \frac{x - \mu}{\sigma} \qquad N(d) = P(Z \le d) = \int_{-\infty}^{d} \frac{1}{\sqrt{2\pi}}\,e^{-t^2/2}\,dt $$
🔍 ทำไม Z = (x−μ)/σ?

ลบ μ: ขยับ distribution ให้ mean = 0 (เหมือนเอา 0 ไว้ตรงกลาง)
หาร σ: scale ให้ standard deviation = 1 (มาตรฐานเดียวกัน)

ผล: ไม่ว่าข้อมูลจะมีหน่วยอะไร scale แค่ไหน → แปลงเป็น Z ได้เสมอ
Z = −2 แปลว่า "ต่ำกว่า mean 2 เท่าของ σ" ทุก distribution

เชื่อมกับ Options — N(d₁) และ N(d₂) ใน Black-Scholes!

C = S₀ × N(d₁) − K × \(e^{-rT}\) × N(d₂)
• N(d₂) = ความน่าจะเป็นที่ option จะ expire ITM (ภายใต้ risk-neutral world)
• N(d₁) = N(d₂) ที่ปรับด้วย delta → ใช้ hedge
• d₁, d₂ คือ Z-scores ที่รวม ln(S/K), r, σ, T เข้าด้วยกัน
พอรู้ Z-score → lookup ตาราง N(d) → ได้ราคา option!

6.4 Lognormal Distribution — ทำไมราคาหุ้นไม่เป็น Normal

ปัญหา: Normal Distribution → ราคาหุ้นติดลบได้!

ถ้าราคาหุ้น ~ Normal(500, 200²) → มีโอกาส ~0.6% ที่ราคาจะ < 0
ราคาหุ้น −฿50 ไม่มีความหมายในโลกจริง (limited liability → ต่ำสุดคือ 0)
Normal ใช้กับราคาไม่ได้!

🔍 อุปมา: เงินทบต้น

ฝากเงิน ฿100 ทบต้นทุกวัน อัตราดอกเบี้ยรายวัน r:
วันที่ 1: ฿100 × (1+r₁)
วันที่ 2: ฿100 × (1+r₁) × (1+r₂)
...
วันที่ n: ฿100 × Π(1+rᵢ) ≈ ฿100 × \(e^{r_1+r_2+\cdots+r_n}\)

ผลคูณของ random variables → Lognormal! เพราะ \(e^X\) > 0 เสมอ

$$ \ln(S) \sim \mathcal{N}(\mu,\sigma^2) \;\Rightarrow\; S \sim \text{Lognormal} \quad (S = e^{\ln S} > 0) $$

Chain: \(r = \ln(S_1/S_0) \sim \mathcal{N}\) → \(S_1/S_0 = e^r \sim \text{Lognormal}\)

Normal distribution (can be negative) vs Lognormal (always ≥ 0)
สาย Chain: Log Return → Normal → ราคา → Lognormal

r = ln(S₁/S₀) ~ Normal → S₁ = S₀ × \(e^r\) ~ Lognormal
Black-Scholes สมมติว่า log returns เป็น Normal Distribution
→ ราคาหุ้นเป็น Lognormal → ราคาไม่ติดลบ ✓

Quant Desk: Lognormal เป็น Working Assumption — รู้ข้อจำกัดไว้ด้วย

Lognormal ใช้กันทั่วไปใน derivatives pricing เพราะ:
• ราคาไม่ติดลบ (bounded below by 0) ✓
• มี closed-form solution สำหรับ Black-Scholes ✓
• Log returns additive ข้ามช่วงเวลา ✓
แต่ data จริงมี fat tails และ negative skew (§6.6) — นั่นคือทำไมตลาดจึงให้ implied vol ที่ OTM Put > ATM (Volatility Skew)

6.5 Central Limit Theorem (CLT) — เวทมนตร์ของสถิติ

Central Limit Theorem

"ค่าเฉลี่ยของตัวอย่างจำนวนมาก → Normal Distribution เสมอ
ไม่ว่า distribution เดิมจะเป็นรูปร่างอะไรก็ตาม"

ต้องการแค่: (1) sample size ใหญ่พอ (n ≥ 30 มักพอ) (2) variance มีอยู่จำกัด

🔍 Demo: ทอยลูกเต๋า

ทอย 1 ลูก: distribution สม่ำเสมอ (แต่ละหน้า 1/6) — ไม่ใช่ Normal เลย!
เฉลี่ย 2 ลูก: distribution เริ่มรูปสามเหลี่ยม (กลางนูน)
เฉลี่ย 10 ลูก: distribution คล้าย bell curve
เฉลี่ย 30 ลูก: Normal Distribution ชัดเจน!

ลูกเต๋าไม่ Normal เลย แต่ ค่าเฉลี่ยของลูกเต๋าหลายๆ ลูก → Normal = CLT

เชื่อมกับ Options

• Binomial → Normal (CLT): เมื่อ n steps → ∞ → ได้ Black-Scholes สูตร!
• Return รายวันอาจไม่ Normal แต่ return รายเดือน/ปี ≈ Normal (CLT)
• Monte Carlo: เฉลี่ย payoff จากล้าน simulations → converge หา E[payoff] ได้แม่น

6.6 Skewness และ Kurtosis — ตลาดจริงไม่ใช่ Normal

🔍 อุปมา: เงินเดือนในไทย (Skewness)

เงินเดือนคนไทยส่วนใหญ่ 15,000–30,000 บาท แต่มีมหาเศรษฐีไม่กี่คนรับ 10 ล้าน/เดือน
→ กราฟ เบ้ขวา (Positive Skew): หางขวายาว, Mean > Median

ตลาดหุ้นกลับกัน: เบ้ซ้าย (Negative Skew)
วัน crash (−10%) เกิดบ่อยกว่าวัน rally (+10%) และรุนแรงกว่า
→ หางซ้ายยาว = ผู้ถือหุ้นกลัวขาดทุนหนักกว่าที่ Normal ทำนาย

🔍 อุปมา: แผ่นดินไหว 100 ปีครั้ง (Kurtosis)

ถ้าตลาดเป็น Normal จริง: เหตุการณ์ 5σ (เช่น −40% ในวันเดียว) ควรเกิด 1 ในล้านล้านวัน
แต่ในความเป็นจริง: crash รุนแรงเกิดบ่อยกว่านั้นมาก (ทุก 10–20 ปี)

Fat Tails (Kurtosis สูง) = หางหนากว่า Normal
= เหตุการณ์สุดขั้วเกิดบ่อยกว่าที่ model ทำนาย

สมบัติNormalตลาดจริงผลกระทบต่อ Options
Skewness0 (สมมาตร)เบ้ซ้าย (negative)Put OTM แพงกว่า Call OTM
Kurtosis3 (mesokurtic)>3 (fat tails)Deep OTM options แพงกว่า BS
Real returns have heavier tails than Normal — OTM options are priced accordingly
เชื่อมกับ Options — Volatility Smile / Skew

ตลาด "รู้" ว่า Normal ไม่พอ → ราคา options สะท้อน fat tails จริงๆ
• OTM Puts แพงกว่า BS ทำนาย → Volatility Skew (IV ลดขณะ strike เพิ่ม)
• Deep OTM ทั้งสองด้านแพง → Volatility Smile
นี่คือเหตุผลที่ quant ต้อง "ซื้อ vol ที่ถูก ขาย vol ที่แพง" ไม่ใช่แค่ดู BS

สรุปบทที่ 6

✓ Binomial: C(n,k)×p^k×(1−p)^(n−k) → สะพานสู่ Binomial Tree
✓ Normal: Bell curve, กฎ 68-95-99.7, สูตร 2 ส่วน (รูปร่าง + scaling)
✓ Z-score → N(d): อ่าน N(d₁), N(d₂) ใน Black-Scholes ออกแล้ว!
✓ Lognormal: ราคาหุ้นต้อง ≥ 0 → log return Normal → ราคา Lognormal
✓ CLT: ค่าเฉลี่ยหลายๆ sample → Normal เสมอ → ทำไม BS ทำงานได้
✓ Skew + Fat Tails: ตลาดจริง ≠ Normal → Volatility Smile/Skew

(ก) โอกาสที่ return จะอยู่ใน −25% ถึง +25%
(ข) โอกาสที่จะ ขาดทุนมากกว่า 50%/ปี
(ค) ถ้าซื้อ Put Strike −50% (deep OTM) ความน่าจะเป็นที่จะ ITM คือเท่าไร?

ข้อ 2. หุ้นราคา ฿100, σ = 20%/ปี, T = 1 ปี, r = 3%
ในโมเดล Black-Scholes: d₂ = [ln(100/95) + (r − σ²/2)T] / (σ√T) = [0.0513 + (0.03−0.02)×1] / (0.20×1) = 0.0613/0.20 ≈ 0.31
N(0.31) ≈ 0.6217 → ความน่าจะเป็นที่ Call (K=95) จะ expire ITM คือเท่าไร?

ดูเฉลย
N(d₂) = ความน่าจะเป็นที่ option expire ITM = 62.2%
หมายความว่า: มีโอกาส ~62% ที่หุ้นจะอยู่เหนือ ฿95 เมื่อ expire

ข้อ 3. ตลาดหุ้นมี Negative Skew และ Fat Tails
ระหว่าง (ก) Short ATM Straddle กับ (ข) Short OTM Put — ตัวไหนเสี่ยงกว่าในโลกจริง? เพราะอะไร?

ดูเฉลย
Short OTM Put เสี่ยงกว่า เพราะ:
• Fat Tails: crash รุนแรงเกิดบ่อยกว่าที่ Normal ทำนาย → OTM Put expire ITM บ่อยกว่า
• Negative Skew: หางซ้ายหนากว่าหางขวา → Short Put รับ downside ที่แย่กว่า model
• ในโลก Normal: Short OTM Put ดูปลอดภัย (2.3% โอกาส ITM) แต่ตลาดจริงอาจ 5–8%
