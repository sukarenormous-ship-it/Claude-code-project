บทที่ 11: Put-Call Parity Arbitrage

11.1 ทบทวน PCP

C + K·e⁻ʳᵀ = P + S

📖 อ่านสูตรว่า: ทวน: "ซี บวก เค อี ยกกำลังลบอาร์ที เท่ากับ พี บวก เอส" — โครง "ราคาเดียวกันสองทาง" อ่านเต็มไว้แล้วที่ Part I บท 3.4 · บทนี้ใช้แค่ข้อเดียว: ฝั่งไหนแพงกว่า ขายฝั่งนั้น ซื้ออีกฝั่ง

ถ้าซ้าย ≠ ขวา → Arb [Exact Identity]

11.2 Conversion — ซ้าย > ขวา

ถ้า C + Ke⁻ʳᵀ > P + S:
→ ขายฝั่งซ้าย (Short Call + Borrow K) + ซื้อฝั่งขวา (Long Put + Long Stock)
= Long Stock + Long Put + Short Call = Conversion
กำไร = (C + Ke⁻ʳᵀ) - (P + S) > 0 [locked at entry]

📖 อ่านสูตรว่า: "กำไร เท่ากับ (ซี บวก เค อี ยกกำลังลบอาร์ที) ลบ (พี บวก เอส) มากกว่าศูนย์" · โครงที่ต้องเห็น: ผลต่างของสองฝั่ง PCP — ตัวเลขที่ได้เป็นบาทวันนี้ (เพราะ K ถูกลดค่าแล้ว) และล็อกตั้งแต่เข้า ไม่ขึ้นกับว่า S จะไปทางไหน · กับดักการอ่าน: วงเล็บสองคู่บอกว่า "ขายทั้งก้อนซ้าย ซื้อทั้งก้อนขวา" ต้องทำครบทุกขาพร้อมกัน ไม่ใช่เลือกขา · เครื่องหมายบวกใน "Long Stock + Long Put + Short Call" อ่านว่า "ถือพร้อมกัน" ไม่ใช่บวกราคา

11.3 Reversal — ซ้าย < ขวา

ถ้า C + Ke⁻ʳᵀ < P + S:
→ ซื้อฝั่งซ้าย (Long Call + Lend K) + ขายฝั่งขวา (Short Put + Short Stock)
= Short Stock + Short Put + Long Call = Reversal

📖 อ่านสูตรว่า: กระจกของ 11.2 — สลับทุกเครื่องหมาย: ฝั่งซ้ายถูกกว่าจึงซื้อซ้าย ขายขวา กำไร = (P + S) − (C + Ke⁻ʳᵀ) > 0 อ่านแบบเดียวกัน

11.4 ตัวอย่างตัวเลข

S = ฿100, K = 100, r = 5%, T = 0.5 ปี
Call = ฿8.50, Put = ฿5.80
PV(K) = 100 × e⁻⁰·⁰²⁵ = ฿97.53

ซ้าย: C + PV(K) = 8.50 + 97.53 = ฿106.03
ขวา: P + S = 5.80 + 100 = ฿105.80
Violation = 106.03 - 105.80 = ฿0.23

ทำ Conversion: กำไร gross = ฿0.23
หัก commission (4 legs × ฿0.03) = ฿0.12
หัก bid-ask (avg ฿0.05 × 4) = ฿0.20
Net = 0.23 - 0.12 - 0.20 = -฿0.09 ← ขาดทุน! ไม่คุ้ม!
ทำไม PCP Arb หายาก

Market makers คอย scan PCP violations ตลอด → violations เล็กมาก → หลังหัก bid-ask มักไม่เหลือ
ต้องมี edge ด้าน execution (เร็วกว่า, commission ถูกกว่า) ถึงจะทำได้

บทที่ 12: Box Spread & Synthetic Arbitrage

12.1 Box Spread = Bond

Box(K₁,K₂) = Bull Call Spread(K₁,K₂) + Bear Put Spread(K₁,K₂)
= PV(K₂ - K₁) [Exact Identity]

ถ้า Box Price ≠ PV(K₂-K₁) → Arbitrage!

📖 อ่านสูตรว่า: "บ็อกซ์ของเคหนึ่ง เคสอง เท่ากับ บูลคอลสเปรด บวก แบร์พุตสเปรด เท่ากับ มูลค่าปัจจุบันของ เคสอง ลบ เคหนึ่ง" · โครงที่ต้องเห็น: payoff = ผลรวมของขา ที่รวมแล้วแบน — ลอง S ≤ K₁: call spread ให้ 0 put spread ให้ K₂ − K₁ · S ≥ K₂: call spread ให้ K₂ − K₁ put spread ให้ 0 · ตรงกลางสองขาบวกกันได้ K₂ − K₁ เสมอ — จ่ายเท่ากันทุกกรณี = พันธบัตร · กับดักการอ่าน: PV(·) เป็นฟังก์ชัน "ลดค่า" = (K₂ − K₁)·e⁻ʳᵀ ไม่ใช่ตัวแปรชื่อ PV · ตัวห้อย 1, 2 คือหมายเลข strike (K₁ < K₂) · เอกลักษณ์นี้ Exact เฉพาะ European — ถ้าถูกใช้สิทธิ์ก่อนกำหนด ผลรวมไม่แบนอีก

12.2 ตัวอย่าง Box Arb

K₁=90, K₂=110, r=5%, T=0.25 ปี
Fair Box Value = PV(110-90) = 20 × e⁻⁰·⁰¹²⁵ = ฿19.75

Market prices: Bull Call Spread = ฿12, Bear Put Spread = ฿6.50
Box Price = 12 + 6.50 = ฿18.50 ← ถูกกว่า fair ฿19.75!
→ ซื้อ Box ฿18.50, settle ได้ ฿20 ที่ expiry
→ กำไร ณ วันหมดอายุ = 20 - 18.50 = ฿1.50 risk-free · คิดเป็นมูลค่าปัจจุบัน = 19.75 - 18.50 = ฿1.25 (สองตัวเลขนี้คือเงินก้อนเดียวกันคนละเวลา — เทียบกับ arb อื่นต้องใช้ตัว PV) (ถ้า European + หักค่าธรรมเนียมแล้วเหลือ)

12.3 Synthetic Forward vs Actual Forward

Synthetic Forward = Long Call(K) + Short Put(K) → ราคาต้อง = Forward Price
ถ้าไม่เท่า → Arb เหมือน PCP

12.4 Dividend Arbitrage

เมื่อ Options ไม่ reflect Dividend ถูกต้อง

ก่อน ex-div: American Call อาจคุ้มที่จะ exercise ก่อนวันนั้น
ถ้า market ไม่ price early exercise premium → ซื้อ Call ถูก → exercise ก่อน ex-div → ได้ dividend

บทที่ 13: Volatility Arbitrage

Greeks Quick Reference (จากเล่มคณิตศาสตร์ บทที่ 7)

Delta (Δ) = ราคา Option เปลี่ยนเท่าไร เมื่อราคาหุ้นเปลี่ยน ฿1 (= slope ของ payoff curve)
Gamma (Γ) = Delta เปลี่ยนเท่าไร เมื่อราคาหุ้นเปลี่ยน ฿1 (= ความโค้ง, สูงสุดที่ ATM)
Theta (Θ) = ราคา Option ลดลงเท่าไรต่อวัน (time decay, มักเป็นลบ)
Vega (ν) = ราคา Option เปลี่ยนเท่าไร เมื่อ volatility เปลี่ยน 1%

13.1 IV vs RV — ซื้อ/ขาย Volatility

Implied Volatility (IV) = ตลาดคาดว่า vol จะเป็นเท่าไร
Realized Volatility (RV) = vol ที่เกิดขึ้นจริง

ถ้า IV > RV → Options "แพงเกินไป" → ขาย options (seller's edge)
ถ้า IV < RV → Options "ถูกเกินไป" → ซื้อ options (buyer's edge)

📖 อ่านสูตรว่า: "IV มากกว่า RV" — เทียบ σ สองตัว: ตัวที่ตลาดฝังไว้ในราคา option กับตัวที่วัดได้จากราคาหุ้นจริง · โครงที่ต้องเห็น: อสมการของสองปริมาณหน่วยเดียวกัน (% ต่อปี) — เทียบได้ก็เพราะหน่วยตรงกัน · กับดักการอ่าน: IV ที่ quote มาเป็นต่อปีเสมอ ถ้าคำนวณ RV จากผลตอบแทนรายวันต้องคูณ √252 ก่อนวางข้างกัน · IV เป็น "ราคา" ที่ตลาดตั้ง RV เป็น "ค่าประมาณ" จากอดีต (σ̂) — ทั้งคู่ไม่ใช่ σ จริงในอนาคต ซึ่งไม่มีใครรู้

13.2 Delta-Neutral Trading

ซื้อ/ขาย Option + Hedge Delta ด้วย Spot/Futures
→ เหลือเฉพาะ vol exposure (Gamma + Vega)

ถ้า IV = 30% แต่ RV = 20% → ขาย option + hedge delta
→ เก็บ premium ส่วนเกิน 10% → กำไรจาก vol spread

📖 อ่านสูตรว่า: "IV 30% แต่ RV 20% → เก็บส่วนเกิน 10%" · กับดักการอ่าน: 30 − 20 = 10 คือ 10 จุด vol (vol points) ไม่ใช่กำไร 10% ของเงินที่ลง — จะเป็นเงินเท่าไรขึ้นกับ Vega และ Gamma ของ position · "Hedge Delta" อ่านว่า "ทำให้ผลรวม Delta ของทุกขาเป็นศูนย์" ที่เหลือคือ Gamma กับ Vega ซึ่งไม่ถูก hedge — นั่นคือสิ่งที่เราตั้งใจถือ

13.3 Gamma Scalping

ซื้อ Options (Long Gamma) + Rehedge delta ทุกวัน:
ถ้า actual price moves > IV implied → กำไรจาก rehedging > time decay ที่จ่าย

Gamma Scalping P&L

Daily P&L ≈ ½ × Gamma × (ΔS)² - Theta
ถ้า actual (ΔS)² > implied → positive P&L → RV > IV = buyer wins

13.4 Vol Surface Arbitrage

Vol surface (IV vs Strike vs Expiry) ต้อง smooth + convex:
ถ้า Butterfly < 0 ที่ใด → Arb!
ถ้า Calendar spread < 0 (near-term IV > far-term IV ผิดปกติ) → investigate

13.5 Dispersion Trading

Index Vol vs Component Stocks Vol:
Index Vol ≤ weighted average of Component Vols (เพราะ correlation < 1)

ถ้า Index Vol "แพง" เทียบกับ Components → ขาย Index Options + ซื้อ Component Options

หัวใจของ Dispersion: กำไรจริงๆ มาจาก implied correlation สูงเกินไป — Index vol สูงเพราะตลาดสมมติว่าหุ้นทุกตัวจะเคลื่อนไหวพร้อมกัน (ρ สูง) ถ้า realized correlation ต่ำกว่า implied → dispersion trader ได้กำไร

📖 อ่านสูตรว่า: "วอลของดัชนี น้อยกว่าหรือเท่ากับ ค่าเฉลี่ยถ่วงน้ำหนักของวอลหุ้นสมาชิก" · โครงที่ต้องเห็น: SD ของผลรวมบวกกันแบบกำลังสอง ไม่ใช่เชิงเส้น — สองหุ้นน้ำหนักเท่ากัน σ ของพอร์ตแปรตาม √(σ₁² + σ₂² + 2ρσ₁σ₂) ซึ่งเท่ากับ σ₁ + σ₂ ก็ต่อเมื่อ ρ = 1 ต่ำกว่านั้นทุกครั้งที่ ρ < 1 · ส่วนต่างระหว่างสองข้างจึงเป็น "ราคา" ของ correlation ที่ตลาดฝังไว้ · กับดักการอ่าน: ≤ ไม่ใช่ = — ไม่มี arb จากอสมการนี้ตรงๆ กำไรมาจากการเดาว่า ρ ที่ตลาดคิด (implied) สูงกว่าที่จะเกิดจริง (realized) ซึ่งเป็น [Heuristic] · ρ ตัวเดียวในประโยคแทน "correlation เฉลี่ยของทุกคู่" ไม่ใช่คู่ใดคู่หนึ่ง

บทที่ 14: Advanced Options — Skew, Term Structure, Pin Risk

14.1 Skew Arbitrage

ถ้า Put Skew สูงผิดปกติ (OTM Puts แพงมาก):
→ ขาย OTM Put + ซื้อ ATM structure → เก็บ fear premium

ระวัง: Skew มีอยู่เพราะมีเหตุผล!

OTM Puts แพงเพราะ fat left tail — crash เกิดน้อยแต่เสียหนัก
Skew arb ≠ free money — เป็น Lv.4 Structured [Heuristic]

14.2 Term Structure Arbitrage

ปกติ: IV เพิ่มขึ้นตาม expiry (term structure ขึ้น)
ถ้ากลับทิศ (near > far) → Calendar Spread opportunity

14.3 Pin Risk

ใกล้ expiry: ถ้าราคาอยู่ใกล้ Strike มาก → ไม่รู้ว่าจะ exercise หรือไม่
Market Makers ต้อง hedge → สร้าง pressure ที่ทำให้ราคา "pin" ที่ Strike

14.4 กรณีศึกษา: LTCM Equity Vol Trades

LTCM (1998)

ขาย equity index vol (IV สูงหลัง Asian Crisis) → ถูกต้องว่า IV overpriced
แต่ใช้ leverage สูงเกินไป → Russian default → vol พุ่งอีก → margin call ก่อน vol converge
บทเรียน: ถูกต้องไม่พอ ต้อง survive ให้ถึงวันที่ arb converge

End-to-End Trade Flow: Earn + Hedge (Lv.3 Near-Arb) ★

นี่คือตัวอย่าง trade จริง ตั้งแต่ต้นจนจบ ที่คนธรรมดาทำได้:

Step 1 — Observe: เห็น Bybit Earn USDT 12% APR (promo, ปกติ 4%)
Step 2 — Classify: Lv.3 Near-Arb, edge source = platform subsidy [Heuristic]
Step 3 — Calculate: ฝาก USDT ฿100,000 × 12% / 365 × 30 วัน = ฿986 ต่อเดือน
Step 4 — Risk check: USDT stable (ไม่ต้อง hedge) แต่ platform risk → size ≤ 10% ของพอร์ต
Step 5 — Execute: ฝากใน Bybit Earn → lock 30 วัน
Step 6 — Monitor: เช็คทุกสัปดาห์ว่า promo ยังอยู่ไหม
Step 7 — Exit: ครบ 30 วัน → ถอน USDT + ดอกเบี้ย ฿986
Net P&L: ฿986 (หลังหัก withdrawal fee ฿2) = ฿984

ง่ายมาก 1 ขา ไม่ต้อง hedge! แต่: ไม่ใช่ "arb จริง" (Lv.3) — เสี่ยง platform + ไม่ guaranteed

ปัญหา: American Options exercise ก่อนหมดอายุได้ → Box "แตก" → ขาดทุน $58,000
บทเรียน: Box Spread = PV(width) เฉพาะ European Options เท่านั้น [Contract-specific]!
