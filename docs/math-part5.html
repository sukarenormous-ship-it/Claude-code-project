บทที่ 10: Linear Programming

LP = หาค่า maximum/minimum ของฟังก์ชันเชิงเส้น ภายใต้เงื่อนไข (constraints) ที่เป็นเชิงเส้น

10.1 แนวคิดและการตั้งโจทย์

Maximize z = c₁x₁ + c₂x₂    (Objective Function)
Subject to:
  a₁₁x₁ + a₁₂x₂ ≤ b₁    (Constraint 1)
  a₂₁x₁ + a₂₂x₂ ≤ b₂    (Constraint 2)
  x₁, x₂ ≥ 0             (Non-negativity)
ตัวอย่าง: จัดพอร์ต Options

Maximize Expected Payoff = 8x₁ + 5x₂
(x₁ = จำนวน Call K=100, x₂ = จำนวน Call K=110)
Subject to:
Premium: 5x₁ + 2x₂ ≤ 20 (budget ฿20)
Risk: x₁ + x₂ ≤ 5 (ไม่เกิน 5 สัญญา)
x₁, x₂ ≥ 0

10.2 Graphical Method

สำหรับ 2 ตัวแปร แก้ได้ด้วยกราฟ: วาด constraints → หา feasible region → เช็ค corner points

Corner Point Theorem

คำตอบ optimal ของ LP อยู่ที่มุม (corner) ของ feasible region เสมอ!
ดังนั้นเช็คแค่ทุก corner → เลือกค่า z สูงสุด

10.3 Simplex Method

เมื่อมีหลายตัวแปร (ใช้กราฟไม่ได้) ใช้ Simplex Algorithm:

  1. เริ่มที่ corner หนึ่ง (มักเป็นจุด origin)
  2. มองไปรอบๆ ว่า corner ไหนดีกว่า
  3. เดินไปที่ corner ที่ดีขึ้นมากที่สุด (pivot)
  4. ทำซ้ำจนไม่มี corner ที่ดีกว่า → optimal!
Simplex ไม่ต้องจำขั้นตอน แค่เข้าใจหลักการ

"เดินไปตาม edge ของ feasible region จาก corner สู่ corner ที่ดีขึ้นเรื่อยๆ"
ในทางปฏิบัติใช้ software (Excel Solver, Python scipy.optimize.linprog)

10.4 Dual Problem & Shadow Price

ทุก LP (Primal) มีคู่ (Dual) — ให้มุมมองเพิ่มเติม:

Primal: Max cTx s.t. Ax ≤ b, x ≥ 0
Dual:   Min bTy s.t. ATy ≥ c, y ≥ 0

Weak Duality: ค่า Dual ≥ ค่า Primal เสมอ
Strong Duality: ที่ optimal ค่าเท่ากัน!

Shadow Price (y*) = "ถ้าเพิ่ม resource (b) อีก 1 หน่วย ค่า objective จะเพิ่มเท่าไหร่?"

เชื่อมกับ Options

Shadow Price ของ budget constraint = "ถ้ามีเงินเพิ่มอีก ฿1 expected payoff จะเพิ่มเท่าไหร่?"
ใช้ตัดสินใจว่าควร "ขยาย budget" หรือ "ลด risk limit"

10.5 Sensitivity Analysis

ถ้า parameter เปลี่ยน คำตอบเปลี่ยนไหม?

  • Coefficient ใน objective เปลี่ยน: ถ้า expected payoff ของ Call เปลี่ยน → basis ยังเหมือนเดิมไหม?
  • RHS ของ constraint เปลี่ยน: ถ้า budget เพิ่ม → ใช้ shadow price คำนวณ

10.6 Integer Linear Programming (ILP)

ปัญหา: LP ตอบว่า "ซื้อ Call 2.7 สัญญา" ← ซื้อ 0.7 สัญญาไม่ได้!

ILP = LP ที่ตัวแปรต้องเป็นจำนวนเต็ม

Max cTx   s.t. Ax ≤ b, x ≥ 0, x ∈ ℤ (integers)
ILP ยากกว่า LP มาก!

LP แก้ได้ใน polynomial time แต่ ILP เป็น NP-hard → ไม่มี algorithm ที่เร็วเสมอ
วิธีแก้: Branch and Bound — แก้ LP relaxation ก่อน แล้ว branch ที่ตัวแปรที่ไม่เป็นจำนวนเต็ม

เชื่อมกับ Options

Options ซื้อเป็น สัญญา (1 contract = 100 หุ้น) → ต้องเป็นจำนวนเต็ม!
ตัวอย่าง: เลือก combination ของ option contracts ที่ maximize payoff-to-risk ภายใต้ budget constraint → ILP problem

บทที่ 11: Nonlinear Optimization

โลกจริงไม่เป็นเส้นตรง — Portfolio Optimization ของ Markowitz เป็น Quadratic ไม่ใช่ Linear

11.1 Unconstrained Optimization

หา min/max ของ f(x) โดยไม่มี constraints:

เงื่อนไขจำเป็น: f'(x*) = 0    (slope = 0 ที่จุด optimal)
เงื่อนไขเพียงพอ:
  f''(x*) > 0 → minimum (โค้งขึ้น)
  f''(x*) < 0 → maximum (โค้งลง)

11.2 Gradient Descent — "เดินลงเขา"

เมื่อมีหลายตัวแปรและหาคำตอบ closed-form ไม่ได้ → ใช้ algorithm เดินทีละก้าว:

x(t+1) = x(t) - α × ∇f(x(t))
α = learning rate (ขนาดก้าว)
∇f = gradient (ทิศทางที่ f เพิ่มเร็วที่สุด) → เดินสวนทาง = ลดเร็วที่สุด
เชื่อมกับ Options

ใช้ Gradient Descent สำหรับ:
• Model Calibration: หา parameters ที่ทำให้ model price ≈ market price
• Volatility Surface Fitting: minimize ผลต่างระหว่าง model vol vs market vol

11.3 Lagrange Multipliers — Optimization ที่มี Constraints

หา min/max ของ f(x) ภายใต้เงื่อนไข g(x) = 0:

สร้าง Lagrangian: L(x, λ) = f(x) - λ × g(x)
แก้: ∂L/∂x = 0 และ ∂L/∂λ = 0 (= g(x) = 0)

λ = Lagrange multiplier = "ถ้าผ่อน constraint อีกนิด objective เปลี่ยนเท่าไหร่"
(คล้าย shadow price ใน LP!)
เชื่อมกับ Options — Markowitz Portfolio Optimization!

Minimize Portfolio Risk: σ²_p = wTΣw
Subject to: wTμ = target return, wT1 = 1

ใช้ Lagrange: L = wTΣw - λ₁(wTμ - r*) - λ₂(wT1 - 1)
→ หา Efficient Frontier (เส้นโค้งของ risk vs return ที่ดีที่สุด)

11.4 Convex Optimization

Convex problem: minimize f(x) ที่เป็น convex function, ภายใต้ convex constraints

ทำไม Convex สำคัญ?

• Convex → มี minimum เดียว → Gradient Descent จะหาเจอเสมอ
• Non-convex → มีหลาย local minimum → อาจติดอยู่ที่จุดที่ไม่ใช่ global minimum

ข่าวดี: Portfolio optimization (Markowitz) เป็น convex! → มีคำตอบเดียวที่ดีที่สุด

ข่าวร้าย: Calibration ของบาง model (เช่น Stochastic Volatility) เป็น non-convex → ต้องใช้เทคนิคพิเศษ

11.5 Quadratic Programming (QP)

Minimize ½xTQx + cTx
Subject to: Ax ≤ b
เชื่อมกับ Options

Mean-Variance Optimization ของ Markowitz เป็น QP พอดี!
Q = 2Σ (covariance matrix), c = 0 หรือ -μ
ใช้ QP solver ใน Python (cvxpy, scipy) แก้ได้ในเสี้ยววินาที
