การเดินทางที่ผ่านมา — และคำถามที่ค้างคา

เราเดินทางผ่าน 5 Part: ความสุ่ม (ราคาเดาทิศไม่ได้) → พอร์ต (วัดและกระจายความเสี่ยง) → ประสิทธิภาพตลาด (edge มีจริงแต่หายาก) → การตั้งราคา (hedge คือหัวใจ) → การวัด/พิสูจน์ (อย่าหลอกตัวเอง) คุณมีเครื่องมือครบชุดของ quant แล้ว

แต่คำถามที่ยั่วไว้ท้าย Part V ยังค้าง: ถ้าเครื่องมือทั้งหมดนี้ดีจริง ทำไม quant ส่วนใหญ่ — รวมถึงเจ้าของโนเบล — ยังเจ๊ง? Part นี้จะตอบ โดยมองทั้ง 5 ตำนานเป็นภาพเดียว

ความรู้ทั้งหมดในเล่มนี้ไม่ได้ทำให้คุณ "ชนะตลาด" — มันทำให้คุณ "เข้าใจว่าทำไมการชนะถึงยาก" และนั่นคือก้าวแรกที่แท้จริง

ภาพเดียว: 5 ตำนานคือบทสนทนาเดียวกัน

ทฤษฎีเหล่านี้ไม่ใช่หัวข้อแยกกัน — มันคือคำถามที่ส่งต่อกันเป็นทอด ๆ แต่ละทฤษฎีเกิดเพราะตอบช่องโหว่ (หรือหาเงินจากช่องโหว่) ของทฤษฎีก่อนหน้า:

🔗 สายโซ่ของความคิด

Random Walk (1900): "ราคาเดาทิศไม่ได้" → ถ้างั้นวัดความเสี่ยงยังไง?
↓
Mean-Variance / CAPM (1952–64): "วัดด้วย variance/covariance; เฉพาะความเสี่ยงระบบที่ได้ค่าตอบแทน" → แล้วราคาที่ 'ถูกต้อง' มาจากไหน ตลาดมันฉลาดจริงไหม?
↓
EMH (1970): "ราคาสะท้อนข้อมูลครบ เอาชนะยาก" → แต่ Grossman-Stiglitz: ต้องมี inefficiency เหลือ ไม่งั้นไม่มีใครหาข้อมูล → edge มีจริง
↓
Black-Scholes (1973): "ถ้า hedge ได้ ราคาอนุพันธ์ถูกบังคับโดย no-arbitrage" → แต่ vol คงที่ไม่จริง (smile) → ที่โมเดลพังคือที่หาเงิน
↓
Time Series / Backtest (1982–2014): "วัด vol/หา edge จากข้อมูลได้ แต่ต้องพิสูจน์ว่าไม่ใช่บังเอิญ" → ปิดวงกลับไปที่ random walk: ทุก edge คือ deviation จากความสุ่มที่ต้องพิสูจน์

🧵 เส้นด้ายร่วมที่ร้อยทั้งหมด

ทุกทฤษฎีในเล่มนี้พูดเรื่องเดียวกันจากคนละมุม: "ความไม่แน่นอนมีโครงสร้าง — และโครงสร้างนั้น price ได้ แต่ไม่เคยสมบูรณ์" · ทิศเดาไม่ได้แต่ vol เดาได้ · ความเสี่ยงเฉพาะตัวกระจายทิ้งได้แต่ความเสี่ยงระบบไม่ได้ · ตลาดเกือบ efficient แต่ไม่ 100% · โมเดลตั้งราคาเกือบถูกแต่มี smile · backtest เกือบจริงแต่อาจบังเอิญ — คำว่า "เกือบ" ทุกตัวคือที่ที่ quant ทำมาหากิน และที่ quant เจ๊ง

คำตอบ: ทำไม quant ส่วนใหญ่ยังเจ๊ง

เพราะทฤษฎีบอก "ความจริงโดยเฉลี่ย" แต่การเจ๊งเกิดที่ "หาง" — มี 6 นักฆ่าที่ปรากฏซ้ำในทุก Part และแต่ละตัวมี "ยาแก้" ที่เล่มนี้สอนไว้แล้ว:

นักฆ่าคืออะไร💊 ยาแก้ (จาก Part ไหน)
1. Estimation errorμ/Σ/half-life จากอดีต ผิดในอนาคต — optimizer ขยายความผิดshrinkage/constraint/1-N; ถ่อมตัวกับ input (II)
2. Limits to arbitrageรู้ว่าถูก แต่ถือไม่ไหวจนตลาดกลับ (funding/borrow)คุม leverage ตาม funding; เผื่อ horizon ยาวกว่าคาด (III)
3. Crowdingถือ trade เดียวกับคนอื่น → premium กลายเป็น tail ร่วมเฝ้า crowding metrics; ลด size เมื่อ trade ซ้ำคนอื่น (II/III)
4. Self-deceptionbacktest ปลอมจาก multiple testing/look-aheadDeflated Sharpe; holdout hygiene; point-in-time data (V)
5. Regime changeโหมดตลาดสลับ → ทุกอย่างที่ fit มา invalid พร้อมกันทดสอบหลาย regime; ใช้ filtered ไม่ใช่ smoothed (I/V)
6. Model error / fat tailsสมมติฐาน (normal, no jump) พังตอน crash พอดีสมมติว่าโมเดลผิดเสมอ; stress test หาง; เผื่อ jump (I/IV)
💀 รูปแบบการเจ๊งที่เป็นสากล

นักฆ่าส่วนใหญ่ โจมตีพร้อมกันที่หาง — LTCM เจอ estimation error + limits to arbitrage + crowding + fat tails วันเดียวกัน เพราะตอนวิกฤต correlation วิ่งเป็น 1, funding หาย, ทุกคนเทขายเหมือนกัน, และ normal distribution บอกว่า "เป็นไปไม่ได้" · ส่วน Self-deception (#4) ต่างออกไป — มันคือบาปก่อนเทรดที่ "เปิดประตู" ให้ตัวอื่นเข้า (ลงเงินหนักกับ edge ปลอม แล้วนักฆ่าที่เหลือมาเก็บ) นี่คือเหตุผลที่ "รู้ทฤษฎี" ไม่พอ — ต้องรู้ว่าทฤษฎีพังพร้อมกันเมื่อไร

🧠 มุมที่ quant ที่รอด มองต่างจาก quant ที่เจ๊ง

quant ที่เจ๊ง: หาโมเดลที่ "ถูกที่สุด" แล้วลงเงินหนักเมื่อมั่นใจ
quant ที่รอด: สมมติว่าทุกโมเดลผิด รู้ว่ามันผิดตรงไหน คุม size ให้รอดตอนมันผิดพร้อมกัน — เพราะหลักเดียวที่อยู่เหนือทุกทฤษฎีในเล่มนี้คือ Survival > Optimization: อยู่ในเกมให้นานพอที่ edge เล็ก ๆ จะทบต้น สำคัญกว่ากำไรสูงสุดในรอบเดียว

ประตูสู่เล่ม B — เรื่องที่ยังไม่ได้เล่า

เล่ม A สอนเรื่องเดียว: ความเสี่ยงของ "ราคา" — ราคาขึ้นลง, vol, correlation แต่ในโลกจริง เงินหายได้จากความเสี่ยงอีก 3 ชนิดที่เล่ม A ยังไม่แตะเลย:

🚪 3 เสาที่รออยู่ในเล่ม B

• Credit: จะเกิดอะไรเมื่อ "คู่สัญญาไม่จ่าย"? ราคาของความเสี่ยงผิดนัด (CDS, default models) — ความเสี่ยงที่ทฤษฎีในเล่ม A สมมติว่าไม่มี
• Microstructure: ทำไม คำสั่งของคุณเองถึงขยับราคา? ต้นทุนที่ซ่อนใน bid/ask, market impact, การแข่งกับคนที่เร็วกว่าเป็นมิลลิวินาที
• Risk theory: เมื่อความเสี่ยงหลายตัวรวมกันระเบิดพอร์ต — VaR/CVaR, coherent risk, การวัด tail ที่ Part VI เพิ่งบอกว่าฆ่าคนมากสุด

คำถามค้างที่เล่ม B จะตอบ: ถ้า edge ที่ดีที่สุดของคุณ "ถูกต้องทุกอย่าง" แต่ counterparty เจ๊ง, order คุณเองดันราคา, และ tail risk ที่วัดผิด — กำไรบนกระดาษจะเหลืออะไร?

ปิดเล่ม A — คุณเปลี่ยนไปแล้ว

สิ่งที่เปลี่ยนในหัวคุณ

ก่อนอ่านเล่มนี้ คุณอาจเห็นตลาดเป็นที่ "ทายว่าหุ้นจะขึ้นหรือลง" ตอนนี้คุณเห็น: ความสุ่มที่มีโครงสร้าง, ความเสี่ยงที่ price ได้, edge ที่เสื่อมสลาย, โมเดลที่รู้ว่าตัวเองผิดตรงไหน, และ backtest ที่ต้องระแวง — คุณไม่ได้มองราคา คุณมองโครงสร้างของความไม่แน่นอน นั่นคือสายตาของ quant

เดินต่อยังไง — challenge แรกของคุณ

หยิบ ★★★ สักตัว (แนะนำ cointegration) เขียนโค้ด backtest pairs จริง แล้วลองทำให้มัน "ผ่าน Deflated Sharpe" — คุณจะพบความจริงด้วยตัวเอง: กลยุทธ์ที่ดูสวยราว 90% จะตายทันทีที่คุณ deflate มัน และวันที่คุณทำใจยอมทิ้งมันได้ คือวันที่คุณเป็น quant จริง ๆ — ไม่ใช่วันที่คุณท่องสูตรครบ

จากนั้น: อ่านเล่ม B (เสาที่เหลือ), เก็บ ★★/★ ตามสายงาน, และติดนิสัยถาม 3 คำกับทุก "กลยุทธ์เด็ด" — ลองมากี่ครั้ง? · หลังหักต้นทุน/capacity เหลือไหม? · ถ้า regime สลับจะเป็นยังไง?

quant ที่ดีไม่ใช่คนที่รู้สูตรมากสุด — แต่คือคนที่ระแวงตัวเองเก่งสุด และอยู่ในเกมได้นานสุด ยินดีต้อนรับสู่วงการ 🎓
