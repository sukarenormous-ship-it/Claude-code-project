Glossary — คำศัพท์

คณิตศาสตร์สำหรับ Options | English-Thai Reference
เรียงตามหัวข้อ | ครอบคลุมบทที่ 1–16

A — เครื่องมือพื้นฐาน

อัตราผลตอบแทนReturn
การเปลี่ยนแปลงของมูลค่า: Simple return \(R = (S_1-S_0)/S_0\) หรือ Log return \(r = \ln(S_1/S_0)\)
→ บท 1, 3
ผลตอบแทนแบบ logLog Return
r = ln(S₁/S₀) — สมมาตร, บวกข้ามเวลาได้, เป็น Normal Distribution ได้
→ บท 3.6
มูลค่าปัจจุบันPresent Value (PV)
\(PV = FV \cdot e^{-rT}\) — มูลค่าวันนี้ของเงินอนาคต โดย discount ด้วย rate r
→ บท 3.7
ฟังก์ชัน maxmax() function
max(a,b) = ค่าที่มากกว่า — หัวใจของ options payoff: max(0, S−K)
→ บท 1.4
ความเท่าเทียมของ Put-CallPut-Call Parity (PCP)
\(C + Ke^{-rT} = P + S\) — ความสัมพันธ์ no-arbitrage ระหว่าง Call, Put, หุ้น, Bond
→ บท 2.2
ฟังก์ชันแบ่งช่วงPiecewise Function
ฟังก์ชันที่มีสูตรต่างกันในแต่ละช่วงของ input — ใช้แทน options strategy ทุกประเภท
→ บท 1.6
e (ฐานธรรมชาติ)Euler's number e ≈ 2.718
ฐานของดอกเบี้ยทบต้นแบบต่อเนื่อง — เป็น "ค่าคงที่" ที่พบทุกที่ใน finance
→ บท 3.4
ลอการิทึมธรรมชาติNatural Log (ln)
ln(x) = y ⟺ eʸ = x — inverse ของ eˣ; ใช้คำนวณ log return และใน d₁, d₂ ของ BS
→ บท 3.5

B — สถิติและความน่าจะเป็น

ค่าเฉลี่ยMean (μ)
ค่ากลางของข้อมูล: \(\mu = \sum x_i / n\) — ใช้เป็น drift ของ GBM
→ บท 4.2
ความแปรปรวนVariance (σ²)
\(\sigma^2 = E[(X-\mu)^2]\) — วัดการกระจาย; variance ∝ T (เพิ่มตามเวลา)
→ บท 4.3
ความผันผวนVolatility (σ)
σ = std ของ log returns — annualize ด้วย σ_annual = σ_daily × √252
→ บท 4.3
ความแปรปรวนร่วมCovariance
\(\text{Cov}(X,Y) = E[(X-\mu_X)(Y-\mu_Y)]\) — วัดทิศทางการเคลื่อนไหวร่วม
→ บท 4.5
สหสัมพันธ์Correlation (ρ)
\(\rho = \text{Cov}/(\sigma_X\sigma_Y) \in [-1,+1]\) — ยิ่งต่ำ diversification ยิ่งดี
→ บท 4.5
การแจกแจงปกติNormal Distribution
Bell curve N(μ,σ²) — BS สมมติว่า log returns เป็น Normal
→ บท 6.2
Z-score / คะแนนมาตรฐานZ-Score
\(Z = (x-\mu)/\sigma\) — แปลงข้อมูลเป็น standard units; ใช้ใน N(d₁), N(d₂)
→ บท 6.3
การแจกแจงลอกนอร์มอลLognormal Distribution
ln(S) ~ Normal → S ~ Lognormal — ราคาหุ้นไม่ติดลบ, เหมาะกับ BS
→ บท 6.4
หางอ้วนFat Tails / Leptokurtosis
ตลาดจริงมี extreme events บ่อยกว่า Normal คาด — ทำให้ OTM options แพงกว่า BS
→ บท 6.6
ทฤษฎีบทลิมิตกลางCentral Limit Theorem (CLT)
ค่าเฉลี่ยของตัวอย่างใหญ่ → Normal ไม่ว่า population จะมีรูปร่างใด — รองรับ Black-Scholes
→ บท 6.5

C — แคลคูลัส

อนุพันธ์Derivative
slope ณ จุด = อัตราการเปลี่ยนแปลงทันที: \(f'(x) = \lim_{h\to 0}[f(x+h)-f(x)]/h\)
→ บท 7.2
อนุพันธ์ย่อยPartial Derivative
∂f/∂x = rate of change กับ x โดย hold ตัวแปรอื่นคงที่ — Greeks ทุกตัวคือ partial derivative ของ C
→ บท 7.6
Delta (Δ)Delta
\(\Delta = \partial C/\partial S = N(d_1)\) — อัตราการเปลี่ยนราคา option ต่อการเปลี่ยน S 1 หน่วย
→ บท 7.7
Gamma (Γ)Gamma
\(\Gamma = \partial^2 C/\partial S^2 = \partial\Delta/\partial S\) — ความโค้งของ option; เป็นบวกเสมอ
→ บท 7.8
Theta (Θ)Theta / Time Decay
\(\Theta = -\partial C/\partial T\) — มูลค่าที่ลดตามเวลา (เป็นลบสำหรับ long option)
→ บท 7.6
Vega (ν)Vega
\(\nu = \partial C/\partial\sigma = S\sqrt{T}N'(d_1)\) — ความไวต่อการเปลี่ยน volatility
→ บท 7.6
อนุกรมเทย์เลอร์Taylor Series
ประมาณ ΔV ≈ Δ·ΔS + ½Γ(ΔS)² + Θ·Δt + ν·Δσ — ใช้ P&L attribution บน trading desk ทุกวัน
→ บท 7.12

D — Linear Algebra + Optimization

Matrix CovarianceCovariance Matrix (Σ)
Matrix ที่เก็บ variance บน diagonal และ covariance นอก diagonal — ต้อง Positive Semi-Definite
→ บท 8.2–8.3
ความแปรปรวนพอร์ตPortfolio Variance (wᵀΣw)
วัด risk รวมของพอร์ต — ยิ่ง correlation ต่ำ wᵀΣw ยิ่งเล็ก (diversification)
→ บท 8.3
ค่าเจาะจง / เวกเตอร์เจาะจงEigenvalue / Eigenvector
Av = λv — eigenvectors = ทิศทางหลักของข้อมูล (PCA), eigenvalues = variance ตามทิศนั้น
→ บท 8.5
OLS (กำลังสองน้อยสุด)Ordinary Least Squares
\(\hat{\beta} = (X^\top X)^{-1}X^\top y\) — minimize sum of squared residuals
→ บท 9.1
Beta (ตลาด)Market Beta (β)
\(\beta = \text{Cov}(r_\text{stock}, r_\text{mkt})/\text{Var}(r_\text{mkt})\) — systematic risk, slope ของ regression
→ บท 9.1
Lagrange MultiplierLagrange Multiplier (λ)
เทคนิค optimize f(x) ภายใต้ constraint g(x)=0 — λ = shadow price ของ constraint
→ บท 11.3
เงื่อนไข KKTKKT Conditions
Lagrange สำหรับ inequality constraints — ใช้ใน Markowitz long-only portfolio
→ บท 11.4

E — Time Series + Stochastic Calculus

EWMA (ค่าเฉลี่ยเคลื่อนที่แบบถ่วงน้ำหนัก)Exponentially Weighted Moving Average
\(\sigma^2_t = \lambda\sigma^2_{t-1} + (1-\lambda)r^2_{t-1}\) — λ=0.94 (RiskMetrics daily)
→ บท 12.4
GARCHGeneralized ARCH
\(\sigma^2_t = \omega + \alpha r^2_{t-1} + \beta\sigma^2_{t-1}\) — forecast vol พร้อม mean reversion
→ บท 12.5
Implied Volatility (IV)Implied Volatility
σ ที่ทำให้ BS(σ) = ราคาตลาด — solve ด้วย Newton-Raphson; ตลาด quote ใน IV
→ บท 13.2
Vol Smile / SkewVolatility Smile / Skew
IV ≠ ค่าเดียวกันทุก strike — หลักฐานว่า fat tails มีจริง และ BS ไม่ครอบคลุมทุกกรณี
→ บท 15.4
GBM (Geometric Brownian Motion)Geometric Brownian Motion
\(dS = \mu S\,dt + \sigma S\,dW\) — สมมติฐานของ Black-Scholes สำหรับการเคลื่อนที่ของราคา
→ บท 14.4
Ito's LemmaIto's Lemma
Chain rule สำหรับ stochastic processes — ใช้พิสูจน์ว่า ln(S) ~ Normal; รากฐานของ BS PDE
→ บท 14.5
Brownian Motion / Wiener ProcessBrownian Motion (W_t)
Random walk ต่อเนื่อง: dW = ε√dt, ε~N(0,1) — Var(W_T) = T (variance ∝ time)
→ บท 14.3

F — Black-Scholes + Monte Carlo

สูตร Black-ScholesBlack-Scholes Formula
\(C = S_0 N(d_1) - Ke^{-rT}N(d_2)\) — ราคา European Call ภายใต้สมมติ lognormal, constant σ
→ บท 15.1
N(d₁), N(d₂)Risk-Neutral Probabilities
N(d₂) = P(S_T > K | risk-neutral); N(d₁) = N(d₂) ปรับ Ito — ทั้งคู่เป็น CDF ของ Normal
→ บท 15.2b
Monte Carlo SimulationMonte Carlo
จำลอง S(T) หลาย paths → เฉลี่ย payoff → discount → ราคา option ใช้กับ exotic options
→ บท 16.1
Standard Error ของ MCStandard Error (SE)
\(\text{SE} = \sigma_\text{payoff}/\sqrt{N}\) — ลด SE 2 เท่า ต้องเพิ่ม paths 4 เท่า
→ บท 16.4b
Control VariatesControl Variates
ใช้ราคาที่รู้แน่ (vanilla BS) ปรับ MC estimate → ลด variance ได้ 70–90%
→ บท 16.4d
Antithetic VariatesAntithetic Variates
ใช้ (Z, −Z) คู่กัน — 2 paths ต่อการสุ่ม 1 ครั้ง ลด SE ได้โดยไม่เพิ่ม random draws
→ บท 16.4c
Risk-Neutral PricingRisk-Neutral Measure (Q)
ตั้งราคา option ราวกับว่าทุกคน risk-neutral — ใช้ p* = (e^{rΔt}−d)/(u−d) ใน binomial tree
→ บท 14.2
BS PDEBlack-Scholes Partial Differential Equation
\(\Theta + \frac{1}{2}\sigma^2 S^2\Gamma + rS\Delta - rV = 0\) — Theta + Gamma P&L = risk-free return
→ บท 14.6–14.7

G — Statistical Arbitrage Key Terms

CointegrationCointegration
สองซีรีส์ที่ non-stationary แต่ linear combination ของมัน stationary — เช่น P_A − β·P_B = ε ที่ mean-reverts Engle-Granger test: ADF บน residuals ε
→ SA Ch 5
Ornstein-Uhlenbeck (OU)OU Process
\(d\varepsilon = \kappa(\theta-\varepsilon)\,dt + \sigma\,dW\) — mean-reverting SDE; κ = speed, θ = mean, σ = vol ใช้เป็น model หลักของ spread ใน Stat Arb
→ SA Ch 3 | Math Part VI
ครึ่งชีวิตHalf-life
เวลาที่ spread กลับสู่ครึ่งหนึ่งของระยะห่างจาก mean: \(\text{HL} = \ln 2 / \kappa\) — ถ้า HL สั้น = mean reversion เร็ว = เทรดได้บ่อยกว่า
→ SA Ch 3.3
Spread / Hedge RatioSpread & Hedge Ratio β
Spread = P_A − β·P_B; Hedge Ratio β = จำนวน units ของ B ที่ต้องขาย/ซื้อต่อ 1 unit ของ A หา β ด้วย OLS regression
→ SA Ch 1, 4
VaR / CVaRValue at Risk / Conditional VaR
VaR(α%): loss ที่จะไม่เกินด้วยความน่าจะเป็น α% CVaR = E[loss | loss > VaR] — วัด tail risk ได้ดีกว่า VaR เพราะ average ไม่แค่ threshold
→ SA Ch 20.3 | Math Part II
Sharpe Ratio / Info RatioSharpe / Information Ratio
Sharpe = (μ−r_f)/σ — ผลตอบแทนส่วนเกินต่อความเสี่ยง 1 หน่วย; Information Ratio = α/σ_tracking — ใช้ประเมิน strategy quality
→ SA Ch 19
Regime / Regime-SwitchingRegime-Switching
ตลาดมีหลาย "สภาวะ" (regime) — Normal, Trending, Stressed — แต่ละ regime มี κ, σ ต่างกัน Hamilton Filter ตรวจ regime ด้วย Hidden Markov Model
→ SA Ch 9
ADF TestAugmented Dickey-Fuller Test
ทดสอบ stationarity: H₀ = unit root (non-stationary); ถ้า p-value < 0.05 = reject H₀ = series stationary = mean-reverting
→ SA Ch 5.2, 6.3 | Math Part VI
