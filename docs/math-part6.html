บทที่ 12: Time Series & Volatility Forecasting

อุปมา: นักพยากรณ์อากาศที่พยากรณ์ "ความแปรปรวน" ไม่ใช่ "อุณหภูมิ"

นักพยากรณ์อากาศไม่ได้แค่บอกว่า "พรุ่งนี้ร้อน/เย็น" — เขายังบอก "พรุ่งนี้ฝนฟ้าคะนองมาก" (ความแปรปรวนสูง)

เช่นเดียวกัน Volatility Forecasting ไม่ได้ทำนายว่าราคาจะขึ้นหรือลง แต่ทำนายว่า "ราคาจะผันผวนมากแค่ไหน"

ใน Options Trading: ซื้อ Straddle ก่อนตลาดผันผวน ขาย Straddle เมื่อตลาดเงียบ — ไม่จำเป็นต้องรู้ทิศทาง!

Volatility ไม่คงที่ — มันเปลี่ยนตลอดเวลา ถ้า forecast ได้ = ได้เปรียบในการเทรด Options

12.1 แนวคิด Time Series

ข้อมูลที่เรียงตามเวลา: ราคาหุ้นรายวัน, daily returns, implied volatility

  • Trend: ทิศทางระยะยาว (ขึ้น/ลง/นิ่ง)
  • Stationarity: สมบัติไม่เปลี่ยนตามเวลา (mean, variance คงที่)
สำคัญ: วิเคราะห์ Returns ไม่ใช่ราคา!

ราคาหุ้น = non-stationary (มี trend ขึ้นตลอด) แต่ returns = stationary (เฉลี่ย ≈ 0, variance ≈ คงที่)
ถ้าวิเคราะห์ราคาโดยตรง = เหมือนหาค่าเฉลี่ยส่วนสูงของเด็กที่กำลังโต — ค่าเฉลี่ยเปลี่ยนตลอด ไม่มีประโยชน์!

12.2 Autocorrelation — Volatility Clustering

อุปมา: ความนิยมของเพลง "เมื่อวานฮิต วันนี้มักยังฮิตอยู่"

Autocorrelation วัดว่า "ข้อมูลวันนี้สัมพันธ์กับข้อมูลเมื่อวานแค่ไหน?"

สำหรับ Returns: เกือบ 0 (ทิศทางพรุ่งนี้ทำนายไม่ได้จากวันนี้)
สำหรับ |Returns| หรือ Returns²: สูงมาก! — วันที่ผันผวนมักตามด้วยวันที่ผันผวน

$$ \rho(k) = \text{Corr}(r_t,\, r_{t-k}) $$
ข้อมูลAutocorrelationความหมาย
returns (rₜ)≈ 0ทำนายทิศทางไม่ได้ (Efficient Market)
|returns| หรือ r²ₜสูง! (~0.2-0.4)วันที่ผันผวนมากมักตามด้วยวันผันผวนมาก
ข่าวร้ายวันนี้ → Return² สูง → ตลาดกังวล → Return² พรุ่งนี้สูงด้วย → Volatility Clustering!
เชื่อมกับ Options

Volatility Clustering: ความผันผวนมักมาเป็น "กลุ่ม" — ช่วงที่ตลาดกลัว σ สูงนาน
นี่คือเหตุผลที่ GARCH model ทำงานได้ดี เพราะจำลอง clustering นี้

12.3 AR / MA / ARMA Models & Realized Volatility

อุปมา: "วันนี้ขึ้นกับเมื่อวาน" vs "วันนี้ขึ้นกับ shock เมื่อวาน"

AR (Autoregressive): วันนี้ขึ้นกับ ค่าเมื่อวาน — เหมือนโมเมนตัมของลูกตุ้ม: ถ้าเมื่อวานสูง วันนี้ก็มักสูงตาม (persistent) หรือดีดกลับสู่ค่าเฉลี่ย (mean-reversion)

MA (Moving Average): วันนี้ขึ้นกับ shock (เซอร์ไพรส์) เมื่อวาน — เหมือนเสียงสะท้อนของข่าว: ข่าวช็อกเมื่อวานยังดังก้องมาถึงวันนี้

ทั้งสองคือ "หน่วยความจำ" ของ time series แต่จำกันคนละอย่าง: AR จำ ค่า, MA จำ shock

AR(1) — Autoregressive order 1: ค่าวันนี้เป็นฟังก์ชันเชิงเส้นของค่าเมื่อวาน + shock ใหม่

$$ x_t = c + \phi\, x_{t-1} + \varepsilon_t $$

\(|\phi|<1\) → stationary + mean-reverting (\(\bar{x}=c/(1-\phi)\)); \(\phi\approx 1\) → persistent

φ บอกอะไร?

φ = 0.9 → ค่าเมื่อวานส่งต่อมา 90% ทุกวัน → series เคลื่อนช้า ต่อเนื่องยาว (เหมือน IV ที่ค่อยๆ ลดลงหลัง crash)

φ = 0.1 → ค่าเมื่อวานแทบไม่มีผล → series กระโดดไปมาเร็ว เกือบเป็น white noise

φ < 0 → ดีดสลับขึ้นลง (oscillation) — วันนี้สูง พรุ่งนี้มักต่ำ

MA(1) — Moving Average order 1: ค่าวันนี้เป็น shock วันนี้ + เศษของ shock เมื่อวาน

$$ x_t = \mu + \varepsilon_t + \theta\,\varepsilon_{t-1} $$

ARMA(1,1) — รวมทั้งสอง: วันนี้ขึ้นกับ ทั้ง ค่าเมื่อวาน และ shock เมื่อวาน

$$ x_t = c + \underbrace{\phi\,x_{t-1}}_{\text{AR}} + \varepsilon_t + \underbrace{\theta\,\varepsilon_{t-1}}_{\text{MA}} $$
Lineage: AR → ARCH → GARCH (วางบริบทให้บท 12.5)

เทคนิค AR/MA ข้างบนใช้กับ ระดับ (level) ของ series แต่ในการเงินเราสนใจ ความแปรปรวน (variance) มากกว่า — เลยเอาแนวคิดเดียวกันมาใช้กับ variance:

• ARCH = จำลอง variance วันนี้เป็น AR บน squared-returns เมื่อวาน (σ²ₜ ขึ้นกับ r²ₜ₋₁, r²ₜ₋₂, ...)
• GARCH = เพิ่ม MA term บน variance เมื่อวาน เข้าไป (σ²ₜ ขึ้นกับ σ²ₜ₋₁ ด้วย)

ดังนั้น GARCH(1,1) คือโครงสร้าง ARMA(1,1) บน variance นั่นเอง! — α×r²ₜ₋₁ คือ "AR/ARCH part" และ β×σ²ₜ₋₁ คือ "MA/persistence part" นี่คือเหตุผลที่ GARCH (บท 12.5) จับ volatility clustering ได้

Realized Volatility (RV) — วัด vol จริงจากข้อมูล intraday:

แทนที่จะใช้ โมเดล ทำนาย σ เราวัด σ ที่ เกิดขึ้นจริง ภายในวัน จาก return ย่อยๆ (เช่น ทุก 5 นาที) แล้วรวมกำลังสอง

$$ RV = \sqrt{\sum_i r_i^2} \quad\text{(intraday intervals, model-free)} $$
ตัวอย่าง: Realized Volatility จาก 4 intraday returns

โจทย์: วันหนึ่งมี intraday returns 4 ช่วง: +0.5%, −0.3%, +0.4%, −0.6%

ขั้น 1 — ยกกำลังสองแต่ละตัว:
(0.005)² = 0.000025
(−0.003)² = 0.000009
(0.004)² = 0.000016
(−0.006)² = 0.000036

ขั้น 2 — รวม: Σrᵢ² = 0.000025 + 0.000009 + 0.000016 + 0.000036 = 0.000086

ขั้น 3 — RV รายวัน: RV = √0.000086 ≈ 0.0093 = 0.93%/วัน

ขั้น 4 — annualize ×√252: 0.93% × √252 ≈ 0.93% × 15.87 ≈ 14.8%/ปี

สำคัญ: RV เป็น model-free estimate ของ vol ที่เกิดขึ้น แล้ว (backward-looking, ใช้ข้อมูลจริง ไม่ต้องสมมติโมเดล) ส่วน GARCH เป็น forecast ของ vol วันพรุ่งนี้ (forward-looking) — เทรดเดอร์มักเทียบ RV (จริง) กับ IV (ตลาดคาด) และ GARCH (โมเดลคาด) เพื่อหา edge

โจทย์: Realized Volatility

วันหนึ่งมี intraday returns 3 ช่วง: −0.8%, +0.6%, +0.4%

คำนวณ RV รายวัน แล้ว annualize ด้วย √252 — ได้ vol รายปีเท่าไหร่?

ดูเฉลย

ยกกำลังสอง: (−0.008)²=0.000064, (0.006)²=0.000036, (0.004)²=0.000016

Σrᵢ² = 0.000064 + 0.000036 + 0.000016 = 0.000116

RV รายวัน = √0.000116 ≈ 0.01077 = 1.08%/วัน

Annualize: 1.08% × √252 ≈ 1.08% × 15.87 ≈ 17.1%/ปี

RV นี้เป็นค่า "ที่เกิดขึ้นจริง" (model-free) — ถ้าสูงกว่า IV ที่ตลาดให้ แปลว่าตลาดอาจ underprice vol

12.4 Moving Average & EWMA

อุปมา: คะแนนความนิยมแบบ "ใหม่กว่า = น้ำหนักมากกว่า"

Simple MA ให้น้ำหนักเท่ากันทุกวัน เหมือนนับคะแนนโหวตทุกคนเท่ากัน

EWMA ให้น้ำหนักวันล่าสุดมากกว่า เหมือน "คะแนนใหม่สำคัญกว่าคะแนนเก่า"

λ=0.94 หมายความว่า: ข้อมูล 1 เดือนที่แล้วมีน้ำหนักเหลือ (0.94)^20 ≈ 29% เท่านั้น

Simple MA Volatility: σ = std(returns ใน window n วัน)

$$ \sigma^2_\text{SMA} = \frac{1}{n}\sum_{i=1}^n r^2_{t-i} \quad(\mu\approx 0) $$

EWMA (Exponentially Weighted): ให้น้ำหนักข้อมูลล่าสุดมากกว่า

$$ \sigma^2_t = \lambda\,\sigma^2_{t-1} + (1-\lambda)\,r^2_{t-1} \qquad \lambda=0.94\text{ (RiskMetrics)} $$
ทำไม EWMA ถึงเขียนแบบนี้?

Expand ออกมา: σ²ₜ = (1-λ)[r²ₜ₋₁ + λr²ₜ₋₂ + λ²r²ₜ₋₃ + ...] = weighted average ของ r² ทั้งหมด

น้ำหนักของวันที่ k วันก่อน = (1-λ)λᵏ → ลดลง exponentially → วันเก่าๆ มีผลน้อยมาก

ข้อดีสำคัญ: Update ง่ายมาก! ต้องจำแค่ σ² เมื่อวาน + r เมื่อวาน

1โจทย์: λ=0.94, σ²ₜ₋₁ = 0.0025 (σ=5%), r_{t-1} = -3% = -0.03

2r²ₜ₋₁ = (-0.03)² = 0.0009

3σ²ₜ = 0.94 × 0.0025 + 0.06 × 0.0009

4= 0.002350 + 0.000054 = 0.002404

5σₜ = √0.002404 ≈ 4.90% ลดลงนิดเดียวจาก 5% เพราะ r²=0.09% < σ²=0.25%

EWMA (λ=0.94) reacts faster to volatility spikes than SMA-10

12.5 GARCH Model

อุปมา: นักพยากรณ์ที่จำ "ข่าวเมื่อวาน" + "ความแปรปรวนสะสม"

GARCH บอกว่า volatility วันนี้ขึ้นกับ 2 ปัจจัย:

1. ข่าวเมื่อวาน (r²ₜ₋₁): ถ้าตลาดร่วงแรงเมื่อวาน → ความกังวลสูง

2. Volatility เมื่อวาน (σ²ₜ₋₁): Volatility มี "inertia" — สูงแล้วมักยังคงสูงอยู่

α + β < 1 → ในระยะยาว volatility กลับสู่ค่าเฉลี่ย ω/(1-α-β)

$$ \sigma^2_t = \omega + \alpha\,r^2_{t-1} + \beta\,\sigma^2_{t-1} \qquad \alpha+\beta<1 $$

\(\omega\) = baseline, \(\alpha\) = news impact, \(\beta\) = persistence; long-run \(\sigma = \sqrt{\omega/(1-\alpha-\beta)}\)

ω (baseline) + α × r²ₜ₋₁ (ข่าว) + β × σ²ₜ₋₁ (inertia) = σ²ₜ (forecast)

1GARCH(1,1) ตัวอย่าง: ω=0.000002, α=0.10, β=0.85

2r_{t-1} = -2% = -0.02, σ²_{t-1} = 0.0004 (σ=2%)

3r²_{t-1} = 0.0004

4σ²ₜ = 0.000002 + 0.10 × 0.0004 + 0.85 × 0.0004

5= 0.000002 + 0.000040 + 0.000340 = 0.000382

6σₜ = √0.000382 ≈ 1.95% (ลดลงจาก 2% เล็กน้อย เพราะ r² = σ² พอดี)

7Long-run σ = √(ω/(1-α-β)) = √(0.000002/0.05) = √0.00004 = 0.63%/วัน ≈ 10%/ปี

เชื่อมกับ Options

• Forecast σ → เทียบกับ Implied Volatility (IV) ของตลาด
• ถ้า GARCH forecast < IV → options "แพงเกินไป" → อาจ sell options
• ถ้า GARCH forecast > IV → options "ถูกเกินไป" → อาจ buy options
• BS สมมติ σ คงที่ ← ผิด! GARCH บอกว่า σ เปลี่ยนตลอดเวลา

Model Risk: GARCH ใช้ Historical — ไม่รู้จัก Regime Change

GARCH มีจุดอ่อนสำคัญในการใช้งานจริง:
• Regime shift: GARCH calibrate กับ low-vol period จะ underestimate vol ใน high-vol regime ใหม่ (เช่น COVID breakout ปี 2020)
• Overfitting ช่วงสงบ: α + β → 1 ใน calm markets → Integrated GARCH → ไม่มี mean reversion → forecast vol ไม่กลับ
• Asymmetry (Leverage Effect): basic GARCH ไม่จับ "ตลาดลงแล้ว vol ขึ้นมากกว่าตลาดขึ้น" — ต้องใช้ GJR-GARCH หรือ EGARCH
แนวทาง: monitor μ drift, refit monthly, ใช้ Markov-switching GARCH ถ้า regime ชัดเจน

12.6 Mean Reversion

อุปมา: ยางยืดที่ดึงกลับสู่จุดกึ่งกลาง

Volatility ไม่วิ่งไปเรื่อยๆ มีแรงดึงกลับสู่ค่าเฉลี่ยระยะยาว (long-run volatility)

เหมือนยางยืด: ยิ่งดึงออกห่าง แรงดึงกลับยิ่งแรง

กฎ: α + β < 1 → มี mean reversion; α + β = 1 → ไม่มี mean reversion (IGARCH — ไม่เสถียร)

เชื่อมกับ Options

• ถ้า IV สูงมาก (เช่น หลัง market crash) → มักจะลดลง → sell high IV
• Long-term σ ≈ √(ω/(1 - α - β)) จาก GARCH → ใช้เป็น "anchor" ว่า IV ควรอยู่แถวไหน

บทที่ 13: วิธีเชิงตัวเลข — IV Solver

อุปมา: หาคำตอบที่ "สมการปิด" ไม่มี

ถ้าตลาดบอกว่า Call มีราคา ฿7.50 แต่ Black-Scholes สูตรให้ราคาเป็น σ → หา σ ที่ทำให้ราคา = ฿7.50

ปัญหา: ไม่มีสูตร "ย้อนกลับ" Black-Scholes แบบ closed-form → ต้องลองแล้วปรับ

วิธีเชิงตัวเลข = "การลองแบบฉลาด" ที่ converge หาคำตอบได้เร็ว

บางสมการแก้แบบ closed-form ไม่ได้ — ต้องใช้คอมพิวเตอร์หาคำตอบ ตัวอย่างสำคัญที่สุด: หา Implied Volatility

13.1 Bisection Method — "เกมทายตัวเลข"

อุปมา: เกมทาย "สูงไป/ต่ำไป"

ถ้าเพื่อนคิดตัวเลข 1-100 ไว้ในใจ กลยุทธ์ที่ดีที่สุดคือเดา 50 ก่อน

ถ้า "สูงไป" → เดา 25 ถัดไป; ถ้า "ต่ำไป" → เดา 75
ทำซ้ำ → ทุกครั้งช่วยให้แคบลงครึ่งหนึ่ง → หาเจอใน 7 ครั้งเสมอ (log₂(100) ≈ 7)

ถ้ารู้ว่าคำตอบอยู่ระหว่าง a กับ b → ลอง midpoint → ดูว่าคำตอบอยู่ครึ่งซ้ายหรือขวา → แบ่งครึ่งอีก

1. เลือก \(a,b\) ที่ \(f(a)\cdot f(b) < 0\)

2. \(m = (a+b)/2\)

3. ถ้า \(f(m)\cdot f(a)<0\) → \(b=m\) มิฉะนั้น \(a=m\)

4. ทำซ้ำจนกว่า \(|b-a|<\varepsilon\)

รอบabm = (a+b)/2f(m) = BS(m)−฿7.5ช่วงใหม่
10.051.000.525+3.2 (สูงไป)[0.05, 0.525]
20.050.5250.288+0.8 (สูงไป)[0.05, 0.288]
30.050.2880.169-0.5 (ต่ำไป)[0.169, 0.288]
40.1690.2880.228+0.1 (สูงไป)[0.169, 0.228]
...→ converge ไปที่ σ ≈ 0.20 (IV = 20%)

13.2 Newton-Raphson Method — เร็วกว่า!

อุปมา: ลงเขาโดยใช้แผนที่ความลาดชัน ไม่ใช่แค่ลองผิดลองถูก

Bisection: ลองครั้งละครึ่ง — ช้า แต่แน่นอน

Newton-Raphson: ใช้ slope (derivative) ของฟังก์ชัน เพื่อ "คาด" ว่าคำตอบอยู่ตรงไหน

เหมือนลากเส้นสัมผัส (tangent) จากจุดที่อยู่ → เส้นสัมผัสตัดแกน x ที่ไหน → ลองจุดนั้น

$$ x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} $$
$$ \sigma_{n+1} = \sigma_n - \frac{C_\text{BS}(\sigma_n) - C_\text{mkt}}{\mathcal{V}(\sigma_n)} \quad\text{(IV solver, Vega = }\partial C/\partial\sigma\text{)} $$
ทำไม Vega ถึงเป็น derivative ที่ใช้?

Vega = ∂V/∂σ = อัตราการเปลี่ยนแปลงของราคา option ต่อการเปลี่ยน σ 1 หน่วย

Newton-Raphson ต้องการ f'(σ) = d(BS price)/dσ = Vega นั่นเอง!

ข้อดี: BS Vega มีสูตร closed-form → คำนวณเร็ว → Newton-Raphson converge ใน 3-5 รอบ!

1IV Solver: Market price = ฿7.50, S=100, K=100, T=0.25, r=5%

2เดาเริ่มต้น: σ₀ = 0.30 (30%)

3คำนวณ BS(0.30) = ฿8.20 (แพงเกินไป ฿0.70)

4Vega(0.30) = ฿20 (ราคาเปลี่ยน ฿20 ต่อการเปลี่ยน σ 1 หน่วย)

5σ₁ = 0.30 − (8.20 − 7.50)/20 = 0.30 − 0.035 = 0.265 (26.5%)

6BS(0.265) ≈ ฿7.52 → error เล็กมาก → 1 iteration อีกรอบ → σ ≈ 0.264 = IV 26.4%

เชื่อมกับ Options — IV Solver

Newton-Raphson ใช้ Vega เป็น derivative → converge ใน 3-5 รอบ!

13.3 Numerical Differentiation

ทำไมต้องคำนวณ derivative เชิงตัวเลข?

BS model มีสูตร closed-form สำหรับ Greeks แต่ model อื่นๆ (Local Vol, Stochastic Vol) ไม่มี

แนวคิด: Delta = "ถ้า S เพิ่ม h → V เพิ่มเท่าไหร่?" → หาร h → ได้ approximate derivative

$$ f'(x) \approx \frac{f(x+h) - f(x-h)}{2h} \quad\text{(central difference)} $$
เชื่อมกับ Options

คำนวณ Greeks จาก pricing model ที่ไม่มีสูตร closed-form:
Delta ≈ [V(S+h) - V(S-h)] / (2h)    ใช้ h = ฿0.01 หรือ ฿0.001
Gamma ≈ [V(S+h) - 2V(S) + V(S-h)] / h²    (second derivative)

บทที่ 14: Stochastic Processes & Ito's Lemma

อุปมา: ฝุ่นละอองในน้ำ — ราคาหุ้นก็เคลื่อนที่แบบสุ่มเช่นกัน

Robert Brown ค้นพบ "Brownian Motion" ในปี 1827 โดยมองกล้องจุลทรรศน์ดูละอองเรณูในน้ำ — มันเคลื่อนที่สุ่มตลอดเวลา

Einstein อธิบายในปี 1905 ว่าเกิดจากโมเลกุลน้ำชนทุกทิศทาง

Bachelier (1900) ใช้ Brownian Motion อธิบายราคาหุ้นเป็นคนแรก — ก่อน Einstein อีก!

บทนี้คือ "ยอดเขา" ของเล่ม — เข้าใจบทนี้ = เข้าใจที่มาของ Black-Scholes

14.1 Random Walk & Binomial Tree

Random Walk: ทุก step ราคาขึ้น (+1) หรือลง (-1) ด้วยโอกาส 50/50

Monte Carlo GBM paths — each run gives different S(T); average = option price

Binomial Tree: ราคาขึ้น u หรือลง d ในแต่ละ step

$$ u = e^{\sigma\sqrt{\Delta t}}, \quad d = e^{-\sigma\sqrt{\Delta t}} = 1/u, \quad p^* = \frac{e^{r\Delta t} - d}{u - d} $$
ทำไม u = e^(σ√Δt)?

ต้องการให้ u, d สอดคล้องกับ volatility σ ของหุ้น

เงื่อนไข: Variance ใน 1 step = σ²Δt → p(1-p)(u-d)² ≈ σ²Δt

การเลือก u=e^(σ√Δt) ทำให้เงื่อนไขนี้สอดคล้อง โดยประมาณ (to first order ใน Δt) — ไม่ใช่เป๊ะสำหรับ Δt จำกัด แต่ error เล็กลงเรื่อย ๆ เมื่อ Δt→0 และ u×d = 1 (recombining tree!) ทำให้ tree พับกลับได้ ลดจำนวน node

1Binomial ตัวอย่าง: S=100, K=100, σ=20%, r=5%, T=1ปี, n=1 step

2Δt=1, u=e^(0.2×1)=1.2214, d=1/u=0.8187

3p* = (e^(0.05×1)−0.8187)/(1.2214−0.8187) = (1.0513−0.8187)/0.4027 = 0.578

4S(u)=122.14, S(d)=81.87; Payoff Call: C(u)=max(22.14,0)=22.14, C(d)=0

5C = e^(-0.05×1) × [0.578×22.14 + 0.422×0] = 0.9512 × 12.80 = ฿12.18

เชื่อมกับ Options — Binomial Option Pricing

1. สร้าง tree ราคาหุ้น n steps
2. คำนวณ payoff ที่ปลาย tree (วันหมดอายุ)
3. ย้อนกลับทีละ step: V = e-rΔt × [p*×V(up) + (1-p*)×V(down)]
4. ค่าที่ node แรก = ราคา Option!
เมื่อ n → ∞ → converge สู่ Black-Scholes price

14.2 Risk-Neutral Pricing

อุปมา: ประกันภัย — ราคาไม่ขึ้นกับว่าคุณจะเกิดอุบัติเหตุหรือไม่

บริษัทประกัน define ราคากรมธรรม์จาก "expected payout" โดยไม่ต้องรู้ว่าคุณ "โชคดี" หรือ "โชคร้าย"

Risk-neutral pricing ทำแบบเดียวกัน: คำนวณ "expected option payoff" ในโลก risk-neutral

เหตุผลที่ใช้ได้: เราสามารถ replicate option payoff ด้วย stock + bond → ราคาต้อง = cost of replication

หลักการสำคัญที่สุดใน Derivatives Pricing

เราสามารถ price option ได้โดย ไม่ต้องรู้ว่าหุ้นจะขึ้นหรือลง!

ทำได้โดยใช้ "โลก risk-neutral" ที่สมมติว่า:
• ทุกสินทรัพย์มี expected return = risk-free rate (r)
• ใช้ probability p* (ไม่ใช่ real probability p)
• Option Price = e-rT × E*[Payoff]

ทำไมใช้ได้? — No-Arbitrage Argument

เพราะเราสามารถ replicate payoff ของ option ได้ด้วย stock + bond (hedging)
ดังนั้นราคาของ option ต้อง = ต้นทุนของ replicating portfolio
ต้นทุนนี้ ไม่ขึ้นกับว่าหุ้นจะขึ้นหรือลง → ไม่ต้องรู้ real probability!

14.3 Brownian Motion

Brownian Motion W(t) = continuous limit ของ random walk สมบัติ:

  • W(0) = 0 (เริ่มที่ 0)
  • Independent increments: W(t₂)−W(t₁) ไม่ขึ้นกับ W(t₁)−W(t₀)
  • W(t₂)−W(t₁) ~ Normal(0, t₂−t₁) → ยิ่งเวลานาน variance ยิ่งมาก (ไม่ใช่ standard deviation)
  • Continuous paths — ไม่กระโดด
ทำไม Variance ∝ t ไม่ใช่ Std ∝ t?

random walk n steps: แต่ละ step ±1 → หลัง n steps, std = √n (จาก CLT)

ถ้า 1 ปี = n steps, 1 วัน = 1 step → std(yearly) = √(252) × std(daily)

นี่คือเหตุผลที่เราคูณ σ ด้วย √T ไม่ใช่ T เมื่อ scale ตามเวลา!

14.4 Geometric Brownian Motion (GBM)

อุปมา: เรือในทะเลคลื่น

ราคาหุ้น = เรือที่ลอยในทะเล:

• Drift (μdt) = กระแสน้ำ: ดันเรือไปทิศหนึ่งอย่างสม่ำเสมอ

• Volatility (σdW) = คลื่น: สุ่มขึ้นลง ยิ่งคลื่นแรง (σ สูง) เรือก็โคลงมาก

ทำไม "Geometric"? เพราะคลื่นใหญ่เล็กสัมพันธ์กับ ขนาดของเรือ — หุ้น ฿1000 ขยับ ฿20 ไม่เหมือนหุ้น ฿10 ขยับ ฿0.20

$$ \frac{dS}{S} = \mu\,dt + \sigma\,dW $$

อ่านว่า: "% การเปลี่ยนแปลงราคา = drift + สุ่ม"

  • μ dt = drift × เวลา → deterministic (คาดเดาได้)
  • σ dW = volatility × Brownian shock → stochastic (สุ่ม)
ทำไม Geometric? → ราคาเป็น Lognormal!

เพราะ dS/S (% change) เป็น normal ไม่ใช่ dS (absolute change)
→ ราคา S เป็น Lognormal (เชื่อมกับบท 6.4!) → ราคา > 0 เสมอ — ไม่สามารถติดลบได้!

14.5 Ito's Lemma — "Chain Rule ของโลกสุ่ม"

Chain Rule ธรรมดา vs Ito's Lemma — ต่างกันอะไร?

Chain Rule ปกติ: ถ้า V = V(S,t) และ S เปลี่ยนไป dS → dV = (∂V/∂t)dt + (∂V/∂S)dS

แต่ในโลกสุ่ม: S ขยับแบบ Brownian Motion → dS มีความ "ผันผวน" ในตัวเอง

ผลลัพธ์: (dS)² ≠ 0 แต่ = σ²S²dt → ต้องบวก "ค่าแก้" ½Γ(dS)² เพิ่มเข้าไป!

ถ้า S เป็น stochastic process และ V(S,t) เป็นฟังก์ชันของ S:

$$ dV = \frac{\partial V}{\partial t}\,dt + \frac{\partial V}{\partial S}\,dS + \frac{1}{2}\frac{\partial^2 V}{\partial S^2}(dS)^2 $$
dS/S = μdt + σdW → (dW)² = dt → (dS)² = σ²S²dt → ไม่ตัดทิ้งได้! → บวก ½Γσ²S²dt
ทำไมมี term ½(∂²V/∂S²)(dS)² พิเศษ?

ในโลกปกติ (dt)² ≈ 0 ตัดทิ้งได้ แต่ในโลกสุ่ม (dW)² = dt ≠ 0!
ดังนั้น (dS)² = (μSdt + σSdW)² ≈ σ²S²dt (เอา dt² และ dt×dW ออก เพราะเล็กกว่า dt)
นี่คือเหตุผลว่าทำไม Gamma สำคัญ — มันเป็น "ค่าแก้" ที่โลกสุ่มบังคับให้ใส่

1ตัวอย่าง Ito: หา d(ln S) เมื่อ dS/S = μdt + σdW

2ตั้ง V = ln(S), ∂V/∂t = 0, ∂V/∂S = 1/S, ∂²V/∂S² = -1/S²

3dV = 0·dt + (1/S)dS + ½(-1/S²)(dS)²

4= (1/S)(μSdt + σSdW) + ½(-1/S²)(σ²S²dt)

5= μdt + σdW − ½σ²dt = (μ − ½σ²)dt + σdW

6นี่คือ "log return ของ GBM" → Normal distribution → S เป็น Lognormal!

14.6 การพิสูจน์ Black-Scholes PDE (5 ขั้น)

อุปมา: สร้าง portfolio ที่ "ไร้ความเสี่ยง" → ต้องโตเท่า risk-free rate

ลองสร้างกระเป๋าลงทุนจาก option + หุ้น ในสัดส่วนที่ "หักล้าง" ความผันผวนของกันและกันออกหมด → กลายเป็น portfolio ที่ ไร้ความเสี่ยง (ไม่ว่าหุ้นขึ้นหรือลง ค่ามันก็เท่าเดิม)

เหตุ→ผล: ถ้าอะไรไร้ความเสี่ยง มันต้องให้ผลตอบแทนเท่ากับเงินฝากปลอดภัย (risk-free rate r) เป๊ะ — ไม่งั้นมี arbitrage! (ถ้าโตเร็วกว่า r ก็กู้เงิน r มาซื้อฟรีๆ; ถ้าช้ากว่า r ก็ short มันแล้วเอาเงินไปฝาก)

เงื่อนไขนี้แหละบีบให้ราคา option ต้องเป็นค่าใดค่าหนึ่งเท่านั้น → ออกมาเป็น PDE

เราจะ พิสูจน์ PDE ทีละขั้น โดยใช้ Ito's Lemma (บท 14.5) + no-arbitrage:

1สร้าง portfolio: long 1 option (มูลค่า V) + short Δ หุ้น (มูลค่า Δ·S)

\(\Pi = V - \Delta\cdot S\)

เป้าหมาย: เลือก Δ ให้ portfolio นี้ไร้ความเสี่ยง

2หา dΠ ด้วย Ito's Lemma: จากบท 14.5, dV ของ V(S,t) คือ

$$ dV = \left(\frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2\frac{\partial^2 V}{\partial S^2}\right)dt + \frac{\partial V}{\partial S}\,dS $$

(term dt มารวมจาก ∂V/∂t กับ Ito-correction ½σ²S²∂²V/∂S² ส่วน dS คูณ ∂V/∂S) ดังนั้น

$$ d\Pi = dV - \Delta\,dS = \left(\frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2\frac{\partial^2 V}{\partial S^2}\right)dt + \left(\frac{\partial V}{\partial S} - \Delta\right)dS $$

3กำจัด randomness: ตัว random ทั้งหมดอยู่ใน dS (เพราะ dS = μS·dt + σS·dW มี dW สุ่ม) เลือก

\(\Delta = \partial V/\partial S\) (Delta hedge)

→ term (∂V/∂S − Δ)dS = 0 → dS หายไปทั้งหมด! เหลือแต่ส่วน deterministic:

$$ d\Pi = \left(\frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2\frac{\partial^2 V}{\partial S^2}\right)dt $$

ตอนนี้ dΠ ไม่มี dW แล้ว → portfolio ไร้ความเสี่ยง ในช่วงเวลา dt

4No-arbitrage: portfolio ที่ไร้ความเสี่ยง ต้อง โตด้วยอัตรา r เท่านั้น คือ dΠ = r·Π·dt จับสองฝั่งของ dΠ มาเท่ากัน (และแทน Π = V − Δ·S = V − S·∂V/∂S):

$$ \left(\frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2\frac{\partial^2 V}{\partial S^2}\right)dt = r\!\left(V - S\frac{\partial V}{\partial S}\right)dt $$

5จัดรูป: หาร dt ทิ้ง แล้วย้ายทุก term มาฝั่งซ้าย → ได้ Black-Scholes PDE:

$$ \frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2\frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0 $$
แก่นของการพิสูจน์: Delta Hedging กำจัด Randomness

หัวใจอยู่ที่ ขั้น 3: เลือก Δ = ∂V/∂S ทำให้ตัวสุ่ม (dS / dW) หายไปหมด → portfolio ไร้ความเสี่ยง

ผลที่ตามมาน่าทึ่ง: PDE ที่ได้ ไม่มี μ (drift จริงของหุ้น) เลย! ราคา option ถูกบังคับโดย no-arbitrage ล้วนๆ — ไม่สนว่าหุ้นจะ "มีแนวโน้มขึ้น" แค่ไหน

นี่คือเหตุผลที่ risk-neutral pricing (บท 14.2) ใช้ได้: ในเมื่อ μ หายไป เราจะแทน μ ด้วยอะไรก็ได้ที่สะดวก — เลยเลือก μ = r (โลก risk-neutral) แล้วราคาที่ได้ก็ยังถูกต้อง

PDE นี้ไม่มี μ — มีแค่ r และ σ

สังเกตว่าตัวแปรในสมการมีแค่ r (risk-free rate) และ σ (volatility) — ไม่มี μ (expected return จริงของหุ้น)

PDE เพียงอย่างเดียวยังบอกราคา option ไม่ได้ ต้องใส่ boundary / terminal condition ด้วย สำหรับ European Call:
V(S, T) = max(0, S − K)   (payoff ตอนหมดอายุ)

แก้ PDE ตัวนี้พร้อม condition นี้ → จะได้ สูตร Black-Scholes (จะประกอบเต็มๆ ใน Part 7)

โจทย์: Terminal Condition + ระบุ Greek ของแต่ละ term

(ก) European Call มี strike K = ฿100 ตอนหมดอายุ ถ้า S = ฿120 payoff เท่าไหร่? ถ้า S = ฿80 ล่ะ? — ตรงกับ V(S,T) = max(0, S−K) ไหม?
(ข) ใน PDE: ∂V/∂t + ½σ²S²·∂²V/∂S² + rS·∂V/∂S − rV = 0 — term ไหนคือ "Theta" และ term ไหนเกี่ยวกับ "Gamma"?

ดูเฉลย

(ก) S=฿120: max(0, 120−100) = ฿20 (in-the-money, ใช้สิทธิ์ซื้อที่ 100 ขายที่ 120)
S=฿80: max(0, 80−100) = max(0, −20) = ฿0 (out-of-the-money, ไม่ใช้สิทธิ์)
ทั้งคู่ตรงกับ V(S,T) = max(0, S−K) เป๊ะ ✓

(ข) • ∂V/∂t = Theta (Θ) — อัตราการเปลี่ยนของราคาตามเวลา (time decay)
• ½σ²S²·∂²V/∂S² → ∂²V/∂S² คือ Gamma (Γ) ดังนั้น term นี้คือ ½σ²S²×Gamma (convexity)
• rS·∂V/∂S → ∂V/∂S คือ Delta (Δ); −rV คือ discounting

14.7 Black-Scholes PDE — ตีความเป็น Greeks

ที่มาของ BS PDE — Hedging Argument

สร้าง portfolio: Long 1 option + Short Δ หุ้น → portfolio นี้ "ไม่มีความเสี่ยง" (delta neutral)

Portfolio ไม่มีความเสี่ยง → ต้องได้ผลตอบแทน = risk-free rate (ไม่งั้นมี arbitrage!)

นำหลักการนี้ + Ito's Lemma → ได้ PDE ที่ทุก option ต้องสอดคล้อง

ใช้ Ito's Lemma + hedging argument → ได้สมการ:

$$ \frac{\partial V}{\partial t} + \tfrac{1}{2}\sigma^2 S^2\frac{\partial^2 V}{\partial S^2} + rS\frac{\partial V}{\partial S} - rV = 0 $$

แต่ละ term คือ Greek:

TermGreekความหมาย
∂V/∂tTheta (Θ)Time decay — ราคา option ลดตามเวลา
½σ²S²(∂²V/∂S²)½σ²S² × Gamma (Γ)Convexity benefit จาก volatility
rS(∂V/∂S)rS × Delta (Δ)Cost of carry ของหุ้นที่ hedge
-rV—Discounting — ต้นทุนการถือ option
Greeks Balance! Theta vs Gamma Trade-off

Θ + ½σ²S²Γ + rSΔ = rV

หมายความว่า: Time decay (Theta) ถูก offset ด้วย Convexity gain (Gamma term)
สำหรับ Long Option: Theta เป็นลบ (จ่าย time decay) แต่ Gamma term เป็นบวก (ได้ convexity benefit)
ไม่มี "free lunch" — ได้ Gamma ต้องจ่าย Theta

1ตรวจสอบ BS PDE: Call ATM, S=K=100, σ=20%, r=5%, T=0.5ปี

2คำนวณ d₁=(0.035)/(0.2×√0.5)=0.247; Greek จริง: Delta=N(d₁)≈0.60, Gamma≈0.027/฿, Theta≈-฿8.1/ปี, V≈฿6.89

3Theta term: −8.1

4Gamma term: ½ × 0.04 × 10000 × 0.027 = ½ × 10.8 = +5.4

5rSΔ term: 0.05 × 100 × 0.60 = +3.0

6rV: 0.05 × 6.89 = 0.34

7LHS = −8.1 + 5.4 + 3.0 = +0.30 ≈ rV = 0.34 ✓ (ใกล้มาก ต่างกันเพราะปัดทศนิยม)

σ₀ = 0.25 (25%), BS(0.25) = ฿5.80, Vega(0.25) = ฿25

คำนวณ σ₁ ด้วย Newton-Raphson แล้วตรวจว่าเข้าใกล้ IV ไหม?

ดูเฉลย

f(σ₀) = BS(0.25) − Market = 5.80 − 5.00 = +0.80 (model แพงกว่า market)

f'(σ₀) = Vega = 25

σ₁ = σ₀ − f(σ₀)/f'(σ₀) = 0.25 − 0.80/25 = 0.25 − 0.032 = 0.218 (21.8%)

σ ลดลง (สมเหตุสมผล: model แพงเกินไป → ต้องลด σ เพื่อลดราคา model)

ทำ iteration ต่อไป → σ converge ที่ประมาณ 21-22% = IV จริง

โจทย์ 3: Ito's Lemma — หา dV

กำหนด V = S² (portfolio value proportional to S squared)
ราคาหุ้น: dS = μS dt + σS dW    (GBM)

ใช้ Ito's Lemma หา dV — มี term พิเศษอะไรเพิ่มมาบ้าง?

ดูเฉลย

V = S², ∂V/∂t = 0, ∂V/∂S = 2S, ∂²V/∂S² = 2

Ito's Lemma: dV = 0·dt + 2S·dS + ½·2·(dS)²

(dS)² = (μSdt + σSdW)² ≈ σ²S²dt (ตัด dt² และ dt·dW ทิ้ง)

dV = 2S(μSdt + σSdW) + σ²S²dt

= (2μS² + σ²S²)dt + 2σS²dW

= S²(2μ + σ²)dt + 2σS²dW

Term พิเศษที่เพิ่มมา: +σ²S²dt (จาก Ito correction) — ไม่มีใน chain rule ธรรมดา!
