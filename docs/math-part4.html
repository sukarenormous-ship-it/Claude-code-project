เพราะความเสี่ยงของพอร์ตไม่ใช่แค่ "เฉลี่ยความเสี่ยงของแต่ละตัว" — มันขึ้นกับว่าสองตัวนี้เคลื่อนไหวไปด้วยกันแค่ไหน (covariance) ด้วย ถ้าไม่ค่อยไปด้วยกัน เวลาตัวหนึ่งร่วง อีกตัวช่วยพยุง → ความเสี่ยงรวมหดลง · นี่คือ "ของฟรีมื้อเดียวในการเงิน" ที่ Markowitz เรียกว่า diversification และเครื่องมือที่คำนวณมันคือ พีชคณิตเชิงเส้น (Linear Algebra)

ความเสี่ยงของพอร์ตไม่ได้อยู่ที่แต่ละตัว แต่อยู่ที่ "ตัวไหนล้มพร้อมตัวไหน" — และเมทริกซ์คือปากกาที่เขียนความสัมพันธ์นั้นทั้งหมดในหน้าเดียว

บทที่ 1: Linear Algebra — คณิตของหลายตัวแปรพร้อมกัน

พอร์ตมีหุ้น 50 ตัว จัดการทีละตัวไม่ไหว (คู่ความสัมพันธ์มีตั้ง 1,225 คู่!) เราจึงมัดทุกอย่างเป็น vector และ matrix แล้วคำนวณทีเดียว

1.1 Vector และ Dot Product = ผลตอบแทนพอร์ต

🚶 อ่านเป็นภาษาคนก่อน: vector ก็แค่ "รายการตัวเลขเรียงกัน" เช่นสัดส่วนพอร์ต · dot product (·) คือ "จับคู่คูณกันแล้วบวก" ซึ่งบังเอิญ = weighted average = ผลตอบแทนพอร์ตพอดี

w = [0.3, 0.5, 0.2] ← สัดส่วน 3 หุ้น (30/50/20%) r = [0.05, −0.02, 0.08] ← ผลตอบแทนแต่ละหุ้น w · r = 0.3(0.05) + 0.5(−0.02) + 0.2(0.08) = 0.021 = 2.1%
เชื่อมกับ Options

พอร์ต Options ก็เป็น vector: ถือ Call K=100 จำนวน 2, Put K=95 จำนวน −1 (short) · Position = [2, −1], Delta = [0.6, −0.4] → Portfolio Delta = 2(0.6) + (−1)(−0.4) = 1.6 (dot product เดียวกัน)

1.2 Matrix และ Covariance Matrix

🚶 อ่านเป็นภาษาคนก่อน: matrix คือ "ตารางตัวเลข" · ตารางที่สำคัญสุดคือ Covariance Matrix (Σ) — ช่องแนวทแยงเก็บความเสี่ยงของแต่ละตัว (variance) ช่องนอกแนวทแยงเก็บ "คู่ไหนไปด้วยกันแค่ไหน" (covariance)

Correlation Matrix ของหุ้น 3 ตัว: A B C A [ 1.0 0.7 0.2 ] ← A กับ B ไปด้วยกันสูง (0.7) B [ 0.7 1.0 0.3 ] C [ 0.2 0.3 1.0 ] ← แนวทแยง = ตัวเองกับตัวเอง = 1
🔬 เจาะลึก (ข้ามได้) — คูณเมทริกซ์ทีละช่องยังไง

คูณ matrix กับ vector: จับ "แถว" ของ matrix ดอทกับ vector ทีละแถว

[1 2] [5] [1·5 + 2·6] [17] [3 4] [6] = [3·5 + 4·6] = [39]

เงื่อนไขขนาด: A(m×n) × B(n×p) — คอลัมน์ของ A ต้องเท่าแถวของ B

1.3 Portfolio Variance — wᵀΣw

Portfolio Variance Markowitz 1952 ★★★ ต้องรู้จัก

🎯 Thesis

"ความเสี่ยงของพอร์ตทั้งก้อน = ผลรวมของ (สัดส่วนคู่หนึ่ง × ความเสี่ยงร่วมของคู่นั้น) ทุกคู่ — เขียนย่อเป็นสูตรเดียวว่า σ²ₚ = wᵀΣw"

🚶 อ่านเป็นภาษาคนก่อน: อย่าเพิ่งกลัวสัญลักษณ์ wᵀΣw มันแค่แปลว่า "ไล่ทุกคู่ (i, j) เอาน้ำหนักสองตัวคูณกับความเสี่ยงร่วมของคู่นั้น แล้วบวกให้หมด" · คู่ที่เป็นตัวเดียวกัน (i=i) ให้ variance ของตัวเอง · คู่ต่างตัว (i≠j) ให้ covariance — ยิ่ง covariance ต่ำ/ลบ ยิ่งดึงความเสี่ยงรวมลง

σ²ₚ = wᵀ Σ w = Σᵢ Σⱼ wᵢ wⱼ Covᵢⱼ w = vector น้ำหนัก · Σ = covariance matrix
🧮 เดินเลขจริง — หุ้น 2 ตัว w = [0.6, 0.4]

Σ = [ 0.04 0.01 ; 0.01 0.09 ] (σ₁²=0.04 คือ σ₁=20% · σ₂²=0.09 คือ σ₂=30% · Cov=0.01)

σ²ₚ = 0.6²(0.04) + 2(0.6)(0.4)(0.01) + 0.4²(0.09) = 0.0144 + 0.0048 + 0.0144 = 0.0336 σₚ = √0.0336 = 18.3%

💎 เฉลย hook — Diversification

σ₁ = 20%, σ₂ = 30% แต่พอร์ต σ = 18.3% ต่ำกว่าทั้งคู่ เพราะ covariance ต่ำ (0.01) · เทอมกลาง 2w₁w₂Cov เล็ก ทำให้ผลรวมไม่พุ่ง · ถ้าสองหุ้นสวนทางกัน (Cov ลบ) พอร์ตจะยิ่งนิ่งลงไปอีก — นี่คือ "ของฟรี" ที่เกิดจาก covariance ไม่ใช่จากการเดาทิศ

🧠 มุมที่มองต่าง

มือใหม่เห็น: "อยากพอร์ตเสี่ยงน้อย ก็เลือกแต่หุ้นเสี่ยงน้อย"
คนจัดพอร์ตเห็น: หุ้นเสี่ยงสูงตัวหนึ่งที่ "สวนทาง" กับพอร์ต อาจลดความเสี่ยงรวมได้มากกว่าหุ้นนิ่ง ๆ ที่ไปทางเดียวกับทุกตัว — ความเสี่ยงตัวเดี่ยวไม่สำคัญเท่า "มันเข้ากับพอร์ตยังไง"

✍️ ลองทำเอง

ถ้า Cov ระหว่างสองหุ้นเป็น 0 (ไม่สัมพันธ์กันเลย) แทน 0.01 · σ²ₚ และ σₚ จะเป็นเท่าไร? (w = [0.6, 0.4] เท่าเดิม)

ดูเฉลย

σ²ₚ = 0.0144 + 0 + 0.0144 = 0.0288 · σₚ = √0.0288 = 16.97% ≈ 17% — ยิ่งต่ำลงอีกเมื่อ Cov = 0 (ไม่มีความเสี่ยงร่วมเลย)

🐍 พอมีหลายหุ้น มือเริ่มไม่ไหว — ให้ matrix ทำแทน · 3 หุ้นมี 9 คู่, 10 หุ้นมี 100 คู่ · แต่ w @ Σ @ w ใน numpy คือบรรทัดเดียวไม่ว่ากี่ตัว · นี่คือเหตุผลที่ต้องรู้จัก matrix จริง ๆ:

🐍 Python — wᵀΣw พอร์ต 3 หุ้น (สร้าง Σ จาก σ + correlation)
import numpy as np

w  = np.array([0.5, 0.3, 0.2])           # น้ำหนัก 3 หุ้น (รวม = 1)
sd = np.array([0.20, 0.15, 0.30])        # σ ของแต่ละหุ้น
Corr = np.array([[1.0, 0.3, 0.2],        # เมทริกซ์ correlation
                 [0.3, 1.0, 0.5],
                 [0.2, 0.5, 1.0]])

Sig = np.outer(sd, sd) * Corr            # Σ = σᵢσⱼρᵢⱼ (covariance matrix)
var = w @ Sig @ w                        # ★ wᵀΣw — บรรทัดเดียว!
print(f"ความเสี่ยงพอร์ต = {np.sqrt(var)*100:.2f}%")   # ความเสี่ยงพอร์ต = 15.31%

# เทียบกับ "ถ้าไม่มี diversification" (เฉลี่ยถ่วงน้ำหนัก σ ตรง ๆ)
print(f"เฉลี่ยถ่วง σ    = {(w @ sd)*100:.2f}%")        # เฉลี่ยถ่วง σ    = 20.50%
✅ อ่านผลลัพธ์

พอร์ตเสี่ยงจริง 15.31% — ต่ำกว่า "เฉลี่ยถ่วง σ" (20.50%) ถึง 5 จุด · ส่วนต่างนี้คือ diversification ที่ covariance มอบให้ · ถ้าหุ้นทุกตัว correlation = 1 (ไปด้วยกันเป๊ะ) เลขสองอันจะเท่ากันเป๊ะ (ไม่มีของฟรี) · w @ Sig @ w ทำงานเหมือนกันหมดไม่ว่า 3 หรือ 300 หุ้น — นี่คือพลังของการเขียนเป็น matrix

🎯 3 อย่างที่ต้องจำ
  • wᵀΣw แค่ "ไล่ทุกคู่ เอาน้ำหนัก×ความเสี่ยงร่วม แล้วบวก"
  • ความเสี่ยงพอร์ตขึ้นกับ covariance ไม่ใช่แค่ σ ของแต่ละตัว
  • covariance ต่ำ/ลบ = diversification = ความเสี่ยงรวมหด

1.4 Eigenvalues และ PCA — "ทิศทางหลักของตลาด"

🚶 อ่านเป็นภาษาคนก่อน: ข้ามสัญลักษณ์ไปก่อนก็ได้ — ใจความคือ ในข้อมูลยุ่ง ๆ หลายมิติ มักมี "ทิศทางหลัก" ไม่กี่ทิศที่ข้อมูลชอบเคลื่อนไปด้วยกัน · eigenvector (v) = ทิศทางหลักนั้น · eigenvalue (λ) = ทิศนั้นสำคัญแค่ไหน (อธิบาย variance ได้กี่ %) · (คนอยากเห็นสมการ: Av = λv แปลว่าเมทริกซ์ A แค่ยืด v ให้ยาวขึ้น λ เท่า ไม่บิดทิศ)

🧮 ตัวอย่างจริง — PCA ของ yield curve

อัตราดอกเบี้ยมีหลายช่วงอายุ (3 เดือน, 1 ปี, ..., 30 ปี) ดูเหมือนหลายสิบตัวแปร · แต่ PCA (หา eigenvector ของ covariance matrix) พบว่า (ผลคลาสสิกของ Litterman-Scheinkman 1991) 3 ทิศทางหลักอธิบายการขยับได้เกือบ 99%:

  • PC1 = Level (~90%): ดอกเบี้ยทุกช่วงขึ้น/ลงพร้อมกัน
  • PC2 = Slope (~8%): สั้นกับยาวแยกทาง (ชัน/แบน)
  • PC3 = Curvature (~1%): กลางโค้งต่างจากปลาย

จากหลายสิบมิติ เหลือแค่ 3 ตัวเลขที่มีความหมาย → hedge ง่ายขึ้นมหาศาล

เชื่อมกับ Options

PCA ใช้ย่อ volatility surface (σ ของทุก strike × ทุกอายุ) ให้เหลือ factor ไม่กี่ตัว · eigenvalue ใหญ่ = ทิศสำคัญ · eigenvalue เล็ก = noise ตัดทิ้งได้

1.5 Positive Definite — ทำไม covariance matrix "ผิดเพี้ยน" ไม่ได้

🚶 อ่านเป็นภาษาคนก่อน: เพราะ σ²ₚ = wᵀΣw คือ variance ซึ่งติดลบไม่ได้ covariance matrix ที่ถูกต้องต้องให้ wᵀΣw ≥ 0 ทุกน้ำหนัก w (เรียกว่า positive semi-definite) · ถ้าคำนวณแล้วได้ค่าลบ = ข้อมูลมีข้อผิดพลาด (เช่น correlation ที่ประเมินมาไม่สอดคล้องกัน)

🎯 3 อย่างที่ต้องจำจากบทที่ 1
  • dot product = weighted average = ผลตอบแทน/Delta ของพอร์ต
  • wᵀΣw = ความเสี่ยงพอร์ตทั้งก้อนในสูตรเดียว
  • Eigenvalue/PCA = ย่อหลายมิติเหลือ "ทิศทางหลัก" ไม่กี่ตัว

บทที่ 2: Regression — หาเส้นที่ fit ข้อมูล → Beta & Hedge Ratio

Regression ตอบว่า "ความสัมพันธ์ระหว่างสองสิ่งเป็นเส้นตรงหน้าตายังไง" — ใช้หา Beta ของหุ้น, hedge ratio, และ fit volatility surface

2.1 Simple Linear Regression = Beta

Regression → Beta OLS ★★★ ต้องรู้จัก

🚶 อ่านเป็นภาษาคนก่อน: ลากเส้นตรงเส้นเดียวผ่านกลุ่มจุดข้อมูลให้ "ใกล้ทุกจุดที่สุด" (ระยะห่างยกกำลังสองรวมน้อยสุด = least squares) · ความชันของเส้นนั้น = β = "ตลาดขยับ 1 หน่วย หุ้นขยับกี่หน่วย"

y = α + βx β = Cov(X, Y) / Var(X) ← ความชัน α = ȳ − β·x̄ ← จุดตัดแกน y Least Squares: minimize Σ(yᵢ − α − βxᵢ)²
เชื่อมกับ Options
  • β (Beta) ของหุ้น = ความชัน regression ของ return หุ้น vs ตลาด · β = 1.5 → หุ้นเหวี่ยงกว่าตลาด 1.5 เท่า
  • Hedge Ratio = ความชัน regression ของราคา option vs หุ้นอ้างอิง ≈ Delta (เพื่อนเก่าจากเล่ม 1 Part III)
✍️ ลองทำเอง

หุ้นมี β = 1.5 · วันหนึ่งตลาดขึ้น +2% · ประมาณว่าหุ้นน่าจะขยับกี่ %? (ใช้ y ≈ βx)

ดูเฉลย

≈ 1.5 × 2% = +3% (โดยเฉลี่ย ไม่รวม α และ noise) — หุ้น high-beta เหวี่ยงแรงกว่าตลาด

2.2 Multiple Regression → Factor Models

🚶 อ่านเป็นภาษาคนก่อน: ถ้าผลตอบแทนหุ้นขึ้นกับหลายปัจจัย (ตลาด + ขนาดบริษัท + มูลค่า) ก็ใส่หลายตัวแปร · แก้ทีเดียวด้วย matrix (นี่คือที่ Linear Algebra บทที่ 1 กลับมาใช้)

y = β₀ + β₁x₁ + β₂x₂ + … + βₙxₙ + ε รูปเมทริกซ์: β = (XᵀX)⁻¹ Xᵀy
เชื่อมกับ Options

Factor Models: return หุ้น = β₁(ตลาด) + β₂(size) + β₃(value) + … → hedge ความเสี่ยงทีละ factor แทน hedge ทีละหุ้น (มีประสิทธิภาพกว่ามาก)

2.3 R² และ Overfitting

🚶 อ่านเป็นภาษาคนก่อน: R² บอกว่า "โมเดลอธิบาย variance ของข้อมูลได้กี่ %" (0–1) · แต่ R² สูงเกินไปจากโมเดลซับซ้อน = สัญญาณอันตราย overfitting

R²ความหมาย
0.95อธิบายได้ 95% — ดีมาก (แต่ระวัง overfit)
0.50อธิบายได้ 50% — พอใช้
0.10อธิบายได้ 10% — ปัจจัยอื่นสำคัญกว่า
❌ พังเมื่อไร — Overfitting

โมเดลซับซ้อนเกินไป "จำ noise" แทนที่จะ "เรียน pattern" → fit ข้อมูลเก่าเป๊ะ แต่ทำนายข้อมูลใหม่แย่ · กฎนิ้วโป้ง: ใช้โมเดลง่ายที่สุดที่อธิบายได้ดีพอ (Occam's Razor) · โยงกับเล่ม 1 Part IV: fit vol surface ก็เจอกับดักนี้

เชื่อมกับ Options — fit Volatility Surface

σ(K, T) ของทุก strike/อายุ fit ด้วย polynomial/nonlinear regression · แต่ degree สูงไป = overfit smile เก่า พลาด smile ใหม่

🎯 3 อย่างที่ต้องจำจากบทที่ 2
  • β = ความชัน regression = หุ้นขยับกี่เท่าของตลาด · hedge ratio ≈ Delta
  • Multiple regression + factor models = hedge ทีละปัจจัย
  • R² สูงไม่ได้แปลว่าดีเสมอ — ระวัง overfitting

🎓 รวมร่าง: วัดความเสี่ยงพอร์ต 3 หุ้นด้วยมือ

เอาทั้ง vector + covariance matrix + wᵀΣw มาใช้จริง

🧮 โจทย์

พอร์ต 2 หุ้น w = [0.5, 0.5] · σ₁ = 20%, σ₂ = 20% · ลอง 2 กรณี correlation: (ก) ρ = +1 (ไปด้วยกันเป๊ะ) · (ข) ρ = 0 (ไม่สัมพันธ์)

🧭 อ่านทีละขั้น

Cov = ρ·σ₁·σ₂ · กรณี (ก) Cov = 1×0.2×0.2 = 0.04 · กรณี (ข) Cov = 0

  • (ก) ρ = +1: σ²ₚ = 0.5²(0.04) + 2(0.5)(0.5)(0.04) + 0.5²(0.04) = 0.01+0.02+0.01 = 0.04 → σₚ = 20% (ไม่ลดเลย — สองตัวเหมือนกัน)
  • (ข) ρ = 0: σ²ₚ = 0.01 + 0 + 0.01 = 0.02 → σₚ = √0.02 = 14.1% (ลดจาก 20% เพราะ diversification)

บทเรียน: diversification ให้ผลก็ต่อเมื่อ correlation < 1 · ยิ่ง ρ ต่ำ ยิ่งลดเสี่ยงได้มาก

✍️ ลองทำเอง

กรณี (ค) ρ = −1 (สวนทางกันเป๊ะ), w = [0.5, 0.5], σ₁ = σ₂ = 20% · σₚ เป็นเท่าไร?

ดูเฉลย

Cov = −0.04 · σ²ₚ = 0.01 − 0.02 + 0.01 = 0 → σₚ = 0%! สองหุ้นที่สวนทางกันเป๊ะและน้ำหนักเท่ากัน หักล้างความเสี่ยงหมด (hedge สมบูรณ์ในทางทฤษฎี)

สรุป เล่ม 2 · A
  • Vector/dot product → ผลตอบแทน & Delta ของพอร์ต
  • wᵀΣw → ความเสี่ยงพอร์ตทั้งก้อน · covariance = หัวใจของ diversification
  • Eigenvalues/PCA → ย่อหลายมิติเหลือทิศทางหลัก
  • Regression → Beta & hedge ratio · ระวัง overfitting
เราวัดความเสี่ยงพอร์ตได้แล้ว — แต่จะ "เลือกน้ำหนัก w ที่ดีที่สุด" ได้ยังไง? เสี่ยงน้อยสุดสำหรับผลตอบแทนที่ต้องการ? คำตอบคือ Optimization ที่ เล่ม 2 · B จะเปิด
📖 ศัพท์ใหม่ในตอนนี้

Vector = รายการตัวเลข · Dot product = จับคู่คูณแล้วบวก · Matrix = ตารางตัวเลข · Covariance Matrix (Σ) = ตารางความเสี่ยงทุกคู่ · wᵀΣw = Portfolio Variance · Eigenvalue/Eigenvector = ทิศทางหลัก + ความสำคัญ · PCA = ย่อมิติด้วย eigenvalue · Regression/OLS = หาเส้น fit · Beta (β) = หุ้นขยับกี่เท่าตลาด · R² = โมเดลอธิบายได้กี่ % · Overfitting = จำ noise แทน pattern
