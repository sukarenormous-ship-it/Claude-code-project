3.1 Thesis — pair คือกรณีพิเศษ rank-1

Part I–II สอนโลก "ทีละคู่" — แต่ Part 0 ตั้งคำถามค้างไว้: ทำไมหุ้น 2 ตัวถึงเดินด้วยกัน? คำตอบไม่ใช่เวทมนตร์เฉพาะคู่ แต่คือ มันโหลด factor เดียวกัน

แนวคิดแกน

ผลตอบแทนหุ้นแต่ละตัว = ส่วนที่มาจาก common factor (market/sector/style ที่ทุกตัวในกลุ่มแชร์) + ส่วน idiosyncratic (เฉพาะตัวมันเอง)

r_i = β_i1·F_1 + β_i2·F_2 + ... + ε_i
└──── common factor ────┘ └─ residual ─┘

"spread" ที่เทรดได้จริง = ε_i (residual) — ส่วนที่ factor อธิบายไม่ได้

เมื่อคุณจับคู่หุ้น A กับ B แล้ว long-short — จริง ๆ คุณกำลังสร้าง factor-neutral portfolio 2 ตัวแบบหยาบ ๆ (หัก factor ร่วมของ 2 ตัวออกด้วยมือ) · PCA / eigenportfolio (Avellaneda-Lee 2010) ทำสิ่งเดียวกันแต่เป็นระบบทั้ง universe

"Pair trading คือ factor-neutral portfolio ที่มีแค่ 2 ตัว — ทำไมต้องหยุดที่ 2?"

3.2 หัก common factor — 3 วิธี (ง่าย → ซับซ้อน)

วิธี 1 — Sector/Market ETF hedge รายย่อยทำได้วันนี้

regress หุ้นบน sector ETF (หรือ SET50/ตลาด) → เทรด residual ที่เหลือ · ง่ายสุด ต้องการแค่ 1 regression

r_stock = α + β·r_ETF + ε → เทรด mean-reversion ของ ε

ในตลาดที่ factor structure ยัง under-modeled (ไทย/SEA) แค่หัก sector ETF ก็อาจพอ ← จุดที่รายย่อยได้เปรียบ

วิธี 2 — Statistical factors via PCA / eigenportfolio

ให้ข้อมูลหา factor เอง — PCA บน return ทั้ง universe → eigenvector ตัวแรก ๆ = "ตลาด" + "sector" โดยไม่ต้องตั้งชื่อ · residual = สิ่งที่เหลือหลังหัก PC หลัก ๆ (Avellaneda-Lee)

วิธี 3 — Fundamental factors

Fama-French / sector dummies / style factors — โยง theory-part2 เล่ม A (factor models) แทนเขียนซ้ำทฤษฎี

3.3 The s-score — แทน "เลือกคู่ + z-score"

🚶 อ่านเป็นภาษาคนก่อน

แทนที่จะถามว่า "คู่นี้ spread ห่างกี่ SD" (z-score) — เราถามทีละหุ้นว่า "residual ของหุ้นนี้ห่างจากค่าปกติกี่ SD" แล้วให้คะแนน (s-score) ทุกตัวในกระดาน · หุ้นที่ residual ต่ำผิดปกติ = ถูกไป → long · residual สูงผิดปกติ = แพงไป → short

idiosyncratic residual → โมเดลเป็น OU (mean-reverting)
s-score = (residual − mean) / std ← มาตรฐานเดียวเทียบได้ทุกตัว

s < −s_open → long · s > +s_open → short · |s| < s_close → ปิด
✅ ประเด็นสำคัญ (ตอบคำถามที่ค้างไว้: "cut-off จำเป็นไหม")

position = f(s-score) ข้ามทุกชื่อ → ไม่มีการ "เลือกคู่" เลย · แทน hard cut-off เลือก/ทิ้งแบบ binary → ใช้ soft ranking ทั้ง universe · cut-off ใน Part II จึงเป็น "baseline ที่ทุกคนรู้" ไม่ใช่หัวใจ

3.4 Cross-sectional mean reversion

พอมี s-score ทุกตัว → rank ทั้ง universe → long ก้นตาราง (residual ต่ำสุด) / short หัวตาราง (สูงสุด) · portfolio นี้ factor-neutral by construction เพราะเราหัก factor ไปแล้ว · และเป็น หลาย bet เล็ก ๆ แทนคู่เดียวลึก → กระจายความเสี่ยงดีกว่า (โยง edge map ชั้น A/D)

3.5 ★ ประเด็นทอง — common factor คือ "ความเสี่ยง"

📉 ทำไม pairs ไร้เดียงสาระเบิดตอนวิกฤต

ถ้าคุณไม่ neutralize factor ให้ดี — "pair/residual" ของคุณคือ factor bet ที่ปลอมตัวมา · คุณคิดว่าคุณ market-neutral แต่จริง ๆ แอบ long/short sector หรือ market อยู่ · ตลาดปกติมองไม่เห็น แต่พอวิกฤตมา factor เคลื่อนแรง — "spread" ที่ควรกลับ กลับพุ่งหนีเพราะมันคือ directional bet มาตลอด

"เข้าใจ common factor ไม่ได้ให้ edge — แต่มันกัน 'edge ปลอม': factor bet ที่คุณนึกว่าเป็น spread"
🔍 วิธีเช็คว่า residual "สะอาด" จริง

regress residual ของคุณกลับบน factor → loading ควร ≈ 0 · ถ้ายังมี loading เหลือ = ยังแบก factor exposure ซ่อนอยู่ = ยังไม่ neutral จริง

ε_ที่เราจะเทรด → regress บน [market, sector] → β ควร ≈ 0
ถ้า β ≠ 0 → ยังมี hidden factor bet → ยังไม่สะอาด
🧠 มุมที่ quant มองต่าง

คนทั่วไปเห็น: "spread พุ่งหนี = ซวย เจอ structural break"
quant เห็น: บ่อยครั้ง spread ไม่ได้ break — มันแค่เผยว่าคุณถือ factor bet มาตลอด และ factor เพิ่งเคลื่อน · ปัญหาไม่ได้อยู่ที่ตลาด อยู่ที่การ hedge ที่ไม่สะอาดตั้งแต่แรก

3.6 ชั้น DL/ML residual — รู้ไว้ + กับดัก (ไม่ใช่ชวนแข่ง)

frontier ของงานวิจัยคือเอา residual จาก factor model ไปป้อนโมเดล non-linear

Deep Learning Statistical Arbitrage (Guijarro-Ordóñez, Pelger, Zanotti)

ขั้นตอน: factor (PCA/IPCA) → arbitrage residual → CNN/transformer หา pattern ใน residual · เป็นงาน top-journal (Management Science) ที่เป็นตัวแทน "ชั้น B" ของแผนที่ Edge

❌ ซื่อสัตย์: ทำไมรายย่อยไม่ควรไล่แข่งชั้นนี้
  • แออัดสุด — กองใหญ่ทุ่มทรัพยากรตรงนี้
  • overfit หนัก — feature เยอะ พารามิเตอร์เยอะ backtest สวยแต่ live หด
  • สู้ compute/data ไม่ได้ · สอนเป็น "รู้ว่ามี + กับดัก" ไม่ใช่พระเอก

3.7 แล้ว retail edge อยู่ไหน (ต้องซื่อสัตย์)

⚠️ ความจริงที่ต้องยอมรับ

factor-residual stat arb ก็ crowded ในตลาด liquid — Avellaneda-Lee เองโชว์ว่า Sharpe เสื่อมลงหลังราว 2002 · แปลว่า ไม่มี edge เหลือใน วิธี selection ใด ๆ แล้ว — pairs · cointegration · copula · PCA · DL ตายเท่ากันหมดในบ่อใหญ่

✅ edge จริงย้ายไป (รายย่อยเล่นได้)
  • บ่อที่ factor ยัง under-modeled — Thai/SEA/crypto: คนยังไม่ได้ map factor structure ดี ๆ แค่หัก sector ETF ก็อาจพอ
  • cost/capacity/access (ชั้น D)
  • วินัย + regime (ชั้น C)
⚠️ ที่ไม่ควรไปแย่ง
  • PCA-residual บน US large-cap — กองใหญ่ครอง
  • DL signal — สู้ compute ไม่ได้
  • ไล่หา "วิธี selection ที่ดีกว่า" — มันตายหมดแล้ว
"เลิกถามว่าคู่ไหนสวย — ถามว่า residual อะไรที่เหลือหลังหักสิ่งที่ทุกคนถืออยู่แล้ว และใครยังไม่ได้หักมัน"

สรุป Part III + สะพานสู่ Part IV

✓ 3 อย่างที่ต้องจำจาก Part III
  1. pair = กรณีพิเศษ rank-1 — spread จริงคือ residual หลังหัก common factor; PCA ทำเป็นระบบทั้ง universe
  2. common factor = ความเสี่ยง — ไม่หักให้สะอาด = factor bet ปลอมตัว → เช็คด้วย regress residual กลับบน factor
  3. ไม่มี edge ในวิธี selection แล้ว — edge อยู่ที่บ่อ (factor under-modeled) + cost + วินัย ไม่ใช่โมเดล

ทั้ง β ของ pair (Part I) และ factor loading ของ residual (Part III) มีปัญหาเดียวกัน: มันเปลี่ยนตามเวลา · เราต้องการเครื่องมือที่อัปเดตมันแบบ real-time โดยไม่ look-ahead และไม่กระตุกตาม noise — นั่นคือ Kalman filter ที่ Part IV จะลงลึกจริง (จูน Q/R · รู้ว่า overfit ยังไง · β ควร random-walk ไหม)

"β เปลี่ยน · factor loading ก็เปลี่ยน — ใครจะอัปเดตมันให้ทันโดยไม่หลอกตัวเอง?"
📖 ศัพท์ใหม่ในตอนนี้
  • Common factor — ปัจจัยร่วม (market/sector/style) ที่ทำให้หุ้นหลายตัวเดินด้วยกัน
  • Idiosyncratic residual — ส่วนของผลตอบแทนที่ factor อธิบายไม่ได้ (ส่วนที่เทรด)
  • Eigenportfolio (PCA) — portfolio ตาม eigenvector ของ covariance = statistical factor
  • s-score — residual ที่ standardize แล้ว ใช้เป็นสัญญาณข้ามทั้ง universe
  • Factor-neutral — portfolio ที่ net exposure ต่อ common factor = 0
  • Factor bet ปลอมตัว — spread ที่แอบมี factor exposure เหลือ (ยังไม่ neutral จริง)
