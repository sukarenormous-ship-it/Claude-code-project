Drill Level 1: อ่าน Payoff (10 ข้อ)

✍️ ลองทำเอง
  1. แบน(−3) → slope+1 ที่ K=100 → คืออะไร? เฉลย: Long Call K=100, P=3
  2. slope−1 จากซ้าย → แบน(+4) ที่ K=95 → คืออะไร? เฉลย: Short Put K=95, P=4
  3. แบน(−5) → +1 ที่ 90 → −1 ที่ 110 → แบน(+15) → คืออะไร? เฉลย: Bull Call Spread 90/110
  4. V-shape จุดต่ำสุดที่ K=100 → คืออะไร? เฉลย: Long Straddle K=100
  5. ที่ราบสูง +2 ระหว่าง 90-110 ดิ่งลงสองข้าง → คืออะไร? เฉลย: Iron Condor

Drill Level 2: สร้าง Payoff จาก Belief (10 ข้อ)

✍️ ลองทำเอง
  1. "ขึ้นไม่จำกัด เสียจำกัด ฿8" เฉลย: Long Call P=8
  2. "ขึ้นจำกัด ฿20 เสียจำกัด ฿5" เฉลย: Bull Call Spread width=25, net=5
  3. "กำไรถ้าราคานิ่ง ขาดทุนถ้าเคลื่อนไหว" เฉลย: Short Straddle (⚠️ unlimited!)
  4. "กำไรที่จุด S=100 พอดี ไม่เสียเกิน ฿2" เฉลย: Butterfly K₂=100, net=2

Drill Level 3: Cross-Market Pricing (10 ข้อ)

✍️ ลองทำเอง
  1. PM "BTC>80K" = $0.72, Options implied = 65% → edge? เฉลย: 7% gap แต่ต้องเช็ค touch/close + fees
  2. Bookmaker odds 1.80 vs Options implied 60% → edge? เฉลย: 1/1.80=55.6% vs 60% → Options แพงกว่า 4.4%

Drill Level 4: Portfolio Analysis (10 ข้อ)

✍️ ลองทำเอง
  1. Long Call K=100 + Short Call K=110 + Long Put K=90 → วาด combined payoff → max loss?
  2. ถ้า portfolio มี delta=+200 gamma=−50 → ราคาขึ้น ฿5 → delta ใหม่ ≈ ? เฉลย: delta ≈ 200 + (−50×5) = −50 → พลิกจาก long เป็น short!

Drill Level 5: Reverse Engineering — 20★ Essential

ภารกิจ: ดู payoff ไม่มี label → ถอดให้หมด

แต่ละข้อ ต้องระบุ:

  • legs ทั้งหมด
  • strikes โดยประมาณ
  • credit/debit
  • market view

เฉลย: อยู่ต่อจากโจทย์แต่ละข้อทันที — พยายามตอบเองก่อนอ่านเฉลย

🧮 ตัวอย่าง RE Drill

กราฟ: แบนที่ −2 → ชัน+1 ที่ 95 → ชัน−2 ที่ 100 → ชัน+1 ที่ 105 → แบนที่ −2

คำตอบ:

  • legs: +Call 95, −2Call 100, +Call 105
  • strikes: K₁=95, K₂=100, K₃=105
  • credit/debit: Debit ฿2
  • market view: กำไรถ้าราคาจบที่ 100 พอดี = Long Butterfly

Quick Rules
  • PCP: C + Ke⁻ʳᵀ = P + S [Exact, European]
  • Phantom Arb: อย่าลืม PV(K)!
  • Net slope = 0 → bounded | ≠ 0 → unbounded
  • Covered Call = Short Put (same shape, diff by PV(K))
  • Butterfly ≥ 0 → convexity → ถ้า < 0 = arb
  • "รูปเดียว สูตรเดียว" → n kinks = n legs (minimal)
  • Payoff ≠ Prediction → ไม่มี probability → ต้องคำนวณ EV แยก

บทที่ 28: "Short Put DNA + แผนที่ ≠ ดินแดน"

เสียงจากสนาม — Senior Options Trader (20 ปี, $500M book)

"Every strategy — covered calls, iron condors, credit spreads — has short put DNA embedded in it. If you can't diagram a short put in your sleep, you have no business trading anything more complex."

แปล: ทุก strategy มี DNA ของ Short Put ซ่อนอยู่ — ถ้าวาด Short Put ไม่ได้หลับตา อย่าเทรดอะไรที่ซับซ้อนกว่านั้น

📉 XIV 2018 — "แผนที่สวย แต่ดินแดนมีหน้าผา"

5 กุมภาพันธ์ 2018: ผลิตภัณฑ์ XIV (Short VIX) เสียมูลค่า ~96% ภายในคืนเดียว แล้วถูก Credit Suisse ยกเลิก

Payoff chart ของ short vol strategies ดูสวย — "เก็บ premium ทุกเดือน กำไรบ่อย" แต่ chart ไม่แสดง: tail risk, gap risk, liquidity vanishing, correlation spike

"The payoff chart is the map, not the territory. The territory has cliffs the map doesn't print."

ถ้าวาด Short Put ไม่ได้หลับตา — อย่าเทรดอะไรที่ซับซ้อนกว่านั้น เพราะทุก strategy ในเล่มนี้มี DNA ของมันซ่อนอยู่ข้างใน
บทสรุปของเล่ม

Payoff Chart คือภาษาสากลของ Risk

ทุก financial product = payoff chart · ทุก payoff chart = ผลรวมของ building blocks · ทุก building block = สร้างได้หลายวิธีหลายตลาด

แต่จำไว้เสมอ:

  • Payoff ≠ Prediction — ไม่มี probability
  • Map ≠ Territory — มีหน้าผาที่แผนที่ไม่แสดง
  • ทุก strategy มี Short Put DNA — ถ้าไม่เข้าใจ Short Put อย่าไปต่อ

"ถ้าวาด payoff ได้ = เข้าใจ risk ได้ = ตัดสินใจได้"

📖 ศัพท์ใหม่ในตอนนี้

Net Slope (Tail Slope) = ความชันที่ปลายขวาสุดของกราฟ ใช้เช็ค bounded/unbounded · Short Put DNA = ทุก strategy ซับซ้อนมี risk profile คล้าย short put ซ่อนอยู่ · Map ≠ Territory = payoff chart (แผนที่) ไม่แสดงความเสี่ยงบางอย่างที่มีอยู่จริง (ดินแดน)
