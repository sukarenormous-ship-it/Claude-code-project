## 0. สรุปสั้น

1. กรณีศึกษา C1–C14 ยังเป็น "ทะเบียน" ไม่ใช่ "เรื่องเล่า": แต่ละชุดมีคำอธิบาย 1 บรรทัด สถานะหลักฐาน 1 บรรทัด และลิงก์ ส่วนแบบบันทึก 7 หัวข้อที่ประกาศว่าจะใช้กับทุกกรณียังไม่ได้กรอกเลยสักชุด
2. ในบท 0–10 ที่เขียนแล้ว **ไม่มีการเอ่ยรหัส C1–C14 เลย** (รหัสปรากฏเฉพาะในแผนบท) กรณีศึกษาเข้าสู่เนื้อหาผ่านการอ้าง R เท่านั้น แกนเรื่องจริงของบทที่เขียนแล้วคือกรณีสมมติ BTC spot–futures–perp ของผู้เขียน (บท 0–3, 6) และคู่จำลอง A/B (บท 7) ไม่ใช่ C1–C14
3. ชุดกรณีศึกษาเลือกไว้ตั้งแต่ฉบับ 0.5 ก่อนตัดสินใจ "ผู้อ่านมือใหม่ + ตลาดคริปโต" ในฉบับ 0.7 จึงหนักไปทางหุ้นสหรัฐ options และ optimization มีเพียง C8 ที่เป็นคริปโตโดยตรง
4. ระดับหลักฐานไม่มีชุดใดถึง L4 และไม่มีชุดใดรันโค้ดภายนอก (C9 "รัน" เฉพาะตัวเลขสมมติของผู้เขียนเอง) ชุดที่ลึกที่สุด (L2) คือชุดขั้นสูง C11–C14 ขณะที่ชุดที่เหมาะกับมือใหม่ที่สุด (C2, C8) อยู่แค่ L1
5. แหล่งอ้างอิง 48 รายการ: ผู้ตรวจฉบับ 0.6 เปิดตรวจจากเว็บได้เพียง 3 รายการ (R7, R9, R38) และพบชื่อเอกสาร R38 ผิด อีก 45 รายการยังค้างตรวจจนถึงฉบับ 0.9 ทั้งที่หัวส่วนอ้างอิงเขียนว่า "ตรวจแหล่งข้อมูลวันที่ 11 พฤศจิกายน 2026"
6. ถูกอ้างในเนื้อหาจริง 45/48 รายการ ไม่ถูกอ้างเลย 3 รายการ: R6, R9, R11 แหล่งเป็นภาษาอังกฤษทั้งหมด และเกี่ยวกับคริปโตโดยตรงเพียง R10 กับ R20
7. แม่แบบบทมีส่วนที่ดีมากสำหรับมือใหม่ (คำถามเปิด ตัวเลขเล็กคำนวณมือ "อ่านสมการ" "อ่านภาพด้วยกัน" โจทย์ 3 ชนิด เฉลยพร้อมเหตุผล หน้าทบทวน) แต่บังคับให้ทุกบทมีชั้นวิศวกรรมระบบ (5 กลไก, 6 เหตุออก, pause/resume, กระทบยอด fill, ระดับหลักฐาน) ซึ่งทำให้บทแข็งและซ้ำ และแม่แบบไม่ได้ปรับตั้งแต่ 0.5
8. ทิศทางการแก้ v0.6→v0.9 ชัด: จากตำราวิธีวิจัยไปสู่หนังสือมือใหม่ที่ใช้คริปโต แต่งานค้างหลายรายการถูกยกยอดทุกฉบับโดยไม่ปิด (ตรวจ 45 แหล่ง, ป้ายภาพภาษาไทย, แบบฝึกข้อมูลจริง, น้ำเสียง) และ "แบบฝึก spreadsheet" ที่สัญญาไว้ในฉบับ 0.7 หายจากรายการงานถัดไปของฉบับ 0.9 ทั้งที่ยังไม่มีในเล่ม

## 1. กรณีศึกษา C1–C14

### 1.1 ข้อสังเกตภาพรวม

- **รูปแบบ:** ย่อหน้าเปิดส่วน (บรรทัด 3026) บอกว่า "แต่ละกรณีจะบันทึกคำถามของผู้เขียน สมมติฐาน ข้อมูล วิธีสร้างสัญญาณ วิธีแปลงเป็นสถานะ และวิธีประเมินผล" แต่ทุกชุดในไฟล์หลักมีเพียงคำอธิบาย 1 บรรทัด + สถานะ + ลิงก์ ส่วน Source Plan v0.5 มีเพิ่มเพียงแกน 3 ข้อ (asset_selection / workflow / position_management) ข้อละ 1 บรรทัด และ `replication_note`
- **แบบบันทึก 7 หัวข้อ** (บรรทัด 3144–3152: Asset Selection, Workflow, Position Management, Signal และกฎหยุด, สถานะของระบบ, หลักฐาน, ข้อสรุป) ไม่ได้กรอกให้กรณีใด ตัวอย่างที่กรอกแล้วในเล่มมีเฉพาะกรณีของผู้เขียนเอง: บันทึก 5 หัวข้อของ BTC spot–futures ใน 01.01 (ตาม CHANGELOG 0.6) และทะเบียนคู่ใน 07.06 (ตาม CHANGELOG 0.9)
- **ไม่ปรากฏในบทที่เขียนแล้ว:** สคริปต์ค้นรหัส C1–C14 ในบรรทัด 1–3023 พบเฉพาะในแผนบท และในตาราง "ที่มาของบทในฉบับ 0.8" (C12) เนื้อหาบท 0–10 อ้างแหล่งของกรณีผ่านเลข R โดยไม่บอกผู้อ่านว่าเป็นกรณีใด
- **ตลาด:** C1, C2, C3, C10, C11 ใช้หุ้น; C9, C12 ใช้ options หุ้น/ดัชนี; C4–C7 เป็นวิธี optimization/ตะกร้า; มีเพียง C8 ที่อิงคริปโต (เครื่องมือ CME crypto basis + บทความ funding ของ Presto) Source Plan C5 กล่าวถึง "การเปลี่ยนเป็น Binance เป็น adaptation" แสดงว่าผู้เขียนคิดเรื่องดัดแปลงไปคริปโตไว้ตั้งแต่ต้น แต่ไม่ได้คัดชุดกรณีใหม่หลังตัดสินใจในฉบับ 0.7
- **หลักฐานที่ตรวจอิสระ:** สถานะในแต่ละชุดเป็นคำประกาศของผู้เขียน ผู้ตรวจฉบับ 0.6 ยืนยันจากเว็บได้เฉพาะ R7 (=C5), R9 (=C7), R38 (=C12)
- **ความลึกของหลักฐานกลับด้านกับความเหมาะกับมือใหม่:** C11–C14 (ขั้นสูง) ตรวจถึงระดับโค้ดบางส่วน แต่ C2 และ C8 (ใกล้มือใหม่ที่สุด) อยู่ระดับอ่านอย่างเดียว

- บทบาทเสนอ: แกนเรื่อง "ทำไมกลยุทธ์ถึงเสื่อม" คู่กับ C1

**C3 Factor และ PCA residual statistical arbitrage**
- เรื่อง: factor returns → residual process → mean-reversion signal → พอร์ตที่ hedge ปัจจัยร่วม
- แหล่ง: PDF Avellaneda–Lee (working paper ที่หน้าอนุสรณ์ NYU) + ArbitrageLab
- สถานะ: "อ่านงาน Avellaneda–Lee และตรวจแหล่ง implementation ที่เผยแพร่; ยังไม่มีผลทำซ้ำ"
- Source Plan: ArbitrageLab "เป็น implementation ของผู้อื่น ต้องเทียบกฎและเครื่องหมายกับต้นฉบับ รวมทั้งตรวจว่า residual หมายถึงระดับหรือผลตอบแทน"
- ใช้: R5 ถูกอ้าง 7 ครั้งใน 7 หัวข้อ (มากที่สุดในเล่ม) รวมกฎ s-score ±1.25 / ปิด +0.75 / −0.50 ใน 09.05
- มือใหม่: ต่ำ (PCA, regression, OU, หุ้นสหรัฐ)
- บทบาทเสนอ: เล่มต่อยอด ในเล่มมือใหม่อาจเหลือกล่อง "ดูกฎจริงจากงานวิจัย" ที่แสดงว่าเส้นเข้าออกไม่สมมาตรและมาจากการปรับเทียบ

**C4 Sparse mean-reverting portfolio selection**
- เรื่อง: แปลงความต้องการ mean reversion และจำนวนสินทรัพย์เป็น objective และ constraints
- แหล่ง: บทความ Hudson & Thames + ArbitrageLab
- สถานะ: "ตรวจว่าแหล่ง code มีอยู่; ยังไม่ได้รัน" (ไม่ถึงการตรวจโค้ด)
- Source Plan: จำนวนขาต้องประเมินร่วมกับสภาพคล่อง ต้นทุน และความเสถียร
- ใช้: ไม่ถูกอ้างในบทที่เขียนแล้ว (R6, R11 = 0) แผนบท 12
- มือใหม่: ต่ำ · บทบาท: ต่อยอด

**C5 Finding moving-band statistical arbitrages**
- เรื่อง: ออกแบบตะกร้าผ่าน objective และข้อจำกัดของกรอบราคา จุดกลางเคลื่อนตามเวลา

- สถานะ: "อ่านบทความและยืนยันแหล่ง repository แล้ว; ยังไม่ได้ทำซ้ำผลเชิงตัวเลข"
- Source Plan: ข้อมูลหุ้นในงานเดิมมีข้อจำกัดการเข้าถึง; "การเปลี่ยนเป็น Binance เป็น adaptation"
- ใช้: 05.04, 10.01 · แผนบท 9, 12
- มือใหม่: ต่ำ แม้ภาพ "กรอบที่เลื่อน" จะอธิบายด้วยกราฟได้ · บทบาท: ต่อยอด

**C6 Markowitz approach กับตะกร้า moving-band หลายชุด**

- สถานะ: "อ่านวิธีและยืนยันแหล่ง code แล้ว; ยังไม่ได้ยืนยันผลทำซ้ำ"
- Source Plan: ต้องตรวจนิยามความเสี่ยงและ neutrality ในต้นฉบับก่อนเขียนตาม
- ใช้: 05.04 (R8) · แผนบท 13–15
- มือใหม่: ต่ำ · บทบาท: ต่อยอด

**C7 Signal strength, decay และต้นทุนการปรับพอร์ต**
- เรื่อง: คุณภาพสัญญาณ horizon การรวมสัญญาณ และการปรับพอร์ตให้คุ้มต้นทุน
- แหล่ง: robot-wealth.github.io/stat-arb-book (4 หน้า; R9 ชี้เฉพาะหน้า intro)
- สถานะ: "อ่าน workflow และตรวจตัวอย่าง code บางส่วน; ยังไม่ได้รัน"
- Source Plan: "โค้ดเขียนด้วย R และมีจุดที่ต้องตรวจความตรงกันระหว่างคำอธิบายกับนิพจน์"
- ใช้: ไม่ถูกอ้าง (R9 = 0) · แผนบท 16, 18
- มือใหม่: แนวคิด no-trade buffer / "ปรับเมื่อคุ้มค่าธรรมเนียม" อธิบายได้ด้วยเลขคณิตและเกี่ยวกับ nature (ต้นทุนกินกำไร) แต่ส่วน optimization ต่ำ
- บทบาท: ยกแนวคิดเป็นกล่องในเล่มมือใหม่ ส่วนเต็มไปเล่มต่อยอด

**C8 Implied carry, funding และ basis**
- เรื่อง: ย้อนสมการหา implied rate แยกอัตราที่ plot, basis, funding cash flow และ P&L
- แหล่ง: CME Cryptocurrency BasisWatch and Implied Rate Tool (=R20); Presto Research "Optimizing Funding Fee Arbitrage" (=R10)
- สถานะ: "อ่านเอกสารและเครื่องมือที่เผยแพร่; ตัวเลขในบท 2 เป็นตัวอย่างสมมติ ไม่ใช่ผล backtest" — **ไม่ได้ปรับหลังเขียนบท 6 ในฉบับ 0.9** (ยังกล่าวถึงเฉพาะบท 2)
- Source Plan: "จะเขียนบัญชีและการทดลองจากสมมติฐานที่ระบุ พร้อมตรวจเอกสารสัญญาปัจจุบันก่อนใช้กติกา funding หรือหลักประกันจริง"
- ใช้: บท 1 (01.04), บท 2 (02.04), บท 6 ทั้งบท (06.02 อัตรา 12.17% → 9.73% ต่อทุน → 9.23% หลังค่าธรรมเนียม → 5.23% หลัง hurdle 4%; 06.04 ถือต่อ 550.75 เทียบค่าเสียโอกาส 821.92/410.96; 06.05 funding สี่เส้นทาง)
- มือใหม่: สูงที่สุด ผู้อ่านเห็น funding rate และราคา futures ในแอปอยู่แล้ว คำนวณด้วยเปอร์เซ็นต์ได้ทั้งหมด
- ตอบ 5 เป้าหมาย: understand (อัตราบนจอ ≠ ผลตอบแทนของทุน), think (ถือต่อหรือปิดเทียบ hurdle; กฎออกที่ช่วยเส้นทางหนึ่งทำร้ายอีกเส้นทาง), do (คำนวณผลตอบแทนต่อทุน ค่าธรรมเนียม เงินเติมหลักประกัน), extend (เหรียญอื่น exchange อื่น dated กับ perp), nature (รายรับเล็กสม่ำเสมอ ความเสี่ยงหางจาก exchange/stablecoin/การเรียกหลักประกัน funding กลับเครื่องหมาย)
- จุดอ่อน: แหล่งไม่มีเอกสารกติกาของ exchange คริปโตเลย (CME เป็นตลาด futures กำกับดูแล) และยังไม่มีข้อมูลจริง
- บทบาท: **แกนหลักของเล่มมือใหม่**

**C9 Exact synthetic: call–put–cash**
- เรื่อง: payoff เท่ากันไม่เท่ากับโอกาสกำไร: long call − put = S_T − K ต้องเติมเงินสดก่อนเทียบหุ้น
- แหล่ง: OIC Put/Call Parity (=R30)
- สถานะ: "อ่านเอกสาร OIC; รัน Decimal checks ของตัวอย่างสมมติ K=100, call=6, put=4, spot=102, r=0 และ terminal spot 80/100/120 แล้ว" — เป็นชุดเดียวที่มีคำว่า "รัน" แต่รันเลขของผู้เขียนเอง
- Source Plan: "ตัวอย่างให้มูลค่าเริ่มต้นและ payoff เท่ากัน จึงไม่ได้แสดง pricing arbitrage ที่มีกำไร"
- ใช้: 05.03 เป็นตัวอย่างหลักของบท 5 (กล่องเปิดบท 5 ระบุ "call 6 ลบ put 4 บวกเงินสด 100")
- มือใหม่: เลขง่าย แต่ผู้อ่านเป้าหมายไม่รู้จัก options การวางเป็นตัวอย่างหลักของบทในภาค 1 จึงเป็นภาระ
- บทบาท: ต่อยอด ส่วนบทเรียน "เหมือนกันตามสัญญา ≠ มีกำไรให้เก็บ" ย้ายไปสอนด้วย spot–futures ที่บรรจบตามสัญญาได้

**C10 Residual momentum**
- เรื่อง: ผลตอบแทนส่วนที่ factor อธิบายไม่ได้ใช้สร้างคะแนนไปต่อ (ไม่ใช่สวนทาง)
- แหล่ง: PDF Blitz–Huij–Martens (คลัง Erasmus) = R31; QuantConnect = R32
- สถานะ: "ตรวจ public project entry point แต่ยังไม่ได้ audit โค้ดแนบครบทั้งโครงการหรือรันภายนอก"
- Source Plan: survivorship, เว้นเดือนล่าสุด, ต้นทุน borrow; "การจัดอันดับ residual ไม่รับประกัน factor neutrality ของ holdings"
- ใช้: 05.07 · แผนบท 2, 5, 11
- มือใหม่: ต่ำ แต่บทเรียน "ไม่ใช่ทุกส่วนต่างจะกลับ" มีค่าต่อ nature · บทบาท: ต่อยอด (คงประโยคสั้นในเล่มมือใหม่)

**C11 Forecast → portfolio: Cvxportfolio และ Deep Statistical Arbitrage**
- เรื่อง: แยกเครื่องพยากรณ์จากการจัดพอร์ต; representation ที่เรียนรู้ต้องแปลงเป็น holdings

**ลำดับประจำบท 9 ข้อ**
1. คำถามเปิดบท (ปัญหาที่ผู้อ่านต้องตัดสินใจ)
2. สิ่งที่ควรรู้ก่อนอ่าน (พร้อมรหัสบทย้อนกลับ)
3. ภาพรวมของแนวคิด: เลือกตัวแปรที่จะ plot (ความหมาย หน่วย บทบาท เวลาใช้ข้อมูล) แล้วแยก payoff, forecast, hedge, construction, execution
4. ตัวอย่างตัวเลขทีละขั้น: เริ่มเลขเล็กคำนวณมือ เพิ่มความซับซ้อนทีละส่วน แยกตัวเลขสมมติจากผลตลาด/paper
5. สมการและคำอ่าน (สัญลักษณ์ หน่วย สมมติฐาน อ่านเป็นภาษาไทย)
6. จากโมเดลสู่การตัดสินใจ: แยก X, forecast, target holdings, ผลอนาคต; กฎออกตามสัญญาณ ขาดทุน เวลา โมเดล ทุน execution; pause/resume; กระทบยอด fill
7. กรณีศึกษาและทางเลือกเมื่อสมมติฐานไม่ผ่าน (หลักฐานหักล้าง หาต้นเหตุ ระบุระดับหลักฐาน 4 ระดับ)
8. ลองเปลี่ยนเงื่อนไข: อธิบาย คำนวณ ถ่ายโอน เสนอการทดลองหักล้าง; รวมกรณี forecast ผิด ราคา gap สัญญาณออกพร้อมกัน pause ที่ต้องไม่เปิดซ้ำ
9. หน้าทบทวน

ส่วนเพิ่ม: "ภาพที่สอนให้คิดตาม" (ภาพละหนึ่งคำถาม แกนและหน่วยชัด สีคงที่ บอกว่าข้อมูลสมมติหรือผลจริง) และ "การจัดหน้าและการทบทวน" (หน้าแบบฝึกแยกจากเฉลย)

### 3.2 ในไฟล์ Template v0.5

โครง: ชื่อบท → คำถามเปิด → "เมื่ออ่านจบ ผู้อ่านควร [อธิบาย] [คำนวณ] [ตัดสินใจ]" → พื้นฐานที่ควรรู้ → แนวคิดและตัวอย่าง (ตาราง A/B 100→102, 50→50.5; สมการ Π = 10(2) − 20(0.5) = 10; "อ่านสมการ") → ภาพและการอ่านภาพ ("อ่านภาพด้วยกัน": แกน หน่วย สิ่งที่เปลี่ยน สิ่งที่ภาพยังสรุปไม่ได้) → จากโมเดลสู่การตัดสินใจ (3 ช่อง) → กรณีศึกษาและข้อจำกัด (4 ช่อง รวมแผนจัดการสถานะค้าง) → **ข้อกำหนดของกลยุทธ์และระบบ** (ตาราง 7 แถว: กลไกและสถานะ · สัญญาณ · กฎเข้าและออก · เหตุที่พักหรือลด · คำสั่งและบัญชี · สิทธิ์เปิดใหม่ · หลักฐาน; บวกหมายเหตุ maker-only และต้นทุนรวม/ต้นทุนคงเหลือ) → แบบฝึกหัด 3 ข้อ (อธิบายด้วยคำตัวเอง / เปลี่ยนตัวเลข / ถ่ายโอน + หลักฐานหักล้าง) + เฉลยพร้อมเหตุผล → ทบทวนหนึ่งหน้า 6 ช่อง (คำถามหลัก, แนวคิด, สมการจำเป็น, จุดตรวจ, คำถามปิดหนังสือ 2–3 ข้อ, บทเชื่อมต่อ)

ความต่างจากไฟล์หลัก: ไฟล์ template มีส่วน "ข้อกำหนดของกลยุทธ์" แยก ส่วนไฟล์หลักไม่มีเป็นข้อของตัวเอง แต่มีข้อ 8 ที่เจาะจงกรณีปฏิบัติการมากกว่า ระดับหัวข้อในไฟล์ template ไม่สม่ำเสมอ ("ภาพและการอ่านภาพ", "ข้อกำหนด...", "แบบฝึกหัด...", "ทบทวน..." เป็น H2 เท่ากับหัวบท)

### 3.3 ส่วนขยายใน Source Plan (`ข้อกำหนดแม่แบบเพิ่มเติม`)

### 3.4 ข้อที่ดีสำหรับมือใหม่ (ควรเก็บ)

- คำถามเปิดบทที่ผูกกับการตัดสินใจของผู้อ่าน และเป้าหมาย "อธิบาย / คำนวณ / ตัดสินใจ" (ตรงกับ understand–do–think)
- "เริ่มจากตัวอย่างเล็กที่คำนวณมือได้ แล้วเพิ่มทีละส่วน พร้อมบอกว่าเราเรียนรู้อะไรเกินกว่าผลคำนวณ"
- "อ่านสมการ" เป็นภาษาไทยทุกสมการ และ "อ่านภาพด้วยกัน" ที่บอกสิ่งที่ภาพสรุปไม่ได้
- ภาพละหนึ่งคำถาม และบังคับบอกว่าเป็นข้อมูลสมมติหรือผลจริง
- โจทย์ 3 ชนิด (อธิบาย / เปลี่ยนตัวเลข / ถ่ายโอน) ตรงกับ understand–do–extend และเฉลยที่ให้เหตุผล หน่วย และจุดที่อาจพลาด
- หน้าทบทวนที่มีคำถามปิดหนังสือและข้อผิดพลาดที่ต้องจำ
- แยกตัวเลขสมมติที่รันตรวจแล้วออกจากผล paper ที่ยังไม่ได้ทำซ้ำ (ความซื่อตรงต่อผู้อ่าน)
- แนวคิด "ข้อกำหนดของกลยุทธ์ที่ให้ผู้อ่านอีกคนตัดสินใจจากข้อมูลเดียวกันได้" เป็นแบบฝึก do ที่ดี ถ้าลดศัพท์

### 3.5 ข้อที่ทำให้บทแข็งหรือเป็นตำรา

- **บังคับชั้นวิศวกรรมระบบในทุกบท:** ข้อ 3 (5 กลไก), ข้อ 6 (6 เหตุออก + pause/resume + กระทบยอด fill), ข้อ 7 (ระดับหลักฐาน), ข้อ 8 (forecast ผิด, gap, สัญญาณออกพร้อมกัน, pause ที่ต้องไม่เปิดซ้ำ) ทำให้ทุกบทวนเรื่องเดิมซ้ำ และวางเรื่องปฏิบัติการไว้ก่อนผู้อ่านจะเข้าใจกลไกกำไร
- **ศัพท์อังกฤษนอกแอปเทรดอยู่ในโครงเอง:** payoff, forecast, construction, execution, target holdings, horizon, fit, loss budget, partial/reject/timeout, inventory, reconciliation, maker-only queue ผู้อ่านตามนิยามรู้เพียงศัพท์ในแอป
- **โทนป้องกันตัว:** ทุกช่องเน้น "สิ่งที่ยังสรุปไม่ได้/หลักฐานหักล้าง/ข้อจำกัด" ถูกต้องเชิงวิชาการ แต่เมื่อทำซ้ำทุกย่อหน้าจะกลบความเข้าใจหลัก (ผู้เขียนรู้ปัญหานี้ จึงเพิ่ม "ข้อตกลงของเล่ม" ในฉบับ 0.7 เพื่อตัดข้อควรระวังซ้ำ แต่ CHANGELOG 0.7 บอกว่า "ฉบับนี้ยังไม่ได้ตัด")
- **ไม่มีช่องสำหรับ:** เรื่องเล่าหรือสถานการณ์ตัวละคร, การเปรียบเทียบเชิงสัญชาตญาณก่อนสูตร, ขั้นทำใน spreadsheet, กล่อง "ธรรมชาติของกลยุทธ์" (กำไรจากใคร รูปร่าง P&L ทำไมเสื่อม), กรอบคำถามตัดสินใจที่พกไปใช้ได้, "ข้อผิดพลาดที่มือใหม่ทำบ่อย" (มีแค่ในหน้าทบทวน), "เรียนอะไรต่อ"

## 6. ข้อเสนอสำหรับแผนเล่มใหม่

### 6.1 โครงกรณีศึกษา

1. **เลือกแกนเรื่องสองเส้น:** (ก) กรณีต่อเนื่อง BTC spot–dated futures–perp (C8 ขยาย) เป็นเส้นหลักตลอดเล่ม (ข) คู่เหรียญเชิงสถิติหนึ่งคู่ เล่าด้วยขั้นตอนของ C1 และจบด้วยบทเรียนการเสื่อมของ C2 กรณีอื่นย้ายไปเล่มต่อยอด
2. **เอ่ยชื่อกรณีในเนื้อหา:** ให้ผู้อ่านรู้ว่ากำลังเดินตามกรณีใด และกรอกแบบบันทึก (ฉบับย่อ ภาษาไทย) ให้กรณีแกนครบทุกช่อง ใช้ 01.01 และ 07.06 เป็นต้นแบบ
3. **ยกระดับหลักฐานของกรณีแกนก่อนตีพิมพ์:** อย่างน้อย L3 ด้วยข้อมูลจริง (ประวัติ funding และ basis จริงของ BTC, ราคาคู่เหรียญจริง) พร้อมบอกที่มาข้อมูล วันที่ และกติกาของ exchange ที่ใช้ แยกเป็น "ผลที่ทดลองเอง" ตามข้อตกลงข้อ 1
4. **ลดกรณีในบท 5:** บท 5 ปัจจุบันอ้าง 14 แหล่งขั้นสูงและใช้ options เป็นตัวอย่างหลัก ควรย้ายไปท้ายเล่มเป็น "แผนที่สำหรับต่อยอด" หรือไปเล่มต่อยอด โดยเก็บบทเรียน "payoff เท่ากัน ≠ กำไร" (สอนด้วย spot–futures) และตัวอย่าง win rate 65% ไว้ในเล่มมือใหม่

### 6.2 เป้าหมาย nature

5. **เพิ่ม "บัตรธรรมชาติกลยุทธ์" ประจำกรณีแกน** ช่องตายตัว: กำไรมาจากไหน · ใครอยู่อีกฝั่งและทำไมเขายอมจ่าย · รูปร่าง P&L (ชนะบ่อย/แพ้หนัก?) · กลไกที่ทำให้เสื่อมหรือตาย · ความเสี่ยงที่มองไม่เห็น · ข้อจำกัดทุนและสภาพคล่อง วัตถุดิบที่มีอยู่แล้ว: 01.04 (รับ +1 ที่ 99% เสีย 120 ที่ 1%; 01.04 ถาม "ใครอยู่อีกฝั่ง" ไว้แล้ว), 05.08 (win rate), 06.03/06.06 (basis, เงินสด, exchange, stablecoin), 06.05 (funding สี่เส้นทาง), 07.04 (selection bias), บท 10 (หลักฐานเสื่อม)
6. **เติมหัวข้อที่การค้นคำไม่พบในบท 0–10:** crowding/คนเข้ามาแย่งกำไร, capacity/ขนาดทุนที่กลยุทธ์รับได้, drawdown (ค้นด้วยคำสำคัญเท่านั้น อาจมีคำพ้องที่ไม่ได้นับ) อาจเพิ่มกรณีเหตุการณ์จริงที่กลยุทธ์ประเภทนี้ขาดทุนหนัก โดยต้องหาแหล่งที่ตรวจได้ก่อน

### 6.3 เป้าหมาย think / do / extend

7. **แบบฝึก spreadsheet เป็นข้อบังคับ:** สัญญาไว้ตั้งแต่ 0.7 แต่ยังไม่มีและหายจากรายการ 0.9 ทุกบทแกนควรมีไฟล์แบบฝึกพร้อมคอลัมน์ทีละขั้น โดยโค้ดเป็นเพียงทางตรวจ
8. **ใช้เกณฑ์ผ่าน 6 ข้อของบทนำร่องใน Source Plan เป็นมาตรฐาน "do"** และเพิ่ม "ดัชนีตามปัญหา" ตามแผนภาคผนวกเดิมเพื่อฝึก think
9. **เพิ่มเช็กลิสต์ "ดัดแปลงไปตลาด/คู่อื่น"** (ต่อยอดจาก 03.10 ย่อหน้าดัดแปลง tutorial และหลัก adaptation ของ Source Plan) และ "แผนที่เรียนต่อ" ที่ชี้ไปกรณีในเล่มต่อยอดพร้อมพื้นฐานที่ต้องมี

### 6.4 แม่แบบ

10. **เขียนแม่แบบมือใหม่ใหม่:** สถานการณ์/คำถาม → สัญชาตญาณ → ตัวเลขเล็กคำนวณมือ → ทำใน spreadsheet → ภาพ (อ่านภาพด้วยกัน) → บัตรธรรมชาติกลยุทธ์ → กรอบคำถามตัดสินใจ → ข้อผิดพลาดที่พบบ่อย → โจทย์ 3 ชนิด + เฉลยพร้อมเหตุผล → ทบทวน → ไปต่อที่ไหน ย้ายชั้นวิศวกรรมระบบ (5 กลไก, 6 เหตุออก, pause/resume, กระทบยอด fill, ระดับหลักฐาน) ไปไว้ที่บทข้อกำหนดกลยุทธ์บทเดียวหรือภาคผนวก แล้วให้บทอื่นอ้างกลับ ใช้ป้ายภาษาไทยในตารางข้อกำหนด และรวมกล่องเปิดบทกับ "ลงลึก" เข้าแม่แบบ

### 6.5 แหล่งอ้างอิงและงานค้าง

11. **ทำความสะอาดบัญชีอ้างอิง:** ตรวจ 45 รายการที่ค้าง; แก้ประโยค "ตรวจแหล่งข้อมูลวันที่ 11 พ.ย. 2026" และ R14 ให้ตรงสถานะจริง; เติมรายละเอียดบรรณานุกรม (ข้อ 2.3 ค); ตรึง commit/รุ่นของเอกสารที่เปลี่ยนได้; เพิ่มลิงก์กรณีที่ไม่อยู่ในบัญชี (ข้อ 2.4); เพิ่มเอกสารกติกาของ exchange คริปโตที่ใช้จริง; ติดป้ายระดับการอ่าน ("มือใหม่อ่านได้" / "เทคนิค") ให้แต่ละรายการ; ตัดหรือย้าย R ที่ใช้เฉพาะกรณีต่อยอดไปเล่มต่อยอด
12. **ปิดงานค้างก่อนขยายเนื้อหาใหม่:** ป้ายภาพภาษาไทย (รวมภาพ 4.2), น้ำเสียงบท 2, 4, 5, 8, 9, 10, ส่วนค้างของบท 8 (หรือย้าย Kalman/rolling ของบท 10 ไปเล่มต่อยอด), ยืนยันประโยคเรื่องเล่มเดิม และปรับ Template/Source Plan ให้ใช้เลขบทปัจจุบันและการตัดสินใจ "มือใหม่ + คริปโต" รวมทั้งแปลง `replication_note` เป็นกล่อง "ข้อควรระวังเมื่ออ่านงานนี้" สำหรับผู้อ่าน
