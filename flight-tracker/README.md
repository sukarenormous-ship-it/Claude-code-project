# ✈️ เครื่องบินลงดอนเมือง — ตัวเช็คไฟเครื่องบินสำหรับหนูน้อย

เว็บแอปหน้าเดียว (ไฟล์ `index.html` ไฟล์เดียวจบ ไม่ต้องติดตั้งอะไร) สำหรับเช็คว่า
เครื่องบินลำไหนกำลังจะบินลงสนามบินดอนเมือง พร้อมนับถอยหลังว่า
**อีกกี่นาทีจะบินผ่านบ้าน** จะได้พาลูกวิ่งออกไปดูไฟเครื่องบินทัน 🏃🌙

## วิธีเปิดใช้ครั้งแรก

1. เปิด GitHub Pages ของ repo นี้: **Settings → Pages → Source: Deploy from a branch → main / (root)**
2. เปิดบนมือถือที่ `https://<username>.github.io/Claude-code-project/flight-tracker/`
3. ตอนอยู่ที่บ้าน กดปุ่ม **📍 ตั้งบ้าน = ตำแหน่งปัจจุบัน** (หรือพิมพ์พิกัดจาก Google Maps เอง)
   — พิกัดถูกเก็บใน localStorage ของเครื่องเท่านั้น ไม่ถูกส่งไปไหน
4. กด **🔔 เปิดเสียง + แจ้งเตือน** หนึ่งครั้ง (เบราว์เซอร์บังคับให้กดก่อนถึงจะเล่นเสียงได้)
5. เปิดหน้าจอทิ้งไว้ — พอเครื่องบินใกล้จะผ่านบ้าน (ค่าเริ่มต้น: ล่วงหน้า 5 นาที
   ระยะเฉียดไม่เกิน 3 กม.) จะมีเสียง + สั่น + การ์ดสีส้มเด้งบอก

## มันทำงานยังไง

- ดึงตำแหน่งเครื่องบินสดจากเครือข่ายอาสาสมัคร ADS-B ทุก ~15 วินาที
  (ฟรี ไม่ต้องมี API key): [adsb.lol](https://adsb.lol) → สำรอง
  [adsb.fi](https://adsb.fi) → [airplanes.live](https://airplanes.live)
- คัดเฉพาะลำที่ "กำลังเข้าดอนเมือง": บินต่ำกว่า 12,000 ฟุต กำลังลดระดับ
  มุ่งเข้าหาสนามบิน หรือตั้งลำตรงแนวรันเวย์ 21/03 แล้ว
  (แยกเครื่องที่จะลงสุวรรณภูมิออกด้วยแนวรันเวย์ + ฐานข้อมูลเส้นทางบิน)
- คำนวณจากความเร็วจริงของแต่ละลำ: อีกกี่นาทีผ่านจุดใกล้บ้านที่สุด / อีกกี่นาทีแตะพื้น
- เช็คต้นทางจากฐานข้อมูลเส้นทาง (routeset ของ adsb.lol) → แสดง "มาจากเชียงใหม่" ฯลฯ
- มีจอเรดาร์เล็ก ๆ ให้ลูกดูจุดเครื่องบินค่อย ๆ เคลื่อนเข้ามา และตัวนับ
  "คืนนี้บินผ่านบ้านแล้วกี่ลำ" ให้สะสม

## ข้อจำกัด

- ต้องเปิดหน้าเว็บค้างไว้ถึงจะเตือนได้ (มีสวิตช์กันจอดับให้ในตั้งค่า)
- เวลาเป็นค่าประมาณจากความเร็วปัจจุบัน คลาดเคลื่อนได้ 1–2 นาที
- ความครบของข้อมูลขึ้นกับสถานีรับ ADS-B อาสาสมัครในพื้นที่ (แถวกรุงเทพครอบคลุมดีมาก)
