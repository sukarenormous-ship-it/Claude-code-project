# ค่าใหม่ต่อบท (ปลั๊กอินของ `tools/sab_figures.py`)

ไฟล์ `chNN.py` หนึ่งไฟล์ต่อบท (เลขบทเล่มใหม่ 00–18) มีฟังก์ชันเดียว:

```python
def extend(data, D, q):
    """data = JSON ที่สร้างแล้ว (อ่านค่าเดิมได้) · D = Decimal · q(x, n) = ปัด half-up n ตำแหน่ง"""
    return {"คีย์ใหม่": q(D("3000") / D("100000") * 100, 2)}
```

ค่าที่คืนจะเติมใต้ `data["chNN"]` · ห้ามทับคีย์เดิม (ชน = หยุด) · คำนวณจากค่าใน `data` หรือจากสูตร — ห้ามพิมพ์ผลลัพธ์ลอย ๆ
หลังแก้ให้รัน `python3 -I tools/sab_figures.py && python3 -I tools/sab_figures.py --check`

คีย์พิเศษสองตัว (ไม่เติมใต้ chNN):
- `"_claims": [{"id": "…", "ข้อความ": "…", "ระดับหลักฐาน": "สมมติฐาน|มีแหล่ง|ตัวอย่างสอน", "แหล่ง": None, "บท": [N]}]` → ต่อท้าย `_claims` ระดับบน (id ห้ามซ้ำ) ใช้กับ `data-claim` ของกล่อง 👥
- `"_แบบฝึก": [{"โจทย์": "…", "คำตอบ": 123.45}, {"โจทย์": "…"}, {"โจทย์": "…"}]` → แทน `แบบฝึก.chNN` (ข้อที่มี "คำตอบ" ตรวจด้วย `sab_persona_strip.py --grade`)
