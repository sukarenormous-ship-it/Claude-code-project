## Cluster: foundations (ch0–3) — 5 issues ยืนยันแล้ว

### 1. 🔴 ch3 §3.6 Running Example — σ_stat ไม่สอดคล้องกับ residual std ของตัวเอง
- **ปัญหา**: ตัวอย่าง Bybit↔Lighter ให้ `b = 0.9985`, `Residual std = 0.00012` แต่สรุป `σ_stat ≈ 0.00080` — ตามสูตรของเล่มเอง σ_stat = 0.00012/√(1−0.9985²) ≈ **0.00219 (0.22%)** ไม่ใช่ 0.08% (ต่าง ~2.7 เท่า)
- **ผลกระทบ**: Entry band (0.293%/−0.027%) และ Stop (0.373%/−0.107%) ที่คำนวณต่อจากค่านี้**แคบเกินจริงทั้งหมด** — ผู้อ่านที่ทำตามจะ entry เร็วเกิน/stop ตื้นเกิน
- **แก้**: เลือกทางเดียว — คง σ_stat=0.08% แล้วแก้ residual std เป็น ≈0.000044 หรือคง residual std=0.00012 แล้วแก้ σ_stat เป็น ≈0.22% + คำนวณ band ใหม่ทั้งชุด
- ความรุนแรง: **สูง — ผู้อ่านเข้าใจผิดเป็นเงิน**

### 2. 🔴 ch3 §3.10 Bias Correction — สอน Kendall bias ด้วย N ผิดหน่วย
- **ปัญหา**: ตัวอย่างใช้ `N = 30 obs` โดยโยงกับ "lookback 30 วัน" — แต่ข้อมูล intraday 30 วันมี N ≥ 720 bars ทำให้ Kendall bias จริง ≈ 0.005 เท่านั้น เล็กเกินกว่าจะอธิบาย b̂ 0.968→0.856 ได้; ชวนผู้อ่านแทน N ด้วย "จำนวนวัน" → b_corrected สูงเกินจริงมหาศาล และเข้าใจผิดว่า half-life ไม่เสถียรเพราะ bias ทั้งที่สาเหตุจริงคือ regime/selection
- **แก้**: เน้นว่า N = จำนวน bar ไม่ใช่จำนวนวัน; แยกตัวอย่าง Kendall ให้ใช้ daily bars (N=30 จริง) หรือระบุว่า intraday lookback 30 วัน bias เล็กมาก
- ความรุนแรง: **สูง — ผู้อ่านเข้าใจผิดเป็นเงิน**

### 3. 🟠 ch3 §3.10 — สูตร half-life corrected มี ×24 เกินมา
- **ปัญหา**: `−ln(2)/ln(0.975) × 24h ≈ 27 ชม.` — ที่จริง −ln2/ln(0.975) = 27.4 **bars** อยู่แล้ว (≈27 ชม. เมื่อ bar รายชั่วโมง) ถ้ากดตามสูตรที่พิมพ์ (×24) ได้ 657 ชม.
- **แก้**: ตัด "× 24h" → `≈ 27.4 bars ≈ 27 ชม. (hourly bars)`

### 4. 🟠 ch3 §3.10 ตาราง Sensitivity — b̂ กับ κ ไม่สอดคล้องกันใน bar size เดียว
- **ปัญหา**: Δt ที่ implied จากแต่ละแถว = 0.0140–0.0171 วัน (ไม่คงที่ และไม่ตรง hourly convention ของบท) เช่น b̂=0.856 hourly ควรให้ κ≈3.7/วัน (half-life ≈4.5 ชม.) ไม่ใช่ 11.1/วัน (1.5 ชม.)
- **แก้**: ระบุ bar size แล้วคำนวณ κ/half-life ใหม่ทุกแถว (แนวโน้มบทเรียนคงเดิม)

### 5. 🟠 ch2 โจทย์ 2.3 เฉลย — "4× σ_stat" ที่จริงคือ 2.7×
- **ปัญหา**: κ=2, σ=0.003 → σ_stat = 0.003/√4 = 0.0015 → 0.004/0.0015 ≈ **2.7σ** ไม่ใช่ 4σ — ต่างเชิงตีความมาก (2.7σ = โซน entry ปกติ แต่ 4σ = โซน stop/โมเดลพังตามเกณฑ์ของเล่มเอง)
- **แก้**: `ห่างกันประมาณ 2.7× σ_stat (σ_stat = 0.003/√(2×2) = 0.0015)`

## Null-hypothesis gaps ที่เจอ (สนับสนุนการเพิ่ม ch5 §5.0 ตามที่ผู้ใช้ขอ)
1. ch3 โจทย์ 3.3 เฉลยใช้ภาษา "ADF ผ่าน/ไม่ผ่าน" ก่อนถึง ch5 โดยไม่เคยบอกว่า H₀ ของ ADF = "มี unit root (ไม่ stationary)" และ "ผ่าน" = reject H₀ (p ต่ำ) — ผู้อ่านที่ชิน "p ต่ำ = แย่" จะตีความกลับด้าน
2. ch3 §3.10 อ้าง "5% significance" และ false positive โดยยังไม่มีนิยาม null hypothesis ในเล่มเลย
