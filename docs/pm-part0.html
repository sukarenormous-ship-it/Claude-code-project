Payoff Mastery

Part 0: First 30 Minutes — "วาดตามมือ"
ก่อนอ่านอะไรทั้งนั้น ทำ 4 ขั้นตอนนี้ → คุณจะวาด payoff chart เป็นแล้ว

ก่อนเริ่ม: คำศัพท์ 3 ตัวที่ต้องรู้

S₀, Sₜ, K — แค่ 3 ตัว

S₀ = ราคาหุ้น (หรือสินทรัพย์) ตอนนี้ (วันที่เปิด trade)
Sₜ = ราคาหุ้น ตอนหมดอายุ (อนาคต — ไม่รู้ว่าจะเป็นเท่าไร)
K = ราคาใช้สิทธิ (Strike Price) — จุดที่ option เริ่ม "ทำงาน"

Payoff chart ใช้ Sₜ เป็นแกน X (ราคาตอนหมดอายุ) → ทุกจุดบนกราฟตอบว่า:
"ถ้าราคาจบที่ Sₜ นี้ → ผมกำไร/ขาดทุนเท่าไร?"

Payoff vs Profit — ห้ามสับสน!

Payoff = ผลตอบแทน ก่อนหัก ค่า premium
  Long Call payoff = max(Sₜ - K, 0)

Profit = ผลตอบแทน หลังหัก ค่า premium
  Long Call profit = max(Sₜ - K, 0) - premium

Premium ไม่เปลี่ยน shape/slope — แค่เลื่อนกราฟขึ้นหรือลง:

จุดสำคัญ: Kink อยู่ที่ K แต่ Break-even อยู่ที่ K+P

Premium เลื่อนกราฟลง → จุดหักศอกยังอยู่ที่ K=100 แต่ จุดคุ้มทุนขยับไปที่ 105
ทุกกราฟในหนังสือนี้แสดง Profit (หลังหัก premium) ยกเว้นระบุเป็นอย่างอื่น

"First 30 Minutes" — 4 ขั้นตอน วาด Payoff Chart เป็น

ขั้นตอนที่ 1: วาด Long Call

Long Call = "สิทธิซื้อ" → จ่าย premium ฿5 เพื่อมีสิทธิซื้อที่ K=100

วิธีวาด (ทำตามนี้):
1. ลากเส้นแนวนอนที่ระดับ -5 (ขาดทุนเท่า premium) จากซ้ายจนถึง K=100
2. ที่ K=100 หักเส้นขึ้น slope +1 (ทุก ฿1 ที่ราคาขึ้น = กำไร ฿1)
3. เส้นตัดศูนย์ที่ K+P = 105 = break-even

ขั้นตอนที่ 2: พลิกเป็น Short Call

Short = กลับหัว Long → ไม่ต้องจำใหม่ แค่พลิกกราฟ!

ขั้นตอนที่ 3: รวม 2 ขา → Bull Call Spread

Long Call(100) + Short Call(110) → วาดทีละขา แล้วบวกรวม:

วิธีวาด:
1. วาด Long Call(100) เส้นประ: แบน → หักขึ้นที่ 100
2. วาด Short Call(110) เส้นประ: แบน → หักลงที่ 110
3. บวก y-values ทุกจุด → ได้เส้นทึบ: แบน → ขึ้น → แบน = Bull Call Spread!

ขั้นตอนที่ 4: อ่านกลับ — เห็นรูป → บอกชื่อได้

ตอนนี้ดูรูป "แบน → ขึ้น → แบน" → คุณรู้ทันทีว่า = Bull Spread

ยินดีด้วย! คุณวาด Payoff Chart เป็นแล้ว

ใน 4 ขั้นตอนคุณทำได้:
✓ วาด Long Call จากสูตร
✓ พลิกเป็น Short Call
✓ รวม 2 ขาเป็น Bull Call Spread
✓ อ่านรูปกลับเป็นชื่อ strategy

ทุกอย่างในหนังสือนี้ต่อจากนี้ใช้ 4 ทักษะนี้ซ้ำแล้วซ้ำอีก

"ได้ยินวาดได้" — โจทย์ 5 ข้อ

อ่านโจทย์ → วาดกราฟในหัว (หรือบนกระดาษ) ก่อนดูเฉลย

โจทย์ 1: "ซื้อ Long Put K=100, premium=6"

คิด: Long Put = ชันลงทางซ้าย, แบนทางขวา
เฉลย: แบนที่ -6 หลัง K → ชันลง (slope -1) ก่อน K → BE = K-P = 94 → กำไรสูงสุดที่ S=0 = 100-6 = ฿94

โจทย์ 2: "ทำ Bear Put Spread: Long Put(110) ฿8, Short Put(100) ฿3"

คิด: Bear = ลง, Spread = จำกัดทั้งกำไรและขาดทุน → "แบน → ลง → แบน"
เฉลย: net debit = 8-3 = ฿5 → max loss = -5 (ราคาเกิน 110) → max profit = (110-100)-5 = +5 (ราคาต่ำกว่า 100)

โจทย์ 3: "ทำ Long Straddle K=100, Call premium=5, Put premium=5"

คิด: Straddle = V-shape → ขาดทุนถ้านิ่ง, กำไรถ้าผันผวน
เฉลย: trough ที่ K=100, max loss = -10 (2×premium) → BE = 90 และ 110 → กำไรไม่จำกัดทั้งสองทิศ

โจทย์ 4: "คิดว่าราคาจะนิ่งอยู่ระหว่าง 90-110 → ออกแบบ payoff"

คิด: กำไรตรงกลาง ขาดทุนสองข้าง → "ที่ราบสูง" = Iron Condor
เฉลย: LP(85) + SP(90) + SC(110) + LC(115) → เก็บ premium ถ้าราคาอยู่ระหว่าง 90-110

โจทย์ 5: "เพื่อนบอกว่า 'ขาย Iron Condor ได้ 80% ของเวลา = easy money'"

คิด: Payoff ≠ Prediction! กำไรบ่อย ≠ กำไรระยะยาว
เฉลย: 80% ชนะ ฿2 + 20% แพ้ ฿8 → EV = 0.8×2 + 0.2×(-8) = 1.6-1.6 = 0 → ไม่มี edge!
"ก่อนดูกราฟ ต้องคิด EV ด้วยเสมอ"
